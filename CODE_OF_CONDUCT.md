# Code of Conduct

WiseOwl COBOL adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct — the same foundation used by the .NET, Swift and many other language and compiler
communities. Everyone who participates in this project's spaces — issues, pull requests, discussions, reviews and
commit messages — is expected to follow it.

## In short

- Be respectful and assume good faith. Disagreement about the standard, a design or a defect is welcome; personal
  attacks are not.
- Critique code, citations and results — never people.
- Harassment, discriminatory language, sexualized content, doxxing and sustained disruption are not tolerated in any
  form.
- Keep technical arguments grounded in evidence: the ISO/IEC 1989 text, a reproducing program, a measured result.

## Scope

This code applies in every project space, and when an individual is representing the project in public.

## Reporting

Report unacceptable behavior privately to the maintainer at **conduct@wiseowl.com**. Reports are handled
confidentially. The maintainer will review every report, respond to the reporter, and take whatever action the
Contributor Covenant's enforcement guidelines call for — from a private warning up to a permanent ban from project
spaces.

If the report concerns the maintainer, say so in the message; it will be handled with that conflict disclosed.
