# Compiler Phases (Frontend Internals)

Detail behind each phase of the [[kb/Compiler/Pipeline]].

## Preprocess
`Frontend.Preprocess` runs five stages, each a no-op on source that doesn't use it:
`StripNistArchiveMarkers → NormalizeToFreeForm(edition,permissive) → ConditionalCompilation interleaved with COPY →
NistPreprocessor(if NIST)`, then the line-count-neutral directive collectors
`>>TURN → >>PROPAGATE → >>REF-MOD-ZERO-LENGTH → >>FLAG-02/14 → >>COBOL-WORDS`. Responsibilities:
- **Reference-format** (fixed↔free) normalization — only this column-aware pass can see the indicator column (VCR rows 2/94 gate here).
- **Conditional compilation** (`>>DEFINE`/`>>IF`/`>>EVALUATE`), processed *inside* copybooks (§7.2.1).
- **COPY … REPLACING** / **REPLACE**.
- **NIST CCVS** `XXXXX###`/`XXXXP###`/`XXXXD###` placeholder substitution (runs after COPY so placeholders inside copied text are substituted).

> Hard invariant (hazard H3): each directive collector must be **line-count-neutral** — if it changes line count it
> throws, because TURN/FLAG anchoring compares `event.Line` to token `Start.Line`, and drift would silently misanchor.

## Lex
The ANTLR `CobolLexer` (`caseInsensitive=true`) with **4 modes**: `DEFAULT`, `PICMODE` (PIC/PICTURE captured as one
token), `SUBSCRIPT`, `COMMENT_MODE` (`*>` to EOL). SUBSCRIPT mode solves the `x(i)`-subscript vs `(a+b)`-grouping
ambiguity: `LPAREN` pushes SUBSCRIPT only when the previous token could be a data-name; it emits parallel `SUB_*`
tokens. Shared literal `fragment`s (`STR_BODY`/`NAT_BODY`/`INT_BODY`/…) are referenced by both DEFAULT and `SUB_*`
twins. Between lex and parse, `ZeroTokenRewriter` retypes `ZERO→ZERO_ARITH` near arithmetic operators (kills an
exponential-prediction ambiguity) and `CobolWordsRewriter` applies `>>COBOL-WORDS` synonyms/de-reservations.

## Parse
Superset `CobolParserCore`, **two-stage** strategy: fast `PredictionMode.SLL` with `BailErrorStrategy`, falling back
on cancel/recognition exceptions to full `LL` with the diagnostic-collecting `CobolErrorStrategy`. A non-parse
exception (buggy predicate/action) propagates instead of being masked as a syntax error.

### The modular grammar — 9 imported Core fragments
```
import CobolExpressions, CobolData, CobolSpecialNames, CobolReportWriter,
       CobolIO, CobolControlFlow, CobolOO, CobolScreen, CobolWords;
```
| Fragment | Covers |
|---|---|
| **CobolExpressions** | literals, arithmetic/condition/boolean tiers, FUNCTION calls, comparisons |
| **CobolData** | DATA DIVISION: FD, level entries, PIC/USAGE/OCCURS(+DYNAMIC)/REDEFINES/VALUE/TYPEDEF, INITIALIZE |
| **CobolSpecialNames** | SPECIAL-NAMES: CURRENCY/DECIMAL-POINT/CLASS/ALPHABET/SYMBOLIC/CRT/CURSOR |
| **CobolReportWriter** | REPORT SECTION, RD, report groups (85 + 2002 PRESENT WHEN/VARYING) |
| **CobolIO** | INPUT-OUTPUT SECTION, FILE-CONTROL/SELECT, OPEN/READ/WRITE/…, SORT/MERGE |
| **CobolControlFlow** | PERFORM/IF/EVALUATE/GO TO/SEARCH/ALTER/USE/EXIT/STOP/CONTINUE/NEXT SENTENCE |
| **CobolOO** | CLASS/INTERFACE/METHOD, INVOKE, inline method invocation |
| **CobolScreen** | SCREEN SECTION description entries (parse-only today) |
| **CobolWords** | `<auto-generated>` `cobolWord` rule (context-sensitive user-words) from `cobol-words.json` |

## CST vs bound tree
The parser yields a pure syntactic **CST** (`CompilationUnitContext`). The `Cst/` layer (`DataDescriptionCst`,
`DataReferenceCst`) is a thin typed façade retiring ~336 `GetText()` binder hand-walks. All *semantics* live in the
**bound tree** the binder builds — the CST carries none. See [[kb/IR/Node Types]].

## Version-conformance mechanism
The *implemented* state (supersedes an earlier "grammar construct-id annotation" design): a **two-arm post-bind walk**
that recovers construct identity *itself* (no `.Syntax` back-reference on bound nodes). Arm 1 (bound-tree) keys
genuinely-semantic gates on resolved node type/attribute; Arm 2 (`ParseArm`, over the raw tree) re-recognizes
syntactic introduction/removal/phrase gates + the §8.9 reserved-word funnel — because an introduction gate must fire
on *recognition* even when the construct also fails to bind. Version *numbers* stay single-sourced in
`constructs.json`. Only two forward-detect predicates survive in the grammar (`retryPhraseAhead()`, `boolExprAhead()`).
See [[kb/Semantics/Passes]].

## Key concepts
- 5-stage preprocessor, each stage a no-op if unused; directive collectors line-count-neutral (H3 throws).
- ANTLR lexer: 4 modes; SUBSCRIPT mode + `ZERO→ZERO_ARITH`; shared literal `fragment`s.
- Two-stage SLL(bail)→LL(recover) parse; superset grammar, 9 imported Core fragments.
- CST = syntax only; bound tree = all semantics.
- Edition conformance = one two-arm post-bind pass; `constructs.json` owns version numbers.
