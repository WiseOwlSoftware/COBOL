# PB1703 — LANDED (2026-09-28)

**Found** when the owner asked, 2026-09-28 ~11:30 PDT: "My statusline shows a shell named 'rolling-wave' (though
there are two) which has been running 16h16m and appears to be completed. Why?"

## The defect

`.claude/skills/workstream/templates/wf_rolling_wave.js`: `runGroup` maps a NULL agent result to `NO-RESULT`, but an
agent that dies on an API error makes `agent()` REJECT. The worker then did the following:
- `running++` was done before the call, and `running--` came after the await, so the count was never decremented;
- `onResult` never recorded the group;
- the wake-up that releases parked workers was never sent;
- the rejection propagated out of the worker, and `parallel()` swallowed it as a null thunk.

A same-file successor (`after:` the dead group) never became eligible, and the worker parked on `wake` found
`running > 0`, so it waited forever. Wave 68's workflow (`wf_e9a82a33-6b6`, task `w0pnnjh1q`) did exactly this after
group U's agent died on an API error on 2026-09-27. It showed as running for 16 h, with its real work later finished
by wave 69, until the orchestrator stopped it with TaskStop.

## The fix

The worker now catches a rejection and records it as `NO-RESULT` with the error text, the same as a null result. It
decrements `running` in a `finally`, and sends the wake-up in a `finally` after `onResult`. A dead predecessor
therefore releases its successor, which runs fresh from main: `successorNote` already says "your predecessor
produced NO branch".

**Proof** (`scratchpad/sim_rolling.js`): the REAL script body runs with a mock `agent()` whose group U rejects, with
U2 `after: U` and one more group. The pre-fix script hangs (a 5 s timeout, only 2 agents started). The fixed script
finishes with U = NO-RESULT, U2 started fresh, and one train landed. `check_practices.py` is GREEN.

## Sibling

The public `agent-fleet/references/rolling-wave.js` shares this scheduler and gets the same fix when the project's
rolling wave migrates onto it (PB1699's remaining phase, after wave 70).
