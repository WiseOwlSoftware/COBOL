# PB3822 — the per-script reconfigure copy can hide behind a line break

**Sites:** `scripts/standard_streams.py#COPY_RE` (line 63, `\.reconfigure\([^)]*\b(?:encoding|errors)\s*=`) and the scan that
applies it to `source.splitlines()`; the scan already parses the AST for the ENTRY rule (`_is_main_guard`).

## Measured

Re-read on origin/main 33e3dcf21. The regex is applied per physical line, so
`sys.stdout.reconfigure(\n    encoding="utf-8")` or `reconfigure(**kw)` is not reported, although PB3637's rule is that no
live script keeps its own copy (the finding is: one UTF-8 switch). A copy written that way reopens the cp1252 crash PB3637 closed.

## Acceptance

- The COPY rule is found on the parse tree (a `Call` whose function attribute is `reconfigure` and whose keywords include
  `encoding`, `errors` or `**`), not by line; the `-c` string arm keeps the regex over the whole string with `re.S`.
- `--self-test` has an arm for a wrapped call and a `**kwargs` call, each reported; the sweep over the live tree stays
  at 0 findings.
