# PB3953 — an arithmetic expression wider than 38 significant digits inside a function argument keeps about 38 digits where GnuCOBOL's GMP intermediate is exact

**Sites:** `src/WiseOwl.Cobol.Runtime/Values/Numeric/FunctionValueField.cs:65` (`FunctionValueField.OfValue`), `docs/CONFORMANCE.md` (DOC-A.1-123)

`ABS(BIG * BIG * BIG)` with 18-digit items differs from cobc in its DIGITS: ours ends `...100000000000000000000`, cobc's
exact result ends `...2999999999999999999`. The standard-decimal intermediate keeps 34 digits and the value 38, where
cobc's GMP is exact. The report calls it intermediate-precision latitude (a nested product past 77 digits is already a
documented determination, `docs/CONFORMANCE.md` DOC-A.1-123); it is filed because the PB3514 review found it recorded in
prose only. Probe: `scratchpad/q` `e.cob` of the PB3514 implementer.

## Acceptance
- Adjudicate whether the determination in DOC-A.1-123 covers an expression inside a function argument; either record the
  case in that row or make the argument exact to the 77-digit lane the non-argument arm already has.
