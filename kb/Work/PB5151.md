# PB5151 - COBOL6862 on a TYPE copy points at the template, once per referencing item

**Sites:** none (the fix site is not located: the TYPE-copy clone path that keeps the source `DeclaredAt`).

**Found.** PB5073's branch review: when a TYPE clause copies a template and the copy trips COBOL6862, the diagnostic carries the template member's line because a clone keeps the source `DeclaredAt`. It is also reported once per item that references the type. The user sees a location inside the template, not at the declaration that caused the error, and repeated reports of one fault.

**Owed.** Give a clone the referencing item's location for diagnostics (or report at the reference with the template as a related location), and report once per template member. Sweep other diagnostics raised on clones for the same location fault.
