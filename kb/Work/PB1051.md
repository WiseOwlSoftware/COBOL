# PB1051 — OPEN

## Measured
Method `D47K.M` with `LINKAGE SECTION. 01 LN PIC S9(4) COMP-5.` / `PROCEDURE DIVISION USING BY VALUE LN.`, invoked
`INVOKE O "M" USING BY VALUE N` → `error COBOLNET0899: method 'M': the BY VALUE phrase on method formal parameter 'LN'
is recognized (ISO §14.2.2 SR2) but a method's value-copy formal is not yet implemented on the INVOKE channel`, and a
second `COBOLNET0828 … header BY VALUE formals are a later slice` on the INVOKE.

## The rule
`cite.py --check 14.2.2 "Each data-name-1 specified in a BY VALUE phrase shall be defined as a data item of class numeric, message-tag, object, or pointer"` → `OK §14.2.2 2)`.

## Code site
`Binding/DataBinder.Oo.cs` ~370 (`DiagnosticCatalog.ByValueFormalCarrier`); the INVOKE argument binder's BY VALUE arm.

## What the fixer owes
The value-copy formal on the method ABI (a C# by-value parameter of the formal's native type, the program ABI's
BY VALUE arm reused), both diagnostics retired; golden for numeric, pointer and object BY VALUE formals.
