# PB3174 — conformance suite slice S1a

Owner approved `docs/rearchitecture/DESIGN-conformance-suite.md` on 2026-10-14 ("approved", revision 2; kb/Work PB3160 holds the decisions verbatim).

**Prerequisites:** PB3172.

**Scope:** Design §13 S1a, built from §3 (the test case), §4 (the tree and the generator) and §9 (drift tests). `conformance-suite/harness/generate.py` parses headers in fixed and free form, refuses everything §4 lists, writes `suites/<edition>/manifest.json` and the `wiseowl` manifest (git-ignored build output), and prints the completeness report by witness kind; `--check` (the refusals only, writing nothing) is a gate audit, one entry of `run_gate_legs.py`'s AUDITS and a command of CI's `audits` job, so a refused test is red in seconds, before the gate slot and the build (design §9); `--self-test` is discovered by `scripts/self_tests.py`. Proved on a seed of tests written from the standard into `conformance-suite/cases/`: an accepted test, a per-edition output, a flag test with its control, an A.1-valued test and a test with a copybook. The old corpus is not touched (PB3177 moves it).

**Rules for the implementer:** implement this slice FROM the design (the sections named above), not from this note, which is its register entry; the complete slice with its tests and drift tests (CLAUDE.md rules 3, 5); a design correction lands in the design in the same change (rules 2, 6); every ISO citation through `python scripts/spec/cite.py --check`; no wrapper, alias or compatibility layer (rule 4); the gate is `pwsh scripts/build-local.ps1 -Priority BelowNormal`; flip this note to `landed` and write `closes_rows` (or `closes_rows_reason`) in the commit that lands it.

## Landed

Wave 1104 C3 (2026-10-16), on PB3173's branch (PB3172 and PB3173 land through it).

**The generator.** `conformance-suite/harness/generate.py` is the one reader of the test headers: it parses the
metadata block in fixed form (`*>` in columns 7-8) and free form (`*>` in column 1), refuses everything design §4
lists (now written out there in full), writes `suites/<edition>/manifest.json` (the cleared tests of `cases/`),
`suites/wiseowl/manifest.json` (every test of both trees at each edition it names, and `wiseowl/diagnostics.json`)
and `suites/completeness.json`, and prints the completeness report by witness kind. `harness/cobol_source.py` holds
what the refusals read from program text: the reference format, tokens, COPY statements, whether the program
observes an exception condition, the class of each data item and the DISPLAY operands. Standard library only.
`--check` is the gate audit `CONFORMANCE SUITE` (`scripts/run_gate_legs.py` AUDITS) and a step of CI's `audits`
job; `--self-test` (68 arms: the manifests on a planted good tree, every refusal on a planted bad one, the source
reader's own arms) is discovered by `scripts/self_tests.py`, whose discovery trees are now `ROOTS = ("scripts",
"conformance-suite/harness")`, read by `SelfTestDiscoveryDriftTests` for its net.

**The seed** (`conformance-suite/cases/`), written from the standard and probed on this branch's `cobol.exe` at
85, 2002, 2014 and 2023: `compute-multi-receiver-size-error` (§14.9.8.4 GR 2, §14.7.5), `compute-alphanumeric-receiver`
(flagged, §14.9.8.3 SR 1; WiseOwl reports COBOLNET1675 at the marked line 20) and its control
`compute-numeric-receiver`, `read-previous-after-open-indexed` (per-edition output: §14.9.30.4 GR 21 d) 3 at 2023,
the first record Annex E.2 item 22 records for 2002 and 2014), `turn-location-unspecified` (A.1 item 204, one
output per value; WiseOwl prints the not-available one, DOC-A.1-204) and `copy-library-text` (a declared
copybook). The generator caught one of them on its first run: a comment line past column 72.

**Design corrections** (in DESIGN-conformance-suite.md, same change): the `constructs` field (§3.1), because no
reader short of a compiler can tell which registry constructs a program uses, so "accept/flag lists that contradict
the construct registry" needs the test to name them; the fixed-form marked line opens the sequence number area
(§3.2), since COBOL-85 has no floating comment and margin R is implementor-defined after 85 (§6.3.1); the lint's
figurative, reference-modification, `UPON` and margin rules (§3.3); `implementor-defined.json` as the registry of
enumerated A.1 items (§3.3); and the manifests' contents and the completeness order (§4).

**Not done here:** the completeness report on the ledger (§9's last bullet) — the ledger's content is the owner's
(kb/Work PB2912); raised as a lead in the wave report.

  cannot classify. S2's migrated tests are `portable: unverified`, so the lint does not read them.
