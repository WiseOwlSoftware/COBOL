# PB3174 — conformance suite slice S1a

Owner approved `docs/rearchitecture/DESIGN-conformance-suite.md` on 2026-10-14 ("approved", revision 2; kb/Work PB3160 holds the decisions verbatim).

**Prerequisites:** PB3172.

**Scope:** Design §13 S1a, built from §3 (the test case), §4 (the tree and the generator) and §9 (drift tests). `conformance-suite/harness/generate.py` parses headers in fixed and free form, refuses everything §4 lists, writes `suites/<edition>/manifest.json` and the `wiseowl` manifest (git-ignored build output), and prints the completeness report by witness kind; `--check` (the refusals only, writing nothing) is a gate audit, one entry of `run_gate_legs.py`'s AUDITS and a command of CI's `audits` job, so a refused test is red in seconds, before the gate slot and the build (design §9); `--self-test` is discovered by `scripts/self_tests.py`. Proved on a seed of tests written from the standard into `conformance-suite/cases/`: an accepted test, a per-edition output, a flag test with its control, an A.1-valued test and a test with a copybook. The old corpus is not touched (PB3177 moves it).

**Rules for the implementer:** implement this slice FROM the design (the sections named above), not from this note, which is its register entry; the complete slice with its tests and drift tests (CLAUDE.md rules 3, 5); a design correction lands in the design in the same change (rules 2, 6); every ISO citation through `python scripts/spec/cite.py --check`; no wrapper, alias or compatibility layer (rule 4); the gate is `pwsh scripts/build-local.ps1 -Priority BelowNormal`; flip this note to `landed` and write `closes_rows` (or `closes_rows_reason`) in the commit that lands it.
