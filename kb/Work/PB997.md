# PB997 — OPEN

## The gap
`scripts/spec/audit_code_citations.py`'s DIAG arm walks `src/` only. A test's assertion message is read by a developer
chasing a failure exactly as a diagnostic is read by a user, and the PB388 sweep (which derived prose citations for
diagnostics) left the tests' copies untouched.

## What the fixer owes
Extend the DIAG arm to the test projects' string literals (or a TEST arm with the same rules), make it fail once on the
current tree (memory `green_gates_arent_evidence`), then fix the ~7 sites with `cite.py --check`-derived numbers.
