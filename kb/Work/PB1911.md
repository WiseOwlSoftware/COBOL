# PB1911 — one may-share predicate, not two

Found by the train-1002 lander's review (the four PB1907 groups were implemented in parallel from one base).

## The duplication

- `src/Cobol.Net.Compiler/Binding/Model/StorageOverlap.cs` `MayShareStorage(Place, Place)` (public; INSPECT,
  `InspectEmitter.EmitBody`): walks the two root-to-item paths through the REDEFINES chain (`RedefinesTarget`,
  which also models the implicit file-record redefinition and SAME RECORD AREA), so two siblings of one record are
  proven disjoint; LINKAGE and BASED roots answer "may"; RENAMES judged by its leaves.
- `src/Cobol.Net.Compiler/Binding/Model/StorageSharing.cs` `MayShare(Place, Place)` (internal; UNSTRING,
  `StringEmitter.EmitUnstring`): record-level only — same 01, same REDEFINES class, any two FILE SECTION records,
  LINKAGE/BASED; compiler temporaries share nothing; RENAMES by its From/Thru roots.

Both docstrings say "THE ONE … question", and `UnstringLiveReadDriftTests` pins "the UNSTRING emitter asks this and
no private copy", which is true per emitter but not across them. They answer the same question with different
precision (StorageOverlap is finer: siblings in one record are disjoint; StorageSharing calls them "may"), so the
two verbs re-read in different situations for the same storage facts. Both are conservative, so no wrong answer
was found; the cost is two rules to keep in step (CLAUDE.md rule 4, one mechanism per job).

`src/Cobol.Net.Compiler/Binding/Model/StorageExtent.cs` (MOVE, group D) answers a DIFFERENT question — "do these
two operands PROVABLY overlap?" (null = not provable) — and is not a duplicate; the unified predicate may still
use it for its "disjoint" proof.

## Closing shape

One public predicate (keep StorageOverlap's path walk, add StorageSharing's compiler-temp arm), every caller moved
to it, the other class deleted (no forwarder), and one drift test that fails when a second may-share predicate
appears. Re-run the PB1907 goldens (INSPECT and UNSTRING) — the finer answer may remove UNSTRING re-reads but must
not change any pinned line. PB1908 (STRING) should ask the unified predicate.
