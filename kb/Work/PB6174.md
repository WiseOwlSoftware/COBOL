# PB6174 — the numeric constant-name check reaches into function arguments

**Mechanism.** PB5709's round-2 fix (R2-2) makes `ConstantEntryBinder.BindConstantLength`, in its Deferred arm at --std 2002, check every
written name token of a subscript (the word after FUNCTION excepted): an undefined name is refused, and a constant-name must be
`PicCategory.Numeric`, else COBOL1547. The loop walks the leaf tokens of the whole subscript group, so a name that is only an
argument of a function in the subscript is held to the numeric rule too.

**Why it is wrong (reviewer R3-1, from the report).** §2002:15.39.2 AR1 admits an alphanumeric literal as the argument of FUNCTION
LENGTH, and the function is of type integer, so `E (FUNCTION LENGTH (KC))` is an arithmetic expression whose value is numeric whatever
the category of `KC` (§2002:8.8.1). The category rule belongs to operands outside a function argument list only. The undefined-name
check (R2-1) is right everywhere. A non-numeric constant-name that is a legal argument of an integer function is therefore refused
legal source.

**Repro (from the review, unrun here).** At `--std 2002`, a constant entry `LENGTH OF CELL (FUNCTION LENGTH (KC))` where `KC` is an
alphanumeric constant-name: expected accepted, observed COBOL1547 "the subscript constant-name 'KC' is not numeric".

**Fix shape.** Skip the category test for a name token inside a function's argument list (keep the defined-name test); a drift
guard for the pair (alphanumeric constant-name as a function argument accepted; as a bare subscript operand refused).
Cite §2002:15.39.2 AR1 and §2002:8.8.1 after `cite.py --check`.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/ConstantEntryBinder.cs:621` (`ConstantEntryBinder.BindConstantLength`, `SubscriptFrame`, `FunctionResultIsNotNumeric`), `src/WiseOwl.Cobol.Compiler/Binding/IntrinsicArgumentRules.cs` (`IntrinsicArgumentRules.ConstantArgumentClause`)

**Fixed.** `BindConstantLength`'s Deferred arm now keeps a paren-context stack over the subscript's tokens (FNARG / REF / grouping) and applies the numeric-category test only to a name outside a function argument list; the defined-name test is unchanged. Goldens: `13.9@2002-CONSTANT-ENTRY/pb6174-constant-length-alphanumeric-function-argument` (accepted, K=3); the bare-operand twin `pb5709-constant-length-alphanumeric-constant-subscript` stays refused.
