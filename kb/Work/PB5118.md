# PB5118 - at --std 85 a PICTURE repeat count after a symbol outside the 1985 list compiles (PIC 9(3)V(1)9, S(1), CR(1)); 1985 allows a parenthesized integer only after A , X 9 P Z * B / 0 + - and the currency symbol

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/PictureAnalyzer.cs#TryExpandRepeats` (line 831: validates the integer alone, under §2023:13.18.40.3 SR6, at every edition; no 1985 check of the symbol the parenthesis follows)

**Mechanism.** The 2023 rule gives the count to "the symbol that immediately precedes the left parenthesis" (§2023:13.18.40.3 SR6), so any symbol may take a count. The 1985 clause lists the symbols a parenthesized integer may follow and states that S, V, ., CR and DB may appear only once; V is not in the list, so `V(1)` is not a 1985 character-string. Siblings probed: PIC S(1)9(3) and PIC 9(3)CR(1) also compile clean; X(0) and 9(+2) draw COBOL2147, S(2)9 and 9V(2)9 draw COBOL1934. kb/Work PB531 (landed) made the integer test and is not this.

**Found by.** The 1985 witness-drafting pass (kb/Work PB4995 item 3): each rule below is a witness program drafted from the 1985 text alone, run at `--std 85`, and its result differs from what the text requires (outcome MISMATCH). Harm and observed text are the record's; nothing here was re-derived.

**Inventory.** The traceability inventory carries no 1985 rows yet (PB5094: work.py refuses 1985 ids), so `inventory_rows` is empty; the row this note covers is the 1985 rule id listed below (catalog `docs/rearchitecture/spec-rule-catalog-1985.json`).

Full rule: "An unsigned nonzero integer which is enclosed in parentheses following the symbols 'A', ',', 'X', '9', 'P', 'Z', '*', 'B', '/', '0', '+', '-', or the currency symbol indicates the number of consecutive occurrences of the symbol." §1985:VI.5.9.3 SR2 admits only "certain allowable combinations of characters ... used as symbols".
