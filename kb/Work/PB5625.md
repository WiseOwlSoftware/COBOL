# PB5625 - two open readings of the 2002 text: a parameterized interface without EXPANDS, and the class of a USAGE NATIONAL numeric item

**Sites:** none (a recorded pair of open readings; no code change is claimed until each is decided)

The report's text for each item follows, unchanged in substance. Every citation below was re-checked with `python scripts/spec/cite.py --check`.

## Reading 1

**Item.** first pass: USE AFTER EXCEPTION OBJECT naming a parameterized interface listed in REPOSITORY without EXPANDS is refused COBOL0859 at --std 2002 (row 2002-SR-14.8.45.2-17; repro E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/p/use_eo_param.cob)

**Outcome.** still conditional: the 2002 text does not settle it

**What the text says.** No 2002 rule forbids the use, and four rules point toward allowing it. §2002:12.2.7.3 GR7 'Interface-name-2 is the name of an interface that may be used throughout the scope of the' (OK). §2002:12.2.7.2 SR9b requires only repository information for an INTERFACE phrase without EXPANDS (quote 'If literal-2 is not specified, there shall be information in the external repository for the interface interface-name-2', OK). §2002:9.3.13 'When a parameterized interface is specified in the REPOSITORY paragraph, a new interface' (OK), which ties instance creation to naming the interface, where §2023:9.3.13 ties it to EXPANDS ('When an interface is specified as the parameterized interface in an EXPANDS phrase in the REPOSITORY paragraph', OK).

**What is unsettled.** The only creation rule that supplies actual parameters is §2002:12.2.7.3 GR8 (EXPANDS; OK), and §2002:9.3.13 says the expansion functions as a non-parameterized interface only 'When it is expanded by substituting specific class-names or interface-names as actual parameters' (OK). So 2002 does not define what interface an instance created without actual parameters is, or whether an exception object can conform to it. Under the owner's rule (judge on the 2002 text) the refusal's stated ground, §2023:12.3.8.4 GR7's second sentence, is not 2002 text whatever the answer, so at minimum it is a PB4950 citation instance. Whether it is also rejected legal source needs a recorded reading (a kb/Work adjudication) of what 9.3.13 creates when no EXPANDS is written.

## Reading 2

**Item.** a numeric or boolean item of USAGE NATIONAL as class national (DISPLAY-OF argument-1, LOCALE-COMPARE, LOCALE-DATE) is refused COBOL1546/COBOL1627 at 2002 and 2023 (rows 2002-AR-15.21.2-1, 2002-RV-15.40.3-1 DOUBTFUL, the numeric-national leg of 2002-AR-15.41.2-1)

**Outcome.** conditional: the 2002 text conflicts with itself

**What the text says.** §2002:8.5.2.7 lists 'An elementary data item explicitly or implicitly described as usage national.' (OK) as category national, while §2002:8.5.2.9 lists 'An elementary data item described as numeric by its PICTURE character-string and not descr' (OK) as category numeric.

**What is unsettled.** which category a PIC 9 USAGE NATIONAL item has in 2002; needs an adjudication (and the PDF page) before any note.
