# at --permissive a reference that resolves an ambiguous name to its first declaration records no occurrence: a candidate set of several records none, and the compile goes on with a warning

**Found by** listing step 7b (branch `listing-step-7b-2`, kb/Work PB5925's dated file `2026-11-20-step-7b-2-built`, lead 7 of its list), filed by step 9b so no lead of the listing's design stays in a dated paragraph alone.


`SymbolTable.Identify` records an occurrence for a candidate set of one member only. The `--permissive` resolution that picks the first
declaration of an ambiguous name reaches a program with a warning, so the cross-reference lacks that reference. The oracle binds clean
programs and never meets it. **Fix:** record the occurrence at the declaration the resolution picks, and a planted permissive program in
the cross-reference tests.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/SymbolTable/SymbolTable.Identify.cs` (`SymbolTable.Identify`), `src/WiseOwl.Cobol.Compiler/Binding/ReferenceResolver.cs` (`ReferenceResolver.Identify`).
