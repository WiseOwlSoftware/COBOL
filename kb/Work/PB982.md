## Reproduced

`reg11/h843a.cob`:

```cobol
       SPECIAL-NAMES.
           CLASS MY-DIG IS "0" THRU "9".
       ...
       01 WS-X PIC X VALUE "5".
       PROCEDURE DIVISION.
           IF WS-X DISPLAY "IF-WSX" END-IF
```

→ compiles with **no diagnostic**, then `Unhandled exception. CobolNet.Runtime.NotImplementedCobolFeatureException:
COBOL.NET: a COBOL feature that is not yet implemented was reached at run time: condition 'WS-X'` (rc 127). The source
report measured `IF MY-CLASS` the same way.

## Rule

- `python scripts/spec/cite.py --check 8.8.4.2.1 "The simple conditions are the relation, boolean, class, condition-name, switch-status, sign, and omitted-argument conditions"` → OK §8.8.4.2.1

A PIC X data-name is none of these, and a bare class-name is a class condition only WITH its identifier (the
identifier-less form is §14.9.13.3 SR5's EVALUATE selection object, which PB843 handles, and not an IF condition).
`IF WS-X` is non-conforming and must be a compile-time error. ⚠ A BOOLEAN data item alone IS a boolean condition
(§8.8.4.2.1's "boolean") — the fixer keeps that arm legal and measures it.

## Cause and what the fixer owes

`ConditionBinder.BindSoleOperandCondition` (`src/Cobol.Net.Compiler/Binding/Procedure/Verbs/ConditionBinder.cs`, callers
at :281 and :768) ends in a branch that returns `BoundConditionError` WITHOUT reporting a diagnostic, and the emitter
lowers an error node to a run-time NotImplemented throw. Two fixes, both owed: (1) the branch reports a named
diagnostic naming what the word IS (data-name / class-name / alphabet-name / mnemonic) and what a condition may be;
(2) a drift test that every `Bound*Error` node the binder returns is accompanied by a reported diagnostic — the
emitter's NotImplemented lowering of an error node is a silent-crash channel for every other verb too (sweep the other
`Bound…Error` constructions for the same diagnostic-less return). Condition positions to sweep: IF, EVALUATE `WHEN`
condition objects, PERFORM UNTIL, SEARCH WHEN, the NOT / AND / OR operands, and an abbreviated combined relation.
