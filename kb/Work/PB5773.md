# PB5773 - SEARCH ALL accepts a parenthesised WHEN condition that Format 2 does not have (every edition)

**What is wrong.** SEARCH ALL accepts a WHEN operand enclosed in parentheses, which Format 2 does not print, at every edition. Page 354 (VI-122) rendered: Format 2 WHEN is `{data-name-1 {IS EQUAL TO|IS =} {identifier-3|literal-1|arithmetic-expression-1} | condition-name-1} [AND {...}]...` with no parentheses; only Format 1's condition-1 may be any conditional expression (SR3). `WHEN (K1 (IX) = "B")` is outside the format but compiles and runs at 85 and at 2023; 2023 `FMT-14.9.37.2` prints the same Format 2. `TryPrimary` unwraps `LPAREN condition RPAREN` silently with no edition switch. The Mythos lane did not run this mechanism itself; the checker ran it.
