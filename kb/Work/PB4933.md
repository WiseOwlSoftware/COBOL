**Repro.** `E:/COBOL-coord/scratch/w20261911b/c22.cob --std 85` (a program that declares a screen item named SCREEN in a SCREEN SECTION): draws `COBOL0001:
unexpected 'SCREEN'` at (4,8). The case `a42-screen-section-at-85` (the same section without the item named SCREEN) draws `COBOL1560: the SCREEN SECTION`.
SCREEN is a free word at 85, the program declares it, and the gate retypes EVERY SCREEN token to `IDENTIFIER`, the section header's too, so
`screenSection` (which spells the bare `SCREEN` token) no longer matches. Expected: the same COBOL1560 (the facility is a later edition's), naming the SCREEN SECTION,
because the user word is incidental to the real refusal. Observed: a generic syntax error that names neither the section nor the edition rule.
The implementer judged the existing `keywordWhereFree` mechanism a poor fit (85 prints no SCREEN SECTION, so it has no keyword to retain), so the fix is a design
question (retype only SCREEN tokens in a name position, i.e. not the first word of a section header, or make the header accept `IDENTIFIER` spelled SCREEN at 85 with the
edition refusal). Low harm: the source is non-conforming at 85 either way. Shares no root with another lead.

Source report and lead: `w20261911b-PB4890-report.md`, New defects.

**Resolution (wave 20261915 F).** Re-probed on f19719cfaf: `c22.cob --std 85` drew `(4,8): error COBOL0001: unexpected 'SCREEN'`.
The mechanism is wider than SCREEN: every reservation-gated word that heads a section or paragraph header of a construct its free
editions lack lost that construct's edition refusal once declared (LOCAL-STORAGE at 85 drew COBOL0001, REPOSITORY and OPTIONS at 85
COBOL1971; COMMUNICATION and CD at 2014/2023 and the five comment paragraphs from 2002 COBOL0001). Fix: a row determination,
`refusalWhereFree`, names those words, and the gate KEEPS the keyword tokens a pass read in a keyword position of such a word the pass
declared (`TokenRetypes.KeptKeywords`, by source offset), retyping the rest. The note's other option, a `<word>Keyword` rule with an
IDENTIFIER arm (the `keywordWhereFree` shape), was built and measured first: the arm entered every predicate-blind ATN reading of the
error strategy and moved 14 Unit and 13 Conformance diagnoses (`MAIN SECTION.` read as a LOCAL-STORAGE header after a missing period,
`WIBBLE GLOBAL.` named GLOBAL), so it was withdrawn. The six source-unit words (CLASS-ID, FUNCTION-ID, INTERFACE-ID, METHOD-ID, FACTORY,
OBJECT) carry no determination (a unit header competes with a COBOL-85 procedure paragraph; FACTORY and OBJECT key phrases a name
competes in). Design: `docs/rearchitecture/DESIGN-frontend-grammar.md` ("A LATER CONSTRUCT'S KEYWORD IS KEPT").
