# PB1590 — LANDED

## What happened
`bash scripts/push-main.sh` on `1de01e454` (doc-rows-2: §7 rows, inventory verdicts, kb/Work notes, one drift-test
edit — no compiler source touched) went RED on exactly one test, in the Windows leg's "Greenfield unit tests" step:

```
Failed CobolNet.Tests.Unit.DeepNestingTests.DeeplyNestedGroup_CompilesInLinearTime [26 s]
  compile took 26.4s — the nested-group blowup may have regressed
```

The same test on the same tree in the lander's worktree: 1 s alone, and green inside the whole Unit assembly
(29,307/0, twice). The Linux legs passed it on the same commit.

## Mechanism
`tests/Cobol.Net.Tests.Unit/DeepNestingTests.cs:41-48` times a full `CompilerDriver.Compile` (Roslyn included) with a
`Stopwatch` and asserts `< 20 s`. The Unit assembly runs its classes in parallel, so the measured interval includes
whatever the runner's other test threads and the shared JIT/Roslyn warm-up cost at that moment; on a loaded hosted
Windows runner that is not bounded. The regression the test guards (an EXPONENTIAL nested-group emission: minutes by
depth 30) is a growth-rate property, and a single wall-clock sample of one depth cannot tell it from runner load.

## To close
Measure the property, not the clock: e.g. compile depth d and depth 2d (or count the emitter's work items / generated
lines) and assert the ratio is linear, or put the test in a non-parallel collection with the ceiling on EMIT time only
(excluding Roslyn). Either way a loaded runner must not be able to turn it red. Until then a red on this one test with
no compiler change is this note, and the run is re-run — never ignored.


## Landed 2026-09-25 — assert the property, never the clock

The owner: "THIS IS THE SECOND TIME THIS FAILED DUE TO A FEW SECONDS OVERRUN." A fixed wall-clock ceiling measures the
CI host, not the code, so it was removed everywhere it existed — six tests, not one:

- **DeepNestingTests** now counts the work the memo bounds: `PhysicalModel.ListBuilds` (one physical-field list per
  group + the root forest), observed through the `AsyncLocal` seam `PhysicalModel.Observer`, at depths 8 and 16, asserting
  ≤ depth + 1 and exactly +8 between them. Planted regression (memo disabled): depth 8 built **749** lists against 9 and
  the test failed in 1 s — the small depths make a regression FAIL, never hang.
- **CobolTimingTests** (two NaN / truncated-zero tests): CONTINUE AFTER's suspension is REPORTED through the new
  `AsyncLocal` seam `CobolTiming.SuspensionObserver` instead of performed; the tests assert "no suspension", and a new
  control test asserts a 2.9-second interval reports exactly 2000 ms (so an empty list cannot mean a disconnected seam).
- **PictureCompositionTests.ALargeRepeatExpandedPicture_CostsLinearTime**: the absolute 5-second ceiling became a GROWTH
  RATIO — best-of-three at 3 000 vs 30 000 symbols, bound 30× (linear ~10×, the quadratic pair walk ~100×).
- **CldrLocaleLoaderTests** zh build (20-second ceiling) and the legacy **FixedFormTests** (two 1-second ceilings): the
  ceilings are removed; the orderings / completion are the property, the time is only reported.
- **NoWallClockAssertionDriftTests** (new, Unit): fails when any test compares an elapsed-time reading; it found the
  PictureComposition ceiling the first grep missed. A same-run growth ratio is the one permitted timing shape.
