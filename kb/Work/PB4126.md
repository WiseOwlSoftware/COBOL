# PB4126 — `cobol --std COBOL-2002` crashes with an unhandled InvalidOperationException instead of a usage error

**Sites:** `src/WiseOwl.Cobol.Cli/Program.cs:66` (`Program.Main`).

New defect of PB4031's finisher ("Distinct root"). `cobol --std COBOL-2002 <file>` ends with an unhandled `InvalidOperationException`
instead of a usage error naming the accepted values (85, 2002, 2014, 2023). The site is the `--std` validator in `Program.Main`
(Program.cs ~line 60-66 on main):

    stdOption.Validators.Add(result => { if (result.GetValueOrDefault<int?>() is { } y and not (85 or 2002 or 2014 or 2023)) ...

For a value `System.CommandLine` cannot convert to `int?` the option's value read throws; the validator should test
`result.Errors`/the token first, or the option should take a string and the edition parse should own the "accepted values" message
(CLI: one parse of the edition, one message). Add a CLI test over `--std COBOL-2002`, `--std abc`, `--std 1999` (each exits with the
usage error, none throws). Not legal COBOL source, hence not MAJOR: a tool-usage crash.

Repro: `cobol --std COBOL-2002 any.cob` (needs only the exe; R2: the report names the command and the line, so no re-probe done here).
