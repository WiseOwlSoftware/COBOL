## Found (listing step 6b-close, review round 1, lead R1-3 sweep, 2026-11-19)

Review lead R1-3 of `listing-step-6b-close` found `SymbolTable.SpellsIndexName` inserted between `DeclareIndex`'s XML doc
comment and `DeclareIndex`, so `SpellsIndexName` carried two `<summary>` elements (the first naming a parameter it does not
have) and `DeclareIndex` none. That site is fixed on the branch. The sweep for the shape (a `///` line ending in
`</summary>` followed directly by a `/// <summary>` line, over every tracked `*.cs`) finds 42 more, all older than the branch. The
three in files the branch touches (`DataItem`, `SubscriptBinder`, `VersionConformancePass`) are fixed there; the other 39
remain, among them `MoveBinder` (the class carries two summaries), `CobolLiteral`/`LiteralClass`, `StatementEmitter`,
`RuntimeApi` and three test files.
Neither the C# compiler nor the analyzers warn: a second `<summary>` is well-formed XML.

The repair is per site (decide which member each summary describes and move or merge it) and then a RepoDrift test that
refuses two `<summary>` elements in one doc comment block, so the next misplaced insert is caught at the gate (rule 5).
The list is the scan above, rerun at the fix's base.
