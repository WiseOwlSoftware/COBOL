# PB5268 - the 2014 standard as public Markdown

**Source.** `specs-private/ISO_COBOL_2014.pdf` (`spec_pdf.path(2014)`), specs-private commit 0727a70: 952 pages, a true text
layer on every page, vector general formats. The submodule pointer moves from 9a8a7a9 to 0727a70 in this change.

**Permission (printed).** Unlike 2002, the 2014 PDF prints the CODASYL grant and the acknowledgment paragraphs, on its INCITS
cover page (PDF page 2, folio ii): "Any organization interested in reproducing the COBOL standard ... is free to do so", asking
that the paragraphs be reproduced "in their entirety as part of the preface". The Preface quotes the grant and reproduces the
paragraphs as printed, so `verify_acknowledgment.py --edition 2014` compares them word for word with the page. The page prints
`OI` for "or" (four times), `1958,1959`, `Translater`, and no full stop after "therewith" or "specifications"; the rendered page
was looked at (2026-11-11) and these are the printed text, not a misreading of a scan, so they are kept as printed and the Preface
says so. The Preface names no person.

**The stamp.** Read from the PDF's own text layer: one line, the same on all 952 pages, "Copyright by INCITS. Licensed to
<name>. ANSI store order # <X_ and seven digits>. Downloaded <date>. Single user license only. Copying and networking
prohibited." It is the 2002 line's shape. Each of the seven `FORBIDDEN` shapes and three `TREE_FORBIDDEN` shapes matches that line
on every one of the 952 pages and no other line of the PDF (measured), so `verify_publishable` names one shape set
(`_INCITS_STORE_STAMP`, `_INCITS_STORE_TREE`) for both editions, each row keyed by its edition.

**The route (PB4813's, unchanged).** `transcribe_pdf.py text --edition 2014 --state E:/COBOL-coord/scratch/transcribe-2014`
converted every page from the text layer with no model; the vector arm drew every general format; `assemble --out` wrote the
pages under `PARTS[2014]`; the Preface was put before the assembly. No tool was forked: each gained a 2014 row.
- `spec_pdf.EDITIONS[2014]`: vector, folio offset 24 (measured from the footer folio of each of the 926 arabic-numbered pages,
  PDF 25 to 951), body line `# Clauses 1 to 16`.
- `transcribe_pdf.EDITION_NAMES[2014]`, `PARTS[2014]`: front matter from page 1, clauses 1 to 16 from page 25 (folio 1),
  Annexes A to G from page 761, the bibliography and index from page 926.
- `verify_publishable.FORBIDDEN`, `TREE_FORBIDDEN`, `REQUIRED`, `ACKNOWLEDGMENT_OPENING` rows for 2014;
  `verify_acknowledgment.ACKNOWLEDGMENT[2014]` (page 2, no misreading: a true text page);
  `sweep_figures.FURNITURE_LINES[2014]`.
- `citation.py` and `cite.py` needed no code: the ISO clause regions are edition-generic. Their self-tests now check a real 2014
  citation (`§2014:14.9.23.2 SR2`), a wrong rule and a phantom clause.

**A sibling defect fixed at its root.** `text_layer.FOOTER` knew only the `© ISO/IEC` copyright line, so the INCITS cover page's
footer, `ii © ITIC 2014 – All rights reserved`, survived as text; it is boxed, so it also sits above the foot band (y 712.5 of 792).
The 2002 transcription carried the same line (`ii © ITIC 2003 – All rights reserved`). The footer now takes the ITIC line, and on a
boxed page the lowest printed row when it carries the copyright sign (a bare number is a folio only inside the band). Proven by
converting every page of both PDFs with the old and the new module: exactly page 2 of each changes, losing only that line; the
other 1,832 pages are byte-identical. The planted case is red on the old code and green on the new. The 2002 file's line is removed.

**Measured result.**
- `specs/ISO_COBOL_2014.md`: 39,263 lines, 952 `## Page N` pages, 470 general formats on 319 pages, every one drawn (0 left as
  a placeholder, 0 refused by the vector arm), 0 pages failed.
- `verify_publishable.py --edition 2014`: PUBLISHABLE. `verify_acknowledgment.py --edition 2014`: verbatim in the Preface and in
  position (1,024 characters each). `lint_rendering.py --edition 2014`: LINT CLEAN.
- `sweep_figures.py --edition 2014 --check`: clean; 464 figures located, 458 byte-identical to the drawn ones.
- `cite.py --check "§2014:14.9.23.2 SR2" "File-name-1 shall be described in a sort-merge file description entry"`: OK.

**Review round 1 (w20261996d), both findings fixed in `text_layer.py`.**
- R1-1 (silent wrong text). `rows_of` refused to add a span to a row when its box overlapped a span already there. 2014 sets a
  minus sign inside a formula as a Times em dash in a Univers line, and its em-wide box overlaps the words beside it (page 336:
  dash x 271.9-280.9, "1." from 278.9). So each such dash became a row of its own, written after its line: §2014:13.18.14.3 GR6b
  read "integer-1 + printable-size 1", GR6c "integer-1 printable-size + 1", and §2014:13.18.52.3 GR6b "'+' and ' '" (a space
  for the negative sign). Now a lone dash (`LONE_DASH`) joins the row its centre agrees with, overlap or not. They read as the
  rendered page sets them (looked at): "printable-size —1.", "integer-1 —printable-size", "'+' and '—'". Page 383's "+ —CR"
  was already in its row; the page prints the dash touching CR, so no space is added.
- So the next case is reported, not silent: `stray_glyphs` reports any one-glyph row, outside a ruled table, that lies inside
  another row's line. It reports nothing in 2014 after the fix. In 2002 it reports page 761 (a queue diagram, which the
  converter reads as a table; its "D" is set under "SUB-QUEUE (2)").
- R1-2 (lead). A dash list whose items are set with no blank line between them ran into one paragraph after an item that
  reached the right edge. A row that opens with a dash set apart from its first word is now a line of its own (a hard break).
- Proof. Every page of both PDFs was converted with the old and the new module.
  - 2014 changes on pages 93, 156, 336, 412, 451, 452, 479, 481, 677 and 838: the three R1-1 sites, the rest dash lists split
    into items.
  - 2002 changes on pages 35, 135, 136, 368, 402, 404, 427, 428, 607 and 773: dash lists only.
  - No word is gained or lost. A wrapped list item keeps its continuation line (`&emsp;`).
  - The changed paragraphs were spliced into both files, each matched exactly once in its page. The spliced 2014 file is
    byte-identical to re-converting those pages and re-assembling.
- Both editions stay PUBLISHABLE and LINT CLEAN, and `sweep_figures --check` is unchanged (2014: 458 of 464, 2002: 439 of 445).
- The two new self-test cases fail on the old module.

**What remains (as for 2002, PB4813).** The page-by-page reconciliation against the rendered PDF (`spec-reconcile`), the
adversarial refuter pass over every drawn figure, the two figure-count clauses and the 55 ambiguous pages. And the edition edges
derived while no 2014 text was held can now be checked against `§2014:E.2` and `§2014:E.3`: the first such check found PB5270 (the
FROM/INTO record-area prohibition, refused at `--std 2014` though 2014 lifted it).
