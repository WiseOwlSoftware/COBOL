# PB4360 - A de-reserved verb written as a verb answers a bare COBOL0001

**Sites:** `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs` (`CobolErrorStrategy`, the parser error strategy that builds the COBOL0001 text) and `src/WiseOwl.Cobol.Editions/CobolWordsMap.cs` (`CobolWordsMap.RemovedBy`) (the map PB4309 already reads for intrinsic names).

Scenario: `>>COBOL-WORDS UNDEFINE "DISPLAY"` followed by `DISPLAY "X"` in the PROCEDURE DIVISION. DISPLAY is now a user word, the statement is not a statement, and the parser answers COBOL0001 ("mismatched input") with no mention of the directive. The user wrote a legal directive and a statement that was legal until the directive; the message gives no hint that the directive is the cause.

PB4309 fixed the same misleading shape for an intrinsic function name (the binder holds `word.RemovedByDirective` and says so). The verb case is parser-layer: the root is that the error strategy has no access to `CobolWordsMap.RemovedBy`. The fix can reuse that map to append a note naming the directive and its line when the offending token's text is in it.

## Landed (wave 20261822 A)

Re-probed on 83a1e47f4: `>>COBOL-WORDS UNDEFINE "DISPLAY"` then `DISPLAY "X".` drew only `COBOL0001: cannot parse
construct near '"X"'`.

**Fix.** A new warning, COBOL5926 (`DiagnosticCatalog.WordWithdrawnBeforeSyntaxError`), reported by
`CobolErrorListener.NoteWithdrawnWord` beside the syntax error, at the directive (`CobolWordsMap.RemovedBy`,
`CobolWordsOp.At` through the line map), once per directive, where the withdrawn word is the offending token or the
one before it (the evidence the margin-R note, COBOL5788, reads). It names UNDEFINE (ISO 7.3.10.4 GR3) or SUBSTITUTE
with its literal-5 (GR4). The syntax error stands: the source is no statement. The note lives in the listener, not the
strategy, because only the listener holds the line map that turns the directive's resultant line into the user's.
Witnesses: `CobolWordsDirectiveTests.AWithdrawnVerbWrittenAsAVerb_IsNamedBesideTheSyntaxError` (UNDEFINE, SUBSTITUTE,
a second fault in the group: one note) and its control. No conformance refusal pins it: a refusal's `expect` is matched
against the errors, and COBOL5926 is a warning.

**Sites (as landed):** `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorListener.cs` (`SyntaxError`, `NoteWithdrawnWord`,
`_withdrawnNoted`), `src/WiseOwl.Cobol.Editions/Diagnostics/DiagnosticCatalog.cs` (`WordWithdrawnBeforeSyntaxError`),
`src/WiseOwl.Cobol.Editions/CobolWordsMap.cs` (`RemovedBy`, read only), `docs/rearchitecture/DESIGN-cobol-words-directive.md`,
