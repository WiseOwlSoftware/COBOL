# PB4992 - lineage slice 1: a store per edition and the 1985 rows

docs/rearchitecture/DESIGN-spec-conformance-review.md §10.2, slice 1. `inventory_store.py` owns the directory of each edition (2023 stays
`tests/version-matrix/inventory/`; 1985 is `tests/version-matrix/inventory-1985/`); `row_name` accepts the 1985 row key
(`1985-SR-VI.5.7.3-1`, `1989-AR-A.2.5.3-1`, `1993-...`), which begins with a digit and is refused today. `build_inventory.py
--edition 1985` seeds one row per 1985 catalog rule (its id, citation, document, locator, kind, ordinal, sublist,
subject, module, level, box, status and rule digest) and preserves adjudicated fields across a rebuild exactly as the
2023 arm does. No 2023 reader changes. The gate audits that read the inventory name their edition; the merge drivers
and `inert_lane.py` treat the new directory as they treat the 2023 one.

**Sites:** `scripts/spec/inventory_store.py` (`INVENTORY_DIR`, `row_name`, `load_inventory`, `write_inventory`, `self_test`),
`scripts/spec/build_inventory.py` (`main`), `scripts/inert_lane.py` (`CLASSIFICATION`), `scripts/merge_drivers.py#self_test`,
`scripts/session-probe.ps1` (whole: the `invent` line reads the store of each edition).
