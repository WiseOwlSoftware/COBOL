# PB1071 — OPEN — ⚠ OWNER VISIBILITY

## The disagreement
DOC-A.1-216 (docs/CONFORMANCE.md, PB970, following GnuCOBOL) defines a pointer's storage image. The shared-area
cell keeps PB231's 'value not in the image' decision and fills the pointer's bytes with a reserved pattern, and the
golden `conformance:2002/pb231_based_pointer_leaf` PINS that fill.

## What the fixer owes
`CobolPtr.SlotWrite` writes the DOC-A.1-216 image; ALLOCATE seeds the NULL image at pointer-leaf class offsets and
`GroupImageCodec` renders it. This OVERTURNS the pb231 pin: re-derive the golden and name the overturn in the DEVLOG
entry so the owner sees it (PB970's implementer reverted the same change to keep the pin, pending this note).
