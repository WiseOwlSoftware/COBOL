# PB151

Rows: GR-14.9.3.4-1 (DIVERGES), -2/-3/-4/-5/-7/-9, findings [ALLOCATE statement].

(1) PtrEmitter.EmitAllocate splits on x.Scale == 0; a NATIVE float operand carries Scale 0 with Real:true so `(long)(double)` truncates 2.5 → 2 where GR1 rounds up (the fixed-point arm is right; STANDARD-DECIMAL is right — the refuter proved the boundary). Same split in EmitSetPointerUpDown. (2) CobolPtr.Allocate has no failure path; `checked((int)size)` throws OverflowException unhandled where GR5 requires NULL + nonfatal EC-STORAGE-NOT-AVAIL (the shape exists next door in Free's notAlloc + EmitFree's gated dispatch); the `(long)` narrowing before it wraps modulo 2^64 (a 20-digit size allocates five characters and returns a VALID pointer) — kb/Work PB22's own root cause, never swept to PtrEmitter. (3) ForceStringCanonical rejects any BASED class with a non-DISPLAY leaf; PtrBindBasedAndAddressables bare-continues with NO diagnostic and EmitAllocate louds at RUN time — while CallMakeExternal turns the IDENTICAL failure into a bind-time COBOLNET (two-arm). GR4a/b labels are swapped at three sites (→ PB159).
