# PB5358 - a borrow is an argument a stale instruction can re-grant

**Sites:** `scripts/orchestrator/orchestrate.ps1` (whole: the parameter block, the review tick, the prompt builder and
the supervisor's main loop each pass the borrow); `scripts/orchestrator/budget.py` (`estimate`, `current`, `main`);
`scripts/orchestrator/plan_wave.py` (`plan_main`); `scripts/orchestrator/review_lane.py` (`budget_decision`, `main`);
`scripts/orchestrator/units/wave.md`; `scripts/arch/r2_cost.py` (`add_budget_args`, `budget_from`);
`scripts/arch/r2_inputs.py` (`main`); `scripts/arch/r2_collect.py` (`main`);
`scripts/orchestrator/account.py` (`Account`, `_overrides`).

## What happened

On 2026-11-11 the owner withdrew every quota borrow (kb/Work PB5357). Plan section 0 still read "100 % of the weekly
allowance (loop `-BorrowDays 6`)" and, lower down, "`orchestrate.ps1 -BorrowDays 3`". Either sentence, followed by a new
session, starts the loop with a borrow the owner no longer grants, and nothing refuses it: the argument carries no
source, no date and no end. The loop's restart commands in the operator's resume note show the same shape, a borrow
granted "for this wave" that a later restart must remember to drop.

The design already has the right home. `Account.quota_at(now)` (kb/Work PB3305) applies each `quota_overrides` entry
whose window holds `now`; an entry carries `_source`, the owner's words, and lapses at its `until`, so taking it back
needs no second change, and `account.py` refuses an entry with no source. `weekly_cap_pct` is granted that way; a
borrow is not.

## Fix

Make the borrow a quota key (`borrow_days`) that only a dated override can set, read by `budget.estimate` through
`quota_at`, and delete `-BorrowDays`, `--borrow-days` and `{BORROW_DAYS}` from every caller in the same change (no
alias, CLAUDE.md rule 4). A grant then names the owner's words and its end, governs the supervisor, the planner and a
unit's own call at once, and lapses by itself. Update `DESIGN-orchestrator-loop.md` (the Allowance paragraph), the
workstream skill and the architecture-review design and skill, which name the argument. The self-tests of `budget.py`,
`plan_wave.py`, `review_lane.py` and the orchestrator prompt cover the argument today and move with it.
