# PB4460 - ExternalRepositoryResolutionTests.MakeStale hand-builds the previous runtime major; tests/_shared RuntimeVersionSkew.OtherMajor is the one place that does it

**Site:** `tests/WiseOwl.Cobol.Tests.Conformance/ExternalRepositoryResolutionTests.cs:346` (`MakeStale`: `new Version(runtime.Major - 1, ...)`); the one place is `tests/_shared/RuntimeVersionSkew.cs:28` (`RuntimeVersionSkew.OtherMajor`, `OtherMajorOf`). Sites are at the head of branch `worktree-wf_d44be67f-63e-4` (PB2104, PR #1046); line numbers are that head's.

**Defect.** The skew version is computed twice by different arithmetic; `Major - 1` also has no answer for a runtime major 0. One rule in one place: `MakeStale` takes the version text from `RuntimeVersionSkew` (keeping its same-byte-length assertion) and the hand-built `Version` goes.

**The other half of this review lead is not new.** `src/WiseOwl.Cobol.Frontend/Parsing/FragmentParse.cs:113` `ParseUnit` is a hand-written copy of the lex / re-lex / fixpoint loop of `Frontend.LexAndParse` / `LexAndParseOnce`, with no drift test tying the two together. That is the open PB2735 (the token-stream preparation written twice), so it was appended there, not filed here.
