**The tooling.** `cite.SOURCE` is the note's shape and `cite.EDITORIAL_NOTE` includes it. `rule_catalog_1985.parse` treats a folio line as the end of a printed page, so it skips the running header after one inside a PDF page, and it puts a rule on the first folio below it (`folio_below`; `folio_of` is deleted). `verify_publishable.check_reconstructions` counts the folios a SOURCE note names as printed and requires each as a folio line below the note. Each of the three has a planted self-test.
