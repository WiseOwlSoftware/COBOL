# PB5284 - a queue or sub-queue name in an input CD that differs from a defined name only in letter case is answered status 20 (unknown), and the MCS definitions accept two names that differ only in case: names are compared ordinally, where 1985 symbolic names follow the system-name rules (lowercase equals uppercase)

**Sites:**

- `src/WiseOwl.Cobol.Runtime/Communication/MessageDefinitions.cs` (`FindQueue`, `Parse`)

**Mechanism.** §1985:XIV.2.2.4 GR4: the queue and sub-queue names "must follow the rules for the formation of system-names", and in those rules "Each lowercase letter is considered to be equivalent to its corresponding uppercase letter" (§1985:p.A-9, the Amendment 1 text that replaces paragraph IV.4.2.2.1).`MessageDefinitions.FindQueue` compares names ordinally, so content "q" does not designate queue Q, and the definition reader keeps "B" and "b" as two sub-queues.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the non-conforming verdicts wait in `E:/COBOL-coord/scratch/coderead-85/p2-for-register.json`.

**Rules (2 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-GR-XIV.2.2.4-4` - `§1985:XIV.2.2.4 GR4` (refuter: OVERTURNED to DIVERGES, harm: wrong-answer): "must follow the rules for the formation of system-names"
- `(the case rule)` - `§1985:p.A-9` (the rule GR4 imports, Amendment 1 text): "Each lowercase letter is considered to be equivalent to its corresponding uppercase letter"

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-pipe/refute-slice-59/g4/p.cob` with its mcs.json (Q with sub-queues A and B): `MOVE "q" TO IN-Q`, ACCEPT MESSAGE COUNT; then Q with sub-queue "b", ACCEPT and RECEIVE; `cobol.exe --std 85 --source-format fixed --run p.cob`.

**Observed (a build of origin/main f2cf36fd15, rerun 2026-11-11; main has since changed only `IndexedConnector.cs` under `src/`, which none of these repros reaches).** `LOWER-Q COUNT 20 000000`, `LOWER-B COUNT 20 000000`, `LOWER-B RECV 20`.

**Expected (from the 1985 text).** `LOWER-Q COUNT 00 000002`, and the "b" forms answer 00 (the B sub-queue).

**Fix direction (root cause, CLAUDE.md rule 4).** Compare and store MCS names case-insensitively in one name type, and refuse a definition with case-only duplicates; sweep the source, terminal and destination lookups.
