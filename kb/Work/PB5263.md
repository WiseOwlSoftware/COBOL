# PB5263 - flipped witnesses no longer discriminate

In `scripts/hooks/test_forbidden_commands.py` `UNIT_CASES` (ba1189f04b, lines about 291-299) three cases were flipped
to `False` ("this repository (kb/Work PB5234)") rather than re-pointed at another repository:
`QS + "git push"` ("a quoted `<<` hides nothing", PB3198), `git commit ... && xargs -n1 git push origin < refs.txt`
("git wherever it stands in the step") and ``echo `git push` ``. A push to this repository is allowed, so each passes
whether or not the push is detected, and each comment states an expectation the case no longer checks. For git after
`xargs` no other case witnesses detection: the only `xargs` case runs git through `sh -c`. Fix: give each case a
push to another repository (`OTHER`) expecting `True`, keeping one `False` case beside it so the pair discriminates.

**Sites:** `scripts/hooks/test_forbidden_commands.py:294` (`UNIT_CASES`)
