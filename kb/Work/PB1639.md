# PB1639 — LANDED 2026-09-27

**Observed.** Landing ca28783e3 (battery #87's record): ci-gate was green on the `ci/` run (36317804054), main
fast-forwarded, and the script then printed `main run 36318722784 = unknown`, "could not enumerate jobs", and
"⛔ CI IS RED ON ca28783e3035 — AND IT IS ALREADY ON MAIN", then exited 1. `gh run list` shows run 36318722784
`completed / success`. The script's one read of `gh run view --json conclusion` came back empty, a transient API
failure, and the test `[ "$MAIN_CONCLUSION" != "success" ]` treated that silence as red.

**Harm.** A false BLOCKING alarm tells the operator that main is red when it is green. The opposite shape (reading a
missing observation as green) is the one the verdict-evidence invariant forbids. This is its mirror: an absence
read as a negative is just as unobserved.

**Fix.** `scripts/push-main.sh` re-reads the conclusion up to 12 times at 10 s intervals. If no verdict arrives it
prints `⚠ UNVERIFIED` with the exact command to read it by hand and exits 3, which is distinct from red (1) and green
(0). A real non-success conclusion still takes the red path unchanged.
