# PB5576 - The 2023 rule catalog's FMT rows carry the next clause's HTML anchor, so no 2002 general format pairs

**Sites:** the rule-catalog extractor (the 2023 FMT rows' text); the 315 2023 FMT digests.

**Evidence.** `FMT-7.3.2`'s text ends `</pre> <a id="section-7-3-3"></a>`. 315 of 322 2023 FMT rows end this way. No 2023
non-FMT row and no 2002 row does. With the anchor erased, 130 2002 FMT rows pair exactly and 4 pair ambiguously
(plan evidence.md section 2).

**Fix at the root.** The extractor stops gluing the next heading's anchor into a format's text. The 315 2023 digests are
re-stamped in the same change. Sweep the 1985 extractor for the same leak.
