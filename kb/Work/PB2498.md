# PB2498 — OPEN

Filed by the train-1034b lander from the wave-1034 group B report (PB244, `E:\COBOL-coord\scratch\reports\w1034b-PB244-report.md`,
new defect 3). Unverified: the implementer did not probe the fix.

**Mechanism.** `src/Cobol.Net.Compiler/Binding/Procedure/Verbs/IntrinsicBinder.cs#VariableLengthGroupSum` sums a variable-length
group's current extent for FUNCTION LENGTH / BYTE-LENGTH, and keeps a group with a USAGE BIT descendant (`HasBitDescendant`) as the
named stage COBOLNET1756, because the bit walk (PB207, PB203) packs bits by the §8.5.1.6.3 rules and the character sum would be wrong.

**Lead.** The group's packed image length probably equals its byte length, so the stage may need only the one-way gate
(`CurrentExtentUse.OneWayImage`) and the bit walk's width per component. Derive the expected value from §15.50.4 and the
§8.5.1.6.3 walk before changing anything.
