# PB3341 — S2's sweep missed the `<edition>/<name>` golden references in docs

Source: wave 1106 A's finisher (report `E:\COBOL-coord\scratch\reports\w1106a-PB1099-report.md`, "Lead, not fixed").

PB3177 slice S2 (main `fb006c1de`, PR #186, 2026-10-17) deleted `tests/conformance/` and moved every program into `conformance-suite/cases/` and `conformance-suite/wiseowl/`. Its sweep rewrote `tests/conformance/...` paths and `conformance:` citations only, so the short form `<edition>/<name>` (85, 2002, 2014, 2023) still names the old location. Example: `docs/CONFORMANCE.md:793` "golden `2002/pb606_call_not_on_propagated`".

**Measured (R2)**, at origin/main `241eac5c1`, repro `git grep -c -E "\b(85|2002|2014|2023)/pb[0-9a-z_-]+" -- docs`: 25 files. Largest: CONFORMANCE.md 71, COBOLNET_DATA_MODEL_DESIGN.md 19, VERSION_CHANGE_REFERENCE.md 15, COBOLNET_NUMERIC_DESIGN.md 15, COBOLNET_INTERPROGRAM_DESIGN.md 9, COBOLNET_FILES_DESIGN.md 9, COBOLNET_CONDITIONS_EXCEPTIONS_DESIGN.md 8, COBOLNET_REPORT_WRITER_DESIGN.md 8, DESIGN-locale-facility.md 6, and two evidence JSON files (fleet-optimization stamped-handoff pilot 28, scale 87; historical records, the fix decides whether they are rewritten). Total occurrences: 392 in docs, 247 of them in markdown. Outside docs (counted, not fixed): `kb/` 1814 occurrences in 1028 files, `src/` 6 in 6 files, `tests/` 256 in 43 files, `scripts/` 0.

**Fix.** One mechanical rewrite of every such reference to the suite test's path, derived from git's rename record of S2 (`git show --find-renames fb006c1de^1 fb006c1de`, or `git diff -M` across the merge), never by hand per file; decide the `kb/`, `src/` and `tests/` references in the same change (they carry the same stale form). Pair it with a drift test that every golden reference in docs resolves to a file that exists. No such test holds it today, which is why S2's gate passed.
