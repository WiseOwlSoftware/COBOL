# PB3590 - D-B3 records the choice but not the survey that rule 1 requires

## Lead (PB3562 review lead R1-3, info)

`docs/CONFORMANCE.md` D-B3 (added by PB3562's landing, line 222 area on that branch; not on main until that branch lands) determines
that a boolean LITERAL is usage DISPLAY, so `MOVE B"01100110" TO G` into an alphanumeric group deposits its characters. The standard
states no usage for a boolean literal, so the question is implementor latitude. CLAUDE.md rule 1 sets the precedence for latitude:
the ISO spec if it controls, otherwise GnuCOBOL, otherwise IBM Enterprise COBOL or Micro Focus, with the choice documented. D-B3
does not record the survey: ISO is silent, so GnuCOBOL comes next, yet the determination does not say what GnuCOBOL does with a
boolean literal in a group move or why WiseOwl follows or departs from it. (The implementer's rejected reading, packing the literal
as USAGE BIT, is recorded; the survey is not.)

## Fix shape (for the clerk or implementer)

Run the literal through GnuCOBOL (`cobc` under WSL; the differential harness may already hold a case) and add one sentence to D-B3
stating the GnuCOBOL result and why the choice follows or departs from it. If GnuCOBOL has no boolean literals, say so and name the
next source consulted. Run `cite.py --check` on every clause the determination names. Do this after PB3562 lands, since D-B3 does not
exist on main before.

**Sites:** `docs/CONFORMANCE.md`.
