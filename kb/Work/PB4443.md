# PB4443 — dead `SameSignatureRestriction` and the docs that still name it

**Defect.** After R1-1 of PB4107 moved `SameAnalyzedProfile` to `NamedRestriction`,
`PrototypeSignatures.SameSignatureRestriction` (`src/WiseOwl.Cobol.Compiler/Binding/PrototypeSignatures.cs:122`) has no
production caller. Its only callers are `PrototypePointerTypeDriftTests`, `PrototypeSignatureClassesTests` and
`RepositoryCodecTests`. Its summary still says it is the question asked inside the classification, and
`docs/rearchitecture/DESIGN-external-repository.md` (lines about 1083-1084, and also 1169 and 2242 at HEAD 101ded510)
and `docs/OO_DESIGN.md:778` still name it.

**Fix direction.** Rule 4 forbids keeping an unused member: delete it and re-point the tests at the relation the
production code uses (or at `SignatureKey` equality), and correct the docs. If PB4442's adjudication makes the
elementary pair-mode arm ask the signature class again, the member has a caller and the note closes by that route
instead.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/PrototypeSignatures.cs` (`PrototypeSignatures.SameSignatureRestriction`), `docs/rearchitecture/DESIGN-external-repository.md` (whole: names the member in three places), `docs/OO_DESIGN.md` (whole: names the member at line 778), `tests/WiseOwl.Cobol.Tests.Unit/PrototypePointerTypeDriftTests.cs`, `tests/WiseOwl.Cobol.Tests.Unit/PrototypeSignatureClassesTests.cs`, `tests/WiseOwl.Cobol.Tests.Unit/RepositoryCodecTests.cs`.

## Landed (wave 20261849 group C, with kb/Work PB4491)

PB4491's landing deleted the member as part of its mechanism: with the signature graph reading a pointer formal by name, nothing
compares two pointers' content restrictions but the SET relation (`ActivationRelations.MaySet`), so
`PrototypeSignatures.SameSignatureRestriction` went with `PrototypeSignatureClasses`. The tests compare
`PrototypeSignatures.SignatureRestriction` texts (`PrototypePointerTypeDriftTests`, `RepositoryCodecTests.RoundTrip`);
`PrototypeSignatureClassesTests` is deleted; docs/OO_DESIGN.md and docs/rearchitecture/DESIGN-external-repository.md no longer name
the member (`grep -rn SameSignatureRestriction docs src tests` finds only this note's history).
