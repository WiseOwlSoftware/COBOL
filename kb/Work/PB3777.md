# PB3777 — one rendered dispatch file per group, not a spec plus a brief that restate it

**Sites:** `.claude/skills/workstream/templates/dispatch-spec-implementer.md`, `.claude/skills/workstream/templates/fix-lane-implementer-brief.md` (deleted), `.claude/skills/workstream/templates/implementer-brief.md` (deleted or folded the same way for its lane), `.claude/skills/workstream/check_practices.py#BRIEFS`, `.claude/skills/workstream/check_practices.py#NUMBERLESS_CAP_BRIEFS`, `.claude/skills/workstream/make_dispatch_specs.py#render`, `.claude/skills/workstream/SKILL.md` (§6 templates), `.claude/agents/cobol-implementer.md`, `scripts/hooks/dispatch_guard.py`, `scripts/orchestrator/plan_wave.py` (where it names the brief), `.claude/skills/workstream/templates/MANDATORY-PRACTICES.md` (`Orchestrator`: O1), `scripts/hooks/test_dispatch_guard.py`, `scripts/orchestrator/test_plan_wave.py`, `scripts/orchestrator/test_rolling_wave.py`, `.claude/skills/workstream/templates/wf_rolling_wave.js`, `docs/rearchitecture/DESIGN-orchestrator-loop.md`, `scripts/orchestrator/groups.py` (`requirements_text`)

## Measured

The spec is read by 27 of 27 implementers (3,363 tokens median) and the brief by 25 of 27 (3,418 tokens), both at
about turn 2, so both ride every later turn: 9.1M and 8.8M token-turns over 27 agents, the second and fourth most
expensive files of the 105 transcripts ($2.40 and $1.54 a day in the operator session alone). Read side by side, the
brief's step 7 and the spec's GATE paragraph, the brief's CHECKPOINT PROTOCOL and the spec's CHECKPOINT, the DEVLOG
ENTRY sentence (identical text in both), I9 (identical text in both), the citation rule, the STOP rule and the report
rule are the same content twice; the agent definition and CLAUDE.md's Testing paragraph carry the gate a fifth and
sixth time. An implementer that reads only the spec (2 of 27) loses nothing the checker requires.

Saving: the brief's read (3.4K tokens × ~95 remaining turns × 84 implementers a day, reads and cache writes) is about
$55 a week; removing the overlap inside the one file (about 2.5K of the 6.8K tokens) about $35 more: **about $90 a
week**, and one file for the next rule to be added to instead of two.

## Fix

Fold `fix-lane-implementer-brief.md` into `dispatch-spec-implementer.md`, which `make_dispatch_specs.py` renders:
every paragraph once, in the order the work runs (contract and re-probe · orient · spec and citations · fix and sweep
· goldens · rows and register · self-review · checkpoint · gate, its wait and GATE-PENDING · Linux half · report),
with the role's practice rows rendered in by PB3778. Delete the brief (rule 4: no forwarder, no stub; every caller
changes: the agent definition's pointer, SKILL.md §6, `dispatch_guard.py`'s "a brief under templates/" arm for the
implementer, `plan_wave.py` where it names the brief, O1). Move the brief's `check_practices.py` patterns onto the
spec's entry so no practice is dropped silently (O1: a practice dropped is removed from the checker in the same change,
never silently), and keep `NUMBERLESS_CAP_BRIEFS` true of the spec (it already reads `{turn_cap}`). `implementer-brief.md`
(the non-fix-lane lane) is folded the same way or deleted if no dispatch names it (`git grep` decides; the finisher,
golden and registrar briefs are other roles' and stay).

Guard: `check_practices.py` over the rendered spec carries every pattern the brief's entry carried; a self-test renders
one group and asserts no sentence appears twice in the output (the duplicate paragraph is the defect's shape); the
dispatch guard's self-test (`test_dispatch_guard.py`) covers the implementer arm with no brief path.

## Acceptance

`git grep fix-lane-implementer-brief` is empty; `check_practices.py` GREEN over the templates and over a rendered wave;
`test_dispatch_guard.py` green; a wave's implementers read one instruction file (the measurement's S2 table re-run on
that wave shows the brief row gone); the rendered spec is at most about 4.5K tokens.

rule twice; `check_practices.repeated_sentences` run over the old pair found 7 sentences stated twice).

self-review, checkpoint, stop, gate, wait and GATE-PENDING, report). `fix-lane-implementer-brief.md` and
`implementer-brief.md` (no dispatch named the second: `git grep` found only SKILL.md section 6 and the checker) are
deleted, and every caller changed in the same commit: `check_practices.BRIEFS` carries the folded briefs' patterns on
the spec's entry plus eight more for what the fold moved (`git grep --cached`, the tracked-STATUS drop, the stash ban,

the spec template, `dispatch_guard.py` takes a rendered spec ONLY for an implementer (a finisher still takes a template
