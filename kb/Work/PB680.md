# PB680 — OPEN — a fix without its witness

Found 2026-09-05 by the `PB327` implementer (report §"New defects" C). Routing every record-area send through
`OperandText.RecordAreaImage` (= `AsStorageImage`, whose `BitsPack` arm packs a bit leaf per §13.18.60.4 GR5 —
`cite.py --check 13.18.60.4 "BIT"` → `OK 5)`: *"The USAGE BIT clause specifies that bits shall be used to represent
a boolean data item"*) fixed an elementary BIT record area that had been writing its character carrier. The
implementer added a golden only for the national shape it was dispatched for.

## Why this is a note

Goldens ship with the feature: a behaviour that changed without a test pinning it can change back without one
noticing, and the byte-window residue guard (`ByteWindowResidueOf`) is now vacuous (PB327 folded the FD gate into
it and PB231's pointer third emptied its refusal list), so nothing else observes the shape. D19/PB43 own the BIT
packing; this note owns the file-record witness.

## Fix

A spec-derived golden: an FD whose record is `01 R PIC 1(8) USAGE BIT.` (and a group with a BIT leaf beside an
alphanumeric one), WRITE then READ back, expected bytes computed from §13.18.60.4 GR5 and §8.5.1.6.3's packing,
printed as ORDs so the output carries no unprintable byte. Register it; close on `unit`/`conformance` refs only.
Dispatchable after train 11 lands (PB327's channel).
