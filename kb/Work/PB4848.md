# PB4848 - the raster measurer, calibrated on real 1985 pages

**Why.** `scripts/spec/figure_raster.py` (PB4817) has only been tested on PLANTED images. Its constants were set without a real
1985 page. The owner lifted the hold on running tools against `specs-private/ANSI_COBOL_1985.pdf` on 2026-11-06 ("yes, go ahead
with all the steps"). PB4812's "1985 is a SCAN" section requires a calibration against about a dozen pages checked by eye before
the measurer regenerates any figure (PB4849).

**What to do.**
- Choose about a dozen general-format pages that together hold every feature the measurer reads: one-line and multi-line
  brackets, braces with three and with five or more lines, nested brackets inside braces, choice-indicator bars, ellipses,
  underlined words with descenders (g, p, y, q), and words underlined in part. Take them from different modules (Nucleus,
  Sequential I-O, Relative, Indexed, Sort-Merge, Report Writer, Communication, Debug) and from both amendments. PDF page 196
  (the Environment Division general format) is one.
- For each page, run the measurer and render the page with `scripts/render-spec-page.py --edition 1985`. Compare every stroke
  the measurer reports with the image, and record the result in a calibration table in the note body or in a fixture beside
  `scripts/spec/test_figure_raster.py`.
- Settle the two open leads from PB4817's review:
  - `BRACE_GLYPH_H` (13 pt) and the `brace_pieces` glyph y positions are assumed values. Measure them.
  - `find_rules` misses an underline fused to a descender. Fix it so the underline is found, and add a planted case.
  - `BRACE_STRAIGHT`, `BRACE_ALIGNED` and `BRACE_POINT` are unverified on a real scan. Verify each or correct it.
- Turn the calibration into self-test cases. Crop the measured regions to small planted images with the stamp margin
  excluded, so no per-copy stamp text reaches the repository (PB4812's standing requirement). Assert each crop's expected
  strokes in the self-test.

**Done when** every chosen page's strokes match the image, the constants carry their measured values with the page that set
each, and the self-test holds the real-page crops.

**Sites:** `scripts/spec/figure_raster.py` (`brace_pieces`, `find_rules`, `BRACE_GLYPH_H`, `BRACE_STRAIGHT`, `BRACE_ALIGNED`, `BRACE_POINT`), `scripts/spec/test_figure_raster.py` (whole: a module-level self-test; the real-page cases are added).
