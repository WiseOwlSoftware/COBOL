# PB5626 - pb739_shared_extend_write_2023 hung past its kill under load

**Sites:** `src/WiseOwl.Cobol.Runtime/IO/FileConnector.cs` (whole: the shared-file open and wait, the first candidate),
`tests/WiseOwl.Cobol.Tests.Conformance/ConformanceSuiteRunner.cs` (whole: the process guard, the second candidate). The
site is not yet located, and a diagnosis may move it. The program run is the suite case
`conformance-suite/cases/14.9.51-WRITE/pb739_shared_extend_write_2023`. Not fixed here.

**What happened.** Gate run `TestResults/build-local/000005-20261115T084536Z` of PB5597's branch (head c493692475; the
diff is tooling and docs only, no compiler, runtime or suite file) reported Conformance RED on one row:
`[2023/14.9.51-WRITE/pb739_shared_extend_write_2023] NO VERDICT: the program did not finish`. Attempt 1: TimedOut, the
process did not exit within 120000 ms and had used 0.1 s of processor time (host 25 % busy); attempt 2: SurvivedKill,
process 427348 still alive 5000 ms after it was killed, 0.0 s of processor time. The run's observation log shows a
host-wide stall at the same moments: at 08:55:23-26 three more programs (SM207A, CM103M, ST132A) timed out with 0.1 s
used and recovered on retry; at 08:58:35-39 fifteen RETRY lines, among them pb3441 (SurvivedKill, then exited) and
pb5125, and a SCRATCH-LEFT on pb739's own suite directory ("being used by another process"). The re-gate (run
000006-20261115T093824Z, the same tree) passed the row. A copy of the run's Conformance.log and observation log is in
`E:/COBOL-coord/scratch/w20262041a/gate-000005/`.

**Why it is a defect.** A program that uses no processor for 120 s and then outlives its kill is waiting on something:
for a shared-extend WRITE test, most likely a file lock or a sharing handle another process (or its own earlier attempt)
still holds. A NO VERDICT says nothing about the compiler, but a gate that can go red for it on an unrelated branch costs
a re-gate each time. The root may be the runtime's shared-file wait (no timeout, or one longer than the guard), a
handle the previous attempt's process kept, or the kill not reaching a child.

**To do.** Reproduce under load (the suite's file-sharing cases in parallel); name what the hung process waits on (a dump
of process 427348's stacks the next time); fix the root, never a longer guard.
