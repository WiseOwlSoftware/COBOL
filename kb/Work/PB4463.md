# PB4463 - raw diagnostic codes with no catalog descriptor, and COBOL1512 shared by three rules

**Sites (PB2296 integration head, branch worktree-wf_7d06ed65-e14-4):** `Binding/Passes/OdoResolvePass.cs` (COBOL0850 and
neighbours, 8 literals), `Binding/Passes/ResolveTableValuesPass.cs` (COBOL1586-1588, 4), `Binding/Passes/CheckStrongTypeDeclarationsPass.cs`
(3), `Binding/Passes/DynamicResolvePass.cs` (3), `Binding/Passes/ResolveRedefinesPass.cs` (2),
`Binding/Passes/CheckValueLiteralClassesPass.cs` (COBOL0898), `Binding/Passes/ClassifyRedefinesClassesPass.cs` (1); COBOL1512 at
`Binding/FileControlBinder.cs:266` (LOCK MODE with sequential access), `Binding/Procedure/Verbs/FileLockBinder.cs:98` (the
AUTOMATIC-locking phrase ban), `Binding/Validation/StatementValidation.cs:1594` (OPEN lock phrase). The descriptor table is
`DiagnosticCatalog`. Find the sites with `rg 'Edition\.Error\("COBOL' src`.

**What is wrong.** These `Edition.Error` calls pass a string literal instead of a `DiagnosticCatalog` descriptor, so the codes
0850-0857, 0898, 1522, 1523, 1525, 1526, 1532, 1539, 1542 and 1586-1588 (19 codes) have no catalog row: no title, no severity or
edition metadata, no documentation entry, no uniqueness check, and `wiseowl-cobol-raw-diagnostic-code-literal` counts each site.
COBOL1512 is one code reused by three different rules (LOCK MODE on a sequential file, the explicit lock phrase under AUTOMATIC
locking, the OPEN lock phrase), so a user who searches the code finds three unrelated meanings and a test that asserts the code
cannot tell the rules apart. The sites were invisible to semgrep until the passes moved to parseable files (PB4462), which is why
they surfaced in the PB2352/PB2355 baseline moves (225 -> 229, 225 -> 226).

**Fix shape.** One catalog descriptor per rule (give the three COBOL1512 rules their own codes, from `session-probe`'s next-free
code, and update every test and golden that asserts COBOL1512), route each call through the descriptor, and drive the raw-literal
rule's baseline down by the same count. A drift test that every `Edition.Error` code argument is a catalog member makes the next
case automatic (CLAUDE.md rule 5).
