# R56 — how debugging lines reach the compiler

The reference-format pass runs before SOURCE-COMPUTER is bound, so it cannot decide whether `D` lines are source or comment. Options were a pre-parse token rewriter, a parse-and-reparse fixed point, or GnuCOBOL's single global flag. **Owner: the token rewriter** — the preprocessor CARRIES the `D` lines as a distinct marked carrier (the carrier already exists; the missing step is the one that turns it back into code), and a pre-parse rewriter keeps them as source when the program's SOURCE-COMPUTER says WITH DEBUGGING MODE and drops them otherwise. Which editions accept the facility at all is R61.
