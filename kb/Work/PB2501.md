# PB2501

Filed by the w1033 clerk from the PB845 refuter (`E:\COBOL-coord\scratch\w1033-adj\PB845-refute.md` section 2 and its corrected decision
item 4: "A lead for the operator. ... same fix site. I found no open kb/Work note for it."). Same mechanism and fix site as the
NATIONAL/BIT entry-name over-reject recorded in `PB845`; the two should land together.

**Observed (refuter `r3.txt`, pinned build `pin-97006f3`).** `05 BINARY-LONG VALUE 5.`, `05 FLOAT-LONG.` and `01 PROGRAM-POINTER.` are
COBOLNET0901 (word used as a name) plus a false COBOLNET0881 ("PICTURE required") at 2002 and 2023. `05 BINARY-CHAR UNSIGNED VALUE 7.`
passes only because UNSIGNED breaks the name reading. GnuCOBOL accepts all three (rc 0).

**Expected from the spec (cite.py --check OK per the refuter).** `§13.16.3 SR8` exempts these usages from PICTURE; `§13.16.3 SR4` and
`§13.18.20.3 SR2` make a missing entry-name clause mean FILLER; `§13.18.60.2` makes `[ USAGE IS ]` optional, so the keyword alone is the
USAGE clause of an unnamed item.

**Mechanism and site.** `src/Cobol.Net.Frontend/Grammar/Core/CobolData.g4:240`
`dataDescriptionEntry : levelNumber dataName? dataDescriptionBody DOT` has no edition predicate; gated words still reach `dataName` through
`reservedGatedWord` (CobolData.g4:266); `VersionConformancePass.cs#IsProvableUserWordPosition` (line 545) treats the slot as provable.
The fix is shared with PB845 item 1: where the word is a reserved USAGE keyword for the edition, the clause reading wins.
Witnesses: conforming goldens at 2002, 2014, 2023 for each of the three shapes.
