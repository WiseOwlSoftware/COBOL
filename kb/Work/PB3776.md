# PB3776 — the agents pay for four tool schemas they never call

**Sites:** `.claude/agents/cobol-implementer.md`, `.claude/agents/cobol-finisher.md`, `.claude/agents/cobol-reviewer.md`, `.claude/agents/cobol-adjudicator.md`, `.claude/agents/cobol-refuter.md`, `.claude/agents/cobol-clerk.md`, `.claude/agents/cobol-locator.md`, `tests/WiseOwl.Cobol.Tests.Unit/ArchReviewFleetDriftTests.cs` (`ArchReviewFleetDriftTests`), `scripts/hooks/tooling_check.py#frontmatter_problems`, `.claude/skills/workstream/templates/MANDATORY-PRACTICES.md` (`Orchestrator`: O4)

## Measured

Every role's first request (its `api-request-shape`) carries the same 16 tool schemas, 71.9K chars: `Artifact` 37,943,
`PowerShell` 8,787, `SendFeedback` 5,618, `Bash` 3,438, `Grep` 3,362, `ReportFindings` 2,314, `Read` 2,006, `Skill`
1,877, `ToolSearch` 1,522, `ListAgents` 1,227, `Edit` 1,037, `StructuredOutput` 970, `Glob` 785, `Write` 694. Of the
105 agents of the operator session none called `Artifact`, `SendFeedback`, `ReportFindings` or `ListAgents` (the
ledger artifact is the attended session's; a headless unit has no Artifact tool, SKILL.md §0). Those four are 47,102
chars, 12-17K tokens of the about 55K-token turn-1 baseline that is re-read from cache on every later turn and is
24 % of agent USD. The reviewer's `disallowedTools: NotebookEdit` removes nothing, NotebookEdit being a deferred tool.

Saving: $18.6 a week per 1K baseline tokens across the agents (24 % of $610 a day over 55K tokens), so **$220-310 a
week**, the largest single skills-side lever measured. Role input shares: 22-31 % of the baseline, 4-7 % of an
implementer's input, 7-10 % of a reviewer's or finisher's.

## Fix

Each agent definition declares its tool set positively, `tools:` in its frontmatter, as the tools its role's
transcripts use: `Bash, PowerShell, Read, Edit, Write, Grep, Glob, Skill, ToolSearch, StructuredOutput` for the
writing roles and the same for the read-only roles (the `readonly_repo.py` hook keeps their writes outside git trees;
they write checkpoint `.jsonl` files), `Agent` for the clerk if a unit dispatches through it (its shape shows the tool).
The four unused tools stay out. First, the hypothesis the saving rests on is verified by ONE dispatched agent's
`api-request-shape` (the schemas are absent from the request); the note records the before and after chars.

Guard (rule 5: the next role is automatic): `ArchReviewFleetDriftTests` reads every `.claude/agents/*.md` and asserts
it declares `tools:` and that none of `Artifact`, `SendFeedback`, `ReportFindings`, `ListAgents`, `NotebookEdit` is in
it; `tooling_check.py` reports a role without `tools:` as it reports a frontmatter that does not parse. O4 names the
rule (one line). A role that needs one of the four later adds it to its own list, and the test's deny set shrinks in
the same change.

## Acceptance

The shape probe shows the four schemas gone from a dispatched implementer's and reviewer's first request; the drift
test and `tooling_check.py` are green; a wave runs with every role returning StructuredOutput as before; the evidence
record's `baseline_cost_per_1k_tokens_per_week_usd` figure times the measured token delta is written into this note's
Landed paragraph.
