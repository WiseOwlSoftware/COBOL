# PB706 — OPEN — a phrase the standard defines and the grammar cannot write

Found 2026-09-05 by the `PB692` implementer (report §"New defects" N1) while probing the organization spellings its
screen must cover: `SELECT F ASSIGN TO "f.dat" ORGANIZATION IS RECORD SEQUENTIAL ACCESS MODE IS SEQUENTIAL.` →
`COBOL0001: no viable alternative at input 'RECORD'`, exit 65, all four editions.

## The rule

§12.4.5.10.3 GR3 (`cite.py --check 12.4.5.10.3 "The RECORD SEQUENTIAL phrase specifies that the file organization
is record sequential"` → OK 3)) defines the phrase; §12.4.5.10.2 prints it in the general format. A phrase the
standard defines and prints cannot be unwritable, whichever way the underline question resolves.

## The mechanism

`src/Cobol.Net.Frontend/Grammar/Core/CobolIO.g4#organizationType : LINE SEQUENTIAL | SEQUENTIAL | RELATIVE |
INDEXED` — the RECORD SEQUENTIAL alternative is absent. Every RECORD SEQUENTIAL program is refused, not only SR2's.

## The transcription question to settle first (rule 1: render the diagram)

The transcription disagrees with itself about whether `RECORD` is underlined: §12.4.5.10.2's figure note says
RECORD is underlined and the inner brace is a required choice — which would make the ubiquitous bare
`ORGANIZATION IS SEQUENTIAL` illegal — while the diagram markup in both §12.4.5.10.2 and §12.4.5.1 Format 3 leaves
RECORD un-underlined, Format 3's own figure note says explicitly that RECORD is not underlined, and Format 4 prints
a bare `[ [ORGANIZATION IS] SEQUENTIAL ]` with no LINE/RECORD brace. Three signals to one say RECORD is an optional
word. Render both pages (`clause_page.py 12.4.5.10.2`, `clause_page.py 12.4.5.1`) and measure the underline; if
the §12.4.5.10.2 figure note is wrong, repair the transcription on discovery.

## Fix

Either reading makes the phrase legal: `organizationType : (LINE | RECORD)? SEQUENTIAL | RELATIVE | INDEXED` if
RECORD is optional (the likely answer), or a `RECORD SEQUENTIAL` alternative if it is required. The binder's
`FileModel.Organization` already has one value for record sequential (`Sequential`) — map RECORD SEQUENTIAL onto it,
never a fourth value. Positive goldens at 85 (the 1985 text also prints the form — confirm) and 2023 with the phrase
written; the corpus sweep for the 824 omitted-organization entries is unaffected. Coordinate with PB695's
CobolIO.g4 family and PB704 (same file, different rules). `Generated/` is never committed.
