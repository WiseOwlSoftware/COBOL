THE FORM: an index data item's character image is its occurrence number as an **8-byte big-endian
two's-complement binary** — matching the documented 64-bit managed carrier (CONFORMANCE.md item 211's
`FUNCTION BYTE-LENGTH` = 8) and the big-endian byte order of every other pinned representation (items
205/207/208), so records interchange. `PicInfo.ByteForm(Usage.Index) = Binary`, `StorageWidth = 8`;
`HasImageByteForm` (THE ONE derived predicate) then admits INDEX-leaf groups to group images, records,

statement, a relation condition, an intrinsic function argument, an inline method invocation argument,

crossing, not the item's statement surface. (The R40 review fleet corrected the first cut's GR10
