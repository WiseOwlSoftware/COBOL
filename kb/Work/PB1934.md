# PB1934 — OPEN

Filed by the train-1005 lander from wave 1005 group A's report (`w1005a-PB1706-report.md`, lead 2).

## Question

§13.18.12.4 GR2: the CODE characters "are not included in the descriptions of the lines in the report, but are
included in the logical record size". PB1129 (landed in train 1005) gives the report line `RECORD CONTAINS − code`
positions, but an aligned or overlong printable item that runs past the record is cut by the line image without an
exception condition or a diagnostic. The implementer found no outcome stated for the record-size cut and left it.

**Verdict needed.** Search the standard first (feedback: spec before asking): §13.18.14 (COLUMN), §13.18.39 (PAGE
width), §13.14 (FD with REPORT clause) and the EC table for a rule on a line wider than the record. If the standard
is silent, follow CLAUDE.md rule 1's precedence (GnuCOBOL, then IBM / Micro Focus) and record the choice in
`docs/CONFORMANCE.md`; a bind-time check is possible whenever the line width and RECORD CONTAINS are both known.

**Site.** `src/Cobol.Net.Runtime/IO/ReportWriter.cs#ReportLineImage` (~:1547) and the line-width walk in
`src/Cobol.Net.Compiler/Binding/DataBinder.Reports.cs#ResolveReports`.
