# PB3643 — append-only prose files conflict at landings

**Sites:** `scripts/merge_drivers.py` (`DRIVERS`), `docs/CONFORMANCE.md`, `docs/rearchitecture/DESIGN-runtime-library.md`.

## What happens

PB3610's measurement of 487 landing logs found prose docs among the files landings stop on: `DESIGN-runtime-library.md` 5 times and `CONFORMANCE.md` 2. Both are append-only prose, where two branches each append a section. `merge_drivers.py` has drivers for keyed JSON, work notes and the ABI pin, but none for these, so each such landing still costs a finisher cycle.

## Fix direction

Measure the current rate with `python scripts/merge_drivers.py --conflicts`. If it holds, add a union driver for append-only prose (git `merge-file --union` is already used for note bodies) to `DRIVERS`, restricted to files whose edits are appends, and let `--check` and `MergeDriverDriftTests` pin it.
