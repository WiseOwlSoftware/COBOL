# PB3616 — comments and a citation that say something the code does not

**Sites:** `src/WiseOwl.Cobol.Compiler/CodeGen/DataDivision/RecordStructEmitter.cs` (the `EmitLeafMethods` summary near line 194), `DEVLOG/2422-the-implicit-bit-filler-follow-ups-of-pb3564-a-table-pad-is.md`, `tests/WiseOwl.Cobol.Tests.Conformance/HostEntryTests.cs` (the summary above `BitPrograms`, near line 1180).

One mechanism: prose that drifted from, or was never anchored to, what the code or the standard says.

1. **Stale summary (PB3597 R1-4, info).** The `EmitLeafMethods` summary says `AsLeaves()` boxes each PHYSICAL field in
   declaration order. The vector is now the non-filler fields in declaration order followed by the filler fields (physical
   fields interleaved in declaration). Reword to say so.
2. **Wrong counts (PB3597 R1-3, low).** DEVLOG entry 2422 says the change closes four of the five shapes and narrows the
   fifth, and lists three negatives below 2002. In fact it closes three (PB3597 leads 1 and 2, PB3598 shape 3), narrows one
   (shape 1), leaves one open (shape 2) and adds two negatives. The entry is stamped, so correct it by the DEVLOG
   correction route (`python scripts/devlog.py`), not a silent edit.
3. **Citation answers a different question (PB3586 R2-1, low).** The test summary cites the NOTE of ISO 14.8.2.1 as
   authority that an ELEMENTARY USAGE BIT formal crosses the host entry as its boolean positions. `cite.py --check` passes,
   but that NOTE says only that a bit group or national group is treated as an elementary item (group versus elementary
   conformance), not the position-versus-occupancy width the test pins. Re-derive the governing clause for the width
   (8.5.2.5 is already cited; check whether it alone carries it) and drop or replace the 14.8.2.1 reference. Needs spec
   reading, so an Opus adjudicator or the implementer decides the citation.
