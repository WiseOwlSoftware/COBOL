# PB4233 — PICMODE is not total: a separator period after PIC/PICTURE [IS] matches no rule, the main lexer reports through ANTLR's ConsoleErrorListener outside the DiagnosticBag and stays in PICMODE across the line, so `01 X PIC.` followed by `X(3) VALUE 'ABC'.` compiles exit 0 and runs

Found by the Mythos front-end review 2026-10-31 (GRAMMAR-REVIEW.md, N4; artifact https://claude.ai/artifact/VpxTVcaFUsArrq59EvUe5r). Pin 84cdb410f.

**Sites** (file:line at pin 84cdb410f): `CobolLexer.g4:1304-1342, :345`; `Frontend.cs:450-452 (no lexer listener; FragmentParse.cs:64-65 and CobolKeywordTokens.cs:104-106 do attach one)`; `CobolErrorListener.cs (a parser-only BaseErrorListener)`.

**Carried shard findings:** S1-1.

**Evidence paths:** `E:/COBOL-coord/scratch/w-gr1/GRAMMAR-REVIEW.md`, `E:/COBOL-coord/scratch/w-gr1/review-S1.md`, `E:/COBOL-coord/scratch/w-gr1/S1-refute/`.

**Evidence.** Probes r01/r06/r07 (S1 and S1-refute); token PIC_END.

**Mechanism.** After `PIC`/`PICTURE [IS]` the lexer is in PICMODE. A separator period matches no PICMODE rule; the main lexer reports through ANTLR's ConsoleErrorListener, outside the DiagnosticBag, and stays in PICMODE across the line, so `01 X PIC.` followed by `X(3) VALUE 'ABC'.` compiles exit 0 and runs.

**Fix direction.** The lexer listener must implement `IAntlrErrorListener<int>` and report only from the final lexer of the PB1913 loop. Drift test: "the lexer reports nothing on the suite's sources". NOT fixed by this: `01 PICTURE PIC X.`, which is a different mechanism (COBOL0808/1941).

## Landed (wave 20261788 B, 2026-10-31)

**Re-probe** (build of 11e8949be, `01 X PIC.` then `X(3) VALUE 'ABC'.`): `line 5:8 token recognition error` on the console,
`ABC` displayed, exit 0, at 2023 and 85, as filed.

**Fix.** PICMODE gains `PIC_PERIOD : '.' -> type(DOT), popMode`: a period PIC_STRING cannot take (one followed by a space, a
line end or the end of the text, §8.3.5 3)) is the separator period, so the mode is total and the parser sees `PIC .`, the
§13.18.40.2 Format 1 clause without its required character-string-1. The error is COBOL5506 "The separator period is not
expected here: expected a picture character-string", AdmittedKinds now naming PIC_STRING (§8.3.1). The main lexer carries a
`LexerErrorListener` in place of ANTLR's console listener; it collects, and `LexAndParseOnce` reports only the last lexer of
the PB1913 loop, as COBOL5704 (a compiler defect: every mode is total). `FragmentParse` and `CobolKeywordTokens` already
attached listeners of their own; there is no other `CobolLexer` in `src`.

**Witnesses.** Goldens `cases/13.18.40-PICTURE/pb4233-picture-clause-without-character-string` (refused at 85, 2002, 2014,
2023) and `pb4233_picture_string_then_separator_period` (accepted at 85: 1.25 / ABC / 3.50 / OK);
`LexerTotalityDriftTests` (the suite's sources lex with no error; the separator period after PIC / PICTURE IS / PIC IS is
DOT and ends the mode; a period inside a picture stays in it; a lexer error reaches the bag as COBOL5704).
