# PB5602 - at --std 2002 a subscripted data-name is refused in RECORD KEY, ALTERNATE RECORD KEY, RELATIVE KEY, key-level COLLATING SEQUENCE and the report CONTROL clause

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.cs#ScreenDataNameShape` (COBOL2024, the subscripted arm)
- `src/WiseOwl.Cobol.Compiler/Binding/ReportSectionBinder.cs#BindReportDescriptionClauses` (ControlOperandRef, COBOL1699) and #ScreenControlItemsDistinct (COBOL2749 treats T-C(1) and T-C(2) as one)

**Mechanism.** In 2002 a data-name-n operand includes subscription if needed (5.1.3), and these clauses' SR1 says only 'may be qualified'; the restriction to bare qualified-data-names and the no-OCCURS rules were added after 2002 (2014 Annex E.2 item 25). The file-clause screen reads every data-name-n operand as §2023:8.4.2.2.2 Format 1 with no edition, and the report CONTROL screen applies §2023:13.18.16.3 SR3.

**Inventory.** Rows claimed: `2002-GR-12.3.4.12.3-3`, `2002-SR-12.3.4.12.2-2`, `2002-SR-12.3.4.12.2-5`, `2002-SR-12.3.4.13.2-3`, `2002-SR-12.3.4.5.2-2`, `2002-SR-12.3.4.5.2-6`, `2002-SR-12.3.4.6.2-6`, `2002-SR-12.3.4.6.2-7`, `2002-SR-13.16.55.2-11`, `2002-SR-13.16.55.2-14`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:5.1.3`: "User-defined word, including qualification and subscription if needed"
- `§2002:12.3.4.12.2 SR1`: "Data-name-1 and data-name-2 may be qualified"
- `§2002:12.3.4.13.2 SR1`: "Data-name-1 may be qualified."
- `§2002:13.16.15.2 SR3`: "Data-name-1 may be qualified"
- `§2002:8.4.1.2.2 SR5`: "Each table element reference shall be subscripted except when such reference appears"

**Observed.** error COBOL2024 RECORD KEY 'K(2)' is written with a subscript ... (ISO §2023:8.4.2.2.2 Format 1); the same for ALTERNATE RECORD KEY 'A(1)' and FILE STATUS 'FS(1)'; rc=65. ctl_sub1: COBOL1699 CONTROL operand 'T-C(1)' is subscripted ... (ISO §2023:13.18.16.3 SR3).

**Expected (from the 2002 text).** RECORD KEY IS K(2) and ALTERNATE RECORD KEY IS A(1) accepted and decided by their SR2 category and location tests; CONTROL IS T-C(1) accepted.

**Sibling sweep.** every ScreenDataNameShape caller (FILE STATUS, LINAGE, RECORD DEPENDING, SORT keys, SAME AS, DEPENDING ON) at --std 2002, each against its own 2002 SR; FILE STATUS FS(1) is refused in the same probe and needs its 2002 rule read before it is added.
