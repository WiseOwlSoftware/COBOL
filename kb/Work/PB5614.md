# PB5614 - at --std 2002 the default '$' currency symbol is treated as an alphanumeric literal-7, refusing a national numeric-edited '$' picture

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/ConfigurationSlice.cs#FinalizeCurrencySigns`
- the test fires in src/WiseOwl.Cobol.Compiler/Binding/PictureAnalyzer.cs#ScreenUsageAgainstPicture (COBOL2883)

**Mechanism.** ConfigurationSlice.FinalizeCurrencySigns adds 2023 SR25's implied alphanumeric '$' clause at every edition, so the SR24/SR28 class-versus-usage test refuses USAGE NATIONAL with PICTURE $9.99. 2002 has no SR25: SR24 speaks only of a written literal-7, the default currency symbol is the COBOL currency sign, and on a national item the insertion characters are national.

**Inventory.** Rows claimed: `2002-SR-12.2.6.2-24`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:12.2.6.2 SR24`: "If literal-7 is of class alphanumeric, the associated currency symbol may be used only to define a numeric-edited item with usage display"
- `§2002:13.16.38.3 GR13d`: "A currency symbol is represented in character-string-1 either by the currency sign or by t"
- `§2002:13.16.38.3 GR2`: "When the usage of the item being edited is national, the value is the national character r"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p/dollar_nat.cob); the text is inline. Command: `cobol.exe p/dollar_nat.cob --std 2002 --run`

`p/dollar_nat.cob`:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. DOLNAT.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 NC5 PIC $9.99 USAGE NATIONAL.
       01 DC5 PIC $9.99.
       PROCEDURE DIVISION.
       P-PARA.
           MOVE 1.25 TO NC5 DC5.
           DISPLAY "DC5=" DC5.
           DISPLAY NC5.
           STOP RUN.
```

**Observed.** error COBOL2883 (5,8): data item 'NC5': the currency symbol of PICTURE $9.99 is defined by an alphanumeric literal-7 of a CURRENCY SIGN clause (the clause SR25 implies for '$' is alphanumeric) ..., rc=65.

**Expected (from the 2002 text).** compiles; NC5 edits with the national currency sign.

**Sibling sweep.** every other reader of the implied '$' clause (Cfg.DollarSpecified, CurrencyClass persisted in the repository) and PB5595 (CURRENCY SIGN SR19, the same 2014-origin pattern).

**Other editions.** 85: n/a (no national). 2014: unknown (where SR25 first appears).
