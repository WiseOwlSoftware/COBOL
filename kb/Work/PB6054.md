## Landing

- `conformance-suite/measurements/gnucobol.json` holds the cause of every failure; `harness/measurements.py record` keeps a cause
  already adjudicated for the same bucket, so a re-run after a cobc upgrade re-classifies only new failures. A new cause is
  set per test from its own diff (run.py `--keep`, then re-run the kept binary for the whole output: run.py keeps no stdout).
- Trap: a diff line that looks like two equal strings is NUL against space (cobc's undefined initial values); show
  non-printing characters before judging. Trap: `cite.py --check` needs a quotation of at least four real words.
- `kb/Work/PB6054/2026-11-22-cause-adjudication-complete.md` is the per-test record of the last 211 causes.
