# PB1683 — LANDED

**Owner approval, 2026-09-28 ~09:45 PDT:** "Okay, approve test impact analysis and start wave 70" (proposed by the
orchestrator 2026-09-28 00:40, queued over the Monday hold).

## The defect

An implementer's gate (fix-lane brief; MANDATORY-PRACTICES; `build-local.ps1 -Filter`) runs the tests the implementer
NAMES: its own goldens, `~Drift|~EditionGate`, the Unit assembly, and `~CorpusRunner|~Nist` on a shared seam. The
names are guessed from the notes. A change that breaks a test nobody thought to name passes that gate, and the red
only appears at the lander's whole-assembly gate, which then drops the branch and costs a finisher wave.

Measured: train 68b (2026-09-27) dropped groups X and Y on whole-assembly reds their filtered gates never ran:

- X: `DiagnosticPositionTests.Copy_MainLinesStayMain_CopiedLinesNameTheCopybook` and
  `ParseErrorInsideCopybook_NamesTheCopybookLine` (the COPY library search stopped searching the source's own folder).
- Y: `01 K CONSTANT AS NULL.` crashed in `DataBinder.Constants.cs`, a site no Y filter term named.

Wave 69 (four agents, 1.17 M subagent tokens) existed only to finish them.

## What to build

1. **The impact map.** For every test in the Conformance, Unit and Characterization assemblies, the set of
   `src/Cobol.Net.*` source files (plus `.g4` grammar files and the runtime) its execution touches. It is RECORDED,
   never hand-maintained: produced by a script run at battery time, or on demand, over a named commit, and stored
   with that commit's sha. Choose the collection mechanism by measurement: per-test coverage, a per-test hit
   recorder, or per-shard coverage bisected to tests. Record the recording's cost, and keep it inside the battery's
   budget.
2. **The lookup.** `python scripts/spec/impacted_tests.py <changed files | --base <sha>>` prints a vstest filter
   covering every test whose recorded set intersects the changed files, unioned with the standing terms
   (`~Drift|~EditionGate`, the Unit assembly). It is conservative by construction:
   - a changed file the map has never seen, a changed `.g4`, a changed build or `.props` file, or a map older than
     the change's base prints the WHOLE-assembly filter (`~.`) and says why;
   - it never silently narrows.
   The filter must obey `reference_vstest_filter_terms` (no `~X|~Y` form that matches nothing and exits 0); verify
   the population it selects with `build-local.ps1`'s filter-population line.
3. **Wire it in.** Once it is proven, the fix-lane implementer brief and the dispatch-spec template make
   `impacted_tests.py --base <worktree base>` the implementer's gate filter, replacing name-guessed terms, with its
   own goldens still run by name. `check_practices.py` gains the matching check. The LANDER is unchanged: it keeps
   the whole Conformance assembly unfiltered, plus Unit and Characterization.
4. **Docs.** Plan §9 (verification commands), the `gate` skill and MANDATORY-PRACTICES describe the new gate. The
   design (collection mechanism, storage, staleness rule) lives in the canonical testing or verification doc per
   `docs/DOC_INDEX.md`; extend it, never fork a second.

## Landed (wave 70 group I, 2026-09-28)

**Built** (design: `docs/rearchitecture/DESIGN-test-build-ci.md` §3.13). `scripts/spec/record_impact_map.py` records
the map in a detached worktree: `tools/impact/ImpactRecording.targets` (imported only through
`-p:CustomAfterMicrosoftCommonTargets`, so no gated or shipped build carries a probe) compiles
`tools/impact/ImpactProbe.cs` into every product assembly and the three test assemblies, plus
`ImpactTestFramework.cs` (xunit's framework with the message bus wrapped, so each collection, class and test gets
its own `AsyncLocal` hit context); `tools/impact/ImpactInstrumenter` (Mono.Cecil) puts one probe on every METHOD
and records the line ranges it owns, charges sequence-point-free members to a type-level entry, records the
static-constructor `implies` relation, and redirects `Process.Start` so a compiled COBOL program's runtime hits
reach the test that ran it. `scripts/spec/impacted_tests.py --base <cut point>` is the lookup (method level; a
declaration change widens to the file and the files naming its types; conservative `FullyQualifiedName~.` with a
reason for everything it cannot bound). `ImpactedTestsDriftTests` (Unit) gates the fallback. Wired into the
fix-lane and implementer briefs (step 7), the dispatch-spec template, `check_practices.py`, MANDATORY-PRACTICES
I1/I2, the `gate` skill and plan §9; the lander is unchanged.

**Measured cost.** Map at `dbea12428`: 35,578 probe entries; Conformance 9,274 green (15 m 19 s cold,
instrumented), Unit 29,693 green, Characterization 33 green; 18.7 min in all at BelowNormal.

**Acceptance.** Replayed with the map recorded at the pre-68b base `4b0f3e22a` (9,190 tests, 11.2 min): X
(`5171c6872`) — the map selects 9,184 of 9,190, including both
`DiagnosticPositionTests.Copy_MainLinesStayMain_CopiedLinesNameTheCopybook` and
`ParseErrorInsideCopybook_NamesTheCopybookLine`; the filter is the whole assembly. Y (`f5d81cf73`) — the whole
assembly (three `.g4` files), and the map alone selects all 8,906 tests that execute `DataBinder.Constants.cs`.

**Selectivity — the finding the owner must weigh.** Every cluster of trains 65–69 (20 commits) replayed against
the `dbea12428` map selects the WHOLE Conformance assembly: FILE granularity reached 50–100 % of the population for
every one, and METHOD granularity still reaches 5,504–9,268 of 9,274, because every golden runs the whole
pipeline, a cluster bundles three to five notes, and nearly every cluster edits a static diagnostic or construct
table (`DiagnosticCatalog`, `DiagnosticDescriptors`, `ConstructRegistry` — a static-constructor change reaches
every test that touched the type). So the derived gate is a CORRECTNESS gate (it runs every test the change can
reach, which the name-guessed filter did not) and not a narrowing one: an implementer's gate becomes one cold
whole-Conformance leg (~11–16 min at BelowNormal) where MANDATORY-PRACTICES I2 used to forbid it for lander
contention. Whether to accept that cost is the owner's decision.
