# PB4019 — the PB3803 non-vacuity check cannot fail

**Sites:** `scripts/orchestrator/test_plan_wave.py:2609` (the `listing(real) != before` check of the PB3803 dry-run arm).

**What.** The arm exists so the test is not vacuous: it must show that the REAL run writes into the coordination directory,
which a dry run must not. It compares `listing(real)` after the real run with `before`, the snapshot of the DRY directory
taken earlier. The two directories were planted separately, so their `mtime_ns` differ whether or not the real run wrote
anything: the inequality holds always, and the check proves nothing about the write path.

**Failure scenario.** A change that makes the real run write nothing (so a dry run that also writes nothing is trivially
"clean") keeps this check GREEN.

**Fix shape.** Snapshot the real directory before its own run and compare that run's after-listing with its own before-listing
(or compare names and sizes, not mtimes, of directories planted from one template). The PB3803 arm then fails when the
real run stops writing.
