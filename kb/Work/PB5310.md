# PB5310 - at --std 85 a Working-Storage OCCURS DEPENDING ON whose object is a Report Section sum counter is refused (COBOL5092, citing the 2023 rule that report items may not be referenced from other sections), where 1985 admits references to sum counters

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/ReportSectionBinder.cs` (`ReportEntryReferenceRefused`)

**Mechanism.** §1985:XIII.3.9.3 SR10 lets data-name-1 be referenced when the entry defines a sum counter, and 1985 restricts report references only where it says so (sum counters and LINE-COUNTER/PAGE-COUNTER as subscripts in the Report Section; LINE-COUNTER/PAGE-COUNTER only in SOURCE there). The OCCURS object need only be an integer (§1985:VI.5.8.3 SR6). The refusal rests on §2023:13.8.6.2.3 ("Report items shall not be accessed ... by any clauses in any other section of the data division"), which has no 1985 counterpart, and it is applied at every edition.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the adjudicated non-conforming verdicts wait in `E:/COBOL-coord/scratch/coderead-85/held-for-register.json`.
