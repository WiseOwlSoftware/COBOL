**Wave kind:** defect-for-fix-lane. Found by the train 1042b lander while reviewing PB2633 (trailing-P negative scale reaching `Pow10.AsWide`), as a sibling of the same mechanism: a PICTURE with trailing P has a NEGATIVE scale (PictureAnalyzer: scale = -trailingP), and a consumer that treats "scale ≤ 0" as "already an integer" forgets the 10^-scale factor.

**Sites:**
- `src/Cobol.Net.Runtime/Values/SetAmount.cs:61` (SetAmount.Land: `if (scale <= 0) { whole = scaled; … }` — the value is `scaled × 10^-scale`)
- callers: `src/Cobol.Net.Runtime/Values/Tables/CobolIndex.cs:90` (SET index UP/DOWN BY), `src/Cobol.Net.Runtime/Control/CobolPtr.cs:187` (SET pointer UP/DOWN BY), `src/Cobol.Net.Runtime/IO/StartKeyLength.cs:41` (START … KEY length)
- correct siblings for comparison: `src/Cobol.Net.Runtime/Intrinsics/CobolIntrinsics.Exact.cs:76`, `src/Cobol.Net.Runtime/IO/ReportWriter.cs:693` (both multiply by `Pow10.AsWide(-scale)`)

**Rule it breaks:** §13.18.40.3 (a P position is a decimal scaling position: `9PP` holding 1 is the value 100) and the SET statement's UP BY / DOWN BY general rules (the index is incremented by the VALUE of the amount).

**Measured:** lander probe `E:\COBOL-coord\scratch\t1042b\probe\setp.cob` on the train 1042b build (src/Cobol.Net.Cli/bin/Debug/net10.0/cobol.dll, base 7fb5cab75 + train): `01 N PIC 9PP VALUE 100.` `SET IX TO 1. SET IX UP BY N. SET W TO IX. DISPLAY "IX=" W.` prints `IX=0002`; `IX=0101` is owed.

**Fix direction:** `scale < 0` multiplies by 10^-scale (checked: a product past Int128 is `SetAmountLanding.BeyondCarrier`), `scale == 0` stays as is; a golden for each of the three callers (index, pointer, START key length) with a trailing-P amount. Sweep every other `scale <= 0` / `scale < 0` early-out over an unscaled value for the same omission.
