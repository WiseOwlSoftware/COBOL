# PB6182 — hand-numbered DialectBehavior values and VCR rows collide between branches

**Mechanism.** A new `DialectBehavior` is added with the next explicit enum value, the next row of
`docs/VERSION_CHANGE_REFERENCE.md` (VCR), a trigger entry in `scripts/spec/data/lineage-screen-triggers-2002.json`, and echoes in
`PublicAPI.Unshipped.txt`, `tests/doc-facts/compiler-facts.json` and the inventory row notes. Every branch that adds one takes the same
"next" number at the same spot, so two branches in flight collide in all three files.

**Evidence (from `w20262163e-PB5706-report.md`).**
1. Main's PB5705 (landed first) and PB5706 each registered a DialectBehavior at value 69 and VCR row 7.125. A finisher merged origin/main
   (da01ec0f9c) keeping both, renumbering PB5706's `PrototypeSpecialNamesAdmitAlphabetAndSymbolic` to 70 / 7.126 in the enum, the behaviour
   table, `PublicAPI.Unshipped.txt`, `compiler-facts.json` (regenerated with `WISEOWL_COBOL_WRITE_DOC_FACTS=1`), the DEVLOG pending entry,
   the inventory row notes, and `lineage_screen.py --write 2002`.
2. Pull request #2066 then bounced DIRTY: main's PB5725 (63e805e0af, 8d2e359c90) had taken 70 / 7.126 for
   `TurnDirectiveRepeatsOnlyNameFileCombination`. A second finisher (merge 5f0eb47d01) renumbered to 71 / 7.127 and re-gated.
Two finishers, two gates, a bounced queue entry, for a collision of a number nobody chooses on its merits.

**Fix shape.** Take the number out of the author's hands: the enum value, the VCR row and the trigger entry derive from a registry
the merge can combine (an append-only line per behaviour, ordered by name, with the integer assigned by a generator at build time, or a
reserved range per branch). The generated echoes (`compiler-facts.json`, the lineage screen) are already regenerated by a script; make
the integer and the row part of that generation. Whether the enum values are an ABI pin (`RuntimeAbiPinDriftTests`) bounds the choice,
which is the implementer's call. Add a drift test that refuses a second behaviour with the same value or row.

**Sites:** `src/WiseOwl.Cobol.Runtime/Control/DialectBehavior.cs` (`DialectBehavior`),
`docs/VERSION_CHANGE_REFERENCE.md` (whole: the row numbers become generated or carry no hand-chosen order),
`scripts/spec/data/lineage-screen-triggers-2002.json` (whole: one entry per behaviour is added by hand at the end today)
