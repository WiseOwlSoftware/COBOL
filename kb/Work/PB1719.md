## Mechanism (`docs/rearchitecture/DESIGN-test-build-ci.md` section 3.14.3, section 3.14.9 row M12)

`tests/_shared/GateLegs.cs` is linked into the three test projects. `ImpactTestFramework` derives from it, and the
shared attribute is compiled out under `IMPACT_RECORDING`. With no handshake, every assembly behaves as today. With a
full handshake, the assembly runs exactly its leg's cases. A partial or stale handshake makes every case an execution
error, so the run is RED; b3 showed xunit catches a constructor throw and would run every case green. Each leg writes
an identity record. `ParenTokenTwinDriftTests` takes a repository-relative path argument, so that no display name
carries the repository root.

## Acceptance

- With no handshake, counts and verdicts are unchanged.
- With a full handshake, each leg's trx definitions are exactly its cases, and the union equals `--list-tests`.
- Each partial handshake is RED.
- A planted non-permutation throws.
- A recording at HEAD still records every test.
