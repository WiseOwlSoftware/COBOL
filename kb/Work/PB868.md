# PB868 — OPEN — docs that describe a compiler that is not this one

Sources: the `PB803` report item (a) (ImageSignKind), the train-28 lander's own lead (the PictureAnalyzer
comment), and the `PB459` finisher report item (b) (VCR row 100). One mechanism: CLAUDE.md rule 6 says every doc
except the DEVLOG describes the CURRENT compiler, and each of these asserts a member or a premise that is gone.

## The sites, verified on this tree (main `b5ca78fb`)

1. **`PicInfo.ImageSignKind` — `grep -rn "ImageSignKind" src/` returns NO hit in `src/`**, while
   * `docs/DESIGN.md:1149` says *"`PicInfo.ImageSignKind` is DELETED"*, and
   * `docs/DESIGN.md:800`, `docs/FILES_DESIGN.md` **D7** and `docs/OO_DESIGN.md:151`
     state determinations that rest on it by name.
   One file contradicts itself 349 lines apart. ⚠ Which statement is CURRENT is a D7 / §14.4 question for the
   owner of the record-image determination — this note does not adjudicate it, and a fixer who guesses would be
   re-deciding the SORT key's sign convention by editing a doc.
2. **`PicInfo.SkeletonGate`** — `src/WiseOwl.Cobol.Compiler/Binding/PictureAnalyzer.cs:827`'s doc comment still
   directs the reader to "the post-bind `VersionConformancePass` GateData enumerator over `PicInfo.SkeletonGate`".
   `SkeletonGate` survives on `DataBinder.Reports.cs:265` (a different carrier); on `PicInfo` it is gone, and
   line 162 of the same file says so (*"no SkeletonGate: the category is no longer recovered"*).
3. **`docs/VERSION_CHANGE_REFERENCE.md` row 100** still reads *"(delta under-documented; confirm against the
   older standard before gating)"* for the FLAG-02 `RANGE-EXCEPTION-FOR-INDEX` delta. The condition is now real
   (PB459 landed it), so the row's premise has changed even though the `<!-- todo -->` convention itself is
   legitimate (line 63 documents it as "a genuine gate obligation not yet a `constructs.json` row").

## Shape of the fix (the structural half)

Repairing three sites is the small half. The mechanism that lets them rot is that a doc may name a compiler
SYMBOL with nothing checking the symbol exists. `scripts/spec/audit_doc_citations.py` already walks the docs for
clause citations; a second pass — for back-quoted `Type.Member` spellings that resolve to nothing in `src/` —
makes the next one automatic. That pass will report false positives (deliberately historical prose), so it needs
an allow-list keyed by file+symbol, which is a small, reviewable artifact rather than a hand-maintained list of
findings.

## Related, deliberately NOT edited here

would find it, and the audit's allow-list is where that decision belongs.
