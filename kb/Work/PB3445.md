# PB3445 — a guard witness hard-codes the default run timeout

> flags: process-only

Source: wave 1131 E (PB3385, PR #303), branch review finding R1-2, severity low.

`scripts/guard-verify.sh:287`: the new predecessor-timeout witness hard-codes the default run timeout (`after 120s`) into its
expected verdict, but the runner takes the timeout from `GUARD_RUN_TIMEOUT`. `guard-fast.sh` runs the witnesses first under the
caller's environment, so raising the timeout turns the guard self-test red. The existing timeout witnesses (lines 157 and 402)
avoid the number on purpose.

**Fix shape.** Match the witness's expected verdict the way lines 157 and 402 do (no number), or set `GUARD_RUN_TIMEOUT`
inside the witness. Owner rule: no fixed time limit in a test (PB3022).
