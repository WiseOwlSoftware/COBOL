**Wave kind:** extract. **Model:** Opus. Where the lookup belongs is a judgment: a binding-layer query that validation may
call, or `NameClass` placed lower.

**Found 2026-11-24** by the census at 9e65164eb, recorded for R2's new pin. It measured a new namespace edge,
`WiseOwl.Cobol.Validation -> WiseOwl.Cobol.Symbols` (1 use). The layers do not allow compiler.validation ->
compiler.symbols, and no tolerated row admitted it.

`FlagConformancePass.cs` has `using WiseOwl.Cobol.Symbols; // NameClass`. It calls
`_currentData.Symbols.Identify(name, NameClass.File, ...)` and `Identify(report, NameClass.Report, ...)`, so the pass
must name the symbol table's lookup enum. An enum constant compiles to an integer, so the IL walk never saw the pair.

The edge was admitted by hand in the change that recorded the census, as a tolerated row naming this note
(`docs/rearchitecture/architecture-edges.json`).

**Target:** validation reaches the file and report lookups through what the binding layer already exposes to it (as
`FilesOfContainingChain`, `FileWhoseRecordIs` and `IdentifyConditionName` are reached), with no symbols-layer type
named. Then delete the tolerated row.

**Removes:** `WiseOwl.Cobol.Validation → WiseOwl.Cobol.Symbols` (its pair)

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Validation/FlagConformancePass.cs` (`FlagConformancePass`)
- `src/WiseOwl.Cobol.Compiler/Symbols/SymbolTableSnapshot.cs` (`NameClass`; unchanged, no longer named by compiler.validation)
- `src/WiseOwl.Cobol.Compiler/Binding/SymbolTable/SymbolTable.Files.cs` (`SymbolTable.IdentifyFile`, the typed file-name question)
- `src/WiseOwl.Cobol.Compiler/Binding/SymbolTable/SymbolTable.Reports.cs` (`SymbolTable.IdentifyReport`, the typed report-name question)
- the binders that asked `Identify` for `NameClass.File` or `NameClass.Report`, each now asking the typed question: `Binding/CounterResolver.cs`, `Binding/FileControlBinder.FileSection.cs`, `Binding/FileControlBinder.IoControl.cs`, `Binding/Passes/CheckCodeSetRecordItemsPass.cs`, `Binding/Procedure/BinderContext.cs`, `Binding/Procedure/DebugDeclarativeResolver.cs`, `Binding/Procedure/UseStatementBinder.cs`, `Binding/Procedure/Verbs/EcBinder.ExceptionPerform.cs`, `Binding/Procedure/Verbs/IntrinsicBinder.cs`, `Binding/Procedure/Verbs/ReportWriterBinder.cs`, `Binding/Procedure/Verbs/SortBinder.cs`, `Binding/ReportSectionBinder.cs`, `Binding/Validation/StatementValidation.cs` (all under `src/WiseOwl.Cobol.Compiler/`)

**Landed (wave 20262172, group A).** The flag pass asks `SymbolTable.IdentifyFile` and `IdentifyReport` and names no
compiler.symbols type. The census at d0c58f441211, recorded in the landing, measures no `Validation → Symbols` edge, and the
