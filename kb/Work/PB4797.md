# PB4797 - VarianceBig and PresentValueBig overflow past about 10^3000

**What the report says (the reviewer's words).** R1-3 LEAD (low, not fixed: not in a file this round changes): `src/WiseOwl.Cobol.Runtime/Intrinsics/CobolIntrinsics.ExactValue.cs:145` `VarianceBig` and `PresentValueBig` form numerators larger than the value, so arguments past about 10^3000 end in a fatal EC-SIZE-OVERFLOW on an in-range result.

**R1.** A grep of kb/Work for `VarianceBig` and `PresentValueBig` finds only PB4750 (landed: the note whose fix wrote both). No open note covers it.

**Sites:** `src/WiseOwl.Cobol.Runtime/Intrinsics/CobolIntrinsics.ExactValue.cs#VarianceBig`, `#PresentValueBig`.

**Landed.** Re-probe on the branch build: `FUNCTION VARIANCE (0, 0, 0, 0, 0, 0, 0, 0, 0, 2.0E+3072)` ended in the fatal EC-SIZE-OVERFLOW (its
numerator 9·X² is 3.6E+6145) where the variance is 3.6E+6143. Root cause: `CobolBig.Of` range-checked every intermediate against 10^6145, but
the numerator and the discount power are body-internal numbers, n² times the result and the result's divisor. Fix: a WORKING flag on
`CobolBig` (`Working`, `AsWorking`), carried by sum, difference, product, negation and power, bounded by `MaxBits` alone; `CobolExact.Working()`
and `CobolExact.Of` keep a working value on the arbitrary-precision form; `VarianceBig` and `PresentValueBig` take their operands as working.
Sibling sweep: the other bodies on `CobolExact` (SUM, MEAN, RANGE, MOD, REM, MEDIAN, MIDRANGE) form no value larger than their result by
more than the argument count, and are left. Pinned by `conformance:cases/15.4.1-Numeric-and-integer-functions/pb4797_working_numerators_past_the_value_range`
and `CobolExactIntrinsicsTests.WorkingNumbersPastTheValueRange_DoNotOverflowAnInRangeResult`.

**Sites (landed):** `src/WiseOwl.Cobol.Runtime/Intrinsics/CobolIntrinsics.ExactValue.cs#VarianceBig`, `#PresentValueBig`, `src/WiseOwl.Cobol.Runtime/Values/Numeric/CobolBig.cs#Working`, `#AsWorking`, `#Of`, `#Add`, `#Mul`, `#Pow`, `#Negate`, `src/WiseOwl.Cobol.Runtime/Values/Numeric/CobolExact.cs#Working`, `#Of`.
