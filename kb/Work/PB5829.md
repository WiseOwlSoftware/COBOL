# PB5829 - six 2023 rules whose recorded test, on an adjudicator's reading, cannot fail on the rule

**These are one adjudicator's readings. Nobody has attacked them, nobody has re-run them, and each 2023 row below reads OK in the inventory today.** They came up while the adjudicator drafted derivations for twenty 1985 rows that carry into 2023 rules: for each 2023 row the 1985 row points at, the draft asked whether the test recorded for it can fail on the rule, and for the six rules below it answered `"test-can-fail-on-the-rule": false`. The draft calls each a FINDING against the 2023 row's evidence. The note files them so a refuter can attack them; it decides nothing about any 2023 row. The draft's list has seven entries; `GR-14.9.27.4-19` is the target of two 1985 rows, so six distinct 2023 rules are named.

**Sites:** none (an analysis of recorded evidence: no change is planned until a refuter has read it).

## A lead nobody has checked: the 1985 sequential row `1985-GR-VII.4.3.4-25` and the case `g85_bf25_01`
From the draft's note on row `1985-GR-XIII.4.5.4-18` (the Report Writer file-attribute-conflict row): the same reasoning reaches the 1985 SEQUENTIAL sibling `1985-GR-VII.4.3.4-25`, which closed on the test `g85_bf25_01`: a fixed-length record sequential file records no size either, so its S4/S5 legs (re-create at 15, read back at 15) print the same whatever size a compiler "established". Nobody has run `g85_bf25_01` against a compiler that established a different size.
