## Landing (2026-10-28, wave 20261734 group A; the whole slice)

- `src/WiseOwl.Cobol.Compiler/CodeGen/RepositoryAttributeRenderer.cs#ModuleAttribute` (and `UnitAttribute`, `TableAttributes`,
  `FormalAttributes`, `ReturningAttributes`, `MethodAttribute`, `PropertyAttributes`) — the value layer that holds every design 6.2
  rule; `CSharp` is the one C# spelling. A new backend encodes the `AttributeApplication`s
  (`tests/WiseOwl.Cobol.Tests.Unit/RepositoryBackendIndependenceTests.cs#Writer`), never re-derives presence rules.
- `src/WiseOwl.Cobol.Compiler/Binding/Repository/RepositoryCodec.cs#Of` (BoundUnit, OoClassUnit, OoInterfaceSymbol) — the one
  translation; a class's methods are the object roster then the factory roster, which `OoEmitter.EmitClassUnit` slices by
  `Symbol.Methods.Count`.
- `src/WiseOwl.Cobol.Compiler/Binding/Model/DataItem.cs#TypeDeclaration` — the declaration the binder resolved beside `TypeName`
  (`DataBinder.ExpandType`, carried by `CopyEntryDescription`); read it, never look a type-name up again outside the binder.
- `src/WiseOwl.Cobol.Compiler/Binding/Repository/RepositoryReader.cs#Class` / `Methods` — slice 8's importer starts from
  `ClassRecord` and `RepositoryCodec.Decode`'s `DecodedMethod`.
- `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/OoEmitter.cs#OoSignatureOf` — takes the method's record; the formal's attributes go on
  the carrier; adapters and presented inherited prototypes pass none.
- `tests/WiseOwl.Cobol.Tests.Unit/RepositoryRoundTripCorpusTests.cs#Corpus` — the one §17.2 corpus enumeration; reuse it.
- `src/WiseOwl.Cobol.Compiler/Binding/Repository/RepositoryCodec.cs#Table` — a link between two entries of a record is a POSITION
  (`OccursRecord.DependingEntry`, the preorder index the attribute ordinals number), never a word to look up again: the review's
  R1-1 (wave 20261739 group A) found `DEPENDING ON N OF B` decoded to the first `N`. A REDEFINES object is the one exception,
  found by the binder's own placement rule `DataItem.RedefinedEntry` (ISO §13.18.44.3 SR7, NOTE 1), which the old
  nearest-same-name lookup also broke for `X REDEFINES X` / `C REDEFINES X`. Both halves of that rule live in the one
  function (round 2's R1-1: the binder's nearest-candidate fallback for a --permissive SR7 chain stayed in the binder, so the
  decoder refused `C REDEFINES B` where B redefines A). `RepositoryCodecTests.Same` compares both links as
  positions, so every corpus formal checks them.
