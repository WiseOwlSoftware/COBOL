past-the-signed-carrier twin now calls `CobolFloat.ScaledMagnitudeToDouble`. `CobolIntrinsics.NumvalFDouble` now calls

so the value is the same. `CobolBig.Binary64Magnitude.NearestBinary64` keeps its string: its BigInteger has no length
bound for a stack buffer. Behavior-neutral: no emitted C# changes (runtime only).
