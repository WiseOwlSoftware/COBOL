# PB5558 - docs/INTRINSICS_DESIGN.md and the PowerWitness summary still describe the literal-base power arm as it was before PB5345's R1-1 fix

UNVERIFIED LEAD: re-probe before fixing.

PB5345's R1-1 fix changed the literal-base arm of `IntrinsicArgumentRules.PowerWitness`: any positive fraction exponent p/q is now
read through `IsPerfectRoot`, and a negative literal base at a fraction exponent fails open (the power-shape table of
`IntrinsicTypeSixPowerShapesDriftTests` records it as FAIL OPEN). Neither description was updated:

- `docs/INTRINSICS_DESIGN.md` line 967, in the section "The §2023:15.3 type-6 integer-argument intake asks the VALUE'S integrality
  on every carrier (PB1526, PB638)": it still says `c ** t` is read only for a positive t below 1, lying between 1 and c for
  |c| >= 2, with `IsPerfectPower`.
- the `PowerWitness` `<summary>` (`src/WiseOwl.Cobol.Compiler/Binding/IntrinsicArgumentRules.cs:1795`): same wording, and its
  fail-open list omits a negative literal base at a fraction literal.

Rule 6: update both in the change set that corrects them.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/IntrinsicArgumentRules.cs` (`IntrinsicArgumentRules.PowerWitness`),
`docs/INTRINSICS_DESIGN.md` (whole: the type-6 intake paragraph at line 967 changes, no member structure).
