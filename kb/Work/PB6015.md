# PB6015 - cite.py: one designator checked two ways

**Sites:** `scripts/spec/citation.py` (`_rule`, `parse`), `scripts/spec/cite.py#resolve`.

**Defect.** `python scripts/spec/cite.py --check "§1985:<clause> L2.4"` (no quotation) answers OK, while the same
citation with a four-word quotation is refused for its kindless designator: the right form is `SRL2.4` (the rule kind,
then the list item). The structure-only path does not hold the designator to the grammar the quotation path does, so a
citation the gate's own rule would refuse passes when it quotes nothing. Second, a table's ordinal is read clause-local:
`Table 1` and `Table 2` both check OK for `XIV.2.2.6 T1`, against the printed caption's number.

**Repro.** The readers' `cite_check` runs named in the triage (slices s-02, s-14).

**Fix.** One designator grammar for both paths (refuse the kindless form everywhere), and a table ordinal checked
against its caption.
