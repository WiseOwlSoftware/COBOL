# PB4954 - SET format wording per row has no introducing edition

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/SetFormatSelection.cs` (`SetFormatSelection.Row`, `SetFormatSelection.InEdition`, `SetFormatSelection.BraceOf`, `SetFormatSelection.RuleOf`, `SetFormatSelection.ReportNoFormat`, `SetFormatSelection.RowEditions`), `tests/WiseOwl.Cobol.Tests.Unit/SetFormatSelectionDriftTests.cs`

**Report (PB4939 finisher).** PB4939 gave a row an optional `RowAt1985` (Formats 1 and 2, the only receiver-taking formats of §1985:VI.6.23.2). Two residues remain.
1. Pointer, capacity and message-tag rows have no 1985 form, so if such a kind ever reached COBOL2112 at 85 the 2023 wording would be used. Those declarations are refused earlier at 85, so the finisher could not reach it in a probe.
2. At 2002 and 2014 the format list still names 2023-only Formats 14/16/17 (the PB4939 note asked for the 2023 text there). A per-row introducing edition would make the list name only the formats the compiled edition has.

Expected: the row table carries each row's introducing edition so a row absent from the compiled edition is absent from the list, the same shape PB4950 decides for citations. A drift test pins "a new row with no form for an edition is absent there".

**Landed.** Re-probe (`SET WS-N UP BY 1`, built `cobol.exe`) at 2002 listed Format 14, and at 2014 the list was right only because every row printed. `SetFormatSelection.Row` now carries `IntroducedIn` (the EditionInfo year): Formats 1 and 2 at 85, 5/7/9/10 at 2002 (`§2002:14.8.35.1` prints them), 8 and 14 at 2014 (registry `set-function-pointer-2014`, `occurs-dynamic-2014`), 16 and 17 at 2023 (VCR row 60, `usage-message-tag-2023`). The no-format list names only rows the compiled edition has; a row reached outside its edition is labelled as a later format. Deviation from the note: it called Format 14 2023-only, but §2023:E.3.3 lists no SET Format 14 change and the registry has OCCURS DYNAMIC at 2014, so Format 14 begins at 2014. Pins: `ARowHas1985WordingExactlyWhenItIsIntroducedAt1985`, `ARowsIntroducingEditionAgreesWithTheConstructRegistry`, `TheNoFormatListNamesOnlyTheFormatsTheEditionPrints`, golden `pb4954-set-no-format-list-omits-later-formats-at-2002`.
