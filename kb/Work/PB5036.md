# PB5036 - the edition-gate audit skips an empty window at the oldest edition

**Sites:** `scripts/spec/edition_gates.py` (`edge_findings`, `listing`)

**Found.** PB5026 lead 2. `python scripts/spec/edition_gates.py --list` prints `· remarks-removed-85 [1985, 1985)`: a row
whose window opens and closes at the oldest held edition, so it claims the construct is in NO edition. `edge_findings`
tests `starts = lo < g.start <= hi` and `ends = g.start <= lo and g.end is not None and lo < g.end <= hi` per lineage
pair, so an empty window at 1985 has no pair to start or end in, and nothing checks the claim against the chain.

**Owed.** Audit the empty window: the construct's lineage chain must hold no rule at 1985 for a row that says "in no
edition", and the audit marks it proven or fails. This continues PB4996's tooling line; add a self-test case for it.
