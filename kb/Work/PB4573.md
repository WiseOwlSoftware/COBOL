# PB4573 - one COBOL0901 rule, two messages for a retyped synonym

**Observed.** The parser arm of COBOL0901 names the ORIGINAL word: `MOVE TO SHOW` after `>>COBOL-WORDS EQUATE DISPLAY WITH SHOW` says "'DISPLAY' is a reserved word".
The funnel arm, since #1103, names the synonym and its original. The original sentence is false for the word the source wrote.

**Sites.** `src/WiseOwl.Cobol.Frontend/Parsing/CobolParserCoreBase.cs#ReservedUserWordViolation` (about line 1105) and the call at about line 729, both through
`ReservedWordSet.UserWordViolationMessage`; the funnel arm is in `src/WiseOwl.Cobol.Compiler/Validation/VersionConformancePass.cs`.

**Fix shape.** One message builder for the rule, naming the word as written and its original.

**Sites (as landed):** `src/WiseOwl.Cobol.Editions/ReservedWords.cs` (`ReservedWordSet.UserWordViolationMessage`), `src/WiseOwl.Cobol.Editions/CobolWordsMap.cs` (`CobolWordsOp.AsWritten`, `Withdrew`, `WithdrawnSyntax`;

**Landed (wave 20261860 A).** Re-probed on 69270302d: `MOVE "A" TO SHOW` after `EQUATE "DISPLAY" WITH "SHOW"` said "'DISPLAY' is a reserved word"; `01 CNST` after `EQUATE "CONSTANT" WITH "CNST"`
(the FUNNEL arm, which the note believed already named the synonym) said "'CONSTANT' is a reserved word"; `PERFORM fetch` after `EQUATE "READ" WITH "Fetch"` named READ. Root: the lexer's retype
(`CobolWordsRewriter.Plan.Apply`) makes a synonym of a word the lexer has a token for that token AND overwrites its `Text` with the original's, so every stage that quoted `Text` named the original; only a
synonym with no token (LOCALE, COPY, ...) kept its spelling. The fix: ONE sentence, `ReservedWordSet.UserWordViolationMessage(written, map, edition)`, whose synonym decision is the map's
(`CobolWordsMap.SynonymOf`), and both stages read the word from the source extent (`WrittenSource.Of(IToken)`). Found on the way and fixed (I9): the parser resolved the already-canonical text again
(`ReservedWordHere` / `ReservedWord` now read the token through `CobolWordsRewriter.CanonicalWordOf`, the one place), so `MOVE "A" TO SHOW` after `SUBSTITUTE "DISPLAY" BY "SHOW"` drew COBOL5506 and a COBOL5926 note that named DISPLAY withdrawn when the source wrote SHOW (it is now the
COBOL0901 sentence, and the note tests the written word). The three review leads of w20261859b: (1) `SwitchBindDecimalPoint` said "is not available" for SUBSTITUTE too, false under GR4, where literal-5 is
usable wherever COMMA is required: UNDEFINE says it is not available (GR3), SUBSTITUTE says the clause is written with literal-5; (2) `SwitchBindCurrency`'s PICTURE SYMBOL arm drew a self-contradictory COBOL0892 for an UNDEFINEd or
SUBSTITUTEd SYMBOL, and now names the directive; (3) the `OoIsExceptionObject` comment quotes GR2 word for word (`cite.py --check` OK). The withdrawn-word sentence is `CobolWordsOp.Withdrew` /
`WithdrawnSyntax`, one builder for the syntax-error note, both clause binders and (through `AsWritten`) `IntrinsicBinder.RemovalClause` and `CobolWordsMap.DirectiveText`.
