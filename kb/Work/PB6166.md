# PB6166 — CONFORMS — BEFORE ADVANCING after AFTER ADVANCING: the same line

Observed by PB6161's code-read refuter (unadjudicated). On a print file at `--std 85`, a `WRITE ... AFTER ADVANCING` followed by a
`WRITE ... BEFORE ADVANCING` puts the second record on the line of the first, after a bare carriage return, so the second overprints
the first. §1985:VII.4.7.4 GR16e: "If the BEFORE phrase is used, the line is presented before the representation of the printed
page is advanced". Whether the line a BEFORE write presents is the current line (left where the AFTER write printed) or a new one is
the question; decide it from the 1985 text and the device model it implies.
