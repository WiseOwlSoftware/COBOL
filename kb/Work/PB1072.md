# PB1072 — OPEN — the ALTERNATE RECORD KEY `SUPPRESS WHEN literal-1` is mis-decoded AND unscreened: `CobolLiteral.Decode` hands a figurative constant or ALL literal to the runtim

## Rule text (every citation re-run by the registrar)
- `python scripts/spec/cite.py --check 12.4.5.6.4 "when the value of data-name-1 or record-key-name-1 in that record is equal to literal-1"` → `OK  §12.4.5.6.4 6)  (General rules)`
- `python scripts/spec/cite.py --check 12.4.5.6.3 "Literal-1 shall be an alphanumeric literal, a national literal, or a figurative constant"` → `OK  §12.4.5.6.3 7)  (Syntax rules)`

### Adjudicator finding (alternate-record-key-clause, harm wrong-answer)
- **Mechanism:** SUPPRESS WHEN value is mis-decoded and compared byte-exact: DataBinder.BindFileControl stores CobolLiteral.Decode(literal.GetText()), which returns a figurative constant or ALL literal UNCHANGED as its source text ("SPACES", "ALL\"*\""), and IndexedConnector.IsSuppressed -> KeyEq -> KeyCompare is string.CompareOrdinal for a key with no collating weights, so a literal shorter than the key is never space-extended and a figurative is never repeated to the key length. Only an exact-length quoted literal suppresses.
- **Repro:** --std 2023: SELECT F ... ORGANIZATION INDEXED ACCESS DYNAMIC RECORD KEY IS R-KEY ALTERNATE RECORD KEY IS R-A1 SUPPRESS WHEN SPACES; FD F. 01 R. 05 R-KEY PIC X(2). 05 R-A1 PIC X(6). WRITE 01/"SPACES", 02/SPACES, 03/SPACES; then READ F KEY IS R-A1 with R-A1 = "SPACES" and with R-A1 = SPACES (probe out/probe/alternate-record-key-clause/gr6b.cob). Also gr6.cob: SUPPRESS WHEN "X" on PIC X(3), ALL "*" on PIC X(3), N"Q" on PIC N(2).
- **Expected (spec):** §12.4.5.6.4 GR6: no alternate access path when the key equals literal-1 ("as if they did not exist"); §14.9.51.4 GR41: a suppressed key's access path is not provided, so it cannot duplicate. gr6b: W2 '00', W3 '00', READ "SPACES" -> FOUND 01, READ spaces -> INVALID KEY '23'. gr6: key "X  " = "X", "***" = ALL "*", N"Q " = N"Q" are all suppressed; the alternate walks omit them.
- **Observed:** gr6b: W2 00, W3 22, READ "SPACES" -> 23, READ spaces -> FOUND 02 - exactly inverted. gr6: all three short/figurative/ALL/national suppression values fail to suppress (walks show records 01 and 03 on every key; READ KEY R-A2="X" finds 01), a spurious '22' on a unique key whose value is SPACES, a spurious '02' on a DUPLICATES key whose value equals the suppression value. IsSuppressed's own summary claims 'the shorter operand space-extended' - the code does not.
- **Code site:** src/Cobol.Net.Compiler/Binding/DataBinder.cs (BindFileControl, the `CobolLiteral.Decode(sl.GetText())` line in the alternateKeyClause arm); src/Cobol.Net.Runtime/IO/IndexedConnector.cs#IsSuppressed / #KeyCompare
- **Clause (adjudicator):** ISO/IEC 1989:2023 §12.4.5.6.4 GR6; §14.9.51.4 GR41; §12.4.5.6.3 SR7 (figurative constants and ALL literals are legal literal-1)

### Adjudicator finding (alternate-record-key-clause, harm under-rejects)
- **Mechanism:** The SUPPRESS WHEN literal-1 is unscreened: `alternateKeySuppressWhen : SUPPRESS WHEN? literal` admits every literal form and no binder or validator checks SR7's category or ALL-length constraints; the accepted value is then passed to the runtime as decoded text.
- **Repro:** --std 2023 on an indexed file with `05 R-ALT PIC X(3)` / `05 R-NAT PIC N(2)`, all compile exit 0 with no diagnostic: SUPPRESS WHEN 5; SUPPRESS WHEN B"1"; SUPPRESS WHEN ALL "AB"; ALTERNATE RECORD KEY IS R-ALT SUPPRESS WHEN N"A"; ALTERNATE RECORD KEY IS R-NAT SUPPRESS WHEN "A" (probes sr7num/sr7bool/sr7all/sr7cat/sr7cat2.cob).
- **Expected (spec):** §12.4.5.6.3 SR7: literal-1 shall be an alphanumeric literal, a national literal or a figurative constant, of the same category as data-name-1, and an ALL literal shall be one character long - each of the five probes shall be diagnosed; SUPPRESS WHEN ZERO (figurative) stays legal (sr7zero.cob, correctly accepted).
- **Observed:** Five violating programs compile clean. No site under src references §12.4.5.6.3 SR7 except FileControlKeyRules' 'NOT HERE' summary.
- **Code site:** src/Cobol.Net.Compiler/Binding/DataBinder.cs#BindFileControl (alternateKeyClause arm - the natural place, the literal is read there); src/Cobol.Net.Frontend/Grammar/Core/CobolIO.g4#alternateKeySuppressWhen
- **Clause (adjudicator):** ISO/IEC 1989:2023 §12.4.5.6.3 SR7
