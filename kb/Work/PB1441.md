# PB1441 — OPEN

## The rule (every citation re-run by the registrar through `cite.py --check`)

> Hex-character-sequence-1 shall be composed of hexadecimal digits

`python scripts/spec/cite.py --check 8.3.3.5.3 "…"` → `OK  §8.3.3.5.3 4)  (Syntax rules)`

## Finding — `national-literals` (wrong-answer; rows `SR-8.3.3.5.3-4`)

**Mechanism.** A hexadecimal-national literal whose content contains a non-hexadecimal character does not match NAT_BODY's HEXDIGITS arm, so the lexer silently re-tokenizes it as IDENTIFIER `NX` + STRINGLIT - the same silent-split degradation R03 closed for well-formed NX literals; §8.3.3.5.3 SR4 is never diagnosed and, with an item named NX in scope, the program compiles to a wrong answer.

**Repro.** REPOSITORY FUNCTION ALL INTRINSIC; `01 NX PIC X(4) VALUE "ZZZZ". 01 NA PIC N(4).` `MOVE FUNCTION MAX(NX"00G1") TO NA. DISPLAY "[" NA "]".` (probe n1) -> compiles with no diagnostic, prints [ZZZZ].

**Expected from the spec.** §8.3.3.5.3 SR4: "Hex-character-sequence-1 shall be composed of hexadecimal digits" (§8.3.3.1: the hexadecimal digits are 0-9 and A-F) - NX"00G1" is not a conforming literal and shall be rejected by a diagnostic naming SR4, never read as two operands.

**Observed / reasoning.** n1 prints [ZZZZ] (MAX(NX, "00G1")); without a data item NX the failure surfaces as unrelated diagnostics (n5 COBOLNET1504 argument count, n6 COBOLNET1639 'NX is not a literal'). Fix shape (the R03 doctrine: the token must match so something is left to diagnose): widen the NX (and sibling X, BX) body to any non-delimiter content and report the non-hex character at the same walker as COBOLNET1635. Siblings: HEX_BODY (X"4G", §8.3.3.2.3 SR5) and BOOL_BODY's BX arms (§8.3.3.4.3 r3) share HEXDIGITS.

**Code site.** src/Cobol.Net.Frontend/Grammar/Core/CobolLexer.g4#NAT_BODY / #HEXDIGITS (also HEX_BODY, BOOL_BODY)

## What the fixer owes

The R03 doctrine: the token must MATCH so something is left to diagnose. Widen the NX body (and the siblings HEX_BODY `X"4G"` §8.3.3.2.3 and BOOL_BODY's BX arms §8.3.3.4.3, which share HEXDIGITS) to any non-delimiter content and report the non-hex character at the same walker as COBOLNET1635. Negative golden per prefix (NX, X, BX); a drift test that every hex-prefixed literal token admits arbitrary content.
