> CONVERTING alphabet"), AGREE_ACCEPT → WE_REJECT_THEY_ACCEPT — `INSPECT X CONVERTING BETA TO ALPHA`
> where ALPHA/BETA are SPECIAL-NAMES ALPHABET names (ASCII/EBCDIC), COBOLNET1639 "'BETA' is not
> defined" since R30.

TWO SEPARATE THINGS. (1) THE DIAGNOSTIC WAS DISHONEST and is fixed with R32's mechanism: BETA IS
declared — as an alphabet-name — so the reference is exempt from the §8.4.2.1 UNDEFINED report and the
staged loud names the alphabet-name cause (the compile-accept posture is preserved pending this
adjudication). (2) THE CONSTRUCT: adjudicate the CONVERTING operand classes against the
alphabet-name form — expected finding: ISO admits identifiers/literals only and the alphabet form is a
GnuCOBOL/vendor extension whose support is a [[dialect_two_axes]] vendor-axis decision (the EBCDIC
translation semantics would need the alphabet's collating table wired to the INSPECT runtime). Survey
per [[survey_compilers_on_latitude]] before deciding.

## LANDED 2026-08-08 (adjudicated — both halves)

**The clause is §14.9.22.2, not the 14.9.19.2 this note first guessed** (14.9.19 is IF; the frontmatter
is corrected). Format 4 read from the transcription's own diagram: CONVERTING's operands are
`{identifier-6 | literal-4} TO {identifier-7 | literal-5}` — an ALPHABET-name is NEITHER (a
SPECIAL-NAMES name is not an identifier), so the CONVERTING-alphabet form is a GnuCOBOL extension not
admitted by any ISO edition. The adjudicated posture is the R37-family compile-time rejection, at the
position whose format decides: `InspectBinder`'s CONVERTING bind screens an unresolved name that IS a
declared alphabet-name and reports COBOLNET1639 with the Format-4 citation and the write-the-strings
guidance (each operand reports; the literal/identifier forms are untouched — probed with the
"ABC"→"XYZ" control). The R32-era compile-accept staging for this position is superseded by the
rejection; the generic declared-alphabet-name exemption in `ReportUnidentified` STAYS (other positions
keep the honest staged reason pending their own adjudications, if any arise). Fixture
`inspect-converting-alphabet` (reject-at all four editions, registered). The differential's
run_misc:1759 flips AGREE_ACCEPT → WE_REJECT at the next battery — the adjudicated divergence,
attribution pre-recorded here. Gate: Negative corpus 198/198 · Corpus|Inspect 528/528 ·
characterization 33/33.
