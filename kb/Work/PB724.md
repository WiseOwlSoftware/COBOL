# PB724 — CLOSED — the gate the finding says is missing is the gate that is doing the work

Train 14's lander listed PB688 report §N2 as note-ready: *"COMMIT / ROLLBACK compile SILENTLY at 85/2002/2014 (no
constructs row, no pass arm) while COBOLNET1579's decline warning is itself edition-conditional and fires only at
2023 — the quiet editions are the dangerous ones."* Verified against main (0db46983) and the standard before
filing. **The observation is accurate; the diagnosis is not.** Closed on filing rather than dropped, so the next
reader of the PB688 report does not re-open it.

## The facts

**What the standard says about the word.** COMMIT and ROLLBACK are 2023 reservations. `ReservedWords.Table.cs:84`
and `:381` encode the §8.9 interval as `(85:false, 2002:false, 2014:false, 2023:true)` with the note *"added 2023
(ISO Annex E.2 item 25 = VCR row 32)"*, and `tests/version-matrix/reserved-words.json` carries the same rows.
`cite.py --check E.2 "Compiler-directive words"` → OK §E.2 5) confirms the annex is the reservation ledger the
table is read from. At COBOL-85, 2002 and 2014 **COMMIT and ROLLBACK are user-defined words**, and the COMMIT and
ROLLBACK statements do not exist.

**What the compiler does, measured** (`src/Cobol.Net.Cli/bin/Debug/net10.0/cobol.exe` on main; sources in
`…/scratchpad/reg14/`):

| probe | source | 85 | 2002 | 2014 | 2023 |
|---|---|---|---|---|---|
| `commit85.cob` | a paragraph `MAIN.` then `COMMIT.` / `ROLLBACK.` at the sentence position | clean | clean | clean | 2× `COBOLNET1579` warning |
| `commitif.cob` | `IF X = 1 COMMIT END-IF.` — the word in a **statement** position | `COBOL0001: no viable alternative at input 'COMMIT'` | same error | same error | `COBOLNET1579`, compiles |

**The second row is the discriminator, and it is what the first row alone cannot tell you**
(`feedback_probe_the_shape_the_subject_hides`: the finding's probe held the *syntactic position* fixed at the one
place where a paragraph name and a bare verb look identical). The statement arm is
`CobolParserCore.g4:745-746`:

```antlr
| {facilityWord("COMMIT")}?   commitFacilityStatement
| {facilityWord("ROLLBACK")}? rollbackFacilityStatement
```

`facilityWord()` "fires only at the editions where §8.9 actually reserves the word" (the rule's own comment at
`:740-742`). So below 2023 the arm is never taken, `COMMIT.` is parsed as what it legally is at those editions — a
**paragraph name** — and accepting it is not an under-rejection but a REQUIREMENT. Rejecting it would be an
over-rejection of conforming COBOL-85, which is the harm `feedback_edition_gate_sweep` warns a careless gate
creates.

**Why COBOLNET1579 is edition-conditional.** It is not conditional at all: `EditionContext.Declined`
(`src/Cobol.Net.Compiler/Binding/EditionContext.cs:178-185`) has no edition test, and `StatementBinder.cs:528`
raises it unconditionally from `BindCommitRollback`. The warning "fires only at 2023" purely because that is the
only edition at which a COMMIT/ROLLBACK **statement** can exist to be declined. The §4.2.6 ¶3 obligation the
warning discharges is discharged wherever the construct is reachable.

## What DOES survive, and it is not a defect

There is no `constructs.json` row for the COMMIT or the ROLLBACK **statement** — the only rows in the family are
`user-word-commit-2023` (the reserved-word band, COBOLNET0901) and, on the DATA DIVISION side, the declined APPLY
COMMIT clause. So the introduction gate for these two statements is carried by `facilityWord()` +
`ReservedWords.Table` alone, with nothing in the version matrix pinning it: the four-editions drift tests cannot
see it, and a future edit to `facilityWord`'s reservation source would silently un-gate the statements with no
test failing. That is a **coverage** observation, not a behaviour defect, and it is exactly the class
[[PB726]] proposes to make mechanical — the Foreword bullet *"An optional Commit and rollback processing facility
using the COMMIT statement and ROLLBACK statement"* (`specs/ISO_COBOL.md:1108`) is one of the eight roster entries
with no `constructs.json` row today. Recorded there; not re-opened here.

## Why it matters

A finding that names the right symptom and the wrong mechanism is more expensive than one that is simply wrong,
because it survives review: the sentence "silent at 85/2002/2014" is TRUE and the conclusion "under-rejection" is
FALSE, and only the discriminator separates them. `feedback_validate_the_premise_not_only_the_rule` — the question
was never "why is the compiler quiet", it was "is `COMMIT.` at `--std 85` legal COBOL-85". It is.
