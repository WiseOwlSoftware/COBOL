## 2026-11-21 — train-1985-c review round 2 leads R2-1 and R2-2, fixed on train-1985-d

**R2-1.** Rule 8 now reads a `python -c` / `py -c` / `python3 -c` payload as a command line (`_python_payload`). A payload
that enumerates (`psutil.process_iter`, `psutil.pids`, a `tasklist` / `ps` / `pgrep` / `wmic` it runs) and kills (`os.kill`,
`.kill()`, `.terminate()`, `.send_signal()`, `TerminateProcess`, a `taskkill` / `pkill` / `killall` it runs) is refused. A
payload that runs `taskkill /IM`, `pkill` or `killall` is refused on its own. A script file stays outside the hook, because
the hook reads the command line and not files. P18 binds such a file.

**R2-2.** Only a `Get-Process` in command position enumerates: the step's command, an assignment's value, or a `foreach`
source. A quoted search pattern is an argument. `timeout`'s own options and duration are no longer read as its command, so
`timeout -s KILL 600 python …` kills nothing, while `timeout -k 5 600 kill $(pgrep cobol)` is still refused.
