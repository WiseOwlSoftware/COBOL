# PB1654 — OPEN

Filed 2026-09-27 by the train-66 lander from the wave-66 K implementer report. PB908 (a BIT group accepted as
INSPECT identifier-1) was discharged: it no longer reproduced once `IsInspectIdentifier1` asked
`ItemCategory.GroupKindsOf(...) & (Alphanumeric | National)` (commit `66fcfda30`). That fix's pattern (a rule that
names group kinds, written as a has-a-PICTURE test) was never swept.

**Work.** Audit the 63 `.Pic is { }` / `.Pic is null` tests under `src/Cobol.Net.Compiler/Binding/`. For each, find
the rule it implements. Where the rule names group KINDS ("an alphanumeric group item", "a national group item",
"a bit group item"), replace the PICTURE test with the one classifier, `ItemCategory.GroupKindsOf`, and add a
negative golden for the kind it used to admit. Record a zero result per site, so the sweep is evidence.
