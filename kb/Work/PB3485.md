# PB3485 — HOLDINGS keys compare as bytes

From the implementer report of PB3337 (`E:\COBOL-coord\scratch\reports\w1137a-PB3337-report.md`, `## New defects` 4, carried). Blocked on PB3337 landing.

**Mechanism.** The HOLDINGS table (the locks a transaction keeps in the file) compares keys as bytes in `TransactionKeys.Record` (`src/Cobol.Net.Runtime/IO/Store/Transactions.cs`). The report gives no failing scenario. The implementer must first establish, against the spec and the index's own key comparison, whether a key the file treats as equal can have a different byte image (collating sequence, national or padded keys). If it can, compare through the index's comparer and sweep the sibling key comparisons for the same fault; if it cannot, record why and close the note.
