# PB3542 — the ordering of item 8's ROLLBACK against the USE procedure

## Lead

Item 8's ROLLBACK (§14.6.13.1.3 item 8: "if there is a fatal exception condition for a file subject to an active APPLY
COMMIT clause, then a ROLLBACK statement is executed unconditionally") is emitted after the I-O hook, so a USE procedure
that ends in RESUME (`dispatch.ResumeTransfer`) or takes the SORT not-normal jump skips it.

Code site: `src/Cobol.Net.Compiler/CodeGen/Verbs/SequentialIoEmitter.cs#EmitUseHook`.

## The rule and the ordering readings (checked with `cite.py --check 14.6.13.1.3`, items 5 and 8 OK)

§14.6.13.1.3 says that when a fatal exception condition exists, "one of the following occurs in the order specified". Item
5: "If checking for the exception condition is enabled and there is an applicable USE statement … the associated declarative
is executed. If execution of the declarative completes normally the execution of the run unit is terminated abnormally …".
NOTE 2 to item 5: "The user is able to continue by using a RESUME statement". Item 8: "If checking for the exception
condition is not enabled, the implementor defines whether or not execution will continue … However, if there is a fatal
exception condition for a file subject to an active APPLY COMMIT clause, then a ROLLBACK statement is executed
unconditionally."

Readings to adjudicate:
- Reading 1, item 8 applies only where checking is not enabled: with checking enabled, items 1 to 7 apply, and a USE
  procedure (item 5) that completes normally ends the run unit through abnormal termination (14.6.12), with no stated
  ROLLBACK there; the emitted order is then not a defect for the checked path, and the question reduces to what the
  unchecked path does after its own hook.
- Reading 2, the ROLLBACK is unconditional for every fatal condition on a file under an active clause, wherever it falls in
  the item order: it must precede or accompany the USE procedure and so run even when the declarative ends in RESUME or the
  SORT not-normal jump takes control.
- Reading 3, the ROLLBACK runs after the declarative but before any RESUME transfers control, so RESUME continues with the
  transaction already rolled back.

The adjudication also decides whether the SORT not-normal jump (item 2: "the rules for those statements apply") is
covered by item 8 at all. No reading is chosen here.
