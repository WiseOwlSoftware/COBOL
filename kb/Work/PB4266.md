# PB4266 — the backend-contract test is missing

**Found:** Mythos session 2026-10-31 (see PB4265 for the context). Owner priority: the seam work is to be done "asap"
(PB2293).

**What is missing.** `docs/rearchitecture/DESIGN-backend-abstraction.md` §6 specifies one fixture with three
assertions that fail the build: (1) no `string`-returning render member on any `Place` subtype or `Bound*` record;
(2) no raw C#-identifier or access-path string field on a bound node, with a curated allow-list; (3) `ICodeGenBackend`
has at least two implementations, and a fixed DISPLAY-only `BoundCompilation` produces byte-identical stdout through
both. A search of `tests/` on 2026-10-31 found no such fixture (no `BackendContract*` or `BackendNeutral*` test), and
`src/WiseOwl.Cobol.Compiler/CodeGen/RoslynBackend.cs` is the only `ICodeGenBackend` implementation. The C#-rendering
member that §1.3 L1 removed from `Place` now lives in the backend (`CodeGen/Roslyn/PlaceRenderer.cs:42`), as designed,
but no test keeps it there.

**Why it matters.** Without the guard, every leak PB2293's campaign removes can come back unseen, and "the bound tree
is the backend-neutral model" (DESIGN.md §1.1) stays a claim. CLAUDE.md rule 5: pair the structure with a drift test
so the next case is automatic.

**Fix direction.** Land assertions (1) and (2) now as a ratchet: a test whose allow-list holds today's offenders and may
only shrink, so each PB2293 campaign wave deletes its rows. Write assertion (2) against the corrected §1.2 (PB4265): CLR
names allocated by `CsNames.Allocate` are allowed; C# fragments, runtime type names as text and target literal formats
are not. Add the parse-context half that §6 does not state: no `Bound*`, `Place` or model type may hold a field of a
`WiseOwl.Cobol.Frontend.Generated` type (today the §8.1 tolerated edges `Binding.Bound → Frontend.Generated` and
`Binding.Model → Frontend.Generated`, which PB2398 removes and PB2417's ArchitectureEdgesDriftTests will pin; one rule
in one place, so this assertion may BE that edge rather than a second copy). Assertion (3) lands with the first
direct-IL seam proof, a CIL backend for the DISPLAY-only program (design §3.2, §3.3: Mono.Cecil).

**Fix (landed).** `BackendContractDriftTests` holds DESIGN-backend-abstraction §6 assertions 1 and 2 as a ratchet over
a MEASURED population: `BackendInput.Measure` walks every type reachable by instance field from `BoundCompilation`
(through arrays and generic arguments, to every subtype) inside the layers `architecture-edges.json` places as
`compiler.model` and `compiler.bound`. Every member that carries or returns text (214)
is neutral by construction (`*ClrName`, 7), a neutral row of `BackendContract.Table` by kind, or a leak row naming its
§1.3 row and removers (164 neutral; 43 leaks: L4 13, L7 7, L8 6, L9 17). An unclassified member fails, a stale row
fails, and a C#-shaped or render-member name cannot be neutral. The name patterns alone would have missed
`PicInfo.ProfileInitializer`, `BoundRelational.Op` and `BoundLogical.Op`; the walk found them, and §1.3 gained L9 and a
wider L4 for them. The parse-context half is the edges file's rule, as this note allowed: the test asserts the file
allows no `compiler.model`/`compiler.bound` → `frontend.parse`/`compiler.binding` edge, and refuses an ANTLR runtime
type on the backend input (the one parse-tree reference the edges walk, which reads product types only, cannot see).
Assertion 3 is held by a pin: `RoslynBackend` is the only `ICodeGenBackend`, so the seam-proof backend cannot land
without the round-trip assertion that replaces it. `BoundUnit.Path`, a run-unit registry key, became
`BoundUnit.RegistryKey` so a neutral run-time datum no longer carries assertion 2's `Path` shape.
`PlaceNeutralityTests` (the codegen-backend §6 R5 net over the `Place` hierarchy alone) is deleted:
`TheBackendInput_HoldsEveryTypeOfTheNeutralLayers` witnesses that assertion 1 holds that whole population.

**Review round 1 (R1-1): the walk's reach.** The first walk followed instance FIELDS from `BoundCompilation` only, so a
type a backend obtains by CALLING the model was outside it: `HostSurface.TypeOf` returns a `HostType` whose `CsType`
(`"long"`, `"Int128"`, `pic.ClrType`) `HostEntryEmitter` writes verbatim, and 83 of the two layers' types were unreached.
A backend reaches a model type by holding a value, by calling a member and by naming a type outright (a static function
or table, a constant, a generated visitor interface it implements), so the walk now starts from EVERY type the edges
file places in `compiler.model`/`compiler.bound`, follows static as well as instance fields, and follows every member's
return type. The widened input classified 68 more text members: neutral rows by kind (CLR-name allocator state, COBOL
words, diagnostic text, identity keys), `HostType.CsType` as an L9 leak beside `PicInfo.ClrType` (PB3252), the runtime
method names `IntrinsicCarrierRules` keys on as an L9 leak with no remover yet, and `StatementBinder`, a binder the bound
layer still declares, as an L6 leak (PB2347), its two parse-tree returns tolerated by that row. Three findings were fixed
at their root rather than tolerated: `UsagePhraseRule.Admits` was a delegate on a model record (now the admitted set, as
data); `BitFiller.Field` was a synthesized CLR field name under a C#-shaped name (now `BitFiller.ClrName`, neutral by
construction); and the bound-visitor generator's types had no declaring file a reader could find (now stamped
`[GeneratedCode]`). The opaque-member refusal stays on FIELDS: a method returning `object` (the generated
`BoundStatementTree.OwnValueParts`) is a traversal over parts already on the input. Totals: 221 neutral rows and 55 leak
rows (L4 13, L6 8, L7 7, L8 6, L9 21).

## Landing

- `tests/WiseOwl.Cobol.Tests.Unit/Architecture/BackendInput.cs#Measure` — the ONE walk of the backend input; reuse it for any
  new backend-neutrality check rather than naming types by prefix. Its roots are every neutral-layer type, and it follows
  fields and member return types. A field typed `object` or a delegate is an exit, refused.
- `tests/WiseOwl.Cobol.Tests.Unit/Architecture/BackendContract.cs#Table` — a landing that removes a §1.3 leak deletes its
  member's row here (the test refuses a stale row); a new text member on a bound or model node needs a row in the same change.
- `tests/WiseOwl.Cobol.Tests.Unit/Architecture/BackendContractDriftTests.cs#Check` — the classifier; a name with `Cs` as a
  word, `Path` or `Field` can never be neutral, so a neutral datum with such a name is renamed (as `BoundUnit.RegistryKey` was).
- `src/WiseOwl.Cobol.Compiler/Binding/Model/BoundUnit.cs#RegistryKey` — the run-unit registry key, formerly `Path`.
