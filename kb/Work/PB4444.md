# PB4444 — COBOL1639 for an unreserved SELF/SUPER lands at the statement

**Defect.** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/OoBinder.cs:650` (`OoBinder.OoPredefinedSearchRoot`)
reports the PB4153 COBOL1639 at `qualifier`, which is null for a bare SELF or SUPER (an INVOKE receiver, an object
property's object). The diagnostic then lands at the enclosing statement or data reference instead of at the word, while
the PB4153 DEVLOG says every reader now reports at the word.

**Repro.** Not given in the report: any bare SELF/SUPER reader at `--std 85` (the PB4153 probes in
`E:/COBOL-coord/scratch/w20261824b/probe-after.txt`); compare the COBOL1639 column with the word's. Report text:
"positions the new COBOL1639 at `qualifier`, which is null for a bare SELF/SUPER, so the diagnostic lands at the enclosing
statement or data reference instead of at the word".

**Fix direction.** Position it at the SELF/SUPER token (the receiver's own token when `qualifier` is null); add a golden
that pins the column, and sweep the other readers `OoBinder.RefuseUnreservedPredefinedObject` serves for the same position
habit.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/OoBinder.cs` (`OoBinder.OoPredefinedSearchRoot`, `OoBinder.RefuseUnreservedPredefinedObject`).
