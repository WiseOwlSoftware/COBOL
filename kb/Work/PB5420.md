# PB5420 - at --std 85 PADDING CHARACTER IS symbolic-character is refused (COBOL1639, the word read as data-name-1) and IS ALL symbolic-character is refused COBOL6848, though a symbolic-character is a one-character figurative constant and QUOTE and ALL QUOTE are accepted

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/FileControlBinder.Padding.cs#CapturePadding`
- `src/WiseOwl.Cobol.Compiler/Binding/FileControlBinder.Padding.cs#OneCharacter`

**Mechanism.** `CapturePadding` resolves a bare word as data-name-1 before asking whether it is a symbolic-character, so `SYM1` fails name resolution (COBOL1639), and `OneCharacter` admits the figurative constants QUOTE, SPACE and the like but not `ALL symbolic-character` (COBOL6848). A figurative constant may stand wherever a literal appears in a format, and `[ALL] symbolic-character` is one, whose ALL is redundant.

**Found by.** The 1985 code read, read 3 (`kb/Work/PB4996/2026-11-12-read-3.md`): `E:/COBOL-coord/scratch/coderead-85/out-read3/rd-05-refute.json`.

Its rows are not recorded: the refuter's OVERTURNED verdict is held for adjudication in `E:/COBOL-coord/scratch/coderead-85/held-8.json`.

"A figurative constant may be used whenever" a literal appears in a format (`§1985:IV.4.2.2.2.3`), and `[ALL] symbolic-character` "Represents one or more of the character specified as the value of this symbolic-character" (`§1985:IV.4.2.2.2.3 GR7`).
