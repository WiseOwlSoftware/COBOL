# PB3128 — a run-time slice of an ANY LENGTH / DYNAMIC LENGTH item into a typed group formal is refused

Source: wave 1071 (unit `w1071a`, PB2077 round 3), carried from `w1070d`'s PB2077 report (lead 2). PB2077 is held by its
branch and is NOT edited; this note names it.

**The rule.** `python scripts/spec/cite.py --check 8.4.3.3.4 "Reference modification creates a unique data item that is a subset of the data item referenced by identifier-1"` -> OK, §8.4.3.3.4 5) (GR5 b)/c) bound the slice by identifier-1's positions). `--check 14.8.2.2 "the maximum length is used"` -> OK, §14.8.2.2 2). An ANY LENGTH item and a dynamic-length item (§8.5.1.10) have no static length, so a slice of one is still a legal argument whose extent is known at run time; its formal group takes the argument's length (§14.8.2.3.2 2) d), checked OK: "its length is considered to match the length of the corresponding argument").

**Observed.** PB2077 round 1 added `RefModPlace.StaticInnerPositions` (`src/Cobol.Net.Compiler/Binding/Model/Place.cs:1181` on branch `worktree-wf_787860dd-104-18`), the ONE reader of identifier-1's positions when they are static, and null for ANY LENGTH / DYNAMIC LENGTH identifier-1. `ActivationDescriptions.OfReferenceModification` (`src/Cobol.Net.Compiler/Oo/ActivationDescriptions.cs:146`) then gets `inner == null` and describes the slice with length zero; a typed group formal of positive length then refuses with COBOLNET0828 ("formal ... is larger than the argument (0)"). The case is the report's "`StaticInnerPositions` returns null" case: `E:\COBOL-coord\scratch\w1070d\r1\g1.cob` proves the STATIC case (`G(1:N)`, `G(3:)` of a 10-character group); the ANY LENGTH / DYNAMIC LENGTH twin has no recorded repro (R2: none to run), so the implementer writes it from `g1.cob` by making `G` a `PIC X ANY LENGTH` formal of a contained program/method, or a DYNAMIC LENGTH item.

**Fix shape.** A slice of a no-static-length item needs a run-time extent: take the slice's own length expression (the `N` of `(start:N)`, or identifier-1's run-time length for `(start:)`), the way D-RM1 a) of PB2077 does for the write-back; do not guess zero.
