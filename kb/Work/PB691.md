# PB691 — OPEN — the third arm of a drop fixed twice

Found 2026-09-05 by the `PB334` implementer (report §"New defects" 1) by a MECHANICAL sweep over `CobolIO.g4`: for
every I-O statement rule, which sub-rules does each binder arm consume? `writeStatement`'s `writeInvalidKey` is
consumed by the keyed arm only. Probe `<a9d94900 scratch>\PB334\probe\seqwik.cob` (ORGANIZATION SEQUENTIAL,
`WRITE SQ-REC INVALID KEY DISPLAY "W-IK" NOT INVALID KEY DISPLAY "W-NIK" END-WRITE`) prints `DONE 00` at every
edition: compiles clean, neither branch runs.

## The rule

§14.9.51.3 SR2 (`cite.py --check 14.9.51.3 "If the organization of the write file is sequential, format 1 shall be
specified"` → OK 2)), and §14.9.51.2 Format 1 has no INVALID KEY bracket — a better citation than READ's, whose
rule is a chain (§12.4.5.5.2 SR2 → §14.9.30.3 SR8 → §14.9.30.4 GR19). The program is illegal source and §4.2.2
requires the indication; under `--permissive` the bind must stand and mean something — §9.1.14's final rule runs the
NOT INVALID KEY imperative on a successful completion.

## Fix

The identical shape PB334 landed for READ: in `SequentialIoBinder.BindWrite`'s sequential leg (after the
`keyedIo.BindWrite` reroute), `ctx.Validation.ScreenForbiddenPhrase(…, "WRITE", "a file with sequential
organization", "ISO §14.9.51.3 SR2")` → COBOLNET1720 (no new code), plus a `KeyedInvalidKey?` on `BoundWrite` whose
NOT arm the emitter runs on success; `BoundStores`/`UsageCollectionPass`/`EcBinder` walk the new lists on the
sequential arm as they do on the keyed one (PB334's sweep found `BoundStores` disagreeing the moment `BoundRead`
gained the member — check the same three for WRITE). ⛔ The D9 precedent requires a MEASURED corpus sweep before
the screen lands: 309 `WRITE … INVALID KEY` sites in `tests/nist/extracted/newcob.val`, almost all on keyed files
where the phrase is legal — compile the affected NIST programs at `--std 85` and prove the failure set unchanged
(a comprehensive-gate job, not wave-local). Negatives at four editions; a `--permissive` golden for the NOT arm.
