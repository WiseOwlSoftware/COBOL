# PB5802 landing (2026-11-16)

Fixed at the root: `AssignTargetRule.Text` now reads the `predefinedNull` token as an ordinary word (`WordText`, which now takes the
spelling and an anchor context) when `UnreservedKeywordReference.IsFreeAt("NULL", edition)`, i.e. at COBOL-85, where NULL is
implementor-name-1 (§1985:VII.2.3.3 SR3). At 2002 and later it still reaches `PredefinedNullRule.Report` (COBOL2576).
Witnesses: `cases/VII.2.3@1985-FILE-CONTROL-ENTRY/pb5802-assign-to-null-85` (accept 85) and
`cases/8.4.3.10-NULL-address-pointer-and-message-tag/pb5802-assign-to-null-2002` (refused 2002, 2014, 2023, COBOL2576).
