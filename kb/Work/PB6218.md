# PB6218 — a socket that cannot be adopted leaks on the bell arm, and the test cannot see it

**Mechanism.** `tests/WiseOwl.Cobol.Tests.Unit/SocketTransportTests.cs:313`. The bell half of
`AnAcceptedSocketThatCannotBeAdoptedIsClosedAndLeavesTheServerAcceptingAndTheBellRinging` witnesses nothing the fix changed.
`AcceptBellAsync`'s `onAccepted` is `_ = Task.Run(() => ReadRingAsync(...))`, which cannot throw synchronously, so the new catch in
`AcceptLoopAsync` is never reached on the bell arm. The unadoptable socket instead faults `ReadRingAsync` at `new NetworkStream`,
before its `try`: an unobserved task exception that leaves the socket undisposed (pre-existing). The DEVLOG and the PB6134 note say
the fix applies on both arms; on the bell arm it does not.

**Fix shape.** Move `new NetworkStream` (and the socket's disposal) inside `ReadRingAsync`'s try so the socket is closed on any
fault and the exception is observed; then make the bell half of the test fail without that change (a socket that throws at
`NetworkStream` adoption, then assert it is disposed and the bell still rings).

**Sites:** `tests/WiseOwl.Cobol.Tests.Unit/SocketTransportTests.cs:313`, `AcceptBellAsync`, `ReadRingAsync`, `AcceptLoopAsync` (socket transport, runtime)
