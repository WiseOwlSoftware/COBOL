**Re-design (2026-11-12, kb/Work PB3726; `docs/rearchitecture/DESIGN-orchestrator-loop.md` section 16 rewritten).** This addendum supersedes the body above wherever they differ; the design section is the SSOT.

What changed since this note was filed: the pipeline's arm lists left the compiler's test assembly for
`scripts/self_test_arms.py` (kb/Work PB4395), so there is no `SelfTestArmSource.AssertCases` and no
`SelfTestCaseLayoutDriftTests`. The layout rule is `scripts/selftest_layout.py`, called by `self_tests.py` on every run
(a refusal is the run's RED verdict), and it carries the `REMAINING` ratchet: the count of Python files under the live
roots that still hold a self-test outside `selftests/`, exact, lowered by every conversion (section 16.2). The tests of a script
under any live root live in `<root>/selftests/<path>/<name>/`, reached through `selftest_cases.subject(__file__)`.

**Sites:** `scripts/selftest_cases.py` (new), `scripts/selftest_layout.py` (new), `scripts/self_tests.py` (whole: discovery calls the layout rule first and its docstring names the layout), `scripts/self_test_arms.py` (whole: a converted subject's arms are read as case names), `scripts/orchestrator/test_plan_wave.py` (whole: deleted; its checks become case files), `scripts/selftests/orchestrator/plan_wave/` (new), `scripts/selftests/selftest_cases/` (new), `scripts/selftests/selftest_layout/` (new), `scripts/orchestrator/testdata/plan_wave_default.json`, `docs/rearchitecture/DESIGN-test-build-ci.md` (section 3.14.10)

**Oracle.** The 416 `check(` labels of `test_plan_wave.py` equal the case files' expectation labels (both lists in the
report); `self_tests.py --list` finds every new file with the headers the old file had; the golden plan unchanged; the
layout rule RED on each planted breach section 16.2 lists (a duplicate `case_` name, a `test_x` function, a module-level
`expect(`, an out-of-order case, a file that is neither `fixtures.py` nor `test_*.py`, a directory whose subject is
missing, a count above `REMAINING`); the gate GREEN.

**Done when** `test_plan_wave.py` is gone, `REMAINING` equals the measured count, and section 12 of the design names the layout.
