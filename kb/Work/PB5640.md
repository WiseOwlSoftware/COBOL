# PB5640 - at --std 2002 INVOKE and CALL accept a bit argument reference-modified with a data-item length, where 2002 requires fixed-point literals for the whole reference modification

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ParameterConformance.cs#ScreenBitAlignment` (BitStartFault.NonLiteralRefMod)
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ParameterConformance.cs#BitAlignmentRule` (the one table of edition clauses and the reference-modification reach; `BitStartOf`)
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/AddressOfOperandScreen.cs#Admit` (SR4: ADDRESS OF keeps the whole reference modification at every edition)
- callers of `ScreenBitAlignment`: `CallBinder.cs`, `OoBinder.cs`, `UdfBinder.cs`, `MoveBinder.cs`; `PtrBinder.cs` (`BitStartOf`)

**Mechanism.** ParameterConformance.ScreenBitAlignment (BitStartFault.NonLiteralRefMod) checks only the leftmost position, the 2023 rule, at every edition; 2002 SR12a constrains subscripting and reference modification (leftmost position and length) to fixed-point numeric literals.

**Inventory.** Rows claimed: `2002-SR-14.8.22.2-12`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:14.8.22.2 SR12`: "subscripting and reference modification in that identifier consist of only fixed-point num"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p3/invoke_bit_refmod_len.cob); the text is inline. Command: `cobol.exe p3/invoke_bit_refmod_len.cob --std 2002 --run`

`p3/invoke_bit_refmod_len.cob`:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. TCIBR.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 O USAGE OBJECT REFERENCE.
       01 L PIC 9(2) VALUE 8.
       01 BG.
          05 B8 PIC 1(16) USAGE BIT.
       PROCEDURE DIVISION.
       MAIN.
           IF O NOT = NULL
               INVOKE O "TAKEB" USING B8(1:L)
           END-IF.
           DISPLAY "COMPILED".
           STOP RUN.
       END PROGRAM TCIBR.
```

**Observed.** compiles and prints COMPILED, rc=0.

**Expected (from the 2002 text).** refused at compile time.

**Sibling sweep.** CALL (§2002:14.8.4.2 SR6/SR8, same words) and function arguments (§2002:8.4.2.2.2 SR12); ADDRESS OF (AddressOfOperandScreen also reads NonLiteralRefMod).

**Other editions.** 2023: no (constrains the leftmost position only). 2014: unknown. 85: n/a (no bit items).
