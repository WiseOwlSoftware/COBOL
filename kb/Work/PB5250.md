# PB5250 - at --std 85 SAME SORT AREA and SAME SORT-MERGE AREA naming a report file are refused (COBOL2738): SameOccurrenceRule carries the 2023 limits at every edition, where 1985 lets a report file appear in any SAME clause without the RECORD phrase

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/FileControlBinder.IoControl.cs` (`SameOccurrenceRule`, `ScreenSameClauses`)

**Mechanism.** §1985:XIII.2.4.3 SR2: "A file-name that represents a report file can appear in a MULTIPLE FILE TAPE clause or in a SAME clause for which the RECORD phrase is not specified." SAME SORT AREA and SAME SORT-MERGE AREA have no RECORD phrase. `ScreenSameClauses` asks `SameOccurrenceRule`, a table with no edition arm that carries §2023:12.4.6.4.3 SR5 (a report file in one file-area clause and in no sort-merge-area clause; kb/Work PB1087 landed it), so at 85 a legal SAME SORT AREA with a report file is refused. The RECORD half (SAME RECORD AREA naming a report file, refused) holds.
