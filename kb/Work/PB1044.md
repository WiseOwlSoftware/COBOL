## The rules
- `cite.py --check 13.8.3 "Within a class definition, the report section may be specified only in a factory definition or an in"` → `OK §13.8.3 1)` — the RD in the instance definition is legal.
- `cite.py --check 14.9.49.4 "The declarative is invoked just before the named report group is produced"` → `OK §14.9.49.4 8)`.
- PB1010 made method DECLARATIVES legal; PB369 built the GR4 selector per program unit.

## Code site
`CodeGen/Verbs/OoEmitter.cs:338` `dispatch.BeforeReportingSelectors.Clear()` ('no GR4 report selector crosses into a
class unit'), while `ProgramEmitter.cs:396` is the only caller of `ReportWriterEmitter.EmitBeforeReportingSelectors`.

their golden. Sweep the other per-unit dispatch fields `OoEmitter` clears (`UseDecls`, `OuterGlobalUse`, `DebugActive`)
