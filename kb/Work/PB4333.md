# PB4333 — step 10 of PB4323: growth trigger, then the emitted-assembly differential

**Sites:** `scripts/gate.py` (whole: new in step 5, PB4328; would gain the manifest comparison), `scripts/shard_weights.py` (whole: the weekly median of the code lane's test phase is read from `verdict.json`).

**Trigger.** Conformance grew 94 % in 27 days (10,503 to 20,406). Built when the weekly median of the code lane's test phase (recorded in `verdict.json`) exceeds 6 min, or the population exceeds 1.5 times today's (about 30,000 Conformance cases). Until the trigger fires, nothing is built.

**If built.** The merge group writes a manifest of case to hash of the emitted program bytes for each main commit. A local code-lane gate whose diff does not touch `src/WiseOwl.Cobol.Runtime` compiles the population (46-84 s) and runs only the Conformance cases whose program bytes differ from main's manifest, plus every case that is not a compiled program. A runtime change runs everything. It is a sound selection: a case whose program bytes, runtime and harness inputs are byte-identical to main's cannot be affected. Measured first over 20 recent non-runtime landings; built only if the median fraction of changed programs is under 10 %.

**Adds / deletes.** 0 until it fires.

**Effect.** Conformance in a non-runtime gate from about 290 s to under 100 s if built.

**Closes.** Nothing.

**Order.** After step 5 (PB4328); step 5's acceptance measurement names this as the remedy after a thread cap and 2 slots.
