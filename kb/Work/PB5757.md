# PB5757 - 1985-GR-VI.6.17.4-7 cannot be pinned by a golden

**Sites:** none (a record of a row's evidence; `docs/conformance/8/` gains the DRV record when the registrar acts).

**The rule.** §1985:VI.6.17.4 GR7: "If identifier-1 occupies the same storage area as identifier-2, the result of
the execution of this statement is undefined, even if they are defined by the same data description entry."
(`python scripts/spec/cite.py --check "§1985:VI.6.17.4 GR7" "the result of the execution of this statement is
undefined"` printed `OK  §1985:VI.6.17.4 GR7  (║6.17.4 General Rules║)  the text is in GR7` on 2026-11-15.)

**Why no program can pin it.** The rule grants no form and states no behavior. Whatever an INITIALIZE of overlapping
operands prints is consistent with it, so no accepted case can fail on it. It is a general rule, not diagnosable, so a
refusal cannot witness it either.

**Decision.** The row gets no golden. It stays a GAP until the registrar records it as an own 1985 verdict on a
`DRV-1985-GR-VI.6.17.4-7` record of class `undefined-in-rule` (kb/Work PB5373 class 1), as
`docs/conformance/8/DRV-1985-GR-XIV.2.2.4-29.md` does for another 1985 rule that declares its own result undefined.
