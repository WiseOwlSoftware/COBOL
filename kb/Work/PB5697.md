# PB5697 - three gates at once exhausted the host's commit limit and gave 24 false reds

**Sites:** `scripts/gate_slot.py` (whole: the fix is not designed yet, either a cap sized from the commit limit or an
INFRA verdict, so the fixer names the members it changes)

**What happened.** The golden-2002-3 branch gated GREEN at f0ea270228 (run 000003-20261115T195306Z). After a merge of
main and seven PROGRAM-ID renames in its own suite cases, its next gate (run 000004-20261115T203340Z, slot 2 of 3,
the other two slots held by whole-population gates) went `RED — Conformance RED; Unit RED`, with 24 `Failed` lines. None
of the failing cases is one the branch touched, and every failure is a host-resource error:

- `System.IO.IOException : Insufficient quota to complete the requested service.` (ERROR_NOT_ENOUGH_QUOTA) in
  `Directory.CreateDirectory`, from `ConformanceSuiteRunner.Stage` and `ScratchDirectory.Create`;
- `Failed to load System.Private.CoreLib.dll (error code 0x8007000E)` (out of memory) in a NIST chain run;
- `Failed to load [...]\hostfxr.dll], HRESULT: 0x800705AF` (the paging file is too small);
- "the compiler crashed on it: System.InvalidOperationException: Decoder ran into invalid data", and empty program
  output, in cases that pass everywhere else.

Afterwards the host read FreePhysicalMemory 56.5 GB and FreeVirtualMemory 57.9 GB of TotalVirtualMemorySize 137.7 GB,
with three gates still in their slots and one waiting (`gate_slot.py status`). The commit limit was exhausted while
the gates ran and recovered afterwards.

**Why it matters.** The gate reports a host's resource exhaustion as test reds. An agent reading `RED` either re-gates
(a whole-population run spent) or hunts a defect that is not there. PB2514's cap of 3 was measured for wall time
(PB4328: three gates together, 503 s each), not for peak commit charge.

**For the fixer.** Measure the peak commit charge of one whole-population gate. Then either size the slot cap from the
host's commit limit, or make the gate tell host exhaustion apart from a test red. The second means classing these
HRESULTs and IOExceptions as an `INFRA` verdict that names the resource, never `RED`. Re-measure with three gates
together.
