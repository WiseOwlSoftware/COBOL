# PB4951 - the fix lane's population is the register's `next`, whatever the kind

**Sites:** `scripts/spec/work.py` (`fixable`, `actionable`) · `scripts/orchestrator/clusters.py` (`ready_notes_view`) ·
`scripts/spec/ledger_plan.py` (`lanes_of`, `remaining`) · `.agent-fleet.json` · `scripts/spec/gen_ledger.py` (`build`)

**What was wrong.** Two predicates answered "what does the fix lane work". `work.py next` (`actionable`) lists every open,
ready note that sets a harm flag and is not `process_only`, whatever its `kind`. The planner handed `fix_clusters.py`
every ready note, and `fix_clusters.py` kept only `.agent-fleet.json`'s `kind: defect` and skipped its `skip_flag`
(`process_only`); `ledger_plan.lanes_of` read the same two keys. So a harmed ANALYSIS led `next` and was planned by no
lane: on 2026-11-07 `next` led with PB4929 and PB4923 (both analyses), and after PB4949 flagged PB4115, PB4119, PB4623,
PB4641, PB4765 and PB3631, the ledger listed all eight among the open compiler notes no lane plans. PB4949 made the
register rank them; this makes the loop work them.

**The fix.** `work.fixable(it)`: a harm flag set and not `process_only`, read on `with_inherited_harm`'s copy so a
prerequisite counts with the harm it owes (PB4769). `actionable` uses it; `clusters.ready_notes_view` copies a note only
when it is ready and fixable, so the public `fix_clusters.py` filters nothing; `ledger_plan.lanes_of` gives FIX exactly
when it holds. `.agent-fleet.json` loses `kind` and `skip_flag`, and `remaining()` its `fleet` argument (every caller
changed). On the register at main e72a54d641 the planner's view is exactly the 14 notes `next` lists, and the notes no
lane plans fall from 16 to 7, all decisions.

**Self-tests.** test_plan_wave: a harmed analysis is in the view; an unharmed decision, an unharmed analysis and a
process_only defect are not; a process_only note with no harmed dependent stays out. ledger_plan: a harmed analysis and
a harmed adjudication get the fix lane, an unflagged defect gets none.

**Left open.** The 7 decisions no lane plans (PB3099, PB3942, PB3983, PB4222, PB4223, PB4253, PB4950) await the owner;
a decision is not fix-lane work, and the ledger keeps naming them.
