# PB1736 — OPEN

Filed by the train-72 lander, 2026-09-29. Reported by wave 72 group H, and reproduced twice by the lander.

## Finding

**Code site.** `scripts/hooks/forbidden_commands.py:108`:
`VERDICT = re.compile(r"\bdotnet\s+(?:test|build)\b|build-local\.(?:ps1|sh)\b|push-main\.sh\b|battery\.sh\b|" …`,
applied per segment at line 139 (`if not VERDICT.search(seg)`). The script names are matched anywhere in the
segment, not only in command position.

**Repros (each was BLOCKED as "chained after the verdict command").**
1. Group H: `cat scripts/build-local.ps1; echo`.
2. Lander: `git ls-tree 0e3262237 scripts/linux-gate.sh scripts/build-local.sh; git ls-tree <branch> …`. The first
   segment is a read-only `git ls-tree` that names the file as an argument.
3. Lander: `grep -rlE '…|build-local.p…' kb/Work | head; …`. Here the name is only a regex pattern text.

**Harm.** False blocks on read-only commands. Each costs a turn and teaches agents to split commands for no reason,
and agent cost is quadratic in turns (MANDATORY-PRACTICES P14).

**Fix shape.** Match a verdict command only in COMMAND position: the segment's first word (after `env`/assignment
prefixes, `pwsh`/`bash`/`python` launchers and their flags) is the script. Keep `dotnet test|build` as it is. Add
the three repros above as ALLOWED arms and `pwsh scripts/build-local.ps1 -Mode lander; git commit` as a BLOCKED arm
in `scripts/hooks/test_forbidden_commands.py`.
