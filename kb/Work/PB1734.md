## Finding

M13 (PB1721) deleted the gate's selection interface: `build-local -Filter`, `impacted_tests.py`'s filter line and
`--plus` are gone, and every gate runs the whole discovered population in order (`-Mode implementer|lander`). The
project's own `gate` skill was updated in the same change. The PUBLIC base skill it overlays,
`skills/test-gate/SKILL.md` in https://github.com/BrentRector/claude-skills (local clone `E:\claude-skills`, pinned
here as `tools/claude-skills`), is a different repository and was not touched.

**Harm.** The owner's standing rule (keep the public skills current with every process change, the same session)
is unmet. Readers of the public repository, and any project that uses the base skill, see the superseded method.

**Fix shape.** Generalize "order, don't skip" into the base `test-gate` skill (ordering changes when a case runs,
never whether; a population check against the discovered listing; fail-fast legs for the implementer, one leg for
the lander). Run its eval cases (MANDATORY-PRACTICES O7), publish a new version, and bump the `tools/claude-skills`
pin here.
