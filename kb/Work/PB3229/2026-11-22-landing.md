## PB3229 landed (wave 20262135 group D, 2026-11-22)

**Re-probe on the branch's build (base 608ccf507c).** The note's own UDF scenario no longer reproduces: PB1400/PB3192
already route the BY VALUE class screen through `IntrinsicArgumentRules.ClassNameOf` ("is of class alphanumeric
(numeric-edited)"). The mechanism did: `01 E PIC ZZ9 SIGN LEADING.` printed `COBOL2422 … this entry is of category
numericedited (PICTURE ZZ9)`, and 18 more sites interpolated a `PicCategory` or `Usage` member's C# name into a message.

**Fix.** One reader per word: `ItemCategory.CategoryName` gains a `PicCategory` overload (a literal's, a constant's or a
function result's category, which has no PICTURE to refine it) and its `Table16Operand` overload is public; every
binder message that named a category (`AssignTargetRule`, `DataBinder.SignClause`, `DataBinder` bit-window leaf,
`ExternalizedName` x2, `CheckUsageDeclarationsPass`, `ResolveRecordFormatPass`, `OperandClassScreen`, `CallBinder`,
`ConditionBinder`, `MoveBinder`, `SetBinder` x2, `ReportSectionBinder` x3, `RefModBinder`, `SpecialNamesBinder.Literals`
(which also said "class" for a category), `ExpressionBinder`, `StringUnstringBinder`) reads it. The usage siblings
(`ResolveRecordFormatPass`, `RefModBinder`, `DataBinder`, `InspectBinder`, `StringUnstringBinder.UsageOffence`) read
`UsageFamilies.UsageWord`. `IntrinsicArgumentRules.Name`'s `ToLowerInvariant` fallback is an `UnreachableException`:
the switch is exhaustive over `CobolClass`.

**Drift.** `ClassSpellingDriftTests.NoDiagnostic_SpellsACategoryFromTheEnumName` and `…SpellsAUsageFromTheEnumName`
sweep the compiler for an interpolation hole that renders either enum's member name (exception text and
`string.Create` identity keys exempt), each with a theory pinning the forms it was written in. No `ToLowerInvariant`
on a category remains, so CA1308 has nothing to report here.

**Golden.** `conformance-suite/cases/13.18.52-SIGN/pb3229-sign-numeric-edited-category.cob`, refused at 85/2002/2014/2023
with `this entry is of category numeric-edited`.

**Left alone.** `CtCategory` (Frontend, `CobolWordsDirectiveProcessor`) has only one-word members, whose lower-cased
names are Table 2's words; `FileOrganization` lower-casing in `KeyedIoBinder`/`StatementValidation`/
`ExceptionPhraseRequirement` names an organization, and its one two-word member, `LineSequential`, reaches none of
them (`ExceptionPhraseRequirement` spells every sequential file "sequential"; the other two are relative/indexed
screens).
