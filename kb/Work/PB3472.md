# PB3472 — a Conformance test duplicates the keyed-file registration

Low, non-blocking DUPLICATION lead from the branch review of PB3459 (report `E:\COBOL-coord\scratch\reports\w1134b-PB3458-report.md`, `## Review findings` LEAD 2).

**Mechanism.** `tests/Cobol.Net.Tests.Conformance/RelativeEnginePermanentErrorWitnessTests.cs` (a different project) registers its own relative file, because `FileHarness` lives in `tests/Cobol.Net.Tests.Unit` and a test project cannot share it without a shared test-support project.

**Fix shape.** Decide whether a shared test-support project (holding `FileHarness` and any other cross-project helpers) is warranted; if so, move the harness there and convert the Conformance class, deleting its private registration in the same change. Sweep `tests/Cobol.Net.Tests.Conformance` for further private connector-registration copies first; if this is the only one, record the decision in this note and close it as not worth a project.

**Sites:**
- `tests/Cobol.Net.Tests.Conformance/RelativeEnginePermanentErrorWitnessTests.cs`
- `tests/Cobol.Net.Tests.Unit/FileHarness.cs`
