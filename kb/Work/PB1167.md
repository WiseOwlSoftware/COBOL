# PB1167 — OPEN

## The rule (every citation re-run by the registrar through `cite.py --check`)

> 4) If the receiving operand is described with the ANY LENGTH clause, the sending operand shall also be described with the ANY LENGTH clause.

`python scripts/spec/cite.py --check 14.8.3.3 "…"` → `OK  §14.8.3.3 4)  (Elementary items)`

## Finding — `returning-items` (rejects-legal-source; rows `GR-14.8.3.3-L3.5`, `GR-14.8.3.3-L3.4`)

**Mechanism.** An ANY LENGTH returning item (contained program or method) is refused at declaration (COBOLNET0899, 'the ANY-LENGTH-RETURNING wave'), so rule 5's relaxation and rule 4's conforming pairing are unreachable; no register note owns the wave

**Repro.** Class RIC7 method GETV 'LINKAGE SECTION. 01 R PIC X ANY LENGTH. PROCEDURE DIVISION RETURNING R.' 'DISPLAY "MLEN=" FUNCTION LENGTH(R)' 'MOVE "ABCDEFGH" TO R'; main 'INVOKE O "GETV" RETURNING R5' with R5 PIC X(5); and the same as a nested program NR7 called 'CALL "NR7" AS NESTED RETURNING C5' (p7.cob).

**Expected from the spec.** §13.18.2.3 SR3 b) permits ANY LENGTH on a contained program's or method's returning item; §14.8.3.3 rule 5 makes its length match the receiver's; §13.18.2.4 GR1 b) gives n = 5. Output MLEN=5, [ABCDE], NLEN=5, [ABCDE].

**Observed / reasoning.** COBOLNET0899 on both declarations ('recognized (ISO §13.18.2.3 SR3b) but not yet implemented'), then COBOLNET0828/1736 'length mismatch (formal X(1), argument X(5))'. The comparator's anyLengthFormal relaxation and OoEmitter's width-fit delivery are written but dead. Rule 4's prohibition (ANY LENGTH receiver, fixed sender) IS enforced (p8.cob -> COBOLNET1736 citing rule 4).

**Code site.** src/Cobol.Net.Compiler/Binding/DataBinder.Linkage.cs#AnyLengthValidateUnit; src/Cobol.Net.Compiler/Binding/DataBinder.Oo.cs#OoBindMethodData

## What the fixer owes

Lift the COBOLNET0899 staging in DataBinder.Linkage.AnyLengthValidateUnit / DataBinder.Oo.OoBindMethodData for a contained program's or method's RETURNING item (§13.18.2.3 SR3 b)), give the returning item its length from the receiver (§13.18.2.4 GR1 b)), and wire the existing comparator relaxation and OoEmitter width-fit. Keep rule 4's prohibition (p8.cob, already enforced). Golden p7.cob: MLEN=5 [ABCDE] NLEN=5 [ABCDE].

# PB1211 — OPEN

## Measured

**any-length-clause** — ANY LENGTH on a PROCEDURE DIVISION RETURNING item (contained program and method) is staged loud as RecognizedNotImplemented COBOLNET0899, so the legal 13.18.2.3 SR3b leg and the returning-item half of 13.18.2.4 GR1 are unimplemented

- **Repro:** p2.cob: outer program `01 A3 PIC XXX VALUE "XYZ". CALL "ALP2SUB" RETURNING A3. DISPLAY "A3=" A3.`; contained ALP2SUB `LINKAGE SECTION. 01 L PIC X ANY LENGTH. PROCEDURE DIVISION RETURNING L. MOVE "ABCDEF" TO L. EXIT PROGRAM.` -> COBOLNET0899 'ANY LENGTH on the PROCEDURE DIVISION RETURNING item is recognized ... but not yet implemented'. Method arm: p8.cob METHOD-ID RET with `PROCEDURE DIVISION RETURNING R`, R PIC X ANY LENGTH -> same 0899.
- **Expected (spec):** 13.18.2.3 SR3 b) permits the returning item for a contained program or method; 13.18.2.4 GR1 b) makes L n=3 repetitions of X (the length of the activator's returning item A3), so MOVE "ABCDEF" TO L stores ABC and the caller prints A3=ABC; GR1 a) makes L zero-length when the activator's returning item is zero-length. Only an INLINE method invocation forbids an ANY LENGTH returning item (8.4.3.4.3 SR4).
- **Observed:** DataBinder.Linkage.cs AnyLengthValidateUnit (`else if (returning && !formal) Edition.Error(DiagnosticCatalog.AnyLengthReturning, ...)`) and DataBinder.Oo.cs OoBindMethodData (same for m.Binding.Returning). The catalog marks it RecognizedNotImplemented ('the ANY-LENGTH-RETURNING wave'); no open kb/Work note owns it - a new defect note is needed. The return crossing must carry the activator's receiving-item length into the callee (CallAbi width = -1 mode for the returning slot), and the inline-invocation SR4 rejection (COBOLNET2140) must remain.
- **Code site:** src/Cobol.Net.Compiler/Binding/DataBinder.Linkage.cs#AnyLengthValidateUnit; src/Cobol.Net.Compiler/Binding/DataBinder.Oo.cs#OoBindMethodData; src/Cobol.Net.Runtime/Control/CallAbi.cs
