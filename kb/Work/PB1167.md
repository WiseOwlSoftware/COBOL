# PB1167 — LANDED (wave 1013, group L)

## Landed

Both COBOLNET0899 'ANY-LENGTH-RETURNING' stagings are deleted (`DataBinder.Linkage.AnyLengthValidateUnit`,
`DataBinder.Oo.OoBindMethodData`; the catalog descriptor `any-length-returning` is a tombstone) and n (§13.18.2.4 GR1 b))
reaches the activated element before its first statement, on each ABI:

- **Program ABI.** `ProgramEmitter.EmitCallMethod` seeds the RETURNING item before `__Activate()` with
  `CobolArgAdapt.ReturningSeed(__ret, fill, declared)`: n = the receiver's stated `CobolArg.Length`, else an ANY LENGTH /
  DYNAMIC LENGTH receiver's carrier length (zero included, GR1 a)), else the declared PICTURE length for an activation with
  no receiver (GR1 is silent: determination D-ALR1 in docs/CONFORMANCE.md; `FitToReceiver` and `ReturningDelivery` needed
  nothing).
- **Method ABI.** `OoEmitter.OoSignatureOf` appends a trailing `int __retLen` for exactly the methods whose RETURNING item is
  ANY LENGTH (class method, interface member and covariant adapter share the one builder); `EmitInstanceInvoke` passes the
  receiver's length (`ReceiverLength`) or the declared length when the statement has no RETURNING phrase; the method's
  RETURNING local starts as `new string(fill, __retLen)`. The universal-receiver switch still sets EC-OO-UNIVERSAL
  (§14.9.23.4 GR7 c)); an inline invocation (§8.4.3.4.3 SR4, COBOLNET2140) and a PROPERTY method (§13.18.2.3 SR2) stay refused.

Goldens: `conformance:2002/pb1167_any_length_returning` (method and nested program; X, N, 1 and group receivers; an ANY
LENGTH receiver), `conformance:2002/pb1167_any_length_returning_zero_length` (GR1 a) end to end), negatives
`pb1167-inline-invocation-returning-any-length` (the ANY LENGTH twin of PB428's SR4 fixture),
`pb1167-any-length-returning-property-method`, `pb1167-returning-fixed-sender-any-length-receiver` (rule 4); unit
`ReturningSeedTests`. Rows closed: GR-14.8.3.3-L3.4, GR-14.8.3.3-L3.5, SR-13.18.2.3-3, GR-13.18.2.4-1, GR-8.5.4-3 (batch
w1013l-pb1167, GAP 381 -> 376).

Found while here and noted, not changed: a DYNAMIC LENGTH argument to an ANY LENGTH formal through `CALL ... AS NESTED` is
refused COBOLNET1688 'DYNAMIC LENGTH mismatch' (§14.8.2.3.2 rule 2 lists DYNAMIC LENGTH among the clauses that shall match
and rule d) relaxes only the length), while a Format-1 CALL accepts it; the reading is the standard's, so no defect is filed.

## Finding — `returning-items` (rejects-legal-source; rows `GR-14.8.3.3-L3.5`, `GR-14.8.3.3-L3.4`)

**Mechanism.** An ANY LENGTH returning item (contained program or method) is refused at declaration (COBOLNET0899, 'the ANY-LENGTH-RETURNING wave'), so rule 5's relaxation and rule 4's conforming pairing are unreachable; no register note owns the wave

**Repro.** Class RIC7 method GETV 'LINKAGE SECTION. 01 R PIC X ANY LENGTH. PROCEDURE DIVISION RETURNING R.' 'DISPLAY "MLEN=" FUNCTION LENGTH(R)' 'MOVE "ABCDEFGH" TO R'; main 'INVOKE O "GETV" RETURNING R5' with R5 PIC X(5); and the same as a nested program NR7 called 'CALL "NR7" AS NESTED RETURNING C5' (p7.cob).

**Expected from the spec.** §13.18.2.3 SR3 b) permits ANY LENGTH on a contained program's or method's returning item; §14.8.3.3 rule 5 makes its length match the receiver's; §13.18.2.4 GR1 b) gives n = 5. Output MLEN=5, [ABCDE], NLEN=5, [ABCDE].

**Observed / reasoning.** COBOLNET0899 on both declarations ('recognized (ISO §13.18.2.3 SR3b) but not yet implemented'), then COBOLNET0828/1736 'length mismatch (formal X(1), argument X(5))'. The comparator's anyLengthFormal relaxation and OoEmitter's width-fit delivery are written but dead. Rule 4's prohibition (ANY LENGTH receiver, fixed sender) IS enforced (p8.cob -> COBOLNET1736 citing rule 4).

**Code site.** src/Cobol.Net.Compiler/Binding/DataBinder.Linkage.cs#AnyLengthValidateUnit; src/Cobol.Net.Compiler/Binding/DataBinder.Oo.cs#OoBindMethodData

## What the fixer owes

Lift the COBOLNET0899 staging in DataBinder.Linkage.AnyLengthValidateUnit / DataBinder.Oo.OoBindMethodData for a contained program's or method's RETURNING item (§13.18.2.3 SR3 b)), give the returning item its length from the receiver (§13.18.2.4 GR1 b)), and wire the existing comparator relaxation and OoEmitter width-fit. Keep rule 4's prohibition (p8.cob, already enforced). Golden p7.cob: MLEN=5 [ABCDE] NLEN=5 [ABCDE].
