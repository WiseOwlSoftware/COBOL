# PB3793 — the OO design doc's GR7 c) bullet list is stale

**Sites:** `docs/COBOLNET_OO_DESIGN.md` (lines 677-695, the GR7 c) enumeration and its closing sentence at line 693; the PB1112 paragraph at line 1047 is current)

## Measured

The doc's GR7 c) bullet (the list of what the universal switch checks) names the ACTIVE-CLASS returning arm
(`ActiveClassReturningViolation` / `CheckActiveClassReturning`, which proceeds unchecked) but not the ACTIVE-CLASS formal
arm (`ActivationRelations.ActiveClassFormalViolation` / `CobolObject.CheckActiveClassFormal`, section 14.8.2.3.2 rule 4).
Its closing sentence (line 693) says a nonconforming crossing with checking not enabled in both "cannot proceed" and takes
`CobolImplementorFatalException`, which contradicts the formal arm, where the invocation proceeds unchecked. Only the
PB1112 paragraph (line 1047) was updated by PB2985.

## Acceptance

- The GR7 c) list names both ACTIVE-CLASS arms; the closing sentence states which crossings raise
  `CobolImplementorFatalException` and which proceed unchecked, matching `CobolObject.CheckActiveClassFormal` and
  `CheckActiveClassReturning`.
- Run `python scripts/spec/cite.py --check 14.8.2.3.2 "<quoted rule 4 text>"` before the section is cited.
