# PB6135 - the 1985 transcription is finished by checks, not by more reading passes

**What happened.** PB6051's end was "when a full pass finds nothing". Passes 3, 4 and 5 each read all 976 pages with opus at
about 10M subagent tokens and confirmed 7, 5 and 4 new errors, on pages earlier passes had passed. A reader misses at
random, so repeated whole-document readings do not converge cheaply. Owner 2026-11-23: "10M tokens scanning the same text
over and over, finding a new handful of bugs each time is wasting my funds and tokens. You should have found all the errors
in the first scan."

**Decision (owner approved, 2026-11-23).** No further full agent pass over the 1985 Markdown. PB6051 closes when:
1. every error class the passes found has a mechanical whole-document check that is GREEN in the gate: heading levels and
   title forms (PB6057, PB6095, `heading_levels.TITLE_FORMS`), plus one check per further class (table-row indentation
   against the printed hierarchy, level-2 box markers on `<pre>` formats and prose, `<u>`/`║` nesting, brace and bracket
   continuation layout, figure identity via `sweep_figures.py`); and
2. a script comparing the PDF's text layer (`specs-private/ANSI_COBOL_1985.pdf`, present on all 976 pages; it is OCR text,
   e.g. `file-name-l` for `file-name-1`, so the diff normalises known OCR confusions) with the Markdown, word sequence by
   page, reports no unexplained difference. A residual difference the script cannot classify goes to an agent for that page
   alone, never a whole pass.

**How to apply elsewhere.** Verifying a transcription or any large text: one reading pass at most, then turn each error
class into a mechanical check and fix every instance in one sweep; agents only for what a script cannot judge, scoped to
the pages that need it.

**Closes** when PB6051 closes on the two conditions above.
