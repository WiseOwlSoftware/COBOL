# R17 — a SIGNED floating-point literal cannot be written as an intrinsic argument (lexed as two arguments)

> R00 ledger-audit orphan (2026-08-08): F12 of `PHASE-B-15.32-15.44-findings.md`, probe-verified OPEN
> against the R10-landed tree (`5312996a`). The probe programs are reproducible from the finding text.

PROBE (2026-08-08): `COMPUTE R = FUNCTION EXP(-1.5E1)` → `COBOLNET1504: FUNCTION EXP takes 1 argument(s);
2 given`. §8.3.3.3.3 r2 makes the sign part of the literal; the lexer has FN_SIGNED_DECIMALLIT and
FN_SIGNED_INTEGERLIT twins but NO FN_SIGNED_FLOATLIT (and no SUB_FLOATLIT in subscript mode), so maximal
munch takes `-1.5` and orphans `E1` as an identifier. Family-wide: every intrinsic and UDF argument position.
FIX (ledger): add the signed float twin ORDERED FIRST so the exponent stays attached, plus the subscript-mode
twin, plus a drift test pinning the three signed-literal shapes against one another.
