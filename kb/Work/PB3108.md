# PB3108 — the harness's fixed run budget turns host load into reds

> ⚙ **flags:** process-only

Source: kb/Work PB3104 "Separately worth recording".

non-observation report near line 174: a run is killed after the budget and the case reads HARNESS NON-OBSERVATION (RED).
The budget is a fixed number, not scaled from the measured cost of the case.
