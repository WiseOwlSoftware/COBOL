# PB62 — LANDED 2026-08-18 — TryExpandAll expanded table ALL at bind time only, so ODO tables rejected and the arity gate saw phantom arguments

> ⚙ **flags:** rejects-legal · **12 inventory rows** (triage 2026-08-09, probe+refute confirmed; the
> per-row mechanisms live in the triage record and each row's inventory notes)

> `IntrinsicBinder.TryExpandAll` expands `table(ALL)` subscripts at BIND time by the OCCURS count and
> emits `BoundOperandError` on OCCURS DEPENDING ON — but the SS15.4 variadic model is a RUNTIME argument
> list, so legal `FUNCTION SUM(T(ALL))` over an ODO table is REJECTED, and a fixed table's expansion runs
> BEFORE the arity gate so arity diagnostics count phantom arguments. `AlignedArgsEx` then forces the MAX
> scale across the whole expansion (RV-15.60.4-1's precision leg). CURRENT-DATE's arity arm miscounts for
> the same before/after reason (FMT-15.21.2), and TryExpandAll runs unconditionally for EVERY catalogued
> function (FMT-15.47.2).
> **The fix**: ALL-expansion becomes a runtime enumeration seam (the emitter iterates the live occurrence
> count), the arity gate counts SOURCE arguments, and both stray arms fall out of the restructuring.

### ✅ LANDED 2026-08-18 (DEVLOG 1298) — 12 of 12 rows CONFORMS (GAP 4079 → 4067)

> `IntrinsicBinder.TryBindAllArgument` binds a `table(… ALL …)` argument as ONE `BoundFieldOperand` over a
> `TableAllPlace(Element, IndexVar, Counts)` — a decorator over the element place carrying one `AllCount` per ALL
> level (`Fixed` / `Odo(depending, min, max)` / `Capacity(register)`), which the backend ENUMERATES
> (`CobolTable.AllArgs` via `IntrinsicRenderer.ArgArray`; every `params T[]` list, PRESENT-VALUE's leading rate,
> MEAN's divisor, TRIM's argument-2 tail). §15.3 admissibility is decided FIRST from the definition
> (`IntrinsicSig.RepeatsAnArgument` — MaxArgs unbounded, pinned to the §15.x.2 formats' ellipsis by
> `IntrinsicRepeatedArgumentDriftTests`) — COBOLNET1645 on MOD/ANNUITY/LOG/INTEGER-OF-DAY at any cardinality; the
> arity gate counts the arguments as written. Under a standard mode the summing family always evaluates on the
> SDIDI carrier (RV-15.60.4-1). Goldens `pb62_all_subscript_runtime_ranges` (every range and shape) and
> `pb62_standard_decimal_summing_family`; negatives `pb62-all-subscript-*`. **Registered:** PB81 — SUBSTITUTE with
> a table(ALL) argument is a bind-time COBOLNET0899 stage (the from/to pairing over a runtime count), where it used
> to throw at run time. The empty-range case is defined as EC-ARGUMENT-FUNCTION (CONFORMANCE.md).
