## Measured (adjudicator / refuter evidence, verbatim)
### [exception-conditions] nonfatal-handled-NOT-phrase: the I-O verbs' NOT INVALID KEY (and by the same shape NOT AT END) imperative is gated on IoStatusClass.Successful(status) alone, and __IoCheckEc's successful-completion arm returns -1 both when a WHEN phrase / USE declarative handled EC-I-O-WARNING and when nothing applied, so a raised-and-handled nonfatal condition on a successful I-O statement still runs the NOT phrase
- **Rows:** GR-14.6.13.1.4-2, GR-14.6.13.1.4-3 — harm `wrong-answer`
- **Repro:** out/probe/exc-nonfatal/g2.cob: '>>TURN EC-I-O-WARNING CHECKING ON'; INDEXED file, RECORD KEY K, ALTERNATE RECORD KEY AK WITH DUPLICATES, FILE STATUS FS; DECLARATIVES 'USE AFTER EC EC-I-O-WARNING' (DISPLAY "F3-DECL " FS); OPEN OUTPUT, write K=0001/AK=DUPE, then K=0002/AK=DUPE with 'WRITE R INVALID KEY DISPLAY "INV2" NOT INVALID KEY DISPLAY "NOTINV2 " FS END-WRITE', then DISPLAY "AFTER " FS. g3.cob: no declarative, the second WRITE inside 'PERFORM ... WHEN EC-I-O-WARNING DISPLAY "WHEN " FS END-PERFORM' followed by DISPLAY "IMP1-NEXT" in imp-1.
- **Expected (spec):** Status '02' raises EC-I-O-WARNING (§9.1.13.1). §14.6.13.1.4 3): the USE declarative runs and 'If a conditional phrase with a NOT phrase is specified in the interrupted statement, the imperative-statement in that phrase is not executed' -> g2: 'NOTINV1 00 / F3-DECL 02 / AFTER 02'. §14.6.13.1.4 2): the WHEN runs and the NOT phrase 'is also not executed' -> g3: 'NOTINV1 00 / WHEN 02 / IMP1-NEXT / AFTER 02'. (The standard's own successful-with-exception WRITE rule, §14.9.51.4 GR27 c)/d), likewise transfers to the end of the WRITE after the WHEN/USE.) With NO handler (g4) the NOT phrase correctly runs per 4).
- **Observed:** Observed g2: 'NOTINV1 00 / F3-DECL 02 / NOTINV2 02 / AFTER 02'; g3: 'NOTINV1 00 / WHEN 02 / NOTINV2 02 / IMP1-NEXT / AFTER 02'. SequentialIoEmitter.EmitInvalid (the one §9.1.14 renderer, shared by the keyed arm) renders 'if (Successful(st)) { NOT INVALID KEY }' and the READ success arms render NOT AT END unconditionally inside 'if (readCall)'; neither consults whether the EC hook selected a handler. The CALL arm of the same sentence was fixed separately (PB606: NOT ON EXCEPTION vs a propagated condition), so this is the I-O sibling of that fix. Sweep: every verb with a NOT phrase that can complete successfully while raising a nonfatal condition (READ/WRITE/REWRITE/START/DELETE with EC-I-O-WARNING; WRITE NOT END-OF-PAGE is already routed by PB854).
- **Code site:** src/Cobol.Net.Compiler/CodeGen/Verbs/SequentialIoEmitter.cs#EmitInvalid; src/Cobol.Net.Compiler/CodeGen/Verbs/SequentialIoEmitter.cs#EmitRead; src/Cobol.Net.Compiler/CodeGen/Verbs/KeyedIoEmitter.cs (NOT AT END / NOT INVALID KEY at :199-207); src/Cobol.Net.Compiler/CodeGen/EcEmitter.cs#EmitIoCheckEc (successful arm 'return __w == -3 ? -1 : __w')
