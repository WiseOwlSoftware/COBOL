The stash rule exists because a pop took another agent's entry. On current main the chain rule now blocks after a heredoc but stash, push-to-main and the filter rule still exit 0, the per-rule patching the missing model produces. The converse also holds: a '<<' inside quoted text (a C# shift or a 'python -c' string) makes everything after it a 'heredoc body', so the escape rule (:144) blocks a command that has no heredoc (this review's own probe was blocked that way). worktree_rm_allow.py:34,60 splits on a CHAIN regex that ignores quoting, a third rule for the same question.
