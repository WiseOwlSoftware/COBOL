# PB4445 — the SELF/SUPER drift test is per file, not per reader

**Defect.** `tests/WiseOwl.Cobol.Tests.Unit/UnreservedPredefinedObjectDriftTests.cs:62`
(`EveryFileThatReadsSelfOrSuper_GuardsTheEditionOrIsAListedRecognizer`) passes a file as soon as it holds ONE guard call,
however many `.SELF()` / `.SUPER()` / `selfAndSuper()` readers the file holds. A new unguarded reader added to an
already-guarded file draws no failure, so the test does not close the reader list as the DEVLOG says.

**Fix direction.** Decide per reader (per member that reads the keyword, via Roslyn or an ANTLR-aware scan), so the
next reader is automatic and a guard in one member no longer excuses another; keep the listed-recognizer exemptions per
member too.

**Sites:** `tests/WiseOwl.Cobol.Tests.Unit/UnreservedPredefinedObjectDriftTests.cs` (`UnreservedPredefinedObjectDriftTests.EveryFileThatReadsSelfOrSuper_GuardsTheEditionOrIsAListedRecognizer`).
