# PB5162 - at --std 85 FUNCTION ORD of a one-character numeric edited item is refused (COBOL1627): the Verified ORD row carries the 2023 category predicate with no edition arm, where 1989 asks for class alphanumeric, which holds the edited categories

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/IntrinsicArgumentRules.cs` (`Verified`, `PredicateViolation`)
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/IntrinsicBinder.cs` (`CheckArgumentClasses`)

**Mechanism.** §1989:A.2.31.3 AR1 asks that ORD's argument be one character long and of class alphabetic or alphanumeric, and in 1985 the alphanumeric class includes alphanumeric edited and numeric edited items (§1985:IV.4.3.3). The Verified ORD row of `IntrinsicArgumentRules` carries the CharacterCategory predicate of the 2023 rule (category alphabetic, alphanumeric or national) with no edition arm, and `CheckArgumentClasses` / `PredicateViolation` refuse a one-character numeric edited item at --std 85. kb/Work PB5122 is the same class-versus-category substitution in the class condition; the site and the fix here are the intrinsic catalog's.

Verdict, harm, evidence, repro and observed text are the records'; the rows' verdicts are recorded on another branch.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids of the list below.

In 1985 the class alphanumeric holds the edited categories (§1985:IV.4.3.3: "The alphanumeric class includes the categories of alphanumeric edited, numeric edited, and alphanumeric (without editing)."). The Verified ORD row carries the CharacterCategory predicate of §2023:15.70.3 AR1 ("category alphabetic, alphanumeric, or national") with no edition arm, so CheckArgumentClasses and PredicateViolation refuse a one-character numeric edited item at --std 85 as they do at 2023. The rest conforms at 85: the ExactWidth(1) predicate refuses a two-character literal (the witness), item, group and reference modification; Violation refuses a numeric item and literal; a one-character alphanumeric or alphabetic item, group, literal, figurative constant, reference modification and alphanumeric function are accepted; national operands cannot be written at 85 (COBOL0900).

**Observed (the record's).** exit 65: ORD2.cob(10,24): error COBOL1627: FUNCTION ORD argument-1 is of an EDITED category (numeric-edited), which the CATEGORY wording of ISO §2023:15.70.3 r1 does not admit. --permissive accepts it as a coercion extension

**Fix direction (root cause, CLAUDE.md rule 4).** Make the predicate on the row a function of the edition (class at 1985, category at 2023), read through the one catalog, so every intrinsic row that names a class in 1989 and a category in 2023 gets the same treatment from one place; a drift test lists the rows whose 1989 and 2023 argument wordings differ.
