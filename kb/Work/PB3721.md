# PB3721 — a site the reader cannot claim is dropped without a word

**Sites:** `scripts/spec/work.py` (`note_sites`, `sites_problems`).

Found 2026-10-25 ~10:20 PDT by the wave unit of wave 20261107 (session 5ee3740f).

## Repro

    python -c "import sys,pathlib; sys.path.insert(0,'scripts/spec'); import work; print(work.note_sites(pathlib.Path('kb/Work/PB3637.md').read_text(encoding='utf-8')).paths)"

prints `()`. PB3637's site block reads "every `scripts/**/*.py` that calls `sys.stdout.reconfigure` (71 files)";
`work._NOT_A_PATH` (`[<>*{}…]|\.\.\.`) discards the glob token, and nothing else in the block is a path. `work.py check`
accepts the note, because `sites_problems` asks only that a block EXISTS. PB3720's root gap drops a path the same way.

## Harm

`plan_wave.py --cluster PB1957 --from-budget` planned PB3637 as group G of wave 20261107, `UNPARTITIONED`: an empty set
meets nothing (DESIGN-orchestrator-loop.md section 9 item 1b), so the planner put it beside groups A, C, D, E and F, whose
primary files (`turns_by_group_size.py`, `plan_wave.py`, `land_lane.py`, `prune_worktrees.py`, `devlog.py`) are among the
71 it rewrites, and beside the in-flight dispatch w20261031g (`scripts/spec/work.py`). The wave unit released G
(`plan_wave.py --release 20261107g`) and launched the other seven by hand: a hand action is a loop defect (MANDATORY-PRACTICES
O11), and this is it. A note that sweeps many files is exactly the one the partition most needs to see.

## Fix direction

One rule in the one reader: a site block that names something must declare it, or `work.py check` refuses the note.
`sites_problems` reports every open note whose block is not `**Sites:** none (why)` and yields no path (the reader's
drops made visible, PB3720's case included). A glob in a block is expanded against the planned tree into the tracked files
it matches, each claimed whole (a sweep note then holds every group on those files, and runs in a wave of its own or
after them, which is what its scope means), or the reader refuses the glob and the note lists its files; the implementer
chooses one with its reason in the design doc (section 9 item 1b). Drift test: every open note's block either declares a
non-empty set or is `none (why)`.
