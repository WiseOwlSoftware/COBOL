# PB3527 — nothing verifies that a landed pull request entered the merge queue

## Owner question (2026-10-22 ~12:45 PDT, verbatim)

"Why did it get stuck? That is a process problem"

## What happened (facts as recorded)

- PR #385 (`worktree-wf_8c44feac-62f-11`, PB3512): auto-merge enabled 18:44:50Z.
- Run 39834070835 completed success 18:46:47Z.
- Job `ci-gate` (id 120018552758, ubuntu-26.04): status completed, conclusion success, started 18:46:44Z, completed
  18:46:46Z, three steps all success.
- The check-run for the head commit fb899d188e35 showed status `in_progress`, conclusion null, until the Mythos session ran
  `gh run rerun 39834070835` at about 19:35Z, which created check-run 120043423624.
- The merge queue (`gh api graphql mergeQueue(branch:"main") entries`) was empty the whole time. The PR state was BLOCKED.
- Three other PRs enqueued the same hour (#388, #389, #390) merged normally.

The landing ends at `=== ENQUEUE: ENQUEUED ===`. Nothing after that checks that the pull request actually entered the
merge queue, so a required check-run that never resolves holds the landing for as long as nobody looks (50 minutes here).

Code sites: `scripts/orchestrator/enqueue.py`, `scripts/orchestrator/land_lane.py`, `scripts/orchestrator/landing_measure.py`.
Related: PB3023 (the one landing script), PB3103, PB3379.

## Fix shape (for the implementer)

After `=== ENQUEUE: ENQUEUED ===` the landing lane watches the pull request:

1. Within N minutes of its PR-level run completing, the PR must be in the merge queue (or merged).
2. If not, read the head commit's check-runs. A required check-run still `in_progress` whose job is `completed` is a
   propagation fault: run `gh run rerun <run>` once, recorded by `landing_measure.py` as a bounce cause "stuck check-run".
3. A second occurrence on the same PR alerts the operator (mailbox) instead of looping.
4. `prune_worktrees.py --brief` shows the ENQUEUED-but-not-queued state as its own row.

## Golden / drift

A self-test with a stubbed `gh` covers the three states: queued, merged, stuck.
