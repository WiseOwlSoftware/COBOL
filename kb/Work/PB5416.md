# PB5416 - at --std 85 the VALUE OF clause's literal-1 bypasses the edition gate on literals: N"AB", NX"0041" and B"1" compile and run in an FD, though MOVE N"AB" at --std 85 is COBOL0900

**Sites:**

- `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolData.g4#valueOfEntry`
- `src/WiseOwl.Cobol.Compiler/Binding/FileControlBinder.ObsoleteFdClauses.cs#CaptureValueOf`
- `src/WiseOwl.Cobol.Compiler/Validation/VersionConformancePass.cs#VisitValueOfClause`

**Mechanism.** `valueOfEntry` takes any `literal`, and `CaptureValueOf` records it without asking the literal-class edition gate that every other literal position at --std 85 meets (national and boolean literals are COBOL-2002 additions, COBOL0900; a numeric literal of more than 18 digits is COBOL0802). The clause is screened only as a whole from 2002 (COBOL0902), so at 85 its literal escapes both screens.

**Found by.** The 1985 code read, read 3 (`kb/Work/PB4996/2026-11-12-read-3.md`): `E:/COBOL-coord/scratch/coderead-85/out-read3/rd-01-refute.json`.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. Its rows are not recorded: the refuter's OVERTURNED verdict is held for adjudication in `E:/COBOL-coord/scratch/coderead-85/held-8.json`.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-FMT-VII.3.9.2` - `§1985:VII.3.9.2` (refuter: OVERTURNED the read's CONFORMS, harm: under-rejects; the VALUE OF format; its literal-1 is a 1985 literal)

The 1985 literal: "Every literal belongs to one of two types: nonnumeric or numeric." (`§1985:IV.4.2.2.2`). The 19-digit case is weaker (18 digits is the minimum an implementor must allow), but it contradicts the compiler's own 85 limit.

**Repro.** In `E:/COBOL-coord/scratch/coderead-85/out-read3/refute-rd-01/`: `v11.cob` (`VALUE OF ID IS N"AB"`), `v12.cob` (`IS B"1"`), `v16.cob` (`IS NX"0041"`), `v15.cob` (a 19-digit numeric literal); control `c01.cob` (`MOVE N"AB"`). Run as `cobol.exe --std 85 --source-format fixed --run <file>` (each probe copied into its own directory by `reprobe-85i/probe.py`).

**Observed (the pinned compiler of `E:/COBOL-wt/coderead85-tree-c` (fafa91a83c, the head of witnesses-85g; `git diff --stat fafa91a83c origin/main -- src` is empty at 3c4f6fe652), rerun 2026-11-12; `E:/COBOL-coord/scratch/coderead-85/reprobe-85i/log.txt`).** `v11`, `v12`, `v16` and `v15` compile and run, each printing `FS=00`. The control `c01` is refused COBOL0900 (national literal requires COBOL-2002).

**Expected (from the 1985 text).** `v11`, `v12` and `v16` refused COBOL0900 as the same literals are in MOVE; `v15` refused as MOVE of it is (COBOL0802).

**Fix direction (root cause, CLAUDE.md rule 4).** Route the VALUE OF literal through the one literal-class edition gate (the screen a MOVE literal meets), not a clause-local check; sweep the other obsolete FD clauses that take a literal (LABEL RECORDS, DATA RECORDS operands, CODE-SET) for the same bypass.
