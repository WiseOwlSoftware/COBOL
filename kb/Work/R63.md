# R63 — the reach of "indirectly references" (§9.3.8.2.3)

§9.3.8.2.3: "If the description of the returning item of a method in interface-1 directly or indirectly references interface-2, the description of the returning item of the corresponding method in interface-2 shall not directly or indirectly reference interface-1." ISO gives no further text and GnuCOBOL 3.2 implements no OO.

**Owner (2026-09-30): only the transitive closure strictly follows the rule.** As recorded:
1. **Graph.** Nodes are interfaces and classes. There is an edge X -> Y when a returning item described in X is an object reference to Y; and (the orchestrator's stated reading, which the owner recorded as "edges as in point 1" — correct it here if it is wrong) an object reference to a class also reaches the interfaces that class IMPLEMENTS or INHERITS, so the note's ICIRC / CCIRC repro forms the cycle ICIRC -> CCIRC -> ICIRC.
2. **Scope.** The rule applies in a conformance check between two DISTINCT interfaces (interface-1 and interface-2). A self-reference (`Node.Next` returning `Node`) is exempt and stays legal; a golden for exactly that pattern guards against over-rejection.
3. **Cycle safety.** The closure walk carries a visited set.

**Work:** PB1498 — the reference-graph test in the caller of `OoConformance.MethodConformanceMismatches` (one diagnostic from the allocation), a negative from the ICIRC / CCIRC repro, a positive for the self-referencing returning type, and a golden where the cycle is reached indirectly through a third interface. Record the edge set as a determination in docs/CONFORMANCE.md.

## Re-verified against the ISO text (2026-09-30)

The spec text is explicit: §9.3.8.2.3 says "directly or indirectly references" (cite-checked). "Indirectly" has no special definition in the standard, so it carries its ordinary transitive meaning — the owner's own reading, recorded here. The remaining specifics (which relations are edges; the scope to two distinct interfaces so `Node.Next` stays legal) are implementation of that text, stated so the work is unambiguous; they are not discretionary.
