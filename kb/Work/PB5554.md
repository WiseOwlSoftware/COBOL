# PB5554 - at --std 85 a size error raised outside an arithmetic statement or a condition (a function argument in MOVE, a reference-modifier expression) ends the run unit; §1985:B.2.2 item 45 says the program continues

UNVERIFIED LEAD: re-probe before fixing.

**Mechanism.** PB5484 gave the 1985 no-phrase size error its "the program will continue" disposition in arithmetic statements
(`ArithmeticEmitter.EmitArith`); PB5501 gave it to the leaves of a condition (`ConditionRenderer.SizeErrorGuarded`, including a
function argument inside a condition). The 1985 rule, §1985:B.2.2 item 45 ("the program will continue"), has no home for any other
place an arithmetic expression is evaluated, so those still end the run unit:

1. A function argument in a non-arithmetic statement. Repro `E:\COBOL-coord\scratch\w20262038a\probe\f\m1.cob`: at `--std 85`,
   `MOVE FUNCTION INTEGER (B / Z) TO R` (Z = 0) exits 1 with EC-SIZE-ZERO-DIVIDE. GnuCOBOL 3.2 `-std=cobol85` prints `AFTER 0` and
   continues.
2. A reference modifier's arithmetic expression. Repro `probe\f\f2.cob`: `IF X (B / Z : 1) = "A"`. The position is hoisted to a
   temporary before the statement (`StatementBinder.SubscriptSegments`, `BoundPositionValue` in `PendingPreOps`), outside any guard,
   and `EmitPositionValue` keeps the termination by PB5484's choice. DOC-A.1-70 says a 1985 reference-modifier size error still
   terminates; that sentence needs a decision against item 45 (the item speaks of a size error condition generally). A reference
   modifier whose value is out of range is a separate fault, not this one.

The two have one root: the 1985 disposition lives per statement kind instead of at the one place an expression evaluation raises.
Prefer the shape that makes the next evaluation site automatic (rule 5), with a drift test over the sites.

**Sites:** `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/ArithmeticEmitter.cs` (`EmitArith`, `EmitPositionValue`),
`src/WiseOwl.Cobol.Compiler/Binding/Bound/StatementBinder.SubscriptSegments.cs` (`StatementBinder.SubscriptSegments`),
`src/WiseOwl.Cobol.Compiler/CodeGen/Emit/ConditionRenderer.cs` (`SizeErrorGuarded`, `ArithmeticReach`),
`docs/conformance/7/DOC-A.1-70.md` (whole: the reference-modifier sentence).
