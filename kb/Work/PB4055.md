# PB4055 — the landing lane read a field the survey's report does not have

## What happened

#760 (PB3608, the review lane beside the landing lane) merged at about 12:50 PDT on 2026-10-29, and the loop adopted it.
From 13:12 the supervisor logged this every five minutes:

```
land lane tick failed (exit 1; the unit continues):     "report": str(r.report.path) if r.report else None,
AttributeError: 'IndexedReport' object has no attribute 'path'
```

No branch WAITING TO LAND was launched. `worktree-wf_484eb705-564-5` (PB3811) and `-564-8` (PB3840) waited with
CLEAN reviews. PB3840 edits `docs/CONFORMANCE.md`, so the Mythos lane's A.1 chain (PB464, PB1092, PB1397, PB1369,
PB2556, PB1253) and its PB3738 could not plan past it. The owner noticed first: "mythos is waiting on you".

## The mechanism

`scripts/orchestrator/land_lane.py#survey_rows` maps each `prune_worktrees.Row` to the dict the tick and the review
lane read. #760 added `"lead": r.report.lead` and `"report": str(r.report.path)`, because `review_lane.py` stats and
reads the report file. But `Row.report` is a `reports.IndexedReport`, the branch survey's index entry. PB3728 moved
that class to `reports.py`, and it kept the report's file NAME (`name: str`), not its path. So every row that had a
report raised `AttributeError`.

No gate saw it. `land_lane.py --self-test` replaces the whole of `survey_rows` with a fake (`Fake.survey` returns
planted dicts), so the mapping never ran. `review_lane.py --self-test` plants dicts too. Only a live tick on a tree
with a reported branch ran the mapping, and that first happened in production.

## Fix

- `reports.IndexedReport` holds `path: pathlib.Path`. `name` is now a property derived from it, so the survey's
  evidence lines and every `rep.name` reader are unchanged. `report_index` passes `r.path`.
- `land_lane.row_dicts(rows, prs)` is the mapping, now a pure function. `survey_rows` does the I/O and calls it.
- `land_lane.py --self-test` arm 1b runs `row_dicts` on a planted `Row` with a real `IndexedReport`. A reported row
  carries its report's path and lead, and an unreported one carries None for both. Against main's `reports.py`, the
  arm raises the production `AttributeError`.
- `prune_worktrees.py --json` serializes the path with `default=str`. `dataclasses.asdict` now carries a `Path`.

## Sweep

- **Every read of a field of `Row.report`** under `scripts/` and `.claude/skills/`: `age_min`, `finished`, `head`,
  `lead`, `path`, `review`, `status`, `name`. Every one now exists on `IndexedReport`.
- **`prune_worktrees.py --self-test` and `review_lane.py --self-test`** are GREEN.
- **The sibling shape:** a self-test that fakes a function's I/O together with its pure mapping. `review_lane.py`
  plants rows the same way, but it is downstream of `row_dicts`, which arm 1b now pins.
