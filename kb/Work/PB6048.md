# PB6048 - suite 85 Stage 0: the 1985 row obligations (design §6.1 cut to 85) and the 647 1985 rows no test header names

Revision 4 of `docs/rearchitecture/DESIGN-conformance-suite.md` (§8 Stage 0, §13), decided in kb/Work PB6046.

Design §6.1's obligations for the 1985 catalog: GR, RV and AR rows an accepted test whose output shows the effect; SR
rows an accepted test of the legal form (a violation test at 85 is a diagnosis-layer test, design §8); FMT rows an accepted
test and every point (PB6050). 647 1985 rows are named by no test header although 2,936 rows' `test-ref` names a
conformance test: classify each mechanically as a header that omits a row its `test-ref` test witnesses (repair the
header, no agent) or a row with no 85 test (an authoring obligation, Stage 3). Output feeds PB6047's rows term.

**Sites:** conformance-suite/harness/obligations.py (classify, counts, repairs, add_rules, repair_headers); the headers of 178 tests of conformance-suite/cases/ (the `rules` line); docs/rearchitecture/DESIGN-conformance-suite.md (design sections 4.1, 6.1 and 13)

**Landed.** `harness/obligations.py` gives each row its section 6.1 obligation and its first witness kind (non-support,
suite, determination, derivation, accepted-uncleared, refusal-only, other-edition-only, header-omits, shared-test, no-test).
The 647 rows no header named divide, measured before the repair, as 302 header-omits (the `test-ref` test accepts 85 alone:
its header lacked the row), 224 shared-test (the `test-ref` test accepts another edition too; a 1985 row's band is 85 alone,
which the generator enforces, so the row needs an 85-only test: Stage 3 authoring, not a header repair) and 121 no-test.
`--repair-headers` wrote the 371 row names of the 302 rows into 178 headers (`generate.py --check` GREEN, 11,098 tests); no
program or expected output changed, and the accepted-uncleared count went from 1,974 to 2,276. Self-test: `selftests/obligations/test_obligations.py` (every witness kind, the header edit in fixed, free and CRLF form, the unknown-kind refusal). The rows term of
`suite_status.py` reads `counts(...)["unmet"]`.
