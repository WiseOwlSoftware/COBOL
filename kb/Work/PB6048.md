# PB6048 - suite 85 Stage 0: the 1985 row obligations (design §6.1 cut to 85) and the 647 1985 rows no test header names

Revision 4 of `docs/rearchitecture/DESIGN-conformance-suite.md` (§8 Stage 0, §13), decided in kb/Work PB6046.

Design §6.1's obligations for the 1985 catalog: GR, RV and AR rows an accepted test whose output shows the effect; SR
rows an accepted test of the legal form (a violation test at 85 is a diagnosis-layer test, design §8); FMT rows an accepted
test and every point (PB6050). 647 1985 rows are named by no test header although 2,936 rows' `test-ref` names a
conformance test: classify each mechanically as a header that omits a row its `test-ref` test witnesses (repair the
header, no agent) or a row with no 85 test (an authoring obligation, Stage 3). Output feeds PB6047's rows term.
