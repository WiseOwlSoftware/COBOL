# PB4393 - no fail-fast inside the test assemblies

**Read at:** origin/main f0e4650e5.

`tests/_shared/GateLegs.cs#GateAssemblyRunner` (declared at line 104, constructed at line 51) runs an assembly's whole selection. The ordered, fail-fast gate of PB1721 stopped at the first red leg; after PB4328 the gate runs the whole population and that leg structure is gone. A re-gate whose previous reds are still red therefore runs all of the roughly 11 minutes before it says RED, though the previous reds run first. A stop at the first `Failed` result of a first class would end such a re-gate in seconds.

**Source:** branch `worktree-wf_1338af20-657-4`, report `E:/COBOL-coord/scratch/reports/w20261805a-PB4348-report.md`, lead 5.

**Fix shape (the lead):** a bus-level stop in `GateAssemblyRunner` at the first failed case of a first class, with the remainder named in the verdict as the PB1721 gate named it. A drift test pins the stop (a planted failing first class; the remainder not executed). PB3200 (open) covers `GateLegs.cs`'s layout (13 types in one file); if that restructure lands first, put the stop in the type it creates. This note does not block it.
