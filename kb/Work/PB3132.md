# PB3132 — the §8.3.2.2 census sees declarations, not uses

Source: wave 1071 (unit `w1071b`, PB546 round 3, lead 2). PB546 is held by its branch and not edited. PB990 (LANDED, which first wrote the census) mentions the site but is landed: it cannot be extended, so this is a new note that names it.

**The rule.** `python scripts/spec/cite.py --check 8.3.2.2 "a given user-defined word may be used as only one type of user-defined word"` -> OK, §8.3.2.2: "Within a source element, a given user-defined word may be used as only one type of user-defined word with the following exceptions...". The standard says "used", and the exceptions are the table in `UserWordKinds.MayBeOneWord`.

**The gap.** `src/Cobol.Net.Compiler/Binding/DataBinder.cs:3422` `CheckOneTypePerWord(word, kind)` is asked only at the declaration funnel (`DeclareUserWord`, `:3360`); a word never declared twice is never asked. A method whose METHOD-ID spells its CLASS-ID and which also REFERENCES the class-name in its body (a class-name use, so one source element then uses the word as both method-name and class-name) is not refused. The report calls this "the same declaration-only limit as everywhere else".

**No repro was supplied (R2).** The implementer writes one: `CLASS-ID. X.` ... `METHOD-ID. X.` ... `INVOKE X "NEW"` in that method's body (a class-name reference), `--std 2002`, expecting COBOLNET for the word-type conflict (look up the code `DiagnosticCatalog.UserWordTypeConflict`) and observing compile success. PB2921's `__method_X` renaming is what lets the emitter survive the declaration case; the USE case is what this note is about.

**Whether it is a defect at all** is a spec judgment: §8.3.2.2 could be read as covering declaration (the defining occurrence fixes the type; a reference merely resolves to it). That reading is what the census implements. A refuter must decide before an implementer widens the census to reference sites; if it widens, the class-name reference resolvers are the sites (not located here), and a per-use check needs the same exception table.
