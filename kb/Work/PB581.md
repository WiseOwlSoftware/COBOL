# PB581 — OPEN — one row, three obligations, evidence for one

Found 2026-09-04 by the `PB206` implementer, which re-recorded `SR-13.18.63.3-4` with complete evidence after
implementing the two sentences its CONFORMS verdict had never covered. Re-derived on this tree for this note.

## The measurement

```
python scripts/spec/cite.py --check 13.18.63.3 "If the item is of category alphabetic, alphanumeric, or alphanumeric-edited literals in the VALUE clause shall be alphanumeric literals."
OK  §13.18.63.3 4)
python scripts/spec/cite.py --check 13.18.63.3 "Alphanumeric literals in the VALUE clause of an elementary item shall not exceed the size indicated by an explicit PICTURE clause."
OK  §13.18.63.3 4)
```

Both sentences are rule 4 of §13.18.63.3; the rule has a third ("… of an alphanumeric group item shall not
exceed the size of the group item"). The inventory row `SR-13.18.63.3-4` was closed CONFORMS on 2026-08-18 (PB94)
with notes describing the category screen only; `01 E1 PIC X(2) VALUE "ABCD".` then compiled clean and displayed
`AB` until PB206 (`COBOLNET1740`). A closed row is invisible to the burn-down, so the defect could only be found by
re-reading the rule against the code — which is how it was found.

## Why it is a class

The rule catalog mints one row per NUMBERED rule (`PB479` measures the complement — obligations with no number
get no row at all). A numbered rule whose text carries several "shall" sentences is therefore several obligations
under one verdict, and an adjudicator or implementer who satisfies the first closes the row. The same shape is one
of `kb/Work/PB468`'s pending owner questions from the other side ("the ~120 already-OK SR/AR rows with
positive-only evidence"): here the evidence is positive for a different sentence than the one that was open.

## What closes it

1. Measure: over `spec-rule-catalog.json`, every rule whose text contains more than one "shall" (or "shall not");
   for each such row that is CONFORMS, whether its `notes`/`test-ref` name evidence per sentence. Report the
   count — the honest number of rows whose closure is one-sentence evidence.
2. Mechanical guard in `record_verdicts.py` / `SpecTraceabilityInventoryDriftTests`: a CONFORMS verdict on a
   multi-"shall" rule must carry, in `notes`, one evidence pointer per sentence (a simple `s1:`/`s2:`/`s3:`
   convention keyed to the sentence ordinal), else the record is refused with the sentence count named. The
   failure branch is fired once on the PB94 record's original shape.
3. Re-adjudicate the rows the measurement flags (a lane-3 batch of its own, not a fix-lane item).
