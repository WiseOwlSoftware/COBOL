## Finding — `suppress-statement` (wrong-answer; rows `GR-14.9.45.4-1`, `GR-14.9.45.4-2`)

**Mechanism.** suppress-flag-keyed-by-report: SUPPRESS binds only the owning REPORT and sets a per-engine one-shot bool that the NEXT presentation of ANY group consumes (never cleared on hook entry), so a SUPPRESS executed outside its named group's own BEFORE REPORTING hook (a PERFORM of the declarative section, legal per §14.9.49.3 SR4) suppresses a different group or a later instance.

**Repro.** RD R1 with details DET-A, DET-B (no CONTROL/PAGE). DECLARATIVES. SUP-SECTION SECTION. USE BEFORE REPORTING DET-A. SUP-PARA. SUPPRESS PRINTING. END DECLARATIVES. MAIN: OPEN OUTPUT RPT; INITIATE R1; PERFORM SUP-SECTION; GENERATE DET-B; GENERATE DET-B; TERMINATE R1; CLOSE RPT; read the file back. Variants: stale2.cob (same group, later instance), cross.cob (DET-A's declarative PERFORMs DET-B's). Files in E:/Temp/claude/E--CobolSharp/a700c052-f9e4-4942-84ff-a13c7505d6ec/scratchpad/adj-d1/out/probe/suppress-statement/.

**Expected from the spec.** §14.9.45.4 GR1: SUPPRESS inhibits printing only for the group named in the USE procedure within which it appears (DET-A); GR2 limits it to the current instance of that group. DET-B is never inhibited -> two 'DET-B' lines. stale2: both DET-A instances print. cross: 'DET-A' prints, DET-B is suppressed.

**Observed / reasoning.** stale.cob -> one 'DET-B' line. stale2.cob -> one 'DET-A' line. cross.cob -> empty report file. BindSuppress resolves the group but BoundSuppress carries only the report; ReportWriter.SuppressPrinting sets _suppressCurrent; RunBeforeReporting(group) tests it after the selector for whatever group is presenting. Fix shape: carry the group identity in BoundSuppress / SuppressPrinting(groupIndex) and honour it only for that group while its own hook runs (clear on hook entry), otherwise no effect.

**Code site.** src/Cobol.Net.Compiler/Binding/Procedure/Verbs/ReportWriterBinder.cs#BindSuppress; src/Cobol.Net.Compiler/CodeGen/Verbs/ReportWriterEmitter.cs#EmitSuppress; src/Cobol.Net.Runtime/IO/ReportWriter.cs#SuppressPrinting; src/Cobol.Net.Runtime/IO/ReportWriter.cs#RunBeforeReporting

## What the fixer owes

Carry the group identity in BoundSuppress (ReportWriterBinder.BindSuppress already resolves it) → SuppressPrinting(groupIndex), honoured only for that group while its own hook runs (clear on hook entry in RunBeforeReporting), otherwise no effect. Goldens stale.cob (two DET-B lines), stale2.cob (both DET-A instances), cross.cob (DET-A prints, DET-B suppressed).
