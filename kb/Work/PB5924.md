# PB5924 - analysis: unnumbered normative text is outside the rule catalog

**Sites:** none (an analysis; the catalog generator it may change is named when step 2 is decided)

Found while adjudicating the listing (PB5923): the 1985 rule catalog makes rows only from numbered rules (SR, GR,
formats and the like). Normative prose that carries no rule number makes no row. §1985:IV.7 (reference format) is
written that way, so its requirements, among them "each compiler ... produces an output listing" (§1985:IV.7.1), the
slant page eject (§1985:IV.7.2.4) and IV.7.4, are in no row, and "1985 2275 rules 0 GAP" was computed without them.

To do:
1. Measure the hole: list every 1985 clause whose body holds normative text ("must", "shall", "is required",
   "each compiler", "the implementation") and no numbered rule that the catalog turned into a row. Do the same for
   2002, 2014 and 2023 (the 2023 catalog may share the hole).
2. Decide how the catalog takes such text (a paragraph-level row kind, derived by the catalog generator so the next
   edition is automatic, with a drift test), then regenerate the inventories and adjudicate the new rows.
3. Report each edition's GAP before and after. Until this is done no edition's GAP count is complete; 1985's is
   known to miss at least the three IV.7 rows of PB5923.
