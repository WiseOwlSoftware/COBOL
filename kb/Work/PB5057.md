# PB5057 — a test's program child outlives its test host

Filed 2026-11-09 by the operator session, from a Mythos mailbox report (16:09).

**Symptom.** The Mythos session found dotnet PID 477032 running
`E:/COBOL/.claude/worktrees/wf_b9ab56e7-a8d-1/tests/nist/programs/DB205A.dll`. It had been running since 10:47 PST,
its parent process was gone, and its worktree had been deleted (only a leftover directory remained). It was
busy-looping about one core. Mythos killed it at 16:08. Nothing else would have stopped it.

**Mechanism.** The only kill of a program child is the budget kill in `ProcessObserver.Observe`
(`tests/_shared/ProcessObservation.cs:180`): `proc.WaitForExit(budget.Ms)`, then `proc.Kill(entireProcessTree: true)`.
`LiveProcess` (`tests/_shared/LiveProcess.cs:96`) kills only from its own `Dispose`. Both run in the test host. When the
host dies first (a gate stopped or killed, a worktree's run torn down, the testhost crashing), the child is not in any
job that ends with the host, so it is orphaned. Its own hang guard died with its parent.

**Sites:** `tests/_shared/ProcessObservation.cs:156` (`ProcessObserver.Observe`, the `Process.Start` with no job),
`tests/_shared/LiveProcess.cs:96` (`LiveProcess.Dispose`).

**Fix shape.** Tie every program child to its host's lifetime at start: on Windows assign it to a job object created
with `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`, held by the host, so the OS kills it when the host's last handle closes; on
Linux set `PR_SET_PDEATHSIG` (or run it in the host's process group and have the gate kill the group). Put it in ONE
starter that both `ProcessObserver` and `LiveProcess` use. Add a drift test that kills a host which started a sleeping
child and asserts that the child is gone.

**Second question, unprobed.** DB205A looping for 5 h may also be a hang of the program itself at that worktree's head
(the 1985 debug module on a cd-name, PB4713 and PB4759 landed). A budget kill would have hidden it as a timeout. Probe
DB205A at main under the NIST leg and record whether it completes in its budget.
