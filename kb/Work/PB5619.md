# PB5619 - at --std 2002 SET pointer UP/DOWN BY lands its amount at scale 6 in an Int128 carrier: a sub-1E-6 fraction raises no EC-SIZE-ADDRESS and 10**40 ends the run with EC-SIZE-OVERFLOW instead of EC-RANGE-PTR

**Sites:**
- `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/SetEmitter.cs#LandAmount` (caller PtrEmitter, SET pointer UP/DOWN BY)
- Landed fix: `src/WiseOwl.Cobol.Compiler/CodeGen/Emit/NumericRenderer.cs#LandedAmount`; `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/PtrEmitter.cs#EmitSetPointerUpDown`; `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/KeyedIoEmitter.cs#StartLength`; `src/WiseOwl.Cobol.Compiler/CodeGen/Roslyn/RuntimeApi.cs#IndexTryAmountDec`, `#PtrUpByAmountDec`, `#StartKeyLengthDec`; `src/WiseOwl.Cobol.Runtime/Values/SetAmount.cs#Land` (CobolDec overload); `src/WiseOwl.Cobol.Runtime/Values/Tables/CobolIndex.cs#TryAmountDec`; `src/WiseOwl.Cobol.Runtime/Control/CobolPtr.cs#UpByAmountDec`; `src/WiseOwl.Cobol.Runtime/IO/StartKeyLength.cs#OfDec`.

**Mechanism.** SetEmitter.LandAmount (used by PtrEmitter) converts arithmetic-expression-3 to a fixed scale-6 Int128 before the integrality and range tests, so under ARITHMETIC IS STANDARD the 32-digit standard intermediate's fraction is truncated away and a large integral amount overflows the carrier; the message cites the 2023 implementor-defined range (§2023:14.7.5 case 5, A.1 item 179), a licence 2002 standard arithmetic lacks. Not PB5575 (that is the digit count of the standard intermediate); this is the SET amount carrier.

**Inventory.** Rows claimed: `2002-GR-14.8.35.3-16`, `2002-GR-14.8.35.3-17`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:14.8.35.3 GR16`: "If arithmetic-expression-3 does not evaluate to an integer, the EC-SIZE-ADDRESS exception"
- `§2002:14.8.35.3 GR17`: "the EC-RANGE-PTR exception condition is set to exist and the value of the data item refere"
- `§2002:8.8.1.3.5`: "The result shall be the exact quotient truncated to 32 significant digits"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p2/set-ptr-lit20-std.cob, p2/set-ptr-range-std.cob); the text is inline. Command: `cobol.exe p2/set-ptr-lit20-std.cob --std 2002 --run`

`p2/set-ptr-lit20-std.cob`:

```cobol
       >>TURN EC-SIZE-ADDRESS CHECKING ON
       IDENTIFICATION DIVISION.
       PROGRAM-ID. PTRSL.
       OPTIONS.
           ARITHMETIC IS STANDARD.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 BUF.
          05 B1 PIC X VALUE "A".
          05 B2 PIC X VALUE "B".
          05 B3 PIC X VALUE "C".
       01 P USAGE POINTER.
       01 Q USAGE POINTER.
       01 ONE PIC 9 VALUE 1.
       PROCEDURE DIVISION.
       DECLARATIVES.
       H SECTION.
           USE AFTER EXCEPTION CONDITION EC-SIZE-ADDRESS.
       H-P.
           DISPLAY "HANDLED=" FUNCTION EXCEPTION-STATUS.
           RESUME AT NEXT STATEMENT.
       END DECLARATIVES.
       MAIN SECTION.
       MAIN-P.
           SET P TO ADDRESS OF B1.
           SET Q TO ADDRESS OF B2.
           SET P UP BY ONE + ONE / 100000000000000000000.
           IF P = Q DISPLAY "MOVED-1" ELSE DISPLAY "NOT-MOVED" END-IF.
           STOP RUN.
```

**Observed.** set-ptr-lit20-std (SET P UP BY ONE + ONE / 100000000000000000000): prints MOVED-1, rc=0, no condition. set-ptr-range-std (SET P UP BY 10 ** 40): 'abnormal run-unit termination: EC-SIZE-OVERFLOW (fatal): an intermediate value exceeds the native Int128 carrier at this scale (ISO §2023:14.7.5 case 5 ...)', rc=1.

**Expected (from the 2002 text).** first: EC-SIZE-ADDRESS handled, pointer unchanged (NOT-MOVED); second: EC-RANGE-PTR handled, pointer unchanged.

**Sibling sweep.** every LandAmount caller (SET index UP/DOWN BY, SET index TO, PERFORM VARYING index FROM/BY, the keyed I-O lanes named in KeyedIoEmitter) under ARITHMETIC IS STANDARD.

**Other editions.** 2014: likely (STANDARD arithmetic exists there; unknown until probed). 2023: no STANDARD mode; the fraction case is implementor-defined native arithmetic. 85: n/a.
