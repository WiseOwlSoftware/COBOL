# PB5710 - at --std 2002 (and 2014) EXTERNAL and TYPEDEF in one data description entry are accepted, though 2002 and 2014 forbid EXTERNAL with REDEFINES, TYPEDEF or BASED

**Sites:**
- src/WiseOwl.Cobol.Compiler/Binding/DataBinder.ClausePlacement.cs#ClausePlacementRules (Rules row §2023:13.16.3 SR5)
- src/WiseOwl.Cobol.Compiler/Validation/VersionConformancePass.cs#VisitExternalClause

**Mechanism.** ClausePlacementRules.Rules carries one §2023:13.16.3 SR5 row whose excluded set is Redefines | Based, with no 2002/2014 arm adding Typedef. VersionConformancePass.VisitExternalClause gates only the STRONG TYPEDEF combination, and its comment says a weak TYPEDEF IS EXTERNAL was valid in COBOL-2002, which the 2002 text contradicts.

**Inventory.** Rows claimed: `2002-SR-13.14.2-5`, `2002-SR-13.16.20.2-1`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`).**

- `§2002:13.14.2 SR5`: "The EXTERNAL clause shall not be specified in the same data description entry as the REDEFINES, TYPEDEF, or BASED clause" (`cite.py --check`: OK  §2002:13.14.2 SR5  (Syntax rules)  the text is in SR5)
