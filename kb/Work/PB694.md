# PB694 — OPEN — the two sub-rules PB345 could not honestly claim

Found 2026-09-05 by the `PB345` implementer (report §"New defects" 2), which implemented §13.4.5.3 SR3 a) (the
RECORD clause must establish a maximum) and deliberately left `SR-13.4.5.3-3` GAP because b) and c) are not
screened and CONFORMS would have been false.

## The rule

§13.4.5.3 SR3: "When no record description entries are specified: … b) a FILE phrase specifying file-name-1 and the
FROM phrase shall be specified on all WRITE and REWRITE statements associated with the file, and c) an INTO phrase
shall be specified on all READ statements associated with the file" (`cite.py --check 13.4.5.3 "an INTO phrase
shall be specified on all READ statements associated with the file"` → OK 3) c)). §14.9.30.4 GR6 defines the
as-though record only for the INTO form, so the phrase-less READ has no meaning the standard gives it.

**Repro:** `READ FIN AT END … END-READ` (no INTO) on `tests/conformance/2023/pb345_record_less_fd_area.cob`'s `FIN`
compiles clean and reads into an area the program cannot name.

## What has to be settled

- c) is a plain statement-level screen: beside the other phrase rules in `StatementValidation`, keyed on the file's
  records holding only the implied one (a flag on `FileModel`, or `Records[0].CobolName is null`) — dispatchable on
  its own.
- b) requires the `WRITE FILE … FROM` / `REWRITE FILE … FROM` form (§14.9.51.2 Format 2 / §14.9.35.2), which
  `tests/conformance/negative/a413-write-file-format-1.cob` pins as DECLINED (Annex A.4.13's optional element, PB282's
  family). Declining the form while accepting the record-less FD leaves a legal file that can be read and never
  written. Either the decline is documented as the reason a record-less WRITE is rejected (a `documented
  non-support` row with the A.4.13 posture, and a diagnostic that says so rather than silence), or A.4.13's element
  is implemented — an owner posture question the process review's Report-Writer question already resembles. Settle
  which before dispatching b).
