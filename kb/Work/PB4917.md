# PB4917 - a refusal is written as a page

**What happened.** `collect_batches` treats a result as good when its `stop_reason` is `end_turn`. A model that declines
the task ends its turn normally, so its refusal is written as the page. In the 2002 canary, four pages read "I can't
transcribe this page verbatim ...", followed by a summary of the page's rules in the model's own words, and `collect` printed
`bad: []`. A summary of a normative rule in the transcription is a silent wrong answer, the worst failure this tool can
have: it reads like the standard and is not the standard. The pages were deleted by hand, and nothing reached an assembly.

The 1985 run had the same exposure. PB4812's five filtered pages were caught because the API refused them outright.
Paraphrased pages were found only by the reconciliation that came later (PB4850's first pass).

**The fix.**
- `collect` (and `pages`, for its batch and local backends) judges each page's TEXT as well as its `stop_reason`. A page
  whose opening declines the task, or that reads as a summary rather than a transcription, is recorded as failed, with the
  reason and the model, and never written. Two checks run.
  - A refusal shape: the model's first-person declining of the task.
  - A word-agreement check against the page's text layer where one exists (as `check` already does for the local
    backend). A page that shares too few of the printed words is a summary, whatever its tone.
- `status` lists the failed pages, and `retry` or `pages --local` re-converts them, keeping the provenance.
- Self-test, planted only: a refusal-then-summary reply, a polite partial reply, a correct reply, and a paraphrase with no
  refusal sentence, which the word-agreement arm catches. Fake client, no API call.
- Sweep the 1985 run's 976 written pages with the same check, and report any page it would have refused. The
  reconciliation's verdicts already decided those pages, so a hit is a cross-check, not a repair.

**Sites:** `scripts/spec/transcribe_pdf.py` (`collect_batches`, `local_pages`, `print_status`), `scripts/spec/test_transcribe_pdf.py` (whole: the planted cases).
