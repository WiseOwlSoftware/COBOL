# PB4590 - MnemonicSuffixMessage quotes `word.GetText()` for ACCEPT ... FROM and DISPLAY ... UPON

**Mechanism.** PB4573 made the parser's syntax-error sentences quote the word the source wrote (`WrittenSource.Of(token)`), because the lexer's retype of a synonym overwrites `Text` with the
original's. Its sibling sweep missed one arm: in `MnemonicSuffixMessage` the SET arm now quotes `WrittenSource.Of(suffixed)`, but the ACCEPT ... FROM / DISPLAY ... UPON arm
(`return MnemonicNameSlot.SuffixMessage(slot!, word.GetText(), format!)`, about line 2805) quotes `word.GetText()`, which concatenates the retyped token `Text`. A mnemonic-name that is a synonym of a
word the lexer has a token for is then named by its original in the message.

**Fix shape.** Quote the written extent of the word in this arm, sweep the file for any other `GetText()` that reaches a message, and pin it with a unit witness in
`tests/WiseOwl.Cobol.Tests.Unit/CobolWordsDirectiveTests.cs` beside `ASyntaxErrorNamesTheSynonymTheSourceWrote_NotItsOriginal`.

**Site:** `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs#MnemonicSuffixMessage`.
