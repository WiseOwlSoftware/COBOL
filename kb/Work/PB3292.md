# PB3292 — source-text lexical predicates written outside their one owner

- `src/WiseOwl.Cobol.Frontend/Preprocessor/TextWord.cs` `DirectiveLineEnd` (about :289): `text[pos + 1] != '>'`.
- `src/WiseOwl.Cobol.Frontend/Preprocessor/ReferenceFormatProcessor.LogicalLineBuilder.cs` (about :492, in ScanProgramText): `text[i] == '>' && ... text[i + 1] == '>'` (the report called the file `LogicalLineBuilder.cs`).
- Candidate shape (the report's): one `CompilerDirectiveLine.IndicatorAt(span, pos)`, with a drift test of the PB2621 kind so the next spelling is caught.
