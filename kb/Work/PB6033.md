# PB6033 - the reference format of a test's own program text

**The owner's decision R57 (2026-09-30)** gave the conformance harness the CLI's default, fixed form, and had the goldens
that need free form say so, "so the fixed-form tests test fixed form". By 2026-11-21 the goldens are the conformance
suite, and that half is done in fact: the generator refuses a case with no `source-format` header
(`conformance-suite/harness/generate.py`, "no source-format: every test states it"), refuses free form at an edition
before 2002 outside `wiseowl/` (`format_defined_at`, `FIRST_FREE_FORM = "2002"`; kb/Work PB5754 converted the 1985 cases to
fixed form), and `ConformanceSuiteRunner.Options` compiles each case in the format its header states. No golden path
used `auto`.

**What was left** was every harness that compiles program text a C# test writes inline (`EditionHarness`,
`WiseOwlCobolCompiler`, `WiseOwlCobolTestBase`, the version-matrix rows, about 140 files and 178 sites, all passing
`InitialReferenceFormat.Auto`). Measured on 26e6da8f73 (Debug, every test of Unit, Characterization and the Conformance
project less the suite theories): with every one of those sites FIXED, 819 of 42,693 Unit tests and 5,686 of 9,334
Conformance tests fail, because that text is written from column 1 with no sequence or indicator area; with every site
FREE, 17 Unit and 73 Conformance tests fail, and each of those is a test of a fixed-form rule (an indicator in column 7, a
debugging line, a continuation line, margin R, the NIST storage-form pass) whose text is fixed form. The characterization
corpus is fixed form and passes both ways.

**Decided.** R57's purpose is that no test lets a heuristic decide which reference format it exercises. A test's own
text is free form, so it is read as free form, STATED: `tests/_shared/TestSourceFormat.Inline` (= `Free`, the documented
selection available at every edition, `--source-format free`, docs/conformance/7/DOC-A.1-158.md). A test of a fixed-form
rule, a NIST program and the characterization corpus state `Fixed` (the CLI's default, `§2023:7.3.24.3 GR2`); a
version-matrix row states `sourceFormat: "fixed"` where its program is fixed form (eight rows), and the loader refuses any
other value than fixed or free. `auto` is compiled only by the tests of the detector and its option, and
`TestSourceFormatDriftTests` (RepoDrift) refuses it anywhere else under `tests/`.

**Rejected.** Rewriting into fixed form the inline text of the 6,505 tests that failed when read fixed so that the harness default could be literally
the CLI's: it changes what no test asserts, costs a re-layout of every inline program, and buys nothing R57 asked for (the
tests of fixed-form rules now read fixed form, stated). Keeping `auto`: the detector read conforming fixed-form text with a
blank sequence area and text past margin R as free form, so a test could not know its format.
