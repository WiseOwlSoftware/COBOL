# PB6147 - at --std 85 the float-edited count message and its count disagree, and COBOL0900 is displaced

Filed from the round-1 lead on the PB6121 branch.

**Mechanism.** `src/WiseOwl.Cobol.Compiler/Binding/PictureAnalyzer.cs:1459`: the PB6121 message fix picks its text by edition
(`edition.Edition.Cite`; the `y1985` arm is the 2002 sum text), while the count it prints is picked by `wideBounds`, which line 1404 forces true below 2002
because the construct is unavailable there. At `--std 85` the two disagree, so the very defect PB6121 names (a reported total that is not the sum of its
parts) survives at 1985, now with an explicit `+`. The bound error also displaces the construct gate COBOL0900 that the comment at line 1403 says it
must not hide, so the user is told about a digit count instead of that floating insertion edited pictures of this form are not available at 1985.

**Fix shape.** Decide the 1985 behaviour once (the construct gate COBOL0900 reports first and the count check is not reached), pick text and count from
the same condition, and add a `--std 85` case beside the PB6121 goldens. Which exact rule applies at 1985 is for the implementer to derive from the 1985
text.

**Landed (wave 20262166 A).** Re-probe (`--std 85`, `01 B PIC +9(40)E+99.`): COBOL1658 "counts 40 digit position(s) (significand 40 + exponent 2) — the limit is 1 to 36
(§2002:13.16.38.2 SR6)" and no COBOL0900 for B (the construct gate fires from `PicInfo.IsFloatEdited`, which the bound error's `Recovery` result lacks).
Root: `AnalyzeFloatEdited` forced `wideBounds` true when the construct is unavailable, which chose the count (the 2014 significand alone, limit 36) while the text
came from the edition (the 2002 sum text). `wideBounds` is now the register row alone (`DialectBehavior.FloatEditedPictureWideBounds`), and a separate
`constructGated` flag (`ConstructRegistry.IsAvailable(.., PicExternalFloat2002)`) skips the two BOUND checks below COBOL-2002, where the form has no bound (the form itself is the
COBOL0900 gate); the shape checks of the exponent and the significand keep reporting. Text, count and limit are one decision. Golden:
`g1985-pic-float-edited-bound-yields-to-construct-gate` (refused at 85 with the gate text); the 2002 goldens beside it pin the bounds.
