**Expected from the spec.** A compile-time error naming the general format: §8.4.3.3.2 writes identifier-1( leftmost-position : [ length ] ) with leftmost-position REQUIRED (only length is bracketed); the empty-parentheses twin X() already gets COBOLNET2309 citing §8.4.3.3.2.

**Observed / reasoning.** The source is rejected (no under-reject), but the user is told it is a compiler bug; the refusal is 'silent' in PB1029's sense - the rule it breaks is never reported. X(1:2:3) -> COBOLNET2363 and X() -> COBOLNET2309 show the intended per-shape diagnostics exist for the neighbours.

**Code site.** src/Cobol.Net.Compiler/Binding/ReferenceResolver.cs (the depth-0 SUB_COLON ref-mod arm, ~:1897-1900: `if (RenderSegment(tokens.GetRange(0, colonIdx), SegmentPosition.RefMod) is not { } start) return (null, true);`)
