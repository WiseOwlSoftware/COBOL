# PB2023 — OPEN: COBOLNET0827 names seven rules and has no catalog descriptor

Found by the wave-1019 group A implementer (kb/Work PB1425, Format 5 object-view), filed by the train-1019 lander.

## What is wrong

`COBOLNET0827` is a raw string code, written at seven sites, with no `DiagnosticCatalog` descriptor, so
`docs/DIAGNOSTICS.md` says nothing about it and one code carries several unrelated meanings:

- §8.4.3.8.3 SR1, SELF or SUPER written outside a method definition (`cite.py --check 8.4.3.8.3 "may be specified
  only in a method definition"` OK): `OoBinder.cs#RefusePredefinedObjectOutsideMethod` (INVOKE receiver and the
  object-view's identifier-1 share it since PB1425).
- SUPER in a class that has no INHERITS clause: `OoBinder.cs#OoBindByReceiver` (the SUPER search root, ~:324).
- EXIT METHOD placement: `OoBinder.cs#OoBindExitMethod` (~:1792).
- EXIT FUNCTION / PROGRAM / PERFORM / SECTION placement: `ControlFlowBinder.cs:325`, `:350`, `:371`;
  `UdfBinder.cs:460`.

Related, same root: the same SR1 is spelled with its own code by RAISE (`COBOLNET0848`, `EcBinder.cs`) and by SET
(`COBOLNET0867`, `SetBinder.cs`), so "SELF outside a method" draws three different codes by statement.

## Harm

Process only: no program is accepted or rejected wrongly. The user and the diagnostics reference cannot tell the
rules apart, and `cobolnet-raw-diagnostic-code-literal` (semgrep, 273) counts each site.

## Fix shape

One descriptor per RULE (about six new codes from the orchestrator's allocation): SR1 once, used by INVOKE, the
object-view, RAISE and SET alike (retiring the per-statement 0848/0867 spellings of it, or re-pointing them), one for
SUPER without INHERITS, and one per EXIT placement rule (cite each with `cite.py --check` from §14.9.14.3 before
writing it). Regenerate `docs/DIAGNOSTICS.md` (`scripts/gen-diagnostics-doc.ps1`); update the negatives whose `.err`
names 0827.

Repro: any `INVOKE SELF "M"` in a PROCEDURE DIVISION of a program (not a method) draws COBOLNET0827; so does
`EXIT PERFORM` outside an inline PERFORM.
