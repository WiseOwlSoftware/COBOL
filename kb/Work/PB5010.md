# PB5010 - a CLDR loader test reads the borrowed COBOL_CLDR_DIR

**Found.** In the WSL run of HEAD 26cdbeabbf, `CldrLocaleLoaderTests.Pack_Loads_AndEveryFileParses` failed with
`DirectoryNotFoundException` on `/tmp/.../wiseowl-cobol-pb2773-...`. That directory is
`LocaleCollationFailureTests.SiteDirectory`'s scratch directory. `LocaleCollationFailureTests` is in
`[Collection("process-globals")]` and sets `COBOL_CLDR_DIR` process-wide for the length of each test;
`CldrLocaleLoaderTests` is not in the collection, so xUnit runs it concurrently and it resolves the pack through the
variable the other class holds, as the other class deletes the directory. A flake is a kb/Work defect fixed at its root,
never retried.

**Owed.** Put `CldrLocaleLoaderTests` in `process-globals` (as the sibling Collation classes are, PB126), and sweep every
test class that resolves a locale through `CldrLocaleLoader` or `LocaleManager` outside that collection for the same
exposure; a drift test over the Collation tests pins that each class touching those loaders names the collection.

**Sites:** `tests/WiseOwl.Cobol.Tests.Unit/Collation/CldrLocaleLoaderTests.cs` (`CldrLocaleLoaderTests`), `tests/WiseOwl.Cobol.Tests.Unit/Collation/LocaleCollationFailureTests.cs` (`LocaleCollationFailureTests`)
