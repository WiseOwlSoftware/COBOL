# PB6163 — OPEN — SR-12.3.7.3-20's 2002 band

SR-12.3.7.3-20 is banded 2002,2014,2023. Its second sentence, "any equivalence between that character and any other character in
the computer's compile-time coded character set is defined by the implementor", is first stated by §2014:12.3.6.2 SR20; a search of
the 2002 text finds no clause carrying it (PB6130's adjudication and refuter). Decide whether the row's band, or the part of the
rule it witnesses at 2002, is right, each edition on its own text.
