# PB2468 — OPEN

Filed 2026-10-07 by the train-1034 lander from the wave-1033 group D implementer report (`w1033d-PB1457-report.md`,
new lead 1). Not fixed by D: a different binder and rule family from PB1457's data-name-n screen.

**Shape.** A condition-name reference written with a reference modifier is accepted and the modifier is ignored:

* `IF CN(1:2) DISPLAY "X" END-IF` with `01 TK PIC X(3). 88 CN VALUE "ABC".` compiles clean
  (repro `E:\COBOL-coord\scratch\w1033d\c3.cob`);
* SEARCH ALL Format 2 `WHEN CN(IX)(1:2)` with `88 CN` under the ASCENDING KEY item compiles clean
  (repro `E:\COBOL-coord\scratch\w1033d\c1.cob`).

**Rule.** §8.4.4.2 (condition-name, general format) prints only `condition-name-1` and its qualified /
subscripted form (`cite.py --check 8.4.4.2 "condition-name-1"` OK); §8.8.4.5.2 (condition-name condition) prints
`condition-name-1` (`--check 8.8.4.5.2 "condition-name-1"` OK). Neither prints a reference-modifier, and §8.4.3.3.3
SR5 allows reference modification only "anywhere an identifier referencing a data item of class alphanumeric,
boolean, or national is permitted" (`--check 8.4.3.3.3` OK) — a condition-name is not such an identifier. The
source is therefore not conforming and a conforming implementation must diagnose it (§4.2.1); today it is a
silent under-reject whose written (1:2) has no effect on the test.

**Code site.** `src/Cobol.Net.Compiler/Binding/Procedure/Verbs/ConditionBinder.cs#ConditionOf` (line ~1447) reads
the word and the qualifiers (`QualifiersOf`, line ~1516, which keeps only `qualification()` suffixes) and never
asks whether the reference carries a reference-modifier suffix. The one lexical reader of suffixes is
`ReferenceResolver.ReadOperandSuffixes(dref).RefMods` (PB1457 uses it in `DataBinder.ScreenReferenceModifier`).

**Fix shape.** In `ConditionOf`, once the reference has resolved to a level-88, refuse a reference-modified suffix
once per reference (the `_condDiagnosed` discipline) with a §8.4.4.2 / §8.8.4.5.2 citation; every condition-name
position (IF / EVALUATE / PERFORM UNTIL / SEARCH WHEN / SET Format 4 condition-name-1) asks ConditionOf, so one
screen covers them. Add a negative golden per position family (reject-at 85 2002 2014 2023) and sweep SET TO TRUE
/ FALSE.
