# PB4034 — `UnnamedCommands` does not follow a script into the tools it starts

**Sites:** `tests/WiseOwl.Cobol.Tests.Unit/ToolchainManifestDriftTests.cs` (`UnnamedCommands`).

**What.** The audit reads each workflow step's command and refuses one that names a tool the manifest lacks. A step that runs
a repository script (`python scripts/x.py`) is judged by the script name only; the tools the script starts (`gh`, `jq`, `xz`,
...) are not read. Today that is covered by luck: every job installs the whole set. A tool added only to a script, or a job
that installs a subset, goes unflagged.

**Fix shape.** Resolve a step's script one level (the interpreter plus a tracked script path) and audit the commands it
starts with the same list; or have the manifest name the tools each script needs. Independent of PB4035.
