# PB900 — OPEN — the audit that can say the wrong thing, and the quotation no audit reads

bullet, which the lander explicitly marked *(Registrar lead.)*; plus the train-35 lander report, "Findings

## Arm A — the ordinal arm's attribution is LINE-scoped

Train 36 found the same shape for FORMAT NAMES: PB388's new check tested whether the WHOLE LINE spelled any
format name of the cited clause, so on
`tests/conformance/negative/pb489-linage-operand-is-linage-counter.cob:6` — a CORRECT line naming
`qualified-linage-counter` under BOTH §8.4.2.2.2 Format 7 and §8.4.3.1 Format 10 — the second citation's name
was attributed to the first. It was fixed structurally: `_names_format` became `_name_hits` (positions) and
`_owning_cite` gives a name to the citation it stands NEXT TO.

**The rule-ordinal arm did not get `_owning_cite`.** Train 37 measured the consequence: PB408's new comment
took the non-gating arm from 203 to 204, and the finding was FALSE — the audit read a mid-line
back-reference "GR1 b)" against the LATER clause printed on the same line. The sentence was re-spelled to
work around it and the count returned to 203. **The workaround is in the comment; the defect is in the
audit.**

## Arm B — the complementary hole, live in shipped code

```
$ python scripts/spec/cite.py --check 14.9.14.4 "the most closely preceding, unterminated inline PERFORM"
  FAIL: §14.9.14.4 exists but does NOT contain 'the most closely preceding, unterminated inline PERFORM'
$ python scripts/spec/cite.py --check 14.9.14.4 "the most closely preceding, and as yet unterminated, inline PERFORM"
  OK  §14.9.14.4 5) a)  (General rules)
```

Two shipped sites carry the elided form:

```
src/Cobol.Net.Compiler/CodeGen/EmitterState.cs:29
src/Cobol.Net.Compiler/CodeGen/Verbs/ControlFlowEmitter.cs:70
```

Right clause, right rule, quotation marks around words the standard does not contain in that order. Present
at `a2255819`, introduced by `586547c6`, and **both audits report zero findings on it** — `audit_doc_citations`
does not read `src`, and `audit_code_citations` checks the clause against the CONSTRUCT named, never the
quoted text. (The design-doc line PB405 added quotes it correctly, so the repair is to copy that text.)
