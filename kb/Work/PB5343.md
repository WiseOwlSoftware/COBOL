# PB5343 - at --std 85 the SEND/RECEIVE COBOL6171 messages cite "ISO/IEC 1989:2002 A.2.6.2 SR3/SR4" instead of the 1985 rule (§1985:XIV.3.6.3), so the diagnostic names an edition the user did not select

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CommunicationBinder.cs` (`BindSend`, `ScreenSendAdvancing`, `ScreenSendAdvancingLiteral`, `ResolveCommunicationCd`, `BindPath`, `SyntaxRule`, `Cite`, `Prints2002`)

**Mechanism.** The COBOL6171 text built in `CommunicationBinder.BindSend` / `ScreenSendAdvancing` quotes 2002's A.2.6.2 SR3/SR4 at every edition, including `--std 85`, where the rule is §1985:XIV.3.6.3 (the source's own comment names "no mnemonic-name defined in the SPECIAL-NAMES paragraph, §1985:XIV.3.6.3 SR4"). Wording only; its own root (the refusal and its conditions are right). Not verified with `cite.py` here (the lead gives no quotation); the implementer should run `cite.py --check` on the 1985 rule and quotation chosen.

**Fix direction.** Choose the cited edition from `ctx.Edition` (the diagnostic text per edition), as the other communication screens do, and pin the 85 wording in a refusal case.

**Source.** PB5167 report, New defects (note-ready) item 2.
