## Landing (wave 20262075 A, 2026-11-16): traced, fixed at the root, siblings swept

**Re-probe on this branch's base (main 19423a49a4):** `grpv.cob` at `--std 85` printed `G1=[ABCD]`, `G3=[    ]`,
`G5=[0000]`; a wider probe at `--std 2023` lost the VALUE in every shape with a REDEFINES under the group (G8 one level
down `[    00]`, a figurative `VALUE ZEROS` group `[    ]`, a format 2 group VALUE over an element holding a pair
`[        ]`, a national group `[    ]`, a bit group `[000000]`).

**Root cause (traced).** `src/WiseOwl.Cobol.Compiler/CodeGen/DataDivision/GroupValueSlicer.cs#ComposedInit` distributed
the §2023:13.18.63.4 GR5 area only when `DistributableSubtree(group)` held, and that predicate refused any subtree with a
member whose `Class` was set. Every other subtree fell to `PhysicalModel.PhysicalChildrenOf`'s member-wise
initializers: each typed member from its own description, and a Tier-B backing rooted at a member from
`GroupImageCodec.ImageInitOf(member)`, which asks `AreaOf` of the MEMBER (no VALUE). The comment that justified the
fall-through ("its backing is seeded by ImageInitOf, which applies the SAME AreaOf rule to the same group") is true
only for a class rooted AT the VALUE group. Both lanes were correct for their own root; nothing carried the
ancestor's area down to a class rooted below it.

**Sibling found on the way (same mechanism, other lane):** `GroupImageCodec.CarrierInitOfOne`'s group-VALUE arm
returned a NATIONAL group's area as characters into a byte-addressed backing, so
`01 NH GROUP-USAGE NATIONAL VALUE N"KL". 05 NHA PIC N. 05 NHB PIC N. 01 NHR REDEFINES NH PIC X(4).` read NH back as
U+4B4C U+2020. Fixed here (`AreaImageOf` stores it through `NatBytes`, as each national leaf is).

**Shape.** `ComposedInit` slices whenever an area exists. `SliceInit`/`SliceBitInit` walk every non-redefining member
and ask ONE placement, `MemberFromSlice`: a Tier-B canonical's backing takes the slice through the image lane
(`GroupImageCodec.BackingSeedOver`), a Tier-A canonical and every typed member decode it, a redefiner takes none, and a
member it cannot place throws naming the item. The image lane's group arm and the inherited slice share
`AreaImageOf`. Drift test `tests/WiseOwl.Cobol.Tests.Unit/GroupValueAreaStorageFormDriftTests.cs` plants a group VALUE
over each storage form and asks the binder that each case builds the class it names; with the old gate restored, 12
of its 15 run cases fail.

**Siblings.** Per-occurrence (format 2) group VALUE: the same walk, case `per-occurrence-group-value`. Bit group:
`SliceBitInit` had the same gate, now fixed (cases `bit-*`). INITIALIZE ... TO VALUE / `SeedRecipe.Initialize`:
unchanged, §2023:14.9.20.4 GR5 c) 1. b names only an elementary item's VALUE. BASED: ALLOCATE INITIALIZED is that
INITIALIZE (§2023:14.9.3.4 GR7), so no group VALUE applies (probed: spaces). EXTERNAL: a plain external record's
VALUE takes effect only during INITIALIZE (§2023:13.18.63.4 GR4 a). LINKAGE / FILE SECTION: no initial state from
VALUE. LOCAL-STORAGE and a RECURSIVE program's static reset ride `FieldInit` → `ComposedInit` (probed; case
`local-storage`).

**Witnesses.** `conformance-suite/cases/VI.5.15@1985-VALUE-CLAUSE/1985-GR-VI_5_15_6-3` (85, fixed form) and
`conformance-suite/cases/13.18.63-VALUE/pb5851_group_value_over_redefines` (2023).
