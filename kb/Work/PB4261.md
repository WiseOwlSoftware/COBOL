# PB4261 — the enqueue_chains measure and its docstring call every chain that starts after the fix a regression, but the measure also counts consecutive enqueue units that the fixed rules start legitimately; a handoff naming resume with nothing to resume may chain the same way, unmeasured

**Sites:** `scripts/orchestrator/next_unit.py:228` (`enqueue_chains`, `base_choice`), `docs/rearchitecture/DESIGN-orchestrator-loop.md` (the sentence at line 192 that calls a post-fix chain a regression).

The `enqueue_chains` docstring and DESIGN-orchestrator-loop.md line 192 call any chain that starts after the fix a
regression, but the measure also counts consecutive enqueue units that the fixed rules start legitimately: rule 6 agent
work found again after an enqueue unit, and an operator steer of enqueue.

Unmeasured sibling (same chain measure): a handoff naming `resume` with nothing to resume can chain the same way, because
rule 2 obeys the handoff. It has not been seen in units.jsonl, and `next_unit.py --enqueue-chains` measures enqueue chains
only. The fix to the measure should cover resume chains too, and say so, so the case is measured before anyone claims it
absent.
