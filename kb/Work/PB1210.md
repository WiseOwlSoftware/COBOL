# PB1210 — LANDED

## Measured

**any-length-clause** — ANY LENGTH SR1 PICTURE check is a closed list of six literal spellings (X, N, 1, X(1), N(1), 1(1)) instead of the count-1 shape its DYNAMIC LENGTH sibling uses, so a one-occurrence picture written X(01) / N(001) / X(constant-name=1) is refused as not 'one instance'

- **Repro:** Contained program ALP1SUB with `LINKAGE SECTION. 01 L PIC X(01) ANY LENGTH. PROCEDURE DIVISION USING L.` called with PIC XXX and PIC X(8) arguments (probe/any-length-clause/p1.cob) -> COBOLNET1542 'requires a PICTURE whose character-string is exactly one instance ... PICTURE X(01)'.
- **Expected (spec):** 13.18.40.3 SR6: the parenthesized integer 'indicates the number of consecutive occurrences of the symbol'; X(01) is one occurrence of X, satisfying 13.18.2.3 SR1. The program compiles and prints LEN=03 VAL=XYZ then LEN=08 VAL=WXYZABCD (13.18.2.4 GR1b).
- **Observed:** DataBinder.cs ANY LENGTH shape check: `norm is not ("X" or "N" or "1" or "X(1)" or "N(1)" or "1(1)")`. The DYNAMIC LENGTH check ~40 lines below already uses ^[XN](\(0*1\))?$ with a comment that 'a count of 1 in ANY spelling is still one instance'. Two-arm dispatch: one arm generalized, the other not. Fix shape: ONE shared 'single-occurrence picture' predicate (symbol set as parameter), ideally over the parsed PICTURE (symbol + resolved count, so a constant-name count is covered too), used by both clauses, with a drift test.
- **Code site:** src/Cobol.Net.Compiler/Binding/DataBinder.cs (ANY LENGTH declaration-shape validation, SR1 arm)
- **Clause (adjudicator):** 13.18.2.3 SR1; 13.18.40.3 SR6
