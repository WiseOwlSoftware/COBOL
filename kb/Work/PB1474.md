# PB1474 — OPEN

## The rule (every citation re-run by the registrar through `cite.py --check`)

> In the report section, neither a sum counter nor the LINE-COUNTER and PAGE-COUNTER identifiers may be used as a subscript

`python scripts/spec/cite.py --check 8.4.2.3.3 "…"` → `OK  §8.4.2.3.3 8)  (Syntax rules)`

## Finding — `subscripts` (under-rejects; rows `SR-8.4.2.3.3-8`)

**Mechanism.** No screen exists for §8.4.2.3.3 SR8: a report-section subscript that is a sum counter or the LINE-COUNTER / PAGE-COUNTER register is bound like any other subscript in the SUM-addend and PRESENT WHEN legs (the SOURCE leg refuses every subscripted operand as not-yet-implemented, so it rejects for the wrong reason)

**Repro.** FD RPTF REPORT IS RPT. WORKING-STORAGE: 01 TB. 05 TE PIC 9 OCCURS 9 VALUE 1. 01 AMT PIC 9 VALUE 1.
REPORT SECTION. RD RPT PAGE LIMIT 20.
01 DL TYPE DETAIL LINE PLUS 1.
   05 DSUM COLUMN 10 PIC 99 SUM AMT.
   05 COLUMN 20 PIC 99 SUM TE(LINE-COUNTER).        (or SUM TE(DSUM), or PIC X VALUE "P" PRESENT WHEN TE(PAGE-COUNTER) = 1)
OPEN OUTPUT RPTF / INITIATE / GENERATE DL x2 / TERMINATE / CLOSE

**Expected from the spec.** Compile-time refusal at every edition: §8.4.2.3.3 SR8 'In the report section, neither a sum counter nor the LINE-COUNTER and PAGE-COUNTER identifiers may be used as a subscript.'

**Observed / reasoning.** All four spellings (SUM TE(LINE-COUNTER), SUM TE(DSUM), PRESENT WHEN TE(LINE-COUNTER) = 1, PRESENT WHEN TE(PAGE-COUNTER) = 1) compile clean and run (SUM TE(LINE-COUNTER) at 85, 2002 and 2023, printing 00); only PRESENT WHEN TE(DSUM) is refused, by §13.15.3 SR16 (COBOLNET1559). A grep of src/Cobol.Net.Compiler finds no code that tests a subscript for a sum counter or a counter register. Fix shape: one report-section subscript screen applied wherever a report description entry's identifier is resolved (SUM addend, PRESENT WHEN, VARYING/FROM, and SOURCE once ReportSourceSubscripted is lifted).

**Code site.** src/Cobol.Net.Compiler/Binding/DataBinder.Reports.cs#SumAddendRef / #ResolveSumAddend / PRESENT WHEN binding; DataBinder.Reports.cs line ~2414 (ReportSourceSubscripted)

## What the fixer owes

One report-section subscript screen applied wherever a report description entry's identifier is resolved (SUM addend, PRESENT WHEN, VARYING/FROM, and SOURCE once PB1292 lifts ReportSourceSubscripted). Negative goldens for the four spellings.
