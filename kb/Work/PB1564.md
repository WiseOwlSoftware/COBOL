# PB1564

Found 2026-09-24 by the w59a, w59b and w59e implementers (independently). Fix: a per-run temporary folder (the
test's own `Path.GetTempPath()/Guid` directory, deleted on exit) and surface the tool's stderr in the failure message so an
empty-message failure cannot recur. The w59h finisher was asked to investigate the same flake — whoever lands first
closes this note; the other drops it.

## Resolution (train 62, wave 59 H)

Landed by the w59h finisher: `scripts/gen-grammar-diagrams.ps1 -Check` (and its twin `scripts/gen-vault-reference.ps1 -Check`) now write to a per-run `%TEMP%` directory suffixed with a GUID, so concurrent worktree gates no longer delete each other's output (reproduced before: 3 of 4 concurrent `-Check` runs exited 1 with "Could not find a part of the path …CobolOO.md"; after: 4 of 4 pass). The test already carried the script's STDOUT/STDERR in its failure message; the "empty message" was `scripts/build-local.ps1`'s line filter dropping the assertion body, a separate process defect the w59h report filed as a lead.
