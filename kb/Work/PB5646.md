# PB5646 - INSPECT of a national group (GROUP-USAGE NATIONAL) with an alphanumeric literal operand is accepted (2002 and 2023)

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/InspectBinder.cs#BindPhrases` (CharacterOperandClassMix, COBOL2306)

**Mechanism.** InspectBinder's SR4 all-or-nothing class test reads identifier-1's class through IntrinsicArgumentRules.ClassOf, which does not give a GROUP-USAGE NATIONAL group class national; 2002 treats a national group as an elementary item of class national, so SR4 requires every operand to be national.

**Inventory.** Rows claimed: `2002-SR-14.8.21.2-4`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:14.8.21.2 SR4`: "then all shall reference a data item or literal of class boolean or national, respectively"
- `§2002:13.16.27.3 GR2b`: "a national group is treated as though it were an elementary data item of usage national and class and category national"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p3/inspect-natgroup-mix.cob); the text is inline. Command: `cobol.exe p3/inspect-natgroup-mix.cob --std 2002`

`p3/inspect-natgroup-mix.cob`:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. INSPNGM.
      *> a-05 answer probe: INSPECT SR4 with a 2002 national group
      *> (GROUP-USAGE NATIONAL, treated as an elementary item of class
      *> national by 13.16.27.3 GR2b) as identifier-1 and an
      *> alphanumeric literal-1: shall be refused at --std 2002.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  NG GROUP-USAGE NATIONAL.
           05 NA PIC N(3).
           05 NB PIC N(3).
       01  C1 PIC 99.
       PROCEDURE DIVISION.
       MAIN-PARA.
           INSPECT NG TALLYING C1 FOR ALL "A".
           STOP RUN.
```

**Observed.** INSPECT NG TALLYING C1 FOR ALL "A" (NG GROUP-USAGE NATIONAL): compiles, rc=0 (the answerer saw the same at 2023, and the program runs and tallies).

**Expected (from the 2002 text).** refused (COBOL2306): the alphanumeric literal mixes classes with a national identifier-1.

**Sibling sweep.** STRING (StringUnstringBinder uses the same class-mix check), UNSTRING, and every other ClassOf caller given a national group.

**Other editions.** 2023: yes (same rule, same result). 2014: yes presumably. 85: n/a (no national).
