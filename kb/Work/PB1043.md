# PB1043 — OPEN

## The two texts
- `cite.py --check 13.18.22.3 "The EXTERNAL clause shall not be specified for a data item of class object or pointer"` → `OK §13.18.22.3 4)`.
- `cite.py --check 13.18.22.4 "If the EXTERNAL clause is specified in a file description entry"` → `OK §13.18.22.4 4)`; its b) makes the FD's records external.

## The two readings
1. **As implemented (PB1026):** SR4 constrains where the clause is WRITTEN — on a data description entry. A record
   of an EXTERNAL FD does not specify the clause; it is external by GR4. Carried, no diagnostic.
2. **Alternative:** SR4's subject is any external data item of class pointer/object however it became external;
   then an EXTERNAL FD with a pointer-class record is illegal and needs a diagnostic (the implementer reserved
   COBOLNET1796's text for it).
