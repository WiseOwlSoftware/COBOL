# PB5246 - at --std 85 a GENERATE whose presentation SUPPRESS PRINTING inhibited uses up the GROUP INDICATE first presentation, so the indicated items never print: GenerateCore clears the pending indication on any GENERATE (the 2023 rule) where 1985 keys it to the first presentation

**Sites:**

- `src/WiseOwl.Cobol.Runtime/IO/ReportWriter.cs` (`GenerateCore`: clears `GroupIndicatePending`; `ArmGroupIndicate`, `GroupIndicatePresent`, `PresentBody`)
- `src/WiseOwl.Cobol.Runtime/Control/DialectBehavior.cs` (`GroupIndicateConsumedByIssuedGenerate`, VCR row 7.60)
- `src/WiseOwl.Cobol.Runtime/IO/ReportWriter.cs` (`PresentBody` now returns whether the group presented)

**Mechanism.** §1985:XIII.3.13.4 GR1: GROUP INDICATE "causes the SOURCE or VALUE clause to be ignored and spaces supplied, except" on the first presentation of the detail in the report, after a page advance, and after a control break. A GENERATE whose USE BEFORE REPORTING procedure executes SUPPRESS PRINTING presents nothing (§1985:XIII.4.6.4 GR3). `GenerateCore` clears the pending indication after any GENERATE of the detail, the 2023 determination that "the first occasion that a GENERATE is issued" consumes it (kb/Work PB1652 landed it at every edition), so at 85 a suppressed first GENERATE takes the indication the first presented one is owed.

**Found by.** The 1985 code read, slice 51.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the code read's non-conforming verdicts of slices 36-56 wait in `E:/COBOL-coord/scratch/coderead-85/pipe-for-register.json`.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-GR-XIII.3.13.4-1` - `§1985:XIII.3.13.4 GR1` (read: PARTIAL, harm: wrong-answer): "causes the SOURCE or VALUE clause to be ignored and spaces supplied"; `§1985:XIII.4.6.4 GR3` (SUPPRESS).

**Repro (`E:/COBOL-coord/scratch/coderead-85/reprobe-85c/rw_gisupp.cob`).** `RD RPT CONTROL IS WS-K`, `01 DL TYPE IS DETAIL LINE NUMBER IS PLUS 1.` with `COLUMN 1 PIC XX VALUE "AA" GROUP INDICATE`, `COLUMN 4 PIC X SOURCE WS-K GROUP INDICATE`, `COLUMN 6 PIC 9 SOURCE WS-N`; `USE BEFORE REPORTING DL` suppresses when WS-N is 1 or 4; GENERATE with WS-N 1, 2, 3, then WS-K "B", GENERATE with WS-N 4, 5; `cobol.exe --std 85 --source-format fixed --run rw_gisupp.cob`.

**Observed (the records-85c build of origin/main f2cf36fd15, rerun 2026-11-10).** The report file holds `     2`, `     3`, `     5`.

**Expected (from the 1985 text).** `AA A 2`, `     3`, `AA B 5`: GENERATE 2 is the first presentation in the report, GENERATE 5 the first after the control break.

**Fix direction (root cause, CLAUDE.md rule 4).** Consume the indication where the group is presented, not where it is generated, in the 1985 arm (the edition is the only difference), with the read's program as the test at both editions.
