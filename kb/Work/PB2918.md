# PB2918 — the SDIDI lift of a >34-digit container value

Filed 2026-10-10 by the train 1052 lander (phase 1b) from the wave 1052 E implementer's report
(`E:\COBOL-coord\scratch\reports\w1052e-PB2698-report.md`, lead A).

**Repro:** `E:\COBOL-coord\scratch\w1052e\sd1.cob` (`OPTIONS. ARITHMETIC IS STANDARD-DECIMAL.`; `S PIC S9(19) COMP-5`
whose storage is set to `X"80000000000000000000000000000000"` through a redefining `PIC X(16)`, i.e. -2^127, a
value the binary container holds although its PICTURE allows 19 digits). `COMPUTE R = S + 1`, whose result is a valid
value of R's container, reports a size error.

**Where.** The standard-decimal operand path renders a binary item through `NumericRenderer.DecOperand`
(`src/Cobol.Net.Compiler/CodeGen/Emit/NumericRenderer.cs`, about line 753) into `CobolDec.From(unscaled, scale)`
(`src/Cobol.Net.Runtime/Values/Numeric/CobolDec.cs`, line 23), which accepts any Int128. A 39-digit significand breaks
the invariant CobolDec's `Int128.Abs` / significand sites assume (at most 34 digits, the decimal128 coefficient), and
the next operation reads it as an overflow. PB2698 (train 1052) fixed the native-lane ABS of `Int128.MinValue`; this is
the SDIDI lane's sibling, left because it is a different mechanism (the lift, not the function).

**Rule.** §14.7.5 (SIZE ERROR phrase and size error condition): a size error is the RESULT's, after the arithmetic;
an operand the container holds is not one. What the standard-decimal intermediate does with an operand wider than its
34 digits is an implementor determination (the SDIDI intermediate's precision), to be written into CONFORMANCE.md
beside DOC-A.1-179.

**Fix shape.** One place: the lift of a binary operand into the decimal128 intermediate decides an over-wide value once
(round to 34 digits per the intermediate's rule, or raise EC-SIZE at the lift by a recorded determination), instead of
constructing a CobolDec that violates its own invariant. Add a guard in `CobolDec.From` (or a checked twin) so the
invariant is enforced where it is assumed, and a golden at 2023 with the repro's cases.
