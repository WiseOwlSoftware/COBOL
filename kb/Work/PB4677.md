# PB4677 — implement the Communication facility at COBOL-85 and 2002

**Decision (owner, 2026-11-04, PB4614 decision 12).** WiseOwl implements the Communication facility at COBOL-85 and 2002 (the
COMMUNICATION SECTION and its statements), so the per-edition suites can witness it and NIST-85's CM module is subsumed.

**What is wrong.** Today the COMMUNICATION SECTION is not accepted at 85 or 2002: no rule in the grammar names it
(`git grep -n -i communication -- src/WiseOwl.Cobol.Frontend` finds only the reserved-word table row, `ReservedWords.Table.cs:87`,
and two comments, `CobolParserCore.g4:993` and `CobolParserCoreBase.cs:1217`), and the program draws the generic COBOL0001.
`docs/CONFORMANCE.md` §4 documents only the 2023 asynchronous-messaging facility (SEND, RECEIVE, USAGE MESSAGE-TAG) as not
claimed. The reserved-word status is already right (`pb4297-communication-reserved-85-2002`).

**Witnesses that exist.** NIST-85's CM module: `tests/nist/programs/CM101M.cob`, `CM102M.cob`, `CM103M.cob`, `CM104M.cob`,
`CM105M.cob`, `CM201M.cob`, `CM202M.cob`, `CM303M.cob`, `CM401M.cob` (nine programs).

**Fix shape.** Implement the facility per the 2002 text (`t2002.txt`, its COMMUNICATION clauses: communication description
entries, ENABLE, DISABLE, SEND, RECEIVE, ACCEPT MESSAGE COUNT, PURGE) for 85 and 2002, gated by edition. CLAUDE.md rule 2
requires a design first: no deep-dive doc owns the facility today (`docs/rearchitecture/DESIGN-frontend-grammar.md` does not
mention it), so the first step is a design-doc section, then grammar, binder and runtime from it. Each clause is cited with
`python scripts/spec/cite.py --check`. The 2023 SEND/RECEIVE forms keep their own rows.

**Re-probe (base 83365cbf3).** `cobol --nist CM201M` and a program with `CD C1 FOR INPUT SYMBOLIC QUEUE IS Q.` drew `error COBOL0001: unexpected 'COMMUNICATION'` at every edition.

**Landed.** `docs/rearchitecture/DESIGN-communication-facility.md` is the design: the 2002 Annex A at 85 and 2002 with the COBOL-85 KEY phrase, gated by `communication-facility-removed-2014` (obsolete 2002) and
`communication-key-phrase-removed-2002`, and a message control system in the runtime, defined by `mcs.json`. All nine CM programs compile at COBOL-85, and CM102M, CM103M, CM105M and CM201M run with no CCVS failure
(`CommunicationCcvsTests`). Codes COBOL6169 (entry rules), COBOL6170 (a statement's cd-name), COBOL6171 (a statement's operand). The determinations are `docs/CONFORMANCE.md` §3.3.
