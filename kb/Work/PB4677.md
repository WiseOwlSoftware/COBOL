# PB4677 — implement the Communication facility at COBOL-85 and 2002

**Decision (owner, 2026-11-04, PB4614 decision 12).** WiseOwl implements the Communication facility at COBOL-85 and 2002 (the
COMMUNICATION SECTION and its statements), so the per-edition suites can witness it and NIST-85's CM module is subsumed.

**What is wrong.** Today the COMMUNICATION SECTION is not accepted at 85 or 2002: no rule in the grammar names it
(`git grep -n -i communication -- src/WiseOwl.Cobol.Frontend` finds only the reserved-word table row, `ReservedWords.Table.cs:87`,
and two comments, `CobolParserCore.g4:993` and `CobolParserCoreBase.cs:1217`), and the program draws the generic COBOL0001.
`docs/CONFORMANCE.md` §4 documents only the 2023 asynchronous-messaging facility (SEND, RECEIVE, USAGE MESSAGE-TAG) as not
claimed. The reserved-word status is already right (`pb4297-communication-reserved-85-2002`).

**Witnesses that exist.** NIST-85's CM module: `tests/nist/programs/CM101M.cob`, `CM102M.cob`, `CM103M.cob`, `CM104M.cob`,
`CM105M.cob`, `CM201M.cob`, `CM202M.cob`, `CM303M.cob`, `CM401M.cob` (nine programs).

**Fix shape.** Implement the facility per the 2002 text (`t2002.txt`, its COMMUNICATION clauses: communication description
entries, ENABLE, DISABLE, SEND, RECEIVE, ACCEPT MESSAGE COUNT, PURGE) for 85 and 2002, gated by edition. CLAUDE.md rule 2
requires a design first: no deep-dive doc owns the facility today (`docs/rearchitecture/DESIGN-frontend-grammar.md` does not
mention it), so the first step is a design-doc section, then grammar, binder and runtime from it. Each clause is cited with
`python scripts/spec/cite.py --check`. The 2023 SEND/RECEIVE forms keep their own rows.

**Re-probe (base 83365cbf3).** `cobol --nist CM201M` and a program with `CD C1 FOR INPUT SYMBOLIC QUEUE IS Q.` drew `error COBOL0001: unexpected 'COMMUNICATION'` at every edition.

**Landed.** `docs/rearchitecture/DESIGN-communication-facility.md` is the design: the 2002 Annex A at 85 and 2002 with the COBOL-85 KEY phrase, gated by `communication-facility-removed-2014` (obsolete 2002) and
`communication-key-phrase-removed-2002`, and a message control system in the runtime, defined by `mcs.json`. All nine CM programs compile at COBOL-85, and CM102M, CM103M, CM105M and CM201M run with no CCVS failure
(`CommunicationCcvsTests`). Codes COBOL6169 (entry rules), COBOL6170 (a statement's cd-name), COBOL6171 (a statement's operand). The determinations are `docs/CONFORMANCE.md` §3.3.

## Landing

- `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolCommunication.g4#communicationSendStatement`: `SEND x FROM y` is two formats; the 2023 arm's `communicationNameFollows()` predicate decides, from the names `cdName`'s action recorded. An optional WITH can now follow a statement, so a recovery that used to insert a token after a WITH reads "cannot parse construct" (pb332).
- `src/WiseOwl.Cobol.Runtime/Communication/MessageControlSession.cs#Statement`: the one path of every statement, and what makes a 9x status mean no action: it acts on copies of the area and the run unit's half, published only after `MessageStore.Commit`. A statement that writes straight to the run unit's half or to a device breaks that.
- `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.ClausePlacement.cs#EntrySections`: no `All`. A residence row lists its sentence's sections, because an `All` widened GLOBAL silently when the communication section arrived.
- `src/WiseOwl.Cobol.Compiler/Binding/CommunicationSectionBinder.cs#CommunicationFormats`: the one table of each format's clauses and positions; `BuildArea` builds the implicit description from it. The class's anchor is the first written record, so its VALUE clauses seed the area.
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CommunicationBinder.cs#ResolveCd`: every statement's cd-name rule. A new verb collaborator of `StatementBinder` costs a hand-listed pair in `docs/rearchitecture/architecture-edges.json` (`walkUses`, not `uses`, which the census measures); a partial of `StatementBinder` costs more pairs, not fewer.
- `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/CommunicationEmitter.cs#Emit`: the area over `OperandText.RecordAreaImage` and back over `SequentialIoEmitter.EmitImageInto`; that store is for an item's whole storage, so a reference-modified receiver takes `PlaceRenderer.Write`.
- `src/WiseOwl.Cobol.Runtime/Communication/MessageControlSession.cs`: the run unit's half, whose lifetime is ISO/IEC 1989:2002 14.5.10 rule 2. `MessageStore.Run` is the one transaction; `MessageJson` turns a wrong-shaped file into a `FormatException`, which is what status 91 and 92 catch.
- `src/WiseOwl.Cobol.Frontend/Preprocessor/NistPreprocessor.cs#Process`: XXXXX030-043 are the names `tests/nist/data/mcs.json` defines.

**The message control system is redesigned (2026-11-04).** The owner rejected keeping the landed JSON store because it already existed. The approved design (`docs/rearchitecture/DESIGN-communication-facility.md` §6-§9) moves the queues to the runtime's paged store with a socket bell; the slices are PB4734-PB4738, and PB4736 closes the lock defect it names.
