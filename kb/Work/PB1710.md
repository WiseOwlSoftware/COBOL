# PB1710 — OPEN

Filed by the train-70b lander from wave 70 group I's report (`w70i-PB1683-report.md`, new defect 3).

## Finding

**Repro.** `python scripts/spec/record_impact_map.py --commit dbea12428 --overlay`, then read the `children` line:
172 of 4,242 children wrote no hits file (0 of 3,961 in the `4b0f3e22a` recording). The test framework reports the
count as `missing_children` but the recording still succeeds, so a runtime file those children executed can be absent
from the tests that reached it — a narrower selection than the truth, which is the unsafe direction for a gate filter.

**Sites.** `tools/impact/ImpactProbe.cs#WriteHits` (swallows `IOException`); `tools/impact/ImpactTestFramework.cs`
(`missing_children`). A recording with missing children should either fail loudly or mark the affected tests as
reaching every runtime file.
