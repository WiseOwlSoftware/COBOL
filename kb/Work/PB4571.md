# PB4571 — a hung merge-group Conformance step leaves no evidence

**Sites:** `scripts/ci_bounds.py`, `.github/workflows/build-and-test.yml` (the `windows-shard` job's `Conformance, this shard` step, about line 718, and
the `Upload test results` step after it; the Linux shard job's same pair, about line 642).

**Observed.** PR #1101's merge-group run 41779240040: every job passed except Windows shard 6/7, whose `Conformance, this shard`
step started 05:32:09Z and never finished. The job's `timeout-minutes: 20` cancelled it at 05:51:45Z. The other shards'
Conformance steps took under 3 minutes. The `Upload test results` step (`if: ${{ always() }}`) shows no start, so the run
holds no TRX, no harness log and no artifact for shard 6, and `ci-gate` failed with nothing to name. The landing lane's rule
(land_lane.py `classify_red`: no test failed, so INFRA) has it re-queued once, done here by hand, and that is all the rule can do: whether a case
hangs on Windows Release, or the runner stalled, cannot be told from this run.

**Defect.** When the job-level timeout ended this job, the step after the running one did not run despite its `if: always()`
(the run's step list shows it never started), so the upload cannot be relied on to follow a hang. Nothing in
the step names the case that hung either: `dotnet test` runs with no `--blame-hang`. A hang is therefore always classified
INFRA and re-queued, and a real hang (a Conformance case that deadlocks only under Release or on GitHub's runners, class (c) or
(e) of CLAUDE.md's Testing rule) gets one free retry and then a finisher with no evidence.

**Fix shape.** Give each shard's test steps a step-level `timeout-minutes` inside the job's limit, leaving the upload room to run,
and add `--blame-hang --blame-hang-timeout <a few minutes> --blame-hang-dump-type none` to the Conformance (and Unit) `dotnet test`
lines, so a hang aborts with the hanging test's name in the blame sequence file, which the upload already collects under
`TestResults/`. Keep `scripts/ci_bounds.py` (the CI bounds check) in agreement, and make `land_lane.py`'s classifier read a
blame-hang abort as a named red case rather than INFRA.
