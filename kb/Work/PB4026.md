# PB4026 — `audit_annex_a1.py` walks the test directory from the file system

**Sites:** `scripts/spec/audit_annex_a1.py:543` (the `rglob` of the test directory).

**What.** The audit lists the test directory with `rglob`, so it enumerates the test projects' `bin/` and `obj/` (build output
that a running gate rewrites): the file-system race PB3814 removed from the Unit drift sweeps, and the resolver PB3122 wrote
twice. The file is not one PB3814 changes, so the reviewer left it.

**Fix shape.** List tracked files (`git ls-files` under the test directory) instead of walking the file system, as the
TrackedTree scopes do for the C# sweeps; one arm that plants a twin under `bin/`.
