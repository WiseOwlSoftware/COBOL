# PB3588 - the SoleBooleanOperand drift rows for ConditionBinder.cs cannot fail

## Lead (PB3565 review lead R1-1, low)

`tests/Cobol.Net.Tests.Unit/SoleBooleanOperandDriftTests.cs` (line 34 area), test
`EveryHostOfASoleBooleanOperand_AsksTheOneClassifier`: the two rows for `ConditionBinder.cs` look for a call to the pair
`BindSoleBooleanOperand` / `IsSoleBooleanOperand` with a member-call regex, and that regex matches the methods' own declarations in
`ConditionBinder.cs`. The rows pass whatever the file does, so they do not pin the wiring their comments claim: that the boolean leaf
`BindBoolOperandValue` and `IsBooleanValueOperand` call the pair rather than carry their own copy of the classifier.

## Fix shape (for the implementer)

Exclude the declaration (match a call site, for example by scanning only the bodies of `BindBoolOperandValue` and
`IsBooleanValueOperand`), then prove the rows can fail: temporarily inline the classifier in the leaf and see the row go red (record
the red in the commit message). Sweep sibling drift tests that use the same regex helper for the same declaration self-match.

**Sites:** `tests/Cobol.Net.Tests.Unit/SoleBooleanOperandDriftTests.cs`.
