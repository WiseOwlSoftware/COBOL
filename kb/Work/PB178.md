# PB178

Found 2026-08-30 by the PB176 skeptic round; PRE-EXISTING. `OperandText.AsStorageImage` handles
RefModPlace and OdoGroupPlace, then does `p.Item.IsGroup ? Read(p).AsImage() : ...` — no RedefViewPlace
arm, though its sibling `FieldAsString` returns the view's window early with the explicit comment "no
.AsImage() ... for a group or an elementary view alike". A Tier-B class with a GROUP member yields a
RedefViewPlace whose Read is the string window, so `FUNCTION CONVERT(B ANY TO ...)` over
`01 A PIC X(8). 01 B REDEFINES A. 05 B1 PIC X(4). 05 B2 PIC X(4).` emits
`CobolStr.RefMod(_redef_A, 1, 8).AsImage()` — CS1061 on `string` (CONVERT's bind screen rejects only
index/pointer/object usages, so the shape reaches the emitter).

FIX SHAPE: route AsStorageImage's group arm through `PlaceRenderer.GroupImage` (THE ONE reader — its
doc names exactly this violation) instead of spelling the call; that also inherits the PB176 capability
guard for free. Golden: a CONVERT over a Tier-B group view. Sweep the remaining self-spelled sites the
skeptic enumerated (OperandText:133 is guarded but still self-spelled; OoEmitter's are PB177's A).
