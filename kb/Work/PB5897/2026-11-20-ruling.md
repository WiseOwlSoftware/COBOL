  The class half of each argument rule is a source property and is already refused at compile time, as the text requires.

Reasoning: The amendment separates the two halves of an argument rule. The argument's CLASS is a property of the source: an
integer argument is "an arithmetic expression which will always result in an integer value". The compiler refuses a violation
of that half (COBOL1627). A constraint on the argument's VALUE is different. §1989:A.2.2 calls such constraints "constraints on
the permissible values for arguments" and gives their consequence: "If, at the time a function is referenced, the arguments
specified for that reference do not have values within the permissible range, then the result of such a reference is
undefined." The consequence is tied to the time of the reference, so the source is not in error. The text states what happens
when such a reference runs, and Amendment 2 says the result may include terminating the run. A literal argument does not
change this: §1989:A.2.2 lets an argument be a literal, and the value rule is the same for a literal as for a data item.

Refusing FACTORIAL(-1) or RANDOM(-1) at compile time would therefore reject a conforming program. The probe shows a case: the
reference sits on a path that never runs, so the program conforms and runs predictably. That would be `rejects_legal_source`,
the harm the note asks about in reverse. A compile-time warning for a literal outside the domain is allowed, since a warning
does not reject source, but nothing requires one. Whether to add one is a quality choice and does not make the current
behavior a defect. The current run-time behavior is within "undefined": FACTORIAL(-1) returns 0, RANDOM(-1) returns 0, and
neither crashes.

The lead's own citation (`§1989:A.2.2 AR4`, the integer-class sentence) is about the class half, which is already enforced.
It does not support a compile-time refusal of the value half.

Scope: the same holds for every intrinsic function's VALUE constraint at --std 85 (SQRT, LOG, the date functions' ranges,
ANNUITY, and so on): §1989:A.2.2 governs them all. No other edition was ruled.
