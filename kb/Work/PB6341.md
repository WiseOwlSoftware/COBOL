**Rule it breaks:** §2023:13.18.54.4 GR6 (the value a rolled SUM adds is that of the operand of the entry's VALUE clause) with §2023:12.3.7.4 GR14a (under DECIMAL-POINT IS COMMA the decimal separator written in a numeric literal is the comma); and the project's one-mapping rule for numeric literals (ExpressionBinder.NumericLiteralOperand), which RawNumber re-implements as a character filter

**Scenario:** SPECIAL-NAMES. DECIMAL-POINT IS COMMA. In an RD: 05 X COLUMN 10 PIC 9,9 VALUE 1,5. and in a footing 05 COLUMN 20 PIC 99,9 SUM X. RawNumber('1,5') (ReportWriterBinder.cs:405-411) accepts only ASCII digits, '.', '+' and '-', returns null, and RolledValueOf (:379-385) reports ReportSumDataNameRule 'the operand of its SOURCE or VALUE clause is not a number a sum counter can add' against legal source. The same VALUE text is accepted for the printable item itself, because the emitter's ValueInitializer reads pic.DecimalPointIsComma (CodeGen/DataDivision/ValueInitializer.cs:350); only the rolled-value reader disagrees. Repro by reading: the raw text is stored unnormalized as FieldValueSource(Raw) after DataBinder.ScreenValueLiteral (ReportSectionBinder.cs:2775-2823), which does not rewrite the separator.

**Measured how:** R2 batch finding `procedure-binding-6--code--f1#2` (pair procedure-binding-6--code), read in the pinned tree at 9e65164eb3a9; skeptics rule upheld, scenario upheld, site upheld.

**Spec:** §2023:13.18.54.4 "If data-name-1 specifies an item whose entry has a SOURCE or VALUE clause, the value added is that of the operand" (`cite.py --check` passed at collection); §2023:12.3.7.4 "The character written in numeric literals to represent the decimal separator shall be the comma." (`cite.py --check` passed at collection)

**Target:** RawNumber reads the VALUE literal through the one numeric-literal mapping the procedure division uses (ExpressionBinder.NumericLiteralOperand / the figurative ZERO reader), which knows the DESCRIBING unit's decimal-point mode, so the rolled value and the printed value come from one reading
