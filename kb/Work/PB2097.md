## Landed (wave 1045 group B, 2026-10-08)

Implemented from `docs/rearchitecture/DESIGN-external-repository.md` §4.5, §6.2, §11.2, §11.3, §15.4 (§21 item 1 now
reads LANDED and names the parts). Every emitted type lives in `namespace Cobol.<S>` (`CsNames.ModuleNamespaceOf`, the
assembly simple name made one identifier by `DataItem.Sanitize`); the using directives sit inside it and name their
namespaces from `global::`, and every qualified emitted name is `global::`-rooted (`EmittedGlobalNameDriftTests`, over
every string the compiler holds). `[assembly: CobolRepository(schema, runtimeVersion, callAbi, Registrar)]` precedes the
namespace; `__CobolModule.EnsureRegistered()` is the one public registration member (`ProgramRegistry.RegisterModule`),
`Register` is private, and `Main` calls `EnsureRegistered`. `ProgramTable.RegisterModule` keeps one registration set per
run unit, refuses another runtime major or call ABI (`RuntimeAbi.Skew`), and stages the registrar, refusing the module
WHOLE when one of its outermost names is already registered, as a program or as a function: the design said
`kind:name`, but OK §8.3.2.2 2) "Within a run unit, all instances of a given name that is externalized to the operating
environment shall identify the same kind of entity or item" makes the test kind-blind (design §11.2 corrected).
`Register` throws outside a `RegisterModule`. `ProbeSiblingModule` reads the registrar from the record as attribute data,
invokes `EnsureRegistered`, and records its failure reason, which the EC-PROGRAM-NOT-FOUND / EC-FUNCTION-NOT-FOUND and
ADDRESS OF PROGRAM messages carry. `Directory.Build.props <Version>1.0.0`; `Microsoft.CodeAnalysis.PublicApiAnalyzers`
5.0.0 on the runtime with `PublicAPI.Shipped.txt`; `RuntimeAbiPinDriftTests` pins the major beside the shipped surface
and the codec images, and `RuntimeAbi.CallAbi` beside a boundary-layout fixture. Tests: `ModuleRegistrationTests`
(unit); `ModuleRegistrationHostTests` (modules named Cobol, CobolNet and CobolNum call each other; a duplicate and a
version skew are EC-PROGRAM-NOT-FOUND with the reason); the host and witness tests reach a module through the record and
`EnsureRegistered`; 14 snapshots re-baselined. Docs: INTERPROGRAM's probe paragraph, the OO design's namespace sentence,
CONFORMANCE DOC-A.1-14/-65/-89/-167.
