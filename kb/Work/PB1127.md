## Measured (adjudicator / refuter evidence, verbatim)
### [inspect-statement-p1] InspectCharOperandOf has no HEXLIT arm: an alphanumeric hexadecimal literal falls to the 'numeric literal' tail and is refused
- **Rows:** SR-14.9.22.3-3 — harm `rejects-legal-source`
- **Repro:** 01 X PIC X(5) VALUE 'ABCDE'. 01 N PIC 99 VALUE 0. ... INSPECT X TALLYING N FOR ALL X'41' (also REPLACING ALL X'4142' BY 'ZZ', CONVERTING X'414243' TO 'XYZ') --std 2023
- **Expected (spec):** Compiles; N=01. §14.9.22.3 SR3 admits any alphanumeric literal and §8.3.3.2.2 Format 2 makes X'..' a form of alphanumeric literal (2002+).
- **Observed:** error COBOLNET1757: INSPECT operand 'X'41'' is a numeric literal; each INSPECT literal shall be an alphanumeric, boolean, or national literal (ISO §14.9.22.3 SR3). The method decodes STRINGLIT, NATLIT, BOOLLIT and concatenation but never HEXLIT (ExpressionBinder line 218 has the one-line HEXLIT decode the other verbs use); the numeric-literal tail is a catch-all. Sweep: any other verb with a private literal switch lacking HEXLIT.
- **Code site:** src/Cobol.Net.Compiler/Binding/Procedure/Verbs/InspectBinder.cs#InspectCharOperandOf (lines ~354-377)

### [inspect-statement-p1] The SR3 'begins with the word ALL' screen is one predicate applied to every INSPECT operand position and tests only two of the seven figurative formats: it refuses a legal ALL figurative as literal-5 and admits ALL ZERO/SPACE/HIGH-VALUE/LOW-VALUE/QUOTE as literal-1..4
- **Rows:** SR-14.9.22.3-3 — harm `rejects-legal-source`
- **Repro:** (a) INSPECT X CONVERTING 'ABC' TO ALL 'Z' -> refused COBOLNET1757; (b) INSPECT X TALLYING N FOR ALL ALL SPACES, INSPECT X REPLACING ALL 'AB' BY ALL SPACES, INSPECT X CONVERTING ALL SPACES TO 'Z', INSPECT X TALLYING N FOR CHARACTERS BEFORE ALL ZERO -> all compile clean at --std 2023
- **Expected (spec):** (a) compiles: SR3 names only literal-1..literal-4 in the ALL prohibition and GR22 sizes a figurative literal-5 to literal-4, so X becomes 'ZZZDE'. (b) each is a syntax error: §8.3.3.6.2 Formats 1-5 print ALL as an optional word of ZERO/SPACE/HIGH-VALUE/LOW-VALUE/QUOTE, so ALL SPACES is 'a figurative constant that begins with the word ALL'.
- **Observed:** InspectCharOperandOf: `fig.allLiteral() is not null || fig.ALL() is not null && fig.cobolWord() is not null` is evaluated for every inspectChar with no knowledge of which literal-n it is, and misses the `ALL ZERO|SPACE|HIGH_VALUE|LOW_VALUE|QUOTE_` alternatives of figurativeConstant. Fix shape: a position-aware screen (literal-5 exempt) over 'fig.ALL() is not null'; the ALL-literal literal-5 then needs GR22 expansion (repeat to literal-4's size per §8.3.3.6.4 GR2). Harm splits: (a) rejects legal source, (b) under-rejects.
- **Code site:** src/Cobol.Net.Compiler/Binding/Procedure/Verbs/InspectBinder.cs#InspectCharOperandOf (line ~334)

### [inspect-statement-p1] INSPECT never screens a zero-length literal operand (only CHARACTERS BY '' is caught, via SR7)
- **Rows:** SR-14.9.22.3-3 — harm `under-rejects`
- **Repro:** INSPECT X TALLYING N FOR ALL '' (runs, N=00); INSPECT X REPLACING ALL '' BY ''; INSPECT X CONVERTING '' TO ''; INSPECT X TALLYING N FOR CHARACTERS BEFORE '' (runs, N=05) --std 2023
- **Expected (spec):** Each is a syntax error: 'Literal-1, literal-2, literal-3, literal-4, or literal-5 shall not be a zero-length literal.'
- **Observed:** No length-zero test in InspectCharOperandOf or StatementValidation; the BEFORE '' case even changes the result (whole item counted). Distinct from PB895 (edition gating of zero-length literals generally).
- **Code site:** src/Cobol.Net.Compiler/Binding/Procedure/Verbs/InspectBinder.cs#InspectCharOperandOf
