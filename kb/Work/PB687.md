# PB687 — OPEN — the byte that turns a text file binary

Found 2026-09-05 by the `PB673` implementer (report §"New defects" 3), which caught it by reading the diffstat rather
than the exit code — the same discipline that caught the `utf-8-sig` BOM face recorded in the tool-writes memory.

## Repro

Append `\r` before an existing `\r\n` in any tracked `.md`, `git add`, `git diff --cached --stat`: the whole file
is re-stored with CRLF. Review noise at best; at worst a CRLF-normalized file whose later `sed -i` edits then rewrite
every line (the DEVLOG's known failure mode).

## Fix

A two-line pre-commit scan over `git diff --cached --name-only` for lone CR (`\r` not followed by `\n`), NUL and a
UTF-8 BOM, refusing the commit and naming the file and offset — as a git hook under `scripts/hooks/` beside the fleet
guard, so every lander and implementer inherits it, and as a step in `scripts/build-local.{sh,ps1}`'s pre-flight so
the wave-local gate fails on it too. The same scan, run over the whole tree once, tells whether any file is already
stored that way (report, do not mass-normalize — `DEVLOG.md` is deliberately unnormalized).
