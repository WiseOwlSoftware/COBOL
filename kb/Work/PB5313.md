# PB5313 - at --std 85 an area-A item that REPLACE pseudo-text-2 supplies on its own line is judged at the column of the text it replaced, so legal source is refused (COBOL3734): AreaPlacementPass reads an inserted token's position through the source map

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Validation/AreaPlacementPass.cs` (`Run`)

**Mechanism.** Text a REPLACE inserts is "placed in the source program according to the rules for reference format" (§1985:XII.3.4 GR10), and its correctness is judged only after all COPY and REPLACE processing (GR9). A paragraph header "starts in area A" (§1985:IV.7.3.3). The area-A check reads each token's line start through the source map, which gives a REPLACE-inserted token the position of the text it replaced, so a paragraph header that pseudo-text-2 puts in area A of its own line is judged in area B. The same program compiles at 2002.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the adjudicated non-conforming verdicts wait in `E:/COBOL-coord/scratch/coderead-85/held-for-register.json`.

**Rules (1; every citation checked with `scripts/spec/cite.py --check`, and each 1985 rule number compared with the numbered paragraph the quotation sits in, which cite.py does not do: kb/Work PB5317).**

- `1985-GR-XII.3.4-10` - `§1985:XII.3.4 GR10` (adjudicated: PARTIAL, harm: rejects-legal-source): "are placed in the source program according to the rules for reference format"

**Repro.** `E:/COBOL-coord/scratch/held-85/set3/RA3.cob` (REPLACE ==XXX== BY a two-line pseudo-text whose second line is the paragraph header P2 in area A); `cobol.exe --std 85 --source-format fixed --run RA3.cob`.

**Observed (a build of origin/main d9dde0e7ba (the source exported to `E:/COBOL-coord/scratch/main-d9dde0e7ba`), rerun 2026-11-11).** exit 65: `RA3.cob(9,12): error COBOL3734: an area-A item that does not begin its fixed-form line in area A requires COBOL-2002 (targeting COBOL-85) - the paragraph header P2 begins in area B`.

**Expected (from the 1985 text).** Compiles and prints A, B, D, C, as it does at --std 2002.

**Fix direction (root cause, CLAUDE.md rule 4).** Judge an inserted word by its place in the resultant text (pseudo-text-2's own line structure), which the source map can record for REPLACE output; test RA3 and RA5.
