# PB5951 - the object code shows no exception-handling regions

**Found by the owner**, 2026-11-19 19:15, in the NC105A listing: "I see endfinally and leave instructions, but there are no
pseudo try or catch instructions, such as would appear in IL source code", and "catch also".

**Harm:** `wrong_answer` because the object-code section (DESIGN-listing.md sections 6.9 and 7) claims to be the true object
code of each statement, and a method body's exception-handling clauses are part of that code (ECMA-335 II.25.4.6: the clauses
follow the body's IL in the method's data sections); without them a `leave` or `endfinally` stands in a stretch with no
protected block, which a reader cannot interpret. `silent` because nothing says the regions are missing. No program's run-time
result changes.

**Cause:** `ObjectCodeMapReader.Read` takes each body with `PEReader.GetMethodBody` and hands its IL to
`IlDisassembler.Decode`; it never reads `MethodBodyBlock.ExceptionRegions`, so the model (`ListingMethod`,
`ListingObjectRange`) has no place for a region, and no renderer can show one.

**Sites:** `src/WiseOwl.Cobol.Compiler/Listing/ObjectCodeMapReader.cs` (`ObjectCodeMapReader.Read`, `ObjectMethod`),
`src/WiseOwl.Cobol.Compiler/Listing/ObjectCodeMapBuilder.cs` (`ObjectCodeMapBuilder.Build`),
`src/WiseOwl.Cobol.Listing/ListingObjectCode.cs` (`ListingMethod`, `ListingObjectRange`),
`src/WiseOwl.Cobol.Listing/Text/ObjectCodeText.cs` (`ObjectCodeText.CodeRows`),
`src/WiseOwl.Cobol.Listing/Html/HtmlListingRenderer.cs` (`HtmlListingRenderer.Instructions`),
`src/WiseOwl.Cobol.Listing/Json/listing-v1.schema.json`, `docs/rearchitecture/DESIGN-listing.md` (sections 6.9, 7, 7.3, 11),
`docs/manual/user-guide/listing.md`.

**Fix (branch `listing-step-pb5951`):** the reader reads each body's clauses once, beside its IL; the model carries them on the
method and, placed among each stretch's instructions, as ILDASM-style region lines; the three renderers print what the model
holds.
