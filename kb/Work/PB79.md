# PB79 — LANDED — `01 NG GROUP-USAGE NATIONAL.` / `01 BG GROUP-USAGE BIT.` parse, bind, lay out and operate per §13.18.29

> ⚙ **flags:** rejects-legal-source (loud, at parse) · **7 inventory rows** (`FMT-13.18.29.2`, `SR-13.18.29.3-1..3`,
> `GR-13.18.29.4-1..3`) **plus the group legs of two PB61 rows** (`RV-15.50.4-1/2`, recorded PARTIAL on PB61's
> landing) — all CONFORMS 2026-08-18 (DEVLOG 1317). Registered 2026-08-17 while landing PB61.

**Measured repro (before)** (`--std 2023`, `scratchpad/sr6/gu.cob`):
```
       01 NG GROUP-USAGE NATIONAL.        ->  error COBOL0307: unexpected 'NATIONAL'
       01 BG GROUP-USAGE BIT.             ->  error COBOL0307: unexpected 'BIT'
```
`GROUP-USAGE` was a §8.9 reserved word that no clause consumed.

**Spec:** §13.18.29.2 general format `GROUP-USAGE IS { BIT | NATIONAL }`; SR1: only on a group item that is not
strongly typed and not a variable-length group; SR2 (BIT): USAGE BIT implied for the subject, no explicit USAGE,
every subordinate elementary item usage bit / category boolean, every subordinate group GROUP-USAGE BIT explicitly
or implicitly; SR3 (NATIONAL): the same for national (+ SIGN IS SEPARATE for signed numerics); GR1 (BIT): the
subject is a bit group AND a bit data item, class/category boolean, "treated as though it were an elementary data
item … PICTURE 1(m)" (m = the bit length), subordinates allocated per §8.5.1.6.3; GR2 (NATIONAL): class/category
national, "PICTURE N(m)"; GR3: without the clause a group is an alphanumeric group item.

## As built (data-model design **D20**; DEVLOG 1317)

- **Grammar / registries:** `GROUP_USAGE : 'GROUP-USAGE'` (a hyphenated keyword token; a user word below 2002 via
  `cobolWord` — `tests/version-matrix/cobol-words.json` row → `gen-cobol-words.ps1`; in the funnel's
  `CheckedTokenTypes`, so `01 GROUP-USAGE PIC X.` compiles at 85 and is 0901 at ≥2002);
  `groupUsageClause : GROUP_USAGE IS? (BIT | NATIONAL)` as a `dataDescriptionClause`; `constructs.json` row
  `group-usage-clause-2002` (0900 below 2002 — `ParseArm.VisitGroupUsageClause`).
- **The model — ONE as-if picture, two structural predicates:** `DataItem.GroupUsage` (None/Bit/National, propagated
  to every subordinate group by the usage-inheritance walk), `DataItem.AsIfPic` (`PICTURE 1(m)` = the exact bit
  extent, `PICTURE N(m)` = the national positions), **`DataItem.OperandPic => Pic ?? AsIfPic` — THE ONE READER for
  category** (Table 16 both sides, `MoveClassifier`, `MoveReceiverCategory`, `IntrinsicResultType.OperandCategory`,
  `ClassOfPlace`, `RefModPlace.Category`, `LengthPositions`, the INSPECT / STRING / UNSTRING sizes, the relation
  renderer's category and anchor width, the boolean-expression operand check) and `IsAsIfElementary`. `IsGroup` /
  `IsElementary` / `Children` keep their structural meaning — the 116 structural sites are untouched.
- **Layout:** `BitLayout.IsBitItem` (a bit leaf OR a bit group) drives §8.5.1.6.3 rule 1's same-level byte sharing;
  `ExtentBits` omits rule 4's trailing filler for a bit group (the NOTE's "record that is entirely a bit group").
  The GROUP-USAGE BIT / NATIONAL implied usage rides the SAME `PicPending.BitUsage/NationalUsage` adjudication a
  group-level `USAGE BIT/NATIONAL` clause rides — and that walk now APPLIES the implied bit form to PICTURE-1
  leaves without their own USAGE (§13.18.60.4 GR1; before, `01 G USAGE BIT. 05 GA PIC 1(5). 05 GB PIC 1(3).`
  validated the leaves and left them display-form: 8 bytes, now 1).
- **Emitter:** a bit group's operand face is `AsBits()` / `FromBits()` (its subordinates' boolean positions
  concatenated — `GroupImageCodec.EmitBitMethods`; `OperandText`'s as-if arm, `PlaceRenderer.Write`'s as-if arm,
  `BooleanRenderer`, the relation renderer's `BoolRead`); the packed byte image stays `AsImage()`/`FromImage()`,
  and a bit group can be a MEMBER of a §8.5.1.6.3 run in an alphanumeric group (`PhysicalModel` run members are
  bit items; the run's carrier expression is `X.AsBits()` for a group). A national group's operand face IS its
  character image (`AsImage()`), stored through the ONE group-image store.
- **Diagnostics:** COBOLNET1653 (`GroupUsageRule`) for SR1 (elementary / no subordinates / strongly typed /
  variable-length), SR2/SR3's explicit USAGE and subordinate-group conflict; the leaf conformance is the shared
  0881 / national-form-staged 0899 legs, positioned at each leaf (PB82's cursor).
- **Found on the way, fixed here:** **[[PB95]]** — bare (USAGE-less) POINTER / OBJECT REFERENCE / NATIONAL / BIT /
  PROGRAM-POINTER / FUNCTION-POINTER were parse errors (§13.18.60.2 `[USAGE IS]`); `usageClause` is now ONE
  `(USAGE IS?)? usageKeyword` alternative.

**Goldens:** `2023/pb79_group_usage_national` (LENGTH 5 / BYTE-LENGTH 10, MOVE pad/truncate both ways, national
comparison, INSPECT, ref-mod read and write, a nested national group), `2023/pb79_group_usage_bit` (LENGTH 12 /
BYTE-LENGTH 2, MOVE to bit / display / shorter receivers, MOVE into the group distributing to B1/B2/B3, equality,
`B-OR`, a nested bit group, the group-level USAGE BIT leaves, a bit group sharing a byte inside an alphanumeric
group), `2023/pb95_bare_usage_keywords`; negatives `pb79-group-usage-explicit-usage`, `-not-a-group`,
`-subordinate-conflict` (1653), `-85` (0900).

**Residue (documented, not deferred work of this note):** national-form NUMERIC subordinates of a national group
(`PIC 9 … USAGE NATIONAL`, SR3's SIGN IS SEPARATE half) are the Phase 4a national-form staged legs (0899) — the
same status they have outside a national group.
