# PB5008 - is a 98 % uphold rate an independent check

**Found.** Wave 20261931 group a (PB4995). In the audit run the refuter upheld 1,345 of 1,371 verdicts. It is the same
model at the same effort as the pass it checks, so a 98 % uphold may mean it does not catch what the first pass misses.

**Owed.** Before the fleet builds verdicts on the upheld CHANGED and REMOVED rows, a sample audit: an agent re-derives 30
upheld CHANGED or REMOVED rows from the 1985 text and the 2023 rules named, blind to the first verdict; a miss rate
above the uphold rate's complement changes the refute pass (a different model or effort, or a prompt that asks for the
strongest counter-reading first). Record the result here and, if the pass changes, in `DESIGN-spec-conformance-review.md`.

**Sites:** `scripts/spec/audit_batch.py` (`PROMPTS`)
