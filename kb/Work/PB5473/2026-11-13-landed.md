**Landed (2026-11-13, wave 20262025).** Determination (DOC-A.1-40): the libraries available during a compilation are the default library and each library a COPY statement of the compilation group names with OF or IN that a library place holds. The alternative the note's fix direction named, every subdirectory of every library place, was rejected: the compiler's working directory is a library place, so any project directory with a subfolder would make every unqualified COPY of every 85 program wrong, whatever the program uses. ISO/IEC 1989:2002 Annex F.2 item 38 speaks of libraries "referenced", which is this set. `CountLibraries` refuses at 85, through the new constructs row `copy-unqualified-text-name-2002` (COBOL0900, the introduction gate of the 2002 relaxation; no new diagnostic code), each unqualified COPY of a group that names such a library; an unqualified COPY met before the first named library waits for it and is reported at its own position.
