# PB1860 — OPEN

PB1216's brief asked for a drift test: compile a program with an instance WS cell, a LOCAL-STORAGE cell and a RECURSIVE static cell and assert every
`StorageCell _scell_X` field of the generated class is named by exactly one of `_scell_X.End(StorageEnd.ActivationEnded)` (Call's finally),
`EndStorage`, or `_scell_X.Reinitialize(` (`__ResetStatics`). The classification itself is single-sourced (`DataBinder.LifetimeOfCell`), and the three goldens
`2002/pb1216_*_pointer_lifetime` pin the behaviour, but the generated-text pin was not written (turn cap). Site: a new `tests/Cobol.Net.Tests.Unit/CellLifetimeDriftTests.cs`
modelled on `OperandActivationDriftTests.Emit`.
