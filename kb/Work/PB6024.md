**Repro:** `E:/COBOL-coord/scratch/w20262131q/work-q-02/g03.cob` (`05 DI COLUMN 990 PIC X(20) VALUE "ABC".`) at `--std 85`:
`error COBOL2745 ... past the page width 999 (assumed 999, §2023:13.18.39.4 GR5) ... (ISO §2023:13.18.14.3 SR8 b); a page width
is not in COBOL-85, so this rule requires COBOL-2002 (targeting COBOL-85))`. The message itself says the rule is not 1985's, yet
it refuses. The 1985 PAGE clause (§1985:XIII.3.8.2) prints no width phrase and the 1985 COLUMN NUMBER rules (§1985:XIII.3.11.3)
state no right-margin rule, so the program is legal 1985 source as far as these rules go (a line longer than the implementor's
record is a separate question: the report file's record size).

**Code site:** the SR8 b) and c) arms of the COLUMN screen (about lines
4093-4098 and 4143-4150 on train85b-cite2), and COBOL2710 `report-column-beyond-page-width` (its descriptor already records "ANSI
X3.23-1985 gives a report no page width"). **Fix shape:** at 85 the arms do not fire (or, if an implementor limit applies, the
message cites the implementor's line length, not a 2023 rule); a conformance case accepting the program at 85.
