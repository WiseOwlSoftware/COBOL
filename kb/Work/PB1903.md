# PB1903 — OPEN

Filed 2026-10-01 by the train-1001 lander from the wave-1001 group C implementer report
(`w1001c-PB1494-report.md`, new defect 1).

**Site.** `src/Cobol.Net.Frontend/Preprocessor/CopyProcessor.cs`, lines 50 and 52 at train 1001's head: the
removal diagnostic for a comment-entry / REMARKS in library text is reported with the literal `"COBOLNET0902"`
rather than `EditionCodes.RemovedConstruct`. The semgrep rule `cobolnet-raw-diagnostic-code-literal` does not match
this shape, so the baseline (294) does not count it.

**Fix.** Use `EditionCodes.RemovedConstruct` at both sites, and widen the semgrep rule so the shape is counted
(the rule-class fix, not only the instance).
