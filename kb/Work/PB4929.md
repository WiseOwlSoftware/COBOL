## Decisions (wave 20261925 group F, 2026-11-08)

This note and PB4919 are the same lead, filed twice. PB4919 (landed) adjudicated all 36 candidates and fixed the five real
mechanisms (MEMORY SIZE, RERUN EVERY/OF, USE FOR DEBUGGING, the USE AFTER gate, the SET repetition gate). On this
branch's build the run reported 25 candidates, none of them new. Every PB4919 witness was re-run at `--std 85`: USE without
AFTER or PROCEDURE, PERFORM VARYING without BY and SET with a second phrase each draw COBOL0900; `EVALUATE A B` draws
COBOL5506; bare `EXIT`, `SYMBOLIC CHARACTERS BELL 8`, `VALUE OF FILE-ID "F.DAT"`, `READ F INVALID …`, `RERUN EVERY REEL OF F`
and `PAGE LIMIT IS 10` compile. One PB4919 verdict was wrong: §1985:XIII.3.17.2 (page 629) prints the Report Writer SIGN
clause with SEPARATE underlined and unbracketed, and §1985:XIII.3.17.3 SR3 requires it in a report group entry. The compiler
already enforces it (`DataBinder.ScreenReportSignClauses`, construct `report-sign-without-separate-2002`, golden
`13.18.52-SIGN/pb3683-report-sign-without-separate-85`), so the verdict changes and the code does not.

The 25 candidates were the audit's to fix, in four mechanisms, and the 1985 run now reports none:
- **A required choice is one slot** (`_slots`, used by `demanded`). Deleting a word of `(IS | ARE)` deletes the whole choice,
  and a choice with an arm that writes no word demands none: VALUE OF's IS, PAGE's LINE/LINES and SYMBOLIC CHARACTERS'
  IS/ARE. The same change drops the 2023 run's false SYMBOLIC IS/ARE and LINE ARE/NUMBERS candidates (PB4110 cause 1, in
  part), and it no longer anchors `reportPageClause` to the LINE clause's format.
- **A construct is all its printings** (`construct_of`, `drawn_population`). §1985:VIII.2.6.3 GR1 says the Relative I-O RERUN
  clause "is a subset" of the Sequential one. A scan's format is now read with every printing of its construct: a statement
  by its verb, anything else by its whole title. This answers EXIT PROGRAM, RERUN ON (Relative and Indexed), READ KEY and
  SIGN SEPARATE (decided above).
- **An edition-scoped marker** (`DECIDED_BY` `… at 1985`, `Decision`). It covers USE AFTER/PROCEDURE
  (`VersionConformancePass.VisitUseStatement`), PERFORM BY (`VisitPerformVarying`, `VisitPerformVaryingAfter`) and the SET
  repetition (`VisitSetBooleanStatement`). It decides only that edition's candidates, and only a full run of that edition
  can find it dead.
- **Delimiter pairs across lines** (`figure_reading.spans`, a `Holder` with `open_bottom`/`close_top`). Page 316 types `{{WHEN`
  and `[ALSO` at the head of a line and closes them lines later. Unpaired, they left the underlined ALSO held by nothing.
  The 1985 run's unpaired-delimiter count is now zero.

Self-test arms cover each mechanism. Each arm fails with its mechanism removed.
