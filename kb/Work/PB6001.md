# PB6001 - a second numbered list of a disposed clause, and HTML tables, are no units

**Sites:**
- `scripts/spec/rule_catalog_1985.py` (`units`: `items=clause not in numbered and clause not in declared`)
- `scripts/spec/text_units.py` (`segment`, `TABLE_LINE`, `table_units`: only `|` tables are tables)
- `docs/rearchitecture/spec-unharvested-rule-blocks-1985.json` (`paragraph-blocks` of the three clauses)

**What.** kb/Work PB5452's mint left exactly three 1985 units pending, each a hold refuter 85h-01 upheld
(`docs/rearchitecture/spec-dispositions-1985/85h-01-refute.jsonl`). Their consumers are these units:

1. **`§1985:IV.4.2.2.1.3 p3`** ("There are three types of reserved words:"). `rule_catalog_1985.units` segments a clause
   with `items=False` whenever the content-keyed manifest declares it (`clause in declared`), because the declared
   block's numbered list is disposed as a whole. §1985:IV.4.2.2.1.3 prints a SECOND list after p3, one item per line
   (PDF page 154: 1. required words, 2. optional words, 3. special purpose words), which no block disposition holds; with
   items off it is no unit, so p3 leads nothing the catalog has. The root: `items` is per clause where it should be per
   list (the manifest's block names its list; a later list of the clause is units).
2. **`§1985:XIII.3.10.7 p2`** and **`§1985:XIII.3.10.9 p2`**. Each leads a presentation rules table that the
   transcription holds as an HTML `<table>` (the 1985 text holds sixteen so, `rule_catalog_1985.HTML_TABLE_OPEN`).
   `text_units.segment` reads only `|` tables (`TABLE_LINE`), so the HTML table is neither a table unit nor text, and the
   colon unit before it leads nothing. The root: one table reading for both markups (an HTML `<tr>` is a body row).

**Fix.** Make `items` a property of a list, not of a clause; read an HTML table's rows as `table_units` reads a `|`
table's (and `_rules_of`'s HTML-table skip then holds only a table a rule's text holds). Regenerate: the new item and
table units enter pending, are read and refuted with the PB5452 records' form, imported with
`scripts/spec/import_dispositions.py`, and minted by the regeneration.

**Done when** the three units above and the units the fix adds have dispositions (none pending in the 1985
manifest), and `extract_rule_catalog.py --edition 1985 --check` passes.
