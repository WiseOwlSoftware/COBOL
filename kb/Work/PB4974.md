# PB4974 - the PB4623 golden's tag and its missing unchecked arm

**Sites:** `conformance-suite/cases/14.7.5-SIZE-ERROR-phrase-and-size-error/pb4623_function_overflow_alone_and_beside_operator.cob` (line 3 header, line 21 body).

**R1-1 (low).** The header tags GR-14.7.5-L3.2 (no-phrase rule 2, EC-SIZE-ZERO-DIVIDE), copied from pb1581_binary64_intermediate_range. The program has no
division: it witnesses no-phrase rule 3 (GR-14.7.5-L3.3, EC-SIZE-OVERFLOW/UNDERFLOW) and case 5 (GR-14.7.5-5), which its own comment names. Retag.

**R1-2 (low).** The golden pins only the CHECKED arms (`>>TURN EC-SIZE CHECKING ON`, with and without the phrase). The unchecked arm the PB4623 note filed
(bare `EXP10(400)` against `0 + EXP10(400)`) is pinned by no golden. The reviewer re-probed it and it agrees today (both abnormal termination
EC-SIZE-OVERFLOW; `EXP10(-400)` both EC-SIZE-UNDERFLOW). Add the arm so a regression cannot return unseen; expected values from the no-phrase rule, not copied output.
