# PB6216 — the unwrap half of the PB6060 test is untested

**Mechanism.** `tests/WiseOwl.Cobol.Tests.Unit/CliParserTests.cs:343`. `ThrowWrapped` throws the `AggregateException` itself from
`CliParserTests`, so the outer exception's first `WiseOwl.Cobol` frame is already `CliParserTests`. Deleting the AggregateException
unwrap in `Program.FaultingPass` leaves the test green: it cannot fail for the regression it names.

**Fix shape.** Throw the inner exception from a frame in a different `WiseOwl.Cobol` type, wrapped by a real `Parallel` or `Task`
boundary (or build the `AggregateException` around an exception whose stack names another type), and assert the named pass is the
inner one. Mutate `FaultingPass` to drop the unwrap and see the test fail before it is kept.

**Sites:** `tests/WiseOwl.Cobol.Tests.Unit/CliParserTests.cs:343`, `src/WiseOwl.Cobol.Cli/Program.cs` (`FaultingPass`)
