# PB4489 - a repeated paired conditional phrase after a left statement draws no diagnostic

**Rule.** ISO 14.5.3.3 (`python scripts/spec/cite.py --check 14.5.3.3 "the next phrase of any containing statement"` -> OK
14.5.3.3 2) c)): a conditional statement is implicitly terminated by the next phrase of any containing statement, so a phrase
word that no statement the parse left owns is a fault of its own.

**Observed.** PB4449 made the recovery's phrase-word suppression take a phrase only where `ResimulationWalk.AfterABlockOf`
says the left statement's own grammar takes it, so a second `ELSE` after a left IF is reported. The paired conditional phrases
(`ON SIZE ERROR` / `NOT ON SIZE ERROR`, `AT END` / `NOT AT END`, ...) are not walked: they are ONE `conditionalPhrases` loop whose
occurrence count a predicate (`ConditionalPhraseAssociation`) decides, which the walk does not evaluate. A phrase repeated
after a left statement therefore stays silent as it was before PB4449 (`ADD 1 TO X NOT ON SIZE ERROR DISPLAY 'A' NOT ON SIZE
ERROR DISPLAY 'B'` after a faulted statement in the same sentence; the PB4449 note states the shape).

**Repro.** The PB4449 note's `Not fixed, a lead` paragraph: a left `ADD` followed by two `NOT ON SIZE ERROR` phrases; main
reports the fault that left the ADD and nothing for the second phrase. Expected: a diagnostic at the repeated phrase as for the
repeated ELSE (`pb4449-second-else-after-an-empty-if-in-an-if`).

**Fix direction.** Teach `ResimulationWalk` the paired-phrase count (the predicate `ConditionalPhraseAssociation` already
decides over the stream) so the loop's occurrence limit is the walk's, one rule in one place, rather than a second count; golden
beside `conformance-suite/cases/14.5.3.3-Implicit-scope-termination/pb4449-second-else-after-an-empty-if-in-an-if.cob`; unit
beside `ParseRecoveryCascadeTests.ASecondOccurrenceOfAPhraseIsNoPhraseOfTheStatementTheRecoveryLeft`.

**Sites:** `src/WiseOwl.Cobol.Frontend/Parsing/ConditionalPhrases.cs` (`ConditionalPhraseAssociation.UnownedPhraseMessage`), `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs` (`ContinuesAStatementTheRecoveryLeft`, `ResimulationWalk.TakesPhraseAt`), `tests/WiseOwl.Cobol.Tests.Unit/ParseRecoveryCascadeTests.cs` (`ASecondOccurrenceOfAPhraseIsNoPhraseOfTheStatementTheRecoveryLeft`).
