# PB5440 — the self-tests of `scripts/t*.py`–`scripts/v*.py` (about 1,900 lines), `test_held_analyzer_output.py` (to `_tree/`) and the two tools named `test_*` (renamed out of the prefix) become case files under their `selftests/` directories, each script's `--self-test` handler deleted (the second half of PB5403's batch)

**Sites:** `scripts/t*.py`, `scripts/v*.py`, the `selftests/` directory of each converted subject (new), `scripts/selftests/_tree/held_analyzer_output/` (new), `scripts/selftest_layout.py` (`REMAINING`), `scripts/self_test_arms.py` (`DECLARED`), every caller of `test_population.py` and `test_leg_report.py` (`scripts/gate.py` (whole: it runs the two renamed tools) or its modules, `.github/workflows/build-and-test.yml`, the briefs and skills that name them)

## The design this step implements

`docs/rearchitecture/DESIGN-orchestrator-loop.md` section 16.2 and section 16.10 (kb/Work PB3726). The design is the SSOT; this note does not restate it.

## The step

For every script the Sites' globs match that holds a self-test (a `--self-test` handler, a standalone `test_*.py` beside its subject, or a delegate `self_test*`/`*_arms` another self-test calls), cut it into `fixtures.py` and `test_<world>.py` files under the subject's directory (section 16.2), reach the subject through `selftest_cases.subject`, delete the handler, the `self_test` function and every helper only it used, carry each `# SELF-TEST-*` header to every file whose cases need it, rewrite the subject's `self_test_arms.DECLARED` entry to case names, move every caller the section 16.2 sweep finds, and remove the subject's line from `REMAINING`. Rename the two tools named `test_*` (`test_population.py`, `test_leg_report.py`) out of the prefix, every caller moved (the gate, CI, the briefs): once they handle no `--self-test`, the runner's rule (b) would run them bare as tests. `test_held_analyzer_output.py` has no subject file and goes to `scripts/selftests/_tree/held_analyzer_output/`. A script with no self-test is not touched. If the batch does not fit one wave, the implementer stops at a subject boundary, lands what is converted (each subject is whole) and reports the rest; the next dispatch continues this note.

## Oracle

Per subject: the label sets before and after equal (both in the report; an empty set is a failure, section 16.1); `self_tests.py --list` the same headers per subject; the git processes of each subject's run at most one more per new file; the gate GREEN. The two renamed tools' CLI outputs the same before and after.

## Done when

No script the globs match handles `--self-test`, is a standalone `test_*.py` outside `selftests/` or holds a delegate self-test; each one's line is gone from `REMAINING`; the layout rule GREEN.
