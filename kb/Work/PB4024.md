# PB4024 — the `src/**` listings walk the product projects' bin/obj

**Sites:** `tests/WiseOwl.Cobol.Tests.Unit/TrackedTreeScopeDriftTests.cs` (`TestsTreeWalks`, the walk the drift test judges with), and about 190 listing sites across `tests/WiseOwl.Cobol.Tests.Unit/*DriftTests.cs`.

**What.** PB3814 converted the sweeps that walk `tests/` from the file system (descending into every running test host's
`bin/obj`) to TrackedTree scopes, and made the drift test judge them. The same hazard stands on the `src/` side: about 190
recursive listings of `src/**` enumerate the product projects' `bin/obj` (build output the gate writes while it reads), the
race PB3814's reader side describes. `TestsTreeWalks` could judge `src/<project>` roots the same way, and each listing would
convert to a TrackedTree scope.

**Not fixed in PB3814.** About 170 files, beyond that slice.

**Fix shape.** Extend the walk the drift test judges to `src/<project>` roots, then convert the listings to TrackedTree scopes,
file by file, with the drift test's unresolved-root cap holding.
