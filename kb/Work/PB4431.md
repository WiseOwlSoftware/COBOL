# PB4431 - CallBinder operand texts still taken by GetText()

**Defect.** `kb/Work/PB4267.md` (landed) says every CallBinder message that quoted a node now uses `DataBinder.WrittenText`.
The report finds five calls that still pass `GetText()` as the operand text to `ValueClassScreen` (COBOL1628) and
`AddBareExpressionArg`, so a qualified BY VALUE operand (`A OF G`) prints glued (`AOFG`).

**Witness.** `E:/COBOL-coord/scratch/reports/w20261821a-PB2103-report.md`, Review findings R1-2 (low, not blocking at round 1). At origin/main
`CallBinder.cs` lines 430 (`vdref.GetText()`), 459 (`vax.GetText()`), 550 (`bare.GetText()`), 614 (`bArith.GetText()`)
and 621 (`a.GetText()`). Not probed by the reporter; probe each with a qualified operand and a ZERO operand.

**Fix direction.** Name each node as written through `DataBinder.WrittenText`, as PB4267 did for the rest of the file; then
sweep the six binders for any remaining `GetText()` inside a message (PB4252 is the drift-test analysis).

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CallBinder.cs#BindCall`

## Landed (wave 20261842, group A)

**Re-probe** (built tree, `--std 2023`, `CALL "S1" AS NESTED USING BY VALUE A OF G` with `A PIC X(4)`): the COBOL1628 text quoted
the operand glued (`AOFG`) before the fix; after it, `'A OF G'`. **Fix:** the five `GetText()` operand texts of `BindCall` (BY
VALUE identifier-4, BY VALUE arithmetic-expression, the keyword-less identifier under a BY VALUE formal, the bare expression and the
grouped boolean operand) quote `DataBinder.WrittenText`. `OperandUnresolved` (the SCREEN SECTION refusal) looked the glued
`dref.GetText()` up in `ScreenNames`, so a qualified screen name never matched: it now looks up the base word and quotes the
written reference. `CallBinder.cs` holds no `GetText()` of a node in a message any more (the two left are the AS prototype word
and `BarePrototypeWord`, values, not messages). **Goldens:** `conformance:cases/14.9.4-CALL/pb4431-call-by-value-operand-quoted-as-written`
and `pb4431-call-implied-by-value-operand-quoted-as-written` (both expect `BY VALUE operand 'A OF G'`). **Not changed (PB4252's):**
the same pattern in about ninety messages of the other binders (`git grep -n "GetText()" -- src/WiseOwl.Cobol.Compiler/Binding`
lists them), and `ParameterConformance`'s COBOL1688 text quotes the resolved item's declared name (`'A'`), which is the item's
name, not a node.
