# PB5394 - the ledger-publish mail is addressed to a fixed lane, not to the account the loop runs on

**Sites:** `scripts/orchestrator/orchestrate.ps1` (whole: the supervisor's ledger check after a unit sends the
"Ledger publish owed" message with `--to operator` for every account); `scripts/orchestrator/test_orchestrate_ledger.ps1` (whole: it reads `mailbox/to-operator` for the one account it runs and asserts nothing about the other);
`scripts/orchestrator/mailbox.py` (`account_lane`).

## What happened

An artifact belongs to the Claude account that published it (`ledger_state.py` keeps one URL per account). The
supervisor's check, after each unit, finds the publish owed and posts one `publish` message per stamp. The call names
`--to operator` whatever account the loop runs on. When the loop runs on account 1, the message reaches the operator
session, which runs the other account and cannot write account 1's artifact. The publish then waits until that session
reads the mail and forwards it. On 2026-11-12 at 12:04 PST the operator forwarded it to the Mythos session, which
published it. Nothing was lost, but the owner's status page stayed stale for that interval, and the forward is a manual
step nobody is told to make.

## Mechanism

The recipient is a literal in the supervisor; the test reads the same literal's directory. The one rule of which lane a
process belongs to already exists: `mailbox.account_lane` (the lane of the account a process runs under, the rule the
dispatch ledger also reads). The supervisor holds `$Account` and does not use that rule for the recipient.

## Fix direction

Address the message to the inbox of the session whose account the loop runs on, taken from `mailbox.account_lane`, so
the account-to-lane mapping lives in that one place and the supervisor names no lane literal. The test asserts the
recipient for both accounts: the message lands in `to-operator` when the loop runs on the operator's account and in
`to-mythos` when it runs on the other. The message body already names the account; keep it.
