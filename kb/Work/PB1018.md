**Rules** (`cite.py --check`): `OK §13.18.38.3 3)` "The first specification of data-name-2 shall be the name of either

own) and counts through `UniqueOrReportAmbiguous`; the result is `OccursSpec.ResolvedKeys`, read by SEARCH ALL and the
table SORT through `OdoModel.KeyItems`. `OdoModel.FindWithin` (first-wins) is deleted. SR3 was enforced by NOBODY — an
unknown key compiled clean — and is now COBOLNET2353, which also refuses a SUBSEQUENT key naming the table entry.

qualified subtree resolution. The SORT table SUBJECT (data-name-2) took the first same-named item with an OCCURS
clause (`SORT E OF G2` sorted G1's E) — the twin of the SEARCH identifier-1 defect, fixed there long ago and never
here; it now resolves through `ReferenceResolver.ResolveTableOperand`.

**Goldens.** `conformance:85/pb1018_occurs_key_qualified`, `conformance:2002/pb1018_table_sort_qualified_keys`,
`conformance:negative/pb1018-occurs-key-not-within-table` (COBOLNET2353, all editions). **Rows**: SR-14.9.37.3-8

# PB1018 — as filed

## Repro — measured
`scratchpad/reg12/q13_occkey.cob`: `05 E OCCURS 3 ASCENDING KEY IS K OF B INDEXED BY IX. 10 A. 15 K PIC 9. 10 B. 15 K
PIC 9.` then `SEARCH ALL E … WHEN K OF B (IX) = 2` → `error COBOLNET1965: SEARCH ALL 'E': 'KOFB(IX)' is not referenced
in the KEY phrase of the OCCURS clause associated with 'E' … The KEY phrase declares ASCENDING K.` The KEY phrase's
qualifier is gone, and SORT's table key (`SORT E ASCENDING K OF B`) and a SEARCH ALL that DID match would both key on
A's K — the first candidate (wrong order, silently).

## Code site
The OCCURS KEY capture (data binder) stores the bare word; `OdoModel.FindWithin` and `SortBinder`'s table-key path
resolve it to the first descendant with that name. Same root as PB978 (first-candidate resolution of an ambiguous
reference), different resolvers.

## What the fixer owes
Capture the KEY data-name WITH its qualifiers and resolve it through the one qualified-name resolver (ambiguity is a
diagnostic, never first-wins); re-verdict SR-14.9.37.3-8 with this golden.
