# PB6146 - repetition 0 of a multiple COLUMN clause is placed at a constant anchor seed, not at the live horizontal counter

Filed from the round-3 lead on the PB5624 branch (fix commits `bfe8e19067`, `122c06aa72`). The reviewer's reading, kept to its facts:

**Mechanism.** `ReportWriterEmitter.EmitAnchorSeeds` (`src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/ReportWriterEmitter.cs:312`) now writes every operand's
step anchor before any presence test, as the constant sum of all earlier operand widths, which assumes every earlier operand present. The `AnchorSeed`
arm (line 290) places repetition 0 at that seed instead of at the horizontal counter. When an earlier operand of the multiple COLUMN clause is absent in
repetition 0 (per-placement PRESENT WHEN), the later present operand prints at the hypothetical column, not at `__hc` + integer-2.

**Why wrong.** §2023:13.18.41.4 GR2b: an absent data item has the effect on processing "as though the entry were omitted from the description of the
report group". §2023:13.18.14.4 GR8: the position of the item's leftmost character is obtained by adding integer-2 to the current line's horizontal
counter, so an absent earlier item leaves the counter where it was. The emitter's own `EmitCompose` doc says the same (an absent item never advances the
horizontal counter). Before the PB5624 fix the `Columns[1..]` seed was written inside the guard from the live `__hc`, so this shape printed correctly:
the regression is new with the R2-1 fix.

**Fix shape** (reviewer): the seed must be written outside the operand's own presence guard but after the earlier operands' placements, and it must read
the live counter, not a constant sum. A golden: a multiple COLUMN clause whose first operand is absent in repetition 0 and whose second is present, the
expected position taken from GR8.

**Sites:** `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/ReportWriterEmitter.cs:312` (`ReportWriterEmitter.EmitAnchorSeeds`, `ReportWriterEmitter.EmitCompose`), `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/ReportWriterEmitter.cs:269` (`ReportWriterEmitter.EmitFieldPlacements`, the live seed rewrite)
