# PB3429 — COBOL1547 prints a qualified operand run together

Filed 2026-10-19 by the enqueue clerk. Grep of kb/Work for `COBOL1547` finds notes that use it as a repro (PB1226-PB1232,
PB1941, PB1592), none about the quoted text.

**Repro.** `01 C CONSTANT FOO OF X.` at `--std 2023` answers `'FOOOFX' — all operands of the compile-time arithmetic
expression shall be …`. The operand's tokens are joined with no spaces.

**Code site.** `src/WiseOwl.Cobol.Frontend/Expressions/CompileTimeExpressionEvaluator.cs:228` (`dref.GetText()`).
`WrittenSource.Of` is the existing reuse (it keeps the written spacing). Sweep the other diagnostics that quote a
`GetText()` of a multi-token context.

## Resolution (landed 2026-10-30, wave 20261769 group D)

Re-probe on the wave's build: `01 C CONSTANT AS FOO OF X.` answered `'FOOOFX'`. Every message of
`CompileTimeExpressionEvaluator` that quotes a multi-token operand now reads it through `WrittenSource.Of`: the
qualified-name arm, the primary-expression arm, the non-numeric literal arms (a figurative `ALL "X"` runs its tokens
together the same way), the boolean-operand arm, the shift-count arm and the cce bare-operand arm; the CONSTANT binder's
figurative-literal message did the same and reads `WrittenText` now. Witnesses: the refused program
`conformance-suite/cases/13.10-Constant/pb3429-constant-qualified-operand.cob` (`diagnostics.json`) and
`ConditionalCompilationDefineTests.QuotedOperand_KeepsItsWrittenSpacing` for the arithmetic, boolean and shift arms.

## Landing

- `src/WiseOwl.Cobol.Frontend/Expressions/CompileTimeExpressionEvaluator.cs#EvalArith` — every message that quotes a multi-token operand reads it through `WrittenSource.Of` (REUSE it; `GetText()` joins tokens with no spaces, `FOOOFX`). A new message that quotes a node is held to the same.
- `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.Constants.cs#BindConstantStringLiteral` — the figurative-constant refusal quotes through `DataBinder.WrittenText`; the trap was that the evaluator is not the only quoter of a constant entry's operand.

**Sites:** `src/WiseOwl.Cobol.Frontend/Expressions/CompileTimeExpressionEvaluator.cs` (`CompileTimeExpressionEvaluator.EvalArith`, `NonNumericOperand`, `BooleanLeaf`, `ShiftCount`, `EvalRelationOrBoolean`), `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.Constants.cs` (`DataBinder.BindConstantStringLiteral`, the figurative-constant refusal), `docs/rearchitecture/DESIGN-compile-time-expressions.md`
