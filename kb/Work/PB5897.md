# PB5897 - analysis: a literal argument outside a function's domain compiles; nobody has ruled whether it is refused at compile time

Filed from two lead bullets of the Mythos lane's rulings. Their words, unchanged:

- Batch 20 (the reader of the re-read of slice 1985-247): "a literal -1 for FACTORIAL or RANDOM is accepted, and the result is undefined
  (`§1989:A.2.2 AR4` and each function's own rule). Nobody has ruled whether a literal argument outside the domain
  is to be refused at compile time."
- Batch 21 (the reader of slice 248): "a negative or zero argument where 1985 makes the result undefined compiles. Nobody has
  ruled whether a literal outside the domain is refused at compile time (the slice-247 lead)."

The one citation of the leads, checked again here:
- `§1989:A.2.2 AR4`: "An arithmetic expression which will always result in an integer value must be specified"
  `OK  §1989:A.2.2 AR4  (2.2 ARGUMENTS**)  the text is in AR4`

**Not ruled.** Whether a literal argument outside a function's domain is to be refused at compile time, and for which functions: nobody has ruled it. No program was run by the clerk.

**Sites:** none named by the sources.

**Scope.** Edition 85 as the readers saw it; what the later editions require is not stated by the sources.
