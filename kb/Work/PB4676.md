# PB4676 — PERFORM Format 3: imperative-statement-1 sits inside the WHEN brace in the transcription, outside it in print

**What is wrong.** `specs/ISO_COBOL_2023.md` (Format 3 figure, `git grep -n "Format 3 (exception-checking)"`, about line 25774)
drew `imperative-statement-1` as the first line of the repeated `{ WHEN ... imperative-statement-2 } ...` brace, so a reader
of the markdown sees imperative-statement-1 repeat with each WHEN. The printed page (folio 682, PDF page 712, rendered with
`python scripts/render-spec-page.py 712` and read) prints `PERFORM [ WITH LOCATION ]` and `imperative-statement-1` on their
own lines, and the brace opens below them. `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolControlFlow.g4` (line 32 ff.)
already follows the printed page, so no behavior is affected.

**Risk.** Any extractor of format alternatives that reads the markdown (PB4614's coverage-point catalog) would inherit the
defect.

**Fix (landed with this note's filing).** The figure now prints imperative-statement-1 outside the brace, as the page does.
The change makes the transcription match print, so it is not a departure from the printed standard and the Addendum
(which records departures) takes no entry.
