# PB6105 - generate.py's "THE COMPLETENESS REPORT" paragraph describes the pre-PB6047 count

Re-verified on main ae1136f781. `conformance-suite/harness/generate.py` (docstring, line 38 onward) says the report is "per edition and per WITNESS KIND ... each inventory
row whose band holds the edition is counted once, under the first of these that holds", then lists six kinds: documented non-support, a suite test, a documented determination, a
signed derivation, only WiseOwl's own tests, no witness. `conformance-suite/harness/obligations.py:50` now defines `WITNESS` with ten kinds (`non-support`, `suite`,
`determination`, `derivation`, `accepted-uncleared`, `refusal-only`, and the rest), and a held edition (85, 2002) is counted on its own catalog by `obligations.classify`. CLAUDE.md rule 6
requires every doc except the DEVLOG to describe the current compiler.
