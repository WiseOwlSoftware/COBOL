# PB5702 - at --std 2002 a user-defined word whose last character is a special character of 2002 Annex C (MICRO SIGN U+00B5, MIDDLE DOT U+00B7 and others) is accepted, because 2002 is screened with the 2014 table

**Sites:**
- src/WiseOwl.Cobol.Editions/CobolCharacterRepertoire.cs#Violation
- `src/WiseOwl.Cobol.Editions/CobolCharacterRepertoire.Table.cs` (whole: the report names no member)

**Mechanism.** CobolCharacterRepertoire answers 2002 from the Edition2014 table (2023 Annex B with Annex E reversed); 2002 Annex C (TR 10176:2001) marks these characters special, and 8.1.2.1 GR4 forbids them first or last in a user-defined word.

**Inventory.** Rows claimed: `2002-GR-8.1.2.1-4`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`).**

- `§2002:8.1.2.1 GR4`: "Characters identified as special characters in Annex C shall not be written as the first or last character of a user-defined word" (`cite.py --check`: OK  §2002:8.1.2.1 GR4  (General rules)  the text is in GR4)
