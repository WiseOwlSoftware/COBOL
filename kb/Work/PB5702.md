## Landing (wave 20262163, group C)

Re-probed on the fix lane's build: `Xµ` at `--std 2002` was accepted; it is now COBOL2773 (the 2014 and 2023 builds still accept it, 2023 correctly).
Root cause: `CobolCharacterRepertoire.PositionOf` answered every edition below 2023 from the table derived from 2023's Annex B, so 2002's own Annex C.2
(TR 10176:2001, narrower, special characters barred first and last by §2002:8.1.2.1 GR4b) was never consulted. Fix: `gen_annex_bc.py` transcribes
2002 Annex C.2.1/C.2.2 and the combining rows of 2014 Annex B.3.1 (2002 labels none), `Edition2002` builds the anywhere / medial classes, and
`AnnexBCDriftTests.Edition2002Repertoire_IsAnnexC_WithSpecialAndCombiningMedial` holds it to the spec text. Closes row `2002-GR-8.1.2.1-4` (CONFORMS).

Open sibling (not fixed here, COBOL 2014 waits): 2014 is still the table derived from 2023 and disagrees with its own Annex B.3.1 / §2014:8.1.2.1 GR4b:
`Xµ` is accepted at `--std 2014` although µ (U+00B5) is a special character barred last, and the non-ASCII digits (U+0660 ...) are "not first" there but
permitted anywhere by 2014's Digits row. Code site: `CobolCharacterRepertoire.cs` (`Edition2014`).

## Landing (wave 20262165, group B): GR4c, the 2002 Annex D fold

Re-probe on the fix lane's build: `01 X<U+2160>Y` and `01 X<U+2170>Y` at `--std 2002` was COBOL1639 (one name); it is now two items
(output `UP  LO`), and still one name, COBOL1639, at 2014 and 2023. Root cause and fix shape are the addendum's
(`kb/Work/PB5702/2026-11-24-gr4c-fold-is-the-2014-table.md`): `gen_annex_bc.py` transcribes 2002 Annex D.2.1 and D.2.2 (600 pairs) into
`CobolNames.D2002Mappings`; `Fold(cp, 2002)` reads it through `Tables.Own` (an edition-keyed register, no inline year); `EditionSpelling`
writes a character the 2002 table folds differently as the 2002 key, and one 2002 leaves alone that 2023 folds as a private-use stand-in
(`Reserved`), so the one comparer answers for 2002. The character screen and the error strategy read such a word's written text
(`CobolWordRule.WrittenText`), so COBOL2773 still names the character the user wrote. Annex D prints (0256,0189) beside (0189,0256); transcribed as
printed, so U+0189 and U+0256 are two letters at 2002 (2014 Annex E.2 item 14 records the pair as deleted). Goldens:
`pb5702-annex-d-roman-numeral-is-not-folded-2002` (accepted at 2002) and `pb5702-annex-d-roman-numeral-is-folded-2014` (refused at 2014 and 2023, COBOL1639).
