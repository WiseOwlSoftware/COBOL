# PB4225 — a noise word is not an alternative

**Sites:** `src/WiseOwl.Cobol.Frontend/Parsing/AdmittedKinds.cs#Name`.

**Repro.** A `USAGE 5` data description at any edition draws COBOL5506 whose expected list includes `IS`. `IS` is an optional noise word after `USAGE`; the next token is what is expected, and `IS` there is not a usage.

**Fix direction.** Drop optional noise words from the expected-usage list built through `AdmittedKinds.Name`, by the structure that classifies a kind as noise (not a hand-kept exclusion list), and pin the list in the existing USAGE 5 goldens at every edition.
