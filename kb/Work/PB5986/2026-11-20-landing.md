# PB5986 addendum, 2026-11-20: the 1985 obsolete elements are flagged and documented

Re-probe at main 8244f1aa4b: `AUTHOR`, `MEMORY SIZE` and `ALTER` at `--std 85` compiled with no diagnostic (the note's claim held).

Mechanism: every 1985 obsolete element's registry row had `ObsoleteIn` null, so `StatusAt(85)` was `Available` and COBOL0903 never
fired. Setting `ObsoleteIn` to 85 alone is not enough: `ConstructRegistry.IsAvailable` was `StatusAt == Available`, so the sites that
ask "does this 1985 element exist" (STOP literal, segment-numbers, USE FOR DEBUGGING, WITH DEBUGGING MODE) would have read an
obsolete element as absent. The fix is the structure: `ConstructDialectStatus.IsInForceAt` (Available or Obsolete, §1985:I.1.5.2.3
"required to support obsolete language elements") is the one spelling of "in force" and `IsAvailable`, and the two directive-catalogue
readers use it.

What changed: 18 rows (every item of §1985:C.1 but 1 and 13; the segmentation item has two rows and the debug item three) carry `obsoleteIn: 85` and cite the item; the
two debugging rows moved from 2002 (the owner decision R61, GnuCOBOL's edge) to 85, which §1985:C.1 item 18 states. A USE FOR DEBUGGING
section made comment by a unit without WITH DEBUGGING MODE never reached a parse, so `DebuggingLineRewriter.Rewrite` now hands the
frontend the hidden section's header and the frontend reports it once through the registry's verdict (`OnHiddenDebuggingSection`).
`docs/manual/user-guide/editions.md` gains the table of the 18 items; `ObsoleteElementsDriftTests` holds it to the registry in
both directions. Item 1 (double character substitution) is documented as not arising; item 13 (ENTER) stays refused at every edition
(COBOL7240) and so carries no warning row (the version-matrix cell for the row would have to compile).

Not done: a conformance-suite golden. The suite's flagged-test shape needs a `rules:` id for §1985:I.1.5.2.3, and the 1985 catalog has
none (PB5924 is that hole); the drafted `pb5924-obsolete-warning-85` carries several marked sites where the suite allows one. The
version matrix's `ObsoleteConstruct_CompilesEverywhere_WarnsFromObsoleteEdition` now holds each of the 18 rows' 85 cell (compiles, and
warns COBOL0903).
