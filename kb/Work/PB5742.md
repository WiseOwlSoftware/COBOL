# PB5742 - at --std 2002 (and 2014) a relative READ PREVIOUS immediately after OPEN returns the first existing record with status 00, where the file position indicator rule makes a file whose lowest record is above RRN 1 at end with status 10

**Sites:** `src/WiseOwl.Cobol.Runtime/IO/RelativeConnector.cs` (`RelativeConnector.SelectSequentialSlot`, takes no edition); goldens `pb343_read_previous_relative_{2002,2014}` and `docs/VERSION_CHANGE_REFERENCE.md` row 29's SCOPE text pin the 2023 reading at every edition.

**Mechanism.** The relative twin of PB5639 (landed for INDEXED). After OPEN the file position indicator is 1 (the lowest relative record number); `§2002:14.8.29.3 GR18c.2`: "the first existing record in the physical file whose record number or key value is less than or equal to the file position indicator". So at 2002 and 2014 a relative file whose lowest record is RRN 2 or above is at end with '10' for a READ PREVIOUS that is the first operation after OPEN. 2023's relative block rule b) is direction-blind, so only the 2002/2014 arm differs. The compiler returns the first existing record at every edition.

**Repro.** A relative file holding records 2 and 4, OPEN INPUT, `READ file PREVIOUS` first: `cobol <prog>.cob --std 2002 --run` gives `P1=0002|00`; expected `P1=ATEND|10` at 2002 and 2014, unchanged at 2023. The indexed model of the fix is `IndexedConnector.SelectSequentialRecord` + `IndexedConnector.LowestKey` (PB5639).

**Direction.** Follow PB5639's arm: band the behaviour through `DialectBehavior`, correct the two goldens and row 29's SCOPE text, update FILES_DESIGN in the same change. Shares its root with PB5639 (landed).

**Landed (wave 20262158 E).** New behaviour `DialectBehavior.RelativeReadPreviousAfterOpenComparesFpi` (VCR row 7.123, active from 2023): `RelativeConnector.SelectSequentialSlot` seeks `LessOrEqual` the indicator for PREVIOUS at 2002 and 2014 (§2002:14.8.29.3 GR18c.2, §2014:14.9.29.3 GR19c.2), so the sparse file of `pb343_read_previous_relative_{2002,2014}` gives S1=ATEND|10; the 2023 copy keeps S1=EEEE|0005|00. A START's indicator names an existing record, so T1 is unchanged. Sequential files number records densely from 1, so they are unaffected. FILES_DESIGN and VCR row 29's SCOPE are corrected. **Sites:** also `src/WiseOwl.Cobol.Runtime/Control/DialectBehavior.cs` (`DialectBehavior.RelativeReadPreviousAfterOpenComparesFpi`).
