# PB5645 - at --std 2002 REWRITE (and WRITE) FROM a user-defined function is refused COBOL1914 by the 2023 rule that bans any function

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/MoveBinder.cs#BindFromPhrase` (COBOL1914)

**Mechanism.** MoveBinder.BindFromPhrase raises FromPhraseFunctionClass citing §2023:14.9.35.3 SR9 ('If identifier-1 references a function ...'). 2002 SR9 limits only an intrinsic function sender, so a user-defined function returning a numeric item is a legal 2002 FROM operand (a valid MOVE).

**Inventory.** Rows claimed: `2002-GR-14.8.33.3-6`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:14.8.33.2 SR9`: "If identifier-1 references an intrinsic function and the FILE phrase is not specified, ide"
- `§2002:14.8.33.2 SR6`: "identifier-1 or literal-1 shall be valid as a sending operand in a MOVE statement specifyi"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p3/r01_rewrite_from_user_numeric_function.cob); the text is inline. Command: `cobol.exe p3/r01_rewrite_from_user_numeric_function.cob --std 2002 --run`
