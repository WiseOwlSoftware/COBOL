# PB4027 — the unresolved-root bound is a count, not the two named sites

**Sites:** `tests/WiseOwl.Cobol.Tests.Unit/TrackedTreeScopeDriftTests.cs:413` (the reach bound `unresolved <= RunTimeRoots`).

**What.** The drift test caps the roots it cannot resolve at `RunTimeRoots` (two), and every statement of the rule (the DEVLOG,
DESIGN-test-build-ci.md tier 0d, PB3814, the assert message) says the two admitted are `RunDirectoryState`'s run-time
directories. The code compares counts only, so any two other unresolved roots pass.

**Failure scenario.** A new listing rooted at a path the reader cannot resolve is admitted as long as only one other is
unresolved, and the walk it does goes unjudged.

**Fix shape.** Compare the unresolved set with the named two sites (by file and member) and fail on any other; the assert
message then names the unexpected root.
