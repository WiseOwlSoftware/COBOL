## Finding — `function-identifier` (crashes; rows `SR-8.4.3.2.3-12`)

**Mechanism.** SR12 has no screen anywhere, and the numeric-admitting string-argument renderer (IntrinsicRenderer.StrArgVisitor, admitNumeric) renders a nested NUMERIC or INTEGER intrinsic as a LoudValue. So FUNCTION CONCAT / BASECONVERT over a nested integer function compiles clean and aborts at run time, both for the SR12-barred INTEGER form and for the SR12-exempt ABS form.

**Repro.** out/probe/function-identifier/r1_sr12_concat_int.cob: MOVE FUNCTION CONCAT(FUNCTION INTEGER(3) 'A') TO W -> compiles, run -> NotImplementedCobolFeatureException 'intrinsic string argument BoundComputedOperand'. r2_sr12_concat_abs.cob: CONCAT(FUNCTION ABS(3) 'A') -> same crash. r3_sr12_base_int.cob: BASECONVERT(FUNCTION INTEGER(10) 10 16) -> same crash.

**Expected from the spec.** §8.4.3.2.3 SR12: an integer function other than the integer form of ABS shall not be specified where an unsigned integer is required, and §15.18.3 r3 requires a numeric CONCAT argument to be an unsigned integer. So r1 and r3 are COMPILE-TIME errors, and r2 (ABS, exempt) is legal and yields W = '3A' (the §15.18.4 concatenation of the integer image and 'A').

**Observed / reasoning.** StrArgVisitor.Visit(BoundComputedOperand) renders only nested intrinsics whose ResultCategory is Alphanumeric, National or Boolean, and every other case (numeric or integer functions) becomes Loud(n). The binder admits the argument (class numeric is in CONCAT's list), so the failure surfaces at the wrong stage: the PB25 wrong-stage family, on an unowned shape. Two fixes are needed together: an SR12 screen at the unsigned-integer argument positions (sharing IntrinsicArgumentRules' type-based SR11 arm), and a numeric-function arm in StrArgVisitor for the legal ABS case.

**Code site.** src/Cobol.Net.Compiler/CodeGen/Emit/IntrinsicRenderer.cs#StrArgVisitor.Visit(BoundComputedOperand); src/Cobol.Net.Compiler/Binding/IntrinsicArgumentRules.cs (no SR12 arm)

That is a separate lead (see findings), and SR11's own outcome is correct there. || REFUTED: PARTIAL — The screen is sound where the argument table marks an integer slot (i). It fires for MOD (both arguments), FACTORIAL, CHAR, CHAR-NATIONAL, DAY-OF-INTEGER, INTEGER-OF-DAY, TEST-DAY-YYYYDDD, TEST-DATE-YYYYMMDD, YEAR-TO-YYYY (both), FORMATTED-DATE argument-2, PERFORM TIMES, and a user function with a PIC 9V9 RETURNING. Add the SR12 arm to IntrinsicArgumentRules, derive integer positions from the §15 argument rules (RANDOM 15.75.3 r2), and give StrArgVisitor a real rendering for the SR12-exempt integer ABS form (or refuse at bind time) — no LoudValue reachable from legal source.
