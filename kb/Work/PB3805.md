# PB3805 — three doc claims that do not match their subject

**Sites:** `docs/DOC_INDEX.md` (the impact-map row, line 164), `tests/Cobol.Net.Tests.Unit/ImpactMapLaneDriftTests.cs#RetiredWording`, `docs/COBOLNET_OO_DESIGN.md` (GR7 c) closing sentence, line 702), `tests/Cobol.Net.Tests.Unit/LandingLaneDriftTests.cs` (the class summary, line 12)

## Measured

1. **DOC_INDEX impact-map row** still says "The map ORDERS a whole-population gate and never selects it", the pre-PB2515
   claim PB3663's bar 5 retires and that DESIGN-test-build-ci.md section 3.13 now contradicts (the map's tiers decide what
   leg 1 runs locally). `ImpactMapLaneDriftTests`'s `RetiredWording` regex does not cover the phrasing, so nothing holds
   it out. A reader concludes a missing or stale map cannot leave a reached test out of the local run, the CI-invariant gap
   PB3666's bounce shows. Fix: restate as section 3.13 does (the map orders the plan and never filters a leg; under batched
   gating its tiers decide what leg 1 holds) and add the phrase to `RetiredWording`.
2. **OO design GR7 c)** says the ACTIVE-CLASS returning arm proceeds unchecked, but omits that delivery can still end in
   `CobolImplementorFatalException`: `CobolObject.NarrowUniversal` (CobolObject.cs:141-142) throws it when the returned
   object is not of the receiving item class and checking is off. Scenario: universal INVOKE (no EC-OO-UNIVERSAL
   checking) of a method whose RETURNING item is ACTIVE-CLASS, on an object of class B, into a receiving item USAGE OBJECT
   REFERENCE A (A unrelated to B): the match admits it, the method runs, then `NarrowUniversal<A>` throws. Fix: say the
   returning arm proceeds into the method and its delivery takes the exception, while the formal arm proceeds without any
   stop. (Re-derive against the spec and the code before writing; this clerk did not judge the semantics.)
3. **LandingLaneDriftTests class summary** (the rule `drift_rules.py` prints for orchestrate.ps1 and enqueue.md) says only
   "called in Invoke-Unit", dropping "as each unit starts and on a period while it runs" that the test asserts as >= 2
   line-start `Step-Lane` calls (lines 149-151), and its enqueue.md clause omits that step 3 must name
   `land_lane.py rearm` (line 174): the same printed-rule-shorter-than-test mechanism PB3709 fixes. Fix: "called in
   Invoke-Unit as the unit starts and every -LandLaneSeconds" and "enqueue.md step 3 reads land_lane.py status, names
   land_lane.py rearm and lands nothing", under the 400-character cut.

## Acceptance

- Each of the three statements matches its subject; the DOC_INDEX phrase is held out by `RetiredWording`.
- Sweep: other doc rows or summaries that restate a drift test's rule are compared against their test (result reported).
