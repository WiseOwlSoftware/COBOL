# PB3602 — re-derive the provisional pre-2023 edges

## Why

Many `constructs.json` rows carry a pre-2023 edge derived from Annex E's silence ("zero Annex E hits => predates
2023") under "ratified decision #1", and say so ("provisional", "derived, not quoted"). Annex E covers only the
2014→2023 delta, so that silence cannot separate 2002 from 2014 from 1985 ([[PB296]]). The research proved the point
twice: `constant-record-2002` should be 2014 ([[PB3600]]) and `usage-pointer-to-type-2014` should be 2002
([[PB3601]]).

## Population

A mechanical count on origin/main 2026-10-23: 269 rows in `tests/version-matrix/constructs.json`; 45 of them carry
the word "provisional" or the phrase "derived, not quoted" in some field (65 matching lines: 35 lines say
"provisional", 27 say "derived, not quoted", some say both). Examples the report names: `constant-entry-2002`, the
`>>DEFINE` and `>>IF` rows, and the REPLACE stacking row. Re-run the count at the start of the sweep:

```
python -c "import json,re; d=json.load(open('tests/version-matrix/constructs.json',encoding='utf8')); r=d if isinstance(d,list) else next(v for v in d.values() if isinstance(v,list)); print(len([x for x in r if re.search('provisional|derived, not quoted',json.dumps(x),re.I)]))"
```

## Lane

A read-only Opus adjudication sweep (`cobol-adjudicator`), about 25 rows per agent, so two agents. Each row gets one
verdict (edge confirmed, edge moves to N, or not derivable from P1-P3) with the sentence quoted from its source and
labelled P1, P2 or P3; every 2023 clause quoted goes through `cite.py --check`. Each moved edge is re-filed as an
edition-gate defect in the shape of [[PB3600]]. The note holds no inventory row and closes when every row has a
verdict.
