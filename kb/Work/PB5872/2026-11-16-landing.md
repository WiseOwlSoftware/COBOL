**One point of the decided shape changed (rule 5).** Point 1 put the stage "before the gate waits for a slot". Its cases
are compiled tests, so they need the build, and the build is what the slot rations (DESIGN-test-build-ci.md section 3.14.6, the commit admission of
PB5697): a preflight before the slot would build outside the cap. It runs inside the slot, after the build. It saves
the population's test phase, never the slot wait. Point 4's mechanism is the population check's own composition of
trx files (`check`'s union, the RAN TWICE rule), not the per-target carry: the preflight's cases ran in THIS gate, so they
are counted as ran, never as carried, and the growth sample (which skips a gate that carried) still records.

**The branch review (round 1) and its hunt.**
- R1-1, a false green: `PassCarry.carry` took its RED HOSTS (a host whose red its cases do not explain reruns its whole
  assembly, PB5099) only from the record's population `runs`, while it carried the preflight's trx as passes. So a
  preflight host red with every case Passed was carried as green by a re-gate at the same keys. Fixed: the record's
  `preflight.runs` holds each preflight host's run with its file stem, `carry` reads them, `red_explained` reads a host
  by its stem, and an assembly among the red hosts runs its preflight again. Arm `case_06` of `test_preflight.py`: GREEN
  with `2 carried from run(s) …` before the fix, RED after.
- Three arms for a preflight host that crashes, exits 0 with no trx, or exits 0 with a case short: each RED, nothing
  recorded (`case_07`).
- The population's retry file is now written on every gate whose preflight ran, and the host selects by exact display
  name. A listed name could differ from its display name: `parse_listing` split a listing with `str.splitlines`, which
  breaks a line at U+0085, U+2028, U+2029, `\v`, `\f` and U+001C-U+001E where .NET's `ReadAllLines` does not. So one
  display name holding one of them would have been listed as a wrong name that never runs (shown with the old parser on
  `N.T.M(text: "a<U+2028>b<U+0085>c<FF>d")`). Fixed at its one function: a listing line breaks where a retry-file line
  does, and a name holding a carriage return is refused, named (`test_population.py --self-test`). Run 000002 wrote 68,819
  names to retry files (8 truncated, 380 non-ASCII, 31,476 with quotes, 2,224 with backslashes), and every population was
  EXACT; none held such a break today.
