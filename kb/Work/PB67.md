### ⚖ ANSWERED 2026-08-31 — status owner -> landed

The bare question is closed by [[PB198]] (owner protocol 2026-08-30; survey unanimous): **ARITHMETIC IS
STANDARD-BINARY is declined**, so a rule conditioned solely on that mode is unreachable and carries
DOCUMENTED-NON-SUPPORT. The four rows this note named — RV-15.27.3-2, RV-15.73.3-2, AR-15.43.3-3, AR-15.58.3-3 —
are among the **sixteen** stamped from that ONE determination by a DERIVED predicate, not by a hand list.

⛔ **The ground is not the one this note assumed.** It read the decline off "spec-obsolete per §8.8.1.4.1
NOTE 1". Obsolescence licenses nothing — Annex F.2 says a conforming implementation "shall support obsolete
language elements except for elements that are also optional or processor-dependent". The licence is A.3 item 2
plus §4.2.6. See PB198.
