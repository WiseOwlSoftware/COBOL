**Wave kind:** defect-for-fix-lane. Found by the wave-1042 group G implementer (PB2616) and filed by the train 1042b lander.

**Sites:**
- `src/Cobol.Net.Runtime/Values/Tables/CobolTable.cs:58` (the EC-BOUND-SUBSCRIPT detail text)
- `src/Cobol.Net.Runtime/Values/Tables/CobolTable.cs:130-142` (CobolTable.Occ / OccScaled: an out-of-long occurrence number saturates to `long.MaxValue` so §8.4.2.3.4 GR2's out-of-range condition survives)

**Rule:** §8.4.2.3.4 GR2 (a subscript outside 1..the maximum occurrences sets EC-BOUND-SUBSCRIPT). The condition IS raised correctly; only the diagnostic wording is wrong.

**Scenario (implementer's repro `E:\COBOL-coord\scratch\w1042g\p4.cob`, not re-measured by the lander):** `01 A PIC 9(21) VALUE 100000000000000000001.` and `MOVE EL2(A) TO …` raises EC-BOUND-SUBSCRIPT, and its detail names the subscript value 9223372036854775807 (the saturated long) where the item's value 100000000000000000001 is what the program holds. A user reading the message is sent looking for a value the program never computed.

**Fix direction:** carry the saturation as a flag (or format the original image/Int128) into the detail text rather than the clamped long.
