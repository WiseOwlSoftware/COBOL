# PB4386 - the landing lane never passes --lane, so an unreviewed-lane branch cannot be re-landed by it

**Sites:** `scripts/orchestrator/land_lane.py:1069` (`launch`, the default argv `enqueue.py land <branch> --worktree <wt>`; `candidates`, which chooses the branches; `rearm`, `rearms`, which record the re-arms and carry no lane), `scripts/orchestrator/enqueue.py:243` (`UNREVIEWED_LANES`; `review_gate`, which refuses with exit 11 for a branch with no fix-lane report; `land`, where `--lane` is first given and used), and the survey's reading of exit 11 as a finisher's STOPPED (`classify` in `scripts/orchestrator/land_lane.py`).

**Read at:** origin/main 4aff86e01.

The branches of the lanes MANDATORY-PRACTICES I10 does not review (clerk, registrar, golden: `UNREVIEWED_LANES`) write no fix-lane report, so `review_gate` finds none and the landing needs `enqueue.py land <branch> --lane <lane>` (L9). The lane records a branch's re-arm and relaunches it with the argv `launch` builds, which has no `--lane`. The first landing by hand with `--lane` works; a relaunch by the lane does not.

Evidence: `notes-pb4354-leads` (PR #968) was removed from the merge queue by hand at 2026-11-01T10:19:47Z during the PB4353 red and re-armed at 7efcfa6cc8a0. Land-lane attempt `000532-20261101T110405Z` (`E:\COBOL-coord\land-lane\attempts\000532-20261101T110405Z-notes-pb4354-leads.json`, argv without `--lane`) ended rc 11 UNREVIEWED ("no fix-lane report ... names notes-pb4354-leads"), which the survey reads as STOPPED, a finisher's stop. The enqueue unit then ran `enqueue.py land notes-pb4354-leads --lane clerk` by hand (ENQUEUED #968 at 6a76efa8).

Fix direction: the lane learns a branch's lane where `enqueue.py land --lane` first records it, stores it with the re-arm, and `launch` passes `--lane <lane>` on every relaunch; the survey stops classing an unreviewed-lane branch's UNREVIEWED as a finisher's STOPPED. A drift test pins that `launch`'s argv carries the recorded lane (one place, no hand list of lanes).

Related: PB3103 (landing a branch the moment it is ready, landed), PB3636. Grepped `kb/Work` for `--lane` and `UNREVIEWED_LANES`: no open note covers the relaunch.
