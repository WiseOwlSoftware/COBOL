# PB5844 - RECORD DELIMITER accepted on a fixed-length file, and any word accepted as its implementor-name (every edition)

**Ruling: UPHELD (b), harm under_rejects, with a decision.** Four of the six rows of `§1985:VII.2.8` are contradicted: `1985-SR-VII.2.8.3-1`, `1985-FMT-VII.2.8.2`, `1985-GR-VII.2.8.4-3` and `1985-GR-VII.2.8.4-5` (mechanism 1 of the ruling). The other two, `1985-GR-VII.2.8.4-2` and `1985-SR-VII.2.8.3-2`, are confirmed (mechanism 2, REJECTED: the STANDARD-1 arm is a hardware element the implementation does not claim, which 1985 lets it decline). The checker's confidence: high for GR2 and SR2 REJECTED and for SR1 UPHELD-b; the question of FMT, GR3 and GR5 is genuinely open, and the decision below settles it. Cause (b): the same programs compile the same way at `--std 2023`.

**What happens (the ruling's table, copied).** RECORD DELIMITER. The clause on a fixed-length file compiles with a warning only, and ANY word is taken as its implementor-name (`RECORD DELIMITER IS F1`, the file's own name, compiles) though the implementation defines none. The register states the absence of reel devices citing the 2023 text only: a 1985 sentence is owed (carried by this note).

**Mechanism 1, decided (the ruling's paragraph, unchanged).** Three things are true of the 1985 text. `§1985:VII.2.8.3 SR1` says the clause "may be specified only for variable length records" (cite.py OK): a clause on a fixed-length file is a refusal, whatever
else is decided. The format admits STANDARD-1 or an implementor-name, and `§1985:VII.2.8.4 GR3` makes the method
"that associated with implementor-name-1 by the implementor" (cite.py OK): a word the implementor associates with
no method is not an implementor-name, and accepting it with a warning is accepting source the format does not
print. And STANDARD-1 is a hardware element: `§1985:I.1.5.2.5.1` says "Language elements that pertain to specific
hardware components for which support is not claimed need not be implemented" (cite.py OK), which covers the
STANDARD-1 arm and nothing else of the clause.
The checker left open whether the set of implementor-names may be empty. I decide the shape that is right under
either reading, and it is small: the implementation DEFINES ONE implementor-name for the framing its variable-length
record sequential files already use, the clause with it selects that method (it is the only one, so the file
behaves as it does today), EVERY OTHER WORD is refused, and the clause on a fixed-length file is refused. STANDARD-1
stays a documented decline. Which word names the method is the implementor's: by CLAUDE.md rule 1 the fix looks at
the implementor-names GnuCOBOL defines for this clause first (not read here) and takes one that means this framing,
or defines its own. A 1985 entry in the register states all of it.

**The 1985 register entry is owed with the fix, and by whom: the fix.** The entry states that STANDARD-1 is not implemented because no reel device is supported, the implementor-name set and its method, and that SR1 is enforced (the checker's list of what the entry must say, with `docs/conformance/2/26.md` and `docs/conformance/7/DOC-A.1-150.md`, which cite only the 2023 text today).

**The checker's evidence (rulings.json, copied).**
- `1985-GR-VII.2.8.4-2`: REJECTED (conforms as documented non-support): the STANDARD-1 method is the one element listed as hardware dependent (reel device); `docs/conformance/2/26.md` specifies it (no reel device) but cites only the 2023 text: a documentation defect, not a behaviour defect.
- `1985-SR-VII.2.8.3-2`: REJECTED (conforms as documented non-support), same ground as GR2: the medium (magnetic tape) does not exist on this implementation, so every STANDARD-1 use is a use of the exempted element, and it is diagnosed by name (COBOL1778). 1985 asks no compile-time warning for a hardware element; the warning is more than 1985 requires.
- `1985-SR-VII.2.8.3-1`: UPHELD-b, under_rejects, WHATEVER is decided for the arms: SR1 is a syntax rule decidable from the source whenever the FD has a Format 1 RECORD clause (`§1985:VII.3.8.4 GR3`: "Format 1 is used to specify fixed length records", cite.py OK); the hardware exemption reaches only the STANDARD-1 phrase, not the clause's placement rule and not the implementor-name arm. Probes `rdfix.cob` (implementor-name arm) and `rdfixs.cob` (STANDARD-1 arm) on a `RECORD CONTAINS 10 CHARACTERS` file compile and run with warning COBOL1778 only, at 85 and 2023. With no RECORD clause or a Format 3 the record type is the implementor's, so the check reaches exactly the Format 1 file (and any file the implementor's determination in `docs/conformance/7/DOC-A.1-151.md` makes fixed).
- `1985-FMT-VII.2.8.2`: OPEN-READING: the brace admits STANDARD-1 or an implementor-name-1; the compiler takes ANY word, even the file's own name `F1` (`rdown.cob`) or `FOOBAR` (`rdfoo.cob`), with no lookup.
- `1985-GR-VII.2.8.4-3`: OPEN-READING.
- `1985-GR-VII.2.8.4-5`: OPEN-READING, follows GR3: for the STANDARD-1 arm the delimiter in force after OPEN is the documented decline; for the implementor-name arm it is whatever GR3 is ruled.

**The readings the checker records (the decision above chose between them; copied).** The clause is level 2 SEQ (the 1985 summary table lists it `2 SEQ`), and `§1985:I.1.5.2.2` requires the syntax and function of every element of a claimed level. The 2023 licence the register uses for the implementor-name arm (Annex A.1 item 150 "Optional", `docs/conformance/7/DOC-A.1-150.md`) has no 1985 counterpart; 1985 says only that the formation of an implementor-name (`§1985:C.2` item 53) and the method associated with it (item 55) are the implementor's.
- READING A (an implementor may define the implementor-name set as empty): then GR3 and GR5's implementor-name arm are vacuous and CONFORM, but every word written there is NOT an implementor-name, so accepting it is a nonstandard extension that `§1985:I.1.5.2.5.2` requires to be documented as one and flagged; COBOL1778 flags it, and DOC-A.1-150 documents the acceptance, so FMT conforms only if a 1985 register entry calls the acceptance an extension (cost: a register entry, no code).
- READING B (`§1985:I.1.5.2.2`: a claimed level 2 SEQ element must have its function, so at least one implementor-name must exist): GR3 and GR5 are NOT-IMPLEMENTED and FMT under-rejects any word outside the defined set (cost: define one or more implementor-names, each associated with the existing 4-byte length-prefix method, so GR3 and GR5 hold with no runtime change; refuse any other word in `FileControlBinder.BindFileControl`; a register entry; the same at 2023 where defining a feature-name is optional but allowed).
- READING B's fix also satisfies reading A, so it settles the family under both readings at small cost; reading A's costs nothing but leaves `RECORD DELIMITER IS F1` compiling. Either way SR1 is a separate check that is owed.

(The ruling's file records two readings, A and B, and SR1 as the separate check; it does not number a third.)
