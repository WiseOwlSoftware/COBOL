# PB5632 - the 85 numeric-function-as-identifier refusal is pinned at one door of several

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/ExpressionBinder.cs:1190` (`ExpressionBinder.BindArithmeticStatementOperand`)
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ControlFlowBinder.PerformVarying.cs:189` (`ControlFlowBinder.BindVaryingOperand`)
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/IntrinsicBinder.cs` (`IntrinsicBinder.ScreenIdentifierPlacement`, `IntrinsicBinder.IntrinsicOperand`)
- `conformance-suite/cases/15.2-Types-of-functions/pb5108-numeric-function-as-identifier-85.cob` (whole: the refusal golden)
- `conformance-suite/cases/15.2-Types-of-functions/pb5108_numeric_function_as_identifier.cob` (whole: the DERIVATION comment)

**Gap.** kb/Work PB5108 (landed) refuses a numeric function written as an identifier operand at `--std 85` through
`IntrinsicBinder.ScreenIdentifierPlacement`. The golden pins the MOVE door (`IntrinsicOperand`) and, per the report, ADD,
SUBTRACT, MULTIPLY, DIVIDE and PERFORM TIMES/VARYING; the review found the second door,
`BindArithmeticStatementOperand` (ADD, SUBTRACT, MULTIPLY, DIVIDE sending and GIVING operands), and `BindVaryingOperand`
(PERFORM VARYING FROM and BY) with no 85 refusal test, and DISPLAY, GO TO DEPENDING, WRITE ADVANCING and INITIALIZE
REPLACING were probed by hand only. Deleting any one door's call leaves the gate green. Add one refusal case per door
(a diagnostics JSON per verb is enough), driven from the list of call sites of `ScreenIdentifierPlacement` so a new door
without a test fails a drift test.

**Wrong comment.** The accepting golden's DERIVATION says N = 2 at the start, but N is declared `VALUE 7` (line 34); N
becomes 2 only after the first `MOVE FUNCTION SQRT (4) TO N`. Correct the comment.

**Double report (info).** A numeric function as an INSPECT, STRING or CANCEL operand now draws the PB5108 COBOL0900 at 85
beside COBOL0847, COBOL1626 or COBOL1696, which those statements give at every edition. Harmless (same root as PB5108); pin
the order of the two verdicts in the same tests.
