What this adds to the parity record:
- **Row D, the Linux self-tests.** A self-test rule that reads the TRACE of a run sees whatever OS-specific shape the
  tracer gives it. A rule built on the trace has its first Linux run in the merge group unless the change is proved
  under WSL. The PB5227 fix was proved there before it went back to the queue: the whole Linux phase GREEN, 152 ran, 0
  UNKEYED.

  host fast enough to make two edits in one second. The cure is in the fixture (`self_tests.py` `_rewrite` drops the
  bytecode), never a slower runner.
