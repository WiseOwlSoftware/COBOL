# PB5862 - `ArchOracleDriftTests.AnObservation_IsPortable_AndRepeatable` fails without a regression: two observations of one case disagree

Source: the report of wave 20262075a (kb/Work PB5851), `E:/COBOL-coord/scratch/reports/w20262075a-PB5851-report.md`, its Gate section and its "New defects" section; observed by that implementer on Monday 2026-11-16 between 06:02 and 06:14 PST in the worktree of branch `worktree-agent-a7ef6681efccf46e7`, after it merged the main that carries kb/Work PB4333 (pull request 1782). kind: defect. process_only: true. No harm flag. Severity: MAJOR is the filer's to weigh: the test is in every code gate since PB4333 landed, and a red of it costs a whole gate run. area: tests/gate. related: PB4333, PB5851.

## What was observed
Gate run `000001-20261116T140220Z` of that worktree was RED on ONE case, outside the branch's diff: `tests/WiseOwl.Cobol.Tests.Conformance/ArchOracleDriftTests.cs#AnObservation_IsPortable_AndRepeatable`. The test observes one case twice and requires the two observations to agree. The first `Observe` came back `Program = ambient` and the second came back a digest. The implementer ran the test alone: it failed once more, then passed three runs in a row with no change to the tree, and it passed in the second gate (`000002-20261116T141427Z`, GREEN at 098a8ce673df37b6347a8d2e2cbbc3e92ea43e7f, no commit between the two gates).

## What is known of the cause (the implementer's reading, not proven)
`ArchOracle.Ambient` reads the compile's `CompilationInputs`: an observation is `ambient` when the compile read an input outside its scratch directory. With a debug dump of `CompilationInputs` the implementer saw the compiles read the worktree's `.cache/compiled-programs/src/...` copy. Its candidate: the gate fills that store while the test hosts run, so whether a compile of this test reads from it depends on what another host has written by then.

## Why it matters
CLAUDE.md: a flake is a kb/Work defect fixed at its root, never retried inside the run. This one cost the gate lane one full run within an hour of PB4333 reaching main, on the first branch that gated after merging it, and it will recur on any host where the store is being filled while the test runs.

## What a fix must decide (not decided here)
- Whether a read of the compiled-program store is an ambient input (then the test's two observations must be made under one state of the store: its own store, or none) or is not one (then `CompilationInputs` must not record it).
- That the test asserts a property of the oracle and not of the timing of another test host: MANDATORY-PRACTICES' rule against a test that can fail with no regression.
- Whether the differential itself is exposed: a case observed `ambient` is "never carried" (the operator's notice of 2026-11-16 05:25), so a compile that is ambient only sometimes is carried only sometimes, which costs time and is not a wrong verdict; say whether that is all it costs.
