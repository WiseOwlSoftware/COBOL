## Measured
```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. B14SN.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 X PIC 9(31) VALUE 1000000000000000000000000000000.
       01 R PIC S9V9(8).
       PROCEDURE DIVISION.
           COMPUTE R = FUNCTION SIN(X)
           DISPLAY "SIN=" R
           STOP RUN.
```

prints **`SIN=00093314F`** (+0.00933146). The exact value, computed with 120-digit decimal reduction mod 2π:
`sin(10^30) = -0.0901169019…`; `sin(1000000000000000019884624838656) = +0.0093314689…` — the compiler answered the
second.
```cobol

           STOP RUN.
```

→ `abnormal run-unit termination: EC-ARGUMENT-FUNCTION (fatal): floating-point intrinsic argument out of domain (NaN
result)`: the SDIDI argument narrows to +Infinity and sin(inf) is NaN.
