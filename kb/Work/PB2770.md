**Rule it breaks:** R43 (unsupported means unsupported: an implemented construct is never called unsupported) and the DEVLOG 232 precedent that deleted the sibling text-keyed hints COBOL0104-0106/0108-0109; the structural hints 0a-0f of the same method read the ATN, never a word's spelling. No ISO clause governs diagnostic wording.

**Why process_only:** Every measured trigger is an ILLEGAL program (MOVE 1 SET X TO 2 lacks TO; SEARCH ALL E END-SEARCH lacks WHEN; EVALUATE X ALSO ALSO X). No legal source is rejected and no answer changes; the harm is that the winning diagnostic states a false limitation of the compiler (R43 unsupported-means-unsupported) or a false structural claim, sending the user after a cause that does not exist. That is the PB906 family, which carries process_only: true.

**Scenario:** Measured on the pin (8be230068, free form). 'MOVE 1 SET X TO 2' answers COBOL0102 'This SET form may not be supported. Supported forms: SET identifier TO value, SET condition TO TRUE/FALSE, SET index UP/DOWN BY integer.' The user's error is MOVE's missing TO, and setStatement implements every ISO SET format, not three. 'MOVE 1 SEARCH E WHEN ...' answers COBOL0103 'SEARCH statement may not be fully supported.' 'EVALUATE X ALSO ALSO X ...' answers COBOL0107 'EVALUATE with ALSO (multi-subject) may not be fully supported.' Hint 9 (COBOL0101) says BLANK WHEN ZERO 'may not be recognized'. 'SEARCH ALL E END-SEARCH' answers COBOL0306 'END-SEARCH appears without a matching SEARCH statement.', and the same text without ALL gives a plain COBOL0001, because IsInMatchingRule builds the rule name from the END- word's spelling (stmt.ToLowerInvariant() + "Statement"), so searchAllStatement (a sibling rule) never matches and END-OF-PAGE looks for 'of-pageStatement'. Hint 19 compares token TEXT to 'FILE_CONTROL', the token's symbolic name, so that exclusion never fires. Each of these hints has priority 5-15 and wins the message.

**Reproduction:** cobol.exe at 8be230068, --source-format free: 'MOVE 1 SET X TO 2' -> COBOL0102 'This SET form may not be supported. Supported forms: SET identifier TO value, SET condition TO TRUE/FALSE, SET index UP/DOWN BY integer.'; 'MOVE 1 SEARCH E WHEN E(I) = 1 DISPLAY 1 END-SEARCH' -> COBOL0103 'SEARCH statement may not be fully supported.'; 'SEARCH ALL E END-SEARCH' -> COBOL0306 'END-SEARCH appears without a matching SEARCH statement.'
