# PB5779 - 1985-GR-XIII.4.5.4-9: OPEN WITH NO REWIND on this implementation completes with I-O status 07, the rule's condition (a medium that permits rewinding) is not met, and no program can witness it; a 1985 entry in the conformance register is owed before the row closes

**Decision (the Mythos lane, 2026-11-15): the refused fix of wave 4 was right. `1985-GR-XIII.4.5.4-9` has no witness on this implementation; the compiler's status 07 conforms; no golden and no defect.**

**The disagreement** (`E:/COBOL-coord/scratch/gl1985/lane1/reports/g1985-xiii-4-5-open.refute.json` and `.fix.json`). The writer called the row not closable. The refuter wanted a golden that expects I-O status 00 for `OPEN OUTPUT ... WITH NO REWIND` on a disk report file, and a defect because the compiler gives 07. The fixer refused both.

**The text (each citation checked again with `python scripts/spec/cite.py --check`, verdict OK).**
- `§1985:XIII.4.5.4 GR9` begins "If the storage medium for the file permits rewinding, the following rules apply"
  `OK  §1985:XIII.4.5.4 GR9  (4.5.4 General Rules)  the text is in GR9`
- `§1985:VII.1.3.5` defines status 07, a successful completion: "for an OPEN statement with the NO REWIND phrase, the referenced file is on a non-reel/unit medium"
  `OK  §1985:VII.1.3.5  (1.3.5 I-O Status)  the text is in the clause; it lies in GRL2.1d`
- Which media permit rewinding is the hardware's and the implementor's to say; the fixer cites `§1985:C.3` for that. (The adjudication file gives no quoted text for C.3, so no `cite.py --check` line was run for it; it is the fixer's pointer, not re-checked.)

**Decision.** The fixer is right. WiseOwl's files are on a medium it classes as non-reel/unit, so GR9's condition is not met, its two sub-rules do not apply, and an OPEN with NO REWIND completes with 07 as `§1985:VII.1.3.5` says. There is nothing for a program to observe of GR9 here, so the row gets no golden, and 07 is no defect. The refuter's sentence from the CLOSE preamble (sequential mass storage treated as tape) governs CLOSE's reel and unit phrases; it does not make a disk a medium that "permits rewinding" for OPEN, and it cannot outrank the status definition that names this very case.

**What is owed.** An entry in `docs/conformance/` for 1985 stating the classification (the 2023 register has it as `DOC-A.1-24`; an edition-specific statement names its edition). Until the entry exists the row stays open: a row that rests on an implementor's classification closes on the documented determination, not on silence.

**Row.** `1985-GR-XIII.4.5.4-9`.
