## What happened, and why it is a measurement lead

A negative golden asserted that a legal COBOL program is rejected. It was green for months. It was found
only because **PB437**'s implementer fixed the refusal and the golden stood in the way — i.e. by a fix
walking past it, not by any check. `feedback_green_test_can_hold_a_gap_open` names the shape: *a GREEN
test pinning a loud-stage reads as a DECISION.*

The register has no idea how many more there are, and this pass produced a second live instance:
`UdfInvocationTests.PerEvaluationOperandWindows_Bind` pins COBOLNET1509 on the EVALUATE condition subject
that **PB912** shows is legal source.

## The measurement to run

Two populations, both mechanical:

1. **Negative goldens** whose `.err` expectation names a code the compiler emits for a CAPABILITY LIMIT
   rather than for a rule — COBOLNET1509 (function activation cardinality), COBOLNET1756 (non-ISO
   extension / not implemented), and every `BoundUnsupported` message (**PB909**'s population). On this
   tree the `.err` sweep finds two (`pb345-sd-no-record`, `pb347-write-record-of-no-file`), so the
   population is small — which is a RESULT, and makes the audit cheap, not unnecessary.
2. **Unit and conformance test bodies** asserting those codes — `grep -rl "COBOLNET1509\|COBOLNET1756"
   tests/` — which is where the second instance above lives and which the `.err` sweep cannot see.

For each hit, ask the CLAUDE.md rule 1 question: does the standard refuse this source, or does this
compiler? Only the first is a legitimate negative.

```
$ python scripts/spec/cite.py --check 4.2.2 "An implementation shall accept the syntax"

```

## What it should END as

⛔ Not a list. A negative golden should be required to carry, in its `*> reject-at:` line, the CLAUSE that
refuses it — and a drift test should assert that the clause named is real (`cite.py --check` is already the
mechanism) and that the code emitted is not one of the capability-limit codes. A negative that can only
name a capability limit is, by construction, a decision that wants an owner rather than a test.
