# PB5415 - a program CALLed a second time in its last-used state reports DEBUG-CONTENTS 'START PROGRAM' again: DispatchEmitter emits the START PROGRAM debug cause in every activation's entry code, where 1985 gives it only for the first execution of the first nondeclarative procedure

**Sites:**

- `src/WiseOwl.Cobol.Compiler/CodeGen/DispatchEmitter.cs#EmitDispatcher`
- `src/WiseOwl.Cobol.Compiler/CodeGen/EmitterState.cs#EmitDebugCause`
- `src/WiseOwl.Cobol.Runtime/Control/DebugItem.cs#ContentsFor`

**Mechanism.** `DispatchEmitter.EmitDispatcher` emits `EmitDebugCause(StartProgram)` in the entry code of every activation. A program that is CALLed again without a CANCEL is in its last-used state, its first nondeclarative procedure is not executing for the first time, and yet its debugging section reports `START PROGRAM` again. GR11 leaves an item no rule specifies spaces, so the second entry is a transfer of control with DEBUG-CONTENTS spaces (GR18 for a GO TO, or the rule of the cause that applies).

**Found by.** The 1985 code read, read 3 (`kb/Work/PB4996/2026-11-12-read-3.md`): `E:/COBOL-coord/scratch/coderead-85/out-read3/rd-07.json`.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. Its rows are recorded DIVERGES naming this note.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-GR-XV.3.2.4-16` - `§1985:XV.3.2.4 GR16` (read: DIVERGES, harm: wrong debugging output; START PROGRAM): "the first execution of the first nondeclarative procedure in the program"

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-read3/work-rd-07/d4m.cob`: a main program CALLs a debugged subprogram twice. Run as `cobol.exe --std 85 --source-format fixed --run <file>` (each probe copied into its own directory by `reprobe-85i/probe.py`).

**Observed (the pinned compiler of `E:/COBOL-wt/coderead85-tree-c` (fafa91a83c, the head of witnesses-85g; `git diff --stat fafa91a83c origin/main -- src` is empty at 3c4f6fe652), rerun 2026-11-12; `E:/COBOL-coord/scratch/coderead-85/reprobe-85i/log.txt`).** `[S1 ...][START PROGRAM ...]`, `IN S1`, then `[S1 ...][START PROGRAM ...]`, `IN S1` again.

**Expected (from the 1985 text).** `START PROGRAM` on the first CALL only; on the second CALL the program is in its last-used state and the first procedure is not executing for the first time.

**Fix direction (root cause, CLAUDE.md rule 4).** Emit the START PROGRAM cause only on the activation that initializes the program (its initial state: the first CALL, after a CANCEL, or every CALL of an INITIAL program), from the same state flag that decides initialization.
