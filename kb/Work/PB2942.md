# PB2942 — the ledger's charts listed every point in their accessible label

Found by the operator 2026-10-10 17:10 PDT while publishing ledger v32 after train 1052: the Artifact rule says read the
whole file before publishing it, and reading `E:\COBOL-coord\ledger.html` (72,435 bytes) cost the operator about
35-40k context tokens. Filed 2026-10-10 18:10 PDT by the next operator session.

**Measured (ledger v32, 191 trend points):** the two SVGs were 29,964 bytes of the 70,712-character page. The GAP
trend's `aria-label` listed every point as `<date> <gap>` (3,458 characters), and the register chart's listed every
point as `<date> <open> open, <defects> defects` (6,645 characters). Both grew by one entry per landing, without bound.

**Owner (2026-10-10 18:08 PDT):** "For the ledger, the graph of dots if fine. But we do not need detail for each dot."
So the dots and the polyline stay as drawn; only the per-point detail goes.

**Fix:** each label is now a summary: the point count, the first and last point, and (for the GAP trend) the low and
high. On the same 191 points the labels are 107 and 125 characters, and the rendered page is 62,255 bytes instead of
72,435 (-14 %). The label no longer grows with the series. Code: `scripts/spec/gen_ledger.py#trend_svg`,
`#register_svg`, each with a comment that states the rule and cites this note.

**Drift guard:** `gen_ledger.py --self-test` renders both charts from a 3-point and a 400-point series and requires the
two labels to differ by at most 8 characters and the 400-point label to name exactly two dates. Run against the old
generator, the same check reads 80 → 6,829 characters (trend) and 142 → 13,918 (register): it fails there, so it bites.
Structural, never a wall-clock or byte budget on the whole page.

**Sweep:** every `aria-label` in `gen_ledger.py` (the stack bar, the section labels, the two charts). Only the two charts
built their label from the series; the stack bar's label names four fixed counts.

**Not changed:** a circle per dot remains (owner: the graph of dots is fine). At 191 points the circles are about 11 KB,
and they grow with the series too. Draw them as one path, or thin the series to the last N landings, only if the
owner asks.
