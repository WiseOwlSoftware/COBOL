# PB81 — LANDED 2026-08-18 — `SUBSTITUTE("aXbXc" SBF(ALL))` (SBF OCCURS 2: "X","Y") was COBOLNET0899, not the pair (X→Y)

**Landed (2026-08-18, DEVLOG 1315)** — the fix shape below, as designed: an enumeration among the pairs switches
`BindSubstitute` to the FLAT form (`Args` = [argument-1, part…], `SubstituteModes` = one flag per part, `SubstituteFlat`);
`RenderSubstitute` emits `CobolIntrinsics.SubstituteFlat(source, string[][] parts, int[] partFlags)` (each part its
singleton or its `AllArgs` enumeration); the runtime pairs the elements in order, takes each pair's mode from its
argument-2 element (a keyword before an enumeration attaches to the pair its first element opens), and decides the
§15.87.2 shapes only a count can decide (odd count, a keyword on an argument-3 element, FIRST with LAST) as
EC-ARGUMENT-FUNCTION with the zero-length default, then runs the ONE `Substitute` kernel. Written-only calls keep the
bind-time pairing byte-for-byte — the first cut zeroed the pending flags after argument-2 and the `substitute` golden's
FIRST/LAST/ANYCASE rows went red at the CLI probe (a pair's mode is the flags on its argument-2 UNION anything pending
before argument-3, the union the old pairing always applied). The staged descriptor is retired. Measured (golden
`pb81_substitute_table_all`, values derived from the written-out calls): P2 aYbYc, P3 aYbYc (X→Y, Z→!), FIR aYbXc, TWO
bbdbbd, MIX/ODD blank (odd counts → EC-ARGUMENT-FUNCTION, the zero-length default), AC AYBYc. Verdicts FMT-15.87.2,
RV-15.87.4-1…-5 → CONFORMS (GAP 3980 → 3974).

*As registered:*

> ⚙ **flags:** rejects-legal-source (loud, at bind — COBOLNET0899 `substitute-all-subscript-argument`) · found
> 2026-08-18 landing PB62 (the ALL subscript's runtime enumeration); it used to compile clean and throw
> NotImplemented at RUN time on the plain subscript path, so the landing moved the loudness to bind.

**Spec:** §15.3 — "When the definition of a function permits an argument to be repeated a variable number of
times, a table may be referenced by … ALL … the effect is as if each table element … were specified"; SUBSTITUTE's
§15.87.2 format `argument-1 { [ANYCASE] [FIRST|LAST] argument-2 argument-3 } …` repeats the PAIR, so an ALL is
admissible (`IntrinsicSig.RepeatsAnArgument` is true for SUBSTITUTE — its format carries the ellipsis) and its
elements form the pairs by position: `SUBSTITUTE("aXbXc" SBF(ALL))` over ("X","Y") = `SUBSTITUTE("aXbXc" "X" "Y")`
= "aYbYc"; over a 3-element table the third element pairs with whatever follows.

**Mechanism:** `IntrinsicBinder.BindSubstitute` pairs operands at BIND time (`pairOperands` counting, one entry of
`BoundIntrinsicCall.SubstituteModes` per completed pair) and `IntrinsicRenderer.RenderSubstitute` splits
`Args[1..]` into `froms`/`tos` arrays by index. A `TableAllPlace` operand (PB62's one-operand enumeration) is a
runtime-count contribution to that interleave, which neither the pairing nor the per-pair mode list can express, so
the binder reports the staged descriptor and returns a `BoundExprError`.

**Fix shape:** a runtime pairing — `CobolIntrinsics.Substitute(string source, string[] flat, int[] flagsPerElement)`
where `flat` is the enumerated tail (`IntrinsicRenderer.ArgArray(ic, 1, "string", Str)`) and `flagsPerElement`
carries each element's pending FIRST/LAST/ANYCASE flags (a written operand: its flags; an ALL enumeration: the flags
on its FIRST element only — `AllArgs<int>` with a first-index selector — the keywords precede the pair an element
STARTS); the runtime pairs consecutive elements, takes the mode from the even-position element, raises
EC-ARGUMENT-FUNCTION for an odd count or FIRST+LAST on one pair (the §15.87.2 malformed shapes, decided at run time
because the count is). Golden: the 2-element and 3-element shapes above; negative: none (the runtime raise).
