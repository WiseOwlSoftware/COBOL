# PB3809 — a retried copy hides a real build break as ENVIRONMENT

**Sites:** `scripts/abi_pin.py#_HOST_ERROR`, `scripts/abi_pin.py#_HOST_PHRASE`, `scripts/abi_pin.py#_RETRY_NOTICE`, `scripts/abi_pin.py#host_caused`, `scripts/abi_pin.py#failure`, `scripts/abi_pin.py#self_test`, `tests/WiseOwl.Cobol.Tests.Unit/MergeDriverDriftTests.cs`, `scripts/orchestrator/enqueue.py#incomplete`

## Measured

`_HOST_CAUSE` matches the text of MSBuild's transient copy-retry WARNING (`MSB3026: ... being used by another process.
The file is locked by: ...`), not only the final `MSB3027`/`MSB3021` error its comment names. Probed on head
d89f286c0: `abi_pin.failure("the measuring run exited 1", out)` where `out` is a `warning MSB3026: Could not copy ...
Beginning retry 1 in 1000ms ... The file is locked by: "csharp-ls (62616)"` line followed by `error CS0103: The name x
does not exist` and `Build FAILED.` returns cause `merge-blocked`. `enqueue.land` then ends exit 2 with no report line,
the lane retries once, and the second exit 2 is STOPPED and handed to the operator instead of a finisher for a real
merged-tree break. PB3674 (MoveAsideHeldOutput) reduces the frequency.

## Acceptance

- The lock signatures are anchored on error lines (`error MSB3027|error MSB3021`; the held-file and disk phrases only on a
  line that carries `error`).
- A self-test arm: an MSB3026 warning plus a `CS` error is MERGE_FAILED (finisher), an MSB3027 error alone stays
  merge-blocked.

## Fixed

Re-probed on the branch's build before the change: `abi_pin.failure(..., <MSB3026 warning> + <error CS0103> + Build FAILED.)`
returned `merge-blocked`. The one regex is now two anchors and a filter, read line by line by `host_caused`: `error MSB3027` /
`error MSB3021` count on any line; the held-file, full-disk and cannot-start phrases count on a line that is not an MSBuild
warning (`_RETRY_NOTICE`). The acceptance wording "only on a line that carries `error`" is met by the warning filter instead,
because the disk phrase of `System.IO.IOException: There is not enough space on the disk.` carries no `error` word and
stays the host's. The `abi_pin.py` self-test arm: a retried copy plus a CS error (either order) is `merge-failed`; the retry
followed by the ending `error MSB3027` stays `merge-blocked`. `MergeDriverDriftTests` declares the arm. The sibling arms
(`enqueue.land`'s `incomplete`, `run_gate_legs.NOT_RUN_CAUSES`) read the tag and needed no change; a grep of scripts/, .github/
and tests/ for MSB3026/MSB3027/MSB3021 and the held-file phrases finds no second classifier.
