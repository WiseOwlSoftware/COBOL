# PB382 — a funnel that names only the words the grammar already lets through

Found by the PB371/PB375 implementer (2026-09-03) while measuring PB375's false premise that `01 CLASS PIC X.`
is legal at `--std 85`. MEASURED at `--std 2023`, on the tree carrying the CLASS landing:

- `01 DESTINATION PIC X(4).` → `COBOLNET0901: 'DESTINATION' is a reserved word in COBOL-2023 and cannot be
  used …` — the correct, helpful answer, pinned by `conformance:negative/declined-validate-entry-name-still-0901`.
- `01 ALPHABETIC PIC X(4).` and `01 CLASS PIC X(4).` → `COBOL0001: no viable alternative at input '…'` plus
  `COBOL0307: unexpected '…'. A period may be missing at the end of the previous sentence.` — a wholly generic
  pair that says the syntax is bad rather than that the word is reserved, and whose second sentence is actively
  misleading (no period is missing).

Not created by the PB375 landing and not worsened by it: `01 CLASS PIC X.` behaved identically before and after
(verified on both trees).

## Root cause, one place

`VersionConformancePass.IsProvableUserWordPosition` can only fire once the parse has REACHED the entry-name
slot, and `CobolData.g4`'s
`dataName : cobolWord | FILLER | PROCEDURE | {reservedHere("COMMIT")}? COMMIT | {reservedHere("ROLLBACK")}? ROLLBACK`
admits only context-sensitive words (`cobolWord` is GENERATED from `cobol-words.json`'s nameSlot rows) plus four
named exceptions. A reserved word with a dedicated lexer token and no `cobolWord` membership — CLASS, ALPHABETIC,
ALPHABETIC-LOWER, ALPHABETIC-UPPER, NUMERIC and every §8.9 word of that shape — cannot reach the slot, so the
funnel never sees it. The population is mechanically enumerable: every `reserved-words.json` word with a
`CobolLexer.g4` token that is not a `cobolWord` alternative.

## What closes it

⛔ NOT "add these words to `cobolWord`" — that would make them legal user-defined words and contradict §8.9.
The shape is a recovery arm in the entry-name position admitting ANY reserved-word token solely so the funnel can
NAME it — which is what the four `dataName` exceptions already do by hand (PB137 added COMMIT and ROLLBACK
exactly that way, one word at a time: a hand-maintained list where a structure belongs, rule 5). The arm is
derived from the same generated reserved-word table, so the next reserved word is covered the day it is added;
a drift test enumerates the population and asserts every member draws COBOLNET0901 in a name slot; the
`dataName` exceptions fold into the arm. Wave-local gate `~ReservedWord|~CobolWords|~Declined`.

Harm classification: the source is illegal either way, so none of the four harm flags apply and the note is
`process_only` by the PB281/PB283 precedent — a misleading diagnostic is a defect the register cannot yet rank
(the resource/diagnostic-quality axis PB380 records as missing from the harm vocabulary).
