# PB3539 — §12.4.6.4.4 GR3 unenforced for SAME RECORD AREA under APPLY COMMIT

## Lead

§12.4.6.4.4 GR3 is unenforced: two files of one SAME RECORD AREA, both under APPLY COMMIT, compile and run.

Repro: `git show 67069487d:conformance-suite/cases/12.4.6.4-SAME/apply-commit-same-area-shared.cob` with ORGANIZATION RELATIVE
(the fixture was deleted by PB3338's branch; the commit still holds it).

Code site: `src/Cobol.Net.Compiler/Binding/DataBinder.IoControl.cs`, the SR11 loop (about line 70).

## The rule (checked with `cite.py --check 12.4.6.4.4`, OK)

§12.4.6.4.4 GR3: "The file and record area of a file subject to commit and rollback may not be shared with another such
file or record area unless it has been closed, a commit or a rollback has been executed and the APPLY COMMIT clause for
the file has been deactivated."

The rule is a general rule, so it describes execution, and it permits sharing once the first file is closed, committed or
rolled back and its clause deactivated.

## OWNER QUESTION: refuse at compile time, or check at run time

Option A, refuse at compile time (a syntax-style diagnostic for any SAME RECORD AREA group with two APPLY COMMIT files):
- Gain: one diagnostic at the data binder, no run-time cost, the same place that already enforces SR11.
- Cost: it also refuses legal programs, because GR3 allows the sharing after the first file is closed, committed or
  rolled back and its clause deactivated (a program that opens the two files one after the other). That is rejecting legal
  source (CLAUDE.md rule 3).

Option B, check at run time (the second OPEN, or the first use, of a file whose record area is shared with a file still
subject to commit and rollback fails with an exception condition and a file status):
- Gain: exactly GR3's condition, so legal sequential use still runs.
- Cost: a run-time registry of record-area sharing groups and their state (closed, committed or rolled back, clause
  deactivated), a choice of exception condition and status, and the interaction with the kept-state and retirement
  machinery of PB3338.

No decision is named; the owner chooses.
