# PB3844 — Parse-error hint 14 is predicate-blind

**Sites:** `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs#OffendingPosition.APeriodLetsTheSentenceFollow`, `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs#ResimulationWalk.TakesAll`

Repro: `WRITE SQ-REC IGNORING LOCK.` (golden `pb331-write-ignoring-lock`) drew COBOL0307. `APeriodLetsTheTokenFollow` (now `APeriodLetsTheSentenceFollow`) asked the resimulation walk whether a period lets the offending token follow; the walk evaluates no semantic predicates, so a predicate-guarded word after the period (a paragraph-name that `cobolWord` refuses for IGNORING) still passes and the message blames a missing period that would not help.

Register class: a message that names the wrong fault is filed `process_only: true` today because the register has no harm class for it (kb/Work PB3836); the flag becomes the new class when PB3836 lands.

## Landed (wave 20261711 group C, with PB906)

The note's premise was off by one reading: the walk is not blind to `cobolWord`'s predicate. `. IGNORING` really parses,
because IGNORING is a context-sensitive word and a legal paragraph-name outside the READ phrase that keeps it; it was the
LOCK after it that no paragraph header takes. The root was the missing-period reading checking one token. It now checks the
sentence that starts at the token (`OffendingPosition.APeriodLetsTheSentenceFollow`, renamed from
`APeriodLetsTheTokenFollow`), and the statement that ended before a phrase its formats do not print draws COBOL2269 naming
it (hint 0h, PB906). `pb331-write-ignoring-lock` and `pb331-rewrite-ignoring-lock` are pinned COBOL2269; the new
`ParseRecoveryHintTruthTests` PBHT42 reproduces the shape on a CONTINUE statement and PBHT38 pins the other direction. The
sweep of `cobolWord` predicate positions: the walk needs no predicate evaluation for this, because the decision the
predicates take is already the grammar's (a word reaches the paragraph-name slot or does not), and the sentence check rests on
the grammar's own acceptance of the following tokens.

## Acceptance

- The walk answers a period lets the token follow only where the predicate-guarded alternatives would accept it (evaluate or model the predicates); the repro draws the diagnostic its golden should hold.
- Sweep every `cobolWord` predicate-guarded position for the same blindness.
- Fix the root cause, never simply making the diagnostic pass; be consistent with ourselves barring an explicit requirement differently.
