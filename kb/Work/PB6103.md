# PB6103 - the unit-push self-test cases assume origin is the GitHub URL

**Lead** (PB2628 report, `w20262139a`): the Linux selftests leg fails `[unit] git push https://github.com/WiseOwlSoftware/COBOL x` and the `--repo=` form in the
Linux clone and passes on Windows. The report guessed the clone's local-path origin URL. Re-verified by reading the code on main ae1136f781 (the failure itself
was not re-run: this host is Windows, whose origin is `https://github.com/WiseOwlSoftware/COBOL.git`, and the case passes here):

- `scripts/hooks/forbidden_commands.py#_pushes_elsewhere` (line 248) refuses a unit's push when any push URL's `_repo_key` differs from the key of THIS repository's
  own `origin` URL (`git remote get-url origin` in the hook's root).
- `scripts/hooks/test_forbidden_commands.py` states the expected verdict for a push to `https://github.com/WiseOwlSoftware/COBOL` as a literal
  (line 427 `("git push https://github.com/WiseOwlSoftware/COBOL x", False)`, line 458 `--repo=https://github.com/WiseOwlSoftware/COBOL` False, line 461
  `... HEAD` True, and the neighbours). A clone whose `origin` is a local path (a Linux clone made from a path, as the Linux selftests leg makes) keys to a resolved path, so the
  hook correctly judges the GitHub URL another repository and the literal expectation is wrong there. The fixture's own cases already build `THIS_ORIGIN` from
  the clone (`test_forbidden_commands.py:28`), so the literal cases are the only ones tied to a spelling.

**Sites:**
- `scripts/hooks/test_forbidden_commands.py` (whole: lines 427, 458, 461; the literal GitHub URL cases; also any neighbour that spells the URL)
- `scripts/hooks/forbidden_commands.py#_pushes_elsewhere` (judges by the clone's origin: not a hook defect)

**Next:** derive the expected verdict of those cases from `THIS_ORIGIN` (a case whose destination is this repository's origin spelled as a URL, built from the clone's
origin), and run the case in a local-path clone to see it pass (`bash scripts/linux-gate.sh` or a scratch clone). If the Linux failure has another cause, record it here.
