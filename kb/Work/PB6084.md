# PB6084 - a second hand-written reader of TestRepo (CLAUDE.md rules 4, 5; one rule in one place)

**Sites.** `scripts/buildgraph.py:1218` `TESTREPO_BASES` lists TestRepo's helper prefixes by hand; `:1230` `TESTREPO_CALL`
finds calls by the text `TestRepo.`, so a fully qualified call (`WiseOwl.Cobol.Tests.TestRepo.X`) or any other spelling
is missed. This is the failure PB3201 fixed in the architecture census (it moved to a semantic locator).

**Target.** The BUILD TARGETS audit reads the helper set and the calls from the compilation (or from the one list the
census already derives), not from restated prefixes and a text match; a drift test plants a qualified call and an
added helper. Separate root from PB3201; `buildgraph.root_anchors` already reads `TestRepoDriftTests.Anchors` (PB5230),
so the reader has a precedent to extend.
