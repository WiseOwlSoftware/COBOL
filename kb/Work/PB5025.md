# PB5025 - APPLY COMMIT below 2023 gets the closed-format refusal

**Found.** Wave 20261936 group C (PB5015). At `--std 2014` the version-matrix row `apply-commit-clause-2023` expects COBOL1970,
the closed-format refusal, where the diagnosis should name the edition (D7, DESIGN section 1.1: the parse carries no edition
predicate; the validation pass names the edition). It is the last of PB2291's five construct gates; PB5007 removed the
validation-clause one and named this one as outside its group.

**Fix shape.** Delete `{is2023()}?` from `ioControlClause`, add `ParseArm.VisitApplyCommitClause`, change the row's
`diagnosticCode` to COBOL0900 (the edition refusal), and prove that `APPLY` and `COMMIT` used as user words at 2014 keep their
reading (APPLY is context-sensitive, section 2023:8.10, and no earlier edition has an APPLY clause).

**Sites:** `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolIO.g4:341` (`ioControlClause`, the {is2023()}? deleted),
`src/WiseOwl.Cobol.Compiler/Validation/VersionConformancePass.cs` (`ParseArm.VisitApplyCommitClause`),
`tests/WiseOwl.Cobol.Tests.Unit/EditionReadDriftTests.cs` (`RecordedSites`, `ConstructGates_AreNone`),
`tests/version-matrix/constructs.json` (`apply-commit-clause-2023`), `src/WiseOwl.Cobol.Editions/ConstructRegistry.g.cs`
(regenerated), `docs/VERSION_CHANGE_REFERENCE.md` (row 39 and the generated index), `docs/DESIGN.md` (D7),
`docs/rearchitecture/DESIGN-architecture-review.md` (section 8.4). PB2291 holds the adjudication of the five gates;
this was its remaining construct gate.

**Re-probe (wave 20261946 group C, 2026-11-09).** Reproduced on c865ee6dc3: the matrix row's program (free form) at
`--std 85`, `2002` and `2014` drew `COBOL1970: cannot parse construct near 'APPLY'. 'APPLY' is not a clause of the
I-O-CONTROL paragraph`; at 2023 it compiled.

**Resolution.** The fix shape held. `{is2023()}?` is deleted from `ioControlClause` (the union grammar);
`VersionConformancePass.ParseArm.VisitApplyCommitClause` checks `apply-commit-clause-2023`, whose `diagnosticCode` and
`expectDiagnostic` are now COBOL0900, so below 2023 the clause draws `COBOL0900: APPLY COMMIT clause (commit and
rollback) requires COBOL-2023`. No other I-O-CONTROL clause begins with a user word, and a program that declares APPLY
or COMMIT has every occurrence retyped by the token-level reservation gate, so the user-word reading is kept: the new
golden `conformance:cases/12.4.6.4-SAME/pb5025_files_named_apply_commit` (accept 2002, 2014) names two files APPLY and
COMMIT and writes `SAME RECORD AREA FOR APPLY COMMIT.`, the clause's own spelling, and runs to its GR2 output. The two
below-2023 refusals (`pb3338_apply_commit_below_2023`, `pb3540_commit_under_method_below_2023`) now expect COBOL0900.
With this, the recorded edition reads hold no construct gate (`EditionReadDriftTests.ConstructGates_AreNone`).
