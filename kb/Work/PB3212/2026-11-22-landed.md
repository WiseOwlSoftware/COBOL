## Landing (2026-11-22, wave 20262135 group A)

Re-probed on 2061bdb7bb: kb/Work PB5427 had already folded HasExternalAttribute into `DataBinder.IsInExternalRecord`, but the
note's mechanism stood: `IsInExternalRecord` (a static taking the unit's FileSlice), `DataBinder.IsGlobalRecord` (a Files scan),
`DataItem.ExternalItemIdentity` (the narrower copy, clause and type only) and the two GLOBAL loops of
`LinkageBinder.CallBindExternalAndGlobal`. The narrower copy was a live over-rejection: an item of an `FD … IS EXTERNAL` record
named as the RELATIVE KEY of another EXTERNAL file was refused `COBOL1624 ... shall be an external data item (ISO §2023:12.4.5.3
GR1h)` (probe `E:/COBOL-coord/scratch/w20262135/w20262135a/runs/fdext-001`), though §2023:13.18.22.4 GR4b makes "the data
contained in all record description entries" of an external file external and §2023:14.8.4.2 asks only that the item be an
external data item.

Fix: a record joins a file only through `FileModel.AddRecord`, which sets the back-pointer `DataItem.RecordOfFile`. The model
answers each attribute once: `DataItem.HasExternalAttribute` (own clause, external type, or EXTERNAL FD), `DataItem.IsGlobalName`
(own clause or GLOBAL FD) and `DataItem.IsInFileSectionRecord`. `IsInExternalRecord`, `IsGlobalRecord` and the file-scan siblings
the sweep found (`DataBinder.IsFileSectionItem`, `ValueInitializer.InFileSection`, `DynamicResolvePass`'s root set,
`RecordLayout.IsInRecordOfFile`'s Contains, the linkage binder's external-FD record set) are deleted or read the pointer. The FD
case of `ExternalItemIdentity` is decided against §2023:14.8.4.2: such an item IS an external data item, and its storage name is
the file's record-area cell (`FileModel.ExternalAreaName`, the one spelling of the `FD::` keys the re-basing also uses), so every
describer of the file computes the same identity. OdoResolvePass's table side keeps "a record description entry containing the
EXTERNAL clause" (§2023:13.18.38.3 SR21's own words), now stated in its comment.

Witness: `conformance-suite/cases/13.18.22-EXTERNAL/pb3212-external-fd-item-relative-key` (accept 85, 2002, 2014, 2023).
