# PB6220 — a 2023 general rule refuses legal 2002 source

**This is 2002 work.** The 2002 plan is APPROVED as measure first, catalog complete, pilot, then scale; 2002 fixes are frozen until
the plan's fix-train stage. Do not plan this note ahead of it.

**Mechanism.** §2023:12.3.8.4 GR1 says a parameterized class may be named only in a REPOSITORY paragraph; the compiler applies it
at 2002. 2002's own clause (§2002:12.2.7.3 GR1, checked) reads "Class-name-1 is the name of a class that may be used throughout the
scope of the containing environment division", with no parameterized-class restriction. The restriction first appears in 2014
(§2014:12.3.7.3, checked: "If class-name-1 is a class described with the USING phrase, class-name-1 may be specified only in the
REPOSITORY paragraph"). So 2002 source that names a skeleton outside REPOSITORY is refused where its edition's text allows it.
What a reference to a skeleton means at 2002 needs a reading of the 2002 text before the gate moves.

**Sites:** `SymbolTable.ClassNames.Resolve` and `OoClassTable.IsParameterized` (the GR1/GR7 refusal); `OoExpansion.Expand` (the
"EXPANDS ... is the name of the parameterized ... definition itself" arm, `src/WiseOwl.Cobol.Compiler/Oo/OoExpansion.cs`)
