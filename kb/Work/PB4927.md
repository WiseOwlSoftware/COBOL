# PB4927 - a shared staged .cob raced by parallel refusal cases

**Sites:** `tests/WiseOwl.Cobol.Tests.Conformance/CompiledProgramCache.cs` (`CompiledProgramCache.StageSource`, `CompiledProgramCache.CompileThrough`, `CompiledProgramCache.CompileCold`), `src/WiseOwl.Cobol.Frontend/Pipeline/CompilationInputs.cs` (`CompilationInputs.ReadSourceText`)

**Report.** PB4838's first gate (run 000001) went RED on `pb464-set-size-fraction-below-2023` at edition 2014: an `IOException` out of
`CompilationInputs.ReadSourceText` on a cached `.cob` that parallel refusal cases of the same content share (`StageSource` names the directory by the content, so
two editions of one case land on one path). One occurrence; run 000002 on the same tree was green. The reviewer's code site was `CompiledProgramCache.cs:110`.
Per the register's flake rule (CLAUDE.md, the merge-group paragraph) a flake is a defect fixed at its root, never retried: `StageSource` writes through a
temporary file and an atomic move (or holds a per-path lock) so a reader never opens a file mid-write, and the reader opens with `FileShare.ReadWrite|Delete`
only if the root cause is a sharing violation, which the fixer determines from the exception's HRESULT (not recorded in the report). No repro; count one.
This is also an instance for PB1957's record of local/CI differences only if it recurs on the merge group.
