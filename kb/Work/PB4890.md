# PB4890 - the screen entry's name slot holds no gated word, so a reserved name is reported as a missing CONSTANT

**What the report says (the implementer's words).** A reserved word as a screen item's name draws "expected CONSTANT". Flags:
misleads_diagnosis. Repro: `E:/COBOL-coord/scratch/w20261887h/p2/c22.cob`, `SCREEN SECTION.` then `01 SCREEN LINE 1.` draws
`COBOL5506: The word LINE is not expected here: expected CONSTANT` where WORKING-STORAGE and the report slot draw COBOL0901.

**Mechanism.** `screenName` (`cobolWord | FILLER`) carries no `reservedGatedWord`, so `constantEntry` is the loop's sole
surviving alternative in `screenSection` and the diagnostic names the wrong fault. The same implementer's PB4818 note records
that the screen loop "is covered if that changes".

**Not probed here.** The clerk ran nothing; re-run the repro against a fresh build first.
