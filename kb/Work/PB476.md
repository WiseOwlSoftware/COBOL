# PB476 — OPEN — a filter is evidence about what it returned, never about what it dropped

Found 2026-09-04 by the `PB470` implementer: `python scripts/spec/audit_doc_citations.py --check` printed
`249 verbatim-shaped citations checked · 205 correct` before its design-doc edit and `248 · 204` after, because
the edit replaced a quoted spec fragment with prose. Both runs ended `⛔ 0 MISFILED` and the gate passed.
Re-derived on this tree: the population line is `scripts/spec/audit_doc_citations.py:258`
(`print(f"{ok + len(misfiled) + len(absent)} verbatim-shaped citations checked · {ok} correct")`) — computed and
printed, compared against nothing.

## The shape

The audit's `--check` exit code depends only on the findings it returned (misfiled, phantom). A citation that
stops being recognisable as a citation — quoted text reworded, a `§` dropped, a clause turned into prose — is
not a finding; it is a member of the population that silently leaves it. The same shape as
`feedback_measure_the_selectors_complement` (`work.py next` hid nine harmful items for months) and the reason
`ExternalCorpusPopulationDriftTests` carries a COMMITTED population baseline (`{"baseline": 1323 …}`) and goes
red when the census moves. The two citation audits have no such baseline.

**Sibling:** `scripts/spec/audit_code_citations.py --check` has the identical shape — `2846 files scanned for
phantoms, 1331 for construct agreement · 254 constructs keyed to their own clause · ⛔ 0 finding(s)` — its
population is printed and never compared. One fix, both audits.

## Fix shape

A committed population baseline per audit (the counts the last green run measured, in a small JSON beside
`scripts/semgrep/baseline.json`'s pattern, registered where `PB175` registers that one), read by `--check`: a
population BELOW the baseline is a red with the delta and the files whose citation count fell (so the author
either restores the citation or, when the removal is deliberate, re-baselines in the same commit and says why);
a population above it re-baselines automatically on `--update-baseline`. A drift test fires the failure branch
once — a fixture doc whose citation is reworded must turn the check red — per `feedback_prove_the_watchdog_fails`.
