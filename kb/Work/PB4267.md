# PB4267 — diagnostics quote an operand or receiver node by GetText()

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/EvaluateBinder.cs#BindWhenItem` (three `item.GetText()` messages: the non-boolean WHEN, the partial-expression and the WHEN object),
`src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/OoBinder.cs#OoBindInvocationArg` (BY CONTENT `{bx.GetText()}`),
`src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/MoveBinder.cs#Bind` (`MOVE '{move.GetText()}'`),
`src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CallBinder.cs#BindCall` (`CALL USING argument '{a.GetText()}'`),
`src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/SetFormatSelection.cs#Written` (receivers quoted by `r.GetText()`),
`src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/SetBinder.cs#BindSetPointer`, `SetBinder.cs#BindSetProgramPointer`, `SetBinder.cs#BindSetFunctionPointer`,
`SetBinder.cs#BindSetFunctionAddress`, `SetBinder.cs#BindProgramAddressTargets` (per-receiver messages quoting a dataReference by `GetText()`).

**The defect (two leads from the PB4209 report).** (1) "Other binders still quote an operand node by `GetText()` (glued, rewritten ZERO): EvaluateBinder.cs:526/600/697 (`WHEN '{item.GetText()}'`), OoBinder.cs:1451 (BY CONTENT `{bx.GetText()}`), MoveBinder.cs:111 (`MOVE '{move.GetText()}'`), CallBinder.cs:613. One mechanism (PB3961 class); probe each with an operand containing ZERO or two tokens."
(2) "R1-1 LEAD (low, not blocking at round 1): src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/SetFormatSelection.cs:359 The SET RECEIVER half of the same mechanism is left: SetFormatSelection.Written and the per-receiver messages in SetBinder (e.g. lines 521, 635, 787, 852, 1088) quote a receiving dataReference by GetText(), which glues a qualified name, while the branch DEVLOG says the SET family GetText sites are all receiver names and need nothing."
One mechanism; the line numbers above are those of the reports, resolved here to the enclosing member at origin/main 11e8949be.

**Fix direction.** Probe each site with an operand containing ZERO or two tokens, and name the node the way PB3961 and PB4209 name it, as written. Related: PB4252 (the glued-GetText drift-test analysis).
