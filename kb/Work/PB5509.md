# PB5509 - `TE (ALL) OF TT` draws a misleading COBOL2363 beside the correct COBOL2776

UNVERIFIED LEAD: re-probe before fixing.

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/IntrinsicBinder.cs` (`TryBindAllArgument`)
- `src/WiseOwl.Cobol.Compiler/Binding/SubscriptBinder.cs` (`MaterializePosition`)

**Mechanism.** A function argument `TE (ALL) OF TT` writes a qualifier after the subscript list, which no edition's format allows (the qualifier precedes the subscripts). `TryBindAllArgument` returns false for a qualifier after the subscripts, so the argument goes to the ordinary operand bind, whose `SubscriptBinder.MaterializePosition` meets the word ALL outside a context it knows and refuses it as COBOL2363, with a message that says ALL is permitted in a function argument, which it is. The source is refused rightly (COBOL2776 names the real fault); the second diagnostic misleads. No edition arm: PB5209's landing left the shape as it was and recorded it (`kb/Work/PB5209/2026-11-13-landed.md`, "Left as it was").

**Lead, verbatim (wave 20262020 group A, report `w20262020a-PB5163-report.md`, "New defects / leads").** "`TE (ALL) OF TT` (illegal) draws the correct COBOL2776 plus a misleading COBOL2363 ("ALL is permitted in a function argument"): TryBindAllArgument returns false for a qualifier after the subscripts (IntrinsicBinder.cs `TryBindAllArgument`; SubscriptBinder `MaterializePosition`). Own root."

**Expected.** Only the diagnostic that names the fault (COBOL2776) is drawn; the ALL subscript in a function argument is not reported as misplaced once the qualifier is the error. The fixer decides whether `TryBindAllArgument` should bind the ALL position and report the qualifier, or the ordinary bind should suppress COBOL2363 when its ALL sits in a function argument.

**Search first (clerk).** grep of kb/Work for `TryBindAllArgument`, `COBOL2363` and `ALL) OF`: PB5209 (landed) is the neighbouring root (a reference modifier after ALL, fixed); no open note covers this shape.
