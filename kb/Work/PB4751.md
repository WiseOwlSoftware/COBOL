# PB4751 - which kind is the sum of a float item and an approximation (a D16 question)

**What the report says.** A SUM, ABS or RANGE over `ZF + FUNCTION EXP10 (-6)` (a float item beside an approximation, an equivalent
arithmetic expression) lands 0.000000, as the written-out `ZF + EXP10` does on main too. GnuCOBOL 3.2 gives 0.000001. The question
is the D16 one: which kind the SUM of an item and an approximation is. The report marks it owner-level and did not fold it into
the group's branch; it is not the selection defect the group fixed (R1-2 there).

**Repro:** `E:/COBOL-coord/scratch/review-w20261872-a/p/m/a1.cob`, rows 5, 7-10, 12 and 13.

**R1.** No open note covers it.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/FunctionValueLane.cs#Of`, `src/WiseOwl.Cobol.Compiler/CodeGen/Emit/IntrinsicRenderer.cs#RenderFloat`.

**Owner decision (2026-11-05):** asked whether the 2026-11-04 exactness ruling (PB4569) reaches D16, with this note's witness,
the owner answered "Keep D16 binary64" (PB4731) and, for a float item beside an exact-valued term, "Same answer as PB4731"
(PB4751). An expression with a float item operand or receiver is evaluated wholly in IEEE binary64; the values above are
the documented native results, not defects. NUMERIC_DESIGN D16 records the boundary; CONFORMANCE.md DOC-A.1-123 already
publishes the rule. No code changes.
