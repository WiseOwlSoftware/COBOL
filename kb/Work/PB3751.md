# PB3751 — the grammar demands an optional word that sits inside an optional group

**Sites:** `src/Cobol.Net.Frontend/Grammar/Core/CobolReportWriter.g4#reportPageClause`, `src/Cobol.Net.Frontend/Grammar/Core/CobolData.g4#valueClause`, `src/Cobol.Net.Frontend/Grammar/CobolParserCore.g4#mcsReceiveStatement`.

Filed 2026-10-25 by the enqueue clerk from the PB715 report's New defects items 1-3. All three share ONE root: a word the printed
format leaves plain (optional, §8.3.2.4.3) is written as required inside an optional group, the class PB695 closed for the
top-level words. PB715's repaired `scripts/spec/audit_grammar_optional_words.py` now reports them, and the report confirms
each on the rendered page. Rule, quoted by the report with `cite.py --check`: §8.3.2.4.3 "may be specified at the user's option
with no effect on the semantics of the format."

## The three sites
1. **PAGE clause**, §13.18.39.2 (page 468 of the PDF): `[ LIMIT IS | LIMITS ARE ]`, all four words plain. `reportPageClause` has
   `(LIMIT IS? | LIMITS ARE?)?`, so LIMIT is demanded wherever IS is written and `PAGE IS 60` is refused.
   **Needs adjudication before a fix:** GnuCOBOL also requires LIMIT before IS. The spec reading (render page 468 first,
   CLAUDE.md rule 1) controls over GnuCOBOL (rule 1 precedence); an adjudicator confirms the reading.
2. **VALUE clause formats 3 and 5**, §13.18.63.2 (page 546): `[ IN alphabet-name-1 ]`, IN plain. `valueClause` has `(IN cobolWord)?`,
   which refuses the IN-less form.
3. **RECEIVE**, §14.9.31.2 (page 732): `CONTINUE AFTER { arithmetic-expression-1 SECONDS | MESSAGE RECEIVED }`, AFTER and SECONDS plain.
   `mcsReceiveStatement` demands both.

## Repro
`python scripts/spec/audit_grammar_optional_words.py --clause 13.18.39.2` (and `13.18.63.2`, `14.9.31.2`), run on a tree that has
PB715's audit.

## What the user sees
Legal source (`PAGE IS 60`, a VALUE with the IN phrase left out where the format omits it, a RECEIVE with the plain words left
out) is refused as a syntax error.

## Fix direction
Relax each site, with a golden per site (an accept case in every edition that has the format), after the page render and the
adjudication of site 1. Then re-run the audit: it must report none of the three.
