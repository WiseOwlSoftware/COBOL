## Finding — define-directive (rejects-legal-source)

The compilation-variable store lives only in the text-manipulation stage, so the two non-conditional-compilation uses that GR1 permits are refused: CONSTANT ... FROM compilation-variable-name-1 is staged loud (COBOLNET0899), and a compilation-variable-name in another directive's literal position (>>COBOL-WORDS) is rejected as 'not an alphanumeric literal'.

**Rows:** GR-7.3.11.4-1

**Repro:**

```
>>DEFINE N AS 3 / 01 CN CONSTANT FROM N. / DISPLAY CN  (E:\Temp\claude\E--CobolSharp\a700c052-f9e4-4942-84ff-a13c7505d6ec\scratchpad\adj-d2\out\probe\define-directive\p1.cob) -> error COBOLNET0899 constant-from-compilation-variable. Also: >>DEFINE W1 AS \"DISPLAY\" / >>DEFINE W2 AS \"SHOW\" / >>COBOL-WORDS EQUATE W1 WITH W2  (E:\Temp\claude\E--CobolSharp\a700c052-f9e4-4942-84ff-a13c7505d6ec\scratchpad\adj-d2\out\probe\define-directive\s1.cob) -> error COBOLNET1623.
```

**Expected from the spec:** §7.3.11.4 GR1: after a DEFINE without OFF the name 'may be used ... in any compiler directive where a literal of the category associated with the name is permitted, in a defined condition, or in a constant entry where the FROM phrase is specified'. §13.10.4 GR1: the constant behaves 'as if ... the text represented by compilation-variable-name-1 were written where constant-name-1 is written' - CN displays 3. The COBOL-WORDS EQUATE takes the literal values DISPLAY/SHOW, so SHOW acts as DISPLAY.

**Observed:** DataBinder.BindConstantEntry refuses every FROM phrase with COBOLNET0899 (docs/DIAGNOSTICS.md row constant-from-compilation-variable: 'the preprocessor's compilation-variable store is local to the text stage and not reachable at bind time'). No kb/Work note owns this staging. CobolWordsDirectiveProcessor accepts only a literal token and never consults the DEFINE table. >>IF/>>EVALUATE/>>DEFINE operand uses DO resolve.

**Code site:** src/Cobol.Net.Compiler/Binding/DataBinder.Constants.cs#BindConstantEntry; src/Cobol.Net.Frontend/Preprocessor/CobolWordsDirectiveProcessor.cs; src/Cobol.Net.Frontend/Preprocessor/ConditionalCompilationProcessor.cs#Run (the _defines store)
