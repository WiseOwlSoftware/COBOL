# PB6352 — NearestInNameSet has no method tier

`SymbolTable.NearestInNameSet` (`src/WiseOwl.Cobol.Compiler/Binding/SymbolTable.NameSet.cs`, lines 61-104) reads `_dataNames` and `_conditionNames` only, never a method's own tier. Inside a method, the cross-class "declared nearer" ranking therefore ignores method declarations. It shares that root with the hiding checks `NearerNameOfAnotherClassHides` and `DeclaredNearerInNameSet`.

**Status: unprobed.** PB6276 found it in a `_conditionNames` sibling sweep and did not fix it (outside its group). Next step: probe a method that declares a name which a data item of another class also declares; if the answer differs from the nearest-declaration rule, reclassify to a defect with the harm flag the probe shows.
