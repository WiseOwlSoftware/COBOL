# PB4925 - a pointer token displaced by 2^32 or more aliases another area

**Sites:** `src/WiseOwl.Cobol.Runtime/Control/PointerImage.cs` (`PointerImage.DataPointerOf`), `docs/CONFORMANCE.md` (DOC-A.1-216, the one-way/round-trip determination whose domain statement this changes)

**Report (R1-4, low).** The PB4838 slot image writes a data pointer to a file record as an 8-byte address-shaped token (`PointerImage`, bases allocated process-wide by
`s_nextBase`); READ decodes it with `DataPointerOf`, which resolves to the NEAREST base. A pointer displaced from its area by 2^32 or more (legal COBOL pointer
arithmetic on an unbounded `SET ... UP BY`) decodes to a window of another area: a silent wrong pointer, not a refusal. The implementer documented the
domain +/-2^31 in DOC-A.1-216 as inherent in the 8-byte token, and the finisher marked the lead note-ready: the decode answers a displacement outside
the domain with an error (an unusable pointer, so the READ's pointer is NULL or the statement raises the exception condition the standard names for an
invalid pointer, which the fixer chooses from the spec), or the base spacing exceeds 2^32 so a nearest-base answer is unambiguous. Expected: a displacement
beyond the domain never silently names another area. Repro: write a pointer SET UP BY 4294967296, READ it back, compare `ADDRESS OF` against a second area.
Not run by the clerk.

Source report and lead: `w20261905d-PB4838-report.md`, R1-4.

## Landed (wave 20261915 A) - a far pointer takes a base of its own

A data-pointer whose displacement from its cell lies outside [-2^31, 2^31) is not a valid address of the cell's storage (§2023:13.18.5.4 GR4), so its image needs
identity, not arithmetic: `PointerImage.FarBase` gives one base per (cell life, displacement), and `DataPointerOf` decodes it to exactly that pointer
(`FarDisplacement`), so the token never names another area's window and equal pointers image equal. DOC-A.1-216 now states the exact round trip.
Test: `unit:SlotImageRoundTripTests.DataPointerOf_APointerDisplacedBeyondTheWindow_ReadsBackAsItself_NeverAsAnotherArea` (A + 2^32 next to B's base). Sibling sweep:
`>> BaseShift` and the nearest-base rounding occur only in `DataPointerOf`; program/function pointers and message tags carry no displacement.

**Sites:** `src/WiseOwl.Cobol.Runtime/Control/PointerImage.cs` (`Of`, `DataPointerOf`, `InDomain`, `FarBase`, `FarDisplacement`), `docs/CONFORMANCE.md` (DOC-A.1-216).
