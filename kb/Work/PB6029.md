- **CALL/CANCEL literal-1** faults are reported under COBOL1627 `intrinsic-argument-class`
  (`src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CallBinder.cs:1189`, `:1192`), a code whose name and descriptor are the
  intrinsic functions'. They belong to a CALL/CANCEL descriptor (COBOL1681 / COBOL1696's family or their own). Goldens follow.
- **COBOL2256** `assign-target-list-not-allowed` (`src/WiseOwl.Cobol.Compiler/Binding/AssignTargetRule.cs:65`) cites
  §1985:VII.2.3.3 SR3 (sequential I-O) for a relative or indexed file too; each organization's own SELECT rule is its module's
  (§1985:VIII.2.3.3, §1985:IX.2.3.3; derive the rule number).
- **COBOL1516** `intrinsic-argument-data-item-rule`: its IsoSection names LENGTH/BYTE-LENGTH, but it is emitted only from the
  HIGHEST/LOWEST/SMALLEST-ALGEBRAIC screens.
- **COBOL1624** `external-file-item-not-external`: its description says the requirement did not exist before 2023; 1985 states it
  for the RELATIVE KEY, PADDING CHARACTER and LINAGE items (§1985:VIII.2.4.4 GR8, §1985:VII.2.7.4 GR6, §1985:VII.3.7.4 GR11c;
  the descriptor's Rule1985 records them).
