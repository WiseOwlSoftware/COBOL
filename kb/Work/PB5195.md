# PB5195 - at --std 85 ALTER accepts a section-name as procedure-name-1 when the section holds one paragraph: AlterIsSoleGoToParagraph tests PcRange.IsParagraph (Start == End), which a one-paragraph section meets

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/SetAlterBinder.cs` (`BindAlter`, `AlterIsSoleGoToParagraph`)
- `src/WiseOwl.Cobol.Compiler/Binding/Model/PcRange.cs` (`IsParagraph`, deleted by the landing)
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/ProcedureTableBuilder.cs` (`ResolveProcedureQuiet`, now the `ResolvedProcedure`) and `tests/WiseOwl.Cobol.Tests.Unit/ProcedureRangeEmptinessDriftTests.cs` (landed)

**Mechanism.** §1985:VI.6.7.3 SR1 makes procedure-name-1 the name of a paragraph that contains one sentence, a GO TO without DEPENDING. `BindAlter` refuses everything else except one case: its paragraph test is `PcRange.IsParagraph` (Start == End), which a section with one paragraph also meets, so `ALTER S7 TO PROCEED TO P3`, S7 a section whose one paragraph P7 holds a GO TO, compiles at --std 85 and alters P7's GO TO through the section-name.

**Found by.** The 1985 code read (2026-11-10; its records are `E:/COBOL-coord/scratch/coderead-85/for-register.json`): each rule below was read against the code sites it names and probed at `--std 85`, and found non-conforming. Verdict, harm, evidence, repro and observed text are the records'; the rows' verdicts are recorded on another branch.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids of the list below.

**Rules (1; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-SR-VI.6.7.3-1` - `§1985:VI.6.7.3 SR1` (record verdict: PARTIAL, harm: under-rejects). Checked: §1985:VI.6.7.3 SR1: "Procedure-name-1 is the name of a paragraph that contains a single sentence consisting of a GO TO statement without the DEPENDING phrase.". Code sites read: src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/SetAlterBinder.cs#BindAlter; src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/SetAlterBinder.cs#AlterIsSoleGoToParagraph; src/WiseOwl.Cobol.Compiler/Binding/Model/PcRange.cs#IsParagraph. Code read: §1985:VI.6.7.3 SR1: 'Procedure-name-1 is the name of a paragraph that contains a single sentence consisting of a GO TO statement without the DEPENDING phrase.' BindAlter resolves procedure-name-1 and reports COBOL1757 unless target.Range.IsParagraph and AlterIsSoleGoToParagraph (one sentence, one statement, a GO TO whose GoToFormats.Of is not Depending); probed at --std 85, a paragraph holding GO TO DEPENDING, no sentence, two sentences, an IF, a GO TO followed by a second statement or a CONTINUE is refused, a multi-paragraph section is refused, and a single GO TO (with a target or target-less, qualified or not) is accepted. The paragraph test is PcRange.IsParagraph (Start == End), which a SECTION holding exactly one paragraph also satisfies; BindAlter never reads ResolvedProcedure.IsSection, so ALTER section-name is accepted when that section's only paragraph is a single GO TO, and the GO TO of that paragraph is altered. Implemented for every shape of the paragraph's content; not implemented for the paragraph-versus-section distinction when the section has one paragraph. The witness refuses a paragraph whose sentence is DISPLAY followed by GO TO.
