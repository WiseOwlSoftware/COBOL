# PB5228 - three un-prefixed citations in the PB5158 I/O case

**Sites:** none (no code file: the comment of one conformance case, `conformance-suite/cases/14.9.30-READ/pb5158_io_phrases_reversed.cob`
lines 15, 24 and 26).

The header comment writes `(5.2.6.4, cite.py OK)`, `(14.9.30.4, AT END)` and `(9.1.14, cite.py OK)`. CLAUDE.md rule 1
requires the edition form, `§2023:<clause>`. `citation.py` reads only that form, and its BARE refusal reads a `§` with
no edition, so a clause number with no `§` at all is invisible to both. All three are correct today: the reviewer ran
`cite.py --check` on each with the prefix and got OK.

**Fix:** write each as `§2023:5.2.6.4`, `§2023:14.9.30.4` and `§2023:9.1.14`. The next change that touches this case,
or the 14.9.30-READ directory, carries it, so it costs no gate of its own.
