# PB1551 — LANDED (wave 1097, group D)

## Landed

**Re-probe (w1097d, base 59208d8fb):** reproduced in every receiving position — `SET NULL TO O`, `SET SELF TO NULL`,
`SET SUPER TO NULL`, `MOVE X TO SELF`, `INITIALIZE SELF`, `ACCEPT SELF`, `INVOKE … RETURNING SELF`, `MOVE X TO O AS C`
and `MOVE PP TO ADDRESS OF PROGRAM "X"` all drew COBOL0901 (§8.9); `SET ADDRESS OF PROGRAM "X" TO PP` drew COBOL0201;
`ADD 1 TO SELF.` a bare COBOL0001.

**Fix (the superset parse + ONE form table).** Every receiving grammar slot is a `receivingIdentifier`
(`setReceivingIdentifier` in SET — no data-address alternative, so Format 7 keeps `ADDRESS OF data-name-1`): MOVE (and
CORR), INITIALIZE, ACCEPT, the arithmetic resultants (and the CORR forms), COMPUTE, DIVIDE REMAINDER, CALL / INVOKE
RETURNING, READ / RETURN INTO, STRING INTO / POINTER, UNSTRING INTO / DELIMITER IN / COUNT IN / POINTER / TALLYING,
INSPECT TALLYING, SEARCH VARYING, PERFORM VARYING / AFTER, ALLOCATE RETURNING and every SET receiving list (F1, F2, F5,
F8, F9, ENTRY, SIZE, CONTENT, save-locale, Format 7's receiver). `nonReceivableIdentifier` parses the view of a data
reference, SELF / SUPER / NULL (with or without a view) and the function- and program-address-identifiers.
`ExpressionBinder.ResolveReceiving` refuses each by the row of `ReceivingOperandForms` (keyed by `NonReceivableForm`)
that names its rule — §8.4.3.7.3 SR1 NULL (COBOL3977), §8.4.3.8.3 SR2 SELF/SUPER (COBOL3978), §8.4.3.11.3 SR5 /
§8.4.3.12.3 SR3 / §8.4.3.13.3 SR4 the address-identifiers (COBOL3979), §8.4.3.5.3 SR2 the view (COBOL2871) —
and the data-reference screens (LINE-COUNTER, LINAGE-COUNTER, EXCEPTION-OBJECT, the view of a qualified item) report
from the same table. At COBOL-85, where §8.9 leaves SELF / SUPER / NULL / ADDRESS free, an undeclared one is the
§8.4.2.1 undefined reference (COBOL1639), never a rule about a predefined identifier the edition lacks. In the
mixed arithmetic rules' SENDING role (Format 2 with GIVING) such an operand is §8.8.1.1's COBOL0844. The
per-statement `objectViewReceiver` refusals (SET Format 5, INVOKE RETURNING) and the SET object-reference loop's
EXCEPTION-OBJECT copy (kb/Work PB1008) are deleted. Drift test `ReceivingOperandFormDriftTests`.

identifier-3 included). Its two RECEIVING rows are this note's mechanism and move here: **SR-8.4.3.8.3-2** ("This

parse of those receiving positions plus the one receiving-operand check this note describes.
