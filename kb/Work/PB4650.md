**Landed (w20261868c, review round 1 answered by w20261868c-r1).** Re-probe on `630b1f2fb`, `--source-format free`: LIBX, CLIENT1, CLIENT2 failed with `CS0012: The type 'BOX' is defined in an
assembly that is not referenced ... 'LIBX'`. The same arm failed for two libraries holding an identical BOX (CLIENT1 over one, CLIENT4 over the other).
Root: the `ExpansionKey` hashes a class's record and not its home, so "same key" does not say "made over the classes this compilation holds". The first fix
read the expansion's `AssemblyRef` table, which cannot say it: Roslyn emits no reference for an actual or a resolution the expansion's code does not use (review
R1-1), and a set test over the table is satisfied by a home referenced for ANOTHER named class (R1-2). The expansion now PUBLISHES the homes it was made over
(`ExpansionIdentity.Homes`, attribute `ExpansionHomes`: the assembly simple name of each resolution, then each actual; empty for a class the standard supplies), and an existing
expansion is imported only when they equal this compilation's, position by position (`ExpansionPlacementPass.Place`; `HomeOf`: an imported class's assembly, the file that holds a named
expansion, this compilation's output name for a class written here, which is the reference cycle of section 10.5 step (3)). A same-key copy over other homes reports nothing; when it
holds the file placement (a) would write, the expansion is made in the group's assembly instead (COBOL2240 where the skeleton's state forbids that, naming the reason). Witnesses (Unit,
`ExternalRepositoryExpansionTests`): `AnExpansionCompiledAgainstALibrarysClass_IsNotImported_ByAGroupThatWritesThatClassItself`, `AnExpansionCompiledAgainstAnotherAssemblysClass_IsNotImported_NorWrittenOver`,
`AnExpansionOverTheSameClasses_IsImported_WhateverItsCodeReferences` (R1-1), `AnExpansionOverADifferentHomeOfOneNamedClass_IsNotImported_ThoughAnotherNamedClassSharesTheHome` (R1-2),
`AnExpansionWhoseFileHoldsTheSameExpansionOverAnotherHome_IsRefusedWithThatReason_WhenItCannotLiveInTheGroup` (R1-4); conformance golden `12.3.8-REPOSITORY/pb4650_unused_actual_expansion_is_one_class` (R1-5,
accepted from 2002) and its refusal at 85.
