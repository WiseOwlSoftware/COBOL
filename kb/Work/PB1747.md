# PB1747 — run-process failures under load read as conformance reds

## What happened

The machine was running wave 73's implementer gates beside the lander (14 dotnet/testhost processes at the time).

1. Gate run `TestResults/build-local/20260929T203208Z-bb423a` (lander mode, whole population): one red,
   `NumericEditedDifferentialTests.DivideRemainder_Basic` —
   `WiseOwl COBOL failed to compile/run:` followed by an EMPTY detail. The compile succeeded (a compile failure
   prints `[cobolnet compile] …`), so the program ran and exited non-zero with nothing on stderr. The test's program
   is a plain DIVIDE … REMAINDER that no train-73 cluster touches, and the whole class re-run in isolation passed
   11/11.
2. Gate run `20260929T203821Z-321757` (same tree, nothing changed): one DIFFERENT red,
   `SearchIndexRangeSpecTests.Serial_VaryingAnIntegerItem_TakesEveryIncrementIncludingTheLast(edition: 2014)` —
   `Failed to map file. CreateFileW(E:\Temp\CobolNet_Run_83ff145b\prog.runtimeconfig.json) failed with error 5`
   (ERROR_ACCESS_DENIED from the .NET host reading a file the harness had just written). The class re-run in
   isolation passed 37/37.

Neither is attributable to a cluster: the case differs between runs of the same tree, and the second is an OS error
opening the harness's own output.

## Defects

- **Diagnosis is lost.** `CobolNetCompiler.CompileAndRun` (`tests/Cobol.Net.Tests.Conformance/CompilerUnderTest.cs`)
  returns `CutRunner.Run`'s `detail`, which is stderr only; `DifferentialGolden.Assert` prints it. The exit code and
  stdout are dropped, so a host failure with no stderr reads as an empty message. The detail should carry the exit
  code (and stdout's tail) for every non-zero run.
- **A transient host start failure is indistinguishable from a program failure.** An access-denied on
  `prog.runtimeconfig.json` (likely a scanner or indexer opening the freshly written file) is an environment fault,
  not the program's result. The harness could recognize the .NET host's own start-up failure (it prints before the
  program runs) and report it as such, or retry that start once — never retry a program that ran.

## Repro

Not deterministic: run `pwsh scripts/build-local.ps1 -Mode lander` while other gates run on the same machine.
