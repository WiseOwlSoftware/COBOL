# PB3599 - BitRunMap.RunOf is a linear scan

`BitRunMap.RunOf(item)` (`src/Cobol.Net.Compiler/Binding/Model/BitLayout.cs:529` on main, `:737` on PB3564's branch) answers with
`start.Values.First(r => r.Contains(item, ReferenceEqualityComparer.Instance))`, a scan of every run and every run's members per
query. It is off the hot path after the per-parent memo (`RunsOf`), so this is a LOW performance lead with no wrong answer.

## Fix shape (for the implementer)

Build a reference-keyed item-to-run dictionary once when the map is built (it already holds `inRun`) and answer `RunOf` with one
lookup; the `inRun` set folds into it. No behavior change: the existing bit-layout goldens are the differential.
