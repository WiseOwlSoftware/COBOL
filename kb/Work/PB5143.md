# PB5143 - null facilities against "at least one of the specified forms"

**Sites:** none (an analysis awaiting an owner determination; it changes no file).

**Not answered here.** The report says an owner determination is needed; this note records the question.

1. **RERUN.** §1985:VII.2.12.4 GR2 (checked with `cite.py --check`) says: "There are seven forms of the RERUN clause ... The implementor
   must provide at least one of the specified forms of the RERUN clause." The compiler parses and screens RERUN (PB4945, SR1-SR5) but
   provides no checkpoint facility. The PB5086 adjudicator named it an unexamined sibling and VCR row 7.15 says a null RERUN facility
   is conforming. The question: does a clause that is accepted and has no effect "provide" a form under GR2? It shares its root with
   PB4945.
2. **MULTIPLE FILE reel, GR20 a and c** (§1985:VII.4.3.4): that one file is open at a time on a reel and the position numbers are a
   null facility on disk files. It is recorded in `docs/CONFORMANCE.md` section 3.4; there is no code. The question is the same
   shape: whether a null facility on disk storage conforms, which is the posture row 7.6 takes ("inert in function only").

**Owed.** The owner's determination on whether a null facility is conforming for these two cases; the answer is recorded in
`docs/CONFORMANCE.md` as a decision, and if the answer is no, the facility becomes a defect with the full feature as its scope
(CLAUDE.md rule 3).
