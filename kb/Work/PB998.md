# PB998 — OPEN

## Repro — measured
`scratchpad/reg12/q04_set15.cob --std 2002`: three statements `SET CONTENT OF F TO NEAREST-TO-ZERO` / `FLOAT-INFINITY` /
`FARTHEST-FROM-ZERO` → three errors, each reading `COBOLNET0900: SET CONTENT OF n TO FARTHEST-FROM-ZERO requires COBOL-2014`.
(The lead's "flagged only some of the statements" did not reproduce: all three were flagged.) The companion
`USAGE FLOAT-BINARY-64 requires COBOL-2014` error in the same run prints with NO source position — PB1011's mechanism.

## Code site
`ConstructRegistry.g.cs` — the construct row's display text is a fixed string; the gate site does not substitute the
statement's own value word.

## What the fixer owes
Name the construct by its format ("SET CONTENT OF … TO …, Format 15") or substitute the written value word; sweep the
other construct rows whose display text hard-codes one alternative of a brace (grep the registry for a literal word
that is one member of a choice).
