# PB5606 - at --std 2002 ADDRESS OF and SAME AS accept a communication-section item, though their 2002 section lists exclude it

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/AddressOfOperandScreen.cs#Admit`
- `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.cs#ExpandSameAsEntry` (SR7 test)

**Mechanism.** Two 2002 rules admit exactly four data sections (file, working-storage, local-storage, linkage); 2002 has a fifth, the communication section. The binder screens exclude only screen/report entries, constants and special registers, so a CD record item or a CD's own field passes.

**Inventory.** Rows claimed: `2002-SR-8.4.2.11.2-1`, `2002-SR-13.16.47.2-7`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:8.4.2.11.2 SR1`: "Identifier-1 shall reference a data item defined in the file section, working-storage section"
- `§2002:13.16.47.2 SR7`: "Data-name-1 shall reference an elementary item or a level 1 group item described in the file, working-storage, local-storage, or linkage section"
- `§2002:A.1.1`: "The communication section is located in the data division of a source program"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p/addr-cd.cob, p/cd-sameas-cdref.cob); the text is inline. Command: `cobol.exe p/addr-cd.cob --std 2002 --run`

`p/addr-cd.cob`:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. ADDRCD.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  P   USAGE POINTER.
```

**Observed.** addr-cd (SET P TO ADDRESS OF A1, A1 in the record under CD CDOUT): only warning COBOL0903, prints SET, rc=0. cd-sameas-cdref (05 C1 SAME AS C2, C2 a CD record item): prints ABCD, rc=0.

**Expected (from the 2002 text).** both refused at compile time.

**Sibling sweep.** every 2002 rule that lists sections (BASED, TYPEDEF, GLOBAL/EXTERNAL placement, CALL/INVOKE argument sections such as §2002:14.8.22.2 SR9, which DOES list the communication section): grep the binders for section enumerations and read each against its 2002 rule. The k0v3-3 reader lists the inline 13.14 clauses the screen missed.

**Other editions.** 85: n/a (no ADDRESS OF, no SAME AS). 2014, 2023: n/a (no communication section).
