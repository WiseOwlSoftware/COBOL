# PB5623 - an omitted parameter used as the RETURNING item of a CALL in the called program raises no EC-PROGRAM-ARG-OMITTED (2002 and 2023)

**Sites:**
- `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/CallEmitter.cs` (`CallEmitter.EmitCall`) (the CALL RETURNING emission path skipped the omitted-parameter guard that identifier-1 gets)
- `src/WiseOwl.Cobol.Compiler/CodeGen/Roslyn/PlaceRenderer.cs` (`PlaceRenderer.RootGuard`, `PlaceRenderer.OmittedReferenceRaise`, new)

**Mechanism.** The omitted-parameter reference check covers CALL identifier-1 but not RETURNING identifier-3: GR12 makes any reference to an omitted parameter (except as an argument or in the omitted-argument condition) set EC-PROGRAM-ARG-OMITTED, and RETURNING identifier-3 is identified at the start of the CALL.

**Inventory.** Rows claimed: `2002-GR-14.8.4.3-12`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:14.8.4.3 GR12`: "is referenced in a called program, except as an argument or in the omitted-argument condit"
- `§2002:14.8.4.3 GR3a`: "item identification is done for identifier-3 at the beginning of the execution of the CALL"
