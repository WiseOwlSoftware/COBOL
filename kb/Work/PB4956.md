# PB4956 - a parent-clause citation passes when its child names the construct

**Sites:** `scripts/spec/audit_code_citations.py` (the PHANTOM and SUBJECT checks)

**Report (PB4744 finisher; shares its root with PB4928, which is landed, so this is a new note linked to it).** A citation of a parent clause whose CHILD clause names the construct the context names passes PHANTOM and SUBJECT. The PB4928 case: "category national" cited at the parent 8.5.2 while the child 8.5.2.10 is "National category". The finisher's shape, which makes the next case automatic: a NARROWER check in `audit_code_citations.py` that flags a citation when a child clause's title words all appear in the context and the cited parent's own text does not state the rule. It needs a planted self-test case (the PB4928 shape) and a sweep of the tree's existing citations for parent-vs-child cases the new check finds.
