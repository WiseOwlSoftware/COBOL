# PB5467 - `selftest_layout` does not require `ensure_utf8()` in a self-test case file's main block, so a converted case file can run with a non-UTF-8 console

The layout rule of the self-test cases (PB5428's `selftest_layout`) checks where a case file lives and what it exports, but not that its main block calls `ensure_utf8()`. A case file converted to the layout without that call runs under a console whose encoding is not UTF-8. The rule is mechanical: scan each case file's main block and refuse one without the call, with a self-test that fails on a file lacking it.

**Sites:** `scripts/selftest_layout.py` (`check`: the new requirement; the rule's self-test beside it).

The other item of that report section (the planner's cases form one order-dependent world) belongs to open note PB3726; nothing is filed for it here.
