# PB4852 - the branch survey runs `git cherry` over a branch with no merge base on main

**Measured, 2026-11-06.** `plan_wave.py --from-budget` started at 09:41:46 PST and returned about 10:16, printing nothing until the end. At 10:00:33 and again at 10:08:54 its children were `git -C E:\COBOL cherry origin/main <branch>`; the 10:08:54 listing shows eight at once, among them `spec-versioned-names`, `notes-transcription-diagrams`, `notes-spec-transcriptions` and `doc-float-arithmetic`. The `spec-versioned-names` call has a different process id in the two listings, so the branch was asked again: the planner runs this question more than once, and a round takes up to about 8 minutes. The previous enqueue unit recorded about 7 minutes per survey.

**The mechanism (the first half measured, the link to the eight minutes inferred).** `git merge-base origin/main spec-versioned-names` prints nothing: the history rewrite of 2026-11-05 (PB4814) left that branch with no common ancestor on main. With no merge base, `git cherry` has to compare the branch against all of main's history (11,939 commits at this writing). The call is `prune_worktrees.carried` (`scripts/prune_worktrees.py`, `git('cherry', 'origin/main', branch, cwd=repo)`). Timing one such call against a branch that has a merge base would confirm the inference; that has not been done. PB3582 already moved a sibling question to one batched `git_batch.patch_ids` read rather than a `git cherry` per pair.

**What it costs.** The supervisor's 60-minute STOP-UNIT (PB3638) arrived at 10:36, 19 minutes after the fleet started, so a wave unit gets far less of that hour than it appears. Any other caller of `carried` would pay the same price; that was not measured. The `git cherry` children seen were the planner's. The landing lane's tick was running only `git patch-id` at 10:01.

**The fix to weigh.** Answer `carried` from one batched patch-id read, and treat a branch with no merge base as its own case. Deleting the pre-rewrite branches removes today's cost but not the mechanism: the next rewrite would bring it back. The operator abandoned those branches on 2026-11-06 (PB4814 records each), so the measured cost goes when they go; the mechanism stays until this note lands.
