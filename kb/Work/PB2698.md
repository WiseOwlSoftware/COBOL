**Wave kind:** defect-for-fix-lane. Filed by the train 1042b lander. Train 1042's cluster F (PB2640/PB2641) wrote a
"more Int128.MinValue magnitude sites" paragraph into kb/Work/PB2639 while PB2639 was open on main; train 1042b then
landed PB2639 (cluster H), which fixed the `CobolNum` and edit sites (`PositionOf`, `TryStore`, `InBinaryRange`,
`WrapBinary`, `RescaleStoreCap`, `InPictureRange`, `CobolEdit`, `CobolLocaleEdit`) but not the intrinsic ones. So the
remaining sites would have been orphaned in a landed note; they live here.

**Sites (on the tree train 1042b leaves):**
- `src/Cobol.Net.Runtime/Intrinsics/CobolIntrinsics.Exact.cs:86` — `AbsScaled(Int128 v) => v < 0 ? -v : v`: for
  `Int128.MinValue` the negation wraps and FUNCTION ABS returns a NEGATIVE value. §15.7.4 (ABS returns the absolute
  value); the result does not fit the Int128 carrier at all, so the fix must decide the §14.7.5 / EC-SIZE disposition,
  not only swap in `CobolDec.UAbs`.
- `src/Cobol.Net.Runtime/Intrinsics/CobolIntrinsics.Exact.cs:473` — `Rescaled`: `Int128.Abs(unscaled) > limit`
  throws on MinValue. Probably unreachable today (the parsed significand is at most 38 digits), so the fix is
  `CobolDec.UAbs(unscaled) > (UInt128)limit` for robustness, with the reachability measured, not deduced.
- `src/Cobol.Net.Runtime/Intrinsics/CobolIntrinsics.Exact.cs:512` — `-p.Unscaled` feeding `CobolFloat.ScaledToSingle`
  (same bound as :473).
- `CobolNum.Divide` with exp < 0 and a divisor of `Int128.MinValue` takes the SDIDI through
  `CobolDec.From(Int128.MinValue, scale)` (a 39-digit significand), untested on the DivToOdd arm (F's lead).

**Repro shape:** a signed 16-byte `COMP-5` item holding LOWEST-ALGEBRAIC (the R2 batch 1 repro in PB2639), then
`COMPUTE R = FUNCTION ABS(X)` into an unsigned 16-byte COMP-5 receiver; expected 2^127 (or a size error by §14.7.5 if
the function's carrier is the limit), observed a negative intermediate.

**The one magnitude:** `CobolDec.UAbs(Int128) → UInt128` (train 1042b collapsed `CobolNum.Magnitude` and
`FloatResultant`'s private copy into it). Reuse it; do not add another.
