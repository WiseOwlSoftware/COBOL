## Landing (2026-11-27, wave 20262177)

Re-probe on the pre-fix tree: `>>TURN EC-ARGUMENT-FUNCTION CHECKING ON` then `CANCEL FUNCTION CHAR(W-Z)` (W-Z = 0) printed no CAUGHT; after the fix it does.
**Fix:** `BoundVisitorGenerator` reads a tuple's elements (`Members`: `ITypeSymbol.TupleElements`) in `CollectValueSources`,
`CollectSources`, `IsValueBearing` and `IsStatementBearing` alike, so `BoundCancel.Targets` yields its `DynamicName` from `OwnValueParts`
and a value node or a statement held in a tuple can no longer hide. **Pinned by** `BoundValueWalkDriftTests` (`CancelYieldsItsDynamicNameFromTheTuple`,
the CANCEL row of `AFunctionReferenceInAnyOperandPositionDeclaresEcArgumentFunction`, and `EveryValueHoldingPropertyIsReadByTheGeneratedWalks`, which
populates every value-holding property of every leaf with a sentinel) and by conformance `15.3-Arguments/pb6328_ec_argument_function_every_operand_position`
(position 10) with its 1985 refusal `pb6328_ec_argument_function_every_operand_position_below_2002`. Rows: none in `inventory_rows`; none re-verdicted.

**For the next implementer.**
- `src/WiseOwl.Cobol.Compiler.SourceGen/BoundVisitorGenerator.cs#Members` (with `Unwrap`) — the one enumeration of what a walk reads of a record or a tuple; reuse it for any new walk. The generator targets netstandard2.0: no list patterns, no `Index`/`Range` (a list pattern broke its build).
- `src/WiseOwl.Cobol.Compiler/Binding/Bound/BoundValueWalk.cs#SelfAndDescendants` — the one descent of a value part; write an EC operand rule as a node test over it, never a switch with a default arm. The generated `BoundStatementTree.ValueChildren` is what it reads.
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/EcBinder.RaiseDeclarations.cs#PartHasIntrinsic`, `#OperandsIn` — thin node tests over that walk.
- `tests/WiseOwl.Cobol.Tests.Unit/BoundValueWalkDriftTests.cs` — populates each value-holding property with a sentinel (a null-probe cannot tell an unread position from an empty one); `ModelsHeldByReference` is its one named exception (the report models; entering them needs a cycle-safe walk).
- Trap: a `EVALUATE ... WHEN "A" THRU FUNCTION CHAR(W-Z) IN AL` probe stays silent when the low bound already fails, because the high bound is then never evaluated; probe a range whose low bound holds.
