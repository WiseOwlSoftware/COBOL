# PB351 — an undelimited IF where the format writes imperative-statement-1

**Rows:** `FMT-14.9.34.2` (shared with **PB350**; this note owns the mechanism, which is not RETURN-local).

## The program

`<lane3 scratch>/out-b1/probe/p12/p12.cob` writes
`RETURN SF AT END IF WS-EOF = "N" MOVE "Y" TO WS-EOF NOT AT END DISPLAY "R=" S-TXT.`
— an IF with no END-IF as imperative-statement-1. Compiles and runs (prints `R=ONE`).

## The rule

> §14.5.1: An imperative statement specifies an unconditional action to be taken by the runtime element or is a
> conditional statement that is delimited by its explicit scope terminator, as specified in Table 12.

`--check 14.5.1 "is a conditional statement that is delimited by its explicit scope terminator"` → **OK**, and
the same clause adds *Any statement with a conditional phrase that is not terminated by its explicit scope
terminator is a conditional statement.* Table 12 gives IF the explicit scope terminator END-IF. An undelimited IF
is therefore a conditional statement and is not admissible where §14.9.34.2 writes imperative-statement-1; the
program shall be rejected.

## What the compiler does

`CobolParserCore.g4:793` — `statementBlock : statement+` — is shared by `returnAtEndPhrase`, `readAtEnd`, the
INVALID KEY, ON SIZE ERROR, ON OVERFLOW, ON EXCEPTION and AT END-OF-PAGE phrases; `PhraseBlocks`' own doc comment
enumerates them. **This is one mechanism under roughly fifteen formats, not a RETURN-local slip.** It is filed
against `FMT-14.9.34.2` because that is one of the rows it makes defective and no other note owns it (grep
*imperative* over `kb/Work`: PB233, PB260, PB3, PB45, PB74, none about this).

## The fix shape

An *imperative statement list* grammar rule — or one bind-time predicate over the block's LAST statement — used
by every conditional phrase, with a drift test asserting **no phrase rule references `statementBlock` directly**.
Never fifteen local checks: the count is exactly what makes the local answer wrong.

**Code site:** `CobolParserCore.g4#statementBlock` (line 793).

## Landed (wave 1015, group C) — one screen of every imperative-statement operand

**Re-probed** on base `fbcb2b3b1`: `ADD 1 TO X ON SIZE ERROR IF X = 1 DISPLAY "A" NOT ON SIZE ERROR …`, `SEARCH K AT END
IF … WHEN K(IX) = 3 IF …` and `EVALUATE X WHEN 2 IF X = 2 DISPLAY "E2" WHEN OTHER …` all compiled and ran (`N`, `E2`).
**Fix:** `Compiler/Validation/ProcedureFormatPass.cs` (new, pre-bind, every edition) screens every `statementBlock`
whose parent is not `ifStatement` and refuses a conditional statement in it — COBOLNET2796
`conditional-statement-as-imperative` (§14.5.1, cite-checked: "Any statement with a conditional phrase that is not
terminated by its explicit scope terminator is a conditional statement"). IF's statement-1/-2 is the one exempt
operand (§14.9.19.3 SR1). The classifier `Binding/ConditionalStatements.IsConditional` reads both halves off the
parse: a conditional phrase is written when the statement's OWN syntax holds a `statementBlock`, and the terminator
is the token `END_` + the Table 12 name — no verb list, so a new statement rule is classified automatically.
**Drift:** `Table12StatementNameDriftTests` re-derives the terminator column from the scraped Table 12 (every
terminator is `END-` + name and is a lexer token; every conditional-phrase row has one) and proves the
`statementBlock` proxy sound (only a conditional-phrase row, or PERFORM with its REQUIRED END-PERFORM, reaches one);
`RequiredImperativeStatementDriftTests` carries five phrase families rejected and the delimited / IF complement.
**Goldens:** `conformance:85/pb351_delimited_conditional_operand` (delimited conditionals in ON SIZE ERROR, SEARCH
WHEN, EVALUATE WHEN, inline PERFORM; an undelimited one ending IF's statement-1); negatives
`pb351-search-when-conditional` (FMT-14.9.37.2) and `pb351-return-at-end-conditional` (FMT-14.9.34.2). Corpus sweep: one own golden wrote one (`2023/oo_object_report`, a READ … AT END with no END-READ inside an inline PERFORM; END-READ added, output unchanged); NIST and characterization wrote none.
