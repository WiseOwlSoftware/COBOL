# PB5609 - at --std 2002 SOURCE-COMPUTER. WITH DEBUGGING MODE. (no computer-name) is a parse error

**Sites:**
- `src/WiseOwl.Cobol` .Frontend/Grammar/CobolParserCore.g4#sourceComputerParagraph

**Mechanism.** The grammar nests the DEBUGGING MODE clause after computer-name (the 1985 shape): SOURCE_COMPUTER DOT (computerName debuggingModeClause? unrecognizedClause?)? DOT?. The 2002 format has two independent brackets, [computer-name-1] [WITH DEBUGGING MODE].

**Inventory.** Rows claimed: `2002-GR-12.2.4.3-3`, `2002-SR-12.2.2-2`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:12.2.4.2 SR1`: "If neither computer-name-1 nor the DEBUGGING MODE clause is specified, the second period"
- `§2002:12.2.4.3 GR3`: "When the SOURCE-COMPUTER paragraph is specified, but computer-name-1 is not specified"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p/sc_dbg_noname.cob); the text is inline. Command: `cobol.exe p/sc_dbg_noname.cob --std 2002 --run`

`p/sc_dbg_noname.cob`:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. SCDNN.
       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.
       SOURCE-COMPUTER. WITH DEBUGGING MODE.
       PROCEDURE DIVISION.
           DISPLAY "NO-NAME".
      D    DISPLAY "DEBUG-ON".
           STOP RUN.
```

**Observed.** error COBOL1971 (5,25): unexpected 'WITH'. 'WITH' is not a paragraph of the CONFIGURATION SECTION ... (ISO §2023:12.3.2), rc=65. In a method (refuter's mthdbg_noname.cob) the same parse error stands in for COBOL2644.

**Expected (from the 2002 text).** compiles (COBOL0903 obsolete warning) and prints NO-NAME, DEBUG-ON.

**Sibling sweep.** OBJECT-COMPUTER and SPECIAL-NAMES clause nesting at 2002 against the rendered PDF diagrams (CLAUDE.md rule 1: the OCR diagrams were lossy toward restriction).

**Other editions.** 85: no (the 1985 format nests it, which is what the grammar encodes). 2014: unknown (debugging mode removed or kept: check 2014 E.2).
