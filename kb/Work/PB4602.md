**Witness.** `E:/COBOL-coord/scratch/w20261863c/p/ALNSTR.cob`: a `01 T TYPEDEF STRONG` group and `01 X TYPE T ALIGNED.` draw COBOL2150 (ISO 13.16.3 SR14: "The TYPE clause shall not be specified in the same data description entry with any clauses except ...") and then a second COBOL1942 ("not an elementary or group data item") and a COBOL0881 on the same entry. Any illegal co-clause does the same.

**Mechanism.** After reporting COBOL2150, `DataBinder.cs#BindEntry` sets `typeRefName = null`, so the entry reaches the later passes as a PICTURE-less leaf. PB1312 measured the same class for `05 B REDEFINES A TYPE T.`.

**Fix shape.** The recovery keeps what the source wrote (the written TYPE name) or marks the entry so the later passes stay silent. Sweep every other pass that reads the cleared clause.

**Site:** `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.cs#BindEntry`.
