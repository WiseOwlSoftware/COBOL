# PB4570 - MEAN's 34-digit native value and the binary64 return carrier against GnuCOBOL's exact decimal

**Lead.** MEAN's native returned value is held to the 34-digit SDIDI (PB3860). GnuCOBOL's is exact: `MEAN (P, 1, 2)` shows `...334000000000000000000`
[`...000000000000000000334`]. PB3860 chose the SDIDI to meet "one reference, one value", which an exact value meets equally. The same CLAUDE.md rule 1 question
applies to DOC-A.1-92's binary64 carrier for VARIANCE, STANDARD-DEVIATION and PRESENT-VALUE on an all-fixed list: GnuCOBOL returns a decimal of 38 or more fraction
digits, so `VARIANCE (A, B, B)` of 31-digit items lands as `.2222222222222222000000` (shortest round-trip binary64) where GnuCOBOL gives `.2222222222222222222222`.

The §15.4.1 / §8.8.1.3 latitude is the implementor's, so the open question is only whether the precedence (spec, then GnuCOBOL) makes the carrier itself a departure.
PB4111's golden pins the D legs only after this is settled.
