# PB5722 - at --std 2002 RECEIVE INTO accepts an alphanumeric-edited item (2002: category alphanumeric) and SEND FROM refuses a numeric-edited item (2002: class alphanumeric)

**Sites:**
- src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CommunicationBinder.cs#BindReceive
- src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CommunicationBinder.cs#BindSend

**Mechanism.** CommunicationBinder.BindReceive and BindSend ask one class question (IntrinsicArgumentRules.ClassOf is null or Alphanumeric) where 2002 asks a CATEGORY for RECEIVE and a CLASS for SEND: ClassOf gives numeric-edited the NumericEditedDeEditing class, so SEND refuses it, and alphanumeric-edited is class alphanumeric, so RECEIVE admits it.
