# PB3760 — `(3)` is a computed operand, yet it crosses as the literal 3

**Sites:** `src/Cobol.Net.Compiler/Binding/Bound/BoundCall.cs#Gr8ArgumentLiteral`, `src/Cobol.Net.Compiler/Oo/ActivationDescriptions.cs#OfValue`, `src/Cobol.Net.Compiler/CodeGen/Verbs/CallEmitter.cs#ArgCarrierText`.

Filed 2026-10-25 by the enqueue clerk. A parenthesized numeric LITERAL `(3)` or `(-3)` BY CONTENT into a GROUP formal is still accepted and stores 3. The report cites §14.9.4.4 GR8 and §14.8.2.2 rule 2 (an adjudicator confirms with `cite.py --check` before the fix): they conform a group formal
only against an argument that is itself an alphanumeric group item or a literal; a parenthesized numeric literal is an arithmetic expression (PB3678's ruling: only an operator, a sign or enclosing parentheses make an expression), so the
call is not conforming and should be refused. It is under-rejection: the source is accepted and silently stores the value.

## Mechanism
`Gr8ArgumentLiteral.NumericText` (`BoundCall.cs` about line 31) recovers a literal's text from a `BoundComputedOperand`, so that `BY VALUE -1.234E-5` (which arrives as `BoundNegate(BoundNumLiteral)`) reads as a literal. It
cannot tell that spelling from a parenthesized `(3)`. Its readers: `ActivationDescriptions.OfValue` (line 33: `BoundComputedOperand ce when Gr8ArgumentLiteral.NumericText(ce.Expr) is { } text`) and `CallEmitter`'s numeric-literal funnel (the `case BoundComputedOperand ce when Gr8ArgumentLiteral.NumericText(ce.Expr)` arm, about line 1017 of `ArgCarrierText`).
Both read the recovery as "this is a written literal".

## Fix direction
Carry a bind-time statement of whether the operand was a written literal (a sign alone is part of the literal; an enclosing parenthesis is not) to those readers, rather than re-deriving it from the expression shape downstream (one reduction, PB165).
Golden: `CALL ... USING BY CONTENT (3)` into a group formal refused, in every edition, with `BY CONTENT 3` and `BY VALUE -1.234E-5` still accepted. Repro: `E:/COBOL-coord/scratch/mythos/w20261500g/p2.cob` lines 21-22.
