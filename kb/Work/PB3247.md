# PB3247 — a changed file's specific drift test is not in leg 1 without an impact map

Filed 2026-10-16 by the enqueue unit's clerk. Source: `E:\COBOL-coord\scratch\reports\w1084f-PB1177-report.md`, "Finisher" (the bullet starting "Lead (ready to file as a note"). Cluster PB1957, the CI-invariant survey; its body does not track this exact gap (grep: no `drift_rules` or impact-map mention).

**Mechanism.** With no impact map (`map none`), a change to `tests/version-matrix/traceability-inventory.json` does not put
the drift test that governs it in leg 1. `python scripts/spec/drift_rules.py tests/version-matrix/traceability-inventory.json`
names `SpecTraceabilityInventoryDriftTests`. It is not a tier-0c sweep (`drift_rules.is_sweep`: its paths are specific), so
the plan lists it in `not-run-Unit.txt` (run 20261016T111103Z-634929) and only the Linux whole-leg run caught the red.

**Harm.** A CI-invariant defect (CLAUDE.md "THE CI INVARIANT"): CI went red on a change the local gate passed.

**Site.** `scripts/gate_plan.py`: the tier assignment, TIER_ORDER and the 0a/0c rules (docstring lines 25-40, the
`SWEEP_TRAIT` block at lines 97-99).

**Fix shape.** A tier that puts in leg 1 the drift tests `drift_rules.py` names as the specific rules of each changed file
(derived from `drift_rules.py`, never a list in `gate_plan.py`), with a self-test whose changed file is the inventory JSON
and whose expectation is that class in leg 1 under `map none`.

## Landed (wave 20261026 group A)

Re-probe on base 24e337272: the first two witnesses no longer reproduce. PB3531 (landed) added tier 0d, which reads
`drift_rules.governed` from the diff with or without a map, so `traceability-inventory.json` already names
`SpecTraceabilityInventoryDriftTests` and `docs/CONFORMANCE.md` names `AnnexA1RegisterDriftTests`. The third
reproduced: for a conformance golden, `drift_rules.py` named none of the drift tests that read the corpus, because they
read it through a helper class (`SuiteManifest`) and name no path. The sibling sweep found the same gap for a kb/Work
note (`ClosesRowsBackLinkDriftTests` and `DefectiveRowCoverageDriftTests` read the register through `WorkRegister`, and
the index's hand copy of TestRepo's helpers lacked `Kb`), and 24 `Path.Combine(TestRepo.Root, ...)` reads in 16 drift
tests that the index never read.

The fix is in `scripts/spec/drift_rules.py`. `Sources` reads every top-level type a drift test uses by name (a member
access, `new`, `typeof`, a base type, `using static`; comments do not count), in the test's own project or
`tests/_shared`. The test then governs, transitively, every path those helpers name (`Sources.inherited`), and the
per-file query prints `— through <helper>`. Inherited paths govern a file (tier 0d) but never make a class a sweep.
TestRepo's helpers are read from its source (`test_repo`); `--check` fails on a helper it cannot read. A suite test
named by its literal id resolves to its program. A call's path is its leading literals. `Path.Combine(TestRepo.Root,
...)` counts as the root helper, so seven classes that scan a whole tree now carry `[Trait("Sweep", "tree")]`
(OdoDependingAdmissionDriftTests had the trait on a method, where the planner never sees it). Witnesses:
`drift_rules.py --self-test` (a planted tree), and the `impacted_tests.py --self-test` arms that run with no map over
the note's three files and a kb/Work note.

## Landing

- `scripts/spec/drift_rules.py#Sources` owns how the index reads a test source (helper calls, literals,
  `Path.Combine(TestRepo.Root, ...)`, helper-class inheritance). Extend `Sources.paths_of` for a new way of naming a
  path; never add a second scan. Trap: `is_sweep` reads only `row["paths"]` and scopes, never `row["through"]`.
  Anything that changes own paths changes the `Sweep` set, and HostWitnessTraitDriftTests then needs the trait moved.
- `scripts/spec/drift_rules.py#test_repo` reads TestRepo's helpers from `tests/_shared/TestRepo.cs`. A new helper
  shape it cannot read fails `--check`; teach `test_repo` the shape, and do not list the helper by hand.
- `scripts/spec/impacted_tests.py#self_test`: its no-map tier-0d arms name real classes, so a renamed drift test must
  be renamed there too.
