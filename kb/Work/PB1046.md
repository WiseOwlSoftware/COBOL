# PB1046 — OPEN

## Measured
`01 DL TYPE DETAIL … 05 PV COLUMN 5 PIC X(3) SOURCE W.` then `MOVE PV TO W` in the procedure division →
`error COBOLNET1639: 'PV' is not defined — no declaration in this source element gives the name 'PV'` — in the
declaring program itself and in a contained program under `RD RR GLOBAL`. `DataBinder.IsReportSectionOnlyName` reads
only the unit's own reports and is asked only by the CONTROL / PRESENT WHEN / SUM / SOURCE screens.

## What the analyst owes
Derive from §13.15 (report group description entry) and the reference rules whether a printable item's data-name
may be referenced in the procedure division. If yes, it is a rejects-legal-source defect of the name registry
(report-section names never registered); if no, the refusal should cite the rule that confines the name, not
§8.4.2.1's 'not defined', and the contained-program case should say the same. Cite with `--check`. Convert this note
to `kind: defect` with the answer.
