# PB4616 - lead from a landed branch's report

**Sites:** `scripts/orchestrator/land_lane.py` (`status_lines`)

The status reads each branch's LATEST attempt, which is a refused one (exit 13, 12, 2 or 8), so a branch that landed through a later pull request still reads HALT or a retry state. Measured 2026-11-04: 15 rows, worktree-wf_96711d9c-c31-5 (PR 1061, HALT), impl-sonnet-default (689), notes-fuzz6 (690), notes-upstream-triage-leads (759), tooling-pb4046 (794), tooling-pb4046-race (802), tooling-pb4072 (782), worktree-wf_1338af20-657-4 (975), worktree-wf_9dc3d34f-2d2-4 (1041), worktree-wf_b208daa7-e31-1 (942), worktree-wf_b47f4999-a3c-1 (1043), worktree-wf_bab81e46-b4c-7 (1104), worktree-wf_d934ffd7-6da-2 (924), worktree-wf_e323943e-6df-4 (736), worktree-wf_fa2fbce8-08c-5 (977). Fix: a row whose pull request MERGED (or whose branch is gone) is not a retry candidate.
