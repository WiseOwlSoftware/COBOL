# PB4968 - Section I's conformance prose is outside the 1985 catalog

**Sites:** `scripts/spec/rule_catalog_1985.py#parse`, `docs/rearchitecture/spec-unharvested-rule-blocks-1985.json`,
`docs/rearchitecture/spec-rule-catalog-1985.json`

Section I, paragraph 1.5 states what a conforming implementation must do, as unnumbered prose. Example:
`§1985:I.1.5.2.3` "A conforming implementation of Standard COBOL is required to support obsolete language elements of
the subset and levels of optional modules for which support is claimed" (checked with `cite.py --check`). The catalog
reads numbered rule blocks and the content-keyed scan reads numbered lists, so neither one reads these requirements. They
have no catalog rows, no map answers and no inventory rows.

Expected: decide how the requirements enter the audit. Either catalog them as rows, keyed by paragraph, or have PB4885's
conformance statement cite them directly as its frame. Check first how the 2023 audit treated §2023:4.2 (its conformance
clause): do the same in both editions, and record the choice in DESIGN-spec-conformance-review.md §10.1.
