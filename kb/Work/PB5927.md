# PB5927 - re-measure the listing's cost on a quiet host

**Sites:** `tests/WiseOwl.Cobol.Benchmarks/Compile/CompileBenchmarks.cs` (`CompileBenchmarks.Listing`),
`tests/WiseOwl.Cobol.Benchmarks/README.md` ("The listing's cost").

Step 1 measured `CompileBenchmarks` at the parent commit and on the branch, back to back, Release, on a Windows host that was
loaded: most rows had a standard deviation of 20-30 % of the mean, so every time difference was inside one standard
deviation and neither budget of DESIGN-listing.md section 9 was decided by time. Allocated bytes were steadier: the text
listing costs 2-9 % over no listing on a full compile and 9-10 % on the front end alone; no listing equals the parent within
0.6 MB except NC218A's full compile (+4.7 MB, of which the front end is 0.6 MB).

Owed: run `dotnet run -c Release --project tests/WiseOwl.Cobol.Benchmarks -- --filter *CompileBenchmarks*` at the landed
step-1 commit and at its parent on a quiet host (no other gate, build or benchmark running), replace the README's table, and
file a defect for any row over its budget. Step 2 re-measures `Text` with JSON and can do both at once.
