**Scenario:** `EVALUATE NUM(1:2) WHEN POSITIVE DISPLAY "P" END-EVALUATE` with NUM PIC 9(4): one relational use, so EvaluateBinder.BindSubjectValue builds no intermediate and the value is BoundFieldOperand(RefModPlace). The partial path under-rejects and then decodes a two-character alphanumeric slice as a number. The private switch reads neither RefModPlace.Category nor the index-data-item rule the expression screen applies, so the same sweep must cover an index data item subject.
