# PB4310 - `CompilerDirectiveLine.TryParse` keeps a dead tab rule outside PhysicalLinesDriftTests' population and a LIVE `TrimEnd('\r')` that silently drops a lone trailing CR on directive lines only, against DOC-A.1-156

Found by the Mythos front-end review, gap pass, 2026-10-31 (GAP-REVIEW.md, G1-4; artifact https://claude.ai/artifact/KaxkLe85tfZBZ3nZ1tDGTs). Pin d7daee1cf.

**Sites:** `src/WiseOwl.Cobol.Editions/CompilerDirectiveLine.cs` (`TryParse`: doc sentence :44, `TrimEnd` :50, the `'\t'` rule :55 and :76); `tests/WiseOwl.Cobol.Tests.Unit/PhysicalLinesDriftTests.cs:27-33` (`PipelineFiles()`, Editions not scanned); `docs/rearchitecture/DESIGN-frontend-grammar.md` section 3.6.0 ("Nothing after the stage has a tab or CR rule" - false); `src/WiseOwl.Cobol.Frontend/Preprocessor/PhysicalLines.cs:16-17`; `docs/CONFORMANCE.md` DOC-A.1-156.

**Finding.** CompilerDirectiveLine.cs keeps a DEAD tab rule (:55, :76; every caller is fed text that passed PhysicalLines.Read, which expands tabs, DOC-A.1-157) that PhysicalLinesDriftTests.PipelineFiles() (:27-33) does not scan because the file is in `WiseOwl.Cobol.Editions`, and a LIVE CR rule (`TrimEnd('\r')` :50, doc comment :44): by DOC-A.1-156 a lone CR not followed by LF is an ordinary character, so `d3` `>>SOURCE FORMAT FIXED` + CR + CR + LF switches the format and prints FIXED where `d6` (CR then space) draws COBOL1911 and `d2` (the same CR on a source line) is refused. A second, contradicting determination for directive lines only. PB1800 claimed the copies were deleted.

**Fix direction.** Delete the dead tab rule and bring Editions into the drift test's population. The CR half changes behavior either way (d3 -> COBOL1911 if the trim goes).

**The CR half waits on owner question 4** (GAP-REVIEW.md section 5.3): "Should directive lines follow DOC-A.1-156 (a lone trailing CR is a character: delete `TrimEnd('\r')`, d3 then draws COBOL1911), or is the directive-line tolerance kept and recorded in CONFORMANCE.md?" Delete: one determination in one place, the design sentence becomes true, a source line already behaves that way (d2). Keep: no corpus program is affected; the tolerance is old and harmless.

**Evidence.** E:/COBOL-coord/scratch/w-gr2/GAP-REVIEW.md (sections 2 and 5.1); G1-refute/d1-d6; review-G1.md. Probe names are copied from the shard reports; the refuter folders are E:/COBOL-coord/scratch/w-gr2/G*-refute/. Shard reports: E:/COBOL-coord/scratch/w-gr2/review-G*.md.
