# PB1460 — OPEN

## The rule (every citation re-run by the registrar through `cite.py --check`)

> except that the program possessing the common attribute and any programs contained within it may reference the program-name only if the program possesses the recursive attribute

`python scripts/spec/cite.py --check 8.4.6.3 "…"` → `OK  §8.4.6.3 2)  (Scope of program-names)`

## Finding — `scope-of-names` (under-rejects; rows `SR-8.4.6.3-2`)

**Mechanism.** The bind-time AS NESTED visibility table (BinderDriver.NestedCallablesOf) admits every COMMON child of every ancestor unconditionally, dropping §8.4.6.3 rule 2's exception that the COMMON program itself and the programs contained within it may reference its name only if it is RECURSIVE; the run-time resolver (ProgramTable.ResolveVisible, onOwnChain screen) applies the exception, so the two scope implementations disagree.

**Repro.** PROGRAM-ID. SNO3. ... CALL "SNQ" AS NESTED ... / PROGRAM-ID. SNQ IS COMMON PROGRAM. (no RECURSIVE) ... CALL "SNQ1" AS NESTED ... / PROGRAM-ID. SNQ1. PROCEDURE DIVISION. CALL "SNQ" AS NESTED ON EXCEPTION DISPLAY "Q1->Q NF at run time" END-CALL GOBACK. END PROGRAM SNQ1. END PROGRAM SNQ. END PROGRAM SNO3. (file: out/probe/scope-of-names/r2n.cob; pinned cobol.exe --run)

**Expected from the spec.** Compile-time rejection of SNQ1's CALL "SNQ" AS NESTED (and of SNQ's own CALL "SNQ" AS NESTED): §14.9.4.3 SR15 requires literal-1 to name "a common program as specified in 8.4.6.3, Scope of program-names, or ... a program that is directly contained in the calling program", and §8.4.6.3 rule 2 puts a non-RECURSIVE COMMON program out of scope for itself and its containees. The CallAsNestedScope diagnostic already exists for this rule.

**Observed / reasoning.** Compiles with no diagnostic and exits 0; at run time ResolveVisible correctly finds nothing and the site takes ON EXCEPTION (prints 'Q1->Q NF at run time'). Without ON EXCEPTION the run unit terminates on EC-PROGRAM-NOT-FOUND for source the compiler accepted, and the callee signature bound at compile time names a program the resolver will never activate. Fix shape: one scope predicate shared by NestedCallablesOf and ResolveVisible (the rule-2 exception written once), with a drift test; a negative golden for both the self and own-containee spellings.

**Code site.** src/Cobol.Net.Compiler/Binding/BinderDriver.cs#NestedCallablesOf (second loop: `if (c.Common) map.TryAdd(...)` with no own-chain/Recursive screen) vs src/Cobol.Net.Runtime/Control/ProgramTable.cs#ResolveVisible (onOwnChain arm)

## What the fixer owes

ONE scope predicate shared by NestedCallablesOf and ProgramTable.ResolveVisible (rule 2's exception written once) plus a drift test that the two agree over a generated containment tree; negative goldens for the self and own-containee spellings (the CallAsNestedScope diagnostic exists).
