# PB1955 — OPEN (measured in CI; blocks PB322)

Filed by the train-1013 lander. Wave 1013 group M's report (`w1013m-PB322-report.md`, "New leads", item 2) predicted it,
and train 1013's first CI run measured it.

## What happened

PB322's determination E-extended (wave 1013 group M, branch `worktree-wf_49d7e2da-ea4-2`, head `467e14020`; Annex A.1
item 103) terminates the run unit on a fatal I-O status that no FILE STATUS clause, USE procedure or ON EXCEPTION phrase
covers. Two NIST programs depended on continuing, and the branch records them in `tests/nist/corpus.tsv` as `divergent`
rows whose note begins `TERMINATES`: `NC401M` and `ST146A`. The branch's `NistDifferentialTests` asserts the termination,
and both the Windows lander gate and the WSL Linux gate were GREEN.

CI run 37217227958 (train 1013 head `aa8bd9030`, job "Guard (WiseOwl COBOL NIST + legacy unit + integration, parallel)",
step "Run parallel guard (scripts/guard-fast.sh)") was RED:
`ST146A: DIFF — REGRESSION! (run exited 1: abnormal run-unit termination: EC-I-O-LOGIC-ERROR (fatal): I-O status 47 on
SQ-FS1 (READ) …)`, `NC401M: RUN NO-VERDICT (produced no report — nothing was observed) — NOT SCORED`,
`=== NIST (cobol): 362 MATCH, 1 REGRESSION(S) ===`, `=== FAILURES (cobol): nist=1 audit=1 … ===`. The lander dropped
cluster M from the train, so PB322 is NOT on main.

## Mechanism

The guard derives `LEGACY_DIVERGENT` from every `divergent` row (`scripts/guard-population.sh#guard_legacy_divergent`;
`scripts/guard.sh` lines 173-197, 262-265) and reads it one way: the golden is the ISO-conforming output, which WiseOwl
COBOL reproduces and the LEGACY compiler legitimately diverges from (line 189). For a TERMINATES row both readings are
inverted. The golden is the continuing run, which the legacy compiler still produces, and WiseOwl COBOL terminates
instead. So the greenfield leg scores a regression (or no verdict), and its audit counts a mismatch against the manifest.

## Fix shape

Give the guard the awareness `NistDifferentialTests` already has. A `TERMINATES` divergent row is checked on the greenfield
leg as "the run terminates with the named EC", and compared to the golden on the legacy leg. Derive it from `corpus.tsv`:
one population, one reader, the PB898 shape (`kb/Work/PB925` is the open sibling that moves the remaining NIST population
out of a shell literal). Then land it together with PB322's group M branch, and re-run CI's guard job on that head.

Repro: the guard job of CI run 37217227958, or `scripts/guard-fast.sh` on group M's branch.
