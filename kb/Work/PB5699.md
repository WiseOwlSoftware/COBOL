# PB5699 - decide() read the pairing before the refuter

**Finding.** `scripts/spec/lineage_reads.py#decide` turns each read of an older-edition rule into a KEPT record, a
refusal or a work item. For a SAME read, the arm for a rule with NO candidate pair (`own-verdict-from-pointer`)
stood above every refuter arm (no refute record, DOUBTFUL, OVERTURNED), so a SAME of an unpaired rule became `own-verdict-from-pointer` whatever its refuter
said, including no refuter at all. Design 10.6 item 3 states that work item as "a SAME its refuter UPHELD, for a rule
with no candidate pair".

**Harm.** In the operator's dry run on main d615406082 (2002, state `E:/COBOL-coord/scratch/records-2002-u1/state`)
the 698 `own-verdict-from-pointer` rows held 123 OVERTURNED reads, 10 DOUBTFUL reads and 63 reads with no refute yet:
196 rows counted as covered work that were not. No inventory record was ever written from them, because nothing built
own-verdict records before records-2002-reads-2. What was wrong was the work list: the operator's wave lists built
from that dry run were short by those rows (an OVERTURNED read is its refuter's `defect` or `needs-own-witness` item, a
DOUBTFUL one `undecided`, an unrefuted one refused `no refuter`).

**Root.** The refuter's verdict is a property of the read and decides first for every rule; the pairing decides only
between the two outcomes of an UPHELD SAME (a KEPT change record, or an own verdict from the pointer). The arm order
had the pairing as a peer of the refuter arms.

**Sites:** `scripts/spec/lineage_reads.py` (`decide`).

**Landed.** Commit 8fa47da80a (branch records-2002-reads-2) reads the refuter first, as for a paired rule: no refute
record refuses the row `no refuter`, DOUBTFUL is `undecided`, OVERTURNED is the refuter's work item, and only an UPHELD
SAME reaches the pairing. The import on the fixed code (`audit_batch.py import-reads --edition 2002`, 3,098 rules)
counts 571 `own-verdict-from-pointer`. Self-tests: `scripts/selftests/spec/lineage_reads/test_reads.py` case_12 (an
unpaired SAME whose refuter is OVERTURNED is a defect item, DOUBTFUL is undecided; and, commit 3a9b245962, an unpaired
SAME with no refute record is refused `no refuter` and is no work item). The last expectation fails when the pairing
arm is moved back above the refuter arms (a mutated scratch copy of `lineage_reads.py`).
