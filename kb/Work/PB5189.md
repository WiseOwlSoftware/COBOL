# PB5189 - at --std 85 SYNCHRONIZED is accepted on a USAGE INDEX item: InheritSynchronized passes an elementary item of any usage, the 2023 rule

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.SynchronizedClause.cs` (`InheritSynchronized`)
- `src/WiseOwl.Cobol.Compiler/Binding/Passes/CheckClauseSubjectsPass.cs` (`Run`)

**Mechanism.** §1985:VI.5.14.3 SR6 bars BLANK WHEN ZERO, JUSTIFIED, PICTURE, SYNCHRONIZED and VALUE on a usage INDEX item. Four of the five are refused at every edition. SYNCHRONIZED is not: the only screen on the clause is the group gate, and `InheritSynchronized` passes an elementary item of any usage, which is the 2023 rule (no usage excluded). `01 I USAGE IS INDEX SYNCHRONIZED` and `05 J SYNC LEFT` under a USAGE INDEX group compile at --std 85.
