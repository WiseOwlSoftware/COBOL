# PB6013 - 1985 messages name an ISO standard that does not exist

**Sites:** every `"ISO §1985:` string under `src/` (`git grep -c 'ISO §1985' -- src`: 256 occurrences in 74 files on
main 43288fb52c), among them `src/WiseOwl.Cobol.Compiler/Binding/CommunicationSectionBinder.cs` (`FormatCitation`,
`SeriesRuleCitation`), `src/WiseOwl.Cobol.Compiler/Binding/ArithmeticOperandRule.cs`, `src/WiseOwl.Cobol.Compiler/Binding/BinderDriver.cs`,
and the PADDING CHARACTER check that emits COBOL6848 (`src/WiseOwl.Cobol.Compiler/Binding/FileControlBinder.Padding.cs`).

**Repro** (`E:/COBOL-coord/scratch/w20262131/pad85/src/PADLIT2.cob`, `PADDING CHARACTER IS "**"`, `--std 85`):
`error COBOL6848: PADDING CHARACTER IS "**": literal-1 is not a one-character nonnumeric literal (ISO §1985:VII.2.7.3 SR1:
"Literal-1 must be a one-character nonnumeric literal.")`. The refusal is right; the standard it names is wrong.

**Expected.** The 1985 standard is "American National Standard X3.23-1985" (`specs/ANSI_COBOL_1985.md` line 7). Other
messages already say so (`EditionContext.cs`: `Edition.Cite("ANSI X3.23-1985", "ISO/IEC 1989")`). A message that names ISO for
the 1985 text tells the user to look in a document that does not exist. The repository citation form is `§1985:<locator>`
(CLAUDE.md rule 1, `scripts/spec/citation.py`); the message's user-facing prefix for the 1985 edition must be ANSI's.

**Fix.** The fix belongs to PB6010's mechanism (one place that renders a citation per edition): the standard's designation
is a property of the edition, rendered by that one function, never typed into a message string. Move every message to it
and add a drift test that refuses a literal `ISO §1985` (or any hand-typed standard designation) in `src/`.
