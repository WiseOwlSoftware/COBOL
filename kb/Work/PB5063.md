# PB5063 - added paragraphs carry no amended_by

**Sites:** `scripts/spec/rule_catalog_1985.py` (`resolve_change`).

**Found (PB5045).** `resolve_change` returns early when a change row names no rule, so the rows of a paragraph an amendment adds
(Amendment 1's IV-22: "Add the following as new paragraph 4.3.8.3", page 841) carry no `amended_by`. Every rule an amendment
adds or changes must name its amendment row (the attribution the owner requires, PB5045).
