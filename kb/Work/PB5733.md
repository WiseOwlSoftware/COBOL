# PB5733 - two programs of one run unit that describe one EXTERNAL indexed file with the SAME alternate record key: the second program's OPEN fails with I-O status 39, because FileRegistry.AddAlternateKey has no already-registered ::EXT:: guard and appends the shared connector's alternate keys again (every edition)

**Sites:**
- `src/WiseOwl.Cobol.Runtime/IO/FileRegistry.cs#AddAlternateKey` (no guard for a connector already registered under its `::EXT::` name)
- `src/WiseOwl.Cobol.Runtime/IO/FileRegistry.cs#_alternateKeysDescribed` (the field the fix added; RegisterIndexed sets it and AddAlternateKey reads it)
- `src/WiseOwl.Cobol.Runtime/IO/FileRegistry.cs#RegisterIndexed` (returns early for an `::EXT::` connector already registered; the guard to share)

**Mechanism.** `RegisterIndexed` returns early when the external connector is already registered, but `AddAlternateKey` runs
for every describer and appends its alternate keys again to the one shared `IndexedConnector`. The connector's declared key
table then has the key twice and no longer agrees with the stored file, and `OPEN INPUT` gets status 39. The refusal half of the
rule (entries that DISAGREE, COBOL6847 through `FileEntryIdentity`'s ALT segment) is right; the agreeing run unit, which the rule
makes one connector with one set of alternate keys, fails. Separately compiled describers (the run time's `ExternalTable` path)
were not probed: the fix's sweep.

**Inventory.** `GR-12.4.5.3-1` (2023, re-recorded PARTIAL naming this note by the registrar landing records-sample-pb5692).
The 1985 row `1985-GR-IX.2.5.4-5` (a KEPT record into `GR-12.4.5.3-1`; a 1985 id is refused in `inventory_rows`, kb/Work PB5094)
reads GAP through its chain once the 2023 row is non-conforming. Four more 1985 rows are KEPT records into the same 2023 rule
and read GAP through it with no defect of their own found (measured with `inventory_view.py --states --edition 1985` before and
after the re-record): `1985-GR-IX.2.4.4-5` and `1985-GR-VII.2.4.3-3` and `1985-GR-VIII.2.4.4-8` (the ACCESS MODE agreement of an
external connector, indexed, sequential and relative) and `1985-GR-IX.2.7.4-4` (the RECORD KEY agreement). They close again when
`GR-12.4.5.3-1` does; the fix's landing re-runs their witnesses at `--std 85`.
