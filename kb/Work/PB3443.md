# PB3443 — the program-level CLOSE-30 witness misses the third keyed CLOSE 30 route

> flags: process-only

Source: wave 1131 C (PB3382, PR #302), branch review `w1131c-review-r1`, finding R1-1, severity low.

`tests/Cobol.Net.Tests.Unit/KeyedClosePermanentErrorWitnessTests.cs:17`: the program-level CLOSE-30 witness (USE procedure x
FILE STATUS x EC-I-O checking) says the keyed engine answers a CLOSE 30 "in two ways" (a refused promotion, a refused
re-adoption read) and runs only those two. The branch documents a third in DESIGN-runtime-library 2.2.1.16 (the refused sync
of a CLOSE that owes no promotion) and tests it only at the page and connector layers.

**Rule that applies.** MANDATORY-PRACTICES I11: file I/O tests cover the abnormal paths as fully as the success paths. This is
a file I/O abnormal-path coverage gap: the third CLOSE 30 route has no program-level run through the USE procedure, FILE STATUS
and EC-I-O checking, and the comment's "two ways" is stale against the design.

**Fix shape.** Add the third scene to the witness (a program whose CLOSE owes no promotion and whose sync the host refuses) and
correct the comment. Siblings: PB3382 (the page layer's sync of an unchanged CLOSE) and PB3431 (the design sentence naming this
witness).
