# PB1573

Found 2026-09-25 by the w59h finisher. A gate that hides WHY a test failed breaks the verdict-evidence rule (a red
must be attributed by name and cause). Fix: keep the failing test's full message and stack in the log (the filter may trim
passes, never failures), and add a self-test that plants a failing assertion and asserts its text reaches the log. Then
re-run `pb64t5_character_classification` under concurrent load to attribute the w59h one-off red (it passed alone and in
a full re-run).

## Landed (wave 60 A)

The rule is now written once, in `scripts/test_leg_report.py`:

- **GREEN** (exit 0 and a `Passed!` verdict) prints the verdict line and the log path.
- **RED** (a non-zero exit, a `Failed!` verdict, or no verdict line) prints the leg's COMPLETE output, untrimmed.
- **Unreadable log.** A log the reporter cannot read exits 2, which also counts as RED.

The mechanism was measured on the retired filter: PowerShell's `-match` is case-insensitive, so the `Error
Message:` LABEL matched `error`, but the message under it and the stack frames did not. `build-local.sh` had the
same filter case-sensitively. `guard-fast.sh` printed six matching lines of the legacy unit and integration legs, in
CI, where `$TMPDIR` dies with the runner.

Callers now:

- `build-local.ps1` and `build-local.sh` keep every leg's full log under `TestResults/build-local/`.
- `guard-fast.sh`'s two legs use the reporter.
- `battery.sh`'s characterization leg now writes a TRX like the other two. At `--verbosity quiet` it used to keep no
  failure text anywhere.

Proof:

- **Self-test.** `--self-test` drives the real golden lane #2 failure transcript (DEVLOG 1700) with a planted
  message. It proves the message, the stack and every line reach the report. As the calibration, it proves that both
  retired filters DROP that message.
- **Unit drift test.** `TestLegReportDriftTests` runs the self-test by arm name. It also refuses any script line that
  filters test output by keyword. It was RED on a restored copy of the retired `guard-fast.sh` line, and a mutant
  reporter that trims fails 7 of the self-test's 13 arms.
- **Live probe.** A real failing Unit test piped through the reporter printed its full message and stack.

The pb64t5 one-off red was re-run under concurrent load; the result is in the wave 60 A report.
