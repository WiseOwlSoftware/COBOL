# PB5926 - re-adjudicate 1989-RV-A.2.46.3-3 now that a listing exists

**Sites:** `docs/conformance/8/DRV-1989-RV-A.2.46.3-3.md` (the derivation), `tests/version-matrix/inventory-1985/1989-RV-A.2.46.3-3.json`
(none yet: the row carries only the derivation), `conformance-suite/harness/` (a case cannot yet ask for a listing).

§1989:A.2.46.3 RV3: "The returned value must denote the same time as the compilation date and time if provided in the
listing of the source program and in the generated object code for the source program, although their representations
and precisions may differ."

The row is CONFORMS through `DRV-1989-RV-A.2.46.3-3` (unpopulatable-antecedent): "the compiler produces no listing in any
edition ... CONTINGENT on the absence of a listing ... re-adjudicate when a listing or a PE timestamp is produced". Listing
step 1 (kb/Work PB5923) produces a listing, by default at `--std 85`, whose page heading and DATE-COMPILED replacement
print the compilation time. So the antecedent is now populated and the derivation's premise is false.

The behavior conforms by construction: `CompilationInputs.ReadCompilationTime` reads the clock once per compilation and
answers that instant to the emitter's WHEN-COMPILED and to the listing alike, and
`Listing1985Tests.DateCompiled_TheHeading_AndWhenCompiled_DenoteTheCompilationInstant` checks the program's WHEN-COMPILED
(RV1's 21 positions) against the instant the listing prints.

What blocked the re-adjudication in step 1: the row is KEPT (its chain's newest rule holds the verdict), and
`record_verdicts.py` refuses a KEPT row's own witness unless it is a conformance-suite case that runs at its edition
(`conformance:<key>`, kb/Work PB5675). No suite case can ask for a listing today. The fix is either a suite harness option
that compiles a case with a listing and compares the listing's heading instant with the program's output, or a derivation
rewritten on the new premise (one instant by construction), with the witness above named in it. Until then the row's
record states a premise that is no longer true.
