# PB5585 - generate.py's construct-window screen fires only on cases that declare `constructs:`

**Sites:** generate.py's construct-window screen; run.py's `--suites` selection.

**Evidence.** adopt-2002/S1-report.md section 4. Of the widened cases, 40 were screened, all through another rule's band.
95 cases that are not 2002 programs reached the compiler and were refused by edition gates (COBOL0900 ORGANIZATION LINE
SEQUENTIAL 18, OCCURS DYNAMIC 12, DYNAMIC LENGTH 12, ...). run.py also runs only a suite's portable tests, so a widened
unverified case is not run by `run.py --suites` at all.

**Fix:** derive the constructs a case uses from its program text through the construct catalog's detectors, so the
window check is automatic.
