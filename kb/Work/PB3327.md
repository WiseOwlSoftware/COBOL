# PB3327 — the adapter-pattern translation exists twice

## Source

The round-3 reviewer of `worktree-wf_01e2943e-c55-21` (wave 1104 C4, PB3175), the "Considered and dropped" lead; report
`E:\COBOL-coord\scratch\reports\w1104c4-PB3175-report.md`, findings file `E:\COBOL-coord\scratch\w1104\review-w1104-c4.jsonl`.

## Observation

The Python-to-.NET translation of the adapter pattern (`(?P<` becomes `(?<`) is written twice; both give the same result
today. One rule, one place (CLAUDE.md rule 4).

## Code sites

- `tests/Cobol.Net.Tests.Unit/ConformanceSuiteAdapterDriftTests.cs` `AdapterPattern` (line 37: `python.Replace("(?P<", "(?<", ...)`);
  this file is on branch `worktree-wf_01e2943e-c55-21`, not yet on main when this note was filed.
- `tests/Cobol.Net.Tests.Conformance/ConformanceSuite.cs` `LoadCompiler` (line 134: `pattern.Replace("(?P<", "(?<", ...)`).

## Fix shape

Keep the translation in one helper that both call (the drift test calling the suite's own, or both calling a shared one),
so the drift test checks the rule the suite uses, not a copy of it.
