# PB4828 - the pb4799 golden's header quotes 13.18.40.5 rule 7 b) wrongly and claims a leg that cannot fail

**What the report says (the reviewer's words).** R1-1 LEAD (low): the golden quotes 13.18.40.5 rule 7 b) as "If the value is not zero, the result is the same as if the zero suppression were defined only to the left of the decimal point position"; the standard reads "zero suppression with replacement were defined", and cite.py --check FAILs the quoted text. Re-run for this note: `cite.py --check 13.18.40.5` of the quoted text FAILs, and of "the result is the same as if the zero suppression with replacement were defined only to the left of the decimal point position" is OK (§2023:13.18.40.5 7)).
