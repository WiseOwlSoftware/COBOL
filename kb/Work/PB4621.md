# PB4621 - lead from a landed branch's report

**Sites:** `src/WiseOwl.Cobol.Runtime/Values/Numeric/CobolEdit.cs:540` (`CobolEdit.DeEdit`), `src/WiseOwl.Cobol.Runtime/Values/Numeric/CobolEdit.cs` (`CobolEdit.FloatingZone`, new: the one extent of a floating string, read by `DeEdit` and `FindFloatingPlacement`), `tests/WiseOwl.Cobol.Tests.Unit/CobolEditStoredSignTests.cs` (`DeEdit_Character1OutsideTheFloatingString_ShowsItsLiteralAndIsNotTheSign`), the golden `conformance-suite/cases/13.18.40.5-Editing-rules/pb4621_deedit_char1_outside_floating_string`

PB4514's R2-1 fix made the arm fire for ANY non-floating character-1 in a mask with a floating '+'/'-' string (`facts.Plus + facts.Minus > 1`), not only one embedded in (or immediately right of) that string. A character-1 whose literal is '-' placed left of the floating string always shows its literal with no digit before it, so DeEdit reads that literal as a negative sign (report: wrong answer on de-editing; severity medium, found at review round 3, not blocking there). The arm's own comment scopes it to an EMBEDDED character-1. Line 540 re-read on origin/main: the condition is still `c == '-' && facts.Plus + facts.Minus > 1 && (!digitSeen || ...)`. Repro as reported, not re-run; probe not named in the report.

## Landing

Re-probed on a Debug build: PIC T--9 EDITING T IS "-" holding 55 is "- 55" and de-edited to -55 (wrong), likewise T++9 ("-+55").
The !digitSeen character-1 arm tested only that the mask had a floating +/- string somewhere. It now tests that the character-1 position
lies INSIDE that string, where CobolEdit.FloatingZone (13.18.40.5 rule 6: the first floating symbol through every following floating
symbol or simple insertion symbol) is the one extent; FindFloatingPlacement, which lands the sign, was rewritten over the same
function so the landing and the read-back cannot drift. Golden pb4621_deedit_char1_outside_floating_string (2023) and the
refused-below pb4621-deedit-char1-outside-floating-at-85; a unit theory over left-of, past-a-9 and immediately-right-of positions.
