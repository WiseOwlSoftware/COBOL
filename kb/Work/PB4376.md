# PB4376 - A Class.Method citation is resolved by file name

**Sites:** `tests/WiseOwl.Cobol.Tests.Unit/AnnexA1RegisterDriftTests.cs` (the resolver that turns a `Class.Method` citation in the Annex A.1 register into a test; find the member with `python scripts/arch/source_units.py tests/WiseOwl.Cobol.Tests.Unit/AnnexA1RegisterDriftTests.cs`).

The resolver finds the file whose name matches the cited class and then looks for the method. Splitting a class into partitions or partial files (PB4325 does this) or moving it to another file makes the citation resolve to the wrong file or to none, while the class itself still exists. Resolve by the declared class (the `drift_rules.CLASS` index that PB4325 tightened) instead of by file name.

Grepped `kb/Work`: no open note names this resolver's file-name lookup.
