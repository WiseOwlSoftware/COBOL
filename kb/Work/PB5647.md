# PB5647 - at --std 2002 a PICTURE SYMBOL character 2002 permits is refused COBOL0891 when its invariant upper case is an excluded letter (for example U+017F LONG S)

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/SpecialNamesBinder.Currency.cs#CurrencySymbolExclusion.Excludes` (and its Cobol2002 row's citation)

**Mechanism.** CurrencySymbolExclusion.Excludes tests UppercaseLetters.Contains(char.ToUpperInvariant(c)), the 2023 Annex A.1 item 44 extension (DOC-A.1-44, 'additional characters prohibited'), in every edition. 2002 SR23 excludes the listed letters 'or their lowercase equivalents', and 2002 equivalence of case is between basic letters only, by the Annex D mapping (§2002:8.1.2.1 GR3); LONG S is an extended letter with no Annex D pair. The Cobol2002 row also cites ISO §2023:12.3.7.3 SR22/SR27.

**Inventory.** Rows claimed: `2002-SR-12.2.6.2-23`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:12.2.6.2 SR23`: "Literal-8 may be any character from the computer's coded character set except for the following"
- `§2002:12.2.6.2 SR23b`: "alphabetic characters A, B, C, D, E, N, P, R, S, V, X, Z, or their lowercase equivalents"
- `§2002:D`: "This annex shows the mapping of uppercase letters to lowercase letters in the COBOL character"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p3/cur8_long_s.cob); the text is inline. Command: `cobol.exe p3/cur8_long_s.cob --std 2002 --run`

`p3/cur8_long_s.cob`:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. CURLS.
       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.
       SPECIAL-NAMES.
           CURRENCY SIGN IS "EUR" WITH PICTURE SYMBOL "ſ".
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 WS-X PIC ſſ9.99.
       PROCEDURE DIVISION.
       MAIN-P.
           MOVE 12.5 TO WS-X
           DISPLAY "X=[" WS-X "]"
           STOP RUN.
```

**Observed.** error COBOL0891 (6,12): PICTURE SYMBOL literal 'ſ': not a valid currency symbol — digits, the picture letters A B C D E N P R S V X Z (either case), space, and + - , . * / ; ( ...; rc=65.

**Expected (from the 2002 text).** accepted.

**Sibling sweep.** the 1985 row (same ToUpperInvariant test; 1985 has no Unicode letters, so check what 1985 permits) and every other place char.ToUpperInvariant stands for COBOL case equivalence at 2002.

**Other editions.** 85: unknown. 2014: unknown. 2023: no (DOC-A.1-44 licenses it).
