# PB904 — OPEN — an edition gate deleted because it had no source, and the question it leaves

Source: the `PB391` report, "New defects" item 2, filed by the implementer who deleted the gate.

## What was there, and what happened to it

`CorrespondingBinder.CorrMoveValid` — now deleted, replaced by a single delegation to
`MoveTable16.DataItemRefusal` — admitted a numeric-edited SENDER into a numeric RECEIVER only when
`DialectLevel >= 2002`, with a comment calling it *"an ISO-2002 introduction"* and **no clause number**.
`MoveTable16.Refusal` admits the same pair at every edition. The PB391 implementer deleted the gate so that
one table decides for both askers, and recorded the open question here rather than guessing.

## The question, stated so it can be answered

§14.9.25.3 Table 16 **as printed in the 2023 standard** shows Numeric-edited → Numeric / Numeric-edited =
*Yes*, with no edition qualifier. The 2023 text therefore CANNOT settle whether de-editing entered at
COBOL-2002. It is a VERSION-CHANGE-REFERENCE question, answered from the historical editions and the
project's own `docs/VERSION_CHANGE_REFERENCE.md` method, not from §14.9.25.3.

## Both answers are work, and they are different work

* **If de-editing IS a COBOL-2002 introduction:** the compiler is under-strict at `--std 85` for the DIRECT
  MOVE — far more common than MOVE CORRESPONDING — and the fix is a VCR row plus ONE edition arm in
  `MoveTable16` (one place, because one table now decides for both askers), plus the edition-gate sweep over
  the `85` goldens that de-edit.
* **If it is NOT:** the deleted gate was simply wrong, the current behaviour is right, and what is owed is a
  VCR row saying so — an explicit "no edition axis" row is what stops the next reader re-inventing the gate.

## Why `kind: analysis`

There is no measured defect yet; there is a deleted claim and no evidence either way. The deliverable is a
DERIVATION recorded in `docs/VERSION_CHANGE_REFERENCE.md`. Whatever it concludes becomes either a defect or
a documentation row.
