# PB5413 - at --std 85 a USE AFTER STANDARD EXCEPTION ... ON EXTEND procedure excuses the mandatory INVALID KEY or AT END phrase on a random- or dynamic-access file, which can never be open in extend mode: ExceptionPhraseRequirement.HasApplicableUse counts every open-mode declarative, and the invalid key then goes unhandled

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/ExceptionPhraseRequirement.cs#HasApplicableUse`
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/ExceptionPhraseRequirement.cs#Require`

**Mechanism.** `ExceptionPhraseRequirement.Require` (in force below 2002) refuses a READ, WRITE, REWRITE, DELETE or START that has neither the phrase nor an applicable USE procedure (COBOL6826). `HasApplicableUse` accepts any open-mode declarative (`d.ModeIndex is not null`) for every file, on the reading `docs/FILES_DESIGN.md` D31(a) states: "the file may be in any mode when a statement runs". That reading fails for EXTEND: a file in random or dynamic access can never be opened EXTEND (the compiler itself refuses `OPEN EXTEND` of it, COBOL2372), so a USE ... ON EXTEND procedure can never run for it. A program whose only declarative is USE ... ON EXTEND compiles, and at run time the invalid key condition is taken by neither a phrase nor a procedure: the statement fails with 22, 23, 47 or 49 and execution continues silently. Four refuters overturned nine CONFORMS verdicts on this one mechanism.

Why EXTEND cannot apply: "The EXTEND phrase must only be used for files in the sequential access mode." (`§1985:VIII.4.4.3 SR1`, the same text at `§1985:IX.4.4.3 SR1`), and an EXTEND procedure runs "for any file open in the extend mode or in the process of being opened in the extend mode" (`§1985:VIII.4.8.4 GR5`). The DELETE of an indexed file (`1985-SR-IX.4.3.3-2`) has the same EXTEND arm (`refute-rd-04/d-useEXT.cob` reproduces), but its refuter case is DOUBTFUL because it also argues the INPUT and OUTPUT arms, so that row is held as doubtful, not claimed here. Whether INPUT and OUTPUT declaratives are "applicable" or "appropriate" to a statement whose invalid key condition arises only in I-O mode (REWRITE, DELETE) is the open reading the held rows carry; this note is the EXTEND arm alone, which needs no reading.
