# PB5312 - at --std 85 RERUN ON a sort-merge file, and RERUN EVERY END OF REEL OF one, compile: ScreenRerunClauses takes an SD file as sequentially organized

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/FileControlBinder.IoControl.cs` (`ScreenRerunClauses`)

**Mechanism.** "File-name-1 must be a sequentially organized file" (§1985:VII.2.12.3 SR1), and END OF REEL/UNIT "may only be used if file-name-2 is a sequentially organized file" (SR2). A relative file is refused (COBOL6529), so only the SD arm is missing.
