# PB3959 — golden pb3794_order_data_item_duplicates_in_order quotes 14.9.40.4 GR3 b) in words the clause does not use

**Sites:** `conformance-suite/cases/14.9.40-SORT/pb3794_order_data_item_duplicates_in_order.cob:15`

The header of `pb3794_order_data_item_duplicates_in_order.cob` (line 15) quotes 14.9.40.4 GR3 b) as "in the order in
which these records are released by an input procedure". The rule reads "The order in which these records are released by an
input procedure, when an input procedure is specified" (verified here with `cite.py --check 14.9.40.4`: OK §14.9.40.4 3) b)),
so the quoted text fails `cite.py --check` though the clause number is right.

## Acceptance
- Replace the header quotation with the clause's text; run `cite.py --check` on the new header text.
