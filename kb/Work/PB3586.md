# PB3586 - a USAGE BIT RETURNING item loses its value on the way back to the caller

## Scenario

Found by the PB3565 implementer while sweeping sole-boolean-operand hosts. Repro (kept at
`E:\COBOL-coord\scratch\reports\w1157j-lead-udf-bit-returning.cob`, run with `--source-format free --run`; never run it inside
conformance-suite, which writes .dll/.g.cs beside the file):

```cobol
IDENTIFICATION DIVISION.
FUNCTION-ID. UBIT.
DATA DIVISION.
LINKAGE SECTION.
01 L-X PIC 9.
01 L-R PIC 1(8) USAGE BIT.
PROCEDURE DIVISION USING L-X RETURNING L-R.
P.
    MOVE B"00001010" TO L-R.
    DISPLAY "INSIDE=" L-R
    GOBACK.
END FUNCTION UBIT.
IDENTIFICATION DIVISION.
PROGRAM-ID. UDF4.
ENVIRONMENT DIVISION.
CONFIGURATION SECTION.
REPOSITORY.
    FUNCTION UBIT.
DATA DIVISION.
WORKING-STORAGE SECTION.
01 B8 PIC 1(8).
01 BB PIC 1(8) USAGE BIT.
PROCEDURE DIVISION.
    MOVE FUNCTION UBIT(3) TO B8
    DISPLAY "MOVE8=" B8
    MOVE FUNCTION UBIT(3) TO BB
    DISPLAY "MOVEBB=" BB
    STOP RUN.
END PROGRAM UDF4.
```

Observed: `INSIDE=00001010`, then the caller's `MOVE FUNCTION UBIT(3) TO B8` shows `00000000`. The same function declared
`PIC 1(8)` (no USAGE BIT) returns `00001010`. Silent wrong answer.

## Rule

The function-identifier's temporary data item takes the description of the item named in the RETURNING phrase, so its value is that
item's value (spec section 8.4.3.2.4 GR1, `cite.py --check 8.4.3.2.4` OK: "the description, class, and category of the temporary data
item is that specified by the description in the linkage section of the item specified in the RETURNING phrase"). Boolean functions
have an implicit usage bit (section 15.2 2, `cite.py --check` OK). The value `B"00001010"` placed in L-R must reach the caller
unchanged.

## Code site (unlocated beyond this)

The PB3565 implementer did not read it: the user-function result copy in `IntrinsicBinder.BindFunctionResult` or the activation
return in `CodeGen/ProgramEmitter.cs`. The `PIC 1(8)` arm works, so the USAGE-BIT arm is the one that drops the bits; compare with
how PB3562 treats a boolean function value (`SendingValueTemp.CharacterUsage`). Sweep the siblings: a USAGE BIT RETURNING item
through MOVE, DISPLAY, a relation condition and a COMPUTE sole operand (PB3565).

**Sites:** `src/Cobol.Net.Compiler/Binding/IntrinsicBinder.cs`, `src/Cobol.Net.Compiler/CodeGen/ProgramEmitter.cs`; golden under
