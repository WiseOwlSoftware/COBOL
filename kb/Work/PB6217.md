# PB6217 — a doc comment describes a fallback the code lacks

**Mechanism.** `src/WiseOwl.Cobol.Cli/Program.cs:71`. The `FaultingPass` doc comment says the method falls back to the exception's
own declaring site before the compiler. The code returns the first `WiseOwl.Cobol` frame, or the literal `the compiler`; it has no
declaring-site arm.

**Fix shape.** Decide which is right. An exception thrown outside any `WiseOwl.Cobol` frame (a BCL or Roslyn frame) names the
compiler, which may be the intended answer; then the comment shrinks to say so. If the declaring site is more useful to the user,
add the arm and a test that fails without it (see PB6216). One change, the comment and the code agree.

**Sites:** `src/WiseOwl.Cobol.Cli/Program.cs:71`
