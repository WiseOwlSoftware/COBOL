**Found by:** the R1 (PB2118) landing, 2026-10-07. CI run 37712135076 failed in `audits` → "Work register — every
kb/Work note well-formed (work.py check)". The lander gate (`build-local.ps1 -Mode lander`) and the Linux gate
(`linux-gate.sh`, all legs) were both GREEN on the same commit. Neither runs that step. The defect itself (a
working-tree existence check) is fixed in the landing and recorded in PB1957. This note covers the missing leg, which
would have caught the defect locally even with the old rule, because CI's checkout is fresh and unbuilt.

**Harm:** every audit in `.github/workflows/build-and-test.yml`'s `audits` job is verified first by CI. That breaks
the CI invariant (CLAUDE.md Testing, owner 2026-10-04), and each red costs a round trip on main's landing lane.

**Fix direction (rule 5):** add an `audits` leg to `scripts/linux-gate.sh` that runs the job's own commands, read from
the workflow YAML (one list, never a copy), in the gate's Linux clone BEFORE any build, so its tree matches CI's
fresh checkout. Extend PB1957's job-to-leg drift test so the `audits` job maps to the leg. The leg must fail when it
is planted with a register note that names an untracked path.
