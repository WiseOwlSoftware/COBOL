# PB1689 — LANDED

Filed by the train-70 lander from wave 70 group B's report (implementer of PB1362/PB1494; `w70b-PB1362-report.md`,
lead 2). PB1494's Progress section names this as "a separate reserved-word lead".

## Finding

**Repro.** `E:\Temp\claude\E--COBOL\73cac64c-391d-42c0-bcdf-c880e3e10305\scratchpad\w70b\probe\rf17.cob`
(`PERFORM REMARKS`) and `rf18.cob` (`PROCEDURE DIVISION. … REMARKS. DISPLAY "IN-REMARKS".`) both fail with
`COBOL0001 'REMARKS'`. Before train 70 the rf18 text was silently dropped by the unscoped comment-entry heuristic
(PB1494); since train 70 scoped that heuristic to the IDENTIFICATION DIVISION, the lines reach the parser — which
then refuses the word.

**Rule.** PB1494's adjudication: REMARKS is not a reserved word in ISO/IEC 1989:2023, so it is a legal
paragraph-name, and §6.5 5) copies a source line's program-text area. The expected output of rf18 is `START` then
`IN-REMARKS`. The reserved-word status per edition must be re-derived from §8.9 (and the COBOL-85 list, where
REMARKS belonged to the obsolete comment-entry paragraphs) by the fixer, with the edition table in
`tests/version-matrix/cobol-words.json`.

**Code sites.** `src/Cobol.Net.Frontend/Grammar/Core/CobolLexer.g4` token `REMARKS` (and AUTHOR, INSTALLATION,
DATE-WRITTEN, DATE-COMPILED, SECURITY — sweep them); `tests/version-matrix/cobol-words.json`.

## Landed

A first attempt was backed out because `docs/CONFORMANCE.md` D-RW1 listed REMARKS among the vendor words "reserved at EVERY edition ... following GnuCOBOL". Checked against GnuCOBOL 3.2 (`cobc/reserved.c`: `{ "REMARKS", 0, 1, REMARKS, /* 85 (later: C/S) */ 0, CB_CS_DAY /* HACK, we only want it to normally be not usable */ }`, and the lookup at ~4912-4930 returns no keyword when the context test fails) REMARKS is a context-sensitive word whose context normal code never enters, i.e. a user word; the strict-dialect word lists do not contain it either. ISO 4.2.10 permits extra reserved words but does not require this one, so the precedence rule lands on GnuCOBOL. Owner 2026-09-29: overturn D-RW1 — REMARKS is not a special word.

REMARKS moved from `extensionReserved` to a `nameSlot` row of `tests/version-matrix/cobol-words.json` (generator re-run), REMARKS dropped from D-RW1, witness `conformance:2023/pb1689_remarks_is_a_legal_paragraph_name`. The IDENTIFICATION DIVISION comment-entry paragraph at 85 still parses (probed). The other D-RW1 words were NOT re-checked against GnuCOBOL.
