**The open question, settled from the spec and the project's standing determination.** `cite.py --check 8.1.3.2 "An uppercase
extended letter is treated as though it were folded to its corresponding lowercase extended letter, if any, in accordance with
the case mapping described in Annex C"` -> OK §8.1.3.2 4) b). The project folds every COBOL word by Annex C (`CobolNames`,
PB1402/PB1965), and golden `pb1965-kelvin-spelled-reserved-word` already held that the Kelvin-sign KEY IS the reserved word
KEY. So a keyword spelled with a letter Annex C folds to a basic one is that keyword, in every position.

**Re-probe** (build of 11e8949be): `>>IF X DEF<U+0130>NED` -> COBOL1619 at 2023 and 2014 (as filed); `>><U+0130>F ... >>END-<U+0130>F`
accepted; and the sibling the note suspected, `D<U+0130>SPLAY "HI"` -> COBOL0001 at both, while `01 D<U+0130>SPLAY PIC X.` drew
COBOL0901 ("'DISPLAY' is a reserved word"): the keyword rules match only the basic letters (`caseInsensitive`), so the lexer
read a folded keyword as an IDENTIFIER. `>>IF X <U+0130>S DEFINED` (COBOL1619) was the same sibling inside a directive.

**Fix.** `RetypeDirectiveKeyword` compares through `CobolNames.Same` on the lexer's edition spelling. `RetypeFoldedKeyword`
(`NextToken`, after `ApplyEditionSpelling`, before the `>>COBOL-WORDS` retype and every keyword decision) gives an IDENTIFIER
holding a non-basic character the type of the keyword its `UpperFold` spells (`CobolKeywordTokens.TryTokenType`, asked only
of an all-basic fold, so the probe never recurses); the spelling stays the source's. Siblings the keyword token now reaches:
`WordCharacterScreen.IsCandidate` screens such a keyword (else `D<U+0130>SPLAY` compiled at COBOL-85, and the Kelvin KEY before
2023); `CobolErrorStrategy.IsReservedWord` / `IsClosedFormatResidueAhead` and `AdmittedKinds.Written` asked an ASCII first
letter (`char.IsLetter` now), so the Kelvin KEY drew COBOL0001 where KEY draws COBOL1941. `CobolNameFoldDriftTests` scans the
grammars too (the old line is caught by `NoOrdinalIgnoreCase_OverACobolWord_InAnyProject`).

**Witnesses.** Goldens `cases/8.1.3-COBOL-character-repertoire/pb4240_keyword_spelled_with_dotted_capital_i` (accepted at
