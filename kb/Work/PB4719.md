# PB4719 — MCS NameOf misses the colon

**Sites:** `src/WiseOwl.Cobol.Runtime/Communication/MessageStoreState.cs:192` (`MessageStoreState.NameOf`)

The file exists only on open PR #1161 (branch `worktree-wf_d99db659-fdf-22`); the line is read from that worktree. Reported by the branch review, not probed. R2-1, copied: the finisher's new `NameOf` screen refuses a symbolic name holding a slash or a backslash because a device file is built from the name, and misses the colon on Windows, so a name can still leave the MCS directory or land in a file's alternate stream, with status 00. The design section 6 and the `NameOf` summary say a name that would address a directory is refused.
