# PB4216 — the "unresolved / ambiguous" comment no longer covers a declined GLOBAL head

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.Ptr.cs#ResolveStorageClaimHead` (the call site in the ADDRESS OF scan, about line 147).

The comment on `if (hit is null) continue;` reads "unresolved / ambiguous — the SET bind reports 0869 with the source text". PR #880 (bcda6beef) made `ResolveStorageClaimHead` return null also when the head names a container's GLOBAL item (`DeclaringDepth` is not 0): the claim is declined, the container claims the storage, and no 0869 follows.

**Fix:** reword the comment to name all three outcomes (unresolved, ambiguous, a container's GLOBAL item). The wording is applied in the same change set that files this note.
