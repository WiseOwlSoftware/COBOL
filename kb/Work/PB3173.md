# PB3173 — conformance suite slice S0b

Owner approved `docs/rearchitecture/DESIGN-conformance-suite.md` on 2026-10-14 ("approved", revision 2; kb/Work PB3160 holds the decisions verbatim).

**Prerequisites:** PB3172.

**Scope:** Design §13 S0b and §6 step 0. 153 rows have no `editions`, so no per-edition suite can know whether they belong to it. For each row: the editions at which the rule exists, derived from the standard and `docs/VERSION_CHANGE_REFERENCE.md` (the historical editions where the rule's clause changed), each decision with a citation checked by `cite.py`; an adjudicator decides, a refuter checks each decision (the adjudication lane). Then `inventory_schema.py` refuses an empty field.

**Rules for the implementer:** implement this slice FROM the design (the sections named above), not from this note, which is its register entry; the complete slice with its tests and drift tests (CLAUDE.md rules 3, 5); a design correction lands in the design in the same change (rules 2, 6); every ISO citation through `python scripts/spec/cite.py --check`; no wrapper, alias or compatibility layer (rule 4); the gate is `pwsh scripts/build-local.ps1 -Priority BelowNormal`; flip this note to `landed` and write `closes_rows` (or `closes_rows_reason`) in the commit that lands it.

## Landed

Wave 1104 C2 (2026-10-16), on PB3172's branch. **Re-probe:** 148 rows had an empty `editions` (85 CONFORMS, 63
DOCUMENTED-NON-SUPPORT; 66 Annex A.1 items, 82 SR/GR/AR/RV/FMT rules), the count the design records.

**How each was decided.** One script, `adjudication/pb3173-editions/decide.py` (with its batch and a README),
assigns every row a band and a reason. A reason names the facility whose existence bounds the rule and the
evidence for that facility's introducing edition, and the script CHECKS every piece before it writes the batch:
an Annex E or F item through `cite.py --check` (the 2023 introductions: asynchronous messaging E.3.2 item 1,
commit and rollback item 2, DELETE FILE E.3.3 item 15, MODULE-NAME item 28, SMALLEST-ALGEBRAIC item 29, PUSH/POP
item 38; STANDARD-BINARY obsolete but present, F.2 item 3), and for an edge below 2023, which the 2023 text cannot
quote, the compiler's own edition record: a `constructs.json` row's `introducedIn`, the `IntrinsicCatalog` window
(COBOLNET1502), the first edition `reserved-words.json` reserves a word at, or a decided sibling row. A band must
START at its evidence's edition, or the script refuses it. 98 evidence items, all OK. Each row's `notes` carries
its decision and its checked citations (`editions <band> (kb/Work PB3173, S0b ...)`).

**The design correction (rules 2, 5).** Every row is a rule of the 2023 text (the catalog is extracted from it),
so its band ends at 2023 and has no gap. The schema's `editions` entry says so as data, `required` and
`run-through-last`; `Schema.editions_error` and its C# twin `EditionsError` refuse an empty field and any band
that is not a run through 2023; `record_verdicts.py` asks the validator of the row AS WRITTEN (a witness-only
record keeps the row's band); `grammar_findings_to_batch.py` names a finding with no band as a problem. The sweep
found 20 rows that broke the rule (a start edition alone: `2002` on nine constant-entry rows, `85` on six COLUMN
and INSPECT rows; endpoints: `85,2023`, `85,2002,2023`; `85,2002,2014` on three CLOSE / OPEN / USE rules the 2023
text states) and 36 whose band contradicted the evidence a decided row uses: the 31 FORMAT / SELECT WHEN (A.4.8)
rows at `85` (FORMAT is first reserved at 2002), GR-13.18.13.4-5 (conditioned on FORMAT), the two NUMVAL-F rows at
2014 (the compiler's window is 2002), MOD's AR-15.64.3-1 at 2002 (MOD is 85) and the standard-decimal arm
GR-14.7.5-7 at 2002 (standard-decimal is 2014). All 56 are corrected in the same batch, each note saying
`editions corrected from '<old>'`. 204 rows changed; GAP 60 → 60.

**Lower-confidence decisions, named so a refuter can overturn each with one batch record:** the split-key SOURCE
phrase rows (2002, with FMT-12.4.5.12.2; the repo holds no 2002 or 2014 text); the A.4.8 module's 2002 edge
(derived from FORMAT's reservation); DOC-A.1-34 and -37 (the compile-time / runtime coded-character-set items,
2002); DOC-A.1-188 (the UCS-4 / UTF-8 / UTF-16 alphabet phrases, 2002); DOC-A.1-112 and -202 (the time forms,
2014). No separate refuter ran in this lane: the decision script checks every decision's evidence mechanically,
and the branch review (MANDATORY-PRACTICES I10) is the judgment check.
