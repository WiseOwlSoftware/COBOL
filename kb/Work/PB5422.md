# PB5422 - at --std 85 a REPLACE statement that begins library text compiles when the COPY statement that brings it follows no separator period (DISPLAY "X" COPY LIBR.): FollowsSeparatorPeriod accepts any REPLACE whose preceding character comes from another file

**Sites:**

- `src/WiseOwl.Cobol.Frontend/Preprocessor/CopyProcessor.cs#FollowsSeparatorPeriod`
- `src/WiseOwl.Cobol.Frontend/Preprocessor/CopyProcessor.cs#ApplyReplaceStatements`

**Mechanism.** `ApplyReplaceStatements` finds each REPLACE over the text COPY has already expanded and, below 2002, refuses one that `FollowsSeparatorPeriod` rejects (COBOL0900). `FollowsSeparatorPeriod` accepts a REPLACE whose preceding character comes from a different file, so a REPLACE at the start of a copybook is accepted even when the COPY statement it replaces follows `DISPLAY "X"` with no period. In the source program the REPLACE then follows `DISPLAY "X"` with no separator period on any reading.

**Found by.** The 1985 code read, read 3 (`kb/Work/PB4996/2026-11-12-read-3.md`): `E:/COBOL-coord/scratch/coderead-85/out-read3/rd-03.json`.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. Its rows are recorded PARTIAL naming this note.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-SR-XII.3.3-1` - `§1985:XII.3.3 SR1` (read: PARTIAL, harm: under-rejects; REPLACE placement): "must be preceded by a separator period except when it is the first statement in a separately compiled program"

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-read3/work-rd-03/c5l.cob` and `c5n.cob` (`DISPLAY "X" COPY LIBR.` with `LIBR.cpy` holding `REPLACE ==AAA== BY =="LIB"==.`). Run as `cobol.exe --std 85 --source-format fixed --run <file>` (each probe copied into its own directory by `reprobe-85i/probe.py`).

**Observed (the pinned compiler of `E:/COBOL-wt/coderead85-tree-c` (fafa91a83c, the head of witnesses-85g; `git diff --stat fafa91a83c origin/main -- src` is empty at 3c4f6fe652), rerun 2026-11-12; `E:/COBOL-coord/scratch/coderead-85/reprobe-85i/log.txt`).** Both compile and run, printing `X` and `LIB`.

**Expected (from the 1985 text).** Refused COBOL0900 at --std 85 as a REPLACE after `DISPLAY "X"` with no period in the same file is.

**Fix direction (root cause, CLAUDE.md rule 4).** Judge the preceding text across the COPY boundary: the character before a REPLACE that begins library text is the character before the COPY statement that brought it.
