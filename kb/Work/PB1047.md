# PB1047 — OPEN

## Measured
```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. B20OUT.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 G GLOBAL.
          05 X PIC X(3) VALUE "GLB".
       PROCEDURE DIVISION.
           CALL "B20IN"
           STOP RUN.
       IDENTIFICATION DIVISION.
       PROGRAM-ID. B20IN.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 L.
          05 X PIC X(3) VALUE "LOC".
       PROCEDURE DIVISION.
           DISPLAY "X=" X
           GOBACK.
       END PROGRAM B20IN.
       END PROGRAM B20OUT.
```

→ `error COBOLNET1639: 'X' does not uniquely identify a data item — 2 declarations share the name and no
qualification distinguishes them`.

## The rule
`cite.py --check 8.4.6.2.1 "If the name is declared in source element B, the item in source element B is the referenced item"`
→ `OK §8.4.6.2.1 3) a)`. Expected output `X=LOC`.

## What the fixer owes
Resolve data-names over the depth-tiered candidate set PB919 built for index-names (§8.4.6.2.1 1)–3)): local names
first, then each container outward, qualification applied within a tier. One resolution, shared by index-names,
data-names, condition-names, file-names and report-names — sweep them all. Golden: the probe plus a two-deep nest.
