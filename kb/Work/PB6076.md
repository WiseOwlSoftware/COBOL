# PB6076 - flakes are defects, never retries (CLAUDE.md "Testing and landing")

1. `CompilationInputs.ReadSourceText` read `.cache/compiled-programs/src/<hash>/<case>.cob` while another process held it
   (`BothRunnersVerdictDriftTests_P3`, run 000002 of the PB5777 worktree). The staging side is `CompiledProgramCache.StageSource`
   (PB3453). Root cause to find: a writer that holds the file open for write while a second test host reads it, or a staged file
   without share-read. Fix the staging (write to a temp name and rename, or open both sides with `FileShare.Read`), not the reader's
   retry.
2. `RunUnitProcessBoundaryTests.ARefusedDeleteFile_ReachesTheProgramsHandlers...` timed out once (120 s with no stdout) under gate
   load and was green at the re-gate. PB4375 holds the class's length; the question here is what the test waits on that the load
   starves (a child process start, a lock file, an inherited pipe handle).

**Sites:** `src/WiseOwl.Cobol.Frontend/Pipeline/CompilationInputs.cs#ReadSourceText`,
`tests/WiseOwl.Cobol.Tests.Conformance/CompiledProgramCache.cs`, `tests/WiseOwl.Cobol.Tests.Unit/RunUnitProcessBoundaryTests.cs`.
