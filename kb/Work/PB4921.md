# PB4921 - a CONTINUE AFTER longer than the timer maximum ends early

**Sites:** `src/WiseOwl.Cobol.Runtime/Messaging/MessagingPeer.cs` (`MessagingPeer.Arm`, `MessagingPeer.MaxSeconds`)

**Lead R1-7 (low).** `MessagingPeer.Arm` clamps `deadline.Seconds` to `MaxSeconds` (`(uint.MaxValue - 1) / 1000` s, about 49.7 days, the platform
timer's limit) and creates one timer with `Timeout.InfiniteTimeSpan` as the period, so `CONTINUE AFTER 5000000 SECONDS` (about 58 days) stops
waiting after 49.7 days: the deadline queue entry fires at the cap and the program continues early. Expected: the CONTINUE AFTER statement
waits the whole time it names (the clerk did not re-derive the governing rule; the fixer cites it with `cite.py --check`), so `Arm` re-arms for the remainder when the cap fires before the deadline, using the run unit's clock (`_settings().Time`) so a test clock
drives it. Observed: one timer, capped. PB4744 (open, the exchange slice that owns CONTINUE AFTER) may take this with its other work; the
clerk filed it separately because the site is landed code in `MessagingPeer` and the note does not name `Arm`.

Not probed. Source report and lead: `w20261887g-PB4742-report.md`, R1-7.

## Landed (wave 20261915 A) - the wait never exceeded a day

**Re-probe.** The note's scenario does not occur: the RECEIVE's CONTINUE AFTER value reaches `MessagingPeer.Arm` through `StatementEmitter.IntervalCall`, that is
`CobolTiming.Interval`, the one rule of "the maximum meaningful value" the implementor specifies (§2023:14.9.9.4 GR1; `CobolTiming.MaxSeconds`, one day), so
`CONTINUE AFTER 5000000 SECONDS` waits 86,400 seconds by that documented rule, and the 49.7-day cap inside `Arm` was unreachable from a compiled program. `Arm` now
clamps to the same `CobolTiming.MaxSeconds` (a host that builds a `MessageWait` itself is held to the rule) and the timer-range constant is gone.
Test: `unit:MessagingPeerTests.AWaitAboveTheMaximumMeaningfulValueIsArmedForTheMaximum_TheOneRuleOfContinue` (a 5,000,000-second wait arms one one-day timer).

**Sites:** `src/WiseOwl.Cobol.Runtime/Messaging/MessagingPeer.cs` (`MessagingPeer.Arm`), `tests/WiseOwl.Cobol.Tests.Unit/MessagingPeerTests.cs`.
