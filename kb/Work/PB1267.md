**Mechanism.** F1 — The INITIALIZED seed for a new dynamic-table element is the data-division INITIAL-STATE initializer (VALUE, else the §14.6.2.3.2 background), not the §8.5.1.9.5 'INITIALIZE … WITH FILLER ALL TO VALUE THEN TO DEFAULT' result. The two recipes give different results for a VALUE-less NUMERIC-EDITED leaf: the background fills it with spaces, but INITIALIZE TO DEFAULT moves ZEROES into it (edited zero).
