# PB5424 - at --std 85 a USE BEFORE REPORTING procedure for a page heading, page footing, control footing or report footing group may reference a control data item or the group holding one: ScreenSourceControlData screens only SOURCE clauses

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/ReportSectionBinder.cs#ScreenSourceControlData`
- `src/WiseOwl.Cobol.Compiler/Binding/ReportSectionBinder.cs#ControlDataReferenceOf` (the one SR5 relation, landed), `#ControlDataRuleWords`
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ReportWriterBinder.cs#CheckControlDataReferences` (the USE half, landed)
- `src/WiseOwl.Cobol.Compiler/Binding/Bound/StatementBinder.cs#BindStatement` (asks it of every statement of a USE BEFORE REPORTING procedure)
- `src/WiseOwl.Cobol.Editions/Diagnostics/DiagnosticCatalog.cs#ReportSourceControlData` (COBOL6825, its text now names USE statements)

**Mechanism.** The rule bars SOURCE clauses "and associated USE statements" in CF, PH, PF and RF groups from referencing control data. `ScreenSourceControlData` (below 2002, COBOL6825) applies the SOURCE half; nothing screens the procedure a USE BEFORE REPORTING statement names for those groups. kb/Work PB5079 landed without the USE half.

**Found by.** The 1985 code read, read 3 (`kb/Work/PB4996/2026-11-12-read-3.md`): `E:/COBOL-coord/scratch/coderead-85/out-read3/rd-03.json`.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. Its rows are recorded PARTIAL naming this note.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-SR-XIII.3.20.3-5` - `§1985:XIII.3.20.3 SR5` (read: PARTIAL, harm: under-rejects; the USE half): "In page heading and page footing report groups, SOURCE clauses and USE statements must not reference control data-names."

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-read3/work-rd-03/c9h.cob` (`USE BEFORE REPORTING PH-G` whose procedure DISPLAYs the control item WS-KEY) and `c9k.cob` (the CF form, a group holding the control item). Run as `cobol.exe --std 85 --source-format fixed --run <file>` (each probe copied into its own directory by `reprobe-85i/probe.py`).
