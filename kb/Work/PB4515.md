# PB4515 — An all-'*' or all-'Z' picture whose STORED value is zero after high-order truncation is edited as nonzero (MOVE 1000 TO PIC ***.** gives '***.00', ZZZ.ZZ gives '   .00'): the zero test reads the pre-truncation value (an unswept sibling of landed PB566)

**Found:** 2026-11-03 by the Sonnet-written fuzz batch; adjudicated WISEOWL-DEFECT (Opus adjudicator, billed to the API key), and its reduced repro re-run on a judge built from main 3c8b2845c (`fuzz_triage.py verify`) still shows it.

**The adjudicator's finding.** (2) Sibling of landed PB566 (unswept): an all-'*' / all-'Z' picture whose STORED value is zero after high-order truncation must be all asterisks (decimal point kept) / all spaces; MOVE 1000 TO PIC ***.** gives '***.00' (expected '***.**'), ZZZ.ZZ gives '   .00' (expected spaces), while BWZ on the same store blanks — fz00669 F10; repro probes/star/prog.cob. Site CobolEdit.cs:421 tests the pre-truncation 'scaled' (RescaleStoreCap, :239) instead of the stored digit string PB566's BWZ guard (:269) reads. fz00669 F11 and fz02081 E7 lines are WiseOwl-correct floating/zero-suppression insertion.

**The rule** (each marked checked by the adjudicator; re-run `cite.py --check` before writing one into code): §14.9.25.4 r6 1. 'de-editing establishes the operand's numeric value, which may be signed' (checked); §3.56 de-editing (checked); §13.18.40.5 r7 b) '... all character positions of the item will contain the character asterisk, but the decimal separator ... will appear' (checked)

**Sites:** `src/WiseOwl.Cobol.Runtime/Values/Numeric/CobolEdit.cs`:421 (the all-*/all-Z zero test reads the pre-truncation `scaled`, RescaleStoreCap :239), :269 (PB566's BWZ guard, which reads the stored digit string), the golden `conformance-suite/cases/13.18.40.5-Editing-rules/pb4515_zero_suppress_stored_value_zero`, `tests/WiseOwl.Cobol.Tests.Unit/CobolEditStoredSignTests.cs` (`Format_AllSuppressedPicture_TestsTheStoredDigits`)

**Landed (2026-11-03).** The re-probe printed `STAR [***.00] Z [   .00] BWZ [      ]` before the fix and `***.**` / six spaces after. `Render`'s whole-field-blank test now reads the stored digit string (`digits`), the same fact the BLANK WHEN ZERO guard reads; the all-floating-insertion pictures (`++++.++`, `----.--`, rule 6 b) share that one test and are fixed with it. `TryFormat`'s `scaled` is the size-error bound (§14.7.5), a different question, and stays.
