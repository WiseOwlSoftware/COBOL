# PB5213 - a PICTURE clause with IS written more than once compiles (PIC IS IS IS X(4), PICTURE IS / IS 9(3)): the lexer's PICMODE rule PIC_IS skips every IS, where the format prints one optional IS before the character-string

**Sites:**

- `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolLexer.g4` (`PIC_IS`, mode `PICMODE`; `OnPictureIs`, `_pictureIsWritten`, `NextToken`)
- `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolData.g4` (`pictureClause`: `PIC IS? PIC_STRING`)
- `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolSpecialNames.g4` (`currencySignClause`: the PICTURE SYMBOL phrase takes no IS)

**Mechanism.** The format is `{PICTURE | PIC} IS character-string` (§1985:VI.5.9.2), IS being an optional word: a word "whose presence is optional to the user when the format in which the word appears is used" (§1985:p.III-16), written once where the format prints it. In `PICMODE` the lexer has `PIC_IS : 'IS' -> skip ;`, a rule that fires on every IS before the character-string, so any number of IS words vanish and the parser sees one PICTURE clause. Under the format the second IS is the character-string, and `IS` is not a character-string (I is no picture symbol; §1985:VI.5.9.3 SR2: "A character-string consists of certain allowable combinations of characters in the COBOL character set used as symbols."). The rule is the same at every edition (2023's format prints the same single IS).

**Found by.** The 1985 refuter pass (2026-11-10; records `E:/COBOL-coord/scratch/refute-85/out/r08.json`, probes `probes-r08/p3.cob`, `p3b.cob`): a refuter attacked the CONFORMS verdict of the row below, OVERTURNED it, and the repro was rerun on current main for this note.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the row this note claims is the rule id below.

**Rules (1; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-FMT-VI.5.9.2` - `§1985:VI.5.9.2` (refuter: OVERTURNED, harm: under-rejects). The format prints `IS character-string` after PICTURE or PIC; §1985:p.IV-1: "Uppercase words which are not underlined are optional to the user and need not be written in the source program." The rest of the row held: a semicolon separator, a character-string continued on a hyphen line, edited and currency strings run; `PICTURE PIC X` (COBOL0808), `PIC.` (COBOL5506) and PIC twice (COBOL2423) are refused; S9(18) and an ODO table run.

**Repro (`pi1.cob`).** `cobol.exe --std 85 --source-format fixed --run pi1.cob`

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. PI1.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  A PIC IS IS IS X(4) VALUE "WXYZ".
       01  B PICTURE IS
               IS 9(3) VALUE 7.
       PROCEDURE DIVISION.
       P1.
           DISPLAY A "|" B.
           STOP RUN.
```

**Observed (current main, the build at 3d12682fd2, rerun 2026-11-10).** exit 0, no diagnostic; prints `WXYZ|007`.

**Expected (from the 1985 text).** Both entries are refused: after the one optional IS the next word is the character-string, and `IS` is not a valid PICTURE character-string (§1985:VI.5.9.2, §1985:VI.5.9.3 SR2).

**Fix direction (root cause, CLAUDE.md rule 4).** Make the optional word optional once: replace the skip rule with a PICMODE state that consumes at most one IS (for example a token the parser's `pictureClause` takes as `IS?`, or a lexer action that leaves the mode's IS state after the first), so a second IS reaches the character-string rule and is diagnosed there. Add a grammar test for PIC IS IS and for IS on its own line between PIC and the string.
