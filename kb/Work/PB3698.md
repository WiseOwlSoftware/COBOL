# PB3698 — ReceivingStore.AreaHoldsCharacters (PB3666) has a second, inline copy in SliceStorageArea, so the summary's claim that the predicate cannot drift from StorageCharacters has nothing structural behind it

**Sites:** `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/ReceivingStore.cs` (`AreaHoldsCharacters` near line 50, the inline test in `SliceStorageArea` near line 109)

One rule in one place: `SliceStorageArea` should call `AreaHoldsCharacters`, and a drift test should pin the predicate to `StorageCharacters`' decoding arms (the complement the summary claims).

## Landed (wave 20261716, group B, with PB3697)

Fixed in the same change that rebuilt the boolean storage-area store (PB3697): `SliceStorageArea` now asks `AreaHoldsCharacters` instead of spelling the `Usage.National or Usage.Bit` test, and `ReceivingStoreDriftTests.EveryStoreIntoABooleanItem_ConvertsItsCharacters` pins the predicate to `DecodedStorage`'s decoding arms (the test counts the pattern: exactly one spelling in `ReceivingStore.cs`, asked by the slice arm). `Characters` no longer asks the predicate, so the only reader besides the slice arm is the documentation of the complement.
