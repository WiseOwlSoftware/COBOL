# PB4080 — the R2 writer emits the one site form `work.py` reads as prose

**Sites:** `scripts/arch/file_census_notes.py` (`render_r2`)

**Where the code is.** `render_r2` (line 677 on main, unchanged on branch `worktree-wf_484eb705-564-32` at `e1b97d1ed`) writes each site as a bullet of the form path-in-a-code-span followed by the symbol in a parenthesis outside any code span (the loop over `rec["sites"]`, about lines 698-702).

**What happens.** The register reader takes a member only from a code span (PB3797, landing on that branch: the reader stays strict about the one form), so a parenthesised bare `Type.Member` is prose; the planner then claims the file whole and `work.py check` can refuse the note. PB3797 rewrote the 52 site lines of eight existing R2 notes by hand and left the writer alone, so the next R2 batch writes the old form again.

**Fix.** Emit the symbol inside a code span in `render_r2`, and add a case to the writer's self-test that round-trips an R2 record through `work.py`'s site reader and finds the member.
