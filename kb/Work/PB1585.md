# PB1585

Found 2026-09-25 by the train-64 lander: push-main exited 1 with "CI IS RED" on sha 5cd487c8f while both runs concluded
`success` (ci/ run 36132108302, main run 36133468693, confirmed with `gh run view`). A false red costs a landing's
attention and invites "it's a flake" — the pattern the verdict-evidence rule forbids.

Fix: retry each `gh` lookup with backoff; an EMPTY conclusion is "no verdict" — its own message and its own exit code
(never RED, never GREEN); keep gh's stderr in the log (do not `2>/dev/null`). Add a self-test that stubs `gh` to fail
once and asserts the script neither reports RED nor lands on a missing verdict.
