# PB3814 — the drift sweeps are a reader side that walks a test host's live bin/obj

**Sites:** `tests/WiseOwl.Cobol.Tests.Unit/SpecTraceabilityInventoryDriftTests.cs#UnresolvedTestRefs` (line 889,
`Directory.GetFiles(dir, cls + ".cs", SearchOption.AllDirectories)`), `TestRepoDriftTests.cs#TestSources`,
`ClassSpellingDriftTests.cs`, `ImpactedTestsDriftTests.cs`, `NoWallClockAssertionDriftTests.cs`,
`OneHostSurfaceDriftTests.cs`, `ProcessObservationDriftTests.cs`, `TrackedTreeScopeDriftTests.cs`,
`FileHarnessOneHomeDriftTests.cs`, `VacuousTestDriftTests.cs`, `GateLegDriftTests.cs`; the shared reader is
`tests/_shared/TrackedTree.cs` (declared TreeScopes).

## Measured (PB3677 merge group, run 40233968286)

`SpecTraceabilityInventoryDriftTests.EveryTestRef_ResolvesToARealTest` threw `UnauthorizedAccessException` on
`tests/WiseOwl.Cobol.Tests.Unit/bin/Release/net10.0/.wolk-gone-c76e2f0cd71e4edf8ddd1a7c8c1704ad`. `UnresolvedTestRefs`
resolves a `unit:` ref by walking `tests/WiseOwl.Cobol.Tests.Unit` with `AllDirectories`, so it enters the test host's working
directory (bin/<config>/net10.0). `CobolFileLockTests` opened shared files there by bare name, so the sidecar lock
directories (`.wolk-<hash>`, renamed `.wolk-gone-<guid>` then deleted by `SidecarLockFiles.RetireDirectory`) appeared in
the walked tree; on Windows a delete-pending directory answers access denied to the walk. PB3677's finisher removed the
one known WRITER (f779c6b22: `CobolFileLockTests` now keeps its files in a per-test scratch directory). The READER side
is untouched: about a dozen sweeps (sites above) still walk tests/ from the file system, and several filter bin/obj only
AFTER the enumeration has entered them. PB3122 (the resolver written twice) does not name the bin/obj walk.

**Repro.** Run any of the listed sweeps while a test in the same host opens a file in its working directory.

## Acceptance

- Every sweep above reads the source tree through ONE reader (TrackedTree with declared TreeScopes, or `git ls-files`),
  never `Directory.GetFiles(..., AllDirectories)` over a directory that holds a build output.
- A drift test fails when a Unit drift test enumerates `tests/` with `SearchOption.AllDirectories` outside that reader.
- Check first with `git grep -n "AllDirectories" -- tests` that the site list is complete.
