# PB5163 - at --std 85 a function-identifier with empty parentheses compiles (FUNCTION RANDOM (), FUNCTION CURRENT-DATE ()): functionCall makes the argument list optional inside the parentheses at every edition

**Sites:**

- `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolExpressions.g4` (`functionCall`)
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/IntrinsicBinder.cs` (`BindIntrinsic`, `BindFunctionResult`)
- `src/WiseOwl.Cobol.Compiler/Validation/VersionConformancePass.cs` (`ParseArm.VisitFunctionCall`)
- `tests/version-matrix/constructs/function-empty-argument-list-2002.json`

**Mechanism.** The 1985 function-identifier format (§1985:IV.4.3.8.3.2, added by Amendment 1) writes the parentheses only around one or more arguments, and §1989:A.2.35.2 prints RANDOM the same way; braces require one of their options (§1985:IV.2.1.4). The grammar rule `functionCall` writes `FNARG_LPAREN functionArgList? FNARG_RPAREN`, the later form with an empty list, and neither `BindIntrinsic` nor `BindFunctionResult` asks the edition, so FUNCTION RANDOM (), FUNCTION CURRENT-DATE () and FUNCTION WHEN-COMPILED () compile and run at --std 85.

**Found by.** The 1985 code read (2026-11-10; its records are `E:/COBOL-coord/scratch/coderead-85/for-register.json`): each rule below was read against the code sites it names and probed at `--std 85`, and found non-conforming. Verdict, harm, evidence, repro and observed text are the records'; the rows' verdicts are recorded on another branch.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids of the list below.

**Expected (from the 1985 text, the record's).** --std 85 refuses lines 9 and 10 at the empty parentheses. §1985:IV.4.3.8.3.2 prints "FUNCTION function-name-1 [ ( { argument-1 } ... ) ] [ reference-modifier ]": the brackets make the parenthesized list optional as a whole, and inside it the braces hold argument-1; §1985:IV.2.1.4: "When braces, { } , enclose a portion of a general format, one of the options contained within the braces must be either explicitly specified or implicitly selected." An argument-less reference is written without parentheses (FUNCTION RANDOM, FUNCTION CURRENT-DATE).

**Observed (the record's).** exit 0, no diagnostic; the program runs and displays RAN. --std 2023 gives the same (there the empty list is the standard's own form). Controls at --std 85: FUNCTION RANDOM and FUNCTION RANDOM (1) compile; FUNCTION MAX () draws COBOL1504 (an arity error from the function's definition, not a format refusal).

**Fix direction (root cause, CLAUDE.md rule 4).** Refuse an empty argument list below the edition that introduced it, in the one place the function-identifier is bound (BindIntrinsic), as a registry construct; the arity rules stay the catalog's.
