# PB5916 - COBOL2729 may have PB5906's wording fault

Filed from wave 20262102 group C's lead (kb/Work PB4950's branch, which also landed PB5906's message fix). The implementer's words, unchanged:

> COBOL2729 `PAGE-COUNTER OF 'R': the qualifier shall name a report description entry` may have PB5906's pattern for a report of another program that is not visible.

The dated file of PB5906 on that branch says the same: "`PAGE-COUNTER OF 'R9': the qualifier shall name a report description entry` may be the same pattern for a report of another program that is not visible."

PB5906's own pattern (that note): COBOL0863 said the file named by a LINAGE-COUNTER qualifier lacks a LINAGE clause when the real reason is that the file is not visible; the branch now gives two messages, one for a file this program cannot see and one for a visible file with no LINAGE clause. COBOL2729 is raised by `CounterReportOf` (kb/Work PB1049, PB1456), `src/WiseOwl.Cobol.Compiler/Binding/CounterResolver.cs#ReportOf` (kb/Work PB5800).

**Not reproduced or ruled:** the source says "may". The clerk has run no program.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/CounterResolver.cs#ReportOf` (named by kb/Work PB5800); the report-counter qualification message is COBOL2729 (kb/Work PB1049).

**Rows.** None claimed.

**Scope.** A `PAGE-COUNTER OF` or `LINE-COUNTER OF` qualifier naming a report of another program that is not visible; edition not stated by the source.
