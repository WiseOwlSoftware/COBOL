# PB6037 - the unit arm of PB5754's witness rule

**Finding.** PB5754 decided that a witness of a row at an edition is source text in a reference format that edition
defines, so before 2002 a free-form case witnesses nothing; its audit and writer apply it to conformance-suite cases.
PB6033 (landed on train-1985-c) states every inline C# test source free form at every edition, `--std 85` included
(`tests/_shared/TestSourceFormat.cs:31`, `TestSourceFormat.Inline`). That is behaviour-neutral (the detector already read
column-1 text as free), but 1985 inventory rows cite `unit:` witnesses (for example `1985-FMT-IV.4.2.2.2.1.1 ->
unit:CobolLiteralTests...`) whose text compiles free form at 85, which by PB5754's reasoning witnesses nothing there.

**Sites:** `tests/_shared/TestSourceFormat.cs` (`TestSourceFormat.Inline`), `scripts/spec/lineage_reads.py` (`ref_format_problem`,
`format_problem`: PB5754's one predicate of a witness's text, which gains or rules out a `unit:` arm)

**Question to decide.** Either extend PB5754's predicate to `unit:` witnesses at an edition before 2002 (an inline
source at 85 then states `Fixed` and is laid out fixed, or the row loses the witness and reads GAP), or record why a unit
test's free-form text at 85 still witnesses a rule that does not depend on the reference format. The measurement first:
count the KEPT 1985 rows whose only witness is a `unit:` test whose source is `TestSourceFormat.Inline`.
