## Measured

### Finding physical-subdivisions-of-a-report — §13.8.6.2.3 1); §13.18.54.4 GR12, GR8 a); §13.18.14.4 GR12; §8.4.2.3.3 SR5 (rejects-legal-source; rows SR-13.8.6.2.3-1)

**Mechanism.** A sum counter is modeled as ONE register per SUM entry, never as a table: DataBinder.Reports builds a single ReportSumModel.Register per entry and ReferenceResolver.SumCounterFor returns null for any subscripted reference, so a REPEATING sum counter (multiple COLUMN, equivalently OCCURS, §13.18.14.4 GR12) cannot be subscripted from the procedure division, while an unsubscripted reference is accepted and alters every occurrence at once.

**Repro.** --std 2023 (probe/physrpt/R6.cob): WS-X PIC 9 VALUE 3. RD R1 CONTROL IS FINAL PAGE LIMIT 20 LINES. 01 DET TYPE DE LINE PLUS 1. 03 DV COLUMN 1 5 9 PIC 99 VALUE 7. 01 CFG TYPE IS CONTROL FOOTING FINAL LINE PLUS 1. 03 CF-U COLUMN 1 13 25 PIC 9999 SUM WS-X. PROCEDURE: OPEN OUTPUT PRT. INITIATE R1. MOVE 500 TO CF-U(2). GENERATE DET. TERMINATE R1. CLOSE PRT. Variant R8.cob writes MOVE 500 TO CF-U unsubscripted.

**Expected, from the standard.** R6 compiles; the CONTROL FOOTING FINAL line prints '0003        0503        0003' (only occurrence 2 altered; each occurrence is its own counter per §13.18.54.4 GR8/GR12 and §13.18.14.4 GR12). R8 is rejected: CF-U is a table element and §8.4.2.3.3 SR5 requires every table element reference to be subscripted outside its listed contexts.

**Observed.** R6: error COBOLNET1639 'CF-U(2)' is not defined. R8: compiles clean and prints '0503        0503        0503' - one shared counter behind three printable occurrences. The single-register model also cannot represent per-occurrence accumulation (GR8 a) data-name addend repetition).

**Code site.** src/Cobol.Net.Compiler/Binding/ReferenceResolver.cs#SumCounterFor (early return when a suffix has no qualification); src/Cobol.Net.Compiler/Binding/DataBinder.Reports.cs sum Register construction (~L2394) and _sumCounters registration (~L2462); src/Cobol.Net.Compiler/Binding/Model/Place.cs#ReportSumCounterPlace (no occurrence index)
