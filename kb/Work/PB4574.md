# PB4574 - a golden header quotes a spliced sentence and records it OK

**Site.** `conformance-suite/cases/7.3.10-COBOL-WORDS/pb4488_cobol_words_directing_statements_precede_the_directive.cob`, header line 13: "Step 1: Library text identified in COPY
statements is incorporated". Step 1 of 7.2.1 begins "An expanded compilation group is created..."; the quoted sentence is its second sentence spliced onto the label.

**Check run on main (2026-11-03):**
`python scripts/spec/cite.py --check 7.2.1 "Step 1: Library text identified in COPY statements is incorporated"` printed
`FAIL: §2023:7.2.1 exists but does NOT contain 'Step 1: Library text identified in COPY statements is incorporated'`.
The header records `cite.py: OK` for it.

**Fix shape.** Quote the sentence without the label (and re-run `--check` on each quotation), and fix the header's OK line.
