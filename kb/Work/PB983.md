## Rule

The transcription's figure notes, measured from the printed page: §14.9.13.2 range-expression — "`IN` is **not**
underlined, so it is an optional word per 5.2.3"; §13.18.63.2 Format 3 — "`IS`, `ARE`, `IN`, `WHEN`, `SET`, and `TO` are
not underlined"; Format 5 — "`IS`, `ARE`, and `IN` are not underlined". (The CLASS clause's `IN alphabet-name-4` in
§12.3.7.2 IS underlined — that one stays required.) The fixer renders the three printed pages
(`scripts/render-spec-page.py`) before relying on the notes, per CLAUDE.md rule 1.

- `python scripts/spec/cite.py --check 5.2.3 "optional"` → OK §5.2.3 (Optional words)

With IN optional, `"M" THRU "A" AL` is a range whose collating sequence is alphabet AL's; the binder already
resolves the IN form (PB843: `BindRangeHigh` reads a trailing `IN <alphabet>` and binds through
`ReferenceResolver.WithoutTrailingSuffix`). Without IN, a bare trailing word after a range's high bound is either an
alphabet-name (the phrase) or — in EVALUATE — the start of the next object; only the symbol table decides, the same
§8.3.2.2 principle PB843 applied (`TrailingInPhraseDriftTests` pins the IN form's grammar shape).

## What the fixer owes

   `one_rule_one_place`).
2. Re-verdict FMT-14.9.13.2 (CONFORMS today) and the VALUE format rows.
3. COBOLNET1639 (and every diagnostic that echoes a qualified reference) renders the reference with its connectives

4. Goldens: EVALUATE at 2002 and VALUE Format 3 at the edition that introduced the alphabet phrase; a negative for a
   trailing word that is not an alphabet-name.
