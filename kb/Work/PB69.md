# PB69 — OPEN — the sentinel-as-argument residue of the PB13 saturation discipline

> ⚙ **flags:** wrong-answer, silent · found by the PB65/RV-15.64.4-1 landing's edge probe 2026-08-09;
> pre-existing (the old scale-9 arm saturated the same way at a lower threshold), NOT a regression.

**Measured repro** (`--std 2023`, probe `pb65b_edge.cob`, PB65 landing session): with
`A PIC S9(18) VALUE 999999999999999`, `B PIC S9(18) VALUE 1000000007`:
`COMPUTE R18 = FUNCTION MOD(A ** 3, B)` prints **639816141** where the owed value is **980012199**
(python: `999999999999999**3 % 1000000007`), silently — no SIZE ERROR, no EC.

**Mechanism.** `A ** 3` is 45 digits — past the Int128 exact window — so `PowNativeInt` takes its
documented double-approximation fallback (owner decision 2026-08-03: exact while it fits, the double
approximation past it, never a size error merely for outgrowing the carrier), and `FromDouble(9.99e44, 0)`
SATURATES to `Int128.MaxValue`. The PB13 saturation discipline is safe exactly when a receiver's capacity
check sits downstream ("the sentinel stays above the capacity check"); consumed as an intrinsic ARGUMENT
there is no capacity check, so `ModScaled(Int128.MaxValue, B)` answers from the sentinel. The same class
exists for ANY saturated Int128 carrier consumed at a value-semantics site rather than a store.

**Fix design question (record the alternatives, decide at fix time):**
1. Route the literal-exponent arm through `PowNativeIntDec` too (one arm, no sentinel — the overflow case
   carries the double approximation on the SDIDI, and `ModDec` computes an honest approximation). Cost:
   the hot `A ** 2` shape rides CobolDec, and ⚠ MEASURE FIRST whether `CobolDec.From(r, 0)` keeps a
   35–38-digit significand exact — if the SDIDI normalizes to §8.8.1.5.2's 32 digits, this arm LOSES
   exactness the Int128 lane has, and the split must stay.
2. Keep the split; make the FALLBACK Dec-carried by splitting at run time (an Int128-returning body cannot
   express it — needs the renderer to emit a Dec-typed call whose fast path is the exact integer).
3. Sweep the CLASS, not just `**`: enumerate every site where a saturated `FromDouble` result can reach a
   value-semantics consumer (intrinsic argument alignment, comparison operands, subscripts) — the PB13/PB5
   family's remaining quadrant.
