# PB2985 — rule 2's ACTIVE-CLASS sender is not described from the invocation at run time

**Sites:** `src/Cobol.Net.Runtime/Control/CobolObject.cs` (`CobolObject.NarrowUniversal`, `CobolObject.CheckActiveClassReturning`), `src/Cobol.Net.Runtime/Control/ActivationRelations.cs` (`ActivationRelations.ReturningConformance`, `ActivationRelations.ActiveClassReturningViolation`), `src/Cobol.Net.Runtime/Control/BASE.cs` (`BASE.__CobolInvoke`, `__FACTORY_BASE.__CobolInvoke`, `StandardMethodCrossing`), `src/Cobol.Net.Compiler/CodeGen/Verbs/OoEmitter.cs` (`OoEmitter.EmitCobolInvokeCase`, `OoEmitter.OoUnivCallerWrite`), `src/Cobol.Net.Compiler/CodeGen/Roslyn/RuntimeApi.cs` (`RuntimeApi.ObjNarrowUniversal`, `RuntimeApi.ObjCheckActiveClassReturning`)

Filed 2026-10-10 by the train 1055 lander from the wave 1055 C implementer's report
(`E:\COBOL-coord\scratch\t1055\review-CF\pa.cob`, `pd.cob` run clean), so the run-time reading must not be widened to it.

## Landed (wave 20261505 group A)

**Re-probe (own build).** `pa.cob` T4 (`SET U TO OS`, `INVOKE U "RA" RETURNING OP`, OP described P, RA's returning item
ACTIVE-CLASS) printed no exception and delivered the object; `pd.cob` ran clean. Rule (`cite.py --check`: OK 14.8.3.3 2)
b) 4.): "If the activated method is invoked with any other object reference, the sending operand has the same description
as that object reference" — a universal INVOKE is invoked with a universal reference, so the sender is universal;
§14.9.39.3 SR10 / SR12 / SR14 (OK 14.9.39.3 12)) close their lists of senders without a universal one and SR8 (OK
14.9.39.3 8)) lets only a universal receiving item take it; §14.9.23.4 GR7 c) (OK 14.9.23.4 7)) sets EC-OO-UNIVERSAL "if
checking for it is enabled in both the activated method and the activating runtime element" and makes the invocation
unsuccessful. The compile-time lane agreed already (COBOLNET0828 for an INVOKE through an interface-typed reference into
a class-typed receiver, `OoConformance.ReturningSender`); the run-time lane admitted every ACTIVE-CLASS item
(`ReturningConformance`'s `if (sending.ObjectKind is ActiveClass) return null`).

**Fix (the ONE table, the universal arm).** `ActivationRelations.ActiveClassReturningViolation` asks
`ObjectReferenceSet.Refusal` with a universal sender; `CobolObject.CheckActiveClassReturning(enabledInMethod, what,
receiving, sending)` raises EC-OO-UNIVERSAL before the method runs when checking is enabled in both halves, and returns
silently otherwise (the delivery's `NarrowUniversal` class narrowing stays the floor, so an unchecked program that worked
still works). Asked by every emitted `__CobolInvoke` case whose returning item is ACTIVE-CLASS (`EmitCobolInvokeCase`,
`RuntimeApi.ObjCheckActiveClassReturning`) and by BASE's New and FactoryObject (the standard class has no source, so its
half is on). It is a relation of its own, not a term of `ReturningViolation`, because that one's stop is unconditional
(`OoUnivStop`: an implementor-fatal when unchecked), which would turn a working unchecked program into a crash.

**Sibling sweep.** Arms of the dispatch: universal emitted case (fixed), BASE New / FactoryObject (fixed), typed INVOKE
(`ReturningSender`, already right, golden t03 pins it), CALL RETURNING (`CallReturningViolation` -> `ReturningConformance`:
ACTIVE-CLASS is legal only in a factory / instance / method definition, §13.18.60.3 SR16 — a program's returning item
cannot be one, so that arm is unreachable and unchanged). `pb2463_universal_returning_set_match` c14 (a universal INVOKE
of an ACTIVE-CLASS item into a typed receiver whose class is the containing class) changes from "match" to
EC-OO-UNIVERSAL: its own note recorded that rule 2 b) 4. would refuse it; its golden and comment are updated.

**Goldens.** `conformance-suite/cases/14.8.3.3-Elementary-items/pb2985_active_class_returning_universal_invocation`
(ten cases: universal and typed receivers, factory and instance methods, BASE New / FactoryObject, the method's half off,
the activator's half off); negative `pb2985-active-class-returning-universal-invocation-below-2002` (COBOLNET0900);
`tests/Cobol.Net.Tests.Unit/ActiveClassReturningUniversalSenderTests.cs`.
