## Finding — `stop-statement` (silent; rows `GR-14.9.42.4-2`, `GR-14.9.42.4-3`, `GR-14.9.42.4-5`)

**Mechanism.** Single exit-code channel: the ERROR/NORMAL indication and the STATUS value are merged into one int, with an unchecked (int) narrowing of a long, so the OS indication can contradict the phrase that was written

**Repro.** STOP RUN WITH ERROR STATUS 4294967296.  -> process exit 0 (normal). Also STOP RUN WITH ERROR STATUS 0. -> exit 0, and STOP RUN WITH NORMAL STATUS 7. -> exit 7.

**Expected from the spec.** §14.9.42.4 GR2: with ERROR, 'the operating system will indicate an error termination of the run unit if such a capability exists'. GR3 is the same for NORMAL. GR5: the value 'is passed to the operating system', and 'Any constraints on the value ... are defined by the implementor' (Annex A item 192, required documentation). The spec gives no precedence of GR5 over GR2/GR3. An implementor constraint must at least be documented truthfully, and ERROR must never produce a normal-termination exit because a large value wrapped around.

**Observed / reasoning.** RunUnit.ExitStatus (a long) flushes to Environment.ExitCode = (int)value, and NumericRenderer.ExitStatus emits (long)(value). A value of 2^32 therefore wraps to exit 0, so the OS reports normal termination for WITH ERROR. The documented item-192 constraint says 'the integer value ... becomes the exit code' and does not mention the int32 range or the wrap (nor Linux's 8-bit truncation). That part is an undocumented, silent divergence. Separately, CONFORMANCE.md item 192 publishes that 'GR5's value phrase overrides' the ERROR/NORMAL indication, so WITH ERROR STATUS 0/"ABEND"/SPACE exits 0 and WITH NORMAL STATUS 7 exits 7. Both GR2 and GR5 apply, and the spec does not state that precedence. The owner should re-confirm it as a determination tied to the GR2/GR3 text, or replace it with a mapping that keeps the indication (for example, ERROR with a value that maps to 0 still exits nonzero). The narrowing wrap needs a fix either way: saturate or range-check, and document the range.

**Code site.** src/Cobol.Net.Runtime/Control/RunUnit.cs#ExitStatus (Environment.ExitCode = (int)value); src/Cobol.Net.Compiler/CodeGen/Emit/NumericRenderer.cs#ExitStatus; docs/CONFORMANCE.md item 192 paragraph
