# PB2853 — stale golden-lane-1 templates

A lead from the operator's 2026-10-07 session, verified against main 495e8fb6f on 2026-10-08 ~22:00 PDT
(`.claude/skills/workstream/templates/`):

- `wf_lane1_draft.js`, `wf_lane1_validate.js`: no stop-file check (their only "STOP" text is "Stopping at the cap"), no
  authorization line; `wf_rolling_wave.js` has both (P3 scoped stop, PB2483; `args.authorization`).
- `wf_lane1_validate.js:48` pins `E:\COBOL\.claude\worktrees\lane3-pin-5fe593a0\…\cobol.exe`; that worktree does not
  exist.

## Fix

tree state passed in and checked, inputs written to the coordination scratch dir, the repo path from the script's own
location), with a check_practices.py rule that refuses a workflow template lacking a stop check or an authorization line
— or retire lane 1 if the lane is no longer used (then delete the three files in the same change, rule 4).
