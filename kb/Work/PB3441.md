# PB3441 — variable-length group with a dynamic national member: displayed width differs from LENGTH, CONVERT ANY aborts

**Register search before filing (R1).** `kb/Work` grepped untruncated for `CurrentMemberImage`, `ContiguousLayout`, `CobolContiguousLayout`, `dynamic-length national`, `dynamic national`, `BYTE-LENGTH`, `DOC-A.1-57`, `CONVERT ANY`, `Tier-C`, `xy06`, `displayed width`. Open notes naming the code sites are PB2203 (delete an unreferenced member of `CobolContiguousLayout`), PB2646, PB2654 and PB2746 (R2 restructure notes on the same carrier code, not this behavior), PB3099 (alphanumeric group holding a national leaf, a different question). PB164 recorded the original national width divergence and PB327 dissolved it for FIXED national members. Landed PB3358, PB3120, PB3129, PB2818 and PB1210 do not own the dynamic-national case. No open note owns it, so this one is new (id PB3441; PB3442 not used: the CONVERT ANY abort has the same root, below).

**Symptom (one mechanism).** `QG` holds `05 QA PIC N DYNAMIC LENGTH LIMIT IS 10` (value `N"xy"`) and `05 QN PIC 9(2)` (value 6).
- `DISPLAY QG` shows `xy06`, 4 positions (A.1 item 57's current-extent image, one character a position).
- `FUNCTION BYTE-LENGTH (QG)` is 6 (a national position is two bytes, D-N1).
- `FUNCTION CONVERT (QG ANY ANUM HEX)` (a `--permissive` coercion, a group is not a legal ANY source under strict) aborts at run time with `NotImplementedCobolFeatureException: raw-storage image (CONVERT ANY) of 'QG' ... the Tier-C byte island`. The storage is `007800793036`; the item's own `CONVERT (QA ...)` prints `00780079`.

**Root.** `GroupImageCodec.CurrentMemberImage` composes a dynamic-length leaf as its characters (`d.CsName`) while a FIXED national member contributes its UTF-16BE byte pairs (`AsImageOf`), and the same image doubles as the contiguous record image of A.1 item 63 (`ContiguousLayout`, `CobolContiguousLayout`, the Dyn carrier decomposing one character a unit). So the image is not the storage, which is why PB3424 round 2 had to gate CONVERT ANY's one-way arm on `DataItem.CurrentImageIsStorageImage` (false here) and leave the named loud abort rather than return the wrong value `78793036`. The abort is therefore a symptom of the same divergence, not a second mechanism.

**Spec.** §14.9.11.4 GR7 leaves the display format of a variable-length group to the implementor (cite.py --check 14.9.11.4: OK). §15.19.3 r7 requires CONVERT's ANY source to be the argument's storage (cite.py --check 15.19.3: OK). The defect is the compiler's own inconsistency: the DOC-A.1-57 row on main says "`LENGTH(G)` equals the displayed width, with no exception", which is false for this shape; PR #300 (PB3424) rewrites that row to call it "a recorded divergence", and a documented divergence is not a design (rule 6, and the dispatch spec: a found issue left in prose is a defect). Legal source (the group, DISPLAY, LENGTH) works; the strict-legal consequence is the permissive CONVERT abort and the width mismatch.

**Reproduced.** Yes, 2026-10-19, on the built compiler of worktree `wf_bf536e03-d89-7` (`src/Cobol.Net.Cli/bin/Debug/net10.0/cobol.exe`, `--permissive`), repro `E:/tmp/w1130a-review-r2/NV.cob` (copy `E:/tmp/pb3424-leads/NV.cob`): `[xy06]` and BYTE-LENGTH 6 with the CONVERT lines for PG/QG removed (`NV2.cob`); with them, CONVERT (FG...) and CONVERT (PG...) print `6162006300640102`, then CONVERT (QG...) aborts as above.

**Fix shape (record-framing redesign; the estimate is not a ceiling, rule 5).** Make the group image carry a dynamic national leaf as UTF-16BE (two bytes a position) in `GroupImageCodec.CurrentMemberImage`, so DISPLAY, LENGTH and storage agree, then move the contiguous record framing (A.1 item 63, `ContiguousLayout`, `CobolContiguousLayout`, the Dyn carrier) to the same unit; fold in PB2746 (the carrier implemented twice) so one composer states it. Then delete `CurrentImageIsStorageImage`'s national exception, let CONVERT ANY read the image, replace the PB3424 divergence text in DOC-A.1-57 with the single rule, and pin it with goldens for the item, a table of national elements and a nested group, all in a declared group and a cell-backed one, plus a drift test that the image, LENGTH and storage widths agree for every variable-length shape.
