# PB921 — OPEN — the edition axis written on one of two spellings

Source: the `PB560` report, "New defects" item 1. Re-measured here at `--std 85`.

## The measurement

`<scratch>/reg7/probe/m_numed_fmt1.cob` — the Format-1 spelling, `--std 85`:

```cobol
       01 X PIC ZZ9.99 VALUE 10.
```
```
m_numed_fmt1.cob(5,8): error COBOLNET0900: numeric-literal VALUE for a numeric-edited item requires
COBOL-2023 (targeting COBOL-85) — data item 'X' (ISO §13.18.63 SR6; Annex E.3.3 item 43)
```

`<scratch>/reg7/probe/m_numed_fmt3.cob` — the Format-3 spelling of the same fact, `--std 85`, `--run`:

```cobol
       01 X PIC ZZ9.99.
          88 X-TEN VALUE 10.
       PROCEDURE DIVISION.
           SET X-TEN TO TRUE
           DISPLAY "X=[" X "]"
```
```
X=[ 10.00]
```

Accepted at COBOL-85, and it stores the 2023 numeric-edited image. A COBOL-85 compiler has no such
conversion, so a program that relies on it is not COBOL-85 source — and `--std 85` said it was.

## The rule, and the open question inside it

```
$ python scripts/spec/cite.py --check 13.18.63.3 "may be numeric"
OK  §13.18.63.3 6)  (Syntax rules)
    6) If the item is of category numeric-edited, then, subject to Syntax rules 2 and 3, literals in
       formats 1, 2, and 4 of the VALUE clause may be numeric when they shall be converted to their
       numeric-edited forms according to the rules of the PICTURE clause …
```

SR6 names **formats 1, 2 and 4** — the level-88 condition-name VALUE is Format 3, and it is NOT in the
list. Two readings, and they give opposite answers:

* **SR6's list is exhaustive.** Then a numeric literal on a Format-3 VALUE over a numeric-edited subject is
  not admitted AT ANY EDITION, and `m_numed_fmt3` should be refused at 2023 too. The whole 2023 numeric-
  edited golden set that rides Format 3 would move.
* **SR6's list is editorial** (formats 1, 2 and 4 are the *data-item* VALUE formats, and Format 3 inherits
  through §13.18.63.4 GR19 "the characteristics of a condition-name are implicitly those of its conditional
  variable"). Then Format 3 needs the SAME Annex E.3.3 item 43 gate as Format 1, and today it has none.

**Either reading makes the current behaviour wrong**, which is why this is a defect note and not an
adjudication: the fixer derives the answer from the rendered §13.18.63.2 figure and the E.3.3 entry, and
implements it. The PB560 report flags the choice as a DETERMINATION and is the reason every numeric-edited
golden in that change set rides 2023 — that dependency is real and is recorded here so it is not rediscovered.
