# PB5445 - at --std 85 an indexed file's record key may name a group that contains an OCCURS DEPENDING ON table

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/FileControlKeyRules.cs#Rules` (the rows `SR-12.4.5.12.3-3` and `SR-12.4.5.6.3-3`)

**What the 1985 text requires.** Of the ALTERNATE RECORD KEY clause: "Data-name-1 must not reference a group item that
contains a variable occurrence data item." (§1985:IX.2.5.3 SR3, cite.py OK). Of the RECORD KEY clause, the same sentence
(§1985:IX.2.7.3 SR3, cite.py OK). A variable occurrence data item is a table with OCCURS ... DEPENDING ON. The 2023 rules
in the same place say instead "Data-name-1 and data-name-2 shall not reference a variable-length data item"
(§2023:12.4.5.12.3 SR3 and §2023:12.4.5.6.3 SR3, cite.py OK), which names a dynamic-length elementary item or a
dynamic-capacity table, not a group containing an ODO table: the two 1985 rows are CHANGED records for that reason
(band-85, kb/Work/PB4996/2026-11-10-band-85-and-first-verdicts.md).

**Repro (origin/main 09ce7dc601, cobol 25.0.0, assemblies 2298d8a35026).** The record is
`01 IXR. 05 IK PIC X(3). 05 IA PIC X(2). 05 IG. 10 IGN PIC 9. 10 IGT PIC X OCCURS 1 TO 5 TIMES DEPENDING ON IGN.`
- `E:/COBOL-coord/scratch/draft-85m/repro/1985-SR-IX.2.7.3-3.cob`: `RECORD KEY IS IG.` at line 9;
- `E:/COBOL-coord/scratch/draft-85m/repro/1985-SR-IX.2.5.3-3.cob`: `RECORD KEY IS IK` and `ALTERNATE RECORD KEY IS IG.` at
  line 10.

Expected at --std 85: each refused at the key's line. Observed: `cobol --std 85` translates both, exit 0, no diagnostic
(`repro/*.txt`; run_drafts: "no diagnostic at the marked line"). Their controls (the key naming IK, or IA) translate too.

**Mechanism.** The key rows of `FileControlKeyRules.Rules` for SR3 test `op.Item is { IsDynamicLength: true }`, the 2023
reading, with no edition condition, and no row states the 1985 rule. The fix is a 1985 row (or an edition arm of these two
rows) that refuses a key whose item is a group with a subordinate variable occurrence data item, in force at 85 only.

**Inventory.** `1985-SR-IX.2.5.3-3` and `1985-SR-IX.2.7.3-3` (CHANGED, no witness yet). `work.py check` refuses a 1985 rule id
in `inventory_rows` (kb/Work PB5094), so `inventory_rows` is empty. No verdict was recorded; the two drafts in
`E:/COBOL-coord/scratch/draft-85m/state` place as the rows' witnesses once the fix lands.
