## Measured (rows this note claims beyond the findings above)

### `GR-8.3.3.6.4-7` — DIVERGES (adjudicator + refuter record, verbatim)

Rule: 'At runtime, when referenced outside the SPECIAL-NAMES paragraph, the low-value format represents the character, or multiple-character combination, that has the lowest ordinal position in the runtime collating sequence.' (cite.py --check 8.3.3.6.4 -> OK 7)). U+0000 IS the lowest position of both 65,536-position native sequences, so the native pin is correct here (unlike GR6); a literal-phrase sequence takes its first-specified lowest character. PROBES (probe/figurative-constant-values): p1.cob native ORD(LOW-VALUE)=1; p3.cob PCS 'B' 'A' 'C' -> LOW-VALUE = 'B', ORD 1; p5.cob national PCS N"B" N"A" N"C" -> MOVE LOW-VALUE TO PIC N = N"B" while the alphanumeric LOW-VALUE stays ordinal 1 (national context uses the national PCS); p4.cob LOCALE PCS ORD(LOW-VALUE)=1 (U+0000, completely ignorable rank, determination L7); SPECIAL-NAMES arm AlphabetFigurative -> U+0000 native (§12.3.7.4 GR10). Goldens da1_alphabet_hex_thru and pb297_figurative_sizing_categories derive LOW-VALUE='Z' from GR7. || REFUTED: DIVERGES — The value is correct in MOVE, VALUE, comparison, STRING, DISPLAY, INITIALIZE and EVALUATE, but INSPECT ignores the program collating sequence. Under PROGRAM COLLATING SEQUENCE IS AL (ALPHABET AL IS "B" "A" "C"), GR7 makes LOW-VALUE the lowest-ordinal character, 'B'. The INSPECT emitter instead hard-codes the native U+0000 for LOW-VALUE in both its TALLYING and REPLACING arms. That is a wrong answer at runtime, outside SPECIAL-NAMES, which is exactly what GR7 governs. INSPECT SR3 (§14.9.22) says a figurative operand 'refers to an implicit one character data item' of alphanumeric class, so it carries the GR7 value. The adjudicator's probes never put LOW-VALUE under a non-native PCS in any verb except MOVE. This looks like the two-arm pattern: FigurativeConstants.Fill/FillChar honour the PCS, and the INSPECT literal path does not route through them. The HIGH-VALUE sibling is presumably the same, but GR6 is already DIVERGES.
