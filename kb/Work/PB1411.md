### `GR-8.5.1.9.1-1` — PARTIAL (adjudicator + refuter record, verbatim)

Rule: 8.5.1.9.1 1) 'its occurrences are created dynamically' (cite.py --check 8.5.1.9.1 "its occurrences are created dynamically" -> OK 8.5.1.9.1 1)). CobolDynTable<T> is an out-of-line growable store; GrowTo creates and seeds occurrences [old..new) on demand, RefReceiving grows on a receiving subscript past the current capacity (8.5.1.9.3, --check OK 'a new element is automatically created and the capacity of the table is increased to the value given by the subscript'), SetCapacity grows/shrinks explicitly. Probe p3: MOVE 8 TO LZ(100000) in LOCAL-STORAGE -> LC=0000100000, LZ(100000)=8; 7-level nested dynamic tables grow on demand (p4 A7=4). Covering golden dyn_implicit_grow (expected values derived from 8.5.1.9.2/.9.3 in its header). || REFUTED: PARTIAL — Occurrences are NOT created dynamically when the receiving operand is an element of a dynamic-capacity table that is a VARIABLE-LENGTH GROUP (an element containing a nested dynamic table). The variable-length-group MOVE emitter renders the receiving element through RefSending instead of RefReceiving (the two-arm dispatch shape), so a MOVE to such an element past the current capacity does not create it, does not raise the capacity, and writes into the benign scratch slot -- the data is silently discarded (wrong answer, no diagnostic). All elementary/fixed-group receiving shapes I probed DO grow correctly (MOVE, ADD, SUBTRACT, MULTIPLY, DIVIDE, COMPUTE, STRING INTO, UNSTRING INTO, ref-mod receiver, INITIALIZE, INSPECT REPLACING, ACCEPT, SET 88 TO TRUE, CALL BY REFERENCE, nested dyn in dyn, dyn in fixed OCCURS, LOCAL-STORAGE, arithmetic subscripts), so the rule is half-verified => PARTIAL. The cited golden dyn_implicit_grow pins only an elementary MOVE and also asserts undefined content (E3 without INITIALIZED per 8.5.1.9.5) and a checking-off sending-past-capacity read, so it does not pin this branch.

## What the fixer owes

Route the variable-length-group receiving element through RefReceiving (the arm every elementary/fixed-group receiver already uses); drift test that no receiving-position emitter calls RefSending.
