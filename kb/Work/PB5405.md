# PB5405 — the self-tests of `scripts/spec/e*.py`–`l*.py` with `test_figure_*.py` (about 2,450 lines) become case files under their `selftests/` directories, each script's `--self-test` handler deleted

**Sites:** `scripts/spec/e*.py`, `scripts/spec/f*.py`, `scripts/spec/g*.py`, `scripts/spec/i*.py`, `scripts/spec/l*.py`, `scripts/spec/test_figure_*.py`, the `selftests/` directory of each converted subject (new), `scripts/selftest_layout.py` (`REMAINING`), `scripts/self_test_arms.py` (`DECLARED`)

## The design this step implements

`docs/rearchitecture/DESIGN-orchestrator-loop.md` §16.2 and §16.10 (kb/Work PB3726). The design is the SSOT; this note does not restate it.

## The step

For every script the Sites' globs match that holds a self-test (a `--self-test` handler, or a standalone `test_*.py`
beside its subject), cut it into `fixtures.py` and `test_<world>.py` files under the subject's directory (§16.2), reach
the subject through `selftest_cases.subject`, delete the handler, the `self_test` function and every helper only it used,
carry each `# SELF-TEST-*` header to every file whose cases need it, rewrite the subject's `self_test_arms.DECLARED` entry
to case names, move every `<script> --self-test` spelling, and lower `REMAINING` to the new count. A script with no
self-test is not touched. If the batch does not fit one wave, the implementer stops at a subject boundary, lands what is
converted (each subject is whole) and reports the rest; the next dispatch continues this note.

## Oracle

Per subject: the label sets before and after equal (both in the report); `self_tests.py --list` the same headers per
subject; the git processes of each subject's run at most one more per new file; the gate GREEN.

## Done when

No script the globs match handles `--self-test` or is a standalone `test_*.py` outside `selftests/`; the layout rule
GREEN at the lowered `REMAINING`.

## The bar (CLAUDE.md rules 2, 4, 5 and 6; PB3726)

- The design is `docs/rearchitecture/DESIGN-orchestrator-loop.md` §16.2 and §16.10; read §16.1 (the oracle) and §16.2 (the case layout) first. A design correction
  found while implementing updates the section in the same change (rule 2), and a definition the section's table does not
  name goes to the module whose job it does, with the table updated (rule 5).
- No wrapper, shim, forwarder, alias, re-export or compatibility import: every caller moves and the old name is gone in
  this landing (`git grep` of the old spellings over `scripts/`, `.claude/`, `tests/`, `docs/`, `conformance-suite/` and
  `.github/` finds nothing outside the DEVLOG and kb/Work).
- The docs current in the same change set (§16.11).
- Dispatched as a group claiming its Sites WHOLE, one PB3726 step per wave (§16.10); the loop does not plan this cluster.
