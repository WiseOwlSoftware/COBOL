# PB4504 — a Claude program writer for the differential fuzz

**Sites:** `scripts/fuzz_claude.py` (whole: new), `scripts/differential_fuzz.py` (`writer_reply`, `Fuzz.spent_out`,
`Fuzz.one`, `Fuzz.record`, `Fuzz.run`, `Settings`, `main`, `self_test`)

**What was missing.** `differential_fuzz.py` asked `fuzz_ollama.ollama_chat` for every program, so a run needed a
local Ollama model (qwen3-coder:30b on this host). A cloud session (claude.ai/code, 4 vCPU, no GPU) has none, and the
owner's direction for one is that "an appropriate Claude model" writes the programs.

**As landed.** `fuzz_claude.claude_chat(model, messages, temperature)` returns the same `(reply, seconds, done,
thinking)` shape as `ollama_chat`, through `claude -p` made a plain text generator (`--tools ""`,
`--no-session-persistence`, `--setting-sources ""`, `--strict-mcp-config`, the fuzz's own `--system-prompt`,
`--output-format json`, a per-call `--max-budget-usd`). The exchange so far travels as one labelled user turn on stdin.
`max_tokens` is a reply cut short ("length"), and an error record, a missing CLI or a timeout is a RuntimeError, the
row's RUNNER_ERROR, as an Ollama failure is. Every call's `total_cost_usd` adds to a process-wide meter (`spent()`).
`differential_fuzz.py` gains `--writer {ollama,claude}` (default ollama; with claude, `--model` is a Claude alias or id
and `--bake-off` / `--model-option` are refused) and `--max-usd` (no new program starts once the meter reaches it;
refused for the Ollama writer, which spends nothing). The generation asks `writer_reply(settings, options, messages)`,
rows record `writer` and, for Claude, `spent_usd`, and only an Ollama model is unloaded at the end. No sampling
temperature reaches the CLI (it has none), so the writer is recorded in `run.json` with the settings.

**Witnesses.** `python scripts/fuzz_claude.py --self-test` (a stub CLI: the arguments, the labelled transcript on stdin,
the metered cost, "length", the error and non-JSON replies); `python scripts/differential_fuzz.py --self-test` (the
`--writer` / `--max-usd` refusals, the writer routing and the spend ceiling).
