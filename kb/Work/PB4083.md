# PB4083 — the PowerShell self-tests' scratch repositories live outside the one fixture

**Sites:** `scripts/orchestrator/test_orchestrate_adopt.ps1` (`G`, `Land`, the `init`/`clone` of `adopt-origin.git`,
`adopt-checkout`, `adopt-lander`), `scripts/orchestrator/test_orchestrate_ledger.ps1` (the same helpers and three repositories),
`scripts/orchestrator/testdata/orchestrate_test_lib.ps1`, `scripts/scratch_repo.py` (`NO_AUTO_MAINTENANCE`, `REPO_CONFIG`, `--audit`)

**What is wrong.** kb/Work PB3584 made `scripts/scratch_repo.py`'s `ScratchRepo` the one place a self-test's git starts.
It writes each repository's own config with one identity, `NO_AUTO_MAINTENANCE` and no signing, and it checks every
fixture command. `SelfTestFixtureDriftTests` and `scratch_repo.py --audit` hold that rule for PYTHON self-tests only.
The two PowerShell self-tests above build three repositories each with plain `git init`/`git clone`. Each defines its own
`G` helper (an identity passed as `-c` options, so it never reaches the code under test's git) and its own `Land`, a
word-for-word copy in both files, and neither writes `NO_AUTO_MAINTENANCE` into its repositories.

**Harm.** Under `self_tests.py` nothing is wrong, because its private global config (`GIT_CONFIG_GLOBAL`) turns maintenance
off for every git process. Run by hand, as their own header says (`pwsh -NoProfile -File ...`), every commit, push, fetch
and merge in those repositories, the supervisor's included, may start a detached `git maintenance run --auto`. That is the
harm PB3584 measured for Python (74 processes from one self-test). The identity and the checking also drift per file.

**Fix direction.** Give the fixture a face PowerShell can use. Either a `scratch_repo.py` command creates the repository
(init, clone or bare origin) with `REPO_CONFIG` written into it, or one prints `REPO_CONFIG` for the harness to apply. The
values then stay in the one place `SelfTestFixtureDriftTests` says owns them. Move `G` and `Land` into
`orchestrate_test_lib.ps1` once, and extend the audit, or the drift test, to the PowerShell self-tests.
