# PB4362 - Two weak witnesses of PB4335

**Sites:**

- (a) `tests/WiseOwl.Cobol.Tests.Conformance/StopGobackExitCodeTests.cs` (`StopGobackExitCodeTests.CalledGobackReturningWithoutAHeaderItem_IsInert_AndTheMainProgramsStatusStands`, line 125).
- (b) `conformance-suite/cases/14.9.18-GOBACK/pb4335-goback-returning-below-2002.cob` (line 9, the header comment).

(a) The main program of the test ends `GOBACK WITH ERROR STATUS 6`, and `RunUnit.SetExitStatus` (`src/WiseOwl.Cobol.Runtime/Control/RunUnit.cs:249`) is last-write-wins. A callee that wrongly set its folded status would be overwritten by the main program's 6, so the test passes with the defect it is named after present. Fix: have the main program end without a status of its own (plain `GOBACK` or `STOP RUN` with no status), so the callee's status would show; and prove it fails by planting the defect once.

(b) The golden's header names its positive control as `2002/pb4335_goback_returning_no_header_item.cob`. No such path exists; the positive case sits in the same directory. Fix: name the real file.
