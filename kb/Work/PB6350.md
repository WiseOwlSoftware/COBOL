# PB6350 — another hand switch over conditions with a default arm

`src/WiseOwl.Cobol.Compiler/Binding/Passes/UsageCollectionPass.cs` (`Cond`, near line 411) is a hand switch over `BoundCondition` shapes ending in `default: break`; it names neither `BoundRangeMembership` nor `BoundUdfEvaluated`, so an operand inside either is never visited. This is the class PB6328 removed from `EcBinder` (hand switches replaced by a node test over `BoundValueWalk.SelfAndDescendants`). The sweep `grep -rn "BoundLogical" src` found it.

**No observed wrong output.** The implementer's probe (`probe5.cob`: a group with a numeric leaf holding spaces, an EVALUATE range IN an alphabet, an OR window) printed the right answer, so no harm flag is set. What is open is whether the pass can miss a usage through the omitted arms (a usage fact, for example, that a UDF-evaluated condition's operand is read), and whether it should be the same node-test rewrite. Probe that first; file a defect if a usage is lost.
