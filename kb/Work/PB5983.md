# PB5983 - one EXTERNAL record described with two lengths by separately compiled programs

The PB5912 decision (docs/conformance/3/D-85-EXTERNAL-FD-AGREEMENT.md) documents that WiseOwl COBOL does not compare the
descriptions of one external file connector across separately compiled programs at `--std 85`: a mismatch has undefined
results. Undefined must not mean a crash of the run time. Probe: two separately compiled programs, one describing an EXTERNAL
record (and one an EXTERNAL file's record) at 10 bytes and the other at 100, the second writing all 100 and reading them back,
at `--std 85`. If the run time faults (an out-of-range access, an unhandled exception), this becomes a defect with
`crashes: true`; if it behaves (the storage is sized by the largest description, or the call is refused with a diagnostic),
record what it does in the determination and retire this note.

**Sites:** none (an analysis; the probe decides whether code changes)
