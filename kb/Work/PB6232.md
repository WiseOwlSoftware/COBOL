**Rule it breaks:** §2023:14.9.13.4 GR3 (each selection subject is evaluated at the beginning of the EVALUATE statement); the PB396 doctrine written at EvaluateBinder.cs:38-49 and SubjectUsage summary (:1054-1058): a single use skips the intermediate only when the render sits in the FIRST arm condition, which the emitted if/else-if chain always executes

**Scenario:** SubjectUsageOf sets ReadByFirstPhrase from the first WHEN phrase alone, without the position of the object in it. The pairs of a phrase are AND-ed and short-circuit left to right (GR4 c; line 98 and the comment at :588-590), so a subject at ordinal i > 0 is rendered only if pairs 0..i-1 are true. Repro: 01 T. 05 R PIC 9 OCCURS 3. 01 X PIC 9 VALUE 2. with EC-BOUND-SUBSCRIPT checking on: EVALUATE X ALSO R (9) WHEN 1 ALSO 5 DISPLAY "A" WHEN OTHER DISPLAY "O" END-EVALUATE. Subject 2 has one use, in the first phrase, so NeedsIntermediate is false and the emitted test is X == 1 && R[9] == 5. With X = 2 the R (9) reference is never evaluated and EC-BOUND-SUBSCRIPT is never raised, where a conforming run evaluates both subjects first. EVALUATE X ALSO A / B with B = 0 loses EC-SIZE-ZERO-DIVIDE the same way. These are the shapes PB396 measured, one ordinal over.

**Measured how:** R2 batch finding `procedure-binding-4--code--f1#1` (pair procedure-binding-4--code), read in the pinned tree at 9e65164eb3a9; skeptics rule upheld, scenario upheld, site upheld.

**Spec:** §2023:14.9.13.4 "At the beginning of the execution of the EVALUATE statement, each selection subject is evaluated and assigned a value, a range of values, or a truth value" (`cite.py --check` passed at collection); §2023:14.9.13.4 "If the result of the analysis is false for any pair in a WHEN phrase, no more pairs in that WHEN phrase are evaluated" (`cite.py --check` passed at collection)

**Target:** ReadByFirstPhrase holds only when every object before position index in the first phrase is ANY (a constant-true pair that always reaches the next one); otherwise the subject takes the PRE-op intermediate. Add a test of a two-subject EVALUATE whose second subject faults and whose first pair is false.
