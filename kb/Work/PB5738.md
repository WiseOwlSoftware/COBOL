# PB5738 - adjudication: at --std 2002, is a method declared METHOD-ID m AS literal reachable by its method-name-1 through a typed object reference (INVOKE P \"m\")? The compiler keys the class's methods by the externalized literal only and refuses it COBOL0825; GR1b/GR4 and 8.3.1.1.1 read two ways

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Model/OoClassSymbol.cs#TryAddMethod` (keys the method roster by `m.ExternalizedName` only, kb/Work PB303; documented as an implementor choice in `docs/conformance/7/DOC-A.1-68.md`)

**The question.** `2002-GR-11.6.3-4` (KEPT into `GR-11.7.4-4`, recorded CONFORMS) says the method's name "may be referenced in
the invocation of a method". For `METHOD-ID. ALIASED AS "Ext-Name-1".`, is that name `ALIASED` (method-name-1) or `Ext-Name-1`?

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**
- `§2002:11.6.3 GR1b`: "Otherwise, the name is method-name-1" (the sentence continues: literal-1, if specified, "is the name of method that is externalized to the operating environment")
- `§2002:11.6.3 GR4`: "The name of this method may be referenced in the invocation of a method for an object of the class in which this method is defined"
- `§2002:14.8.22.2 SR4b`: "literal-1 shall be the name of a method contained in the instance interface of that class-name"
- `§2002:8.3.1.1.1`: "the naming convention and mapping to be used for the method-name is determined by the entry convention of the class or interface that contains the method"

**Reading A (refuse is wrong).** By GR1b the method's NAME is method-name-1 and the literal only names it to the operating
environment; GR4 and INVOKE SR4b let that name be the INVOKE literal, so `INVOKE P "ALIASED"` through a reference typed `PA` is
legal 2002 source, and refusing it rejects legal source (cause b: the same at 2023).

**Reading B (the code's).** 8.3.1.1.1 hands the mapping of a method-name used through a typed reference to the class's
implementor-defined entry convention, so matching only the externalized name is a permitted convention, which
`docs/conformance/7/DOC-A.1-68.md` documents.

The text does not settle it; this note decides nothing.
