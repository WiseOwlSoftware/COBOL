# PB5476 - at --std 85 a class condition on an integer function whose value the binder folds (FUNCTION LENGTH (X5) IS NUMERIC) compiles, where §1985:VI.6.3.1.2 GR5 admits only an alphanumeric function

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ConditionBinder.cs` (`ConditionBinder.CheckClassConditionOperand`)
- `src/WiseOwl.Cobol.Compiler/Binding/ClassConditionModel.cs` (`ClassConditionModel.Violates`)
- `src/WiseOwl.Cobol.Compiler/Binding/IntrinsicResultType.cs` (`IntrinsicResultType.OperandCategory`)

**Mechanism.** kb/Work PB5122 landed the 1985 operand rules of the class condition, and `FUNCTION NUMVAL ("1") IS NUMERIC` is refused (COBOL6918). `FUNCTION LENGTH (X5)` of a fixed-size item is folded to a constant before the operand screen asks the operand's category, so the screen sees no function-identifier and the 1985 rule "it must reference an alphanumeric function" is never applied. LENGTH is an integer function (Amendment 1).

**Found by.** The 1985 code read, read 4 (`kb/Work/PB4996/2026-11-13-read-4.md`): the reader of `E:/COBOL-coord/scratch/coderead-85/out-read4/rd-04.json`.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. Its rows are recorded naming this note (records-rd4).

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`, log `E:/COBOL-coord/scratch/op-20261113/records-rd4/cites.txt`).**

- `1985-GR-VI.6.3.1.2-5` - `§1985:VI.6.3.1.2 GR5` (read: PARTIAL, harm: under-rejects): "If identifier-1 is a function-identifier, it must reference an alphanumeric function".

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-read4/work-rd-04/c2/s1.cob`:

```cobol
       01  X5 PIC X(5) VALUE "ABCDE".
       PROCEDURE DIVISION.
       MAIN-PARA.
           IF FUNCTION LENGTH(X5) IS NUMERIC DISPLAY "T".
           STOP RUN.
```

`cobol.exe --std 85 --source-format fixed --run s1.cob` (the reader also tried `FUNCTION LENGTH ("ABC")`).

**Observed (the pinned compiler of `E:/COBOL-wt/coderead85-tree-d` (main 725550baca, the base of this branch), rerun 2026-11-13 from copies in `E:/COBOL-coord/scratch/op-20261113/records-rd4/rerun/`; the log is `E:/COBOL-coord/scratch/op-20261113/records-rd4/rerun-log.txt`).** Compiles with no diagnostic and prints `T`; exit 0.

**Expected (from the 1985 text).** Refused (COBOL6918, as for NUMVAL): LENGTH is an integer function, not an alphanumeric one.

**Fix direction (root cause, CLAUDE.md rule 4).** Apply the function-identifier operand rule to the operand as written, before (or independent of) constant folding, so a folded function keeps its function category for the screen; sweep the other operand screens that read a folded operand's category.
