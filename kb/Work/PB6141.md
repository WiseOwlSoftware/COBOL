r2_ids: data-binding-2--duplication--f1#1

**Wave kind:** unify. **Model:** Opus (touches the data model's REDEFINES classes).

**Mechanism.** A Tier-A (`RedefinesTier.Alias`) class has one canonical member and views that own no storage. The test "this item is a
non-canonical member of an Alias class" is spelled inline as `item.Class is { Tier: RedefinesTier.Alias } && !item.IsCanonical` at
several sites below, and as `cls.Tier != RedefinesTier.Alias`, `alias.Members.Contains(child)` and `c.IsCanonical` variants elsewhere.
Two guard shapes disagree about what else must hold (membership of the class, the canonical's own flag). A change to the alias rule must
be made at every site, and nothing fails if one is missed.

**Target.** One named predicate on `DataItem` (the alias view and the canonical it forwards to), every inline pattern replaced and
the old spellings deleted in the same change (CLAUDE.md rule 4), and a drift test that no other file spells the tier test. The sites
below are a 2026-11-23 grep of the pattern, not the R2 list; the implementer re-derives the full set of 13.
