r2_ids: data-binding-2--duplication--f1#1

**Wave kind:** unify. **Model:** Opus (touches the data model's REDEFINES classes).

**Mechanism.** A Tier-A (`RedefinesTier.Alias`) class has one canonical member and views that own no storage. The test "this item is a
non-canonical member of an Alias class" is spelled inline as `item.Class is { Tier: RedefinesTier.Alias } && !item.IsCanonical` at
several sites below, and as `cls.Tier != RedefinesTier.Alias`, `alias.Members.Contains(child)` and `c.IsCanonical` variants elsewhere.
Two guard shapes disagree about what else must hold (membership of the class, the canonical's own flag). A change to the alias rule must
be made at every site, and nothing fails if one is missed.

**Target.** One named predicate on `DataItem` (the alias view and the canonical it forwards to), every inline pattern replaced and
the old spellings deleted in the same change (CLAUDE.md rule 4), and a drift test that no other file spells the tier test. The sites
below are a 2026-11-23 grep of the pattern, not the R2 list; the implementer re-derives the full set of 13.

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/Model/DataItem.cs` (`DataItem.AliasCanonical`, `DataItem.IsAliasView`, `DataItem.IsPlainMember`: the one rule, landed)
- `tests/WiseOwl.Cobol.Tests.Unit/Architecture/AliasViewRuleDriftTests.cs` (`AliasViewRuleDriftTests`: the drift pin)
- `src/WiseOwl.Cobol.Compiler/Binding/LinkageBinder.cs:330` (`LinkageBinder.AnchorOf`)

**Fixed (2026-11-23, wave 20262161 group E).** Every inline spelling now reads `DataItem.AliasCanonical` / `IsAliasView` /
`IsPlainMember`; `CorrPlainMember` is deleted; `AliasViewRuleDriftTests` pins that only `RedefinesModel.cs`,
`ClassifyRedefinesClassesPass.cs` and `DataItem.cs` name the Alias tier. The membership guard `RecordLayout` added
(`alias.Members.Contains`) was redundant: the classifier admits Tier A only when every member is elementary, so no subordinate
carries an Alias class. `PlaceBuilder.PlaceForItem`'s "non-canonical, not Alias" guard is now the Rejected-tier test it meant
(Tier B returns earlier). Behavior-neutral: the §4 oracle comparison is in the DEVLOG entry.

## Landing
- `src/WiseOwl.Cobol.Compiler/Binding/Model/DataItem.cs#AliasCanonical` — the Tier-A view rule; ask `AliasCanonical ?? item` for the item whose field a reference renders, `IsAliasView` to skip a view's field or local, `IsPlainMember` for "reached as a typed member by its own name". Never spell `RedefinesTier.Alias` elsewhere (`AliasViewRuleDriftTests`).
- `src/WiseOwl.Cobol.Compiler/Binding/Passes/StorageFormPass.cs#Classify` — arm (2) forwards a Tier-A view first, then the Tier-B window; a Rejected view falls through.
- `src/WiseOwl.Cobol.Compiler/Binding/Model/PlaceBuilder.cs#PlaceForItem` — the null guard is the Rejected tier only (Tier B returned above it).
- Trap: `RedefinesTier`'s default value is `Alias`, so an unclassified `RedefinesClass` reads as Tier A; the classifier assigns every member's class and then classifies in one pass, so no reader sees that window today.
