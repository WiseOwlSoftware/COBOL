# PB3786 — a worktree mid-merge crashes the planner

**Sites:** `scripts/orchestrator/inflight.py#inflight_units`, `scripts/orchestrator/inflight.py#bounded_pathspec`, `scripts/orchestrator/inflight.py#shared_hunks`, `scripts/orchestrator/test_plan_wave.py`, `docs/rearchitecture/DESIGN-orchestrator-loop.md`

## Measured

`plan_wave.py --cluster PB3726 --budget-points 3 --dry-run` on origin/main c397e1e27 raised
`FileNotFoundError: [WinError 206] The filename or extension is too long` from `inflight_units` (plan_wave.py line 1103,
`git("diff", "-U0", "--no-renames", "HEAD", "--", *lf, cwd=m["path"])`). At that moment worktree-wf_6e0a917c-500-26
held 3,331 changed paths: a finisher was in the middle of `merge_drivers.py merge origin/main`, so every file main had
changed showed as uncommitted and shared.

The committed arm a few lines above already guards the same limit: it passes its pathspec only while
`sum(len(f) + 1 for f in spec) <= PATHSPEC_CHARS`, and otherwise diffs the whole range. The uncommitted arm has no such
guard (PB3582's batching added the guard to one arm only). Every bug is a pattern (CLAUDE.md rule 4): sweep the other
`git(...)` calls in plan_wave.py, prune_worktrees.py and land_lane.py that splat a computed path list.

## Acceptance

- The uncommitted arm uses the same rule as the committed arm (one helper, not a second copy of the condition): over
  `PATHSPEC_CHARS` it diffs without a pathspec and keeps only the shared files' hunks.
- A test in `test_plan_wave.py` drives `inflight_units` with a worktree whose uncommitted shared set is over the limit and
  asserts the plan completes with the same hunks the pathspec form gives.
- The sweep's result (every other call site that splats a computed path list, guarded or shown bounded) is in the report.

## Landed

Re-probed on a 300-file uncommitted shared set (120-character names, over the 32,767-character Windows limit):
`inflight_units` died with `FileNotFoundError: [WinError 206]`. The planner's pieces had moved to `inflight.py` (PB3728), so
the site is `inflight.py#inflight_units`. The fix is ONE rule for both diff arms: `bounded_pathspec` (over `PATHSPEC_CHARS`,
no pathspec) and `shared_hunks` (keep the shared files' hunks of a pathspec-free diff; the committed arm also read every
file of the whole diff, not only the shared ones). Sweep of computed path lists on a git command line: `land_lane.py`
`conflict_brief` (`git log -- *files`, the conflicted files, one per brief line: bounded by what the finisher resolves, not
by a worktree's whole change set), `devlog.py` (`rm -- *removed`: the pending entries of one stamp), `adopt_main.py`,
`inventory_ratchet.py`, `ledger_state.py`, `run_gate_legs.py`, `merge_drivers.py` (constant lists or three paths).
