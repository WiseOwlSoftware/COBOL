# PB6063 - the 1989 anchor is wider than the doctrine it enforces

`citation_problems` refuses a read none of whose citations is of the rule's own edition (`year`), the edition its catalog citation
names, or `§1989:` (the module docstring, lines 35 and 58, and the function at 177-184). Before PB5842 the 1989 amendment anchored
only a rule whose catalog citation names it; now `anchors = {year, 1989}` anchors every rule. A 2002 read that cites only `§1989:`
passes although the 1989 amendment is not the 2002 text (CLAUDE.md memory rule: judge a rule by its own edition's text).

Fix: anchor 1989 only for a rule whose catalog citation names it, as before, and add the failing case to `scripts/spec/test_reads.py`
(a 2002 read citing only `§1989:` is refused). Find whether `lineage_reads.py` copies the anchor set.

**Sites:** `scripts/spec/code_reads.py#citation_problems`, `scripts/spec/test_reads.py`.
