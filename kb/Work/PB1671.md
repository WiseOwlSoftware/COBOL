# PB1671 — OPEN

Filed 2026-09-27 by the train-68b lander from the wave-68 X implementer report (`w68x-PB1355-report.md`, new
defect 3).

**Repro.** Any of the wave-68 X negatives, e.g. `tests/conformance/negative/pb1353-replace-operand-content.cob`:
the COBOLNET2572 diagnostic carries the right line and column 1, whatever the operand's column.

**Rule.** None of the standard's (diagnostic placement is a product-quality property, not a conformance rule) —
hence `process_only: true`.

**Code site.** `src/Cobol.Net.Frontend/Preprocessor/CopyProcessor.cs#Report` and `#ScreenOperandPair` (the
operand screen): `mapped.OriginAt(p)` returns the origin line only. The fix belongs in the source-line map (carry
the column through the mapping), not in each report call.

**What the fixer owes.** A column-carrying origin for a mapped offset; a unit test asserting the column of one COPY
and one REPLACE diagnostic.
