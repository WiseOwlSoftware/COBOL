# PB1754 — the comprehensive architecture review

## The request (owner, 2026-09-29)

"At some point in the future, I want a skill to run a full, 100%, end-to-end, architectural review of the entire
COBOL compiler codebase, grammar and C# lexer/parser/code generator. Everything. I want the review to use the latest
and greatest code review techniques, eliminate duplicate code, refactor god classes, refactor as necessary the file
system layout, filenames, and classes. Basically to follow all tried and true architectural designs. All C# code
should use the latest .NET and C# features, including those that may require to update to a later .NET / C#
compiler if necessary. Create the plan for all this and design/update appropriate skills in anticipation."

## What exists now

- **The plan:** `docs/rearchitecture/DESIGN-architecture-review.md`.
  - Phases R0 (baseline census and the behavior-neutrality oracle), R1 (the target architecture, adversarially
    reviewed), R2 (the review fleet: subsystem × dimension; findings become notes), R3 (behavior-neutral
    restructuring waves), R4 (analyzer-driven .NET/C# modernization) and R5 (close).
  - Its §4 is the neutrality contract every wave proves: emitted C#, diagnostics, tokens and parse trees, program
    output, and performance.
- **The skills:**
  - `.claude/skills/architecture-review` is the project overlay: subsystems, oracles, and COBOL-specific rules.
  - The public base is `brent-tools:architecture-audit` (a new whole-codebase review-and-restructure campaign).
  - The public `dotnet-engineering` skill gains "Modernizing an existing codebase".

## Owner decisions needed (ask one at a time, when the review is about to start)

1. **When.** The design's §2 preconditions are: the design has settled, P15 has deleted the legacy engine, the R0
   oracle exists, and there is a quiet fix lane.
2. **The SDK.** The latest STABLE .NET only (net11.0/C# 15 once .NET 11 is GA, expected November 2026), or a preview
   SDK if R4 runs before then. The design's §5.5 records the .NET 11 alternative the owner asked for (2026-09-29):
   C# 15 unions for closed hierarchies, and the JIT gains adopted only if measured against the R0 baseline.
3. **Names.** Whether project and assembly names may change. The NuGet package id `WiseOwl.COBOL` is public.
4. **Tests.** Whether the `tests/` layout is in R3's scope, or only production code.

Until the start, this note stays `owner` and nothing is dispatched.
