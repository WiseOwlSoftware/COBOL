Fix as the report proposes: ONE note, one generalized drift test. Name the written phrase in each message, as PB4121 did for SET
(the echo is the statement as written, from the statement's own written source, `WrittenSource.Of`), then generalize
`SetDiagnosticNamesReceiversDriftTests.ElidedEcho` into a rule over every binder's message opening so that no message OPENS with
`VERB ...` and the next elided message cannot arrive (CLAUDE.md rule 5: the shape that makes the next case automatic). Re-count
with `git grep -n` before starting; this sweep shares its root with nothing else.
