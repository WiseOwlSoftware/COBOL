# PB4160 — LANDED (wave 20261780 G)

## Landing — no diagnostic message opens with an elided statement, in any binder, pass or parse layer

**Re-count** (`git grep` for a string literal opening `WORD ...`): 96 source lines of message heads (the note said about forty): the note's nine binders plus
`AcceptDisplayBinder`, `ControlFlowBinder`, `InitializeBinder`, `OoBinder` (INVOKE USING), `PtrBinder` (ALLOCATE), `ProcedureFormatPass`,
`StatementValidation.CheckInitialize*`, `DataBinder.Switches` (CLASS / SYMBOLIC CHARACTERS IN), `DataBinder.Reports`, `DataBinder.ReportItemDescription`,
the parse layer's `CobolErrorStrategy.SearchFormatShapeMessage` and `ConditionalPhrases`, and the COBOL2894 warning of `SET ... TO ENTRY`.
**Fix.** Each message names the phrase it is about as the programmer wrote it, never a verb and an ellipsis: `CALL USING BY VALUE 3`
(the written operand from `DataBinder.WrittenText`, which also ends the doubled `BY CONTENT BY CONTENT NULL`), `OCCURS ASCENDING KEY IS 'K'`
(`OccursKey.Descending`), `COLLATING SEQUENCE OF IK IS 'X'` (the written keys), `SET 'PP' TO ENTRY` (`SetFormatSelection.Written`), `DIVIDE REMAINDER with 2 GIVING receivers`.
A mid-sentence ellipsis is the general format's own notation and is kept (`where`/`site`/`face` labels a registry splices after a dash).
**The next case is automatic.** `ElidedMessageOpening` (tests/_shared) is the one definition of the head, with two readers: its `Source`
pattern is the drift test `DiagnosticOpeningElisionDriftTests` over every `Error(` / `Report(` / `Refused(` / `Warning(` /
`InitializeErrorAction(` / `EditionDiagnostic(` call in `src/` (it replaced `SetDiagnosticNamesReceiversDriftTests.ElidedEcho`, which saw SET
heads only; that file keeps the receiver-naming half), and its `Rendered` pattern is asserted in `ConformanceSuiteTests` over the RENDERED text of
every negative golden, which sees a head that string-building assembled from a label.
**Goldens.** `14.9.4-CALL/pb4160-verb-phrase-diagnostics-name-the-phrase` and `13.18.38-OCCURS/pb4160-clause-diagnostics-name-the-phrase`
(two programs, twelve and five diagnostics, each checked for the elided opening).
**Not changed (named so a successor does not re-derive them).** The ELLIPSIS-labelled runtime messages of `CodeGen/Verbs/SetEmitter.cs`
and `ControlFlowEmitter.cs` (`LandAmount(..., "SET ... TO", ...)`, which a snapshot pins) and `FileRegistry.MisroutedVerb`
(`OPEN ... REVERSED`) are exceptions of the running program, not compile diagnostics, and are reported as a lead.
