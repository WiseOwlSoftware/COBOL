# PB4301 - For a misspelled clause keyword the closed-format residue arm names the first reserved word after it as "not a clause"; the misspelled word is named only by ClosedFormatPass, which a unit with any parse error never reaches

Found by the Mythos front-end review, gap pass, 2026-10-31 (GAP-REVIEW.md, G4-3; artifact https://claude.ai/artifact/KaxkLe85tfZBZ3nZ1tDGTs). Pin d7daee1cf.

**Sites:** `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs` (`Sync` :551-563, `IsClosedFormatResidueAhead` :591-608, `ClosedFormatResidue` :1022-1043, the 0g arm ~:815-860); `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolExpressions.g4:58-70` (`unrecognizedClause`, `unrecognizedDataClause`); `src/WiseOwl.Cobol.Compiler/Validation/ClosedFormatPass.cs:225` (`Refuse`); `src/WiseOwl.Cobol.Compiler/CompilerDriver.cs:154`.

**Finding.** For a misspelled clause keyword the closed-format residue arm names the first RESERVED word after it as "not a clause": `i3` `ASIGN TO` -> COBOL1970 at TO; `I27` `SINC LEFT` -> COBOL1941 at LEFT; `I26` `OCURS 3 TIMES` -> COBOL0001 at 3 plus a phantom level-03 COBOL1941 at TIMES; `i9/m7` `OCCURS 0 TO TIMES` names TO, a word OF the clause, where the fault is the missing integer-2 (section 13.18.38.2). The misspelled word is refused by name only by ClosedFormatPass at bind, which never runs when any parse error exists (`i29`: `SELECT F1 FOO.` beside `MOVE A B.` draws nothing for FOO; `I23` alone draws the by-name COBOL1970). cobc says "unexpected Identifier" at the word (class, not spelling).

**Fix direction.** Where the run the error production opened (unrecognizedClause/unrecognizedDataClause) is ended by a reserved word, report the run's OPENING word by name at parse time. Where the stray word is one the PRECEDING clause could have taken at the point it ended (the walk from the clause's end takes it: `OCCURS 0 TO` then TIMES), report that clause as incomplete with Expected() at the next token. Membership in TokensWithin is NOT that test (the first report's second branch was wrong): `SYNC LEFT RIGHT` (D1) and `PIC X ON` (D2) keep today's accurate "is not a clause" message. The integer-ended runs (`I25` `VALEU 5` -> COBOL0307; I26) need their own decision or a drift-test exclusion. Reconcile with the analysis note on shape-only refusals delegated to the bind (G4-4) so one word is never named twice.

**Citations checked** (`python scripts/spec/cite.py --check`): section 13.18.38.2 "integer-2 TIMES".
