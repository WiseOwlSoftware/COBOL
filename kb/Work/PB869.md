# PB869 — OPEN — nine tests parsing a table that could simply be read

Source: the `PB256` implementer report, item B (recorded there as an observation, "not urgent, and deliberately
not done here").

## The facts, on this tree

`src/Cobol.Net.Compiler/Binding/IntrinsicCatalog.cs` is `public static class IntrinsicCatalog` whose only public
member is `TryGet(string name, out IntrinsicSig sig)`; `Table` is private. The tests that need the WHOLE table
therefore read the source file:

```
tests/Cobol.Net.Tests.Unit/IntrinsicArgumentClassDriftTests.cs
tests/Cobol.Net.Tests.Unit/IntrinsicArgumentIntakeContractDriftTests.cs
tests/Cobol.Net.Tests.Unit/IntrinsicCarrierAgreementDriftTests.cs
tests/Cobol.Net.Tests.Unit/IntrinsicFloatLaneArgumentRunDriftTests.cs
tests/Cobol.Net.Tests.Unit/IntrinsicModeFlagCoverageDriftTests.cs
tests/Cobol.Net.Tests.Unit/IntrinsicRealArgDriftTests.cs
tests/Cobol.Net.Tests.Unit/IntrinsicRepeatedArgumentDriftTests.cs
tests/Cobol.Net.Tests.Unit/IntrinsicResultTypeDriftTests.cs
tests/Cobol.Net.Tests.Unit/StandardModeReturnedValueContainerDriftTests.cs
```

## Why it is a defect and not a style question

A regex over source text is a SECOND, hand-maintained model of the table, and each copy is wrong in its own way:
PB256's newest one was blind to the three fold rows with an empty `RuntimeMethod` until it was corrected. Every
such test can pass while the table it claims to check has changed shape — the
`feedback_green_gates_arent_evidence` failure, nine times over. It is also squarely in two of the owner's four
review dimensions (duplication, and code review).

## Shape of the fix

`public static IReadOnlyList<IntrinsicSig> All` (or an `IReadOnlyDictionary` view) on `IntrinsicCatalog`, and
every one of the nine tests reads it. Delete the regexes in the same change set — leaving one behind recreates
the second model. `process_only` is set because no user program misbehaves today.

## Sibling sweep the fixer owes

* Any other compiler table read as text by a test: grep the test assemblies for `ReadAllText` over a path under
  `src/` — each hit is the same defect with a different table.
* After the conversion, mutate one table row and confirm at least one of the nine FAILS; a converted test that
  still cannot fail was not fixed.
