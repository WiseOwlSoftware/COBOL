# PB5473 - COPY text-name with no OF or IN resolves silently in the default library when a named library holds the same text-name: §1985:XII.2.3 SR1 requires the qualification when more than one COBOL library is available

**Sites:**

- `src/WiseOwl.Cobol.Frontend/Preprocessor/CopyProcessor.cs` (`CopyProcessor.FindCopybook`, `CopyProcessor.LibraryPlaces`)

**Mechanism.** `CopyProcessor.FindCopybook` resolves an unqualified COPY against the default library (`LibraryPlaces`) even when a named library (a subdirectory of a library place, which OF/IN reaches) is available, and nothing at --std 85 counts the available libraries. The second sentence of SR1 holds (a text-name names one text in a library). Which libraries are "available during compilation" is the implementor's to state: the fix states it in docs/CONFORMANCE.md and applies SR1 to that set.

**Found by.** The 1985 code read, read 4 (`kb/Work/PB4996/2026-11-13-read-4.md`): the reader of `E:/COBOL-coord/scratch/coderead-85/out-read4/rd-03.json`.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. Its rows are recorded naming this note (records-rd4).

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`, log `E:/COBOL-coord/scratch/op-20261113/records-rd4/cites.txt`).**

- `1985-SR-XII.2.3-1` - `§1985:XII.2.3 SR1` (read: PARTIAL, harm: under-rejects): "If more than one COBOL library is available during compilation, text-name-1 must be qualified by library-name-1".

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-read4/work-rd-03/c1/c1.cob`, run in its directory, which holds `MSGTXT.cpy` (`DISPLAY "DEFAULT TEXT".`) and `LIBB/MSGTXT.cpy` (`DISPLAY "LIBB TEXT".`):

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. C1.
       PROCEDURE DIVISION.
       MAIN-PARA.
           COPY MSGTXT.
           COPY MSGTXT OF LIBB.
           COPY MSGTXT IN LIBB.
           STOP RUN.
```

`cobol.exe --std 85 --source-format fixed --run c1.cob`.

**Observed (the pinned compiler of `E:/COBOL-wt/coderead85-tree-d` (main 725550baca, the base of this branch), rerun 2026-11-13 from copies in `E:/COBOL-coord/scratch/op-20261113/records-rd4/rerun/`; the log is `E:/COBOL-coord/scratch/op-20261113/records-rd4/rerun-log.txt`).** Exit 0; prints `DEFAULT TEXT`, `LIBB TEXT`, `LIBB TEXT`; no diagnostic.

**Expected (from the 1985 text).** Refused at the unqualified `COPY MSGTXT`: two COBOL libraries (the default library and LIBB) are available, so text-name-1 must be qualified.

**Fix direction (root cause, CLAUDE.md rule 4).** Record which libraries a compilation has available (the default library and each named library a library place holds), document that set as the implementor's, and refuse an unqualified text-name at 85 when more than one is available.
