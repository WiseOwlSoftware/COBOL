# PB3272 — dead public RunMain entry points

Source: `E:\COBOL-coord\scratch\reports\w1093b-PB2099-report.md`, "New defects", second bullet ("carried from the reviewed branch").

**Claim.** `ProgramRegistry.RunMain` and `ProgramTable.RunMain` are dead public ABI (`src/Cobol.Net.Runtime/Control/ProgramRegistry.cs:140` per the report; the one-line forwarder is at about line 137 on main at 746f569da). The report says removing them is a runtime-major bump. Deleting them means changing every caller and deleting the old one in the same change (CLAUDE.md rule 4; no compatibility layer). The implementer first confirms nothing, including generated code and `ModuleStack.PushMain`'s own callers (PB2207), still calls them. PB2659 lists `ProgramTable.RunMain` as the thread entry for the main program, so "dead" needs measuring before removal.
