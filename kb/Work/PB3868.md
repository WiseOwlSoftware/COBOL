# PB3868 — the implementer's default model is Sonnet, in one home

## Decision (owner)

Run `cobol-implementer` on the cheaper model, on the condition that the change is cost-effective: a cheaper model that
fails costs more.

## The evidence

`docs/rearchitecture/evidence/fleet-optimization/2026-10-27-implementer-model-cost.md` measured 789 groups (1,060
implementer agents) over a month. From 2026-10-17, where landing is measurable, Sonnet groups cost **0.16 weekly points
per landed note against Opus's 0.27**, with reviews, fix rounds, finishers and retries charged in. They landed 95 %
against 94 % and reached DONE on the first pass 92 % against 82 %. In the one like-for-like area (`runtime/io`) Sonnet
cost 0.16 per note against 0.21. Sonnet is unmeasured on grammar, OO and CI/build work, so the routing that sends that work
to Opus stays.

## What was already true, and what was wrong

The planner already defaulted implementers to Sonnet (`model_rules.json` `routing.default`), so the loop's waves were
mixed. But the default was stated in four places that disagreed: `routing.default` (`sonnet`), `wave.implementer_model`
(`sonnet`, the wave's fallback and the ledger's cost estimate), the agent definition's `model: opus` (what the harness runs
when a call names no model, and so every hand dispatch's default), and `wf_rolling_wave.js`'s `implementer_model || 'opus'`.
MANDATORY-PRACTICES P1 and O4 still called the implementer an Opus role.

## The change

- `.claude/agents/cobol-implementer.md` `model: sonnet` is the ONE home. `coord.agent_model(role)` reads it (beside
  `agent_turn_cap`, PB3701's one home for the cap); `groups.choose_model` takes the default from it, and refuses a model
  outside `routing.allowed`.
- `model_rules.json` loses `routing.default` and `wave.implementer_model`; `routing.opus_when` is the only rule that
  moves a group to Opus.
- `plan_wave.py` writes no `implementer_model` arg; each group carries its routed `model`. `wf_rolling_wave.js` drops
  `IMPL_MODEL` and passes a group's own `model` when it has one, otherwise none, so the harness runs the definition's.
- The ledger's estimate (`ledger_plan.py`, `gen_ledger.py`) prices groups at `coord.agent_model("cobol-implementer")`.
- P1, O4, the workstream skill, `references/rolling-wave.md` and `DESIGN-orchestrator-loop.md` say so;
  `check_practices.py`'s turn-cap copy pattern follows O4's new wording.
- Drift test (`test_plan_wave.py`, PB3868 block): the default is Sonnet from the definition, an allowed model, stated nowhere
  else in `model_rules.json`, and a definition without `model` is refused, never defaulted.

## Re-measure

After a week of waves, re-run the evidence record's scripts. A Sonnet sample on an `opus_when` area comes only from an
explicit trial.
