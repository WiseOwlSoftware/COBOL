# PB4928 - a wrong clause in the national-data refusal text

**Sites:** `tests/version-matrix/constructs.json` (the `national-data-2002` row, which `src/WiseOwl.Cobol.Editions/ConstructRegistry.g.cs` is generated from), `conformance-suite/cases/13.18.14-COLUMN/pb541_report_national_item.cob` (header comment), `conformance-suite/wiseowl/diagnostics/pb541-report-national-at-85.json`

**Report.** The COBOL0900 national-data gate's text reads "ISO §2023:8.5.2 category national / §2023:13.18.40 / ..." (`ConstructRegistry.g.cs`, row
`national-data-2002`, generated; the clerk found it with `git grep "8.5.2 category national"` and the same words in the pb541 golden's header comment at
line 34). `python scripts/spec/cite.py --check "§2023:8.5.2" "national"` FAILs: 8.5.2 exists ("Class and category of data items and literals") but its own
text does not contain the word; `python scripts/spec/cite.py --check "§2023:8.5.2.10" "national"` is OK ("National category"). A refusal that
names a clause that does not state the rule misleads whoever follows it. Expected: the message and the goldens cite `§2023:8.5.2.10`, and every other
construct-row citation is `cite.py --check`ed by the fixer (the sweep: `git grep -n "8\.5\.2[^.0-9]"` in `tests/version-matrix/constructs.json`; a drift test
that runs `cite.py --check` over every citation the registry prints is the shape that makes the next case automatic, as the owner's rule 1 requires).
Regenerate `ConstructRegistry.g.cs` with the project's generator after the JSON edit; never hand-edit the generated file.

Source report and lead: `w20261905e-PB4889-report.md`, New defects 2.

## Landed (wave 20261915 A)

`national-data-2002` and `boolean-data-2002` cite §2023:8.5.2.10 (National category) and §2023:8.5.2.5 (Boolean category), each checked with `cite.py --check`;
`ConstructRegistry.g.cs` regenerated by `scripts/gen-constructs.ps1`; the pb541 and pb886 golden comments corrected. Sweep: `git grep -n -E "8[.]5[.]2,? category"` finds
no other parent-clause citation of a single category (the rest name the category concept of 8.5.2 itself). The general drift (a citation of a parent clause whose own
child names the construct) is a lead in the wave report, not built here.
