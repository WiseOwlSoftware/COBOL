# PB5778 - at --std 85 a CORRESPONDING operand is refused when a group ANCESTOR is USAGE IS INDEX, where the rule is about the operand's own entry

**What is wrong.** Legal source is refused at `--std 85`: a MOVE CORRESPONDING operand whose group ancestor is USAGE IS INDEX. The refuter of the adjudication of `1985-GR-VI.6.4.3-3` (`E:/COBOL-coord/scratch/my-20261115/open20-refute/refute.json`) overturned its CONFORMS; the Mythos lane checked the citations and ran its program. A level-number is something an entry has, not something it inherits, so "the description of D1 contains" speaks of D1's own entry. `§1985:VI.6.4.3 GR2` then keeps index data items out of the move by its own words: a pair corresponds only where "the resulting move is legal according to the move rules". Small in reach.

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/Validation/StatementValidation.cs#CheckCorrespondingGroupOperand` (the 85 arm, its `Level85Forbidden`, walks up the operand's ancestors where the rule is about the operand's own entry)

**1985 rows this note blocks.** `1985-GR-VI.6.4.3-3`, which is PARTIAL, not CONFORMS: the direct cases (a level 66 operand, an operand whose own entry says USAGE IS INDEX) are refused as the rule requires. `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094), so the row is named here.

**2023 rows whose stored verdict is wrong.** None named: the program is accepted at `--std 2023` and prints `78`.

**Rules (each citation checked again with `python scripts/spec/cite.py --check`, verdict OK).**
- `§1985:VI.6.4.3 GR3`: "The description of D1 and D2 must not contain level-number 66, 77, or 88 or the USAGE IS INDEX clause."
  `OK  §1985:VI.6.4.3 GR3  (║6.4.3 The CORRESPONDING Phrase║)  the text is in GR3`
- `§1985:VI.6.4.3 GR4` uses the same verb for subordinate items: "contains a REDEFINES, RENAMES, OCCURS, or USAGE IS INDEX clause is ignored"
  `OK  §1985:VI.6.4.3 GR4  (║6.4.3 The CORRESPONDING Phrase║)  the text is in GR4`
- `§1985:VI.5.14.4 GR1`: "If the USAGE clause is written at a group level, it applies to each elementary item in the group."
  `OK  §1985:VI.5.14.4 GR1  (5.14.4 General Rules)  the text is in GR1`
- `§1985:VI.6.4.3 GR2`: a pair corresponds only where "the resulting move is legal according to the move rules"
