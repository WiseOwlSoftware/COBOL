# PB5518 - the pack-time conformance statement (PB5431) is proven only by a hand-run oracle: no gate, self-test or CI step packs a project

**Sites:** `Directory.Build.props:37` (target `CobolPackConformanceStatement`, its `TfmSpecificPackageFile` and the `TargetsForTfmSpecificContentInPackage` hook; XML, no member check), `scripts/selftests/orchestrator/` (new: the pack self-test the fix adds)

**Mechanism.** The pack-time conformance statement (kb/Work PB5431) puts `docs/CONFORMANCE.md` into every packed project through the target `CobolPackConformanceStatement`, hooked by `TargetsForTfmSpecificContentInPackage` (line 37 on `origin/worktree-wf_2e8662c7-06c-15`; not on main at filing). Its only proof is an oracle run by hand. No gate, self-test or CI step packs a project, so an edit that drops the `TfmSpecificPackageFile`, renames the target or breaks the hook ships a package with no `docs/CONFORMANCE.md` and every gate stays green.

**Fix direction.** A self-test (tooling lane) that packs one small packable project, or reads the produced `.nupkg`, and requires `docs/CONFORMANCE.md` in it, with `Directory.Build.props` among its recorded inputs so an edit of the file reaches it.
