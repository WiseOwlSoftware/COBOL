# R14 — the (statement, location) pair is dropped at most last-exception-status writes; EcWrap has no SEARCH or GO TO arm

> R00 ledger-audit orphan (2026-08-08): F3 (with F4-probe corroboration) of `PHASE-B-15.32-15.44-findings.md`, probe-verified OPEN
> against the R10-landed tree (`5312996a`). The probe programs are reproducible from the finding text.

PROBE (2026-08-08): `>>TURN EC-RANGE-SEARCH-NO-MATCH CHECKING ON WITH LOCATION` + a no-match SEARCH, then
`DISPLAY FUNCTION EXCEPTION-STATEMENT` prints 63 SPACES where §15.32.3 r2 requires `SEARCH` + 57 spaces. A
second probe (`GO TO … DEPENDING ON T(I)` with the subscript out of range inside a Format-3 PERFORM) raised
NOTHING at all — the EcWrap QueryFor switch has no BoundSearch and no GO TO arm, so those statements never
receive a wrapper. The control (`MOVE T(I) TO X` in the same PERFORM shape) prints `CAUGHT=[MOVE …]`, so the
kind-mapped name machinery (R01–R10 wave's R04) works where a wrapper exists.

Ledger F3 enumerates the full site list: every `ExceptionState.Set(name, fatal)` 2-argument call drops the
(statement, location) pair — SEARCH's two range conditions, the nonfatal ambient gates (EC-DATA-CONVERSION,
EC-BOUND-OVERFLOW), CobolTiming, CobolDynString, CobolString.ThruMember, EmitPropagationPickup — and
`GOBACK/EXIT PROGRAM … RAISING` cannot even thread it (`BoundRaising` has no location fields, unlike its
sibling `BoundRaise`). FIX SHAPE (ledger, one-rule-one-place): make the pair AMBIENT per statement — the same
channel the `…Checking` flags already ride — set/cleared by the emitted statement wrapper, so
`ExceptionState.Set` picks it up unconditionally and no raise site can forget it; give SEARCH and GO TO their
QueryFor arms; bring the RAISING leg onto the channel; delete the positional stmt/loc parameters from the
7 sites that thread them today. Pair with a drift test that no Set call can fire under WITH LOCATION while
the ambient slot is unset. Also corrects COBOLNET_CONDITIONS_EXCEPTIONS_DESIGN.md's claim that the name is
recorded at the raise site.
