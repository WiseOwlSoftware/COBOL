PB4446 binds a refused or surplus object's operands by themselves so that their own faults are reported. `ConditionBinder.cs#BindPartialOperandsStandalone` still returns on a `PrimaryCondition` whose `comparisonExpression` has one child (`p.comparisonExpression() is { ChildCount: 1 }`), giving the reason "the inserted subject's relation". In a pair with no verdict to bind, that operand is still a reference the program wrote, and nothing else binds it. The reviewer reads the PB4446 symptom as still reproducing in this arm; no probe has confirmed that yet.

**Fix shape.** Write a probe first: a refused and a surplus object whose succeeding abbreviated operand names an undefined data item. If it reproduces, bind the bare operand standalone in this walk. Sweep for the same early return in SEARCH WHEN and PERFORM UNTIL; PB4446's implementer listed both as unprobed.

**Site:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ConditionBinder.cs#BindPartialOperandsStandalone`.

**Sites (landed):** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ConditionBinder.cs#BindPartialOperandsStandalone`, `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ConditionBinder.cs#BindBareOperandStandalone`; `docs/CONDITIONS_EXCEPTIONS_DESIGN.md` D5a.

## Landing

- Re-probe on the branch build: `EVALUATE TRUE WHEN > 1 AND UNDEFX` drew COBOL1634 alone, `... AND RELF (1)` COBOL1634 alone, and the surplus `EVALUATE N WHEN 1 ALSO > 1 AND UNDEFX` COBOL2106 alone, so the symptom reproduced in both arms. `IF`, `PERFORM UNTIL` and `SEARCH WHEN` bind through `BindCondition`, which has no such early return, and each drew its COBOL1639 (the siblings are clean).
- The early return is replaced by `BindBareOperandStandalone`. The bare operand is classified by the ONE `AnalyzeBareOperand` (a condition-name, a switch-status and a boolean are bound by the analysis, a class-name has no operand), and only a plain VALUE is bound again as the comparison operand the inserted subject's relation (ISO 8.8.4.12.4 GR1) would have read. Pinned by `EvaluateObjectOperandFaultTests` (11 refused-pair rows, 2 surplus rows) and two refusal goldens `pb4606-*`.
