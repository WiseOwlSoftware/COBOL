> keyed-test helpers (Tmp, TryDelete, Register, Rec, Position, Write, Rewrite, Read, Seed; cf. StoreCoherenceTests.cs:48-101,

**Mechanism.** One job (open, seed, position, read and write a keyed store from a test) has five private
implementations, so a change to the connector API or the store-mutex shape needs five edits, and the copies can drift.

**Fix shape (for the implementer).** One shared test fixture in the unit-test project (a keyed-store test harness
class) carrying the helpers and the store-mutex probe, and every copy deleted in the same change (CLAUDE.md rules 4 and
5, no forwarders). The first four copies are those the finding names; sweep `tests/` for further copies before cutting
the fixture.
