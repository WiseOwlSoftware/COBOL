# PB5277 - at --std 85 a REPLACE statement stays in effect into the NEXT separately compiled program of the source: one ReplaceStates covers the whole compilation group (the 2023 scope), where 1985 ends it at the end of the separately compiled program

**Sites:**

- `src/WiseOwl.Cobol.Frontend/Preprocessor/CopyProcessor.cs` (`ApplyReplaceStatements`, `ReplaceStates`)
- `src/WiseOwl.Cobol.Frontend/Preprocessor/ConditionalCompilationProcessor.cs` (`Manipulate`)

**Mechanism.** A REPLACE "is in effect from the point at which it is specified until the next occurrence of the statement or the end of the separately compiled program" (§1985:XII.3.4 GR3). `ConditionalCompilationProcessor.Manipulate` runs `CopyProcessor.ApplyReplaceStatements` once over the compilation group with one `ReplaceStates` that nothing resets at an end program header, so the 2023 scope (to the end of the compilation group, §2023:7.2.4.4 GR5) applies at 85 and a REPLACE of the first program rewrites the programs after it. A contained program is inside its separately compiled program and is rightly replaced.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the non-conforming verdicts wait in `E:/COBOL-coord/scratch/coderead-85/p2-for-register.json`.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-GR-XII.3.4-3` - `§1985:XII.3.4 GR3` (read: DIVERGES, harm: wrong-answer): "until the next occurrence of the statement or the end of the separately compiled program"

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-pipe/work-slice-48/g3d.cob`: program G3D (`01 MSG PIC X(8) VALUE "FIRSTPG"`, `REPLACE ==DISPLAY MSG== BY ==DISPLAY "REPLACED"==.`, `DISPLAY MSG. CALL "G3E".`), END PROGRAM G3D, then separately compiled G3E (`01 MSG PIC X(8) VALUE "SECONDPG"`, `DISPLAY MSG.`); and `g3a.cob` (`REPLACE ==VAL== BY =="REPLACED"==` in the first program, `01 VAL PIC X(8) VALUE "SECONDPG"` in the second). `cobol.exe --std 85 --source-format fixed --run <file>`.

**Observed (a build of origin/main f2cf36fd15, rerun 2026-11-11; main has since changed only `IndexedConnector.cs` under `src/`, which none of these repros reaches).** `g3d`: exit 0, `REPLACED`, `REPLACED`. `g3a`: exit 65, `error COBOL1941: '"REPLACED"' is not a clause of the data description entry`.

**Expected (from the 1985 text).** `g3d` prints REPLACED then SECONDPG; `g3a` compiles and prints REPLACED then SECONDPG.

**Fix direction (root cause, CLAUDE.md rule 4).** Make the end of a separately compiled program a REPLACE-scope boundary in the edition table the preprocessor reads (1985: the separately compiled program; 2023: the compilation group), and test both repros at 85 and 2023.
