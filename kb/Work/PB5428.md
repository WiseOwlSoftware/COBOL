## The step

Write `selftest_cases.py` (`run`, `subject`, `Expect`) and `selftest_layout.py` (`subject_of`, the refusals section 16.2 lists, the `REMAINING` set of every file that still holds a self-test outside `selftests/`, one path per line in sorted order, the `scripts/docchecks/*.py` delegates included), and make `self_tests.py` call the layout rule before it runs anything, start every file under a `<root>/selftests/` tree with `PYTHONPATH` = `<repo>/scripts` prepended (one place), and run named files with `--only <path> ...`. Teach the static readers the two edges (`import selftest_cases` resolves against `scripts/`; `selftest_cases.subject(__file__)` is an import of `subject_of(rel)`) in `inert_lane._imports` and `script_layering.py`, and make `scratch_repo._self_test_scopes` read every file under a `selftests/` tree as whole self-test scope. Planted cases for the three readings go where each reading's subject keeps its tests today (`scratch_repo.py`'s and `inert_lane.py`'s in-file self-tests: a `fixtures.py` that runs `git init` directly is refused; a case file's closure holds its subject's imports) and in `selftest_cases`' case files (a case file run bare fails at its import). Then convert `test_plan_wave.py` into `scripts/selftests/orchestrator/plan_wave/`, its imports re-pointed through `subject`.
