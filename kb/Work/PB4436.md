# PB4436 - a lost true COBOL0306 after the R2-1 recovery fix

**Defect.** Introduced by the R2-1 fix (commit 70b66101b) on the branch now queued as PR #1021 (not on main until that lands):
when an empty IF nested after a statement in another IF faults at its own END-IF and the enclosing IF's END-IF follows it
immediately, the true stray END-IF later in the sentence draws no COBOL0306. origin/main and round-2 head df87a3682 both
report it, so this is a regression versus main (the R2-2 class: a lost true COBOL0306). `under_rejects` is set
conservatively from the wording "lost true COBOL0306"; the report does not use that term.

**Witness.** `E:/COBOL-coord/scratch/reports/w20261823a-PB4299-report.md`, R3-1 (medium, not blocking at round 3);
`src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs:518`. No repro path in the report.

**Fix direction.** The report states none; fix it with PR #1021's recovery bookkeeping (`NoteLeftBefore`, `EnclosingStatement`).

**Sites:** `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs#NoteLeftBefore`

## Resolution

**Root cause (re-probed on the wave 20261825 build, `IF W-N = 1 DISPLAY "A" IF W-K = 2 END-IF END-IF DISPLAY "X" END-IF.`
drew COBOL2072 only).** Not the bookkeeping: `Recover` consumed the empty inner IF's own END-IF and then
`Resynchronize` went on, taking the ENCLOSING IF's END-IF (directly after it, not in the sentence's recovery set) with
it, so the outer record outlived its terminator and took the true stray END-IF as its own. The same root as PB4438.
**Fix.** A terminator consumed as a statement's own ends the recovery (`Recover` returns after `ReportMatch` + `Consume`),
so the enclosing IF's END-IF is parsed and consumed as its own and the third END-IF draws COBOL0306.

**Branch review R1-1 (fixed).** Ending the error condition un-masked the failure at the next phrase word of an enclosing
statement the prediction had closed early (`IF A DISPLAY "Q" IF B END-IF ELSE DISPLAY "Z" END-IF.` drew a false COBOL0001
at the ELSE; a WHEN or WHEN OTHER in an EVALUATE or SEARCH, a COBOL0001 or COBOL2073). `Report` now suppresses a word a
still-due left statement's rule lets follow an imperative block (`ContinuesAStatementTheRecoveryLeft`, `PhraseWords`).
