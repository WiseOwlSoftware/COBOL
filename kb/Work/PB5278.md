# PB5278 - at --std 85 RECEIVE INTO and SEND FROM a numeric, numeric edited or alphabetic data item are refused COBOL6171: CommunicationBinder applies the 2002 class rules (A.2.5.2 SR2, A.2.6.2 SR2) at every edition, where 1985 restricts identifier-1 only when it is a function-identifier

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CommunicationBinder.cs` (`BindReceive`, `BindSend`, `IsCommunicationAlphanumericArea`)
