# PB5005 - the SEARCH ALL counter-register naming has no test

**Found.** On main `SearchAllFormat2Rules.CheckConditionNameSide` carries the comment "a counter register's cobolWord()
is its QUALIFIER, so `WHEN LINAGE-COUNTER OF F` would name F" and reads `ReferenceResolver.WrittenWordOf(dref)`;
`CheckKeySide` is swept the same way. No golden under `conformance-suite/cases/14.9.37-SEARCH/` and no test in
`SearchAllFormat2RuleCoverageDriftTests` or elsewhere writes a counter register in a WHEN phrase, so reverting either
site back to `cobolWord()` fails nothing.

**Owed.** A test pair for each side: `WHEN LINAGE-COUNTER OF F` (no relational operator, Format 2's condition-name arm)
whose refusal names LINAGE-COUNTER, and a counter register as a KEY-phrase operand whose refusal names the register, not
F. Expected wording from the clause the refusal cites (check every citation with `cite.py --check`). A mutation of either
site to `cobolWord()` must turn a test red.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Validation/SearchAllFormat2Rules.cs` (`SearchAllFormat2Rules.CheckKeySide`), `tests/WiseOwl.Cobol.Tests.Unit/SearchAllFormat2RuleCoverageDriftTests.cs` (whole: the witness joins the SEARCH ALL rule coverage)
