main, and correcting them is most of its value** — the mechanism the dispatch described (a generated file with no
banner and no drift test) does not exist here. What is real is smaller, later in the pipeline, and still open.


## The actual defect

Two sentences in the register of instructions, and one absence:

1. **The lander briefs frame a RENDERED file as a second place to write.** *"is in `DiagnosticCatalog` AND
   `docs/DIAGNOSTICS.md`"* is a true statement of the END STATE and a false statement of the METHOD: the doc is
   `AND`-ed with the catalogue as if a writer had to put the row in both. A verifier reading that clause and
   finding a row missing does the obvious thing — adds the row.
2. **`implementer-brief.md` never mentions the doc.**
   `grep -n -i "diagnostic" .claude/skills/workstream/templates/implementer-brief.md` returns **nothing**. The
   agent that writes the descriptor is told nothing about the file its descriptor renders into, so it learns
   about `docs/DIAGNOSTICS.md` only when a red arrives — or when it opens the file and edits it.
3. **The one brief that gets it right is the one that says nothing about diagnostics at all:**
   `implementer-brief.md:18` routes its gate through `pwsh scripts/build-local.ps1`, which builds the solution.
   Nothing anywhere says `pwsh scripts/gen-diagnostics-doc.ps1`.

## Fix shape — three sentences, no code

⛔ **Do not add a banner, a generator change or a drift test — all three exist and are correct.** Change the
briefs:

- `implementer-brief.md`: one clause where the descriptor work is described — *"register the code in
  `DiagnosticCatalog`, then run `pwsh scripts/gen-diagnostics-doc.ps1`; NEVER edit `docs/DIAGNOSTICS.md`, it is
  rendered from the catalogue."*
- `lander-brief.md:10` / `lander-train-brief.md:10`: replace *"is in `DiagnosticCatalog` AND
  `docs/DIAGNOSTICS.md`"* with *"is in `DiagnosticCatalog`, and `docs/DIAGNOSTICS.md` was REGENERATED (not
  edited) — `git diff` on it shows only rows the catalogue change explains."* The verification the lander
  actually needs is that the doc is a clean render, which is what the drift test already answers.

The mechanical half is already free: `DiagnosticsDoc_IsInSync_WithTheCatalogue` runs in the full Unit assembly,
which `lander-train-brief.md:11` mandates unfiltered for every train.
