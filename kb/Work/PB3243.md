# PB3243 — a fixed file name in the machine-wide temp dir, C# arm

Filed 2026-10-16 by the enqueue unit's clerk. Source: `E:\COBOL-coord\scratch\reports\w1089a-PB2922-report.md`, "New defects".

**Where.** `tests/_shared/ProcessObservation.cs:80`: `LogPath` is `COBOLNET_HARNESS_LOG` or
`Path.Combine(Path.GetTempPath(), "cobolnet-harness-observations.log")`. Every test process of every gate on the host, in
every worktree and session, appends to the same file; the log that "supplies a distribution" (its own comment, A12/A12d)
mixes the runs it should separate.

**Mechanism.** The one PB2922 fixed for the Python and PowerShell tools (a fixed name in the machine-wide temp dir;
`scripts/temp_names.py` is the one source of the per-run names). PB2922's body does not record this site; `temp_names.py`
covers scripts, not C#, so it is its own note, clustered with PB2922.

**Harm.** Process only: interleaved observations from concurrent gates; no user program affected. PB1957 row 25 lists the
site among the `GetTempPath` users.

**Fix shape (rule 4).** One per-run name or a directory under the run's own coordination directory, chosen by the same
rule `temp_names.py` encodes (not a second copy of it); a drift test that no `tests/` or `src/` file builds a fixed file
name from `Path.GetTempPath()` (sweep also `tests/_shared/HostCapability.cs:37`).

**Update 2026-10-22 (PB3108, wave 1155 group A, landing in flight).** PB3108 makes every gate leg (`run_gate_legs.py`
`leg_env`, `linux-gate.sh` `test_leg`) and every CI test step write `COBOLNET_HARNESS_LOG` to a per-run file, which removes
most of the harm stated above for gate and CI runs: their observations no longer mix across concurrent gates.
**Remaining harm:** the fallback is unchanged, so any test process started outside those legs (a developer or agent
`dotnet test`, a single-test run) still appends to the fixed `cobolnet-harness-observations.log` in the machine-wide temp
dir, and `tests/_shared/HostCapability.cs:37` is unswept. The fix shape above (one per-run name or a coordination
directory, plus the drift test that no `tests/` or `src/` file builds a fixed name from `Path.GetTempPath()`) therefore
still stands for those sites, and the note stays open. Cross-reference: PB3553 (the review lead that noticed PB3108 neither
names nor updates this note).
