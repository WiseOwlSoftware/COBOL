# PB4423 — a method's INDEX-NAME cells are named by text on the bound tree

**Found:** by the PB4416 implementer ("New defects", no note created). No open note owns the L4 row: a grep of `kb/Work` for `L4`, `IndexField`, `index cell` and `IndexDeclaration` finds only landed notes (PB1132, PB2151, PB459 and older) and the design doc's own row. PB4416 (landed) converted a method's data roots to `MethodLocal` identities; the index cells are the same root shape and were left.

**Sites:**
- `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/OoEmitter.cs#EmitMethod`: declares `long {idx.Cell} = 1;` for every LOCAL/LINKAGE table index (per activation).
- `src/WiseOwl.Cobol.Compiler/Binding/Model/Position.cs#IndexDeclaration` (`Cell`) and `#PositionIndexCell` (`Cell`): the local's C# name as a string.
- `src/WiseOwl.Cobol.Compiler/Binding/Bound/BoundTree.cs#BoundIndexRef` (`IndexField`), `#SetIndexTarget` (`IndexField`), `#BoundSearch` (`IndexField`).
- `docs/rearchitecture/DESIGN-backend-abstraction.md` 1.3 L4 (OPEN) lists exactly these members; they are tolerated leak rows of the section 6 contract test.

**Repro.** Any method with `05 E OCCURS 3 INDEXED BY IX` in LOCAL-STORAGE: the index cell is a method local, and every use reaches it by its name text.

**Fix direction.** L4's own fix: carry the index symbol (the index `DataItem`, SSOT 3.5) and read the CLR name off it; the method arm becomes a `MethodLocal` identity, as PB4416 did for the data roots. It spans the bound tree's three index nodes and Position, which is why it did not fit the PB4416 slice. Update L4 and delete the tolerated-leak rows in the same change.
