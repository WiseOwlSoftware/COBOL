# PB2840 — LANDED — an INVOKE literal compares by the 2023 comparer at every edition

Found by the w1047a implementer (PB1965, report lead 2) and Filed by the train 1047 lander, 2026-10-08 20:53 PDT.

## Repro
`E:\COBOL-coord\scratch\w1047a\p\d.cob --std 2014`: `INVOKE O "X<final sigma>"` against `METHOD-ID. X<sigma>.`
is refused COBOL0825 (method not found), though below 2023 the Annex C fold makes final sigma and sigma one name
(PB1965's batch, row GR-8.1.3.2-4: below 2023 two METHOD-IDs of those names are one name, COBOL0822).

## Mechanism
The literal method-name compares through the 2023 comparer; `CobolNames.EditionSpelling` reaches only lexed words, so
an alphanumeric literal naming a method is never edition-spelled. The literal's content should be folded by the same
edition rule as the word it names.

## Code sites
The INVOKE method-selector resolution (`src/Cobol.Net.Compiler/Oo/` INVOKE binding, the COBOL0825 site) and
`src/Cobol.Net.Runtime/CobolNames.cs#EditionSpelling`.

## Landed (wave 1056 G)

Re-probed first on the wave's own build: `E:\COBOL-coord\scratch\w1047a\p\d.cob --std 2014` gave COBOL0825 for
`INVOKE O "X<final sigma>"`, and `CALL "Z<final sigma>"` against `PROGRAM-ID. Z<sigma>` at 2014 stopped with
EC-PROGRAM-NOT-FOUND (a sibling arm of the same mechanism, found by the sweep).

**Mechanism.** A literal that NAMES a word is source text, so it is written in the edition's Annex C spelling
(`CobolNames.EditionSpelling`) exactly as the lexer writes the word. One producer per kind of literal:
`OoBinder.OoMethodNameOf` (the INVOKE statement and every inline-invocation segment),
`ExternalizedNames.FormWritten` (new: `Form` then `EditionSpelling`) for the CALL / CANCEL / `ADDRESS OF` literal
(`CallBinder.ProgramNameLiteral`) and for the AS literal (`ExternalizedName.Form`, and the repository scope's pure
read, `ExternalizedName.Peek(lit, dialectLevel)`, through `OoClassTable` which now carries the edition's year). A name
in a data item stays run-time data and maps by the 2023 table (DOC-A.1-68 says so).

**Witnesses.** `conformance:2002/pb2840_literal_names_edition_spelled` (INVOKE, CALL and AS arms),
`conformance:2023/pb2840_literal_names_two_words_at_2023` (the same names are two names at 2023),
`conformance:negative/pb2840-invoke-literal-final-sigma-is-another-word-at-2023` (reject-at 2023, COBOL0825).
