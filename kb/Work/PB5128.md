# PB5128 - at --std 85 the page footing and page heading USE procedures reached from a control footing's page advance see the prior control values; 1985 gives only the control footing the prior values and every other reference the current ones

**Sites:** none (not located: the record names no site; the implementer locates where the report writer holds the prior control values during the control-footing phase of GENERATE, in the runtime ReportWriter)

**Mechanism.** On a control break the 1985 text gives the control footing USE procedures and SOURCE clauses the control values used to detect the break (§1985:XIII.4.3.4 GR6 a 1), and says every other reference within report groups and their USE procedures accesses the current values (§1985:XIII.3.20.4 GR13 c). When CF-MAJ does not fit, the page advance processes the page footing and page heading; their USE procedures must see the current values. The compiler follows §2023:13.18.16.4 GR4 a, which gives them the prior values; the prior values stay in the control data items for the whole control-footing phase, so a page group USE procedure reached from inside it reads them. kb/Work PB1187 and PB1235 are the 2023 TERMINATE order, a different rule; PB5127 is the sibling ordering defect in the same footing processing. Every other line of the draft matches.

**Found by.** The 1985 witness-drafting pass (kb/Work PB4995 item 3): each rule below is a witness program drafted from the 1985 text alone, run at `--std 85`, and its result differs from what the text requires (outcome MISMATCH). Harm and observed text are the record's; nothing here was re-derived.

**Inventory.** The traceability inventory carries no 1985 rows yet (PB5094: work.py refuses 1985 ids), so `inventory_rows` is empty; the row this note covers is the 1985 rule id listed below (catalog `docs/rearchitecture/spec-rule-catalog-1985.json`).

**Rules (1; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-GR-XIII.4.3.4-6` - `§1985:XIII.4.3.4 GR6` (record harm: wrong-answer, slice-08): Checked quotations: `§1985:XIII.4.3.4 GR6` "Process the control footing report groups in the order minor to major." and `§1985:XIII.3.20.4 GR13` "All other data item references within report groups and their USE procedures access the current values that are contained within the data items at the time the report group is processed". Page advance after a control footing that does not fit: §1985:XIII.3.20.4 GR12; fit test §1985:XIII.3.10.8.
