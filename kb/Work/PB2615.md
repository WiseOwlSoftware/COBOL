# PB2615 — `--help` crashes on a cp1252 console

RETIRED: a duplicate of PB1546, which now owns this mechanism and this note's evidence; kept only so references resolve.

Filed by the train 1039b lander from the wave-1039 group X implementer report (`w1039x-PB2611-report.md`, unfiled
minor lead), re-run on train 1039b's tree.

**Repro.** `PYTHONIOENCODING=cp1252 python scripts/filter_population.py --help` exits 1:
`UnicodeEncodeError: 'charmap' codec can't encode character '⛔'` (a Windows console whose code page is 1252
behaves the same). PB2611 fixed `scripts/spec/record_impact_map.py` alone (`stream.reconfigure(encoding="utf-8")`,
`record_impact_map.py:228`).

**Sweep start.** A scan for scripts that pass a non-ASCII docstring to argparse and never reconfigure stdout found
`scripts/collation/generate-collation-table.py`, `scripts/collation/pack-cldr-collation.py`,
`scripts/orchestrator/train_measure.py` (since replaced by `landing_measure.py`, which reconfigures both streams before it parses), `scripts/unicode/generate-grapheme-table.py`; `filter_population.py` builds
its help another way, so the scan under-counts: the sweep must run every script's `--help` under cp1252.

**Fix shape.** One shared helper (beside `scripts/hooks/sharedfile.py` or in a small `scripts/console.py`) that
reconfigures stdout and stderr to UTF-8, called first by every script entry point, and a self-test that runs
`--help` of every discovered script under `PYTHONIOENCODING=cp1252` (one rule, so the next script is covered
automatically).

**Re-measured 2026-10-11 (PB3028's review finisher, wave 1064 C2).** `gen_ledger.py` and `ledger_plan.py` failed
`--help` the same way (their `reconfigure` ran after `parse_args`); both now set stdout and stderr to UTF-8 before the
parser exists. A sweep (every `scripts/**.py` with argparse, `--help` with stdout to a pipe) still finds 31 that fail,
among them `filter_population.py`, `gate_plan.py`, `work.py`, `impacted_tests.py` and nine `scripts/spec/audit_*.py`
and repair scripts: the fix stays this note's, one helper and a drift test rather than 31 hand edits.
