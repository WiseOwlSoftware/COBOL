# PB4006 — a cumulative fuzz history and its page, updated every night

**Owner, 2026-10-28:** "Publish a cummulative summary as an artifact. It should briefly describe how the fuzz testing and
analysis works, then produce a cummulatively summary with tables and/or graphs, as best illustrates the data. It should make
clear that the artifact is machine-generated and maintained automatically as an artifact of each fuzz testing run. So we
should add that updating to the process." Then: "Write the artifact from the PoV of someone totally unfamilar with my COBOL
project."

**The gap.** Seven nights ran (2026-10-20 to 10-27). Each night's numbers were in its run directory (git-ignored) and its
evidence record's prose; its verdict files were session scratch. No reader could see the trend (compiler bugs per night 2, 4,
9, 3, 3, 0, 2) or the cumulative GnuCOBOL record.

The owner then added (same session): "We should publish this artifact in the COBOL repo root, so I can easily link to it and
track readers, if wanted", and chose Markdown with SVG charts, since GitHub shows a committed `.html` file as source.

**The fix (design `docs/rearchitecture/DESIGN-differential-fuzz.md` §6).**
- `conformance-suite/fuzz-history.json` — one tracked record per night, and the page's `artifact` URL.
  Backfilled for nights 1 to 7 (verdict tallies for nights 3 to 7 from the surviving verdict files); every night's notes by the
  one rule `defects_of`.
- `scripts/fuzz_history.py` — `render` draws the HTML page and, with `--markdown`, `FUZZ-LEDGER.md` at the repository root and
  `docs/fuzz-ledger/*.svg`, both from one text, the history and the register (live statuses and kinds); `show` lists it.
- `scripts/fuzz_triage.py history --triage <dir> --judge-commit <sha> --write` — the morning's last step: records the night,
  writes the HTML page, the ledger and its charts; the session publishes the page to the `artifact` URL.
- `scripts/test_fuzz_history.py` — the self-test.
- The page: https://claude.ai/artifact/UBCptoMp1GohHrvpUFRS7g, and the repository's `FUZZ-LEDGER.md`, written for a reader new
  to the project, stating that they are machine-generated.
