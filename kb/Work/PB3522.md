# PB3522 — the usage-clause host drift test misses one-line grammar rules

## Lead

`tests/Cobol.Net.Tests.Unit/UsageClausePhraseDriftTests.cs:263` `RulesReferencing` only recognises a grammar rule whose
name stands alone on its line, but the grammar also writes one-line rules (`CobolExpressions.g4:378-392`, `733` and
`750-752`). A future one-line host of `usageClause` is therefore never found, and `EveryGrammarHostOfTheUsageClause`
stays green.

The exact inventory is the generated parser's context types that expose `usageClause()`: derive the host list from
those, not from a text scan of the grammar files. The line numbers are the reviewer's, taken on the PB3517 branch
(`worktree-wf_f768a41c-d72-4`); re-find the sites by name.
