# PB5423 - a RESET ON data-name (and a TYPE CF operand) is refused when the CONTROL clause names the same control item qualified (CONTROLS ARE FINAL WS-A OF G1 ... RESET ON WS-A): ControlLevelOf matches the written reference, not the item it names

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/ReportSectionBinder.cs#ControlLevelOf`
- `src/WiseOwl.Cobol.Compiler/Binding/ReportModel.cs#ReportControlRef.SameOperandAs`

**Mechanism.** `ReportSectionBinder.ControlLevelOf` finds the RESET data-name's control level by `ReportControlRef.SameOperandAs`, which compares the reference as written. A CONTROL clause may qualify its data-names, so `WS-A OF G1` and `WS-A` name one item, yet RESET ON WS-A is refused COBOL0899 as "not an operand of the CONTROL clause". The TYPE CF operand check makes the same comparison (`c8g` below).
