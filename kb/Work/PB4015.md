# PB4015 — COBOL0899's catalog description says a boolean cannot cross a CALL

**Sites:** `src/WiseOwl.Cobol.Editions/Diagnostics/DiagnosticCatalog.cs#CallContentOperandFormat`, `docs/DIAGNOSTICS.md` (rendered from the catalog)

**Failure scenario.** The description PB3996 rewrote keeps "A boolean expression is additionally not yet carried across a CALL
boundary -- the INVOKE side has BoundInvokeArg.ContentBool and the CALL argument model has no counterpart." But
`BoundCallArg.ContentBool` exists (`BoundCall.cs`, PB238) and `CallBinder.BooleanContentArg` / `CallEmitter.cs` carry it. A user
reading the rendered COBOL0899 text for `CALL "P" USING BY CONTENT B1 B-AND B2` is told a boolean cannot cross a CALL; with an
AS phrase it compiles and runs through `ContentBool`.

**Fix.** Delete the stale sentence in `CallContentOperandFormat`'s description and regenerate `docs/DIAGNOSTICS.md`; confirm the
rest of the description against the code (and the entry's `RecognizedNotImplemented` status, which the sentence may have been the
only reason for).

**Acceptance.** The description names no capability the code has; the diagnostics-doc drift test is green.
