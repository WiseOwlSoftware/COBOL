# PB5949 - syntax colouring of the source in the HTML listing

**Sites:** `src/WiseOwl.Cobol.Listing/ListingDocument.cs` (`ListingLine`), `src/WiseOwl.Cobol.Listing/Html/HtmlListingRenderer.cs` (`HtmlListingRenderer.Style`, `HtmlListingRenderer.Sections.Source`), `src/WiseOwl.Cobol.Listing/Json/JsonListingWriter.cs` (whole: the line's spans join every line record it writes)

**Asked** by the owner (2026-11-19 19:05): "it would be great for the HTML version to syntax color the COBOL source code."

**Decided (the codebase owner's call, CLAUDE.md "Ownership"): the colours come from the compiler's tokens, not a published grammar.**
Pattern grammars for COBOL exist (the TextMate grammar VS Code's COBOL extensions use; highlight.js's and Prism's `cobol`), but:
- the page is one self-contained file with no external resource (DESIGN-listing.md section 7.2), so it cannot load one;
- they guess with patterns where the compiler knows: the fixed-format areas (sequence, indicator, A and B, the identification
  area), the reserved words OF THE EDITION IN FORCE (a 1985 program's user word may be a 2002 reserved word), context-sensitive
  words, PICTURE character-strings, continued literals, comment entries and directives;
- section 7.2's rule: the renderer joins nothing and computes nothing.

**Shape:** each `ListingLine` carries the classified spans of its text (start, length, class), made once by the listing builder from
the token stream and the reference format the compile used: sequence area, indicator, identification area, comment, comment-entry,
directive, reserved word, context word, user-defined word, alphanumeric literal, numeric literal, figurative constant, PICTURE
character-string, separator/period. The HTML renderer wraps each span in a class whose colour the style names (light and dark); the
text listing ignores the spans; the JSON listing carries them (a schema minor). A drift test pins that every token class the lexer
produces maps to a span class, so a new token kind is coloured by construction. Section 7.2 and section 11 gain it.
