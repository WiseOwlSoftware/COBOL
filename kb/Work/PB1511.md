# PB1511 — OPEN

## The rule (every citation re-run through `cite.py --check`)

> 1. If native arithmetic is in effect, the rounding rules that apply to intermediate data items are defined by the implementor.

`OK  §11.9.11.2   (General rules)`


## Finding — `intermediate-rounding-clause` (silent; rows `GR-11.9.11.2-1`)

**Mechanism.** The native-arithmetic intermediate rounding determination (CONFORMANCE.md DOC-A.1-123) omits the rules the implementation actually applies: the nested quotient's 14-guard-digit TRUNCATION, the binary64 lane's rounding, and the INTERMEDIATE ROUNDING mode reaching the native Dec lane (stated only in DOC-A.1-82)

**Repro.** Default NATIVE arithmetic: COMPUTE R = (A / B) * C with the quotient nested - NumericRenderer computes A / B at receiver scale + 14 guard digits with TRUNCATION; DOC-A.1-123 says the nested quotient 'rounds once, at the final transfer'. Separately, OPTIONS INTERMEDIATE ROUNDING IS TRUNCATION changes COMPUTE R = A * B + 0.0E+0 (native, Dec lane) but not A * B + 0.0 - documented only in DOC-A.1-82.

**Expected from the spec.** 11.9.11.2 rule 1: under native arithmetic the rounding rules for intermediate data items are defined by the implementor; 8.8.1.3: the implementor shall specify techniques used for native arithmetic. The determination should state each native intermediate rounding rule in one place.

**Observed / reasoning.** Code reading (NumericRenderer.CombineCore, DivGuardDigits/nested-division arm, IntermediateMode) versus the DOC-A.1-123 text. Behavior is deterministic and implementor-chosen; only the statement is incomplete.

**Code site.** docs/CONFORMANCE.md DOC-A.1-123; src/Cobol.Net.Compiler/CodeGen/Emit/NumericRenderer.cs#CombineCore / nested-division guard arm (~615-651)

## What the fixer owes

Rewrite DOC-A.1-123 to state every native intermediate-rounding rule the code applies (NumericRenderer.CombineCore's nested-division guard digits and TRUNCATION, the binary64 lane, the Dec lane under INTERMEDIATE ROUNDING) — or change the code to match the published text — and cross-reference DOC-A.1-82 instead of splitting the rule. Pin each stated rule with a golden (the nested-quotient case from the repro).
