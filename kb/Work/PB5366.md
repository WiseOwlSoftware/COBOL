# PB5366 - HostRegionLocks.McsRunUnitLivenessByte is a pure forwarder to TransactionLivenessByte, a second name for one function (CLAUDE.md rule 4)

**Sites:**

- `src/WiseOwl.Cobol.Runtime/IO/Sharing/HostRegionLocks.cs:228` (`HostRegionLocks.McsRunUnitLivenessByte`)
- every caller of `McsRunUnitLivenessByte` (find with `grep -rn McsRunUnitLivenessByte src tests`), including `src/WiseOwl.Cobol.Runtime/Communication/McsStore.cs` (`McsStore.DrawRunUnit`, `McsStore.OwnerIsAlive`)

**Mechanism.** The member only calls `TransactionLivenessByte`. CLAUDE.md rule 4 bans wrappers, forwarders and aliases anywhere: change every caller to the one name and delete the forwarder in the same change. If the MCS run unit and a transaction are genuinely different notions that happen to share a liveness byte today, the answer is one neutral name for the shared concept, not two names.
