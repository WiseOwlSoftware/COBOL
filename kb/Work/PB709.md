# PB709 — OPEN — §4.2.6 written where §4.2.7 governs

Found 2026-09-05 by the `PB693` finisher (report, "Things that did not hold" 1) while re-deriving the citations of
the VALIDATE-STATUS declined-facility red it was attributing.

## The facts

- §4.2.6 (`cite.py --check 4.2.6 "Language elements that depend on"` → OK) is **processor-dependent** language
  elements — Annex A.3 — and requires a compile-time warning mechanism for unsupported syntactically-detectable ones.
- §4.2.7 (`cite.py --check 4.2.7 "Language elements that an implementor may, but need not, implement are listed in
  A.4"` → OK) is **optional** language elements — Annex A.4 — which an implementor "may, but need not, implement" and
  shall identify in user documentation.
- VALIDATE (the facility the finisher was reading) is Annex A.4 item 14 — optional — yet the posture comment in
  `CobolDeclined.g4` and the A.4 arms of `VersionConformancePass.cs` and `DeclinedFacilityPass.cs` justify the
  decline by §4.2.6. `DiagnosticCatalog.cs`'s own descriptor prose states the A.3/A.4 split correctly, so the rule is
  written in two places that disagree. The finisher corrected the text it wrote and left the pre-existing sites alone
  (out of its scope); `grep -rn "4\.2\.6" src/Cobol.Net.Compiler` lists every candidate — separate the A.3 uses
  (correct) from the A.4 uses (wrong).

## Why it matters

No user program gets a wrong answer. This is the `a_real_clause_can_answer_a_different_question` shape: the quoted
text is genuinely in the standard and the clause exists, so `audit_code_citations.py --check` passes, and the wrong
clause propagates into the next comment, golden and DEVLOG paragraph that inherits it. A decline justified by the
processor-dependent clause reads as "we could not", a decline under the optional clause reads as "we chose not to,
and documented it" — the second is the posture the conformance statement actually makes.

## The fix shape

One sweep, one commit: every `4.2.6` citation in `src/` and `docs/` re-derived against Annex A.3 vs A.4 membership
of the element it decorates; A.4 sites moved to §4.2.7 with the quote re-checked. Prefer the structural fix: the
declined-facility descriptor should carry its annex (A.3 or A.4) as DATA and the posture text should be generated
from it, so the next declined facility cannot cite the wrong clause — pair it with a drift test that reads each
declined facility's annex from `CONFORMANCE.md` and asserts the descriptor agrees.
