# PB3767 — the report-entry refusal needs a `!Symbols.TryResolve` guard

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/ReferenceResolver.cs#ReportUnidentified` (the `ReportEntryReferenceRefused` call, now guarded by the ambiguity count), `conformance-suite/cases/13.8.6.2.3-Report-Items/pb3767-ambiguous-reference-sharing-a-report-entry-spelling.cob` and `pb3767-qualified-reference-reaching-only-a-report-entry.cob` (with their refusals in `conformance-suite/wiseowl/diagnostics/`)

On PB1046's branch (PR #596, worktree-wf_1341dc87-1c4-11) the report-entry refusal in `ReportUnidentified` fires before the ambiguity arms with no guard that the name has no ordinary-data candidate. An AMBIGUOUS ordinary reference whose spelling a report entry also carries is therefore told only that it names a report item (COBOL5092) instead of the true ambiguity (COBOL1639 "does not uniquely identify"). The sibling constant-name and condition-name arms both guard with `!Symbols.TryResolve`. Harm: a misleading message on a refused program. Fix: the same guard, plus a golden of an ambiguous ordinary reference sharing a spelling with a report entry.

(2026-10-25, PB1046 review R1-1, severity low, not blocking at round 1.)

## Landing (2026-10-30, wave 20261783 group B)

Re-probed on the current tree: two `PV` data items under G1 and G2 plus a REPORT SECTION entry `PV`, then `MOVE PV TO W`, drew COBOL5092. The fix is NOT the `!Symbols.TryResolve` guard this note proposed: a data item of the same spelling that the written qualifiers do not reach (`PV OF DET-1`, DET-1 the report group) must still draw COBOL5092, and `!TryResolve` would have told that reference "declared, but not under the given qualifier". The guard is the one count the data division's clause operands and OCCURS DEPENDING ON already take before they ask `ReportEntryReferenceRefused`: `QualifiedCandidates(...).Count <= 1`, since more than one data item reached is §8.4.2.2.3 SR1's ambiguity (COBOL1639). The siblings (`DataBinder.ResolveClauseOperand`, `DataBinder.Odo`) were swept and already count first. Goldens: the ambiguity (COBOL1639) and its counterpart, the qualified reference reaching only the report entry (COBOL5092).
