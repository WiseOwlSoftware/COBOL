# PB5175 - at --std 85 a PICTURE with a trailing non-floating currency symbol compiles (PIC 999$, +999$, 999$CR): PictureComposition.Precedence offers the 2002 trailing currency role at every edition

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/PictureComposition.cs` (`Precedence`, `Validate`)

**Mechanism.** §1985:VI.5.9.5 GR6 makes the currency symbol the leftmost counted position, optionally preceded by + or -, and the 1985 precedence chart has one non-floating currency row (§1985:VI.5.9.4 GR6 defers the allowable combinations to that chart). `PictureComposition.Precedence` gives a fixed currency symbol two candidate roles, CurrencyLeading and CurrencyTrailing, at every edition, the trailing one being the 2002 addition, and accepts the string when either fits the table. So PIC 999$, +999$, 999$CR and 999$- define numeric edited items at --std 85 and edit with the symbol last.

**Found by.** The 1985 code read (2026-11-10; its records are `E:/COBOL-coord/scratch/coderead-85/for-register.json`): each rule below was read against the code sites it names and probed at `--std 85`, and found non-conforming. Verdict, harm, evidence, repro and observed text are the records'; the rows' verdicts are recorded on another branch.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids of the list below.
