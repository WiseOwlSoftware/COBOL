# PB1007 — OPEN

## The divergence
A function-identifier sent BY CONTENT is transferred "as for a MOVE" into the formal (§14.8.2.3.3 2)). The MOVE of the
same function value produces `[3   ]` (the §15.4 returned value's own PICTURE, moved to alphanumeric); the INVOKE
path's temporary is a fixed 30-digit numeric PICTURE, so the moved image is the temporary's digits, not the value's.

## What the fixer owes
One definition of "the temporary data item holding a function's returned value" (§15.4) used by MOVE, CALL/INVOKE BY
CONTENT and the MOVE multi-receiver hoist — measure the hoist for the same divergence first (the lead names it as the
same root). Golden: the INVOKE and the MOVE side by side, numeric and integer functions.
