# PB6204 - OPEN - an insertion inside a governed block is anchored only on its neighbour words

PB6144 confined an Amendment note to the block it governs (`_inside`, `scripts/spec/text_layer_diff.py`), which fixed the
page-wide match. Inside that block an inserted run is still located by one neighbour word on each side. Real governed blocks are
wide (6-90 lines on pp. 18, 32, 62, 74 and 739; figures up to 47 lines), so a short insertion placed at the wrong spot inside the
block, next to a common word, still classifies as AMENDMENT-APPLIED.

**Why it is low.** It can hide an error only inside text the note already governs, and the PB6051 page review reads every page.

**Fix shape.** Anchor an insertion on the note's own printed run: at least three words on each side, taken from the Amendment
entry's text, not from the page. Add a selftest case with a short insertion moved inside a wide governed block, which must leave
AMENDMENT-APPLIED.
