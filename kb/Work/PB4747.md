# PB4747 — effort medium by default

**Decision (owner, 2026-11-05).** "By default, all model work should be using effort level 'medium' as this session is
configured to use." The owner gave it while the Mythos lane looked into running `cobol-refuter` on a cheaper model, after
`/usage` attributed about 44 % of a day's usage to refuters and 33 % to adjudicators.

**What was set.** The roles ran at `high` (adjudicator, finisher, implementer, reviewer) and `xhigh` (refuter), and the
user settings of both accounts (`~/.claude/settings.json`, `~/.claude-acct2/settings.json`) set `effortLevel: xhigh`, so
every loop unit and attended session without its own setting ran at `xhigh`.

**What changed.** Every `.claude/agents/*.md` sets `effort: medium`; MANDATORY-PRACTICES O4 states it and its role list;
`check_practices.py`'s copies of the role list follow. Both accounts' user settings set `effortLevel: medium` (also the
per-model Fable, Mythos and Opus rows); those files are outside the repository. A role departs from `medium` only by the
owner's decision.

**Follow-up.** Whether the refuter can also run on Sonnet is measured separately (the Mythos lane's refuter-model
investigation, E:/COBOL-coord/scratch/refuter-model/); the PB3868 standard applies: a cheaper setting is not cost-effective
if it fails.
