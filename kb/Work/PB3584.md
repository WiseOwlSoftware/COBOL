# PB3584 — one scratch-repository fixture per self-test, each with its own git helper

## Found

Fifteen scripts `git init` a scratch repository in their self-test (`devlog.py`, `gate_slot.py`, `line_endings.py`,
`rendered_views.py`, `run_gate_legs.py`, `self_test_inputs.py`, `self_tests.py`, `orchestrator/enqueue.py`,
`orchestrator/land_lane.py`, `orchestrator/landing_check.py`, `orchestrator/test_checkpoint.py`,
`orchestrator/test_ledger_state.py`, `orchestrator/test_plan_wave.py`, `hooks/status_guard.py`, `linux-gate.sh`), and
seven of them define a local git helper of their own (`devlog.py` `sh`, `prune_worktrees.py` `g`, `rendered_views.py`
`git`, `run_gate_legs.py` two, `enqueue.py` `sh`, `landing_check.py` `sh`, `test_plan_wave.py` `git`).

## The divergence

Change how a self-test drives git in one place (an identity, `maintenance.auto=false` and `gc.auto=0` so a commit loop
spawns no `git maintenance`, a `--quiet`, an initial branch name) and the other helpers keep the old behavior. Measured:
run outside `self_tests.py` (which supplies a private global config with auto-maintenance off), the
`prune_worktrees.py` self-test spawned 74 `git maintenance` processes. And each self-test pays its repository's
construction (init, commits, a bare origin, worktrees) in git processes every run, which is PB3582's cost on Windows.

## The fix (a design, for the implementer)

One shared fixture module under `scripts/` (one git helper; one `ScratchRepo` that builds a repository with an origin,
branches and worktrees from a declarative description), every self-test above moved onto it and its local helper
deleted in the same change (CLAUDE.md rule 4: no forwarders). Where a self-test builds the same repository for many
cases, build it once and copy the directory per case (a file copy, no git processes) instead of replaying the commits.
A drift test refuses a new local git helper in a self-test.
