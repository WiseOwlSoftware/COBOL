# PB5620 - at --std 2002 a WRITE that writes its END-OF-PAGE phrases before the retry and lock phrases (the 2002 Format 1 order) is a parse error

**Sites:**
- `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolIO.g4#writeStatement`

**Mechanism.** writeStatement prints recordFromPhrase, writeBeforeAfter, retryPhrase, recordLockPhrase, then conditionalPhrases (the 2014/2023 order). 2002 Format 1 places AT END-OF-PAGE / NOT AT END-OF-PAGE before [retry-phrase] and WITH [NO] LOCK.

**Inventory.** Rows claimed: `2002-SR-14.8.47.2-17`, `2002-SR-14.8.47.2-18`, `2002-SR-14.8.47.2-19`, `2002-SR-14.8.47.2-2`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:14.8.47.2 SR17`: "The phrases ADVANCING PAGE and END-OF-PAGE shall not both be specified in a single WRITE s"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p2/ord2002.cob); the text is inline. Command: `cobol.exe p2/ord2002.cob --std 2002 --run`

`p2/ord2002.cob`:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. ORD02.
       ENVIRONMENT DIVISION.
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT LPF ASSIGN TO "ord02.prt" ORGANIZATION SEQUENTIAL
               LOCK MODE IS MANUAL.
       DATA DIVISION.
       FILE SECTION.
       FD LPF LINAGE IS 2 LINES.
       01 P-REC PIC X(4).
       WORKING-STORAGE SECTION.
       01 N PIC 9 VALUE 0.
       PROCEDURE DIVISION.
       MAIN.
           OPEN OUTPUT LPF
           MOVE "AAAA" TO P-REC
           WRITE P-REC AFTER ADVANCING 1 LINE
               AT END-OF-PAGE ADD 1 TO N
               NOT AT END-OF-PAGE ADD 2 TO N
               WITH LOCK
           END-WRITE
           WRITE P-REC AFTER ADVANCING 2 LINES
               AT EOP ADD 3 TO N
               RETRY 2 TIMES
               WITH NO LOCK
           END-WRITE
           CLOSE LPF
           DISPLAY "N=" N
           STOP RUN.
```

**Observed.** error COBOL2269 (21,16): unexpected 'WITH'. The ADD statement ends before this token ... (WRITE P-REC AFTER ADVANCING 1 LINE AT END-OF-PAGE ADD 1 TO N NOT AT END-OF-PAGE ADD 2 TO N WITH LOCK END-WRITE); rc=65.

**Expected (from the 2002 text).** compiles and runs.

**Citation note.** the load-bearing text is the 2002 Format 1 general format (§2002:14.8.47.1), read from the transcription (END-OF-PAGE block, then [ retry-phrase ], then WITH LOCK / WITH NO LOCK); render the PDF page before the fix (CLAUDE.md rule 1).

**Sibling sweep.** the 2002 order of conditional phrases versus retry/lock in REWRITE, DELETE, START, READ and Format 2 WRITE (INVALID KEY).

**Other editions.** 85: unknown (no retry/lock in 85; END-OF-PAGE is last there). 2014, 2023: no (their order is the grammar's).
