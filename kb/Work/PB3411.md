# PB3411 — the files design doc names a host-failure predicate the code no longer has

A lead from round 2 of the PB3336 branch review (`mythos-a6-review-r2`, report
`E:\COBOL-coord\scratch\reports\w1118a6-PB3336-report.md`, `## Review findings`, "LEAD (low, stale doc, the
predecessor's text)"). PB3336 landed as PR #268 (0eba56a75); the sites below are read on origin/main.

**Mechanism.** `docs/FILES_DESIGN.md:2502` lists "`IOException`, `UnauthorizedAccessException`,
`OutOfMemoryException` — one predicate, `KeyedConnector.IsHostStoreFailure`". The predicate is
`failure is IOException or UnauthorizedAccessException` (`src/WiseOwl.Cobol.Runtime/IO/KeyedConnector.cs:455-456`) and its
own comment says the OOM reason left with the whole-store model (kb/Work PB3335). The PB3336 cleanup section ("nothing
was left to delete") missed this doc line; it came from the predecessor branch (`-326-19`). Line 2502 is the only
`OutOfMemoryException` mention in the doc.

**Fix.** Rewrite the doc line in place to the current predicate (CLAUDE.md rule 6: docs describe the current compiler;
no annotation). PB2842 describes the older predicate in its history only.

**Sites:** (backfilled 2026-10-19 from this note's own text for the wave planner's file-set partition, kb/Work PB3263; the implementer corrects it)
- `docs/FILES_DESIGN.md`

## Landed

Re-probed on wave 1132 (group D) against origin/main ed4477ef2: the line the note names is already correct. `docs/FILES_DESIGN.md` now reads "maps a host failure (`IOException`, `UnauthorizedAccessException` - one predicate, `KeyedConnector.IsHostStoreFailure`)" (lines 2502-2503), which is the predicate at `src/WiseOwl.Cobol.Runtime/IO/KeyedConnector.cs:455-456` (`failure is IOException or UnauthorizedAccessException`). Commit 057e8ce9a (the PB3416-PB3419 lead-filing change) made the edit in passing and did not flip this note. `OutOfMemoryException` is named nowhere else in the files design or in any doc as a keyed-store host-failure reason; the one runtime catch of it under `IO/` is `FileConnector.cs:861`, OPEN's input-output area allocation (RESERVE, ISO 12.4.5.14.3 GR1), a different mechanism from the keyed statement entry and not part of this predicate. No code or design change was needed beyond this register flip.
