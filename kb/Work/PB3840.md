# PB3840 — one conformance row ID, two determinations

**Sites:** `docs/CONFORMANCE.md` (rows at the two `| DOC-A.1-92 |` lines), `scripts/audit_annex_a1.py`

## The defect

`docs/CONFORMANCE.md` has two rows with the ID DOC-A.1-92: "Characteristics and representation of a numeric intrinsic
function's returned value, and its text image" and "Evaluation of an exact-family intrinsic whose ARGUMENT is
floating-point". Code comments in ten files cite DOC-A.1-92 (IntrinsicRenderer.cs, IntrinsicBinder.cs,
SendingValueTemp.cs, DataItem.cs, AlgebraicRange.cs, RelationComparability.cs, ConditionRenderer.cs, OperandText.cs,
OoBinder.cs, CobolIntrinsics.Float.cs) and cannot say which determination they rely on. The ID audit
(`audit_annex_a1.py`) does not refuse a duplicate.

## Fix

Give the second determination its own ID, re-point each citing site to the row it actually relies on (read each one),
and make the audit refuse a duplicate row ID (sweep: run it over the whole file for any other duplicate).

## Acceptance

- `grep -oE '^\| DOC-[A-Z0-9.-]+ ' docs/CONFORMANCE.md | sort | uniq -d` prints nothing, and the audit fails if it would.
- Every code citation names the row it relies on.
