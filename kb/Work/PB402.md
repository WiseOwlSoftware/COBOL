# PB402 — an optional word made mandatory in one shared grammar rule, and three general formats pay for it

## 1. The mechanism

`raisingPhrase` (`src/Cobol.Net.Frontend/Grammar/CobolParserCore.g4:1390-1392`) is

    raisingPhrase
        : RAISING (EXCEPTION cobolWord | LAST EXCEPTION | dataReference)
        ;

EXCEPTION is **mandatory** in the LAST alternative. In the printed general format it is not underlined, and
5.2.3 makes an un-underlined word optional — it *may* be written for clarity and may equally be omitted. So
`RAISING LAST` selects the same alternative as `RAISING LAST EXCEPTION` and this grammar refuses it.

Because the rule is shared, one grammar defect reaches **every** general format that prints the alternative:
14.9.14.2 Format 2 (EXIT PROGRAM), 14.9.18.2 (GOBACK) and 14.9.38.2 Format 2 (SEND). The two live call sites
on this tree are `exitStatement` (`src/Cobol.Net.Frontend/Grammar/Core/CobolControlFlow.g4:333`) and
`gobackStatement` (`CobolParserCore.g4:1363`); there is no `sendStatement` rule in the grammar yet, so SEND's
printing of the phrase is a site the fix must reach when message control lands, not a third repro today.

**The rest of Format 2 is exact.** `exitStatement` is
`EXIT ( PROGRAM raisingPhrase? | PERFORM CYCLE? | SECTION | PARAGRAPH | METHOD raisingPhrase? | FUNCTION raisingPhrase? )?`,
so bare EXIT (Format 1), EXIT PERFORM [CYCLE] (Format 3) and the exactly-one PARAGRAPH|SECTION brace (Format 4)
all match their printed diagrams, and the RAISING bracket/brace of Format 2 is optional-with-select-one. The
edition gating is right too — the b2 sweep measured Format 1 clean at all four editions, Format 2 clean at
85/2002/2014 and COBOLNET0903 (archaic) at 2023, Formats 3 and 4 COBOLNET0900 at 85 and clean above, and EXIT
METHOD / EXIT FUNCTION COBOLNET0902 (removed) at 2023. There is no over-acceptance either: `EXIT PROGRAM WITH
NORMAL STATUS` is rejected, which is correct because Format 2 has no status phrase. **One spelling is refused,
and that is the whole of this row's divergence.**

## 2. The rules, quoted, each `--check`ed on this tree

    python scripts/spec/cite.py --check 5.2.2 "They are shown in uppercase and underlined in general formats. They are required in order to select the functionality associated with that keyword"
      -> OK  §5.2.2   (Keywords)
    python scripts/spec/cite.py --check 5.2.3 "They are shown in uppercase and not underlined in general formats. They may be written to add clarity"
      -> OK  §5.2.3   (Optional words)

The load-bearing fact here is a DIAGRAM fact, so it was **measured from the canonical PDF, not read off the
transcription** (`feedback_underlining_not_bracketing`, `feedback_spec_diagrams_render_pdf`). On the EXIT
Format-2 page the underline rectangle under that alternative spans x 236.89–258.60 while the glyphs of LAST
span 235.5–259.0 and EXCEPTION spans 264.9–317.8 — the rule stops at LAST. The 400 dpi crop the b2 adjudicator
rendered is at `out-b2/exit-fmt2-crop.png`. The identical phrase at the GOBACK site measures the same
(underline 144.22–165.93; LAST 142.8–166.2; EXCEPTION 172.0–224.5), which is the second page the underlining
doctrine demands before a rule is relaxed, and it shows this is the standard's consistent typesetting rather
than a one-page artifact.

## 3. Expected vs observed — RE-MEASURED ON HEAD (89044aa0)

    $ cobol.exe fmt-raising-last.cob --std 2023
      fmt-raising-last.cob(10,37): error COBOL0001: missing token before '.'

The program is four lines: `PROGRAM-ID. PBXFMT1.` / `PROCEDURE DIVISION.` / `MAIN-PARA.` /
`EXIT PROGRAM RAISING LAST.` / `STOP RUN.` Expected: ACCEPTED — an optional word may be omitted, so this is the
same alternative as `RAISING LAST EXCEPTION`. Observed: a raw parser error naming nothing the user can act on,
which is itself the second-order harm: a `COBOL0001` gives a reader no way to tell a compiler limitation from
a genuine syntax mistake.

The GOBACK lane recorded the identical rejection of `GOBACK RAISING LAST.` under `FMT-14.9.18.2`, from the same
shared rule.

## 4. The code site and the shape of the repair

- `src/Cobol.Net.Frontend/Grammar/CobolParserCore.g4:1390-1392` — `raisingPhrase`, the one rule.
- `src/Cobol.Net.Frontend/Grammar/Core/CobolControlFlow.g4:333` — `exitStatement`, call site one.
- `src/Cobol.Net.Frontend/Grammar/CobolParserCore.g4:1363` — `gobackStatement`, call site two.
- `src/Cobol.Net.Compiler/Validation/VersionConformancePass.cs#VisitExitStatement` — the edition gate, which is
  correct and needs no change.

The diff is one token: `LAST EXCEPTION` → `LAST EXCEPTION?`. **The diff is not the work.** Per CLAUDE.md
rule 5, the shape that makes the next case automatic is the **audit**, not the alternative: this is a whole
CLASS of defect (a general format's un-underlined word transcribed into the grammar as mandatory), and
`scripts/spec/audit_grammar_optional_words.py` already exists for exactly this shape. Extend it to cover the
raising-phrase figures and wire it into the gate, so the next un-underlined word that reaches a `.g4` as a
required token fails a check instead of waiting for an adjudication to find it. A hand-kept list of "words we
checked" is the anti-pattern rule 5 names.

## 5. The sibling sweep the fixer must do

- **The other alternatives of the same rule.** `RAISING EXCEPTION exception-name-1` — is EXCEPTION underlined
  there? It selects a different alternative, so if it is *also* optional the grammar becomes ambiguous against
  the bare `dataReference` arm and the fix is not symmetric. Measure the underlining before touching it.
- **Every `LAST EXCEPTION` in the grammar**, not just this rule — `SET LAST EXCEPTION TO OFF` (14.9.39
  Format 13) and `FUNCTION EXCEPTION-*` neighbourhoods print the same two words; each printing has its own
  underlining and each must be measured, not inferred from this one.
- **Goldens ship with the feature**: `RAISING LAST` needs a positive golden at the EXIT site AND at the GOBACK
  site, or the shared rule can regress on one call site while the other stays green.
- **Edition gate sweep** — the RAISING phrase arrives with the 2002 exception model, so the new spelling must
  be accepted at 2002/2014/2023 and produce the *edition* diagnostic, not a parse error, at `--std 85`.

## 6. Rows

- **`FMT-14.9.14.2`** (DIVERGES) — Formats 1, 3 and 4 match their diagrams and every edition gate measures
  right; Format 2 refuses one legal spelling of its RAISING tail. The verdict rests on the PDF underlining
  measurement above plus the HEAD repro, not on the transcription.
