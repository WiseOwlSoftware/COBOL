# PB2980 — the report path follows the wave's scratch, the readers do not

**Found by:** the operator, 2026-10-10 ~20:55 PDT, when wave 1055 (Workflow `wf_6f53c0b7-a74`, six finishers of the
wave-1053 compiler branches) completed with six DONE reports and `prune_worktrees.py --brief` listed none of them
WAITING TO LAND. The owner asked "Why are reports not going to the expected place?".

## Mechanism

- `.claude/skills/workstream/templates/dispatch-spec-implementer.md` rendered `Report: {S}\reports\{slug}-{lead}-report.md`,
  and `make_dispatch_specs.py` filled `{S}` from the groups file's `scratch`.
- The operator dispatched wave 1055 with `scratch` = `E:\COBOL-coord\scratch\w1055` (its own folder, for its stop file
  and specs), so its reports went to `scratch\w1055\reports`.
- The readers each held their own path: `prune_worktrees.py#default_reports_dir` read `<coord>\scratch\reports`, and
  `plan_wave.py` read `<scratch>\reports`. The loop's land unit (`units/land.md`) and MANDATORY-PRACTICES O11 name
  `<coord>\scratch\reports`. The loop's own waves pass `scratch` = `<coord>\scratch`, so only an attended wave with
  another scratch fell through; nothing checked it (`check_practices.py` matched only the file name's shape).
- Harm: the six compiler fixes would have waited for no land unit at all (the branch survey would have turned them
  into stale DECISION rows after 24 h). The operator copied the reports into `<coord>\scratch\reports` by hand.

## Fix (landed)

- ONE definition: `scripts/orchestrator/coord.py#reports_dir` (`<coord>\scratch\reports`). `prune_worktrees.py`
  (its `default_reports_dir` deleted), `plan_wave.py` (the `--reports` default) and `make_dispatch_specs.py` (the
  spec's `{reports}` placeholder) all use it, whatever scratch a wave uses.
- `check_practices.py`: the implementer template must carry `{reports}`, and a RENDERED spec's report path must be in
  `coord.reports_dir()` (`RENDERED_REPORT`).
- Drift guard: `scripts/orchestrator/test_plan_wave.py` section 7c renders a spec whose scratch is a temporary folder
  and requires its report line to name `coord.reports_dir()` and not the scratch, and requires `RENDERED_REPORT` to
  refuse a report under the wave's scratch. 122/122 checks.
- Docs: MANDATORY-PRACTICES P8 and O11, the workstream SKILL §3, `units/land.md`.
