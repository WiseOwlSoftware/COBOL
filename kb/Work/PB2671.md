## The rows

Both determinations are WRITTEN in `docs/CONFORMANCE.md` §7 and recorded CONFORMS, and both rows are `state: GAP`
only because `test-ref` is empty: no test pins the determination.

- **DOC-A.1-116** — A.1 item 116, *"Linkage section (whether access to linkage section items is meaningful when
  called from a non-COBOL program)"* (`cite.py --check A.1` → OK §A.1 116)), conditionally required. It documents
  §13.7.4 GR3 (*"If a program is activated by a non-COBOL runtime element, the implementor defines whether access to
  formal parameters and the returning item is guaranteed"*, `--check 13.7.4` → OK 3)) and GR5 (*"If the runtime
  element containing the linkage section is activated by a non-COBOL runtime element, the initial value of a linkage
  section data item is defined by the implementor"*, `--check 13.7.4` → OK 5)). A COBOL golden runs as an
  OS-activated main program, where GR3/GR5 make access UNDEFINED, so the corpus cannot reach the non-COBOL arm. A
  .NET host invoking the generated program directly can: through `ICobolProgram.Call` (a supplied carrier, an
  omitted one) and through `ICobolProgram.Activate`.
- **DOC-A.1-118** — A.1 item 118, *"Locale specification (how user and system defaults defined; at least one user
  and one system default)"* (`--check A.1` → OK §A.1 118)); §8.2.1 *"The implementor shall specify the manner in which
  the user default locale is defined"* and its system-default twin (`--check 8.2.1` → OK, both). Measured by the
  adjudicator with `loc.cob` (LOCALE-DATE before and after `SET LOCALE LC_ALL TO SYSTEM-DEFAULT`):
  `COBOL_USER_LOCALE=de-DE COBOL_SYSTEM_LOCALE=ja-JP` → `USR=24.09.2026` / `SYS=2026/09/24`; swapped, the reverse.
