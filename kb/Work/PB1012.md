## Original analysis (2026-09-22)

## Rule 7
`OK  §9.3.8.2.3 7)` — "If either of the corresponding formal parameters or returning items in interface-1 or interface-2
is a strongly-typed group item, both are of the same type."
§8.5.3.1 (TYPEDEF) scopes a type-name to its source element; an interface definition cannot declare one, so "the same
type" across an interface and a class needs a ruling (same type-name resolved through the REPOSITORY / an external
type? structural identity?). Survey GnuCOBOL/IBM/MF per `feedback_survey_compilers_on_latitude` before deciding.

- **Rules 1–6 (half slot, after PB1051 for rule 1's mode half):** positive + negative golden per rule against

- **Rule 7 — PREMISE CORRECTED: no adjudication is needed.** The note asks what makes a strongly-typed formal "the same
  type" across an interface and a class. §8.5.3.1 answers it for declarations in DIFFERENT places: "Two type
  declarations are considered equivalent when they have the same type-name, both have the same presence or absence of
  the EXTERNAL clause and the STRONG phrase" (cite-checked OK §8.5.3.1) and, per elementary item, the same relative
  position and length and the same clause list (currency / DECIMAL-POINT / LOCALE exceptions included); two typed items
  are of the same type when their TYPE clauses reference EQUIVALENT declarations. The code already implements that
  relation — `OoConformance.StrongTypeMismatch` → `StrongTypeModel.SameType`, whose message quotes §8.5.3.1 — and
  `MethodConformanceMismatches` asks it for every formal and a non-object RETURNING. What is owed is only the golden
  round: rule 7 positive (prototype and implementation each declaring an equivalent `TYPEDEF STRONG` of one type-name
  → conforms, runs) and negatives (same name, one elementary item's length differs; same structure, different
  type-names; STRONG on one side only) → COBOLNET0841 naming rule 7. Where an interface prototype can legally declare
  the TYPEDEF (its LINKAGE, or a GLOBAL/EXTERNAL declaration visible to it) is the golden writer's first question —
  derive it from §13.18.58 before writing the source.
