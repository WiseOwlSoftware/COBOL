# PB4087 — the optional-words audit cannot run where the licensed PDF is absent

**Site:** `scripts/spec/audit_grammar_optional_words.py#main`. At `4e8251f4f` (branch `worktree-wf_66e93b32-365-8`, PR #795) the
module sets `PDF = next(iter(sorted((REPO / "specs-private").glob("*COBOL*.pdf"))), None)` and `main` exits with "FATAL: the ISO
PDF was not found under specs-private/" when it is missing. Only `--self-test`, which runs fixture grammars, needs no PDF.

**What is wrong.** The audit measures underlines and brackets from the PDF's vector rectangles, so the real-grammar join runs only
on a host with the private submodule. CI and every public checkout run none of it. A regression it would catch (a required word
written into the grammar, an inverse-class violation, a stale `audit:required-word` annotation) reaches a landing unseen: a check
the local operator runs that CI cannot.

**Direction (not a fix).** A mode that reads the measurement-generated `<pre>` figures of `specs/ISO_COBOL.md` (the tracked
transcription carries them) would make the whole join CI-runnable; the PDF mode stays the authority that regenerates them. PB3208
(the PDF locator written 15 times) touches the same file family but is a different mechanism; PB3752 and PB3753 are open findings
about the audit's coverage, not about where it runs.
