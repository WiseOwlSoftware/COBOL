**Wave kind:** unify (one wave per root family). **Model:** Opus. Each step needs judgment about arms that group cases
on purpose.

**The mechanism.** PB6168 made the bound tree and the binding model's Place and AccessPath hierarchies `closed` (C# 15).
A switch over a `closed` root that names every direct case is now exhaustive, and a missing case is CS8509, an error
under `TreatWarningsAsErrors`. But every switch that ends in `_ => throw` or `default: throw` still compiles when a new
case is forgotten, and still throws at run time. DESIGN-architecture-review §8.5 counted 48 to 74 such arms, densest in
`EcBinder`, `IntrinsicBinder`, `ConditionBinder`, `IntrinsicArgumentRules`, `ConditionRenderer`,
`VersionConformancePass` and `PlaceRenderer` (4).

**Sites:** the files below are the first measured arms (a text scan at 9e65164eb). The wave's first step replaces this
list with the DESIGN-architecture-review §8.5 ratchet's count per file, and each per-root wave names its own members.
- `src/WiseOwl.Cobol.Compiler/CodeGen/Roslyn/PlaceRenderer.cs` (whole: its 8 throw arms over `Place` kinds)
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/IntrinsicBinder.cs` (whole: its throw arm over a bound root)
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ConditionBinder.cs` (whole: its throw arm over a bound root)
- `src/WiseOwl.Cobol.Compiler/Binding/IntrinsicArgumentRules.cs` (whole: its throw arm over a bound root)

**The change, per root:**
1. Remove each throw arm whose switch then names every case of the root.
2. Write a deliberately grouped default as an explicit `A or B or C` pattern.
3. Where a switch truly covers only some cases (a partial function), the throw stays and is commented as such.
4. Add the DESIGN-architecture-review §8.5 ratchet drift test over the remaining hand arms per file, so their count can only fall.

Order: smallest roots first (`BoundSetTarget`, `BoundPerformControl`, `BoundEoOperand`, `AccessSegment`, `AllCount`,
`WindowCoding`), then `Place`, then `BoundBoolExpr`, `BoundOperand`, `BoundExpr`, `BoundCondition` and `BoundStatement`.

**The rest of the closed hierarchies.** These abstract types remain:
- 13 in `src/WiseOwl.Cobol.Compiler`, among them `FormalCarrier`, `KeyNameReading`, `MethodLocal`, `OmittedProbe`,
  `Position`, `StorageForm` and `ReportFieldSource`;
- 3 in `src/WiseOwl.Cobol.Frontend`;
- 20 in `src/WiseOwl.Cobol.Runtime`.

Close each compiler and front-end hierarchy whose subclasses are all in its assembly. Measure it the way PB6168 did:
generator output identical, and the suites green. A runtime type is closed only where no emitted program or user code
is meant to derive from it. Its public surface is part of the runtime ABI, `abi_pin.py`.

**Proof:** the DESIGN-architecture-review §4 contract, the same as PB6168 (no diagnostic or emitted-C# change), and the full gate.
