# PB5980 - the file verbs' refusal does not name the declaration that hides a GLOBAL file

The container declares a GLOBAL file F; the contained program declares its own data item F and executes `OPEN ... F`. By
§1985:X.1.3.8.2 GR3a F there names the data item, so the refusal is right. Its text is not: "'F' is not defined as a file ...
no SELECT or file description entry in this source element gives that name", which sends the programmer to a file
description that exists. PB5976 made the report verbs name the hider ("'R1' here names a data item declared at line N in
this program, which hides the GLOBAL report-name 'R1' of a containing program"); the file verbs (OPEN, CLOSE, READ, WRITE,
REWRITE, DELETE, START and the clauses that name a file) need the same hider clause, from one helper shared with the report
verbs rather than a second copy.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ReportWriterBinder.cs:453` (`ReportWriterBinder.HidingOfReportName`)

Witnesses at `--std 85`: OPEN, and one record verb, on a name hidden this way, expecting the hider clause.
