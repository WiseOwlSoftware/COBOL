# PB5116 - at --std 85 a CONTROL HEADING or CONTROL FOOTING report group without its control operand (TYPE CH with no data-name or FINAL) compiles; the 1985 format braces the operand and the 2023 optional operand is applied at every edition

**Sites:** `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolReportWriter.g4#reportGroupType` (`(CONTROL HEADING | CH) (reportControlName (OR PAGE)?)?` and `(CONTROL FOOTING | CF) reportControlName?`) and `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolReportWriter.g4#reportControlName` (`(ON | FOR)?`); no edition gate in `VersionConformancePass`'s report visitors

**Mechanism.** The grammar writes the TYPE clause's control operand as optional (2023 form) and no version gate refuses its omission at --std 85. The 1985 format braces it: `{CONTROL HEADING | CH} {data-name-1 | FINAL}` and `{CONTROL FOOTING | CF} {data-name-2 | FINAL}`, so a control heading or footing must name its control. The omitted operand is resolved as §2023:13.18.57.3 SR11 provides, with no diagnostic (not even the COBOL2894 extension warning). Siblings seen compiling clean at --std 85: TYPE CF with no operand, TYPE CONTROL HEADING FOR WS-KEY (the 2023 optional word) and TYPE CONTROL HEADING WS-KEY OR PAGE; with two controls the bare TYPE CONTROL HEADING is refused, but by the 2023 rule (COBOL0899, §2023:13.18.57.3 SR10/SR11) at the RD line. kb/Work PB3964 (landed) names this as residue it did not gate (its Leads and Residue paragraphs); PB5078 and PB5079 do not carry it. The §1985:XIII.3.20.2 clause is a reconstruction (folio XIII-55 missing from the scan, kb/Work PB4952), so the requirement is taken from the printed Format 1 of §1985:XIII.3.9.2 (PDF page 602, folio XIII-20), which prints braces.

**Found by.** The 1985 witness-drafting pass (kb/Work PB4995 item 3): each rule below is a witness program drafted from the 1985 text alone, run at `--std 85`, and its result differs from what the text requires (outcome MISMATCH). Harm and observed text are the record's; nothing here was re-derived.
