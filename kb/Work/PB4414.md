# PB4414 - Per-record cost of an uncovered sharing WRITE after PB4387

**Sites:** `src/WiseOwl.Cobol.Runtime/IO/Sharing/SidecarRegionLocks.cs` (`SidecarRegionLocks.Look`, and the park rename in the release path with the rename back in the hold path), `src/WiseOwl.Cobol.Runtime/IO/Sharing/SequentialJournal.cs` (`SequentialJournal.Enter`, whose `medium.ListNames(directory, NamePrefix)` lists the `txn-` names).

After PB4387 each record of an uncovered sharing sequential WRITE still costs the lock-file rename pair, one `Look` directory listing and `SequentialJournal.Enter`'s `txn-` listing, about 0.3 ms per record as measured. An OS byte-range mutex on a persistent file would cost near zero but is a different protocol: a DESIGN-runtime-library 2.2.2.3 change, so the fix updates that design doc in the same change set.

No harm flag: performance only.
