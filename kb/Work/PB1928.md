# PB1928 — OPEN

Filed by the train-1005 lander from its own review of the merged train (step 5b). PLAUSIBLE, not probed: a
composition finding between wave 1005 group C (PB1419, which added the predicate) and group B (PB1372, which made
`FunctionWord` the one place the `>>COBOL-WORDS` directive is applied to a function name), plus the parenthesis
reading of group D (PB1464, not landed in train 1005).

## The two gaps

1. **A second resolution.** `ConditionBinder.IsBooleanUserFunction(string written)` calls
   `ctx.CobolWords.Resolve(written)` on the text of the `functionName` token. PB1372 established that resolving token
   text a second time is wrong: the lexer already applied the directive, and a SUBSTITUTE'd literal-4 or an UNDEFINE'd
   word reads as "removed" (null). The bind path (`IntrinsicBinder.BindFunctionResult` over `FunctionWord`) keeps the
   written name of a removed word for the user-function dispatch, so a boolean user function whose name is a word the
   directive de-reserved binds as a function but is not routed as a boolean operand by this predicate. Fix shape:
   `FunctionWord.OfToken(un.Start, ctx.CobolWords).Name`.
2. **Not parenthesis-transparent.** The predicate reads `vo.arithmeticExpression()` where its intrinsic sibling two
   lines above reads `ConditionOperandExpression(vo)` (once PB1464 lands; on today's main the sibling reads
   `vo.arithmeticExpression()` too). §8.8.2 lists "a boolean expression enclosed in parentheses" as a boolean
   expression, so `IF (FUNCTION MYBOOL(1))` should route the same as `IF FUNCTION MYBOOL(1)`.

**Site.** `src/Cobol.Net.Compiler/Binding/Procedure/Verbs/ConditionBinder.cs#IsBooleanUserFunction` and its caller
`IsBooleanValueOperand` (the last return).

**Repro to write.** A REPOSITORY-declared FUNCTION-ID with `RETURNING` a `PIC 1 USAGE BIT` item, used as
`IF (FUNCTION F(1))` and, under `>>COBOL-WORDS UNDEFINE` of a reserved word that names the function, as a bare boolean
operand. Expected: both bind as the boolean result temporary (§8.4.3.2.4 GR1).
