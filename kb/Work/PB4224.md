# PB4224 — hint 0i does not reach a literal at a true statement start

**Sites:** `src/WiseOwl.Cobol.Frontend/Parsing/AdmittedKinds.cs#Name`, `src/WiseOwl.Cobol.Frontend/Parsing/AdmittedKinds.cs#BeginsAStatement`, `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs#GuessCobolIntent`.

**Repro.** `IF W-N = 1 THEN 5 END-IF.` draws only `COBOL0001: unexpected '5'`. PB4174 / PB4201 made `USAGE 5` draw COBOL5506 naming the usages the edition has (hint 0i). A literal where a statement must begin was not covered: no admitted-kind set names a statement start for the hint, so the bare message remains. Output as recorded in the PB4174 report's leads section.

**Fix direction.** Have `GuessCobolIntent` hint 0i name the statement verbs (via `AdmittedKinds.BeginsAStatement`) when the offending token is a literal at a statement start, with a golden at each edition; sweep the sibling openings (after `ELSE`, `WHEN`, `AT END`, `THEN`).
