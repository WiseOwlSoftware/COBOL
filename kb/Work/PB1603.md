Filed 2026-09-26 by the **train-61 lander** from the w61d implementer report (PB1192/PB690/PB1098).

## Observation
Since w61d (R47), `ReportWriter` (`src/Cobol.Net.Runtime/IO/ReportWriter.cs`) advances its device line only on a
successful `WriteAdvancing`, and a refused line appears in the file as a blank line
(golden `tests/conformance/85/pb690_report_line_byte_image_85`). The WriteAdvancing status is otherwise unread, so
the refusal never reaches the program.

## To decide
Not a spec breach as filed: GENERATE is not among the statements §9.1.13.1 gives an I-O status. The question is
whether a refused report line should raise an exception condition (EC-I-O-IMP under checking, or another EC-I-O
condition) so a program can observe it — survey GnuCOBOL / IBM / Micro Focus per CLAUDE.md rule 1, record the
determination in `docs/CONFORMANCE.md`, and implement or close.
