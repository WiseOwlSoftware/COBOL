# R21 — CURRENT-DATE and FORMATTED-CURRENT-DATE bypass the injectable clock, so two now-functions disagree in one run unit

> R00 ledger-audit orphan (2026-08-08): F33 of `PHASE-B-15.32-15.44-findings.md`, probe-verified OPEN
> against the R10-landed tree (`5312996a`). The probe programs are reproducible from the finding text.

MECHANICAL CHECK (2026-08-08): `CobolDate.CurrentDate()` (line 41) and `FormattedCurrentDate` (line 395)
still read `DateTimeOffset.Now` directly — the only clock reads outside the `RunUnit.Current.Clock` seam in
the greenfield runtime (grep-verified; the CobolSharp.Runtime hits are the legacy engine). With
COBOLNET_CLOCK pinned, SECONDS-PAST-MIDNIGHT and FORMATTED-CURRENT-DATE return different instants in one run
unit, and no spec-derived golden for §15.38.4 r1 can exist. FIX (ledger, corrected): widen the seam to
DateTimeOffset (IClock.Now() returns DateTime, and §15.38 needs the offset for §15.3.3.5/.6), route both
functions through it, and add a drift test that no DateTimeOffset.Now/DateTime.Now survives outside
SystemClock + the WHEN-COMPILED capture.

## LANDED 2026-08-08

The seam widened exactly as the ledger prescribed: `IClock.Now()` returns **`DateTimeOffset`** — the wall-clock
reading WITH the local time differential factor §15.21.3 r1 renders at positions 17–21 — and both stragglers
now read `RunUnit.Current.Clock.Now()` (§15.21.1: the value is "provided by the system on which the function
is evaluated", §15.38.4 r1 the same words; both citations cite.py-checked). `SystemClock`'s COBOLNET_CLOCK pin
parses as DateTimeOffset with `AssumeLocal`, so an offset-less pin behaves exactly as before and a pin may now
carry an explicit offset (`…+02:30`) for machine-independent goldens. `AcceptSource.Now()` takes `.DateTime`
(the wall-clock reading as pinned, not re-zoned); the windowing/`SecondsPastMidnight` callers compile
unchanged on `DateTimeOffset`.

Tests: `CobolDateWindowingTests` gains the seam facts — CURRENT-DATE's full 21 characters under a +02:30 pin
(an offset no test machine runs at, so a pass proves the offset travelled through the seam), and the
three-now-functions-one-instant agreement fact that IS this defect's repro. **`ClockSeamDriftTests`** is the
source-form guard: no `DateTime[Offset].{Now,UtcNow,Today}` in `src/Cobol.Net.*` outside `IO/Clock.cs`
(SystemClock's fallback) + `IntrinsicBinder` (the WHEN-COMPILED §15.99.3 r2 compile-time capture) — proven in
the failing direction against an injected offender before being trusted. DESIGN-runtime-library §2.7 records
the widened contract. Gate: Unit clock/date/drift filter 3204/3204 · Conformance Intrinsic|Corpus|Accept
