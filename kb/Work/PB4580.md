# PB4580 — a record counts before anyone asks whether the other project fixed it or already has it

**Sites:** `scripts/fuzz_triage.py#plan_filing`, `scripts/fuzz_triage.py#write_filing`, `scripts/fuzz_history.py` (the ledger counts a filed note as a bug found, `from_fuzzing`).

**Observed.** `fuzz_triage.py file` writes an `upstream` note for every record the refuter upheld, with `upstream_status: unreported` and the line "the tracker has not been searched (owner-gated, PB3838)". The record then counts in the night's yield (47 on night 10, 15.7 per 1,000 programs against 0.29 on night 9). Nothing before that point re-runs the repro on the current 3.3-dev tree or searches the cached tracker for the mechanism. The vetting found: one fixed upstream (PB4538, 3.3-dev prints 77.11, bugs #934), three already on the tracker and ended (PB4519 bugs #996, PB4545 feature-requests #109, PB4546 feature-requests #171), seven already on the tracker that a comment, not a ticket, can serve (PB4528, PB4521, PB4560, PB4550, PB4535, PB4543, PB4529), and three filed twice from different slices (PB4540 into PB4531, PB4532 into PB4542, PB4565 into PB4539; the triage's own refuter had written "file only one" for PB4540). The ledger therefore overstated the bugs found by about 15 to 25 percent (step 1 estimated 36 to 40 of the 47 sound and new; the vetting counts 30 sound and new, two owner decisions).

**Fix shape.** Make the two checks steps of the tool, run before `file` counts a record: (1) re-run every upheld repro on the 3.3-dev judge the run records and refuse a record whose output is already correct there; (2) search the tracker cache (PB4581 gives the searchable form) for the record's mechanism and write the hits into the note as `related_tickets`, so `file` marks a hit `duplicate` or `comment-candidate` and the ledger counts only records with neither. Add a same-mechanism check across the night's own records (same fix site or same source line in the vetter's `fix site`) so a pair filed from two slices merges before it is written.
