## Finding — `cobol-words` (under-rejects; rows `SR-8.3.2.2-3`)

**Mechanism.** A letterless word (digits joined by hyphen/underscore, e.g. `1-2`) is a legal IDENTIFIER token because a paragraph-name or section-name may be spelled that way, but no declaration site other than the procedure-name slots screens for §8.3.2.2's 'at least one basic letter or extended letter' — the lexer comment claims the check, the lexer cannot make it (it must admit `1-2` for paragraphs), and the binder never makes it; so a data-name, condition-name, index-name, mnemonic-name or class-name with no letter compiles and runs

**Repro.** out/probe/onetype/dig3.cob: SPECIAL-NAMES. SYSOUT IS 9-9 CLASS 1-1 IS 'A' THRU 'C'. / 01 V PIC X VALUE 'A'. 88 3-4 VALUE 'A'. / 01 T. 05 E PIC X OCCURS 3 INDEXED BY 5-6. / PROCEDURE: SET 5-6 TO 2, IF 3-4 DISPLAY 'C88' UPON 9-9, IF V IS 1-1 DISPLAY 'CLS' -> `cobol dig3.cob --std 85|2023 --run` compiles, prints C88 / CLS. dig.cob: `01 1-2 PIC X VALUE 'A'.` + DISPLAY 1-2 -> prints A.

**Expected from the spec.** Compile-time rejection of each declaration of a user-defined word that is not a section-name, paragraph-name or level-number and contains no basic or extended letter, at every edition (the sentence is in the 85 standard too).

**Observed / reasoning.** Exit 0 and correct-looking output at 85 and 2023 for five different user-defined-word types. CobolLexer.g4 NAME_BODY arm 1 `[0-9]+ [-_] [a-z0-9] NAME_TAIL?` tokenizes `1-2` as IDENTIFIER; the lexer comment above IDENTIFIER says 'must contain at least one letter' — the check it describes lives nowhere. Fix shape: one declaration-time screen applied wherever a user-defined word is DECLARED (the definition-slot funnel that already distinguishes procedure-name definitions), keyed on the §8.3.2.2 type, with a drift test that every §8.3.2.2 type's declaration slot passes through it; negative goldens per type.

**Code site.** src/Cobol.Net.Frontend/Grammar/Core/CobolLexer.g4#NAME_BODY (the comment at the IDENTIFIER rule); no binder screen exists

## What the fixer owes

One screen at every user-defined-word DECLARATION site except paragraph-/section-names (and level-numbers/segment-numbers, which are not words): data-, file-, record-, condition-, index-, mnemonic-, alphabet-, class-, symbolic-character-names. Fix the lexer comment. Negative golden `01 1-2 PIC X.`
