# PB5280 - RECEIVE reports in SYMBOLIC SOURCE (data-name-7) a source name the MCS itself declares unknown: a delivered message's source defaults to its destination's name and SetReceived writes it unchecked, where 1985 requires spaces for a source not known to the MCS

**Sites:**

- `src/WiseOwl.Cobol.Runtime/Communication/CommunicationArea.cs` (`SetReceived`)
- `src/WiseOwl.Cobol.Runtime/Communication/MessageControlSession.cs` (`Transfer`)
- `src/WiseOwl.Cobol.Runtime/Communication/MessageStoreState.cs` (`KnowsCommunicationTerminal`)

**Mechanism.** §1985:XIV.2.2.4 GR10: data-name-7 receives the symbolic name of the source terminal, and "if the symbolic name of the communication terminal is not known to the MCS, the content of the data item referenced by data-name-7 will contain spaces". A message a program SENDs to a destination that delivers to a queue gets the destination's own name as its source (`DestinationDefinition.SourceName` in MessageDefinitions.cs), and `Transfer` hands it to `CommunicationArea.SetReceived` without asking whether the MCS knows such a source; the same MCS answers status 21 ("Symbolic source is unknown") to an ENABLE INPUT TERMINAL with that name.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the non-conforming verdicts wait in `E:/COBOL-coord/scratch/coderead-85/p2-for-register.json`.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-GR-XIV.2.2.4-10` - `§1985:XIV.2.2.4 GR10` (refuter: OVERTURNED to DIVERGES, harm: wrong-answer): "is not known to the MCS"

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-pipe/refute-slice-57/ck3/c-deliver.cob` with its mcs.json (destination D2 delivers to Q1, no source): `SEND OUT-CD FROM W WITH EMI` to D2, `RECEIVE CDIN` from Q1, then `ENABLE INPUT TERMINAL CDIN` with the received name; `cobol.exe --std 85 --source-format fixed --run c-deliver.cob`.

**Observed (a build of origin/main f2cf36fd15, rerun 2026-11-11; main has since changed only `IndexedConnector.cs` under `src/`, which none of these repros reaches).** `R1 [WXYZ******] ST 00 SRC[D2          ] LEN 0004 END 2`, then `ENT ST 21 SRC[D2          ]`.

**Expected (from the 1985 text).** `SRC[            ]` (twelve spaces): D2 is not a source the MCS knows, as its own status 21 says.

**Fix direction (root cause, CLAUDE.md rule 4).** Write the source name only when the MCS definitions hold it (the same lookup status 21 uses), else spaces; test a defined source, an undefined one and a program-sent message.
