# PB590 — OPEN — one of the class condition's fourteen alternatives is missing

Found 2026-09-05 by the `PB230` implementer, which wired §14.6.13.2 rule 1 (boolean sending items) and found
that the class condition — the context rule 2 exempts and rule 1 relies on — cannot be written for a boolean
item at all. Re-derived on this tree for this note.

## Repro (`--std 2023`)

```cobol
       01  BB  PIC 1(4).
       ...
           IF BB IS BOOLEAN DISPLAY "BOOL" END-IF
```

→ `COBOLNET0901: 'BOOLEAN' is a reserved word … and cannot be used as a user-defined word`. The parser reaches
the identifier slot of a relation condition because the class-condition rule offers no BOOLEAN alternative.

## The rule

```
python scripts/spec/cite.py --check 8.8.4.4.4 "If BOOLEAN is specified, the condition is true if the content of the data item referenced by identifier-1 consists entirely of the boolean values '0' and '1'."
OK  §8.8.4.4.4 3) d) 2.   (cite.py's ordinal stamp — PB222: it walks back to the nearest numbered marker; in the text the sentence is item e) of GR3)
```

The §8.8.4.4.2 general format lists BOOLEAN among the class condition's fourteen alternatives (the
transcription's figure note records every one as an underlined required word — render the page with
`scripts/render-spec-page.py` before implementing, as for any load-bearing diagram).

## The mechanism

Two arms, both missing: the class-condition grammar rule (the alternatives it enumerates omit `BOOLEAN`), and
`ConditionRenderer.RenderClass`'s `ClassKind switch` (arms for `'N'`, `'A'`, `'U'`, `'L'` and the alphabet-name
form; no `'B'`). The predicate the renderer needs already exists since PB230: `CobolClass.IsBoolean` (the
content consists entirely of `'0'`/`'1'`), which `CobolBool.Sending` uses for the §14.6.13.2 rule-1 raise — the
class condition must NOT raise (rule 2's exemption applies to rule 1's twin by the same reasoning PB230
recorded in `docs/COBOLNET_CONDITIONS_EXCEPTIONS_DESIGN.md`).

## Fix shape

Grammar (pre-authorized): add `BOOLEAN` to the class-condition alternatives, edition-gated to 2002+ (boolean
data is a 2002 introduction — `constructs.json` row `boolean-data-2002`; the reserved word already exists).
Binder/renderer: a `'B'` arm rendering `CobolClass.IsBoolean` over the operand's raw window, exempt from the
rule-1 raise. Goldens: a positive at 2002/2014/2023 (a boolean item, an alphanumeric item holding `"0101"`
which is also class boolean by content, an item holding `"01X1"` which is not, and the `NOT BOOLEAN` form) and
the 85 gating diagnostic; `VersionMatrix` sweep per `feedback_edition_gate_sweep`.
