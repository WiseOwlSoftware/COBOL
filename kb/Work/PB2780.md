# PB2780 — wave 1043 A's residue outside its declared set

**Found by** the wave 1043 A implementer (PB2188, PB2191, PB2192, PB2196, PB2201), reported as three leads because each
site lay outside that group's declared set (the same root as PB2679: a Delete's declared set misses the dependencies
its deletions leave dead and the text that names them). **Fixed in train 1043** by the lander, as its own fix-lane
commit (not an R3 cluster commit, so `landing_check.py` attributes it per commit, PB2703).

1. `src/Cobol.Net.Frontend/Cst/SourceSpan.cs` had no reference anywhere once PB2192 deleted `DataDescriptionCst.Span`
   (PB2193 had already deleted `DataReferenceCst.Span`): `git grep -w SourceSpan -- src tests` found only the file
   itself. Deleted. (The `SourceSpan` the design docs mention is the proposed neutral diagnostic location of
   `DESIGN-backend-abstraction.md` / `DESIGN-edition-framework.md`, a different, unbuilt type.)
2. `src/Cobol.Net.Compiler/CompilerDriver.cs` (the comment above `new Binding.EditionContext`) named
   `frontend.TurnEvents`, which PB2196 deleted; it now names `frontend.Directives`, the record the `Bind` call below
   it passes.
3. `Frontend.CobolWordsMap` (`src/Cobol.Net.Frontend/Pipeline/Frontend.cs`, after `LineMap`) was a forwarder of
   `Directives.CobolWordsMap` (CLAUDE.md rule 4: no forwarders) whose one reader was
   `tests/Cobol.Net.Tests.Unit/FormatWordDriftTests.cs:80`. That read is now `fe.Directives.CobolWordsMap` and the
   forwarder is deleted. `DESIGN-cobol-words-directive.md` §8 "Threading", which still described the pre-PB65 path
   (`Frontend.CobolWordsMap` → `BinderDriver.Bind(..., cobolWordsMap)` → `VersionConformancePass.Run(..., cobolWordsMap)`),
   now describes the current one: `DirectiveResults.CobolWordsMap` → `BinderDriver.Bind(..., directives)` → the bind
   session's `CobolWords`, read by `VersionConformancePass.Run` and `IntrinsicBinder`.

Neutrality: the train's arch oracle and whole-population gate (DEVLOG, train 1043).

- `src/Cobol.Net.Frontend/Pipeline/Frontend.cs#Directives`: the ONE directive output of the front end. Read a
  directive fact through it (`fe.Directives.CobolWordsMap`); never re-add a per-member forwarder.
