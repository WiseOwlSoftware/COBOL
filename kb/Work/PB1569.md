# PB1569

Found 2026-09-24 by the golden-lane-2 misc-p34 refuter on pin f0d582ccd; **re-probe first**. Repro:
`<scratchpad 9db39f61…>\gl\run\misc-p34-refute\f.cob` → prints `01`, expected `02`.

Rule: §13.18.57.4 GR1 drops the type's own alignment and GR2 d) applies the alignment of a level-1 item; per §8.5.1.6.3 a
bit group following a same-level bit item would start at the next BIT, but a level-1 bit group starts at the first bit of
a BYTE. (cite.py --check both before quoting.)

Fix: the TYPE expansion must compute the expanded subject's offset with level-1 alignment (the layout pass, not the
TYPE copier); sweep SAME AS (§13.18.49) for the same alignment question. When fixed, GR-13.18.57.4-2 gets a d) leg
(`BLR=02`) added to the golden-lane draft `2002/l1c34_…type…` (misc-p34), which today pins a)–c) only.
