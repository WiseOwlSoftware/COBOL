# PB5713 - a level-88 entry written with VALUE ... FROM (subscripts) [TO ...] (the data-item VALUE formats 1 and 2) is accepted, and SET of it to TRUE crashes the compiler with ArgumentOutOfRangeException in SetEmitter.EmitSet (2002 and 2023)

**Sites:**
- src/WiseOwl.Cobol.Compiler/Binding/DataBinder.cs#BindCondition
- src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/SetEmitter.cs#EmitSet (line ~391, the crash)

**Mechanism.** DataBinder.BindCondition has no screen of the table phrase (the non-88 arm has the SR33 mirror), so FROM/TO phrases bind into a condition with no values; SET cond(n) TO TRUE then indexes an empty value list.

**Inventory.** Rows claimed: `2002-SR-13.16.61.2-9`.

**2023 row:** SR-13.18.63.3-37, recorded DOCUMENTED-NON-SUPPORT in tests/version-matrix/inventory/SR-13.18.63.3-37.json, contradicted by this repro at --std 2023 (no inventory record is changed by this note; a separate landing does that).
