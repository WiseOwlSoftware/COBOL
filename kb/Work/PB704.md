# PB704 — OPEN — a required word that the grammar treats as a name

Found 2026-09-05 by the `PB678` implementer (report §"New defects" N1) while writing its SORT goldens: any SORT
with the phrase, at `--std 2002/2014/2023`, draws `error COBOLNET0901: 'ORDER' is a reserved word in COBOL-2002 and
cannot be used as a user-defined word (ISO §8.9)`. It compiles at `--std 85`, where ORDER is not yet reserved.

## The rule

§14.9.40.2 (`cite.py --check 14.9.40.2 "DUPLICATES"` → OK; the format prints `[ WITH DUPLICATES IN ORDER ]`, DUPLICATES
underlined) and MERGE's §14.9.24.2 twin make ORDER a required word of the phrase; §8.9 (`--check 8.9 "ORDER"` → OK)
reserves it from 2002. A reserved word appearing in its own general format is not a user-defined word. The phrase is
the only way a program can demand §14.9.40.4 GR3's release-order tie-break over GR4's undefined order.

## The mechanism

`src/Cobol.Net.Frontend/Grammar/Core/CobolIO.g4` ≈725: `sortDuplicatesPhrase : WITH? DUPLICATES IN? cobolWord?` with
the comment "cobolWord matches ORDER (not a lexer token)"; it parses, then the reserved-word screen refuses the
matched `cobolWord`. Same family as [[PB693]] (a reserved word admitted to the name slot unguarded — there the word IS
a token; here it is not one at all) and [[PB655]]/[[PB657]] (the reserved-word funnel's reach).

## Fix

An ORDER token in this position (the lexer/`cobol-words.json` row with the 2002 reservation, `reservationGated` so
the 85 lane keeps accepting it as a name elsewhere — PB693's drift test then covers it), or an exemption at the
screen for a word matched inside its own format; the token is the honest shape. Sweep (rule 4): every other
general-format position where a RESERVED word is spelled as `cobolWord` in the grammar — `grep -n "cobolWord" src/
Cobol.Net.Frontend/Grammar/Core/*.g4` against §8.9's list — and pin each with a positive golden at 2002+ and the 85
behaviour measured. A positive golden with `WITH DUPLICATES IN ORDER` whose expected order is GR3's (records equal on
every key in release order), at 2002 and 2023.
