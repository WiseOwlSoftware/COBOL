# PB2881 — a landing-gate valley measured but not removed

**Source:** PB2880 (wave 1050 A, measured 2026-10-09 with the counter API; report w1050a-PB2880-report.md), lead 1.

**Measured:** the Conformance leg is latency-bound, not thread-bound: alone and warm it ran 122/80/54/64 s in four runs (32/64/32/64 xUnit threads) with the host at 40-50 % and ~26 tests in flight, each spawning dotnet prog.dll; in the lander gate its tail after Unit ends runs at 22-40 % for 30-65 s.

**Code site:** `tests/Cobol.Net.Tests.Conformance/CompilerUnderTest.cs:51` (`CutRunner.RunExit`).

**What closes it:** Thread count is noise against host state, so the leg waits on something per test. Measure where each run waits (process creation, the real-time scan, the cache copy) before changing anything; compare runs only in the same host state (PB2880 Landing: Conformance alone varies 54-122 s on host state).

**Rule:** none (process tooling, no ISO clause).
