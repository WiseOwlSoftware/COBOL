The source wrote a data-name that happens to be reserved. The message reports a clause problem, so it points away from the cause. Re-probe on the current build, because PB4239's COBOL-WORDS hints touch the neighbouring code, then make the message name the reserved word.

**Sites:** `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs#ClosedFormatResidue`, `Cst/ClosedFormats.cs#Refusal`.

## Landed (wave 20261865 group E)

Re-probed on a fresh build: `01 MOVE PIC X.` (and `77`, `66`, `88`, a subordinate `05`, `LINKAGE`/`LOCAL-STORAGE`, `TO`, `ZERO`, `IF`, `ADD`, `SECTION`) drew COBOL1941 "'MOVE' is not a clause of the data description entry", and `01 JSON.` drew COBOL0313 plus that same residue sentence. ISO 13.16.3 SR4: "the entry-name clause shall immediately follow the level-number" and, without it, the entry is a filler, so the first word after the level-number is read as the name and as the first clause; a word that is neither is a name written (8.3.2.1 1), "Reserved words shall not be used as user-defined words or system-names"). Root cause: `ReservedWordUse` and hint 0g both yielded to `ClosedFormatResidue`, which read the name slot as a clause position only, and `ReservedWord` limited the COBOL0901 report to verbs and reservation-gated words.

Fix: `OffendingPosition.EntryNameIsDue` (`ClosedFormats.EntryNameDueAfter` plus the previous token being the entry's level-number) marks the slot; `ClosedFormatResidue` returns null for a reserved word there that is a name violation (`CobolParserCoreBase.ReservedAsAName`: a word 8.9 reserves at the edition, any keyword at a name slot via `WordScope.AnyReservedWord`, or an extension word of the 4.2.10 register); `ReservedWordUse` reports COBOL0901; an extension word other than JSON/XML (ENTRY) draws the COBOL0313 sentence through `ExtensionReservationSentence`, now shared with the JSON/XML hint. The word after a name or a clause keeps COBOL1941. Goldens: `conformance-suite/cases/8.3.2.1-General/pb4604-entry-name-*` (three refusals, each at all four editions) and `13.16-Data-description/pb4604-clause-keyword-at-the-entry-name-slot` (accepted guard); unit `ClosedFormatReservedWordTests.ReservedWordAtTheEntryNameSlot_NamesTheReservation`. Design: `docs/rearchitecture/DESIGN-frontend-grammar.md`, "The entry-name slot".

**Sites (as landed):** `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs` (`ClosedFormatResidue`, `ReservedWordUse`, `OffendingPosition.EntryNameIsDue`, `GuessCobolIntent` hint 0, `ExtensionReservationSentence`), `src/WiseOwl.Cobol.Frontend/Cst/ClosedFormats.cs` (`EntryNameDueAfter`), `src/WiseOwl.Cobol.Frontend/Parsing/CobolParserCoreBase.cs` (`ReservedUserWordViolation`, `ReservedWord`, `ReservedAsAName`, `ExtensionReservedWord`).
