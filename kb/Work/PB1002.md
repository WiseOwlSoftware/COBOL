# PB1002 — OPEN

## Repro — measured
`scratchpad/reg12/q06_linesr.cob`: `RD RP PAGE LIMIT 10 LINES. 01 DL TYPE DETAIL LINE 20.` and `RD RQ. 01 DQ TYPE DETAIL
LINE 3.` → compiles, prints `COMPILED`.

## The rules
`OK  §13.18.35.3 3)` — "Neither integer-1 nor integer-2 shall exceed the page limit, or 9999 if the report is not
divided into pages."
`OK  §13.18.35.3 5)` — "If the report is not divided into pages, all its LINE clauses shall be relative."

## What the fixer owes
Two screens in the Report Writer binder's LINE pass, each a negative golden. The page-limit value is already in the RD
model; reuse it rather than re-deriving (PB1003 records the placement arithmetic already written twice).

## Landed — 2026-09-22 (wave 54 E, with PB1001)

Re-probed first on the worktree's own build: `q06_linesr.cob` still printed `COMPILED`. After: both RDs are refused
on COBOLNET2199 — `integer-1 20 exceeds the page limit 10 … (ISO §13.18.35.3 SR3)` and `the report is not divided into
pages, so all its LINE clauses shall be relative — LINE 3 is absolute (ISO §13.18.35.3 SR5)`.

- **One screen** — `DataBinder.Reports.ScreenReportLineClauses`, once per WRITTEN LINE clause over the flat entry
  array, reading the RD's page model (`ReportModel.Paged` / `PageLimit`, bound before the groups) — the value the
  NEXT GROUP clause's SR1 screen reads, not a re-derivation. It also carries PB1001's SR7/SR8.
- **SR5 and the bare operand** — ⚠ DETERMINATION: the bare `ON NEXT PAGE` operand is not the relative FORM, so it is
  refused in an unpaged report (the §13.18.37.3 SR3 reading of NEXT GROUP NEXT PAGE; docs/CONFORMANCE.md).
- **Overflow** — a LINE integer too large for an `int` no longer throws in `int.Parse`: `LineInteger` saturates and SR3
  reports it.
- **Sweep** — every non-negative corpus and NIST program with a REPORT SECTION (46) was compiled on this build: none
  trips the new screens.
- **Goldens** — negatives `pb1002-line-beyond-page-limit` (SR3), `pb1002-unpaged-absolute-line` (SR5, absolute),
  `pb1002-unpaged-next-page` (SR5, bare operand); all reject at every edition.
- **Rows** — SR-13.18.35.3-3 and SR-13.18.35.3-5 closed CONFORMS (batch `scratchpad/w54e/PB1001/batch.json`).
