# PB3970 — the Format-1 BY CONTENT literal/grouped screen is unpinned

**Site:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CallBinder.cs:311` (the `!formatTwo && (cBool ... || cBareLit
... || cGrouped ...)` screen).

Filed 2026-10-27 by the enqueue unit's clerk from the PB3760 review report. No wrong answer today.

## The gap

Commit e59657dfb gave the Format-1 BY CONTENT screen `cBareLit` and `cGrouped`, so a literal or a parenthesized
expression that the operator-free boolean node holds is refused as its written spelling is (Format 1 admits
`{ identifier-2 } ...` only). No golden pins that arm: every new golden is Format 2 (AS NESTED). In the note scenario
(`BY CONTENT "AB" BY CONTENT B1 B-AND B2`) the CALL is refused by its second argument anyway, so reverting the added
terms leaves the suite green.

## To do

A Format-1 golden per arm whose refusal can only come from the added terms: a bare literal and a grouped expression
that the boolean node holds, each as the sole BY CONTENT operand. Each seen RED with the terms reverted.
