# PB6124 - the REPLACE pair reader of the suite harness is partial

**Site.** `conformance-suite/harness/cobol_source.py:374` `_split_on_by`. It accepts only one-token or pseudo-text operands (no qualified or
subscripted identifiers); one unparsable pair drops the whole phrase; REPLACE ALSO / LEADING / TRAILING / LAST OFF (2002 and later) yield no
pairs. Not a regression of PB3178: the fallback is the old unreplaced classification. Fix by parsing the REPLACE operand grammar rather than
splitting on BY.

**Docstring.** The `_statement_end` docstring (`cobol_source.py:372`) cites §2023:7.2.3.2 for the rule that pseudo-text holds any text words.
7.2.3.2 is the COPY statement's general format; the sentence is in §2023:7.2.2.4 (Pseudo-text), which also covers the REPLACE statement
this function serves. Check with `cite.py --check` before correcting.
