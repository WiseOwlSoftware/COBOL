# PB5242 - at --std 85 the Report Writer accepts the 2002 and 2023 additions to its clause formats: CODE IS, PAGE ... COLUMNS and LAST CONTROL HEADING and IS and the DE/CH spellings, NEXT GROUP ... WITH RESET, TYPE CH ON and OR PAGE, the bare LINE NEXT PAGE, and SUM OF, ROUNDED and an arithmetic-expression addend all compile

**Sites:**

- `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolReportWriter.g4` (`reportCodeClause`, `reportPageClause`, `reportPageSubclause`, `reportGroupEntry`: the 2023 formats)
- `src/WiseOwl.Cobol.Compiler/Validation/VersionConformancePass.cs` (`VisitReportGroupEntry`, `VisitReportLineClause`, `VisitReportSourceClause`: the Report Writer edition arms, which have none for CODE IS, the PAGE additions, NEXT GROUP WITH RESET, TYPE CH ON / OR PAGE, the bare NEXT PAGE operand of LINE, SUM OF / ROUNDED / expression)
- `src/WiseOwl.Cobol.Compiler/Binding/ReportSectionBinder.cs` (`BindReportDescriptionClauses`, `GroupLimits`: the accepted phrases then change the 1985 page regions)

**Mechanism.** The Report Writer grammar is the 2023 format, and each 2002 or 2023 addition is refused at --std 85 only where `VersionConformancePass` has an arm for it. kb/Work PB3964 gated FILLER, `+`/`-` and SOURCE expressions, and its "Residue (not gated)" section named OR PAGE, SUM OF / ROUNDED / expression with no open note owning them; the code read of slices 50-52 found the rest. Once accepted, an addition also runs with its 2023 meaning, which then reaches the 1985 rules around it: OR PAGE moves the body-group upper limit off FIRST DETAIL by the 2023 rule (a 1985-legal detail `LINE 5` with `FIRST DETAIL 5` is then refused, COBOL2199), and LAST CONTROL HEADING bounds a control heading apart from LAST DETAIL (a legal CH `LINE 10` with `LAST DETAIL 12` is refused, or a control heading moves to the next page). ROUNDED changes the sum presented (3.6 where the MOVE gives 3.5). A program without the additions is unaffected, so the harm is an under-rejection.

**Found by.** The 1985 code read, slices 50-52, and the slice-51 refuter (the bare `LINE NEXT PAGE`, which OVERTURNED `1985-GR-XIII.3.15.4-1`).

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the code read's non-conforming verdicts of slices 36-56 wait in `E:/COBOL-coord/scratch/coderead-85/pipe-for-register.json`.
