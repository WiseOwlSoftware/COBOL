The decisions, one line each:
- Tests: every script's tests leave the script, into `<root>/selftests/<path>/<name>/` (fixtures.py plus one
  `test_<world>.py` per fixture world, one `case_` per case), reached through `selftest_cases.subject(__file__)`, found by
  the runner's existing rule (b), held by `scripts/selftest_layout.py` which the runner calls first, with an exact
  `REMAINING` ratchet that stops any new in-file self-test; every `--self-test` handler is deleted with its conversion and
  the runner's rule (a) for Python goes in the last step (§16.2).
- Splits, hottest first: `gate.py` in two steps (modules, then the 944-line `Gate` class), `inert_lane.py` (new),
  `land_lane.py` (adds `lane_bounce.py`), `enqueue.py`, `prune_worktrees.py`; every definition of today's files assigned
  (§16.4–§16.7, §16.12); `Say` is `coord.py`'s once.
- `docs/CONFORMANCE.md`: one reader first (`conformance_source.py`, step A), then one file per entry under
  `docs/conformance/<section>/` for every keyed entry, §7 and §8 rows included; the whole is a gitignored rendered view;
  citations unchanged and checked by the renderer (§16.8).
- The three design documents PB3726 named are NOT split: 14, 0 and 1 dispatch holds and no conflict brief in 14 days
  (§16.13).
- `PublicAPI.Unshipped.txt`: no driver; the file kept in the analyzer's order and the baseline rules in one module with a
  gate audit, so plain git merges two branches' symbols (§16.9).
- Sequencing: one PB3726 step per wave in one `blocked_by` chain, pairs only at tiers 2 and 3 (§16.10).
- Out of scope, with homes: §16.13; the compiler-side hold concentrations are kb/Work PB5410 (analysis) for the
  architecture review.
