# PB5969 - the program differential carries nothing when the harness key changes

**Rule** (`scripts/gate_differential.py`, kb/Work PB4333): a Conformance case whose program bytes, diagnostics, manifest entry and named files equal those of
a passed case at the SAME harness key is carried, not run.

**Evidence** (`gate.log` of each run under `E:/COBOL/.claude/worktrees/*/TestResults/build-local/*20261120*/`, line "program differential (kb/Work PB4333)").

Runs that carried **0** (reason in the log: "17,754 no pass stands at this harness key", the harness key had just changed, so "Conformance runs whole"):
listing-step-9 000001 (key 570ff050ee58); listing-step-6b-r2 000001 (3baaf02b2c1e) and 000002 (97d1ab4d25b1); listing-step-6b-r3 000001 (171a6225c9fd);
listing-step-6b-r4 000001 (ed0b982b1366); listing-step-6b-r5 000001 (d1bd12d62627); listing-step-pb5947 000001 (c03ea385b70a); listing-step-pb5949 000001
(682382e53bd4), 000003 (1ff2ac50fee4), 000004 (356cb06a0844), 000005 (67d58fd500d0); listing-step-pb5941 000002 (7f6261e319e7); listing-step-9b 000002 and
000003 (c785bd3faec7). Each time the run then recorded 17,754 passes at the new key.

Runs that carried cases: listing-step-pb5950 000001 and 000002 (key c03ea385b70a, 11,412 carried, 16,776 run; 6,342 had "no pass at its digest");
listing-step-6b-ids 000001 and 000002 (11,412); listing-step-pb5948 000001 (570ff050ee58, 11,412); and the SECOND run at an unchanged key:
listing-step-6b-r1 000003 (75c9baecaffa, 17,754 carried), listing-step-pb5941 000003 (17,750), listing-step-pb5949 000002 (17,750). So the differential
helps only on a re-gate at an unchanged harness key, or on a branch whose key equals a key already recorded on this host.

**Observation to establish:** which inputs make the harness key change from head to head within one branch (listing-step-9b: 000002 and 000003 stayed at
c785bd3faec7, yet carried 0 because the record was not yet published until the end of 000003; listing-step-pb5949 moved its key on every run). If the key
includes the compiler or test sources, every code change forces a full 28,000-case run; the differential's carry rule is per case digest, and a
per-case digest that covers the harness's inputs would carry across harness changes the case does not read.

**Fix shape:** identify the key's inputs (`scripts/gate_differential.py`), and replace the single key by per-case dependencies where the case's result
cannot depend on them; a drift test, not a wall-clock limit.
