# PB1526 — LANDED

## Landed (wave w0930-numeric — one bundled commit with the seven siblings of this note)

Re-probed first on the implementer's own build: `FACTORIAL(X / 2 + 1)` with X = 5 answered 6 (FACTORIAL(3)) with `ES=` blank under
`>>TURN EC-ARGUMENT-FUNCTION CHECKING ON`, exactly as filed.

**Root cause.** Two holes, one rule: the compile-time screen can only refuse an argument that is PROVABLY non-integral and fails
open on the rest (by design — `IntrinsicArgumentRules.NotAlwaysIntegral` is sound, not complete), so the VALUE is the rule's
real test, and the run-time intake truncated on EVERY carrier (`AsInt`/`AsIntWide`'s `NumRescale` Truncation, the SDIDI
`DecToUnscaledIntermediate(…, "0", Truncation)`, `IntegerArgReal`'s `Math.Truncate`, `TryIntegerArg` / `TryTotalIntegerArg`).
**Fix (one mechanism):** `CobolIntrinsics.IntegerArg{Scaled,Dec,Real}` and the wide twins ask the exact-value integrality
predicate (`CobolNum.HasFraction`, the new `CobolDec.HasFraction`, binary64 `v != Math.Truncate(v)`) through ONE raise site
(`RequireIntegral` → EC-ARGUMENT-FUNCTION, §15.3's closing paragraph) before the truncating narrowing; checking off keeps the
truncated integer as the implementor-defined result. `RuntimeApi.IntegerArgOf` is the one builder; `IntrinsicRenderer.AsInt`
and `AsIntWide` collapsed into `IntegerIntake(NumX, wide)`, total over `NumXCarrier` (PB638's missing arm came free). The static
screen is left fail-open — its soundness is its whole design and the run-time test makes it safe.
Citations (`cite.py --check`): §15.3 type 6 OK `15.3 6)`; §15.3's EC-ARGUMENT-FUNCTION sentence OK (locator prints `15.3 14)`,
the paragraph follows the list); §5.5 3) a) OK. Golden `2023/pb1526_integer_argument_has_integral_value`; units in
`IntrinsicCarrierAgreementDriftTests`.

**Siblings swept:** every integer intake in `CobolIntrinsics` (`IntegerArg`, `IntegerArgReal`, `IntegerArgWideReal`,
`TryIntegerArg`, `TryTotalIntegerArg` — the TOTAL TEST-DATE / TEST-DAY / FIND-STRING / RANDOM / BOOLEAN-OF-INTEGER arguments
are still "shall be an integer"), the renderer's `IntArg` / `IntArgWide` / `ArgInt` / `ArgIntWide` callers (all funnel into
`IntegerIntake`), and the subscript / ref-mod / SET intakes — which already test integrality but through a 9-fraction-digit
temporary, a SECOND divergence of the same predicate found here and filed as PB1890.

## Repro (re-probed by the registrar, Debug build of `0caa7d5`, `--std 2023`)

```cobol
       01 X PIC 9 VALUE 5.
       PROCEDURE DIVISION.
      >>TURN EC-ARGUMENT-FUNCTION CHECKING ON
           DISPLAY FUNCTION FACTORIAL(X / 2 + 1).
           DISPLAY "ES=" FUNCTION EXCEPTION-STATUS.
           DISPLAY FUNCTION FACTORIAL(X * 0.5).
           DISPLAY FUNCTION ORD(FUNCTION CHAR(X / 2 + 64)).
```

Observed: `6`, `ES=` (blank), `2`, `66`. Expected: `X / 2 + 1` = 3.5 and `X * 0.5` = 2.5 are not always integral, so either the
bind-time screen refuses them (as it does `FACTORIAL(X / 2)`: COBOLNET1627) or, with checking enabled, the non-integer value
raises EC-ARGUMENT-FUNCTION (fatal) — never a silent FACTORIAL(3). `CHAR(66.5)` silently returns ordinal 66.

## Two holes, one path (code sites)

1. **Static** — `src/Cobol.Net.Compiler/Binding/IntrinsicArgumentRules.cs` (`NotAlwaysIntegral` / `CollectAdditive`) checks a
   quotient only at the ROOT of the argument expression and treats a non-additive subtree as opaque, so a division or a
   fractional-literal product nested in an additive spine fails open. This is the data-item sibling of PB617 (literal-only spines).
2. **Runtime** — `src/Cobol.Net.Runtime/Intrinsics/CobolIntrinsics.cs#IntegerArgReal` is `(long)Math.Truncate(v)` and the Int128
   intake narrows the scaled value, so the fraction is discarded and EC-ARGUMENT-FUNCTION is never set. The fail-open design of (1)
   is only sound once (2) exists.

The subscript and reference-modification general rules DO test integrality at run time (`EC-BOUND-SUBSCRIPT … 2.500000000 is not an
integer`), so the de-facto native-arithmetic definition ("the exact scaled value has a zero fraction", §5.5 3) a) is already made —
its documentation is DOC-A.1-124 (PB1534 / PB1535). Row GR-5.5-3 recorded **PARTIAL**.
