# PB493

## Mechanism — sign-clause
sign-group-inheritance-display-only-citation

### Expected, from the standard
GR1 says the clause applies 'for each numeric item subordinate to the group to which it applies', with exactly one narrowing -- 'The SIGN clause applies only to numeric items whose picture character-string contains the symbol S'. It states NO usage condition. The only usage restriction in §13.18.52 is SR2, and SR2 governs 'an elementary item for which the SIGN clause IS SPECIFIED' -- the item whose own entry carries it -- not an item the clause merely applies to; SR2 also admits `national`, which the filter excludes.

```
$ python scripts/spec/cite.py --check 13.18.52.4 "The SIGN clause applies only to numeric items whose picture character-string contains the symbol S"
  OK  §13.18.52.4 1)  (General rules)
```

### Observed
The inheritance pass applies the group clause only where `item.Pic is { Category: PicCategory.Numeric, Signed: true, Usage: Usage.Display }`, so `01 G SIGN IS LEADING SEPARATE. 05 A PIC S9(4) USAGE COMP VALUE -12.` silently keeps its 2-byte binary form. The BEHAVIOUR is very probably the correct determination -- it is what the surveyed implementations do, and §13.18.60.4 defines no separate-sign representation for a binary or packed item -- so this is filed as a citation and a determination defect, not a behaviour change request. What is wrong is the JUSTIFICATION: the code asserts '§13.18.52 applies only to usage-display items' (DataBinder.cs:3411, echoed in the InheritSignClauses summary at :3431), and §13.18.52 says no such thing -- a real clause answering a different question, the shape that has shipped gaps here before. If the DISPLAY-only narrowing is the intended determination it needs to be recorded as one (which rule licenses it, and what happens under `national` once national-form numerics land -- SR2 admits that usage and the filter would silently drop it too; that arm is unreachable today only because a signed numeric NATIONAL item is COBOLNET0899). Related and worth the same pass: nothing in the corpus tests a group-level SIGN clause at all -- every SIGN declaration under tests/ is on an elementary item -- so GR1's central mechanism, and GR2's and GR3's precedence rules with it, are carried entirely by probes.
