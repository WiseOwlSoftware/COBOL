# PB3749 — SequentialJournal's Held message names one of three causes

**Sites:** `src/Cobol.Net.Runtime/IO/Sharing/SequentialJournal.cs#Begin`, `src/Cobol.Net.Runtime/IO/Sharing/SidecarLockFiles.cs#Publish`, `docs/rearchitecture/DESIGN-runtime-library.md` (2.2.2.5 R1), `tests/Cobol.Net.Tests.Unit/SequentialJournalHolderPublicationTests.cs`.

After PR #575 (PB3675) the Held refusal message in `SequentialJournal` (and the matching sentence in `DESIGN-runtime-library.md` 2.2.2.5 R1 and the `Begin` comment) attributes every lost try to another run unit removing the lock directory. `SidecarLockFiles.Publish` also counts a try lost when a tester reaps the pending file (`FileNotFoundException`, `LockFileState.Gone`) or holds it as it is locked or renamed (a sharing refusal). Reword the message, the design sentence and the comment to name the three causes (or "the pending file was reaped, held or removed"); fix them together so there is one wording (the `RegionLockResult` PB3675 carries can name the cause). Confirm each cause against `Publish` before rewording.

(2026-10-25, review R1-1, severity low.)

**Landed (2026-10-25):** the Held refusal in `SequentialJournal.Begin`, its comment, the `Held` remark of `SidecarLockFiles.Publish` and `DESIGN-runtime-library.md` 2.2.2.5 R1 now name the three ways `Publish` loses a try (lock directory removed, pending file reaped, pending file held as it was locked or renamed), confirmed against its catch arms and its `Gone` probe arm; `SequentialJournalHolderPublicationTests` asserts the wording.
