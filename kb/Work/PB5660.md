# PB5660 - a cascaded COBOL0809 after the inline-invocation refusal at 2002

**The lead.** "pb428 at 2002 fails COBOL0809 (MOVE of an object operand) after the inline temp; check 2002 MOVE rules (cases pb428-inline-invocation-returning-active-class)."

**Repro run once (2026-11-15, Debug `cobol.exe` dated Nov 8, older than main):** the golden `conformance-suite/cases/8.4.3.4-Inline-method-invocation/pb428-inline-invocation-returning-active-class.cob`
(free form, `refuse-at: [2014, 2023]`, expect COBOL2140) compiled `--std 2002 --source-format free` gives, at 32,12:
`error COBOL2140: the inline method invocation of "CLONEME": the invoked method's RETURNING item is described with the ACTIVE-CLASS phrase (ISO §2023:8.4.3.4.3 SR4)`
AND `error COBOL0809: a MOVE operand shall not be of class object - ... (ISO §2023:14.9.25.3 SR1). Use SET to assign an object reference`.
Two defects visible: (1) the first diagnostic cites a 2023 SR and fires at 2002, where PB5598 established the ACTIVE-CLASS ban is a 2014 addition (`§2002:8.4.2.4.2 SR4`
bans only ANY LENGTH: `cite.py --check` OK, "shall not be described with the ANY LENGTH clause"), so the refusal should not fire at 2002 at all unless PB5598's BASE-only gate
leaves this user-method case (the lead's own question); (2) the COBOL0809 is a cascade: the statement's inline temporary is typed as an object operand of a MOVE, which
the 2002 MOVE rules are read for ("check 2002 MOVE rules": `§2002:14.8.24.2`'s MOVE operand rules, found with `cite.py --edition 2002 --find`). The fixer decides
whether 2002 legally compiles this program (then both go) or refuses it (then one diagnostic, not two, citing 2002).

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/MoveTable16.cs` (`MoveTable16.Sr1ClassRefusal`)
- `src/WiseOwl.Cobol.Compiler/Binding/CompilerTemps.cs` (`CompilerTemps.ForInvocationObject`)
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/OoBinder.cs` (`OoBinder.OoBindSetObjectRef`)

(The COBOL2140 site is the inline-invocation binder that PB5598 gated for BASE New / FactoryObject; the fixer names the member that raises it for a user method with `git grep -n COBOL2140 src` and adds it here.)

**Sibling sweep.** A refusal that leaves its statement half-bound so a second diagnostic fires from the leftover temp (the cascade pattern): every refusal arm of the inline invocation binder binds an error expression, never a typed temp. Add a golden at `--std 2002` for this case.
