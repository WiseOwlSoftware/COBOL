# PB4221 — the doc of BoundHoldTableAll.Count omits the dynamic-capacity arm

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Bound/BoundHoldTableAll.cs:22,26` (`BoundHoldTableAll`, its summary and the
`Count` param doc), read against `src/WiseOwl.Cobol.Compiler/Binding/Procedure/SendingValueTemp.cs:617`
(`SendingValueTemp.FreezeTableAll`) and `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/TableHoldEmitter.cs:36`
(the emitter branch on `Held.Counts is [AllCount.Capacity]`).

**Mechanism.** The summary says a non-fixed count is held in `Count` as an `AllCount.Odo`, and the param doc says `Count` is
null when the count is static. `FreezeTableAll` also leaves `Count` null for the dynamic-capacity arm, whose count is the
held table's current capacity (`AllCount.Capacity`), and `TableHoldEmitter` branches on `Held.Counts` being
`[AllCount.Capacity]`, not on `Count`. The next implementer reading the doc would conclude a null `Count` means a static
count and could mishandle the capacity arm.

**Fix direction.** Correct the summary and param doc to name the three arms (static, `AllCount.Odo` held in `Count`,
`AllCount.Capacity` with `Count` null). Not the same mechanism as PB4220: that is duplicated construction code, this is a
doc that omits an arm.
