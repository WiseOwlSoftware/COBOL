**Mechanism.** §1985:VI.6.2.3 GR5 c raises the size error only "If no real number exists as the result of the evaluation". `CobolIntrinsics.CheckPowRule6`, the one screen every ** reaches, raises it for every negative base with a non-integer exponent, the 2023 rule, with no edition arm. NumericRenderer.Power lowers every ** to the exact power (CobolExact.Pow, integer exponent) or the native one (PowNativeReal), and both ask the one screen CobolIntrinsics.CheckPowRule6 first; no edition reaches it differently. a) conforms (0 ** 0 and 0 ** -1 are size errors, 0 ** 2 and 0 ** 0.5 are 0) and b) conforms (4 ** 0.5 is 2, 16 ** 0.25 is 2: the principal root); the witness runs one case of each. c) is implemented as the later, stricter rule: CheckPowRule6 raises the size error for EVERY negative base with a non-integer exponent (§2023:8.8.1.2 GR6 c: 'If the value of an expression to be raised to a power is less than zero, the evaluation of the exponent shall result in an integer'), where 1985 raises it only when no real result exists.
