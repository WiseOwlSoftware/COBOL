# PB1096 — OPEN — the declined APPLY COMMIT clause's grammar encodes §12.4.6.3.3 SR4 as syntax (`APPLY COMMIT ON? dataReference+`), so the zero-operand spellings the §12.4.6.3.2 

## Rule text (every citation re-run by the registrar)
- `python scripts/spec/cite.py --check 12.4.6.3.3 "At least one file or data-item shall be specified"` → `OK  §12.4.6.3.3 4)  (Syntax rules)`

### Adjudicator finding (apply-commit-clause, harm silent)
- **Mechanism:** The declined APPLY COMMIT clause's grammar encodes §12.4.6.3.3 SR4 (at least one operand) as syntax (`dataReference+`) although the §12.4.6.3.2 general format makes the whole operand group an optional repetition, so the zero-operand spellings never match applyCommitClause and fall to a generic parse error instead of the named declined-facility refusal COBOLNET1709.
- **Repro:** --std 2023, I-O-CONTROL paragraph containing `APPLY COMMIT ON.` (or `APPLY COMMIT.`), with a SELECT F and FD F present. Pinned cobol.exe: `(9,27): error COBOL0001: unexpected '.'` / `(9,24): error COBOL0001: unexpected '.'`. Contrast `APPLY COMMIT ON F W.` -> COBOLNET1709.
- **Expected (spec):** §12.4.6.3.2 `APPLY COMMIT ON [ [ file-name-1 ] [ identifier-1 ] ]…` admits zero operands syntactically; SR4 (§12.4.6.3.3) forbids it semantically. Because the clause belongs to the declined Annex A.4.3 module (item 2), the recognized clause should draw the SAME named refusal COBOLNET1709 as every other spelling (the recognize-and-refuse-by-name posture docs/CONFORMANCE.md A.4.3 documents), i.e. grammar `APPLY COMMIT ON? dataReference*` with SR4 left to the binder/declined pass.
- **Observed:** Probed on the pinned compiler: zero-operand forms answer COBOL0001 at the period; one-or-more forms (with/without ON, any file/identifier mix, qualified+subscripted) answer COBOLNET1709. The source is illegal either way (SR4), so no legal program is rejected; the harm is that the refusal does not NAME the declined feature, the exact failure mode PB695 fixed for the ON-less spelling. Harm flag 'silent' is the closest enum value for a wrong-diagnostic-only defect.
- **Code site:** src/Cobol.Net.Frontend/Grammar/Core/CobolDeclined.g4#applyCommitClause (line ~235: `APPLY COMMIT ON? dataReference+`)
- **Clause (adjudicator):** 12.4.6.3.2 (with 12.4.6.3.3 SR4; Annex A.4.3 item 2)
