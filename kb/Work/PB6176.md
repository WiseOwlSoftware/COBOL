# PB6176 — the 2002 stand-in leaks into printed spellings

**Mechanism.** PB5702 screens a 2002 user-defined word with 2002 Annex B/D rules; a word holding a character 2002 does not fold is
rewritten to a Reserved stand-in for comparison. Readers that need the written text were repointed, but the diagnostics that print a
word's spelling (`Spelled`, PB4312; the COBOL1639 undefined-name message) and the listing's data map and cross-reference still print
the stand-in. The report says it shares its root with PB4312.

**Repro (from the report).** `--std 2002`, `01 A<U+10A0>B` with `DISPLAY Z<U+10A0>B`: the undefined-name diagnostic and the listing show
the stand-in, not the written word. Unrun here (R2: the lead carries a runnable repro).

**Fix shape.** One reader of "the word as written" for every printed spelling; the design text
(`docs/rearchitecture/DESIGN-frontend-grammar.md` near line 2785) already says which readers see written text and which still show
the stand-in, and changes with the fix (rule 6).

**Also recorded here (same report, lead 2).** COBOL 2014 is still 2023's tables with Annex E reversed; it needs its own Annex B.3.1 / D
transcription. 2014 waits (owner decision), so no work item is opened for it; the PB5702 addendum `2026-11-24-gr4c-fold-is-the-2014-table.md`
records the 2002 side.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.cs:3748` (`DataBinder.Spelled`),
