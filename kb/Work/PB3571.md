# PB3571 — a zero standard-decimal function result prints at its held places

## Lead (round 6 of the PB3538 review, finding R6-1, severity low, category docs)

The PB3538 fix changes the TEXT IMAGE of a standard-decimal function result that is zero or sums with a zero:
`CobolDec.ToFunctionText` renders `-Exp` places (DOC-A.1-92: exactly the result scale), and a zero now keeps its held places, so
DISPLAY, STRING and a `--permissive` MOVE of such a result print `0.00` / `1.000` where main prints `0` / `1`. The reviewer's
reading: the new text is the consistent one (it matches the nonzero neighbour on both builds: `2.51 - 2.50` prints `0.01` on main
and on the branch) and follows DOC-A.1-92, and the value is unchanged. But DOC-A.1-92, the PB3538 DEVLOG entry and the report
state only the comparison effect, and no golden pins the text. The 26 standard-decimal goldens that DISPLAY a function result all
still match.

Site: `src/Cobol.Net.Runtime/Values/Numeric/CobolDec.cs:1158`.

### Reviewer probes (branch a52b59c45 against the main build; `scratchpad/w1153/rev-a6/z1.cob` and `z2.cob`)

- `DISPLAY FUNCTION ABS (Z + FUNCTION NUMVAL ("1"))` with `Z PIC 9V999 VALUE 0` prints `1.000` (main `1`).
- `FUNCTION ABS (FUNCTION NUMVAL ("2.50") - 2.50)` prints `0.00` (main `0`).
- `FUNCTION ABS (Z ** 5)` prints `0.000000000000000` (main `0`).
- `FUNCTION ABS (Z * FUNCTION NUMVAL ("2.5"))` prints `0.0000` (main `0`; with `Y = 0.001` it prints `0.0025` on both).
- `FUNCTION ABS (FUNCTION NUMVAL ("0.00") / 7)` prints `0.0000000000000000` (main `0`).

A user diffing output across the upgrade sees these lines change with no documented reason.

## Fix shape (the reviewer's)

Add one sentence to DOC-A.1-92 (a zero result renders at the places it is held at, as a nonzero one does), one DEVLOG clause, and
pin text legs in a golden (for example `ABS (NUMVAL ("2.50") - 2.50)`). The spec column is empty: no ISO clause was derived for
the text image; DOC-A.1-92 is the documentation row, and the clerk did not judge the text.

## Landing

Lands with PB3538 (its pull request was queued on 2026-10-23); the note closes when the DOC-A.1-92 sentence and the golden are
on main.
