# PB4996 - lineage slice 5: derived bands and the edition-gate drift test

docs/rearchitecture/DESIGN-spec-conformance-review.md §10.2, slice 5. A band is a chain's span, so the conformance suite's band schema (DESIGN-conformance-suite.md §3.5,
slice S5, PB4683) reads the chains instead of hand-written edges, and a 1985 edge's evidence class is the 1985 text.
A drift test holds each `constructs.json` window start and end, and each version predicate of the grammar, to a NEW or
REMOVED edge with its citation.

**Sites:** `docs/rearchitecture/DESIGN-conformance-suite.md` (§3.5), `tests/version-matrix/constructs.json` (whole: the
windows the test reads), `tests/WiseOwl.Cobol.Tests.Unit/` (the drift test, new).
