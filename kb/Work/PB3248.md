# PB3248 — one reserved-word reference, two diagnostics

Filed 2026-10-16 by the enqueue unit's clerk from the PB656 implementer's report
(`E:/COBOL-coord/scratch/reports/w1084b-PB656-report.md`, "New defects (note-ready)"). The report's repro is
`probe/rv.cob` in the w1084b scratch directory; it was not re-run for this filing (R2: a runnable repro and the
sites are given).

**Symptom.** At `--std 85`, `2002` and `2023`, `DISPLAY RECEIVE.` (RECEIVE reserved at that edition) reports
COBOLNET0901 (the section 8.9 user-word message) and then ALSO `COBOL0001: unexpected '.'` at (7,27). The
declaration of the word on line 5 is not the one reported; the reference is. Harm: noise only, the program is
refused anyway (`process_only`).

**Code sites.**
- `src/Cobol.Net.Compiler/Validation/VersionConformancePass.cs:2583` `VisitCobolWord`, the funnel that raises
  COBOLNET0901 for a reserved word in a user-word slot (reporter `FlagReservedUserWord`, `:2695`).
- `src/Cobol.Net.Frontend/Grammar/CobolParserCore.g4:185,869,887` and `Grammar/Core/CobolData.g4:273`: the generated
  `reservedGatedWord` alternative (from `cobol-words.json` `reservationGated`) that re-admits a gated word in a
  DECLARATION slot but not in a statement operand slot.
- `src/Cobol.Net.Frontend/Parsing/CobolParserCoreBase.cs:620` converts a parse error at a gated word to the
  COBOLNET0901 text; the token that follows (`.`) is then reported separately as COBOL0001 because the statement
  parse was abandoned at the reference.

**Mechanism.** The reference to a gated word is unparseable by design (PB693), so the parser raises one error at
the word and a second at the next token. The listener folds only the first into 0901. The report says this shares
its root with the class-3 parse path PB655 made data-driven (PB655 is landed): rejection of a gated reference and
the recovery that follows are one path, so the fix belongs in the listener's recovery (suppress the follow-on error
for a reference already reported as 0901), not in a per-word grammar edit. The exact recovery site was not traced
for this filing; the implementer owes that.

**Sweep owed.** Probe the other statement operand slots (MOVE, ADD, IF, PERFORM) with a gated word and confirm
each yields exactly one diagnostic.
