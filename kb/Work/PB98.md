# PB98 — LANDED — `MOVE 2,5E+2 TO F` → "no viable alternative at input ','"; `01 F USAGE FLOAT-LONG VALUE 1,5E+3.` → F = 1

> ⚙ **flags:** rejects-legal, wrong-answer, silent · found 2026-08-18 probing [[PB66]] under DECIMAL-POINT IS
> COMMA · **landed 2026-08-18** (DEVLOG 1322, the same change set as PB66).

**Spec:** §12.3.7.4 GR14 a) — under DECIMAL-POINT IS COMMA "the character written in numeric literals to represent
the decimal separator shall be the comma"; §8.3.3.3.3 — a floating-point literal is two fixed-point literals
joined by E, so its significand carries that comma: `1,5E+3` is one literal of value 1500.

**Mechanism:** the lexer had a `FLOAT_BODY` for the dot form only; the comma-decimal FIXED form assembles in the
parser (`INTEGERLIT COMMA INTEGERLIT`) because ',' alone is a token, but the float shape needs its E-tail, and
`1,5E+3` lexed as INTEGERLIT `1`, COMMA, INTEGERLIT `5`, IDENTIFIER `E`, PLUS, INTEGERLIT `3` — a parse error in
a statement; in a VALUE clause `ExtractValue` took the first operand text `1`.

## As built (DEVLOG 1322)

`fragment FLOAT_COMMA_BODY` (`( [0-9]+ ',' [0-9]* | ',' [0-9]+ ) 'E' [-+]? [0-9]+`) with the full twin set the
`SignedLiteralShapeDriftTests` scrape demands — `COMMA_FLOATLIT` (default mode), `FN_SIGNED_COMMA_FLOATLIT` (the
predicated function-argument twin), `SUB_SIGNED_COMMA_FLOATLIT` / `SUB_COMMA_FLOATLIT` (SUBSCRIPT mode, re-typed);
`numericLiteralCore` and `subToken` accept `COMMA_FLOATLIT`; the three token-type consumers
(`CobolParserCoreBase.IsBoolOperandTerm` / `retryPhraseAhead`, `CompileTimeExpressionEvaluator`'s §7.3.3 SR10 bar)
know it. The lexer cannot know the SPECIAL-NAMES clause, so the shape is one token in every mode; the binder's ONE
normalizer canonicalizes it to dot-decimal and reports COBOLNET0895 without DECIMAL-POINT IS COMMA (no dot-mode
program legally spells `<digits>,<digits>E<exponent>`). Golden `2023/pb66_float_edited_comma_mode` (VALUE, MOVE,
COMPUTE, a signed literal inside a FUNCTION argument); negative `pb98-comma-float-literal-without-comma-mode`.
