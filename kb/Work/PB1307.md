## Measured

### Finding working-storage-section — §13.5.4 GR1; §14.6.2.3.3; §3.168 (rejects-legal-source; rows GR-13.5.4-1)

**Mechanism.** BinderDriver.BindUnitData gives the §13.5.4 GR1 static-WS channel only to units with no contained programs, and refuses the rest with COBOLNET0899. A RECURSIVE (non-INITIAL) program that directly contains any program and declares WORKING-STORAGE or a FILE SECTION is rejected outright, even when nothing is GLOBAL. The staged-loud gap (the static fields do not compose with the containee's __outer/GLOBAL ref-bridges, §13.18.27.4 GR2) has no open kb/Work owner: PB168, which widened it to the FILE SECTION, is landed.

**Repro.** probe/ws/p5reccont.cob: P5MAIN CALLs P5REC twice. `PROGRAM-ID. P5REC RECURSIVE.` has `WORKING-STORAGE SECTION. 01 CTR PIC 9(2) VALUE 0.`, does ADD 1 TO CTR, DISPLAY "REC=" CTR, CALL "P5IN", and directly contains the plain program P5IN (DISPLAY "IN"). No GLOBAL item anywhere. `cobol p5reccont.cob --run` (default 2023) fails: error COBOLNET0899: program 'P5REC': a RECURSIVE program that directly contains programs and declares WORKING-STORAGE or a FILE SECTION is recognized but not yet implemented.

**Expected, from the standard.** §13.5.4 GR1: the WS of a program without the initial attribute is static data. §14.6.2.3.3: static data is in the last-used state on re-entry. Nothing in §13.5.3 or §11.10 forbids a RECURSIVE program from containing programs. The program must compile and print REC=01 / IN / REC=02 / IN at 2002, 2014 and 2023.

**Observed.** Rejected at compile time with COBOLNET0899 (measured with the pinned compiler). The code comment at BinderDriver.cs:471-491 says C# forbids `instance.staticField` for the GLOBAL/__outer bridges and stages the whole shape loud. The stage also fires when the containee references nothing of the container's, so it rejects far more than the bridge gap actually needs.

**Code site.** src/Cobol.Net.Compiler/Binding/BinderDriver.cs#BindUnitData (lines 471-491, `bool staticWs = unit.Recursive && !unit.Initial && unit.Children.Count == 0;` and the RecursiveContainedWs error); src/Cobol.Net.Editions/Diagnostics/DiagnosticCatalog.cs:1452
