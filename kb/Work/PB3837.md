# PB3837 — DECISION (owner, 2026-10-26): retire Cobol.Net / CobolNet / COBOLNET as names; the root name is WiseOwl.Cobol

## The owner's words

2026-10-26 ~11:20 PDT: "As the product is no longer named COBOL.NET, we also should not have Cobol.Net.* assemblies,
should not have CobolNet namespace, in fact, likely should not be using COBOLNET as a name anywhere ongoing."

Asked "What root name replaces Cobol.Net / CobolNet in assemblies, namespaces, folders, projects and the solution?"
(WiseOwl.Cobol, recommended for .NET's casing of three-letter-plus acronyms, or WiseOwl.COBOL to match the NuGet id),
the owner answered **"WiseOwl.Cobol"**.

And, of the legacy byte engine's product name (2026-10-26): "CobolSharp should appear nowhere except possibly in
history".

## What it overturns

A session wrote on 2026-09-26, during the product rename to WiseOwl COBOL: "`src/Cobol.Net.*` assembly/namespace names
are code, not renamed". The owner never set that limit; this decision removes it. The diagnostic prefix rename
(PB3575) kept the same names for the same reason, and this note is its follow-on.

## Measured on main, 2026-10-26

- Projects: `src/Cobol.Net.Cli`, `Cobol.Net.Compiler`, `Cobol.Net.Compiler.SourceGen`, `Cobol.Net.Editions`,
  `Cobol.Net.Frontend`, `Cobol.Net.Runtime`, the `tests/Cobol.Net.Tests.*` projects, and `Cobol.Net.sln`.
- Environment variables: `COBOLNET_CLOCK`, `COBOLNET_KEYCHECK`, `COBOLNET_SORT_MEMORY`, `COBOLNET_SORT_TMPDIR`,
  `COBOLNET_UCA_CONFORMANCE_DIR` (and any other `COBOLNET_` name a fresh grep finds).
- Docs: 18 `docs/COBOLNET_*.md` files (the plan, the design SSOT and the subsystem designs), linked from CLAUDE.md,
  the skills, the DOC_INDEX and many notes.
- The older name CobolSharp appears in about 3,171 tracked files (mostly kb/Work tags and prose); it is retired with
  the same sweep. The untracked `src/CobolSharp.*` directories on the main checkout are build leftovers, not tracked.

## Execution

One re-runnable rename, the PB3575 pattern: a committed script maps every old name to its new one (assemblies,
root namespaces, project and folder paths with `git mv`, the solution, `InternalsVisibleTo`, the runtime ABI pin
(`abi_pin.py settle`), test class prefixes, environment variables (`WISEOWL_COBOL_*` or `COBOL_*`, chosen once and
stated in the report), doc file names and every link to them, CI workflow paths, scripts and skills), never DEVLOG/
or the frozen evidence. No alias, no forwarder, no old environment-variable reader (CLAUDE.md rule 4). A drift test
refuses the retired names outside the history list. It runs after PB3575 lands, with the loop drained, and a branch
cut before it converts itself by running the script after merging main.
