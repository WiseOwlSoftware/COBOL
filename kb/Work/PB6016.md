# PB6016 - run_probe.py cannot stage a library directory

**Sites:** `scripts/orchestrator/run_probe.py` (`parse`, `main`: the `--with` staging).

**Defect.** `python scripts/orchestrator/run_probe.py ... --with LIB-19/TXT-20.cpy E:/COBOL-coord/scratch/pb5453/probes/s-02/udw_types3.cob`
stages `TXT-20.cpy` beside the program, not under `LIB-19/`, so a probe of `COPY text-name OF library-name`
(§1985:XII.2.2) cannot be run through the one probe runner. A reader who needs the form must stage it by hand, which
P17 forbids. The PB5453 import found 14 needs-own-witness probes that exit 65 on this branch's build for want of their
library texts or data files (`E:/COBOL-coord/scratch/w20262131a/probes-classified.json`, kind `probe`, exit 65), so
their rows stay GAP until they can be staged and placed with their `files`.

**Fix.** `--with <relative path>` keeps the relative path under the run directory (refusing `..` and an absolute path).
