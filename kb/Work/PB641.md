# PB641 — OPEN — measure the reachability first

Found 2026-09-05 by the `PB288` implementer (report, the "third, smaller one"), which made the numeric CALL crossing
land with COMPUTE semantics for BY CONTENT and BY VALUE (GR9/GR10) and observed that the BY REFERENCE view (GR8,
`OK §14.2.3 8)` — run `cite.py --check 14.2.3` on its first sentence before acting) re-lands on every reference
through the same primitive on READ, but the WRITE-BACK from the callee into the caller's storage carries no
conformance to the ACTUAL's capacity: the formal's description governs the store, and when the formal is wider
than the actual, digits land outside the actual.

## Why it is a probe and not yet a defect

§14.8.2 (the conformance rules for a CALL's arguments against a prototype's formals) forbids the mismatch for a
prototyped or nested CALL, and PB237's registry enforces it (COBOLNET1762 family). The shape is reachable only through
a NON-NESTED, non-prototyped external CALL, where the description of the formal is not knowable at the call site —
and there the standard's own answer is that the mismatch is a user error with undefined results (§14.2.3's
"otherwise" leg for a description the activating element cannot see). Whether that makes the implementation's
behaviour (a write past the actual's digits into the caller's adjacent storage? or a clamped store?) a defect
depends on what actually happens to the caller's neighbouring items — a wrong VALUE in the actual is defined
behaviour under a user error, but corrupting a NEIGHBOUR is not the kind of undefined the standard means.

## The probe

Two separately compiled programs: the caller declares `01 A PIC 9(4). 01 B PIC X(4) VALUE "CTRL".` and CALLs the
callee BY REFERENCE A; the callee declares its formal `01 F PIC 9(9)` and stores 123456789 into it. Observe A and B
after return under `--std 2023`, both with the typed-native record layout and through the byte-window view
(PB231's carriage gate) if A is under a REDEFINES. Outcomes: B unchanged and A clamped/low-order → document as the
undefined-result disposition in `COBOLNET_INTERPROGRAM_DESIGN.md` and close; B changed → convert to `kind: defect`
(wrong_answer, silent), severity MAJOR, and the fix is a capacity conformance on the GR8 write-back mirroring
PB288's `Land`.
