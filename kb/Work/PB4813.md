# PB4813 - the 2002 standard as public Markdown

**Source.** `specs-private/ISO_COBOL_2002.pdf` (`spec_pdf.path(2002)`) (882 pages, a true text layer; owner bought it 2026-11-05; specs-private
9cee9e8).

**Permission (owner-confirmed, not printed).** Unlike the 1985 and 2023 texts, this PDF prints no CODASYL reproduction grant.
Every page was searched. Its page 4 reads "© ISO/IEC 2002 All rights reserved. Unless otherwise specified, no part of this
publication may be reproduced ... without permission in writing". The owner confirmed on 2026-11-05 that the permission to
transcribe and distribute it is in place ("I confirm the 2002 permission"). The Preface states that the
transcription is published with permission and names NO person (owner 2026-11-05: "we remove the per-copy stamps and
references to me from the markdown versions"); the confirmation is recorded here only. The per-copy
stamp, the order number and the licensee name must not reach the public file.

**Output.** `specs/ISO_COBOL_2002.md`, in the 2002 clause numbering (the same skeleton the 2023 file follows).

**The process is the 2023 one, unchanged** (owner 2026-11-05: "using the same processes and guidelines" as `specs/ISO_COBOL_2023.md`):
- Convert with `scripts/spec/transcribe_pdf.py --edition 2002` (`submit`, `status`, `collect`, `retry`, `pages`,
  `check`, `assemble`; kb/Work PB4816). It replaced the 2023 conversion's `specs-private/scripts/` tools, which are deleted.
- Reconcile page by page against the PDF with the `spec-reconcile` skill and `.claude/workflows/spec-reconcile.js`. Its durable
  per-agent ledger lives under `docs/rearchitecture/spec-reconciliation/` (README.md, REPORT.md, LEDGER.json). Every claim gets
  an adversarial verify before a repair.
- Follow the rules in `docs/rearchitecture/spec-reconciliation/TRANSCRIPTION-STATE.md`: Markdown re-parses plain text, the
  rules for drawing a general format, and the standard's own defects transcribed AS PRINTED. `FIGURE-STYLE.md` and
  `PDF-TEXT-LAYER.md` apply too.
- Run the same gates: `lint_rendering.py`, `sweep_figures.py --check`, `verify_publishable.py` (no licence stamp, no order
  number, no licensee name anywhere in the public file) and `verify_acknowledgment.py`. Each tool gains a parameter naming the
  edition; none is copied (CLAUDE.md rule 4: no forks of a tool).
- Write a Preface like `specs/ISO_COBOL_2023.md`'s, naming the edition and the permission it is reproduced under, with the
  acknowledgment paragraphs reproduced in their entirety.
- Make `scripts/spec/cite.py` able to check a citation against this edition, so a design doc can cite the old edition
  mechanically (rule 1).
- Record the transcription in `docs/DOC_INDEX.md` and in `docs/VERSION_CHANGE_REFERENCE.md`, whose edition claims can then be
  checked against the edition's own text.

  reader.
A page the API's content filter refuses is converted locally (`pages --local`), never worked around (PB4812's practice).

**The canary refused, and the route changed (owner decision 2026-11-07).** The canary batch (pages 40, 180, 330, 520 and
760; $0.10 on account2) returned ONE transcription (page 180). The model declined the other four, naming the per-copy
license line printed on each page as its reason, and wrote a summary in place of each. `collect` accepted the summaries as
pages (PB4917). They were deleted from the private state directory, and no full run was submitted. The license line is not
hidden or cropped to get past the refusal: that is the same rule as never working around the filter. The owner, asked how
the 2002 transcription should be produced, chose **"Text layer (Recommended)"**:
- **Text.** The 2002 PDF has a true text layer (unlike the 1985 scan). The text is extracted from it directly, with no
  model, under `PDF-TEXT-LAYER.md`'s rules: reading order, hyphenation, ligatures, and the standard's own defects kept as
  printed.
- **General formats.** They are measured from the PDF's vector drawing by the vector arm that the 2023 transcription built
  (`figure_extract`, `figure_geometry`, `render_figure`, `sweep_figures --edition 2002`), never typed from extracted text
  (FIGURE-STYLE.md).
- **Structure.** Headings, rule numbering, tables and lists come from the text layer's fonts and positions. The local vision
  model (`pages --local`, PB4912) is used only for a page whose structure the text layer leaves ambiguous, as a reading
  that the page decides.
- **Stamp.** The stamp line is dropped by `verify_publishable.FORBIDDEN[2002]` (wave 20261906), and the assembly is gated by
  it.
- **Where the tool lives.** It is one tool, `transcribe_pdf.py`, with a text-layer backend beside its batch and local ones.
  It is not a second converter. The Message Batches path stays for an edition with no text layer.
**The 2002 stamp row (2026-11-07).** The canary batch (pages 40, 180, 330, 520 and 760, account2) ended, but `collect --edition
2002` stopped before writing a page: `verify_publishable.FORBIDDEN` had no 2002 row. The row is now read from the 2002 PDF's own
text layer. The reseller's per-copy stamp is ONE line, the same on all 882 pages. It carries the 1985 stamp's opening and
licence-terms sentences, a store order reference, an order number longer than six digits, and 2023's download date. 2023's
order-number shape needs a word boundary after six digits, so it misses this number, and 2002 has its own. `FORBIDDEN[2002]`
holds seven shapes: the opening sentence, `Licensed to`, `order #`, the order number, the download date and the two
licence-terms sentences. `TREE_FORBIDDEN[2002]` holds the order number, the date and a purchaser's name. Every shape matches
that line on all 882 pages and no other line of the PDF. `transcribe_pdf.clean_page` applied to the text layer drops exactly
one line from each of the five canary pages, 882 in all, and leaves no stamp. The self-test plants an invented stamp of the
same shape. The canary pages are NOT collected yet: the key file at hand holds a single key whose label names neither
account, and `read_run_key` correctly refuses to bill a run recorded as account2 with it. Collecting needs the key file
that holds account2's labeled key.

## ⛔ The general formats (syntax diagrams) are the hard part (owner 2026-11-05)

The owner: "we need to properly handle all the difficult issues we encountered during the original spec convertion. THe syntax
diagrams were especially problematic with underlines, vertical bars, brackets and other graphical items indicating syntax and
grammar requirements that OCR and other techniques missed."

A general format carries four things, and losing any of them changes what the language permits (FIGURE-STYLE.md):
- grouping: brackets (at most one) and braces (exactly one);
- repetition and order: the choice-indicator bars;
- required against optional words: the UNDERLINE;
- operand structure: vertical alignment.
OCR and text extraction keep the words and drop all four. The 2023 transcription's general formats were wrong until they were
REGENERATED from the measured page, and four of FIGURE-STYLE.md's six rules were found by the owner looking at a rendered figure.
So for this edition:

1. **Every general format is regenerated from the measured page, never transcribed from extracted text.** Use the 2023 pipeline
   made edition-aware: `figure_geometry.py` measures the strokes, `figure_extract.py` reads the words with their coordinates,
   `render_figure.py` draws the figure and `sweep_figures.py --check` regenerates and diffs every figure. Then audit with
   `audit_underlining.py`, `audit_figure_structure.py`, `audit_figure_text.py` and `audit_grammar_optional_words.py`.
2. **Draw by FIGURE-STYLE.md and TRANSCRIPTION-STATE.md's "Rules for drawing one":**
   - `<pre>` with `<u>` for underlining, never a fenced block;
   - box-drawing glyphs only;
   - a collision-guarded canvas, and geometry computed, never counted;
   - `<` and `>` escaped at write time.
3. **Markdown re-parses the standard's notation** (TRANSCRIPTION-STATE.md, the class that did the most damage):
   - escape rule labels;
   - set character-sequence words in code;
   - never indent a sub-rule four spaces;
   - gate with `lint_rendering.py`, and render a slice with pandoc before any sweep.
4. **The printed page is the authority, rendered and looked at.** `render-spec-page.py` takes the edition through
   `spec_pdf.path(edition)`. A figure is accepted only after its rendered output is compared with the rendered page.
5. **Every figure gets an adversarial check,** as the 2023 `spec-grammar-conformance` and `spec-reconcile` workflows did. A
   refuter compares the drawn figure against the printed page for each of the four carried things.

**2002 is a true vector PDF,** like 2023. Its general formats are vector strokes (the COPY format page carries 21), so the 2023
geometry pipeline applies with the edition parameter. Calibrate it first: the 2002 typesetting may draw underlines and bars with
different stroke widths and offsets from 2023's, so run `figure_geometry.py` on a dozen 2002 formats and compare them against the
rendered page before the sweep.

**The text-layer backend (wave 20261909, group A).** `transcribe_pdf.py text [PAGES] --edition 2002 --state DIR
[--replace]` converts pages from the PDF's own text layer with no model, through `scripts/spec/text_layer.py` (the backend;
no command line of its own; PyMuPDF imported inside `read_layout` only). It reads WORDS from per-glyph positions, because a
span of the text layer is not a printed run: the glossary sets each bold term over the leading blanks of the regular span
after it, and an unruled table's cells share a span. It drops the running header, the footer and the stamp row, and writes
headings, rules (labels escaped), notes, hard-break lists, ruled and unruled tables, Courier `<pre>` blocks and two-column
pages from fonts and positions. A General format clause's rows, and any row carrying a Symbol brace piece, are written as a
`text_layer.FIGURE_MARK` placeholder naming the page, the figure and its measured extent; `assemble` refuses a page that
still holds one. Measured on all 882 pages in memory: 411 general formats on 296 pages, the folio offset 22 on all 859
arabic-numbered pages (now `spec_pdf.EDITIONS[2002]`), and no stamp left. Measured for the vector arm: 2002's underlines
and brackets are line strokes (0.405 pt; a bracket is three segments), but its BRACES are Symbol-font glyphs in the text
layer (U+F8F1..U+F8FE), so a stroke reader alone does not find them.

**The vector arm reads 2002, and the transcription is assembled (wave 20261923, group A).** The 2023 figure pipeline read
no 2002 page, for five measured reasons, each fixed where the rule lives: `render_figure.headings` required an 11 pt heading
(a heading is now larger than the page's regular body text, `body_size`; 2002 sets 9/10 pt, 2023 10.7/11.7) and its y is
rounded as `extract` rounds a word's top; `GLYPH_PIECES` (now in `figure_extract`, where the text layer is read) carries
the Adobe private-use spellings of the brace and paren pieces; `figure_geometry.strokes` measures each LINE of a drawing
path (2002 strokes many lines to one path, so a path's box was no stroke), and a 2.7 pt 2002 bracket foot is a horizontal;
`figure_extract.level_top` gives a Symbol-face word (`{`, `}`, the raised `…`) the top of the text face on its baseline;
`split_fused` re-measures a word split off a brace hook for its underline; and an annex clause (`A.2.1.1`) is a clause.
The 2023 oracle (`sweep_figures --check`) moved five 2023 figures, each a trailing ellipsis lifted onto the row above its
printed line (7.3.13.2, 12.3.7.2, 13.18.54.2, 14.9.26.2, 14.9.43.2, checked against the rendered pages), applied to
`specs/ISO_COBOL_2023.md`; its two other drifts are PB4913's. The text backend now DRAWS each figure it places
(`transcribe_pdf.draw_figure`, `render_figure.draw`, whose band is `find_figures`' own padding rule), classifies a General
format clause's rows with `render_figure.classify_row` (5.1's prose is text), writes a `Format N` label as a label in any
face, joins an out-of-clause figure's notation rows (NUMVAL's `DB`), splits a found table at a row no vertical rule spans
(`ruled_parts`: 2002 folio 802's two INSPECT tables were one) and reads two columns only across a 10 pt gutter (the old rule
split the contents and 26 other single-column pages). `PARTS[2002]`, `spec_pdf.EDITIONS[2002].body`,
`verify_publishable.REQUIRED[2002]` (the Preface states the permission; 2002 prints no acknowledgment, so
`ACKNOWLEDGMENT_OPENING[2002]` is None) and `sweep_figures.FURNITURE_LINES[2002]` are written. Result: 882 pages, 450
general formats, every one drawn; `specs/ISO_COBOL_2002.md` (35,873 lines) is PUBLISHABLE and LINT CLEAN, and
`sweep_figures --edition 2002 --check` is clean, 439 of the 445 figures `find_figures` locates byte-identical to the
drawn ones. `cite.py --check` resolves a 2002 citation (`§2002:14.8.25.2 SR1`) against it.

**What remains of this note.** The page-by-page reconciliation against the rendered PDF (`spec-reconcile`, the
