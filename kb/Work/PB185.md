# PB185

**The third self-block mode of the same guard** — after [[PB101]] (an agent inside its own
`.claude/worktrees/` checkout) and [[PB103]] (a main-tree agent counting its own transcript). Both earlier modes
were fixed at `fleet_active_build.py:82-89` (the worktree bail) and `:100-105` (the own-transcript filter). The
`:100-105` filter is the one that does not work.

**WITNESSED TWICE in session `01PEJTGVQX17pwVbXZq7mYxS` (2026-08-30/31)**, by two different agents, both alone in
`E:\CobolSharp` with no fleet running:

```
BLOCKED — 1 subagent transcript(s) were written in the last 120s, so a fleet is LIVE: subagents.
```

`detail` is `subagents`, i.e. the one "live" transcript is the CALLER's own
`~/.claude/projects/*/<session>/subagents/agent-*.jsonl`. The guard globs it at `:64`, and `:103-105` is
supposed to drop it:

```python
own = (data.get("transcript_path") or "").replace("\\", "/").lower()
if own:
    live = [p for p in live if str(p).replace("\\", "/").lower() != own]
```

The comparison is an EXACT string equality between the hook payload's `transcript_path` and the glob's path. For
a subagent those two are not the same string — the payload names the SESSION transcript (or a differently-rooted
/ differently-cased spelling of the agent file), so nothing is filtered, `live` stays non-empty, and the deny is
emitted. Because the caller writes to its own transcript on EVERY tool call, the 120-second window never clears:
the block is permanent for the whole agent, not merely for the next two minutes.

**WHAT IT COSTS.** An agent cannot build, test, run a probe, or run its own wave gate — `dotnet
build|test|clean|publish|run|msbuild` are all in `BUILD_VERBS`. In this session it cost the PB164 finisher the
`SpecTraceabilityInventoryDriftTests` reference check after a verdict batch and a three-shape CLI probe of
[[PB190]]; the lander and the fixer each hit it earlier. The guard's own harm model does not apply to any of
these cases: there IS no fleet, and the only binary being changed is the one the agent itself is about to test.

**THE FIX IS NOT A THIRD SPECIAL CASE.** Two exclusions have now been bolted on for two ways of asking the same
question, and a third string comparison would be the fourth. The question the guard actually wants to ask is
"is any transcript OTHER THAN MINE live?", and the reliable identity is not a path string:

- pass the caller's own agent id / transcript through the hook payload and compare on the RESOLVED, case-folded
  `pathlib.Path` (`Path(own).resolve() == path.resolve()`), never on raw strings — and, when the payload gives
  no usable identity for a subagent, treat "exactly one live transcript, and it is in MY session's
  `subagents/` directory" as self and bail; or
- key liveness on something that cannot name the caller at all (a lock file each dispatched fleet writes and
  removes), which is what the guard's docstring actually describes as its rule.

Whichever shape is chosen, **fire the failure branch once before trusting the silence**
([[feedback_prove_the_watchdog_fails]]): the guard must still deny a main-session build while a real fleet is
live, and must allow a lone subagent's build — both proven, not assumed. The guard is FAIL-OPEN by construction
everywhere else; this is the one path where it fails CLOSED.

**Interim, and it is a bad interim:** an agent that needs to build must be dispatched with
`isolation: "worktree"` (the `:82-89` bail), or the work must be handed back to the main session. Routing around
the hook from inside an agent is not an option — [[feedback_authorize_tooling_explicitly]]: surface it with
evidence, never route around it.
