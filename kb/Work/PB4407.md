# PB4407 - the STOP RUN / GOBACK status arm of PB4383's operand positioning is unpinned

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ControlFlowBinder.cs:133` (`ControlFlowBinder.StatusOperand`, the `using var statusAt` position), `tests/WiseOwl.Cobol.Tests.Conformance/DiagnosticPositionTests.cs` (`OperandOnAContinuationLine_NamesItsOwnLineAndColumn`).

PB4383 positioned the status operand of STOP RUN / GOBACK at its own token. `OperandOnAContinuationLine_NamesItsOwnLineAndColumn`
covers DISPLAY, the MOVE sender and receiver, and STRING, but not this arm: deleting the `using var statusAt` line leaves
every test green. Fix: add a STOP RUN (and a GOBACK) row whose index-name status operand sits on a continuation line and
pin its line and column. Kept apart from PB4406 because it is a missing test for a landed arm, not unfixed reach; the
PB4406 fix extends the same fact and may land it together.
