# PB856 — OPEN — half a rule, quoted as the whole of it

Source: the `PB646` finisher report, item N1. Not PB646's mechanism: identifier-1 already takes a different path
and the refusal predates that landing (category NATIONAL has been live since Phase 4a).

## Repro — re-run on this tree

`scratchpad/reg4/probe/p18_inspect_national.cob` (PROGRAM-ID `R4P18`), `--std 2023`:

```cobol
       01 NS PIC N(5) VALUE N"ABABA".
       01 NA PIC N(1) VALUE N"A".
       01 CT PIC 9(3) VALUE 0.
           INSPECT NS TALLYING CT FOR ALL NA
```
```
(9,12): error COBOLNET0847: INSPECT operand 'NA' shall be an elementary usage-display item (ISO §14.9.22.3 SR2)
```

## The rule, quoted

```
$ python scripts/spec/cite.py --check 14.9.22.3 "shall reference an elementary item described implicitly or explicitly as usage display or national"
  OK  §14.9.22.3 2)  (Syntax rules)
      2) Identifier-3, … , identifier-n shall reference an elementary item described implicitly or explicitly as usage display or national.
```

SR1 is the same shape for identifier-1 — "either an alphanumeric or national group item or an elementary item
described implicitly or explicitly as usage display or national" — and a GROUP is admitted there too. The
diagnostic's own text is the evidence: it paraphrases SR2 as "usage-display" and the rule says "display or
national".

## Code site

`src/Cobol.Net.Compiler/Binding/Validation/StatementValidation.cs:281` —
`if (!(p.Item.IsGroup || p.Item.Pic is { Usage: not Usage.Display })) return true;`

## Expected vs observed

Expected: the program compiles and `CT` counts 3 (`N"A"` occurs three times in `N"ABABA"`). Observed: refused.
That the literal form works (`INSPECT NS TALLYING CT FOR ALL N"A"` answers 003, as does the same over a
`GROUP-USAGE NATIONAL` group) isolates the defect to the identifier operand's usage screen.

## Sibling sweep the fixer owes

* Every INSPECT operand position: identifier-1 (SR1, with its group arm), identifier-2 REPLACING, the BEFORE /
  AFTER delimiters, and the CONVERTING operands — each has its own syntax rule and each must read the SAME
  predicate.
* `feedback_two_arm_dispatch` applies literally here: the DISPLAY arm was fixed and the NATIONAL arm was never
  written. Ask which arm you fixed.
* A golden per operand position, at `--std 2002/2014/2023` (national is 2002+).
