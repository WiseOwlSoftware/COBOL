# Landing, 2026-11-20: the print arm keeps a line-framed record's size before 2023

**Ruled and fixed.** DOC-A.1-146 (c') governs a RECORD SEQUENTIAL print stream; a file whose records the RECORD DELIMITER IS LINE-SEQUENTIAL clause frames is not one, and before 2023 no line sequential file exists, so §1985:VII.2.8.4 GR1 binds its print-control WRITE as it binds the plain one (PB5903). `WriteAdvancingRecord` now keeps the record at its size when `_lineSequential && !LineSequentialFileRules`. Witness: `conformance:cases/VII.4.7@1985-WRITE-STATEMENT/pb5914_line_delimited_advancing_keeps_size_85`. Re-probe before the fix: the file held `AB` with its eight trailing spaces dropped. LINAGE and report streams keep their 2023 text form unless the file carries the delimiter clause.
