# PB6108 - the exception catalog's edition drift test skips EC-USER and EC-ALL

Re-verified on main ae1136f781. `tests/WiseOwl.Cobol.Tests.Unit/ExceptionCatalogEditionDriftTests.cs` (lines 36-49) builds `allNames` from
`ExceptionCatalog.Level3Rows` and each row's `Level2Parent`, then compares each name's `IntroducedIn` with the first of the 2002, 2014 and 2023 transcriptions that
names it. A level-2 name with no level-3 child in Table 13 (EC-USER) is never enumerated, and EC-ALL (the level-1 name) is not either, so a wrong `IntroducedIn` on either passes.
The PB5599 DEVLOG entry says every level-2 `IntroducedIn` is held.

**Sites:**
- `tests/WiseOwl.Cobol.Tests.Unit/ExceptionCatalogEditionDriftTests.cs` (whole: the `allNames` construction, lines 36-38)
- `src/WiseOwl.Cobol.Runtime/Exceptions/ExceptionCatalog.cs` (`EcAll` line 50, the level-2 family list line 100, `Level3Rows`)

**Next:** enumerate every catalog entry of every level (add an accessor that yields all of them, rather than deriving the set from the level-3 rows) and hold each to the
transcriptions; add the test's own check that the enumeration is complete against the catalog's count.
