# PB2846 — OPEN — a refused module registration crashes past RunMain

Found by the train 1047 lander's review (step 5b; `E:\COBOL-coord\scratch\reports\train1047-report.md`, finding (c)) on cluster 45B (PB2097's module registration), PLAUSIBLE (traced in code, not run). The lander had no ids left; the land unit reserved this id and the resume unit of 2026-10-08 21:46 PDT filed it.

## Mechanism
`src/Cobol.Net.Compiler/CodeGen/ProgramEmitter.cs:871` emits `<registrar>.EnsureRegistered();` and line 881 emits
`try { ProgramRegistry.RunMain(...); }`. `EnsureRegistered` is `ProgramRegistry.RegisterModule(registrar,
runtimeVersion, callAbi, Register)` (line 795), which refuses a module built against a different runtime version or
call ABI. That refusal is thrown before the try, so it never reaches the RunMain boundary that owns the run unit's
termination (the STOP-status flush and the fatal-error report, ProgramTable.RunMain).

## Repro to build
Compile a main program, then run it against a runtime assembly whose version or call ABI differs (or force
`RegisterModule` to refuse in a unit test of the emitted shape). Observed (by trace): an unhandled .NET exception and
the host's stack dump. Expected: the runtime's fatal-error report and exit status.

## Done when
Registration runs inside the RunMain boundary (or RunMain performs it), with a unit test that a refused registration
ends the run unit through the same surface as any other fatal error.
