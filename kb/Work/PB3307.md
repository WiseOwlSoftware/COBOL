# PB3307 — Index links off by the 30-page front matter

Source: `E:\COBOL-coord\scratch\reports\w1103z-PB3149-report.md`, lead L2. Harm: process_only; a reader following an Index link lands on an unrelated clause.

**Mechanism.** Where an Index link is only approximate, the converter read the PRINTED page number (folio) as the PDF page number; the front matter is 30 pages, so the link resolves about 30 pages too early.

**Examples from the report.**
- Index "555" links to 13.18.64 (VARYING; PDF page 555) instead of 14.6.13.1.6 (folio 555 is PDF page 585).
- "703" links to 14.9.26 (MULTIPLY) instead of 14.9.31 (RECEIVE).
- "441" links to 13.18.29.4 (PDF 440) and "728" links to 14.9.30.4 (PDF 724) show the same shape.
- "E function 843" links to 15.27 and is correct.

**Sites.** The Index in `specs/ISO_COBOL.md` (for example :45071-45079) and the tool that converted it, likely `scripts/spec/resolve_index_folios.py` or its predecessor.

**Scope.** The count of affected links is unmeasured; measuring it is the first step.
