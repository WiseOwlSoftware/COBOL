# PB5557 - COBOL7282 (an external record's name reused) names a user-defined function as a program

UNVERIFIED LEAD: re-probe before fixing.

`ExternalRecordNameRules.cs:62` (`ExternalRecordNameRules.Check`) builds the COBOL7282 message with `$" described in program '{u.Name}'"`
whenever the owning source element has a unit, so when that unit is a user-defined function (`BoundUnit.IsFunction`) the message
calls it a program and misnames the kind of element the user must look in. A class half already gets its own wording. Use the
unit's kind word (the one `SourceUnitShape.KindOf(IsFunction, IsPrototype)` already knows) instead of the literal "program".

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/ExternalRecordNameRules.cs` (`ExternalRecordNameRules.Check`).
