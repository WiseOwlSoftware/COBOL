# PB409 — one rule pair, two halves, neither written

**Rows:** `SR-14.9.18.3-1` and `GR-14.9.18.4-6`. They are one item because they are the standard's own pair —
the syntax rule that forbids the construct and the general rule that says what happens when a GOBACK reaches a
global declarative's range anyway. All measurements below were re-run on this worktree's HEAD `cobol.exe`
(base 89044aa0).

## THE MECHANISM

`src/Cobol.Net.Compiler/Binding/Procedure/Verbs/CallBinder.cs#BindGoback` (`:492-514`) forks on
`host.InMethod`, resolves a RETURNING operand, binds a RAISING phrase and decodes the status phrase. **It never
looks at the enclosing declarative.** No site in the tree tests a declarative's GLOBAL flag at a GOBACK bind.

The second half is worse than unimplemented — it is *catalogued as if it were implemented*.
`src/Cobol.Net.Runtime/Exceptions/ExceptionCatalog.cs:99` declares
`L3("EC-FLOW-GLOBAL-GOBACK", EcFatality.Fatal)`, and a tree-wide search of `src/` finds that name at **exactly
that one site** (the only other hit is a comment in `Binding/EcNameResolution.cs:113`). Nothing sets it, and
`CodeGen/EcEmitter.cs:79`'s `NonfatalAmbientGates` exception-name → checking-flag table carries no row for it,
so `>>TURN EC-FLOW-GLOBAL-GOBACK CHECKING ON` is accepted and wires nothing. A green compile reads as support.

Both inputs a correct check needs already exist and are already consulted **one verb over**:
`Binding/Procedure/Verbs/EcBinder.cs:113` finds the enclosing declarative from `ctx.Table.Declaratives` and
`:124-126` reads `decl.Global` to raise `COBOLNET0713` for the identical placement rule on RESUME.

## ⚠ SR1 AND GR6 ARE NOT THE SAME CASE — GR6 GOVERNS LEGAL SOURCE

SR1 forbids a GOBACK *specified in* a global declarative procedure. GR6 fires when a GOBACK *is executed within
the RANGE of* one. A GOBACK written in an ordinary paragraph that a global declarative PERFORMs is **within the
range and not specified in the procedure** — SR1 does not reach it, so it is legal source, and GR6 alone
governs it. The b2 adjudication measured only the SR1 shape; **this note adds the GR6-only probe**, which is
why the row is a behavioural divergence and not merely a missing diagnostic.

3. **GR6 alone, on LEGAL source — new here.**
   `scratchpad/probe-g3-goback-goto/gr6b/rangegoback.cob`: a called subprogram whose global declarative

## THE SHAPE OF THE REPAIR

Two halves, and they are not the same site.

- **SR1** belongs at `CallBinder.cs#BindGoback`, copying `EcBinder.cs:113`'s declarative lookup and `:124`'s
  `decl.Global` test with §14.9.18.3 rule 1's own citation. That is a lexical, bind-time question.
- **GR6 is NOT a bind-time question** — "within the range" is a *runtime* relation (a declarative may PERFORM
  arbitrary procedures), so a static "is this paragraph inside a declarative" test cannot answer it. The honest
  shape is an ambient runtime flag maintained by the declarative entry/exit the EC emitter already generates,
  consulted by the GOBACK emit. ⛔ Do not implement GR6 as a bind-time approximation of SR1 and call the pair
  closed; that would leave probe 3 — the legal-source case — still wrong.
- Whatever sets the condition must also get a row in `EcEmitter.cs:79`'s name → ambient-flag table (or whatever
  structure supersedes it), so that `>>TURN EC-FLOW-GLOBAL-GOBACK CHECKING ON` means something. **A catalogued
  name with no raise site and no TURN wiring is the defect shape to sweep, not just this instance**
  (`feedback_a_dead_lookup_is_also_unverified`).

## THE SIBLING SWEEP

1. **EC-FLOW-GLOBAL-EXIT (`ExceptionCatalog.cs:98`) is the §14.9.14 twin and is equally unset** — same catalog,
   same missing TURN row, same missing raise site, and §14.6.13.1.3 rule 6 names the two together. The sweep is
   two conditions and two verbs wide (EXIT PROGRAM's own global-declarative rule is at
   `probe/sr2-exit-program-global-decl`).
2. **Audit every other `L3(...)` row in `ExceptionCatalog.cs` for a raise site.** The mechanical question — for
   each catalogued exception-name, is there any `src/` site that sets it and a TURN wiring row — is a drift test
   the repo should own, not a one-off grep. A name with neither is a green compile that reads as support.
3. `probe/sr2b-resume-global-decl` is the working RESUME analogue; use it as the acceptance shape.
4. Edition sweep: the rule pair is edition-invariant (GOBACK itself is a 2002 introduction), so the new
   diagnostic must be checked at 2002/2014/2023 and must NOT fire at 85, where GOBACK is gated off anyway.
