# PB6144 - an insertion is excused without checking where it stands

`scripts/spec/text_layer_diff.py` (PB6135): when a difference is an insertion on the Markdown side only, the printed side is empty and is
not checked, so an added run of three or more words that occurs anywhere in the note's own Amendment entry is classified
AMENDMENT-APPLIED at any position on the page. The review probe passes a misplaced duplicate (`the file is`) and a stray `page` (the next
table row's page cell sits at the end of each located entry). 33 of the 57 committed AMENDMENT-APPLIED rows are insertions.

**Fix.** Anchor an insertion: the words on each side of the gap in the Markdown must stand consecutively around the inserted run in the
amended text, as the dropped-word case already requires; trim the entry at the next row's page cell. Self-test the two probes.

**Landed** (2026-11-24, branch `fix-pb6144-insertion-anchor`): insertions are anchored by `_stands_between` and an entry ends before the next row's page cell; self-test case_15; AMENDMENT-APPLIED 57 → 45 (insertions 33 → 21), UNCOVERED 787 → 798, UNEXPLAINED 602 → 603 over all 976 pages.
