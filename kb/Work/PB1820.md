# PB1820 — LANDED

Found 2026-09-30 by the directives-cluster implementer while making LEAP-SECOND per-unit (PB1378). `BinderDriver.BindUnitData` set
`DataBinder.LeapSecond` for program and function units, but the three `new DataBinder(...)` in `Oo/OoDriver.cs` (interface prototype
data, class data, factory data) never did. Measured on main: `>>LEAP-SECOND ON` before a CLASS-ID, a method computing
`FUNCTION SECONDS-FROM-FORMATTED-TIME("hhmmss", "235960")` printed `00000000`; §7.3.4 GR5 ("applies to all of the source text and library
text that follows") and §7.3.17.4 GR4 require 86400 (`08640000` in PIC 9(6)V99). Fixed: each takes `session.LeapSecond.IsOnAt(<its first line>)`.
Golden: `conformance:2023/pb1820_leap_second_reaches_object_methods`.
