## Filed text (kept for the forensic trail)

Filed 2026-10-07 by the train-1033 lander from the wave-1032 group B implementer report (`w1032b-PB2076-report.md`,
new defect 1).

**Shape.** PB2076 made §9.3.6 rules 6 and 7 ask whether the method's returning item may be a MOVE or SET sender for
the invocation's returning item (`ActivationRelations.MayMove` / `MaySet`). Rule 6's OBJECT REFERENCE arm still asks
nothing: `MaySet` ends in `_ => true`, so a method returning `OBJECT REFERENCE C2076S` matches an invocation whose
returning item is `OBJECT REFERENCE C2076O` of an unrelated class, and the mismatch only surfaces later as
EC-OO-UNIVERSAL from `CobolObject.NarrowUniversal`.

**Rule.** §14.9.39.3 12) a) 2. (`cite.py --check`: OK): "if the data item referenced by identifier-3 is described
without an ONLY phrase, the object-class-name specified in the description of the data item referenced by
identifier-4 shall reference the same class or a subclass". A pair SET refuses is not a match under §9.3.6 rule 6, so
the resolution ends at "otherwise, the EC-OO-METHOD exception condition is set to exist" (§9.3.6 6)). SR10, SR12 and
SR14 also carry the interface, ONLY, FACTORY and ACTIVE-CLASS arms.

**Repro.** `E:\COBOL-coord\scratch\w1032b\probe\setarm.cob` (`INVOKE U "RO" RETURNING OO`): prints
`HANDLED=EC-OO-UNIVERSAL`; expected `HANDLED=EC-OO-METHOD`.

**Code sites.** `src/WiseOwl.Cobol.Runtime/Control/ActivationRelations.cs#MaySet` (the `_ => true` arm);
`src/WiseOwl.Cobol.Runtime/Control/CobolObject.cs#NarrowUniversal` (where the late raise happens);
`src/WiseOwl.Cobol.Compiler/Oo/ActivationDescriptions.cs#Of` (where the description would carry the class facts).

**Why it was not fixed in PB2076.** An activation description carries a class NAME only and the runtime has no class
hierarchy to ask "same class or a subclass"; the fix puts the CLR type (or its interface set) in the description and
implements SR10/SR12/SR14 over it — a description-model change beyond PB2076's slice. Same root as PB2464 (the
description lacks the type facts SET needs); PB1780 is the shared design for activation conformance.
