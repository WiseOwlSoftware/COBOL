# PB5291 - without WITH DEBUGGING MODE a debugging section whose text is not COBOL syntax is refused (COBOL5506): the comment treatment is applied after parsing, where 1985 compiles the USE FOR DEBUGGING statement and its section as comment lines

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/ProcedureTableBuilder.cs` (`DeclCollectSection`)
- `src/WiseOwl.Cobol.Compiler/Validation/VersionConformancePass.cs` (`VisitDeclarativeSection`)

**Mechanism.** §1985:XV.2.1.3 GR2: without WITH DEBUGGING MODE "any USE FOR DEBUGGING statements and all associated debugging sections are compiled as if they were comment lines". `DeclCollectSection` skips a debugging section when debugging mode is not declared, so a well-formed body's meaning is ignored, but the text is still parsed first, so a body line that is not COBOL syntax (which a comment line may hold) is refused.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the non-conforming verdicts wait in `E:/COBOL-coord/scratch/coderead-85/p2-for-register.json`.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-GR-XV.2.1.3-2` - `§1985:XV.2.1.3 GR2` (read: PARTIAL, harm: rejects-legal-source): "are compiled as if they were comment lines"

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-pipe/work-slice-67/m1i.cob`: no WITH DEBUGGING MODE; `DBG SECTION. USE FOR DEBUGGING ON ALL PROCEDURES. DBG-P. MOVE "Q" TO X . THIS IS NOT COBOL GO TO P1. END DECLARATIVES.`; `cobol.exe --std 85 --source-format fixed --run m1i.cob`.

**Observed (a build of origin/main f2cf36fd15, rerun 2026-11-11; main has since changed only `IndexedConnector.cs` under `src/`, which none of these repros reaches).** exit 65: `m1i.cob(15,20): error COBOL5506: unexpected 'IS' ... expected SECTION` and a second COBOL5506 at DECLARATIVES.

**Expected (from the 1985 text).** Compiles and prints `P1 A`.

**Fix direction (root cause, CLAUDE.md rule 4).** Treat a debugging section as comment text before parsing when debugging mode is off (the preprocessor already turns debugging lines into comments by the same switch), with tests of unparseable bodies.
