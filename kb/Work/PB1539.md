# PB1539 — LANDED (wave 73 D)

## The rule

> Within a run unit, all instances of a given name that is externalized to the operating environment shall identify the same kind of entity or item. Except for method-names and property-names, when two or more source elements identify something with the same externalized name, they refer to the same instance.

`cite.py --check 8.3.2.2 "when two or more source elements identify something with the same externalized name, they refer to the same instance"` → OK §8.3.2.2 2).
`cite.py --check 14.9.4.4 "EC-PROGRAM-NOT-FOUND"` → OK §14.9.4.4 3) (the CALL fails only when the program cannot be found).

## Repro (`/tmp/adj/doc/doc-w1-s3/probe/as68b.cob`; re-probed, `--std 2023`)

```cobol
       PROGRAM-ID. M68.
       PROCEDURE DIVISION.
           CALL "trail  "
           STOP RUN.
       END PROGRAM M68.
       PROGRAM-ID. S68 AS "trail  ".
       PROCEDURE DIVISION.
           DISPLAY "IN S68"
           GOBACK.
       END PROGRAM S68.
```

Observed: `abnormal run-unit termination: CALL 'trail': program not found in the run unit (ISO §14.9.4.4 GR3b — EC-PROGRAM-NOT-FOUND)`.
Expected: `IN S68` — the CALL literal and the AS literal are the same externalized name. The implementor may instead define a
formation rule that refuses such a name at compile time, but it may not create a program that nothing can reach.

## Mechanism and code sites

`src/Cobol.Net.Runtime/Control/ProgramTable.cs` (~l.538) trims every CALL / CANCEL / ADDRESS OF PROGRAM target; `ProgramRegistry`
registers the AS literal untrimmed. One normalization function must serve both sides (register and look up), so the two can never
disagree again; decide trim-vs-refuse, then state it in the A.1 item 68 row (whose other arm, the CALL-CONVENTION mapping, is
kb/Work PB1383).

## Sibling sweep

Every externalized-name key: the EXTERNAL clause AS literal (data and files), the REPOSITORY AS phrase, class/interface/function AS
names — grep for `Trim()` on program/method names in `ProgramTable`, `ExternalStore`, `OoEmitter`.

## doc-rows-2 landing (2026-09-25)

**Sibling arm (doc-rows-2 item 68): the EXTERNAL AS name.** `01 X PIC X(3) EXTERNAL AS "Shared Two "` does not
share with `AS "shared two"` (probe `cc68.cob`): the same untrimmed-AS-literal mechanism on the EXTERNAL data/file
name path. DOC-A.1-68 determines that EVERY externalized name is formed by one rule — leading and trailing spaces
removed — and that a compile-time WARNING is given when an AS literal has leading or trailing spaces; **no such
warning exists today** (grep of src finds none; `as68.cob` prints no warning before EC-PROGRAM-NOT-FOUND). Note:
GnuCOBOL keeps AS literals verbatim (cobc/parser.y `_as_literal` / `_as_extname`, never passed to
`cb_trim_program_id`), so trimming AS names is COBOL.NET's own one-rule choice, not a GnuCOBOL precedent.

## Landed — wave 73 group D (branch `worktree-wf_1a52c830-9ba-4`)

**One rule, one place.** `src/Cobol.Net.Runtime/Control/ExternalizedNames.cs` is the formation (`Form`: leading and
trailing SPACES removed, nothing else) and mapping (`Same` / `Comparer`: case ignored) of every externalized name, and
every side now asks it: the bind-time AS screen (`ExternalizedName.Screen` → `Form`, so PROGRAM-ID, FUNCTION-ID,
CLASS-ID, INTERFACE-ID, METHOD-ID, REPOSITORY and EXTERNAL AS literals are formed once), the CALL / CANCEL literal
reader (`CallBinder.ProgramNameLiteral`, now also the AS NESTED lookup's reader, which decoded the raw literal), the
INVOKE method name (`OoBinder.OoBindByReceiver`, `CobolObject.NormalizeMethodName`), the run-time resolver
(`ProgramTable`: every target formed by `Form`, every match by `Same`, the registered `CallName` formed too), the
EXTERNAL store's keys (`ExternalTable`), pointer equality (`ProgramPointer` / `FunctionPointer.SameTarget`) and the
bind-time group tables (`BinderDriver` — its private `NameEq` copy of the mapping rule is deleted). The five emitted
`.Trim()` calls (CallEmitter ×2, PtrEmitter ×3), a second, white-space-wide copy of the formation rule, are deleted:
the runtime forms every identifier target.

**Diagnostics (DOC-A.1-68's promised warning).** COBOLNET2642 (warning) when an AS literal has leading or trailing
spaces; COBOLNET2643 (error) when an AS literal is ALL spaces and its clause refuses a zero-length literal (every AS
clause but §11.3.3's CLASS-ID) — it would form the zero-length name, which nothing can reach.
