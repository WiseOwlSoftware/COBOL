# PB1684 — LANDED

Filed by the train-70 lander from wave 70 group A's report (implementer of PB1471; `w70a-PB1471-report.md`, lead 1).

## Finding

**Repro.** `E:\Temp\claude\E--COBOL\73cac64c-391d-42c0-bcdf-c880e3e10305\scratchpad\w70a\probe\pecf.cob`: a FLOAT-LONG
item holding +Inf through a REDEFINES of `X"7FF0000000000000"`, under `>>TURN EC-DATA-NOT-FINITE CHECKING ON`;
`COMPUTE R = FL + 1` aborts with `EC-DATA-NOT-FINITE (fatal): a NaN or infinite standard-float sending operand`.
FL is not a standard floating-point item.

**Rule** (both through `cite.py --check`). §14.6.13.2 3): "When a sending operand is described with a standard
floating-point usage, and the content of the sending operand would evaluate to true in an infinity class condition
or to true in a FLOAT-NOT-A-NUMBER class condition, the EC-DATA-NOT-FINITE exception condition is set to exist".
§14.6.13.2 2) covers "a numeric sending item that is not described with a standard floating-point usage" — the
EC-DATA-INCOMPATIBLE arm. The standard floating-point usages are §3.166 / §3.167 (the FLOAT-BINARY and
FLOAT-DECIMAL families).

**Code sites.** `src/Cobol.Net.Compiler/CodeGen/Emit/NumericRenderer.cs` :411, :480, :750 and
`src/Cobol.Net.Compiler/CodeGen/Emit/OperandText.cs` :347, :488 apply the `CobolFloat.Sending` (FloatSending) wrap
to every `PicInfo.IsFloat` item.

**Mechanism.** The same root as PB1471 (landed, train 70): `PicInfo.IsFloat` is a STORAGE question, asked where the
rule means `UsageFamilies.IsStandardFloat` (the one written-down standard-float set). The fix asks the standard-float
predicate at each wrap site and routes a non-standard float through §14.6.13.2 2)'s arm; sweep every other
`IsFloat` reader that answers a "standard floating-point usage" rule.

## Landed

`SendingRefRules.FloatChecked(r, pic)` now asks `UsageFamilies.IsStandardFloat(pic.Usage)` as well as the exemption list, at all five wrap sites (`NumericRenderer` x3, `OperandText` x2); a FLOAT-LONG / COMP-2 / FLOAT-SHORT / FLOAT-EXTENDED sender is never EC-DATA-NOT-FINITE. Witness `conformance:2023/pb1684_implementor_float_is_not_checked_for_nonfinite`; `ec_data_not_finite` moved to FLOAT-BINARY-64 / -32 (it had asserted the raise on COMP-2/COMP-1); `SendingRefDriftTests` holds the usage scope.
