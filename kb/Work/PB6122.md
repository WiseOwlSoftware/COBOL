# PB6122 - PB5715 witnesses missing at 2014, and the method arm unreachable

1. The 2014 inventory rows for §2014:14.9.13.3 GR2 (EXIT in a GLOBAL declarative) and for the 2014 `EC-FUNCTION-*` exception names have no
   2014-edition golden. The 2002 rule rows accept at 2002 alone. The program ends the same at `--std 2014` (probed by the PB5715
   implementer, not a golden).
2. A method may carry no declarative (COBOL0899), so §2002:14.8.13.3 GR2's EXIT METHOD arm and PB5599's method observables stay
   termination-only. This shares its root with the method-declarative gap, which this note does not own: when the declarative-in-method
   restriction is decided, add the witnesses.
