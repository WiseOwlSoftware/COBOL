# PB3991 — a version bump hides an emitter change's NIST reach from leg 1

**Sites:** `scripts/spec/impacted_tests.py` (`reach_cs`)

PB3869's fix bounced in the merge queue (#716, run 40612629630) on the CCVS85 NOT-only SIZE ERROR programs, which the
local leg 1 never ran: the CI invariant (CLAUDE.md "Testing") says that is also a local-gate defect. c8afacb68 fixed one
cause (a declaration hunk now keeps the method hunks' tier-1 reach). The review of the next branch found a second: that
branch also changed `Directory.Build.props` (the version bump), which makes the impact plan take `every_tier1`, and that
path loses the method-level reach, so leg 1 again ran none of those 12 programs. Fix: a project-wide file's change adds
its own reach without replacing the method-level reach of the source hunks beside it; a drift test pins a branch that
touches both.
