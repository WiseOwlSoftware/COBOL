# PB5992 addendum, 2026-11-20: both leads ruled against the 1985 text

Compiler at main 8244f1aa4b plus the PB5986 change; probes under `--std 85` through `scripts/orchestrator/run_probe.py`.

## Lead 1: a contained program named like its container (§1985:X.1.3.8.1)

Probe: `OUTERP` containing a contained `OUTERP`, the outer calling `OUTERP`. It compiles and runs at `--std 85` and `--std 2023`
(stdout `INNER` then `OUTER`: rule (1) of the paragraph makes the contained non-common program the target of a CALL written in
its container).

The text (cite.py OK): "when two programs in a run unit are identically named, at least one of those two programs must be
directly or indirectly contained within another separately compiled program which does not contain the other of those two
programs." The contained `OUTERP` is contained within a separately compiled program (the outer `OUTERP`), and that program does
not contain "the other of those two programs", which is itself. The condition holds, so the pair is allowed. Two programs
contained in one container still break it (each is contained in a program that contains the other), which is COBOL2214. The 2023
text reads the same way: §2023:8.4.6.3 makes the names of CONTAINED programs unique within the outermost program and leaves the
outermost program's own name out of that set. Ruling: CONFORMS, no defect.

## Lead 2: a SEGMENT-LIMIT clause in a program with no sections (§1985:XVI.1.4.1)

Probes: `OBJECT-COMPUTER. X SEGMENT-LIMIT IS 20.` with a Procedure Division of paragraphs only (exit 0, the clause draws the
COBOL0903 obsolete warning this change adds), the same with an unnumbered section (exit 0), and a numbered section after a
paragraph outside every section (refused COBOL2797, §1985:IV.6.4.1.2).

§1985:XVI.1.4.1 says "when segmentation is used, the entire Procedure Division must be in sections" and never says what makes
segmentation used. The one classification the module reads is a section's segment-number (§1985:XVI.3.2.1), and a program of
paragraphs alone has no section to classify. A violation has an undefined result (§1985:I.1.6), so diagnosing it is the
implementor's choice; GnuCOBOL accepts the clause and ignores it. Ruling: accepted, recorded in `docs/conformance/3.8/index.md`
(a new row). A numbered section with a paragraph outside every section is already refused by §1985:IV.6.4.1.2.
