### Expected, from the standard
A syntax rule is a "shall", so each of these shall draw a compile-time diagnostic at every edition: `05 B REDEFINES A PIC X(4) VALUE "ZZZZ".`; the same at level 01; a VALUE on any entry SUBORDINATE to a REDEFINES entry; a GROUP-level VALUE on a REDEFINES entry; and, through SR16, a Format-2 `... OCCURS 3 VALUE "ZZ" FROM (1) TO (3)` inside a REDEFINES subtree. An entry with a REDEFINES clause and NO VALUE remains legal, and so does a level-88 under a REDEFINES.

```
$ python scripts/spec/cite.py --check 13.18.63.3 ".`; the same at level 01; a VALUE on any entry SUBORDINATE to a REDEFINES entry; a GROUP-level VALUE on a REDEFINES entry; and, through SR16..."
  FAIL: §13.18.63.3 exists but does NOT contain '.`; the same at level 01; a VALUE on any entry SUBORDINATE to a REDEFINES entry; a GROUP-level VALUE on a REDEFINES entry; and, through SR16, a Format-2 `... OCCURS 3 VALUE'
$ python scripts/spec/cite.py --check 13.18.63.3 ", so each of these shall draw a compile-time diagnostic at every edition: `05 B REDEFINES A PIC X(4) VALUE"
  FAIL: §13.18.63.3 exists but does NOT contain ', so each of these shall draw a compile-time diagnostic at every edition: `05 B REDEFINES A PIC X(4) VALUE'
```

### Observed
ALL FIVE COMPILE CLEAN and the VALUE is silently discarded. MEASURED at the pin, --std 2023: (a) `05 A PIC X(4) VALUE "AAAA". 05 B REDEFINES A PIC X(4) VALUE "ZZZZ".` -> A and B both display [AAAA] (b_sr12_run); (b) the level-01 form -> both [AAAA] (c_sr12_01_redefines); (c) `05 B REDEFINES A. 10 C PIC X(2) VALUE "ZZ".` -> A [AAAA], C [AA] (b_sr12_sub_run); (d) a group-level VALUE on the REDEFINES entry (c_sr12_group_value); (e) the SR16 Format-2 carrier -> A [AAAAAA], T(1) [AA] (d_sr16_sr12_sub). EDITION-INVARIANT -- the same program compiles at --std 85, 2002 and 2014 (b_sr12_85 / b_sr12_2002 / b_sr12_2014); Annex E records no change to SR12. The OVER-REJECTION CONTROLS pass: a REDEFINES with no VALUE compiles (e_sr12_control) and a level-88 under a REDEFINES compiles (sr12_88_under_redefines) -- both must STAY legal, which is the trap a careless landing falls into. Harm is under-rejection plus a silent drop: the stored value is the one 13.18.63.4 GR5/GR9 would give for the conforming spelling, so nothing is numerically wrong, but the programmer's second VALUE vanishes without a word.
