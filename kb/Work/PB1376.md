## Row GR-7.3.14.4-1 — PARTIAL (adjudicator + refuter record)

cite.py --check 7.3.14.4 'The implementor shall provide a warning mechanism that flags the incompatibilities potentially affecting existing programs' OK (GR1). The mechanism exists: a separate parse-tree pass emits COBOLNET1620 (Warning, per-option message + citation) whenever an ON option matches; documented in docs/DIAGNOSTICS.md line 108 (the A-list item 79 documentation duty). Per-option completeness is judged on the GR4 rows (b/e/f defects are recorded there, not here). Doc defect: docs/CONFORMANCE.md line ~528 still says the FLAG-02/FLAG-14 flags 'are not yet emitted' — stale against the pass (dossier gap). || REFUTED: PARTIAL — GR1 requires a warning mechanism that FLAGS the incompatibility. The cited mechanism, FlagConformancePass.Flag(option, line, where), uses `line` only for the IsOnAt fold and never puts it into the EditionDiagnostic, so position comes from the walk cursor. The post-walk path (FlagEcProgramDirectives, option b) runs after the cursor is gone. Its warnings therefore carry NO source location, and identical unlocated warnings collapse: two flagged >>TURN directives yield ONE warning. The mechanism works for the walk-time options c/d/e/f. The test-ref pins only option c, so it cannot show the mechanism is sound for every selected option.

**Code location:** src/Cobol.Net.Compiler/Validation/FlagConformancePass.cs#FlagConformancePass.Run; src/Cobol.Net.Compiler/Validation/FlagConformancePass.cs#FlagConformancePass.Flag; src/Cobol.Net.Editions/Diagnostics/DiagnosticCatalog.cs#Flag02Warning
