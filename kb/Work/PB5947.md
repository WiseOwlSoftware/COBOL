# PB5947 - the diagnostic summary's table of flagged constructs by edition is not built

**Sites:** `src/WiseOwl.Cobol.Frontend/Diagnostics/Diagnostic.cs` (`Diagnostic`), `src/WiseOwl.Cobol.Listing/ListingDocument.cs` (`ListingDiagnostic`), `src/WiseOwl.Cobol.Listing/Text/TextListingRenderer.cs` (`TextListingRenderer.SummaryRows`), `src/WiseOwl.Cobol.Listing/Html/HtmlListingRenderer.cs` (`HtmlListingRenderer.Sections.Diagnostics`), `src/WiseOwl.Cobol.Compiler/Listing/DiagnosticSectionBuilder.cs` (whole: the flag kind joins each record it builds)

**Found** by listing step 9 (w20262104j), checking every section of `docs/rearchitecture/DESIGN-listing.md` for what is built
(section 11, "What is not built"). Section 6.11, "Conformance flags": "The edition flags (COBOL0903 obsolete, COBOL0902 removed under
`--permissive`, COBOL2894 with `--flag-extensions`) are diagnostics and print inline; the summary adds a table of flagged constructs
by edition."

**On origin/main 9427f2ede0:** the flags print inline and in the summary's list (step 3), but neither the model nor a renderer has the
table: `git grep -n -i "flagged constructs"` finds only section 6.11; `TextListingRenderer.SummaryRows` prints the counts by severity
and the list; the HTML page's summary (step 9) the same. Section 11's step 3 paragraph (diagnostics) does not name the table, so no
step owned it.

**What building it needs (a design decision first, rule 2):**
- which diagnostics are edition flags: today a code (`COBOL0903`, `COBOL0902`, `COBOL2894`), which the listing would have to know as a
  list beside the diagnostic catalog; the root is a fact on the diagnostic itself (its kind: obsolete, removed, extension), carried by
  `Diagnostic` and `ListingDiagnostic` from where the flag is raised, so the table is a view of the records and a flag added later is
  in it by construction;
- what "by edition" groups by: the edition whose rule makes the construct obsolete, removed or an extension, read from the flag's
  citation (`ListingCitation.Edition`) or from the edition in force;
- the model member (in the diagnostics section or the statistics) and a schema minor bump only if 1.0 has frozen by then (section 7.3).
