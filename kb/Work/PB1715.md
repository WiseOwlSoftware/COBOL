# PB1715 — the ANTLR lexer never caches its default mode's start state

## Landed 2026-09-28 (wave 71 A, PB1708 pivot M6)

Each of the six predicates became an unconditional rule whose ACTION decides the match (actions do not suppress
DFA edges): `DEFINED` is a virtual token `IDENTIFIER`'s action retypes when primed (a literal `'DEFINED'` rule
would publish a literal name `CobolKeywordTokens` reads as "a keyword token"); `FNARG_SEPARATOR` matches the §8.3.5 2)
separator everywhere and `Skip()`s it outside an argument region (`COMMA_SEP` deleted); the four `FN_SIGNED_*`
twins call `OnSignedLiteral`, which keeps the signed literal where `SignedLiteralCanStart()` holds (now asked of
the character before the TOKEN'S start) and otherwise cuts the token back to its `PLUS`/`MINUS` sign, re-seeks to
the digits and restores the column. `LexerDfaCacheDriftTests` (Unit) holds the invariant with an input-side DFA-walk
probe over a private DFA — the designed "counting `LexerATNSimulator` subclass" is impossible, ANTLR's
`MatchATN`/`ComputeTargetState` are not virtual (DESIGN-test-build-ci.md §3.14.5 corrected).
- Differential: every distinct (input, priming) the three test assemblies lexed on the old grammar — 17,055 inputs,
  9,955,488 tokens — replays to identical token streams (type, channel, offsets, line, column, text, errors, mode).
- Plants: the old grammar is red (5,216,645 start-state misses); a predicate one character into `DEFINED` is red
  (68,289 mid-token misses). Re-lex of the suite's real lexer inputs: zero ASCII misses; non-ASCII residual 77,196.
- `b2` (`evidence/impact-map-pb1708/b2-scaling/b2-after-m6.txt`): 1 thread 110.1 s → 3.4 s; 12 threads 2.0 s (55×),
  zero lock contention; CPU 21 % at 12 threads — now bounded by workstation-GC pause (server GC: 87 %).

For the next implementer:
- `src/Cobol.Net.Frontend/Grammar/Core/CobolLexer.g4#OnSignedLiteral` — the one place a sign-adjacent literal is
  decided; never put a `{…}?` predicate on a lexer rule (LexerDfaCacheDriftTests goes red, 3 s).
- `tests/Cobol.Net.Tests.Unit/LexerDfaCacheDriftTests.cs#ProbedCharStream` — reuse it to measure any lexer change's
  DFA behaviour; the trap: a lexer over the static DFA measures what other tests lexed first — use a private DFA.
- `CobolLexer.g4#IDENTIFIER` / `#RetypeDirectiveKeyword` — a word that is a keyword only in a primed region is a
  VIRTUAL token (`tokens { }`) retyped here; the trap: a literal rule publishes a vocabulary literal name, and
  `CobolKeywordTokens` + `CobolWordsDriftTests` read literal names as "always a keyword token".

## Defect

`src/Cobol.Net.Frontend/Grammar/Core/CobolLexer.g4`'s default mode has six rules with a semantic predicate at their
LEFT EDGE: `FN_SIGNED_FLOATLIT`, `FN_SIGNED_COMMA_FLOATLIT`, `FN_SIGNED_DECIMALLIT`, `FN_SIGNED_INTEGERLIT`,
`DEFINED` and `FNARG_SEPARATOR`. With a predicate there, ANTLR 4.13.1's `MatchATN` never caches the mode's start
state (confirmed by decompiling `MatchATN`), so every token recomputes it (`ComputeStartState`) and re-adds it with
`AddDFAState` under `lock(dfa.states)`.

## Harm

This is a PRODUCT speed defect. Every `cobol` compile pays ATN simulation per token, serially. Parallel compiles
(the test suite; any host compiling in parallel) contend on one Monitor.

**Evidence** (`docs/rearchitecture/evidence/impact-map-pb1708/b2-scaling/`):
- the in-process CompileNist check-only probe peaks at 3.5x by 8 threads;
- CPU use falls to 15 % at 24 threads;
- there are about 1,400 contended Monitor acquisitions per compile;
- 28 of 30 single-thread samples and 24 of 24 twelve-thread stacks are in `ComputeStartState`/`AddDFAState`, with
  12 of the 24 blocked in `Monitor.Enter`.
It is the root of the continuity cells' one-process limit (b6).

## Fix (PB1708 pivot M6; `docs/rearchitecture/DESIGN-test-build-ci.md` section 3.14.5 and the section 3.14.9 row)

After warm-up the lexer performs no ATN simulation: move each predicate off the left edge, or turn it into a mode.
`LexerDfaCacheDriftTests` goes red on a planted left-edge predicate and on one placed after a common prefix's first
character.

**Acceptance:**
- the token streams of every suite source are identical before and after (a one-time differential);
- zero ATN simulation on re-lexing the suite's ASCII sources, with the non-ASCII residual reported;
- b2 at 12 threads is at least 8x today's 1-thread wall, with CPU use of at least 70 %;
- the whole battery is green.

## Harm flag

`process_only: true` because the register has no harm flag for COMPILE-TIME PERFORMANCE: the defect changes no
program's output or diagnostics, only how long the compile takes. It is a product defect all the same (it ships in
the `cobol` CLI).
