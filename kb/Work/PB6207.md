# PB6207 - OPEN - `IF N > 1 AND.` keeps the generic COBOL0001

**Repro.** `IF N > 1 AND.` (the sentence ends after AND). The compiler reports the generic COBOL0001 and names nothing the
statement needs. PB6119 named the cut-off forms of `SET I TO.`, `COMPUTE N =.` and `IF N = .`; this one stayed bare.

**Mechanism.** After AND or OR in an abbreviated combined condition the parser admits an operand and also the relational
operators (the abbreviated form `N > 1 AND < 5` repeats the subject with an operator alone). `AdmittedKinds.Refusal` names a
missing operand only when the admitted set holds no symbol, so the operators in the set veto the naming.

**Fix shape.** Tell "an operand or an operator is due after AND/OR" from "an operator is due after a completed operand"
(`IF N.`, where the operators alone are due): name the first case as an operand-or-operator position, with the symbol test
kept for the second. Add the probe as a golden diagnostic case beside PB6119's.

**Sites:** `src/WiseOwl.Cobol.Frontend/Parsing/AdmittedKinds.cs:93` (`AdmittedKinds.Refusal`)
