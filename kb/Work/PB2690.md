# PB2690 — one pair conversion at the activation boundary, over static atoms

## What was found (w1042 C, PB2496, landed in train 1042)
PB2496 moved MOVE and the relation condition onto ONE pair conversion, `CobolVarGroup.Reshape`/`Compare` over the
two operands' `GroupAtom` shapes, which recurse per element into a nested dynamic table of variable-length elements.
The activation boundary did not move with them:

1. **LOUD on legal source.** At CALL (`CallAbi.Text`, `TextValue`, `VarGroup`, `VarGroupValue`, `StoreReturn*`) and at
   INVOKE (`OoEmitter.FixedArgumentSpans`, `VarPlaceSpans`) a fixed-length group facing a variable-length group is
   still paired by flat `CorrespondingSpans`, which carry no element layout. A fixed group opposite a dynamic-capacity
   table of variable-length elements therefore reaches the named refusal in the span adapters (`ToFixedImage`,
   `OverlayFixedImage`, `ElementCarriersAt` refuse a nested component by name), where §14.2.3 GR8/GR9 and
   §8.5.1.12.1 make the pair legal when the groups are compatible.
2. **PERF.** The atom arrays for `Compare` and `Reshape` are emitted inline (`RuntimeApi.GroupAtomsNew`, used by
   `RuntimeApi.cs` lines ~1886 and ~1911, and by `CallEmitter.BoundaryAtoms` / `ProgramEmitter.GroupFormalAtoms`),
   so every execution of a variable-length MOVE, comparison or CALL allocates them; `Compare` also re-walks the
   correspondence on every call.

## Fix shape (one mechanism)
Move `CallAbi` and `OoEmitter` to `Reshape` with `(image, [])` for the fixed side and the argument/formal atoms, as
MOVE does since PB2496, and delete `FromFixedImage`, `ToFixedImage`, `OverlayFixedImage` and `CorrespondingSpans`
(rule 4: no adapter left behind). Emit each distinct atom array ONCE as a `static readonly GroupAtom[]` field of the
program class and reference it, and let the runtime cache the correspondence walk per atom-array pair.

## Repro
Variant of `tests/conformance/2014/pb2496_vlg_dynamic_element_tables_call.cob` whose actual argument is a FIXED group
of the formal's element layout (a fixed OCCURS table of fixed elements) passed BY REFERENCE to a formal that is a
dynamic table of variable-length elements: aborts with the named NotImplemented in the span adapter.
