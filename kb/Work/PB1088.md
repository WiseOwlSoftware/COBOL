# PB1088 — OPEN — a contained program never sees its container's `SOURCE-COMPUTER … WITH DEBUGGING MODE`: `DataBinder.InheritConfiguration` copies `DebuggingModeDeclared`, then `

## Rule text (every citation re-run by the registrar)
- `python scripts/spec/cite.py --check 12.3.5.4 "All clauses of the SOURCE-COMPUTER paragraph apply to the source unit in which they are explicitly or implicitly specified and to any source unit contained within that source unit"` → `OK  §12.3.5.4 1)  (General rules)`

### Adjudicator finding (source-computer-paragraph, harm wrong-answer)
- **Mechanism:** Contained-unit binding overwrites the inherited SOURCE-COMPUTER WITH DEBUGGING MODE switch: DataBinder.InheritConfiguration copies the container's DebuggingModeDeclared, then DataBinder.BindDeclarations reassigns it from the contained unit's own (necessarily absent) configuration section, so a 1985 contained program never sees its container's compile-time debug switch — while VersionConformancePass inherits it (two-arm split).
- **Repro:** cobol nest85.cob --std 85 --run  (probe/source-computer-paragraph/nest85.cob): outer program SOURCE-COMPUTER. IBM-PC WITH DEBUGGING MODE. CALLs contained program SCINNER whose DECLARATIVES hold DBG SECTION. USE FOR DEBUGGING ON ALL PROCEDURES. DBG-BODY. MOVE DEBUG-NAME TO NM. DISPLAY "DBG N=" NM. and whose paragraph P-IN displays INNER.
- **Expected (spec):** OUTER / DBG N=P-IN / INNER — §12.3.5.4 GR1: all clauses of SOURCE-COMPUTER apply to any contained source unit (and §12.3.4 GR1 for the configuration section generally); the contained program cannot restate the clause (§12.3.3 SR1), so inheritance is its only route. Object-time switch ON is the compiler's existing posture (conformance:85/wavef_dbg_proc).
- **Observed:** Observed: OUTER / INNER — byte-identical to the control without WITH DEBUGGING MODE; the contained debugging section is silently compiled as comment lines. Cause read in code: BinderDriver calls InheritConfiguration (sets DebuggingModeDeclared = container's) then data.Bind -> BindDeclarations line ~445 unconditionally assigns DebuggingModeDeclared = EnvDivisions(program).Any(...debuggingModeClause()...). Fix shape: OR the own clause into the inherited value (or skip the reassignment for contained units), matching VersionConformancePass's per-top-level-unit reset.
- **Code site:** src/Cobol.Net.Compiler/Binding/DataBinder.cs#BindDeclarations (DebuggingModeDeclared assignment, ~line 445) vs src/Cobol.Net.Compiler/Binding/DataBinder.Switches.cs#InheritConfiguration (~line 463)
- **Clause (adjudicator):** §12.3.5.4 GR1 (with §12.3.4 GR1, §12.3.3 SR1); X3.23-1985 WITH DEBUGGING MODE

## What the fixer owes
OR the unit's own clause into the inherited value (never overwrite) at `BindDeclarations` ~line 445; sweep every other field `InheritConfiguration` copies for a later unconditional reassignment in `Bind` (the same overwrite would silently undo each). Golden at 85.
