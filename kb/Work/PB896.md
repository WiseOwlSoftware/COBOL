# PB896 — LANDED — a rule that changes which KIND of move a statement is

Source: the `PB425` report, "New defects" item 2, which recorded it as out of PB425's own shape.

## The rule

```
$ python scripts/spec/cite.py --check 14.9.25.4 "is evaluated only once, immediately before data is moved to the first of the receiving operands"
  OK  §14.9.25.4 1)  (General rules)
```

GR1 is the clause; its zero-length sentence (`--find "zero-length item, it is as if literal-1 were specified
as a zero-length literal"`, recorded by the PB425 implementer as `OK §14.9.25.4 1)`) re-reads the statement
with a zero-length LITERAL in place of the sender. §8.5.4 items 2, 5 and 7 are what make a GROUP a
zero-length item:

* a group whose only member is a zero-length item,
* a zero-length variable-length record,
* a variable-length group of empty dynamic tables.

**Because the substituted sender is a literal, the statement is no longer a GROUP move under §14.9.25.4 GR4 —
it becomes an ELEMENTARY move**, with the receiver's own category rules. That is a change of KIND, not of
length, which is why it cannot be handled inside the group-move path.

## The code site

`src/Cobol.Net.Compiler/Binding/Bound/MoveClassifier.cs#ZeroLengthItemRoute` — the route exists and asks the
elementary question only; the §8.5.4 group predicate is not asked anywhere.

## NOT MEASURED HERE, and why that is recorded rather than hidden

Building the three §8.5.4 group shapes needs a variable-length group with an empty dynamic table, which
is the same construct whose whole-group image is a Tier-C abort on this tree (`PB878`'s p38 probe reaches it
from INITIALIZE). A probe that dies in the Tier-C island tells you nothing about the classifier, so the
fixer must reach the classifier through a unit test on `MoveClassifier` first, and only then write the
behavioural golden.

## LANDED — 2026-09-21, wave 42 (group MOVE OPERANDS)

MEASURED FIRST, because this note was filed without a measurement. `<scratch>/probe/p24_zl_odo.cob`, §8.5.4

```

         NUM=[   ]    EDIT=[   ]   ALPH=[    ]
```

GR1 makes those two statements the SAME statement — *"If identifier-1 is a zero-length item, it is as if
literal-1 were specified as a zero-length literal"* — and they disagreed on the numeric receiver alone, which is
exactly the receiver filter `MoveClassifier.ZeroLengthItemRoute` already carried for the elementary shapes.

The fix is the route's SENDER filter, and the predicate is **§8.5.4's stem as one structure**:
`DataItem.MinimumLengthIsZero` — *"A zero-length item is a data item or a literal whose minimum length is zero
and whose length at runtime is zero"* — a recurrence over the non-redefining children at their MINIMUM occurrence
count (integer-1 of an OCCURS DEPENDING, zero for a DYNAMIC-capacity table), not four copies of the clause's
group bullets. `MoveEmitter.Emit`'s zero-length arm now puts the statement's OWN store in its else branch
(`EmitStore`, factored out) instead of an else hard-wired to the elementary one, because GR1's substitution
CHANGES THE KIND: GR4's first sentence makes the substituted-literal move elementary while the non-zero arm stays
the group move. The length tested for a group is the group's SENDING IMAGE, which §13.18.38.4 GR8 a) already
narrows to the current extent; the plain place would read the maximum and the test could never fire.

WHICH OF §8.5.4's FOUR GROUP SHAPES IS REACHABLE, measured rather than assumed: only item 1. Items 5 and 7 —
and any group holding a dynamic-length member — are VARIABLE-LENGTH groups, and §14.9.25.3 SR9 refuses a
variable-length group against a non-group receiver at compile time (COBOLNET1931), so GR1's run-time
substitution is never reached for them. `tests/conformance/negative/pb896-variable-length-group-to-elementary`
is the witness for that, and the predicate covers the other three without a second site if SR9 ever admits one.

Goldens: `tests/conformance/85/pb896_zero_length_group_sender` (the zero-length arm, the written-literal control
that makes the two answers owed to be equal, and the non-zero-extent complement) plus
`tests/Cobol.Net.Tests.Unit/ZeroLengthItemDriftTests` (each enumerated §8.5.4 shape asked of the recurrence, and
the ordinary shapes asked too). `GR-14.9.25.4-1` — the row this closes a sentence of — is held and re-verdicted
by `kb/Work/PB394`.
