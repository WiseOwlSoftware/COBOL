# PB3320 — DOC-A.1 band versus documented-rule band

Filed by the clerk from lead 2 of the PB3173 report (`E:\COBOL-coord\scratch\reports\w1104c2-PB3173-report.md`, "New defects (leads)"). PB3173's branch is PR #173; this note's work starts once it is on main and PB3321 is decided.

**Mechanism.** The DOC item band versus documented-rule band has no mechanical check. 28 DOC rows start at a different edition from the earliest rule their A.1 text names (for example DOC-A.1-40/-43/-65/-68/-117/-126 start earlier). Deciding them needs the reading rule PB3321 asks for ("core obligation" versus "as worded").

**Repro.** `python E:\COBOL-coord\scratch\w1104\w1104c2\docsweep2.py`

**Fix shape (for the implementer to confirm).** Once PB3321 is decided, add a drift test in `SpecTraceabilityInventoryDriftTests` that compares each DOC-A.1 item's band with the earliest rule its A.1 text names, and re-decide the 28 rows in one `record_verdicts.py` batch.

**Resolution (wave 20262148 group E, 2026-11-23).** The reading is docs/VERSION_TEST_MATRIX_DESIGN.md P2.10: an A.1 item's band never starts before the earliest rule row its text names; a later start is the adjudicator's reading (the item names an arm or facility the earlier text lacks); an 85 start means the 1985 text leaves the same latitude (1985 has no Annex A), which also answers the BASE85 addendum.
- The sweep on the per-rule store (a port of the note's `docsweep2.py` that reads rule references strictly) printed 26 rows that differ: 18 start later than the earliest rule they name (each a facility decided in PB3173 and upheld by PB3322: national characters, EC conditions, hexadecimal literals, function prototypes, line sequential) and 8 earlier. Of the 8 earlier, `DOC-A.1-117` and `-68` name whole clauses (not rule-only references); `-64`, `-43` and `-131` are exempt on a recorded determination of the behaviour at the earlier edition (§2002:11.8.5.3 GR2; DOC-A.1-43's determination; the owner's PB670 option (i), which also keeps `-77` at 85); `DOC-A.1-65` ("EXIT and GOBACK statements") is exempt too: its EXIT PROGRAM arm is 1985 text (§1985:II.6.1) and its GOBACK arm starts at §2002:14.8.17.3 GR2. No row changes band. A first batch moved `-43`, `-65`, `-77` and `-131` to 2002; the gate's conformance suite refused it (their 85 goldens, `l1c06_currency_non_cobol_equivalence_85` and `pb670_cobol85_no_sharing_facility`, witness recorded determinations) and review R1-1 showed `-65` covers EXIT PROGRAM, so all four stay at 85.
- One mechanical check now holds the early direction: `DocItemBandDriftTests.EveryDocItem_StartsNoEarlierThanTheRulesItNames`.
