# PB1029 — LANDED (wave 54 group G)

## The mechanism
PB909 made `BoundRejected.Report` the one refusal constructor that cannot exist without its diagnostic (COBOLNET2319's
check). The older idiom (report, then return an inert node) and the four error-node kinds bypass it: nothing stops a
future site from constructing the node without reporting, and PB982 is the measured instance (compiles clean, aborts at
run time). BoundOperandError / BoundExprError also carry PB909's two jobs at operand level (e.g. a STRING sending `ALL`
literal, §14.9.43.3 SR2): measure which report before they are staged.

## What the fixer owes
One private constructor per error-node kind reachable only through a factory that takes the diagnostic; migrate the
~150 `Error+BoundNop` sites to `BoundRejected.Report`; a Roslyn/semgrep rule that forbids `new BoundNop()` after an
`Edition.Error` in the same block. Each kind's crash shape gets one negative golden.

## Landed (wave 54 group G)
Re-probed on this worktree's build (base `57d36e4c6`, 0/0): `STRING ALL "AB" DELIMITED BY SIZE INTO X`,
`STRING "AB" DELIMITED BY ALL "B" INTO X`, `INSPECT X TALLYING N FOR ALL ALL "A"`, `INSPECT X TALLYING N FOR ALL 1`,
`COMPUTE B = B B-AND SPACE` and `FUNCTION SUM(E(ALL, ALL))` over a one-OCCURS table all compiled with NO error and (the
two STRING probes, run) aborted with `NotImplementedCobolFeatureException`; with the ledger in place and before the
sites were given diagnostics, every one of them drew the new internal COBOLNET2362 — the net measured each silent
refusal. After: COBOLNET1757 (STRING SR2, INSPECT SR3 ×2), COBOLNET1511 (§8.8.2), COBOLNET2097 (§8.4.2.3.3 SR3; its
undefined-name sibling now reports through the resolver's own `ReportUnidentified`).
- Rule: `cite.py --check 14.9.43.3 "Literal-1 or literal-2 shall not be a figurative constant that begins with the word
  ALL"` → OK §14.9.43.3 2); `--check 14.9.22.3 "Each literal shall be an alphanumeric, boolean, or national literal"`
  → OK §14.9.22.3 3); §8.8.2 "the figurative constant ZERO (ZEROS, ZEROES)" (`--check 8.8.2` → OK); `--check 8.4.2.3.3
  "the number of subscripts shall equal the number of OCCURS clauses in the description of the table element being
  referenced"` → OK §8.4.2.3.3 3); `--check 14.9.43.4 "When a figurative constant is specified as literal-1 or
  literal-2, it refers to an implicit one character data item"` → OK §14.9.43.4 2).
- Fix: THE REFUSAL LEDGER on `EditionContext` (`ErrorsRecorded` counts every Error call, a de-duplicated repeat
  included; `NoteRefusal`; `NoteUnbuilt`/`TakeUnbuiltSince`), read by the ONE funnel `StatementBinder.BindStatement`:

  / `BoundOperandError` / `BoundBoolError` became closed types (private constructor; `Refused` / `Unbuilt` / `Carry` /
  `Report`); `BoundRejected` gained `Report(edition, code, message)` for the bare-code sites and `Reported(edition)`
  for a refusal a callee reported; `ConditionBinder.Refused` routes through the same `NoteRefusal` (keeps 2319).

  catalogued); 98 callee-reported `BoundNop` sites → `BoundRejected.Reported`; 14 reference-resolver-null `BoundNop`
  sites (ACCEPT/INSPECT/STRING/UNSTRING receivers, SET receivers) → `BoundUnsupported` — they used to DROP the
  statement silently when the null was an unbuilt shape; ~120 operand error constructions classified (9 `Unbuilt`,

  '85 ENTER, the accept-inert Declined arm, and the three record-less-SD arms (a lead, see the report).

  shapes). `BoundDeferralDriftTests` factory list updated.

  `conformance:negative/pb1029-string-all-literal`, `pb1029-inspect-numeric-literal`,
