# PB1029 — OPEN

## The mechanism
PB909 made `BoundRejected.Report` the one refusal constructor that cannot exist without its diagnostic (COBOLNET2319's
check). The older idiom (report, then return an inert node) and the four error-node kinds bypass it: nothing stops a
future site from constructing the node without reporting, and PB982 is the measured instance (compiles clean, aborts at
run time). BoundOperandError / BoundExprError also carry PB909's two jobs at operand level (e.g. a STRING sending `ALL`
literal, §14.9.43.3 SR2): measure which report before they are staged.

## What the fixer owes
One private constructor per error-node kind reachable only through a factory that takes the diagnostic; migrate the
~150 `Error+BoundNop` sites to `BoundRejected.Report`; a Roslyn/semgrep rule that forbids `new BoundNop()` after an
`Edition.Error` in the same block. Each kind's crash shape gets one negative golden.
