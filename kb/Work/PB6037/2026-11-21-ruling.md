## 2026-11-21 — decided and encoded (wave 20262132 group i): PB5754's rule has a C# arm

**Decision** (the codebase owner's, recorded here per CLAUDE.md "Ownership"). A `unit:` or `conformance-test:` reference
of a 1985 inventory row witnesses the row only when the program text the test compiles at `--std 85` is fixed form
(`InitialReferenceFormat.Fixed`, or a suite case's stated format through `TestSourceFormat.OfSuiteCase`), or when the test
compiles no program text (a runtime, binder or lexer member driven directly: no reference format is in question). Free
text (`TestSourceFormat.Inline`) at 85 is a regression test of the `--source-format free` extension, and a compile at a
later edition only witnesses no 1985 row. Why not the other branch of the note's question (a rule that "does not depend
on the reference format" still witnessed by free text): which rules depend on the format is a judgment per row that no
tool can hold, while "the text is 1985 text" is one fact a test can check, and every witness the measurement found that
compiles text was already laid out in fixed columns, so the stronger evidence cost nothing.
