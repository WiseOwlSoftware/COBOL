# PB5471 - at --std 85 an identifier-2 that COPY REPLACING writes over two lines keeps the D of its own debugging line instead of the replaced line's indicator, so its qualifiers vanish from the program (COBOL1639)

**Sites:**

- `src/WiseOwl.Cobol.Frontend/Preprocessor/CopyProcessor.cs` (`CopyProcessor.IntroducedText`, `CopyProcessor.ApplyReplacements`)

**Mechanism.** GR11 gives an introduced line "the same character as the line on which the text being replaced begins", and GR9 puts BY-phrase words on a debugging line only where the replaced library word is on one or where the words sit on a debugging line "within pseudo-text-2"; identifier-2 is neither. `ApplyReplacements` and `IntroducedText` carry the indicator of the COPY statement's own line for a non-pseudo-text operand written over two lines, so the `OF B1 OF C2` written on a D line of the COPY statement lands on a debugging line of the resultant program and, without WITH DEBUGGING MODE, is a comment. The word-2 arm is right (`q15w`).

**Found by.** The 1985 code read, read 4 (`kb/Work/PB4996/2026-11-13-read-4.md`): the refuter of `E:/COBOL-coord/scratch/coderead-85/out-read4/rd-06-refute.json` OVERTURNED the read's CONFORMS of 1985-GR-XII.2.4-11.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. Its rows are recorded naming this note (records-rd4).

**Observed (the pinned compiler of `E:/COBOL-wt/coderead85-tree-d` (main 725550baca, the base of this branch), rerun 2026-11-13 from copies in `E:/COBOL-coord/scratch/op-20261113/records-rd4/rerun/`; the log is `E:/COBOL-coord/scratch/op-20261113/records-rd4/rerun-log.txt`).** `q15`: `LQ15.cpy(1,24): error COBOL1639: 'A1' does not uniquely identify a data item`, exit 65; `q15d` prints `[Z]`; `q15w` prints `[Q]`.

**Expected (from the 1985 text).** `q15` and `q15d` both print `[Z]`: the replaced line has a space indicator, so every line the replacement introduces is a source line.

**Fix direction (root cause, CLAUDE.md rule 4).** Give every line a non-pseudo-text operand introduces the indicator of the replaced line (GR11), and keep the debugging-line placement of GR9 for pseudo-text-2 only; sweep the REPLACE twin (§1985:XII.3.4).
