# PB2115 — R0 census (DESIGN-architecture-review §3 R0; `brent-tools:architecture-audit` Phase 0)

Opinions come after measurements. This builds the measuring instrument and runs it once at a recorded baseline
commit. **Model:** Opus builds the tool (a Roslyn `MSBuildWorkspace` pass, per `brent-tools:roslyn-analysis`, never
grep); Sonnet re-runs it later. **Prerequisite:** none; it runs on the tree as it is, and is re-run after PB2110.

## Output

1. `scripts/arch/census.py` (or a `tools/` C# console the script drives) writing one JSON under
   `docs/rearchitecture/evidence/arch-census/<sha>.json`: per type including every partial — lines, members, fields,
   fan-in, fan-out, folder-equals-namespace; per project — the dependency graph; clone families (type-2); members
   with NO reference in the solution, measured (reflection-visible and generator-emitted members excluded by a stated
   rule, never by assumption).
2. The god-class census: every type over ~800 lines across partials, with its responsibilities NAMED in the
   finding (DataBinder, DiagnosticCatalog, IntrinsicBinder, ReferenceResolver, VersionConformancePass,
   ExceptionState, BoundTree, RuntimeApi are the 2026-09-29 starting list; R0 re-measures).
3. Every finding becomes a `kb/Work` note of `kind: analysis`, `area: architecture`, `cluster: ["PB1754"]`, with its
   code site, the rule it breaks, a concrete scenario, the target and the wave kind (extract · unify · move and
   rename · data-ize · **delete**). The clerk files them from the tool's structured report; nothing stays in a
   report or a plan section (CLAUDE.md rule 8).
4. A drift test that the census population equals the solution's compiled type population, so the instrument
   cannot silently skip a project.

## Rules

Reachability is measured, not deduced (`engineering-standards`). The census never edits production code. The
performance baseline is PB2117 and the oracle capture PB2116: three instruments, three notes, one R0.

## Landing (wave 1026 C, 2026-10-07)

**The instrument.** `scripts/arch/census.py` (policy) drives the Roslyn host `tools/ArchCensus` (facts; MSBuildWorkspace,
Microsoft.CodeAnalysis 5.0.0, never part of `CobolSharp.sln`) over a DETACHED worktree at one commit, and writes
`docs/rearchitecture/evidence/arch-census/<sha>.json` plus `<sha>.findings.json`. Run at the base `a02b165da`:
2,087 census types (1,413 authored), 52 god-class candidates (DataBinder 20,375 lines across 24 partial files,
DiagnosticCatalog 6,841, CobolIntrinsics 3,523, ReferenceResolver 3,386, IntrinsicBinder 2,977), 9 type-2 clone
families (162 duplicated lines; the roslyn-analysis skill's `detect-clones.cs` over the same tree reports the same 9),
219 unreferenced and 266 test-only members, 1 unreferenced type, 15 dead artifacts, 234 findings.

**How reachability is measured.** One semantic walk binds every name, construction, constructor initializer,
attribute, indexer, user-defined operator and conversion, `foreach` pattern member, deconstruction, collection
initializer `Add` and positional pattern; a use inside the member's own body is not a use, and a use bound to an
override also uses its override chain. Every member the walk leaves unused is RE-QUERIED with `SymbolFinder`
(cascading; an XML-doc `cref` is not a use), and the walk's misses are recorded (3, all interface members whose
implementations are used). Exclusions are stated rules the record carries: entry-point, implicit-call,
framework-dispatch, dispatch, reflection-attribute, serialized, emitted-text (a `Cobol.Net.Runtime` member whose
name the code generator writes inside a string literal), named-in-string, record-positional, enum-member.

**The population check.** For every census project the types the workspace saw must equal the type definitions of
the BUILT assembly's metadata (`System.Reflection.Metadata`, an independent reader; `[CompilerGenerated]` types are
the one stated exclusion), or no record is written. `ArchCensusDriftTests` (Unit) runs `census.py --self-test`
(19 arms) and holds the newest record to the solution's `src/Cobol.Net.*` projects and to its own population.
