# PB5642 - at --std 2002 a floating-point literal is left out of the composite of operands of ADD and DIVIDE, so a 36-digit composite is accepted

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/Validation/StatementValidation.cs#CheckComposite` (its InComposite test, about line 1315)

**Mechanism.** StatementValidation's composite check skips a floating-point literal (`case BoundNumLiteral lit when !NumericLiteral.IsFloatingPointForm(lit.Text)`, the PB155 exclusion from §2023:14.7.7 rule 2), at every edition. 2002 14.6.6 rule 2 excludes only intrinsic functions and binary/float usages, not a floating-point literal.

**Inventory.** Rows claimed: `2002-SR-14.8.2.2-1`, `2002-SR-14.8.11.2-4`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:14.8.2.2 SR1`: "When native arithmetic is in effect, the composite of operands described in 14.6.6, Arithm"
- `§2002:14.6.6`: "When none of the operands is an intrinsic function or a data item described with usage bin"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p3/add_composite_float_lit.cob); the text is inline. Command: `cobol.exe p3/add_composite_float_lit.cob --std 2002 --run`

`p3/add_composite_float_lit.cob`:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. ADDCFL.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 X PIC 9(18)V9(13) VALUE 1.
       PROCEDURE DIVISION.
           ADD 1.234567890123456789E0 TO X.
           DISPLAY "X=" X.
           STOP RUN.
```

**Observed.** ADD 1.234567890123456789E0 TO X (X PIC 9(18)V9(13)): compiles and prints X=000000000000000002.2345678901234, rc=0; the fixed-point twin is refused COBOL0805 (36 digits).

**Expected (from the 2002 text).** refused COBOL0805: composite of 18 integer + 18 fraction digits exceeds 31.

**Sibling sweep.** SUBTRACT, MULTIPLY, COMPUTE-free arithmetic statements and the CORRESPONDING forms that use the same composite check.

**Other editions.** 2023: no (the exclusion is 2023 text). 2014: unknown. 85: n/a (no floating-point literal).
