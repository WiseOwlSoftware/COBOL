## The compiler is RIGHT; the record is STALE

The `BIN` row asserts that a group RETURNING item with a `PIC 9(4) USAGE BINARY` leaf draws
`COBOLNET1510`. **[[PB164]]'s F8 finding deliberately deleted that reject** (commit `06d9fa31`,
DEVLOG 1406): `UdfBinder.UdfReturningResidue` had hand-rolled the DISPLAY-only union
`{ Category: Numeric, IsFloat: false, Usage: Display }` and was widened to the derived predicate
`DataItem.ElementImageCapable`. The commit message states the intent in its own words — the old screen
"rejected conforming source (ISO §14.2.2 SR5 places NO category restriction on a RETURNING item)" — and
`DisplayUsageUnionDriftTests`' class comment says the same.

**Spec ground, re-derived rather than inherited** (both `cite.py --check`ed):

- §14.2.2 SR5 — the RETURNING-item rule, and the *only* one: "Data-name-2 shall be defined as a level 01
  entry or level 77 entry in the linkage section. The data description entry for data-name-2 shall not
  contain a BASED clause or a REDEFINES clause." Level, section, and two forbidden clauses — **no USAGE
  and no category restriction whatsoever**.
  ⚠ SR**1** is the *data-name-1* rule (the USING formals) and answers a different question; the inherited
  wording "§14.2.2 SR5" in `06d9fa31` is the CORRECT one and was re-derived here rather than trusted.
  Note also that SR5's REDEFINES prohibition is on data-name-2 ITSELF — it says nothing about a
  subordinate entry, so `UdfReturningResidue`'s internal-REDEFINES arm remains an implementation residue,
  not this rule.
- §8.4.3.2.4 GR1 — "the description, class, and category of the temporary data item is that specified by
  the description in the linkage section of the item specified in the RETURNING phrase". The temp clones
  the description; it does not narrow it.

**Measured, not deduced** — the exact `BIN` shape, with values assigned in the function and read back
through a like group in the caller (the test row only ever asks whether it COMPILES):

```cobol
       PROGRAM-ID. PB199PROBE.
       REPOSITORY.  FUNCTION UDFBINPROBE.
       01 WS-G.  05 WS-A PIC X(2).  05 WS-B PIC 9(4) USAGE BINARY.

           DISPLAY "A=[" WS-A "] B=[" WS-B "]".
       FUNCTION-ID. UDFBINPROBE.

       01 L-X PIC 9(4).
       01 L-R.  05 L-R-A PIC X(2).  05 L-R-B PIC 9(4) USAGE BINARY.
```

Both leaves cross the activation boundary carrying their values. The widening is correct end-to-end, not
merely "it compiles".
