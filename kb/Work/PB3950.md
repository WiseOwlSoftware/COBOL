# PB3950 — golden L18 of pb3666_boolean_receiver_converts_characters: the contained program PB3666XB names the external record RX2 where 13.18.22.4 GR6 requires RX

**Sites:** none (the fix changes only the golden `conformance-suite/wiseowl/cases/14.9.25-MOVE/pb3666_boolean_receiver_converts_characters.cob:219`, program PB3666XB, its `.out` and header; outside the planner's campaign roots)

In `pb3666_boolean_receiver_converts_characters.cob` the contained program PB3666XB (line 219) describes the external
file FX with the first record named `RX2`, where the caller names it `RX`. The report states that 13.18.22.4 GR6 (cite.py
`--check` OK) requires each externalized name of the record description entries to be the same across the source elements
(GR5: a record's externalized name is its data-name); only the complete redefinition (RA2) may differ. The case header's
rules list also does not name `GR-13.18.22.4` for the new line. A golden that breaks the rule it relies on proves nothing
about the rule it means to pin.
