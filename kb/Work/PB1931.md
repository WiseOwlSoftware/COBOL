# PB1931 — OPEN

the lander.

## The defect

`python scripts/spec/cite.py --check 14.2.3 "occupies"` → `OK §14.2.3 8)`: "If the argument is passed by reference,
the activated runtime element operates as if the formal parameter occupies the same storage area as the argument."
So `SET WP TO ADDRESS OF FORMAL` inside the activated element yields the address of the caller's argument. Today the
formal's carrier is its own object: the pointer handed back compares unequal to the caller's `ADDRESS OF` the
argument, and a BASED item placed at it does not alias the argument (the write raises EC-BOUND-PTR).

**Repro.** `scratchpad/w1005c/p1419e.cob` of the orchestrator session 5ab816c6 (a CALL ... RETURNING a pointer set to
`ADDRESS OF` a BY REFERENCE formal; `IF WP2 = WP` prints DIFF; the BASED write traps EC-BOUND-PTR). A finisher should
copy it into a golden.

**Sites.** `src/Cobol.Net.Runtime/Control/CallAbi.cs` (`CobolArgAdapt` formal carriers) and
`src/Cobol.Net.Runtime/Control/ManagedPointer.cs#SameTarget`.
