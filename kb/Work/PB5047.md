# PB5047 - at --std 85 a SUM identifier-1 naming a SOURCE or VALUE report entry is accepted

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/ReportSectionBinder.cs` and `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.Reports.cs`, `ScreenRolledAddend`.

**Found.** `§1985:XIII.3.19.3 SR1` requires the report-entry identifiers of a SUM clause to be sum counters (its sentence "If the UPON phrase is omitted, any identifiers in the associated SUM clause which are themselves sum counters must be defined either in the same report group ..." passes `cite.py --check`). At `--std 85` a SUM identifier-1 that names a SOURCE or VALUE report entry (not a sum counter) is accepted. The exact SR1 sentence that requires a sum counter is to be re-derived and `cite.py --check`ed by the implementer before it enters code.

**Owed.** Refuse it at 85, pin it with a golden, and sweep the other editions' arms in `ScreenRolledAddend`.
