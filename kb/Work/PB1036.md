# PB1036 — OPEN

## Measured
```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. FOPEN.
       ENVIRONMENT DIVISION.
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT G-OUT ASSIGN TO "fopen.dat"
               ORGANIZATION IS SEQUENTIAL FILE STATUS IS GS.
           SELECT SRT-FILE ASSIGN TO "fopenw.tmp".
       DATA DIVISION.
       FILE SECTION.
       FD G-OUT.
       01 G-REC PIC X(3).
       SD SRT-FILE.
       01 SRT-REC PIC X(3).
       WORKING-STORAGE SECTION.
       01 GS PIC XX.
       PROCEDURE DIVISION.
       DECLARATIVES.
       D-SM SECTION.
           USE AFTER EXCEPTION CONDITION EC-SORT-MERGE.
       D-SM-P.
           DISPLAY "DECL " FUNCTION EXCEPTION-STATUS.
       END DECLARATIVES.
       MAIN SECTION.
       MAIN-P.
       >>TURN EC-ALL CHECKING ON
           OPEN OUTPUT G-OUT.
           SORT SRT-FILE ON ASCENDING KEY SRT-REC
               INPUT PROCEDURE IS FEED GIVING G-OUT.
           DISPLAY "AFTER GS=" GS.
           STOP RUN.
       FEED.
           MOVE "A" TO SRT-REC RELEASE SRT-REC.
```

prints **`AFTER GS=41`**: the as-if OPEN of the GIVING file fails with its own `41`, no EC-SORT-MERGE condition is
set, and the `USE AFTER EXCEPTION CONDITION EC-SORT-MERGE` declarative never runs.
