## Landed (wave 20261029 group A)

Re-probe on e5cf90436 plus the PB3155 follow-up. Of the six instances, the first five stay covered (tier 0h runs the
trait guard at every gate; tier 0d runs the drift tests the index says govern a changed file). The replay of the 35
Linux-red landing heads against today's index leaves four names ungoverned, none a rule the index could place: a lock
race (w1069c), a harness timeout (w1108a), an apphost rebuild (w1141i, PB3529) and `SpecTraceabilityInventoryDriftTests`
(w1077h, w1078d, PB3131's second form, landed). w1129g's `ConstantNameLiteralPositionDriftTests` is governed since PB3247
read helper classes (`SuiteManifest`), the form the previous report named as this note's remaining mechanism.

**The mechanism that was still open** is the same shape one level down: the index read a call's path with a regex over
arguments that held no parenthesis, so `TestRepo.Src(Path.Combine("WiseOwl.Cobol.Frontend", "Grammar"))`,
`Path.Combine(TestRepo.Root, GrammarDir)` (a class constant), `Path.Combine("src", ..)` and a wrapper method whose callers
spell the path (`Read("src", "WiseOwl.Cobol.Compiler", "X.cs")`) named nothing. 62 of the 391 drift tests read a path it
missed; five scan the grammar (`ArithmeticOperandRoleDriftTests`, `SendingOperandDriftTests`,
`ReceivingOperandFormDriftTests`, `LevelNumberArmDriftTests`, `ClassConditionTableDriftTests`) and governed no grammar
file, so a grammar edit's red reached the landing's Linux gate. `SourceEncodingDriftTests` read `TestRepo.At(tree)` from
a theory parameter and governed nothing at all.

**Fix.** `scripts/spec/drift_rules.py` reads a call's path with ONE evaluator (`path_expr` / `path_join`: literals,
`TestRepo.Root`, class constants, collection expressions, nested `Path.Combine` and `TestRepo.X` calls, balanced
parentheses, up to the first argument it cannot spell), reads a wrapper method at its callers (`Sources.reads`), and
`--check` refuses a drift test that reads the repo and spells no path (`blind`). No hand table. The exactness moves the
`Sweep` trait for four classes: `LevelNumberArmDriftTests` gains it; `CitationAuditSelfTestDriftTests`,
`FixedFormRecordDriftTests` and `Gr4GroupDecisionDriftTests` read only the files they name and lose it (the trait guard
holds both ways). `SourceEncodingDriftTests` spells its two trees with literals and carries the trait;
`GateLegDriftTests` spells its five. Witnesses: `drift_rules.py --self-test` (four planted classes), the
`impacted_tests.py --self-test` arms over a grammar file, a model file and an emitter file, and `drift_rules.py --check`.
The tier-0d cost of a grammar edit rises from 476 s to 581 s of recorded time (DESIGN-test-build-ci.md section 3.14.2).

Instances three to five (a load-skewed timing, a leg-2 case never re-timed) decided whether a sweep the diff DOES reach
ran at the Windows gate; with tier 0d they decide only the order of a sweep the diff cannot reach, so the timings store
needs no change.
