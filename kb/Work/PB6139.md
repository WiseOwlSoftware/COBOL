r2_ids: lexer-grammar-1--duplication--f2#3

**Wave kind:** unify. **Model:** Opus (a grammar change; `model_rules.json` routes area architecture to Opus).

**Mechanism.** §2023:14.9.28.4 GR17 states that a PERFORM Format 3 WHEN match IS the USE rule. The grammar writes the operand twice:
`performWhenEcItem` / `useEcEntry` and the mode alternatives `performWhenModeList` / `useOnTarget`, in
`src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolControlFlow.g4`. Two resolvers bind them. PB2723's GR3 unify (one
`BoundExceptionSelector`, one `ExceptionOpenMode`) removed the bind and codegen halves. The two rule pairs remain, so the
unify needs a parser regeneration and a shared operand rule.

**Target.** One exception-selection operand rule and one open-mode list rule used by both statements, one resolver on the shared
parse shape, and a drift test that the two statements cannot grow separate operand rules. Behavior-neutral; the §4 oracle proves it.
