r2_ids: lexer-grammar-1--duplication--f2#3

**Wave kind:** unify. **Model:** Opus (a grammar change; `model_rules.json` routes area architecture to Opus).

**Mechanism.** §2023:14.9.28.4 GR17 states that a PERFORM Format 3 WHEN match IS the USE rule. The grammar writes the operand twice:
`performWhenEcItem` / `useEcEntry` and the mode alternatives `performWhenModeList` / `useOnTarget`, in
`src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolControlFlow.g4`. Two resolvers bind them. PB2723's GR3 unify (one
`BoundExceptionSelector`, one `ExceptionOpenMode`) removed the bind and codegen halves. The two rule pairs remain, so the
unify needs a parser regeneration and a shared operand rule.

**Target.** One exception-selection operand rule and one open-mode list rule used by both statements, one resolver on the shared
parse shape, and a drift test that the two statements cannot grow separate operand rules. Behavior-neutral; the §4 oracle proves it.

**Landed (wave 20262161 group C).** One operand rule, `exceptionSelectionOperand` (`cobolWord (FILE fileName)*`), replaces
`useEcEntry` and `performWhenEcItem`; USE Format 3 writes `exceptionSelectionOperand+` and `performWhenEcList` its gated list of
them. The open-mode alternatives of `useOnTarget` and `performWhenModeList` are the OPEN statement's own `openMode` rule
(CobolIO.g4), a third copy of INPUT | OUTPUT | I-O | EXTEND the new drift test found; its keywords are read once, by
`OpenModeOperand.Of` (OPEN's `BoundOpenMode`), and `OpenModeOperand.ExceptionModeIndex` gives the GR3b tier its `FileOpenMode`
ordinal. One resolver, `ExceptionSelectionOperands.Resolve`, binds the operand for both statements (name funnel, FILE pairing
only with an EC-I-O name, each paired file); what differs is passed in: the SR16 (COBOL1601) / SR13 refusal, the file resolution
(USE's `ResolveUseFile` now also serves Format 1, which repeated it) and what each statement records. The file-name LISTS stay
per statement on purpose: a WHEN list's continuation is gated by `whenOperandAhead()` (a statement follows it), a USE list is not
(a period follows it), and gating the USE list would refuse a file named PARSE there. `ExceptionSelectionOperandDriftTests` holds
that no other rule writes either operand. Behavior-neutral: `compare_oracle.py` reported
