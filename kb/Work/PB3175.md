# PB3175 — conformance suite slice S1b

Owner approved `docs/rearchitecture/DESIGN-conformance-suite.md` on 2026-10-14 ("approved", revision 2; kb/Work PB3160 holds the decisions verbatim).

**Prerequisites:** PB3174.

**Scope:** Design §13 S1b, built from §5. `conformance-suite/harness/run.py` (Python 3 standard library only) executes the generator's manifests through an adapter: a fresh working directory per test with its declared files, stdin closed, the ASSIGN mapping and name limits the adapter declares, the flag-mode and diagnostic-line reading; the verdicts PASS, FAIL, NOT APPLICABLE and NO VERDICT (a generous hang guard, never a wall-clock expectation); JUnit XML and JSON with totals per edition and clause; `--record-baseline` and the CHANGES report against `baselines/<compiler>.json`. Ships the WiseOwl (`cobol`) and GnuCOBOL (`cobc` 3.2: cobol85, cobol2002, cobol2014) adapters and profiles. `--self-test` drives a stub compiler (a Python script) through every verdict, on Windows and Linux.

**Rules for the implementer:** implement this slice FROM the design (the sections named above), not from this note, which is its register entry; the complete slice with its tests and drift tests (CLAUDE.md rules 3, 5); a design correction lands in the design in the same change (rules 2, 6); every ISO citation through `python scripts/spec/cite.py --check`; no wrapper, alias or compatibility layer (rule 4); the gate is `pwsh scripts/build-local.ps1 -Priority BelowNormal`; flip this note to `landed` and write `closes_rows` (or `closes_rows_reason`) in the commit that lands it.

## Landed

Wave 1104 C4 (2026-10-16), on PB3174's branch (PB3172, PB3173 and PB3174 land through it).

**The harness.** `conformance-suite/harness/run.py` (standard library only) runs the generator's per-edition
manifests against a compiler through `adapters/<compiler>.json`, under the claims of the profile the adapter names,
and reports PASS, FAIL, NOT APPLICABLE or NO VERDICT per test as design §5 defines them: a fresh working directory
per test holding its source (named within the adapter's limit) and declared files, stdin closed, a hang guard on
every process, the adapter's diagnostic pattern for a flagged test's marked line, its control compiled first in a
directory of its own. Results go to `results/<compiler>/` (git-ignored) as `results.json` (totals per edition and
per clause, every reason, the CHANGES) and `junit.xml`; `--record-baseline` writes `baselines/<compiler>.json`, and a
run is RED only on a verdict worse than its recorded one. `harness/config.py` is the one loader of adapters, profiles
and baselines and the hook interface (`Step`, `StepContext`); the generator's audit validates all three against the
repository (editions, annex names, A.1 items, suite test ids). `--self-test` (56 arms) drives a stub compiler, a
Python script, through every verdict, a hook, the baseline and the CHANGES, and the configuration audit; it passes
on Windows and under WSL, and `scripts/self_tests.py` discovers it.

**Adapters and profiles.** `wiseowl` (the `cobol` command, `--set cobol=<path>`; the seed PASSes 22 of 22) and
`gnucobol` (cobc 3.2.0, measured under WSL: no 2023 dialect, base names of at most 31 characters, `file:line:`
diagnostics; A.1 item 148 variable and item 204 available, both measured; extra reserved words from `cobc
--list-reserved` per dialect). `baselines/gnucobol.json` is the seed's: 14 PASS, 6 NOT APPLICABLE (2023), and 2 FAIL,
READ PREVIOUS after OPEN at -std=cobol2002 and -std=cobol2014, where cobc gives the 2023 at-end rule and Annex E.2
item 22 records that those editions retrieved the first record. WiseOwl's profile claims what docs/CONFORMANCE.md §5
and §2 dispose Claimed or Partial, held there by `ConformanceSuiteProfileDriftTests`.

**Design corrections** (DESIGN-conformance-suite.md §5, §13): the manifest entry's `words` (the user-defined uses a
compiler's added reserved word can stop: the program's non-standard words and the names it defines, so a keyword use
of a context-sensitive word such as PREVIOUS does not make a test NOT APPLICABLE; `cobol_source.defined_names`,
`generate.standard_keywords` from ISO 8.10-8.12) and `clause`; profiles carry the evidence for each claim; the
generator's audit checks the harness configuration. **Found and fixed on the way:** the `cobol` command's exit code
for a source the binding phase refuses was 70 (the compiler's own failure) by a `_` default; `Program.ExitCode` now
names every outcome, BindError 65 like a parse error (`CliParserTests`).
