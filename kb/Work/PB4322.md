# PB4322 — the non-observation witness must run a child that never ends by itself

**Sites:** `tests/WiseOwl.Cobol.Tests.Unit/ProcessObservationDriftTests.cs`
(`AProcessPastOneUnit_IsANonObservationThatNamesItsWorkAndTheHostLoad`, formerly
`ASlowProcess_UnderOneUnit_IsANonObservationThatNamesItsWorkAndTheHostLoad`; `RunsForever` and its two other users, the
retry's both-attempts report and `Observe`'s empty stdout on a timeout).

## The red

The PB4274 finisher's gate on c4aac6fe3 (run `TestResults/build-local/000003-20261101T003516Z` of
`worktree-wf_2201113e-54d-26`) was RED on one Unit case: `ASlowProcess_UnderOneUnit_…` with `Assert.Throws() Failure: No
exception was thrown`. The leg's observation log shows `RETRY cmd.exe /c ping -n 4 127.0.0.1 :: TimedOut (1000 ms, host
85 % busy)`, then `RECOVERED … exit 0`: the second attempt of a 3 s child "completed" inside a 1 s budget.

## The cause

`ProcessObserver.Observe` starts the budget's clock at `WaitForExit`, after `Process.Start` returns and stdin is written
and closed. A BelowNormal test host starved for about 2 s on a host 85–100 % busy reached the wait after the child had
already exited, so the wait returned at once. The test asserted a wall-clock race ("a 3 s child is never seen within
1 s"), which a loaded host breaks with no regression in the observer (MANDATORY-PRACTICES: a test must not fail with no
regression; memory `no-wall-clock-tests`).

## The fix (commit 94b05879c, on the PB4274 finisher's branch)

The witness of "past one unit is a non-observation, and the report names the budget, the work, the process's own
processor time and the host load" now runs `RunsForever`, a child that never ends by itself (`cmd /c ping -t
127.0.0.1` on Windows, `exec sleep infinity` on POSIX; the observer kills its tree), so no scheduling can make it finish
inside its budget. The same change hardens `RunsForever`'s two other users, whose 30 s child carried the same race at a
29 s margin. The case is renamed `AProcessPastOneUnit_IsANonObservationThatNamesItsWorkAndTheHostLoad`.

**Sweep:** no other test under `tests/` uses a finite sleep in place of a timeout (`CiArtifactDriftTests`' `sleep 30`
is YAML fixture text). **Verified:** `ProcessObservationDriftTests` 25/25 on Windows with no `ping` process left
behind, and the whole-population gate on 94b05879c (run `000004-20261101T004929Z`) GREEN on both hosts.

The finisher found and fixed this with no id allocated to it. The enqueue unit filed the note with an id from
`alloc.py` in a register-only commit on the same branch.
