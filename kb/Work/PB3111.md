# PB3111 — an implementer rewrites a predecessor's pending DEVLOG entry

> ⚙ **flags:** process-only

Source: `w1069m-PB3104-report.md`, "New defects" 4; review finding R1-1's root (enqueue unit 2026-10-12 16:45 PDT).

A dispatch that has an implementer merge an unlanded notes branch leaves that branch's `DEVLOG/pending-*.md` in the implementer's tree. The PB3104 implementer rewrote that entry instead of adding its own. Once the notes branch landed (stamped and renamed to `DEVLOG/1972-...`), the implementer's branch conflicted on the stamped entry, which cost a review finding (R1-1) and a finisher round.

**Code sites.** The PREDECESSORS line of the fix-lane brief and spec template: `.claude/skills/workstream/templates/fix-lane-implementer-brief.md`, `.claude/skills/workstream/templates/dispatch-spec-implementer.md`.

**Fix shape (for the implementer to confirm).** Never edit a predecessor's pending entry; always add your own (the stamp folds them). Check whether `devlog.py check` could refuse a branch that modifies a pending file another branch added.
