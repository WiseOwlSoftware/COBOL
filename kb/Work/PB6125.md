# PB6125 - measurements.record stamps the run version on verdicts it kept

`conformance-suite/harness/measurements.py:213` `record` keeps the earlier verdicts of a file but writes the current run's version over the
whole file. A verdict kept from an earlier run then reads as measured at the new version. Not in a file the PB3178 blocking fix changed, so it
was left by that branch.

**Repro.** Record one test at version V1, then a different test at V2: the file's version reads V2 for both verdicts.

**Fix.** Store the version per verdict (or refuse to mix), with a harness selftest.
