# PB5728 - a Linux gate ended and left its self-test's process tree running for 43 hours

**Sites:** `scripts/linux-gate.sh` (`remove_gate`, `on_signal`; the EXIT trap is at line 252, `remove_gate` at line 257, `on_signal` from line 288), `scripts/filter_population.py` (whole: the `--self-test` path that runs `dotnet test --list-tests` has no named member in the finding).

**What was found** (2026-11-15 14:26 PST, `wsl -e bash -c 'ps ...'`): two processes in the Ubuntu distro, both started Fri 2026-11-13 18:48 PST, 0.0 % CPU, parent `/init` (pid 541):
- pid 30276, `/home/brent/.local/bin/python3 scripts/filter_population.py --self-test`, stat `SNs` (a session leader), cwd `/home/brent/linux-gate/wf_52dcfb9a-25b-18.542/wf_52dcfb9a-25b-18.audits (deleted)`;
- pid 35638, its child, `dotnet test tests/WiseOwl.Cobol.Tests.Conformance --no-build --list-tests --filter FullyQualifiedName~AbbreviatedConditionDifferentialTests`, stat `SNl`, cwd under the same deleted directory.

So the gate `wf_52dcfb9a-25b-18.542` ended and `remove_gate` deleted its directory (scripts/linux-gate.sh line 257; the EXIT trap, line 252), while a self-test it had started was still running in it. They held no disk space (one `memfd` only) and 163 MB of memory. `~/linux-gate` itself was clean (one 0-byte `.begin.lock`), so PB3194's mechanism held.

**Questions this note asks:**
1. `on_signal` ends the legs' process trees before it removes the directory (linux-gate.sh line 288 on); does the EXIT path (a verdict, or a hang stop) do the same, and does either reach a child that is its own session leader?
2. `filter_population.py --self-test` waited 43 hours on `dotnet test --list-tests`: that call has no time bound, and why `--list-tests` never returned in a directory deleted under it is not known.

**What was done:** both processes were ended by hand (`kill 35638 30276`, verified gone). No other process older than 6 hours remained in the distro except system daemons and one login shell.

Related: PB3194 (the gate leaves nothing behind on the Linux filesystem), PB2779 (open: battery.sh's wrappers outlived the battery), PB4326.
