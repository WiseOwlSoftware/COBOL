# PB2883 — a landing-gate valley measured but not removed

**Source:** PB2880 (wave 1050 A, measured 2026-10-09 with the counter API; report w1050a-PB2880-report.md), lead 3.

**Measured:** the Linux unit leg's critical path is one partition: StorageFormNistEquivalenceTests_P6 takes 162 s against 54 s for P1 (the eight partitions are unbalanced), ending the leg ~15 s after everything else at 5-10 % of the VM.

**Code site:** `tests/Cobol.Net.Tests.Unit` (`StorageFormNistEquivalenceTests_P1`..`_P6` partitioning).

**What closes it:** Rebalance the partitions by measured cost, not by count, and pin the balance with a drift check so a new NIST program cannot recreate the long pole.

**Rule:** none (process tooling, no ISO clause).
