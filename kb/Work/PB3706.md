# PB3706 — row L12 describes the round-1 two-part wait

**Sites:** `.claude/skills/workstream/templates/MANDATORY-PRACTICES.md` (row L12, the sentence "the lane retries it once the lock is free and no gate run owes a verdict").

## What is wrong

PB3662's review R1-1 changed `land_lane.gate_lock_free` to read the lock alone (a running gate holds the worktree's gate lock until
its verdict file is written). The fix commit updated `landing.md`, `units/enqueue.md` and both design docs, not row L12, and the merge
carried the old words unchanged. An operator or finisher who reads L12 beside a branch held at exit 12 whose lock is free next to a run
directory with no `verdict.json` concludes the lane is right to keep waiting on that run. The code relaunches as soon as the lock is free.

## Fix

Say in L12: exit 12 is retried once the worktree gate lock is free (a running gate holds it until its verdict is written). Sweep
`MANDATORY-PRACTICES.md`, `landing.md`, `units/enqueue.md` and the design docs for the old phrase ("owes a verdict") and make them agree
with `land_lane.gate_lock_free`.
