# PB4130 — a COBOL-85 target and a non-Annex-B character in a word (U+00A0, the euro sign)

**Sites:** `src/WiseOwl.Cobol.Frontend/Common/CobolWordRule.cs:47` (`CobolWordRule.CharacterViolation`).

New defect 1 of PB3845's implementer (wave 20261764 group D; the note PB3845 is held by an in-flight group, so this is a new note that
names it). Under a COBOL-85 target a word containing U+00A0 or the euro sign draws COBOL0900 worded "the extended letter", although no
edition's Annex B admits the character: it is not a letter of any set. Misleading message only (the program is refused either way).
Sites: `WordCharacterScreen.Check` (new with PB3845's branch, not on main when this was filed) and `CobolWordRule.CharacterViolation`.

**Fix:** word the diagnostic by what the character is (not in Annex B of the target edition) and not "the extended letter"; keep the
two-edition split (a 2002+ extended letter is legal where §8.3.2 allows it). Pin with goldens at 85 and 2002.

Source: report `w20261764d-PB3845-report.md`, "New defects" item 1; PB3845 (open, in-flight).
