# PB2529 — the code-citation audit is the gate's costliest audit

## Measured (wave 1033 group W, 2026-10-07, branch `gate-perf`)

After kb/Work PB2525 took `audit_doc_citations.py` from 78.2 s to 2.5 s, the twelve gate audits run serially in 28.3 s
(46 % host load; `docs/rearchitecture/evidence/w1033-gate-levers/audits-after.txt`), and `CITATIONS`
(`scripts/spec/audit_code_citations.py --check`) is 18.5 s of it. cProfile of one `--check` run: 6.5 s tottime in
1,359,604 `re.Pattern.search` calls, 9.9 s cumulative in `_ordinal_findings` (7,991 calls, one per file), 1.8 s in
`_rule_citations` (834,871 calls); `phantom_scan` 2.5 s.

## Site

`scripts/spec/audit_code_citations.py#_ordinal_findings` (and `#_rule_citations` it drives per line).

## Shape

Find the citations of a file ONCE (one pass of a combined pattern, or `_rule_citations` over the file text, not per
line), and only then apply the per-citation ordinal checks; cache the per-clause rule tables the checks look up. The
differential: `--check` output byte-identical before and after over the whole corpus, as PB2525 did; `--self-test`
and `CitationAuditSelfTestDriftTests` stay green. Since kb/Work PB2524 the audits run outside the gate slot, so this
costs each implementer gate's own wall time, not the slot queue.
