# PB4219 — the non-data tier of the nearest-declaration screen has no depth

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.IoControl.cs#ScreenEnclosingFileOperand`,
`src/WiseOwl.Cobol.Compiler/Binding/DataBinder.NonDataNames.cs#NonDataDeclarationOf`.

Until PR #891 (PB3557) is on main these members exist only on branch `worktree-wf_34371f8b-c21-12`; this note is blocked on it.

**Mechanism.** The screen of an APPLY COMMIT / I-O-CONTROL operand decides by the nearest declaring source element for data
items, report entries and GLOBAL files. The tier for names that are not data items (`NonDataDeclarationOf`: constant-name,
index-name, condition-name) carries no containment depth, so it cannot be compared with `fileDepth`. `NonDataDeclarationOf`
also asks `IsVisibleFileName` before `TryResolveCondition`, so a file-name outranks a condition-name regardless of nesting.
ISO §8.4.6.2.1 3) a) makes the item declared in the contained element B the referenced item, and 3) b) 2. makes the nearest
containing declaration win otherwise.

**Repros** (branch cobol.exe, head 71210235b).
1. PA declares `01 T1 GLOBAL` / `05 E OCCURS 3 INDEXED BY RELF`; contained PB declares `FD RELF IS GLOBAL`; PC inside PB:
   `APPLY COMMIT ON RELF`. Draws COBOL1639 "RELF is declared as an index-name", but PB's GLOBAL file is the nearer
   declaration, so SR11 (COBOL4709) is the rule broken.
2. PA declares `FD RELF IS GLOBAL`; contained PB declares `01 W PIC X` / `88 RELF VALUE "A"`; `APPLY COMMIT ON RELF`. Draws
   COBOL4709 SR11 about PA's file, but PB's own condition-name RELF is the referenced item, so the not-a-data-item refusal
   applies.

Both programs are illegal either way: the wrong rule is named and no legal program is refused. The same FileName-before-
ConditionName order in `NonDataDeclarationOf` words the FILE STATUS and OCCURS DEPENDING refusals the same way (round-1 content).

**Fix direction.** Give the non-data tier its depth (own versus inherited constant, index-name, condition-name) and compare it
with `fileDepth` as the data and report tiers are compared; ask an own condition-name before an inherited file-name in
`NonDataDeclarationOf`. Goldens pin both repros.
