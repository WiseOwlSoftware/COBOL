# PB5159 - at --std 85 REWRITE record-name-1 RECORD compiles: rewriteStatement takes the later formats' optional word RECORD after the record-name at every edition

**Sites:**

- `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolIO.g4` (`rewriteStatement`)
- `src/WiseOwl.Cobol.Compiler/Validation/VersionConformancePass.cs` (`VisitRecordFromPhrase`)

**Mechanism.** The 1985 REWRITE formats (sequential §1985:VII.4.5.2, relative and indexed §1985:IX.4.6.2) print REWRITE record-name-1 [FROM identifier-1] and no word RECORD. The grammar rule `rewriteStatement` is `REWRITE (recordName | FILE fileName) RECORD?`, the superset of the 2002 and later formats, and no pass asks the edition about the word, so `REWRITE R RECORD FROM W` compiles at --std 85. WRITE refuses the same word at 85 (COBOL2269), so the two statements disagree. The indexed row 1985-FMT-IX.4.6.2 records the same acceptance; that row is claimed by kb/Work PB5158 (its main defect is the phrase order) and closes when both land.

**Found by.** The 1985 code read (2026-11-10; its records are `E:/COBOL-coord/scratch/coderead-85/for-register.json`): each rule below was read against the code sites it names and probed at `--std 85`, and found non-conforming. Verdict, harm, evidence, repro and observed text are the records'; the rows' verdicts are recorded on another branch.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids of the list below.

The superset rule rewriteStatement accepts it, SequentialIoBinder.BindRewrite resolves record-name-1 (qualified or not) to its file and binds the FROM operand, and almost everything the later format adds is refused at --std 85 (each probed): FROM literal-1 and FROM a figurative constant by VisitRecordFromPhrase (COBOL0871), FILE file-name-1 by DeclinedFilePhrase (COBOL1706), RETRY by VisitRetryPhrase and WITH [NO] LOCK by VisitRecordLockPhrase (COBOL0900), INVALID KEY and NOT INVALID KEY on a sequential file by BindRewrite through ScreenForbiddenPhrase (COBOL1720), AT END, a second FROM, a missing record-name and a file-name operand by the parser or the resolver; FROM a function-identifier (Amendment 1) and END-REWRITE inside an IF compile and run. One thing the 1985 format does not print compiles at 85: the word RECORD after record-name-1. rewriteStatement is REWRITE (recordName | FILE fileName) RECORD? and no pass asks the edition, so REWRITE R RECORD FROM W and REWRITE R RECORD compile and run; the word is the later format's (§2023:14.9.35.2 prints RECORD, not underlined, after the braces).
