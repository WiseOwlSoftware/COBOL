# PB278

Asked as the one bare question of the 2026-09-01 project-management pass (session `c609c011`), answered
**Interleave** (the recommended option) over **Keep backlog-first**.

## What was measured before asking

Computed from the inventory and from the subagent transcripts on disk, not remembered:

* Of the **3,636 GAP rows, 3,361 (92%) had never been adjudicated at all.** The defect backlog — 118 defective
  rows, 54 actionable `kb/Work` notes — is 3% of the GAP. 139 more rows were already verified CONFORMS and
  needed nothing but one spec-derived golden each (every one of the 139 has an EMPTY `test-ref`); 18
  DOCUMENTED-NON-SUPPORT rows owed only their witness.
* 2026-08-29 → 08-31: **thirteen review fleets of 52–117 agents (~1,000 agents, ~4B cache-read tokens) moved the
  GAP by 27 rows.** The one adjudication batch in the same window (Phase-B batch 8: 39 agents, 574M cache-read)
  processed 224 rows. Five of the last fleet's eleven register notes were defects the wave itself introduced.
* Adjudication cost ≈ 2.6–3.4M cache-read per row, with ~120 turns per agent spent mostly on DISCOVERY (finding
  the grammar rule, the binder, the existing tests) — pre-computable. Long-running implementer subagents were the
  single most expensive unit: 19 agents, 1.36B cache-read, ~316 turns each.
* CONFORMS rate when adjudicated: §15 92%, §13 96%, §12 97%, **§14 64%** — the statement clause is where
  adjudication turns into fix work; the data/environment clauses are where it turns into closed rows.

## The decision

The 2026-08-09 standing order "fix the known defect backlog to zero before any new adjudication" is **replaced**.
Adjudication and fixing are two lanes that run **concurrently**:

* **Adjudication lane** — `phase_b_batch.py` batches, dossier-fed (the rule text PLUS the `.g4` rules, the
  binder/emitter files and the tests that cite the clause, and the CONFORMANCE.md determinations for it, so the
  agent verifies instead of searching), refuters reading only the CONFORMS / DOCUMENTED-NON-SUPPORT candidates
  (the only verdicts that are dangerous when wrong — a wrong PARTIAL is re-probed at fix time by rule), run in a
  `git worktree` pinned at a commit so the main tree stays editable and buildable. It stays one batch ahead of
  the fix lane and alternates a defect-rich batch (§14 statement groups, grouped by mechanism so the notes it
  produces already cluster) with a closure-rich batch (§13, §12, §11, §8, §7, the small clauses).
* **Fix lane** — clusters by MECHANISM (the C–F apply-ready contracts and the clusters the adjudication lane
  produces), the proven loop with the fleet resized: the implementer runs a four-lens self-review BEFORE the
  fleet; the fleet is ~40 agents (4 lenses, 2 refuters per finding) and runs once per CLUSTER, not per wave;
  implementer agents receive the contract, not a discovery brief, with a turn budget. One comprehensive battery
  per cluster batch — unchanged doctrine.
* Three cheaper lanes run first or alongside, ordered by rows-per-token: the **golden lane** (the 139 + 18 rows,
  no compiler change), the **derived-verdict lane** (one `derived-verdicts` selector per A.4 module already "Not
  claimed" in CONFORMANCE.md §5, plus one witness test each — the PB198 mechanism, no new owner question), and,
  after the DOC closing shape is defined in `inventory-schema.json`, the **A.1 documentation lane** (39
  determinations exist and zero DOC rows carry a verdict).

Projection: ~10–12B cache-read tokens to zero GAP against ~35B on the per-wave loop, with the two lanes
overlapping in wall-clock. The method is written ONCE, in `DESIGN-spec-conformance-review.md` §5; plan §0 carries
the live state; **no new list, table or tracker anywhere** — every lane is a query over `kb/Work/` and the
inventory (CLAUDE.md rule 8).

## What does not change

Subagents run Opus 5 (the 2026-08-09 directive's second item stands). The spec is the only oracle; every
citation `cite.py --check`ed; only a spec-derived test closes a row; DOCUMENTED-NON-SUPPORT is never an agent's
call; the refute stage on anything that CLOSES a row is not optional. Deferral, a GAP or rejecting legal source
stays debt and an owner decision.
