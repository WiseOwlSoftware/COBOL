# PB911 — OPEN — one format got the message, its twin got COBOL0001

Source: the `PB432` report, "New defects" item 2. Re-measured here, both arms.

## The measurement

`<scratch>/reg7/probe/f_perform_fmt3_empty.cob` — Format 3 (`PERFORM … WHEN condition`), `--std 2023`:

```
f_perform_fmt3_empty.cob(5,15): error COBOL0001: cannot parse construct near 'WHEN'
```

`<scratch>/reg7/probe/f_perform_fmt2_empty.cob` — Format 2 (`PERFORM UNTIL …`), the same omission:

```
f_perform_fmt2_empty.cob(8,12): error COBOLNET2072: unexpected 'END-PERFORM'. The PERFORM statement's
general format shows an imperative-statement here that is not bracketed, so at least one statement shall be
specified: brackets are what license an omission (ISO §5.2.6.2), and one alternative of a brace group shall
be explicitly specified (ISO §5.2.6.3).
```

Same statement, same omission, same rule — one user is told exactly what is wrong and where the rule is,
the other is told the parser gave up.

## The rule

```
$ python scripts/spec/cite.py --check 5.2.6.2 "Brackets"
OK  §5.2.6.2   (Brackets)
$ python scripts/spec/cite.py --check 5.2.6.3 "Braces"
OK  §5.2.6.3   (Braces)
```

Both PERFORM formats print imperative-statement-1 UNBRACKETED, so §5.2.6.2's licence to omit does not
apply to either, and COBOLNET2072's text is correct for both.

## The code site

The ATN expected-set detector behind `DiagnosticCatalog.RequiredImperativeMissing` — the machinery
**PB396** (landed) built when it closed the Format-2 arm. It does not fire on the Format-3 alternative.

## Why this is filed rather than folded into PB396

PB396 is `landed`. This is its residue, and it is the repo's most reproducible defect shape
(`feedback_two_arm_dispatch`, 5x): a dispatch with two arms, one arm fixed. The fix is not "add Format 3" —
that is the same shape one alternative further along. The detector should be driven from the PERFORM
statement's FORMAT TABLE (whatever selects among §14.9.28.2's formats) so every format's unbracketed
imperative slot is covered by construction, with a drift test that enumerates them.

## Rows

None — this is diagnostic quality, not a spec rule with a row. The RULE (§5.2.6.2 / §5.2.6.3) is already
enforced; what is missing is the message on one path.
