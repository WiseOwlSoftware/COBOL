# PB1850 — OPEN — dead run-unit adoption machinery for class halves

PB1308 (decision R62) made a method's WORKING-STORAGE illegal at every edition and deleted the method static-field mapping (D3). The class halves' `DataBinder.EmitsStaticReset` can therefore no longer be true for a class, so `OoEmitter.EmitClassUnit`'s `adopt` list (`runUnit.AdoptStaticStorage(<half>.__ResetStatics)` + the `__AdoptRunUnitStorage` override), `CobolObject.__AdoptRunUnitStorage`, the `RunUnit` call `created.__AdoptRunUnitStorage(this)` and the class-half wording in `RecordStructEmitter.EmitStaticReset` / `OoEmitter` are inert. **To do:** delete them together with the matching cases in `RunUnitStateDriftTests` (the ProgramTable adoption for RECURSIVE/INITIAL programs stays), update COBOLNET_OO_DESIGN.md D3 (the "Implementation" paragraph still describes the static mapping), and confirm by characterization snapshots that no emitted C# changes.
