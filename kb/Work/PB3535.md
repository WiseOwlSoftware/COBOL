# PB3535 — dead branch and docstring sentence in render_figure.py place_rows

## Lead (review lead R2-1, info, not blocking at round 2; wave 1150 group C, PB3530's report)

`scripts/spec/render_figure.py:293` `place_rows` carries an unreachable branch (`if lo > hi: rep = mean  # a contradictory
measurement`) and a docstring sentence (line 262) describing a case that cannot occur. Every per-word constraint
`place_rows` builds contains the word's own y0 (inside: top <= y <= bottom; above: y <= nextafter(top, -inf); below:
y >= nextafter(bottom, +inf)), so the intersection over words sharing a y0 always holds y0, and a part only grows while
its interval stays non-empty.

## Fix shape

Delete the branch and the sentence, or make the branch an assertion that states the invariant.
