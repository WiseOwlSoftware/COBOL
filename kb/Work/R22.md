# R22 — a bare catalogued-intrinsic name without a REPOSITORY declaration compiles clean and dies at run time (COBOLNET1543 fires for only 3 names)

> R00 ledger-audit orphan (2026-08-08): F34 + F37 of `PHASE-B-15.32-15.44-findings.md`, probe-verified OPEN
> against the R10-landed tree (`5312996a`). The probe programs are reproducible from the finding text.

PROBE (2026-08-08): `MOVE FORMATTED-CURRENT-DATE("YYYYMMDDThhmmss") TO WS-R` with NO REPOSITORY paragraph
— zero diagnostics, then `NotImplementedCobolFeatureException: reference 'FORMATTED-CURRENT-DATE(…)'`.
§8.4.3.2.3 SR2: without a REPOSITORY declaration "the word FUNCTION is required". COBOLNET1543 exists with
the exact citation but fires only on the reservedIntrinsicArgFn grammar alternative (SIGN/SUM/RANDOM); every
other name falls to generic unresolved-reference staging. FIX (ledger): in name resolution, when a bare
name(args) matches a catalogued intrinsic and the REPOSITORY does not declare it, raise COBOLNET1543 — the
declared-data-item-wins discrimination is already made. (The traceability inventory's FMT-15.17.2 row carries
the same witness; close both together.)

## LANDED 2026-08-08

The fix is the ledger's, placed at the ONE chokepoint: `IntrinsicBinder.KeywordOmittedFunction` gains the
OTHER arm of its §8.4.3.2.3 SR2 discrimination (the two-arm-dispatch shape — the declared arm bound, the
undeclared arm silently returned null into staging). When the name is catalogued, no declared data item
shadows it (`ctx.Symbols.TryResolve` still wins first), and the REPOSITORY does not declare it, the reference
draws COBOLNET1543 with the same write-FUNCTION/add-REPOSITORY guidance the reserved-name arm (SIGN/SUM/
RANDOM) always gave. A BARE name draws it only when the catalogued function admits zero arguments — mirroring
the declared arm — so a mere name-collision (`MOVE SQRT TO X`, SQRT undeclared, MinArgs 1) stays on the
ordinary unresolved-name path. Every consulting chokepoint (RefExpr / FieldOperand / InspectBinder) funnels
through the one hook, so one edit covers all sites.

Probes before landing: `MOVE FORMATTED-CURRENT-DATE("…") TO WS-R` (the note's repro) and bare
`MOVE CURRENT-DATE TO WS-R` draw COBOLNET1543 at 2002/2014/2023; with `FUNCTION ALL INTRINSIC` both compile
and run (the FORMATTED probe also proved R21's offset-bearing COBOLNET_CLOCK pin end-to-end); a DECLARED
`01 SQRT … OCCURS 3` with `MOVE SQRT(2)` stays a subscript and prints 7. Negative fixtures
`kof-undeclared-intrinsic-args` + `kof-undeclared-intrinsic-bare` (reject-at 2002 2014 2023) and positive
golden `kof_shadowed_intrinsic_name` (the data-item-wins control), all registered. Gate:
Intrinsic|Corpus|Negative 664/664 · the four kof cases green by name · characterization 33/33.

⚠ The probe sweep found the GENERIC arm's own defect and it is now **[[R30]]**: ANY undeclared name in a
sending position (`MOVE NO-SUCH-NAME TO X`, `DISPLAY NO-SUCH-NAME`) compiles with zero diagnostics and
throws at run time — the staging fallthrough this fix stopped short of.
