**The mechanism.** `stopStatement` took `STOP literal`, and the literal rule spells a word only as a concatenation operand,
so a bare symbolic-character after STOP was predicted as a concatenation and refused. The grammar now has the superset
arm `STOP cobolWord`, and `ControlFlowBinder.BindStopWord` decides: a symbolic-character (§1985:IV.4.2.2.2.3 GR7, GRL2.3)
is communicated as its one character (GRL2.2, §1985:VI.6.24.4 GR4); any other word is refused by name at 85, COBOL7558
(it used to be the parse error COBOL5506, which `1985-FMT-VI_6_24_2` expected and now expects COBOL7558); from 2002 the
edition gate's COBOL0902 refuses the statement as it does the literal form (`VersionConformancePass.VisitStopStatement`
asks both arms), which also settles the note's lesser misleads_diagnosis at 2023. The word is resolved by the ONE
literal-alias reader (`ExpressionBinder.LiteralAliasOf`, kb/Work PB1544).

**A recovery defect the word arm exposed (fixed here, I9).** With `STOP word` in the grammar, `PERFORM STOP.` followed by
`STOP RUN.` drew a second, false COBOL2269 at the second period (`ReservedWordPositionConformanceTests`, gate run
000002-20261116T130648Z). `CobolErrorStrategy.ReportError` reads the OFFENDING token as the name and re-parses
(`ReadsAsTheNameAhead`, kb/Work PB4218) even when the report named an EARLIER word (the PB4229 procedure-name path, whose
own recovery is the orphaned tail): it retyped the period of `PERFORM STOP.` as an IDENTIFIER, and the new arm let the walk
accept `STOP <word>`, so the sentence ran on into `STOP RUN.` inside the inline PERFORM. The base passed only because no
walk could take an IDENTIFIER there. The re-read now requires the named word to be the offending token.

**Sweep.** The other 1985 slots probed with `STAR` all work: INSPECT CONVERTING ... TO, INSPECT REPLACING ALL, INITIALIZE
REPLACING ... BY, EVALUATE ... WHEN, besides the note's VALUE, DISPLAY, MOVE ALL, IF, STRING and INSPECT TALLYING; the
PADDING CHARACTER clause reads a symbolic-character already (`FileControlBinder.Padding`). STOP was the only literal-only
procedure slot without an identifier arm.
