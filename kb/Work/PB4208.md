# PB4208 — a never-gated reserved verb as an operand draws two diagnostics

**Sites:** `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs:229` (`CobolErrorStrategy.ConsumeUntil`),
`src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs:269` (`CobolErrorStrategy.IsReportedReservedOperand`, which keys on
`CobolParserCoreBase.ReservedUserWordViolation`, gated words only),
`src/WiseOwl.Cobol.Frontend/Parsing/CobolParserCoreBase.cs:675` (`CobolParserCoreBase.ReservedUserWordViolation`).

**The defect.** Same symptom as PB3248, different mechanism. PB3248 made a gated reserved verb (RECEIVE, SEND, VALIDATE) written
as an operand draw one COBOL0901. CONTINUE is reserved in every edition, so it is not reservation-gated and never reaches the
COBOL0901 path (`ReservedUserWordViolation` is null for it). At --std 2023, `MOVE CONTINUE TO W-X.` gives
`COBOL0001: cannot parse construct near 'CONTINUE'` plus `COBOL2269: unexpected 'TO'. The CONTINUE statement ends before this
token`: the recovery resumes at CONTINUE, parses it as the CONTINUE statement and refuses the next token. §8.3.2.1 1) ("Reserved
words shall not be used as user-defined words or system-names", `cite.py --check` OK) makes it a misuse like the gated ones.
Repro (originally `rv2/c1.cob` in a temp scratchpad, not durable):

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. RVW2.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 W-X PIC X(4).
       01 W-Y PIC X(4).
       01 W-N PIC 9(4).
       PROCEDURE DIVISION.
       MAIN-P.
           MOVE CONTINUE TO W-X.
           DISPLAY "A".
           STOP RUN.
```

**Fix direction.** One rule for "a reserved word was written where a user word is required", not the gated-word test alone;
sweep the other always-reserved statement verbs (GO, STOP, EXIT, EVALUATE, ...) in an operand slot. Rows go in
`ReservedWordPositionConformanceTests.AReservedVerbWrittenAsAnOperand_DrawsOneDiagnostic`. PB4132 is the open note for the gate
hijacking a keyword in statement position (the opposite direction).
