## Mechanism

The corpus is GPL, git-ignored and per worktree (PB209, PB277). `scripts/run_gate_legs.py#Host.fetch_corpus` fetches it
when `tests/external/gnucobol/tests/testsuite.src` is absent and makes the gate RED with the reason
`EXTERNAL CORPUS FETCH FAILED, POPULATION UNMEASURED` when the fetch fails. `scripts/battery.sh` has no fetch at all,
and three more callers each carry their own copy of the rule: `scripts/spec/record_impact_map.py` (fetch when absent,
warn), `scripts/linux-gate.sh` (copy the tree's corpus or fetch, NOTE on failure) and `scripts/hooks/session_start.py`
(cloud: fetch unconditionally). Four spellings of one rule, and the one script that runs the corpus's own leg (phase 3)
has none.

## Shape

One fetch rule in one place: a module that, given a tree, fetches the corpus when its marker is absent, verifies the
marker afterwards, and returns the one named red. The gate driver, the battery (before phase 1, so the Unit leg and
phase 3 both see it), the impact-map recorder, the Linux gate and the cloud session hook all call it; a self-test drives
every arm; a drift test keeps any other script from invoking the fetch script directly.

## Landed (wave 1039 group X, 2026-10-08, branch `w1039x-battery89`)

- **The one rule:** `scripts/external_corpus.py` (`ensure(tree, say, run)`; CLI `ensure [--repo]`, exit 1 on a failed
  fetch; `--self-test`, 5 arms: present = no fetch; absent = one fetch in that tree; non-zero exit, exit 0 with no
  marker, and no `pwsh` each the named red `EXTERNAL CORPUS FETCH FAILED, POPULATION UNMEASURED`).
- **Every caller applies it:** `run_gate_legs.py#Host.fetch_corpus` (its own copy and `CORPUS_MARKER` deleted),
  `battery.sh` PHASE -1/2 (before the build, so phase 1's Unit leg and phase 3 both see the corpus; a failed fetch is
  a named summary line and RC=1, and every leg still runs), `record_impact_map.py`, `linux-gate.sh` (copy the tree's
  corpus, then the rule on the clone; a failed fetch is now the named `corpus-fetch` red instead of a NOTE) and the
  cloud `session_start.py` hook (fetched only when absent; it used to re-extract every session). The `corpus absent`
  hints in `gnucobol_differential.py`, `gnucobol_extract.py`, `corpus_sweep.py` and `ExternalCorpusPopulationDriftTests`
  name `python scripts/external_corpus.py ensure`.

  exception (fresh checkout, the step's exit status is the red).
