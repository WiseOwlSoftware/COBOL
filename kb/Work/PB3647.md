# PB3647 — .gitignore names a deleted test

**Sites:** `.gitignore` (the RENDERED VIEWS comment), `scripts/rendered_views.py`.

## What happens

The comment says `RenderedViewsDriftTests` and CI's `audits` job fail when a registered output is tracked or missing from the list. PB2878 deleted `RenderedViewsDriftTests`; the rule is now only `rendered_views.py --check` in the gate audits and CI. The comment names a check that no longer exists (CLAUDE.md rules 4 and 6).

## Fix direction

Reword the comment to name `rendered_views.py --check` and the audits only. Sweep the docs and scripts for other mentions of the deleted test and `rendered_views.py --tree`.

## Landed (wave 20261031, group E)

Re-probed on the branch: `git grep RenderedViewsDrift` found the stale name in `.gitignore` only (plus the history
paragraph of DESIGN-test-build-ci.md that records the deletion, which is correct as written), and `rendered_views.py
--tree` no longer exists. The `.gitignore` comment now names `rendered_views.py --check` (the gate's `RENDERED VIEWS`
audit and CI's `audits` job), and `scripts/rendered_views.py`'s own docstring no longer calls rule (a) "the drift test the
design names" (it names DESIGN-test-build-ci.md section 3.17.4's rule). No other script, doc or workflow names the
deleted test or flag.
