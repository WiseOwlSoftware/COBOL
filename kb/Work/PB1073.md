### Adjudicator finding (alternate-record-key-clause, harm under-rejects)
- **Mechanism:** Two syntax rules of the ALTERNATE RECORD KEY clause about the key OPERAND have no screen: FileControlKeyRules (the table that screens §12.4.5.6.3 SR1/SR2/SR5 post-resolution) says in its summary that SR3..SR7 are deliberately absent, and nothing else enforces SR3 (no variable-length data item - the dynamic-length elementary arm; the dynamic-capacity-table arm is covered by SR1) or SR4 (leftmost byte position shall not coincide with the prime key or another alternate key). The RECORD KEY twin SR-12.4.5.12.3-3 has the same gap.
- **Repro:** --std 2023, all compile exit 0 with no diagnostic: sr3.cob `ALTERNATE RECORD KEY IS R-DYN WITH DUPLICATES` over `05 R-DYN PIC X DYNAMIC LENGTH`; sr4prime.cob `ALTERNATE RECORD KEY IS R-KEY` where R-KEY is the prime key; sr4alt.cob `ALTERNATE RECORD KEY IS R-GRP ALTERNATE RECORD KEY IS R-G1 WITH DUPLICATES` with R-G1 the first subordinate of R-GRP; sr4dupsame.cob the same alternate key twice (probes under out/probe/alternate-record-key-clause/).
- **Expected (spec):** §12.4.5.6.3 SR3 "Data-name-1 and data-name-2 shall not reference a variable-length data item" (§8.5.1.11.1: a dynamic-capacity table or a dynamic-length elementary item) and SR4 "Data-name-1 shall not reference an item whose leftmost byte position corresponds to the leftmost byte position of the prime record key, or of another alternate record key" (the SOURCE exemption does not apply) - each probe is a syntax-rule violation that shall draw a compile-time diagnostic (COBOLNET0863 family).
- **Observed:** All four probes compile clean; sr3 runs and WRITE returns '00'. FileControlKeyRules.cs lines 154-157: 'NOT HERE, deliberately: ... §12.4.5.6.3 SR3..SR7 - which need machinery this screen does not have' - SR5 has since landed (PB1025) through the same table, so the machinery claim is stale for SR3/SR4: RecordLayout.KeyWindowOf already yields each key's byte offset, and the item's DYNAMIC LENGTH attribute is resolved.
- **Code site:** src/Cobol.Net.Compiler/Binding/FileControlKeyRules.cs#Rules (the AlternateRecordKey rows) and its summary lines 154-157
- **Clause (adjudicator):** ISO/IEC 1989:2023 §12.4.5.6.3 SR3, SR4; §8.5.1.11.1
