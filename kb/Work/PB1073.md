# PB1073 — LANDED — `FileControlKeyRules` still excludes the key-operand rules §12.4.5.6.3 SR3/SR4 and §12.4.5.12.3 SR3 on a stale 'needs machinery this screen does not have' claim

## Landed (2026-10-05, wave 1020 G, with PB773)
Re-probed first on this worktree's own build, exit codes and all: `alt_dyn_last` (ALTERNATE RECORD KEY over a trailing
`DYNAMIC LENGTH` item), `prime_dyn` (RECORD KEY over one), `alt_eq_prime` (the alternate IS the prime item),
`alt_eq_prime_grp` (an alternate that is the first subordinate of the prime GROUP), `alt_vs_alt` and `alt_dup_same`
(two alternate clauses at one position) ALL compiled exit 0 with no diagnostic; the legal controls (`alt_ok`,
`alt_ok2`: an alternate inside the prime group but not at its first byte, one after it) exit 0 as they must. After the
fix the six violations each exit 70 with COBOLNET0863 naming SR3 or SR4, and the controls still exit 0.
**Fix (three rows in the one table, as the note asked, plus the structure PB773 forced).** `FileControlKeyRules.Rules`:
`SR-12.4.5.12.3-3` and `SR-12.4.5.6.3-3` ask the operand's own `DataItem.IsDynamicLength` — the ELEMENTARY half of
§8.5.1.11.1's term; the dynamic-capacity-table half is a key under OCCURS, which SR1 already reports, so the row does
not say one fact twice, and a GROUP merely containing a dynamic-length item is a variable-length GROUP, which the
standard names separately where it means to forbid one (§12.4.5.8.3 SR3, §13.10.3 SR12) and does not name for a key.
`SR-12.4.5.6.3-4` compares each alternate clause's `RecordLayout.KeyWindowInFile` offset (+ whether a variable-length
member precedes it) with the prime key's and with every OTHER alternate clause's; `FileKeyOperand` gained `Ordinal` so
two clauses naming one item each violate it. `RecordLayout.KeyWindowInFile` is the one root-walk + `KeyWindowOf` call
the SR4/SR5 minimum-size rows already did inline, now shared by all three. The stale 'NOT HERE, deliberately' summary
is deleted and rewritten: the screen now carries every syntax rule of the three key clauses except the two
DESCRIPTIVE ones (§12.4.5.12.3 SR5, §12.4.5.6.3 SR6). Witnesses: `conformance:negative/pb1073-*` (four, one per probe
shape), `conformance:2014/pb1073_dynamic_length_member_not_a_key_2014` (the over-rejection twin: a dynamic-length
member that is not a key, keys before it), `conformance:85/pb773_legal_file_control_entries_85` (the SR4 boundary) and
`FileControlKeyRuleSpecTests` (every position the rule names, entry-only and verb-bearing). Design: `COBOLNET_FILES_DESIGN.md` D19 "Boundaries".
