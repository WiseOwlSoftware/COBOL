# PB6115 - the PB6072 comments quote §2014:12.4.4.11.2 SR1 inexactly

The summary on `Rules2014` says the 2014 text prints "Data-name-1 shall not be subscripted" for the RECORD KEY, ALTERNATE RECORD KEY and RELATIVE KEY
clauses and cites §2014:12.4.4.11.2 SR1 first. Checked this session with `cite.py`:

- `§2014:12.4.4.11.2 SR1` (RECORD KEY) reads "Data-name-1 and data-name-2 shall not be subscripted." (OK)
- `§2014:12.4.4.5.2 SR1` (ALTERNATE RECORD KEY) reads "Data-name-1 and data-name-2 shall not be subscripted." (OK)
- `§2014:12.4.4.12.2 SR1` (RELATIVE KEY) reads "Data-name-1 shall not be subscripted." (OK, the only one that prints the short form)

So the quotation fails `cite.py --check` for the two clauses cited first.

**Sites.**
- `src/WiseOwl.Cobol.Compiler/Binding/FileControlKeyRules.cs` (`Rules2014`; the doc comment at line 1003)
- `tests/WiseOwl.Cobol.Tests.Conformance/FileControlKeyRuleSpecTests.cs` (`OccursBanCitationAt`; its doc comment at line 57 says the 2014 key clauses say
  "shall not be subscripted", a paraphrase right only for RELATIVE KEY; name the clause whose words it quotes)

**Next.** Quote each clause's own words (the "Data-name-1 and data-name-2" form for RECORD KEY and ALTERNATE RECORD KEY, the short form for RELATIVE
KEY) and run `cite.py --check` on each quotation before it goes in. No code, golden or manifest changes.
