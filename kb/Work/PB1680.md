# PB1680 — OPEN

Filed 2026-09-28 by the train-69 lander from the wave-69 X finisher report (`w69x-PB1355-report.md`, "New
defects" 1). Diagnostic text only; which file is read is correct.

**What happens.** A copybook `gr9dbook.cpy` next to a source whose COPY names `gr9dbook`, compiled on Windows (a
case-insensitive file system): the library-text diagnostics (CBL3620's "Searched", COBOLNET2574's origin, the
line map's copybook name) print `gr9dbook.CPY`. `CopyProcessor.LocateInLibrary` tries `CopybookSuffixes`
(`.CPY, .CBL, .COB, .cpy, .cbl, .cob` — GnuCOBOL's order, the DOC-A.1-40 determination) and returns
`spelled + suffix`, the probe spelling, and `FileExists` answers true for the upper-case probe.

**Code site.** `src/Cobol.Net.Frontend/Preprocessor/CopyProcessor.cs#LocateInLibrary` (returns `spelled + suffix`);
every consumer of the returned path (the `alreadyIncluded` set, `SourceOrigin.File`, diagnostics).

**Repro.** A two-file probe: `COPY gr9dbook.` with `gr9dbook.cpy` holding a line a REPLACE LEADING makes a comment
(`REPLACE LEADING ==Q== BY ==*==.` over `Q>1`) → the COBOLNET2574 location reads `gr9dbook.CPY`.

**What the fixer owes.** Return the directory entry's real name (enumerate the directory once per library, or
canonicalize the matched path), keeping §7.2.3.3 SR3's "first match is the text" order; a unit test on a
case-insensitive probe.

**Second witness 2026-10-07 (wave 1026 group D, PB2116; filed by the train-1026 lander).** The R0 oracle
(`scripts/arch/capture_oracle.py`) captures the diagnostic stream of every suite compile, and a Windows capture
differs from a Linux capture of the same commit in exactly 19 NIST continuity cells, all this defect:
`nist-continuity/SM101A@2002` reports `<repo>/tests/nist/copylib/K1FDA.CPY(1,5): warning COBOLNET0902` on Windows
and `K1FDA.cpy` on Linux (the file is `K1FDA.cpy`). The oracle manifest records its platform until this lands;
after the fix the two captures should agree, and the platform field can be checked for that. Code site unchanged:
`src/Cobol.Net.Frontend/Preprocessor/CopyProcessor.cs:60` (`CopybookSuffixes` probes `.CPY` before `.cpy`).
