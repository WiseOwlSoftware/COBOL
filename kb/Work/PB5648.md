# PB5648 - at --std 2002 ARITHMETIC IS STANDARD evaluates operations on BINARY-LONG and FLOAT-LONG operands by standard arithmetic, where 2002 puts native arithmetic in effect for them

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/OptionsBinder.cs` (whole: the reader pinned no member; the fixer names it; the arithmetic-mode selection)
- `src/WiseOwl.Cobol.Compiler/Binding/Model/OptionsModel.cs` (whole: the reader pinned no member; the fixer names it)

**Mechanism.** The arithmetic mode is chosen per source unit from the OPTIONS paragraph alone. 2002 8.8.1.2 / 8.8.1.3 keep native arithmetic in effect under ARITHMETIC IS STANDARD when an operation uses a binary-char..float-extended item; 2023 has no such fallback, so the compiler's 2023 model serves 2002. SQRT(FLOAT-LONG 2) under STANDARD returns the 32-digit standard result instead of the native technique's value. Not PB5575 (the digit count); this is which mode applies.

**Inventory.** Rows claimed: `2002-RV-15.68.3-3`.

- `§2002:8.8.1.3`: "When a data item described with a usage of binary-char, binary-short, binary-long, binary-double, float-short, float-long, or float-extended is an"
- `§2002:15.68.3 RV3`: "When native arithmetic is in effect, the returned value is the absolute value of the appro"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p3/sqrt_fl.cob); the text is inline. Command: `cobol.exe p3/sqrt_fl.cob --std 2002 --run`

`p3/sqrt_fl.cob`:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. SQRTFL.
       OPTIONS. ARITHMETIC IS STANDARD.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 FL   USAGE FLOAT-LONG VALUE 2.
       01 BL   USAGE BINARY-LONG VALUE 2.
       01 DD   PIC 9 VALUE 2.
       01 R    PIC 9V9(30).
       PROCEDURE DIVISION.
       MAIN-P.
           COMPUTE R = FUNCTION SQRT(FL)
           DISPLAY "STD-FLOAT-LONG  =" R
           COMPUTE R = FUNCTION SQRT(BL)
           DISPLAY "STD-BINARY-LONG =" R
           COMPUTE R = FUNCTION SQRT(DD)
           DISPLAY "STD-DISPLAY     =" R
           STOP RUN.
```

**Observed.** STD-FLOAT-LONG =1.414213562373095048801688724209, STD-BINARY-LONG =1.414213562373095048801688724209, STD-DISPLAY = the same, rc=0.

**Expected (from the 2002 text).** the float-long and binary-long lines take the native technique (the refuter's native run, sqrt_nat.cob, gives 1.414213562373095100000000000000); only STD-DISPLAY is standard.

**Sibling sweep.** every arithmetic statement, expression and numeric function under ARITHMETIC IS STANDARD with a binary or float operand; the FLAG-NATIVE-ARITHMETIC flagging (PB5600) depends on the same per-operation decision.
