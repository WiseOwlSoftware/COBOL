# PB5998 - item lists, paged tables and 1985 folio pointers in the unit mechanism

**Sites:**
- `scripts/spec/text_units.py` (`segment`: the numbered-item start, the list number, the paged table's continuation and
  the labels' uniqueness; `Unit`: its `ordinal` and `sublist`; `_rows`, `_header`, `table_units`; `POINTER`,
  `PAGE_TARGET`, `pointer_targets`, `class_refusal`, `Context`)
- `scripts/spec/extract_rule_catalog.py` (`extract`: a unit row's ordinal and list number read from the unit, the
  module function that computed the ordinal deleted; `unit_context`: its resolver reads a printed page and its title)
- `scripts/spec/citation.py` (`page_texts`)
- `scripts/spec/cite.py` (`unit_designator`: an item of a later list)
- `scripts/selftests/spec/text_units/test_text_units.py` (`_context`, `PAGES`, and the cases
  `case_10_a_numbered_list_printed_one_item_per_line`, `case_11_a_table_continued_across_pages_numbers_its_rows_on`,
  `case_12_a_1985_folio_pointer_is_a_cross_reference`)
- `docs/rearchitecture/spec-unharvested-rule-blocks.json`, `-2002.json`, `-1985.json` (`paragraph-blocks` only: the
  units the corrected segmentation relabels or re-segments, every one pending)
- `docs/rearchitecture/spec-rule-catalog.json`, `-2002.json`, `-1985.json` (`outside-denominator` only, the pending count)
- `docs/rearchitecture/DESIGN-spec-conformance-review.md` ("Phase A, continued", points 1, 2 and 3) and kb/Work PB5448
  (an addendum: the id of an item of a clause's later list)

**What the pilot found** (kb/Work PB5452, 2026-11-21, `E:/COBOL-coord/scratch/pb5452/campaign.md`):

1. **A numbered list printed one item per line is one unit.** `text_units.segment` started a numbered item only on a
   fresh candidate (after a blank line). The 1985 transcription prints §1985:IV.4.2.2.1.1's two lists as the PDF does
   (page 152), one item per line with no blank line between, so each list became ONE unit labelled `1` holding all its
   items: all 15 numbered-item units of the 1985 catalog's 956 hold a whole list. And two lists in one clause both took
   the printed numbers of their items, so §1985:IV.4.2.2.1.1's two lists and §1985:X.1.3.8's five each produced the
   label `1` more than once: their row ids (`1985-SR-IV.4.2.2.1.1-1`) would collide at the mint.
2. **A table continued across pages restarts its row ids.** §1989:A.2.4's Table 1 prints on three pages, each page
   repeating the header, so the segmentation read three tables all numbered 1 and `T1.1` to `T1.15` occur up to three
   times. The 2002 text has the same shape three times (§2002:14.4 Table 13, §2002:14.5.12.1.5 Table 14, §2002:15.5
   Table 22).
3. **The cross-reference test cannot read 1985's pointer.** The 1985 text points by folio ("(See page VI-13, The
   SPECIAL-NAMES Paragraph.)", about 540 times). `text_units.POINTER` reads only `See <locator>` with a locator in
   `citation.universe(1985)`, so every pure 1985 pointer fails the `cross-reference` class test and could never be
   disposed `not-a-rule`.

**Fix.** At the root, in the one segmentation and the one test: a numbered item starts at its own marker (a fresh
candidate, or the next number of the open list); each list of a clause is numbered, its items labelled by printed
number in the first list and `L<m>.<n>` in the m-th, the form numbered rule lists already have (PB5448 addendum); a
table fragment with the number and header of a table already read continues it, its rows numbered on; `segment` refuses
a clause whose units share a label; and the pointer grammar reads `page <folio>, <title>` (one or more), a folio
resolving when the page exists and its text prints the title. Row-neutral, like PB5449.
