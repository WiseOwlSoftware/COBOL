# PB1717 — LANDED (PB1708 pivot M11)

Filed by the orchestrator from the PB1708 pivot design (workflow wf_08642598-d3c, reviewed APPROVE_WITH_CHANGES, all eleven findings resolved by the reviser), 2026-09-28.
## Mechanism (`docs/rearchitecture/DESIGN-test-build-ci.md` section 3.13, section 3.14.2, section 3.14.9 row M11)

`scripts/spec/impacted_tests.py` loses its selection code and gains `--plan`. Its filter line is always the
whole-assembly filter until M13 deletes the line. A new `scripts/gate_plan.py` builds the order plan: tiers 0a/0u/1–3,
`NameKey`, the budgets and the collection cap. It ships with `ImpactedTestsDriftTests`. This closes PB1712.

  stale-map, empty-leg-1 and whole-assembly-in-leg-1 arms.

- b4 re-run through the script reproduces cheapest-first on 68b X, with the first red at or below 1 % of the work.

## Landed (wave 71 group C, 2026-09-28)

**Built** (design `DESIGN-test-build-ci.md` sections 3.13 and 3.14.2, corrected in the same change).
- `scripts/spec/impacted_tests.py`: the selection is DELETED (`build_filter`, the term budget, `MapIndex.selection`,
  `--dump`). `analyse()` returns the change's `Reach` (tier-1 `direct` and tier-2 `widened` entry masks, the reasons
  every test is tier 1, the test METHODS the change adds, the goldens it touches) and each recorded test's tier per
  assembly; `--plan FILE` writes it as JSON. A stale map is now USED for durations and names (every test tier 1).
  The last stdout line is always `FullyQualifiedName~.`; `--plus` is accepted and ignored until M13 deletes it.
- `scripts/gate_plan.py` (new): `name_key`, tiers 0a/0u/1–3, `LEG_ONE_BUDGET`, `LEG_ONE_UNKNOWN_BUDGET`,
  `LEG_ONE_COLLECTION_CAP`, leg 2 longest collection first, the per-assembly degenerate arms, `leg_of`, and the
  canonical `plan.json` (its `sha256` is the content digest; the last stdout line is the file-bytes digest).
- `ImpactedTestsDriftTests` (Unit, 5 facts): both self-tests by arm; a mapped change is tiered (via `--plan`) while
  the filter line stays whole; an unmapped file puts every test in tier 1; only partition classes end in `_P<k>`;
  every product project is recorded. The evidence scripts moved to the new API (`common.py`, `a2`, `a5`–`a8`, `b4`);
  `a9` and `b4`'s orders A–D reproduce their frozen outputs exactly.

**Design correction (rule 5).** Tier 0a was "a case declared in a test file the diff changes". Run through the real
script, 68b X (which edits the corpus and continuity harnesses) put 5,774 cases and 8,037 test-seconds in 0a and its
first red after 62.8 % of the work. Tier 0a is now the test methods the diff ADDS; an edited test or harness is tier 1
through the map (the test assemblies are recorded).

**Acceptance, measured.** `b4` row P (through `gate_plan.py`): both reds in leg 1, the first after **0.32 %** of the
work (leg 1: 2,829 cases, 248 test-s, 15.0 s floor). `b7`'s last table: an append to the 85 manifest leaves **one**
tier-0u case and a **15.3 s** floor (2002/2014/2023/negative: 1 case, 15.2–15.3 s). With a map, the filter line is
the whole assembly (`AMappedChange_IsTiered_AndTheFilterLineStaysTheWholeAssembly`).

**For the next implementer (M12, M13).**
- `scripts/gate_plan.py#name_key` — THE key: split at the first `(`; in the head split on `.`; with ≥ 3 segments,
  a class segment matching `(.+)_P\d+` in full loses the suffix; rejoin + `(` + args unchanged. `GateLegs.cs` (M12)
  mirrors it exactly; `ImpactedTestsDriftTests.ThePartitionSuffix_IsOnlyOnPartitionClasses` keeps the suffix
  partition-only.
- `scripts/gate_plan.py#leg_of` — the reference leg function (2 for a `leg2` key, else 1: total). `plan.json` =
  canonical JSON, `assemblies.<A>.{legs, leg1, leg2, stats}`, lists in RANK order (rank = position, leg 1 first);
  `sha256` = content digest (every other field, canonical); the last stdout line = SHA-256 of the file BYTES (the
  handshake digest `COBOLNET_GATE_PLAN_SHA256`). `legs` = the legs to invoke the assembly for (`[2]` = skip leg 1).
- `scripts/gate_plan.py#main` — inputs for M13's driver: `--list <Assembly>=<raw --list-tests output>` (header line
  `The following Tests are available:` required), `--base`, `--previous-run <run dir with *.trx>`; REUSE
  `read_listing`, `read_previous_run`, `build_plan`, `write_plan` rather than re-parsing.
- `scripts/spec/impacted_tests.py#analyse` — the one change analysis (`Reach`, tiers keyed by RAW display name); the
