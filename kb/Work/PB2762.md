**Scenario:** CollationElementIterator.TryMatchContraction/FindContraction/MatchesAt match every contraction of the table, and try the discontiguous extension whatever the first code point is. A composite whose NFD holds a root contraction next to a tailored piece is therefore given elements the run-time iterator would not produce for its decomposed spelling, breaking the closure's own invariant; and a later correction to the blocking rule (S2.1.2) in one copy will not reach the other.
