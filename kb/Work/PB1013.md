# PB1013 — OPEN

## Repro — measured
`printf 'QRSTUV\n' | cobol scratchpad/w51b/probe/acc.cob --run` → `L=[Q     ]` / `X6=[Q     ]`. Expected `L=[QRSTUV]`.
GR-14.9.1.4-3 is CONFORMS today on fixed-size witnesses only.

## The rule
`OK  §14.9.1.4 3)` — "If a device is capable of transferring data of the same size as the receiving data item, the
transferred data is stored in the receiving data item." The receiving item's size is the argument's (ANY LENGTH).

## Code site
`AcceptDisplayEmitter.EmitAcceptDevice` reads `DisplayTextWidth` (the declared width, 1 for ANY LENGTH). Same shape as
PB887 (ACCEPT kept a private list of receiver arms instead of going through the MOVE store): the size must come from
the receiver's Place at run time.

## What the fixer owes
Size the device transfer from the receiver's run-time length (ANY LENGTH, dynamic-length, ODO-bearing group); sweep
ACCEPT FROM DATE/TIME/… (format 2) and DISPLAY UPON for the same static width. Golden with a separately-compiled callee.
