# PB5724 - no 2002 determination documents B.1 item 46 (exponentiation results for certain operand values) under 2002 standard arithmetic; docs/conformance/4/POWER-DEVELOPMENT.md covers the 2023 SDIDI development only

**Sites:**

**Mechanism.** The implementor-defined item has a 2023 entry only. PB5575's run-time arm now normalizes into the 32-digit standard intermediate (expo.cob values), so the missing piece is the determination, not the arithmetic.

**Inventory.** Rows claimed: `2002-DOC-B.1-46`.

**Repro.** Command: `cobol.exe expo.cob --std 2002 --source-format fixed --run (E:/COBOL-wt/coderead85-tree-d/src/WiseOwl.Cobol.Cli/bin/Debug/net10.0/cobol.exe, main d615406082)`

`defects-work/d/p/expo.cob`:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EXPO.
       OPTIONS.
           ARITHMETIC IS STANDARD.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 R PIC S9(10)V9(20).
       01 B PIC S9(3)V9(3).
       PROCEDURE DIVISION.
           COMPUTE R = 2 ** 5 DISPLAY "2**5=" R
           COMPUTE R = 2 ** 0.5 DISPLAY "2**0.5=" R
           COMPUTE R = 9 ** 0.5 DISPLAY "9**0.5=" R
           COMPUTE R = 1.1 ** 10 DISPLAY "1.1**10=" R
           MOVE -8 TO B
           COMPUTE R = B ** (1 / 3)
               ON SIZE ERROR DISPLAY "(-8)**(1/3) SIZE ERROR"
               NOT ON SIZE ERROR DISPLAY "(-8)**(1/3)=" R
           END-COMPUTE
           STOP RUN.
```

**Expected (from the 2002 text).** the same values and a documented 2002 determination
