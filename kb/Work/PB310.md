# PB310 — a gate that would pass unchanged if 145 codes were deleted

## The measurement, not an assumption

Scanning `src/` for `/(Error|Warning|Report|Info)\s*\(\s*"COBOLNET[0-9]{4}"/` and differencing against
`DiagnosticCatalog` and `docs/DIAGNOSTICS.md`: **162 codes are emitted as bare literals and 145 of them are in
neither** — `COBOLNET0710`, `0712-0717`, `0805-0898` in bulk, `1501-1568` in bulk (including `1517`),
`1585-1617`, `1642`.

Worked instance, static, no build needed:

1. `grep -rn 'COBOLNET1517' src/` → **one** emit site,
   `src/Cobol.Net.Compiler/Binding/Procedure/Verbs/IntrinsicBinder.cs:600`, written
   `ctx.Edition.Error("COBOLNET1517", …)` with the code as a bare string literal.
2. `grep -n '1517' src/Cobol.Net.Editions/Diagnostics/DiagnosticCatalog.cs` → **no match**.
3. `grep -rn 'COBOLNET1517' docs/` → matches only two `docs/rearchitecture/backlog-*.json` probe records, never
   `docs/DIAGNOSTICS.md`.

## The substance: the gate cannot see the gap

`DiagnosticRegistryDriftTests` has three facts, and none of them reaches a code that is not in the catalog:

* `EveryDescriptor_HasUniqueId` and `EveryDescriptor_HasUniqueCode_OutsideSplitFamilies` both enumerate
  `DiagnosticCatalog.All`.
* `SplitCodes_HaveNoBareEmitLiteral_InCompiler` bans bare `Error("<code>"` literals for exactly **two** codes
  (`SplitCodes` = `COBOLNET0899`, `COBOLNET1533`).
* The doc-sync fact compares the doc against the **CATALOG**.

So the doc is "in sync" **precisely because** the catalog does not know the code exists, and the bare-literal ban
does not reach it because it is not one of the two migration codes. This is the
`feedback_green_gates_arent_evidence` shape at full size: **the gate would pass unchanged if all 145 codes were
deleted from the compiler or renumbered on top of each other**, since nothing outside the catalog is checked for
collision either.

## Why this is not PB175

`kb/Work/PB175` owns the **semgrep** `cobolnet-raw-diagnostic-code-literal` count drift and the fact that
`verify.py` has no gate seat. That is a count that grew. **This** is the different and worse fact that the C#
drift gate is structurally blind — a code can be emitted to users, collide with another, and change meaning, with
every registry fact green. Fixing PB175's count would not fix this; fixing this would make PB175's count
measurable by something that fails.

## The fix, and the shape that makes the next case automatic

Invert the drift test's direction: enumerate the **emit sites in `src/`** and require each to resolve to a
`DiagnosticCatalog` descriptor and a `docs/DIAGNOSTICS.md` row — rather than enumerating the catalog and asking
what it documents. Then a code added as a bare literal fails on the day it is written, and the `SplitCodes`
two-name allowlist becomes unnecessary rather than load-bearing. **Make it fail once** before trusting its silence.

## Bounded consequence for the batch that found it

Two negative fixtures landed by the golden lane name `COBOLNET1517` in their `.err` and are correct to do so — the
compiler really emits it. The cost is only that the code's meaning is recorded **nowhere a user or a future
maintainer can read it**, and that the task instruction "name the expected diagnostic from `docs/DIAGNOSTICS.md`"
was impossible to follow for this code.
