# PB4971 - the map pass's candidate retrieval misses counterparts

**Sites:** `scripts/spec/audit_batch.py#plan_map` (the candidate selection)

Map pass, k = 15 candidates: SAME 1,251, DIFFERS 538, NONE 464. A NONE whose reason names a deleted or replaced feature
(the communication module, the Debug module, ALTER, DATA RECORDS) is right. 217 NONE reasons name no such feature, and
they say the counterpart is missing from the candidates. Examples: `1985-GR-IX.2.3.4-7` ("no candidate addresses the
FILE STATUS clause"), `1985-GR-VI.6.17.4-3` ("would be in 2023 GR 5, which is not among the candidates"). Each of these
becomes an OWN-ROW, which a fleet adjudicator must decide from scratch, when it could carry a 2023 verdict.

Expected: before fleet adjudication, run these rules through a cheap batch re-map with retrieval of another kind (by
clause heading and subject, or with the 2023 clause the reason names). Make that retrieval part of `plan_map`, not a
second tool, so the next edition's audit (2002, PB4813) gets it automatically.

**Landed (owner 2026-11-08: "Use the strongest appropriate signals. Rerun").** Measured first: the heading alone matches no
2023 clause for 598 of the 2,253 rules (1985 repeats a clause per module and names clauses differently), so a
deterministic heading channel would have moved at most 88 of the 217. The design is a ROUTE pass and clause-first
candidates (`audit_batch.py`; DESIGN-spec-conformance-review.md §10.3):
- `route`: one request per 1985 clause (247), with its subject, module and first rules and the list of every 2023 clause;
  the answer names the 2023 clauses that state the same feature (at most 8). 226 ROUTED, 21 NONE, $3.62.
- `candidates`: every 2023 rule of the same kind in the routed or heading-matched clauses, uncapped, then the wording's
  top 15. `plan --pass map` refuses an unanswered route pass. Median 29 candidates a rule (p90 72, max 130).
- The re-run, state `E:/COBOL-coord/scratch/audit-1985/state-route`, on the catalog with PB4972's corrections:
  map $37.90 (SAME 1,323, DIFFERS 540, NONE 390), verify $8.02 (UPHELD 759, REFUTED 530, UNSURE 34); results CARRIES
  759, DISPUTED 564, OWN-ROW 930 (the k = 15 run: 747, 504, 1,002). NONE answers whose reason blames the candidates fell
  from 204 to 131; a sample of the rest reads as genuine (2023 states no such rule). Drafts: 891 of the 930 reused from
  the first run (the same item), 39 sent.
