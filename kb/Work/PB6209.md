# PB6209 - OPEN - the header and footnote classes of text_layer_diff.py excuse more than they prove

All four items sit in the rules PB6135 added to `scripts/spec/text_layer_diff.py` to move LIKELY-ERROR rows into mechanical
classes. Each fails open: a real transcription error in the same shape would be classed as explained.

1. **Bag equality (R1-1).** `_header_reading` (line 576) excuses ANY permutation of a header group's words as TABLE-HEADER,
   so a transcription that swaps two single-word header cells, UNEXPLAINED before PB6135, now passes unseen. The wrapped-cell
   reading has an order the rule does not check: each printed line reads the cells in column order (`2ND 3RD`, then
   `ELEMENT STD STD`), so the layer sequence must be an interleaving of the cells' word runs with every printed line in the
   Markdown's column order. Check that, and keep bag equality as a necessary condition only.
2. **`<td>` header rows.** The headers of pp. 610-620 and p. 617 are `<td>` rows, not `<th>` or a pipe row before a separator,
   so `table_header_groups` (line 549) does not see them and their rows stay LIKELY-ERROR. Recognise them by the same
   structural test, or record why they are not headers.
3. **FOOTNOTE-RENUMBERED.** `_renumbered_hunks` (line 603) excuses a marker that differs by one constant offset from in-page
   evidence only. The offset continuity across pages (a footnote series that continues over a page break) is unused, so a
   renumbering that is wrong on the page after an Amendment insertion passes. Use the cross-page offset.
4. **Link text.** `kb/Work/PB6204.md` named its evidence link `2026-11-24-likely-error-classes` while the target is
   `PB6135/2026-11-24-two-classes-measured.md` (review R1-2). Fixed in the change that filed this note.

**Fix shape.** One selftest case per item, each a swap or an off-by-one the tool must leave UNEXPLAINED or LIKELY-ERROR; then
re-measure the 976 pages and report each class's rows before and after.

**Sites:** `scripts/spec/text_layer_diff.py:576` (`_header_reading`, `table_header_groups`, `_renumbered_hunks`, `classify_page`)
