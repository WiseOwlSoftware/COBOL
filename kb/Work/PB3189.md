# PB3189 — ProgramRegistry.RunMain is dead public ABI

> ⚙ **flags:** process-only

Source: `w1085a-PB2099-report.md` "## New defects (note-ready)", bullet 1 (filed by the clerk, 2026-10-15).

**The lead.** `ProgramRegistry.RunMain(string path)` (`src/Cobol.Net.Runtime/Control/ProgramRegistry.cs:137`, forwarding to `RunUnit.Current.Programs.RunMain`) has had no caller in `src/` since the hosts moved to entries. The clerk's check on origin/main 6452ed98a: the only callers are `tests/Cobol.Net.Tests.Conformance/NonCobolActivatorLinkageTests.cs` (lines 142 and 163) and doc comments (`ProgramRegistry.cs:107`, the test class summary). `ProgramTable.RunMain` (the instance method it forwards to) stays live as the boundary `RunModule` shares.

**Why it is not a drive-by.** Removing a public runtime method is a runtime-major bump (`Directory.Build.props`, every snapshot's version string), which is tree-wide, so it lands on its own (finisher-never-widens). Rule 4 applies: delete the static forwarder and change every caller in the same change (the two test call sites move to the entry the hosts use; the doc comments name the surviving entry). Check whether `ProgramTable.RunMain` is then also only reached by tests, and apply the same rule.

**Harm.** None to a program's output; a public surface that no host uses and that a decade of support would have to keep.
