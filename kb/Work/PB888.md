# PB888 — OPEN — the fourth hand-written copy of a data description

Source: the `PB522` report, "New defects" item 1.

## The measurement

`<scratch>/reg6/probe/p42_udf_groupusage.cob` (PROGRAM-ID `R6P42`, FUNCTION-ID `R6NGFN`), `--std 2023 --run`:

```cobol
FUNCTION-ID. R6NGFN.
LINKAGE SECTION.
01 RESULT-NG GROUP-USAGE NATIONAL.
   02 RN PIC N(4).
PROCEDURE DIVISION RETURNING RESULT-NG.
...
01 CTL-NG GROUP-USAGE NATIONAL.          *> the control: same description, in working storage
   02 CN PIC N(4).
    DISPLAY "LEN-CTL=" FUNCTION LENGTH(CTL-NG)
    DISPLAY "LEN-FN=" FUNCTION LENGTH(FUNCTION R6NGFN)
```

```
LEN-CTL=4
LEN-FN=8
rc=0
```

Same description, two answers. The control is right (§15.50.4 rule 2 counts national POSITIONS); the
temporary is counting alphanumeric ones.

## The rule

```
$ python scripts/spec/cite.py --check 8.4.3.2.4 "the description, class, and category of the temporary data item"
  OK  §8.4.3.2.4 1)  (General rules)
      If function-prototype-name-1 is specified, the description, class, and category of the temporary data
      item is that specified by the description in the linkage section of the item specified in the RETURNING
      phrase of the ...
```

"the description ... is that specified by the description" — the whole entry, not a chosen subset of clauses.

## The code site

* `src/Cobol.Net.Compiler/Binding/DataBinder.Oo.cs#CreateCompilerTemp` (~L571)
* `src/Cobol.Net.Compiler/Binding/DataBinder.Oo.cs#CloneTempNode` (~L601)

Both copy `Pic`, `OwnSign`, `OwnUsage`, `Justified`, `BlankWhenZero` and nothing else. `GroupUsage` is not in
the list, so it does not survive; nor would any clause added tomorrow.

## The remedy — a classified copy, not a sixth field

`CopyEntryDescription` is the existing home for "copy a description entry". The fix is to fold both temps
into it. The report flagged §8.4.3.2.4 GR1 / §11.7.4 as having "their own exclusion story and a pre-gating
residue check" — which clauses a temporary must NOT inherit is a real question and it is the ONE place it
should be answered. **A hand list where a classified copy belongs is the defect; a longer hand list is not
the fix.**

## The sibling sweep

Grep for every site that constructs a `DataItem` by naming clauses one at a time: `CreateCompilerTemp`,
`CloneTempNode`, and whatever `SendingValueTemp` builds (PB886 measures the same shape for a MOVE
intermediate's carrier). A drift test asserting that no code outside `CopyEntryDescription` assigns more than
one description clause onto a synthesised item makes the next clause automatic.
