# PB3264 — named_paths scans whole bodies

**Mechanism.** `scripts/spec/work.py` `named_paths(body)` (line 896) applies `_NAMED_PATH` and `_BARE_PATH` to the entire note text, in code spans and bare in prose. `named_missing_paths` (its caller) therefore reports a missing path for any historical path a note's prose mentions, and any consumer of the full list over-declares. PB3242 moved the planner's declared set to the structured site blocks; this reader was left on the old whole-body rule, so the register has two readers with two answers to "which files does this note name".

**Source.** Report `w1090a-PB3242-report.md`, lead 2. Repro: a note whose prose names a retired path outside any site block makes `named_missing_paths` flag it.

**Fix shape.** One reader of a note's sites (the PB3242 reader) used by `named_paths` and `named_missing_paths` too; delete the whole-body scan in the same change (rule 4: no second path).
