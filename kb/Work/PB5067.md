# PB5067 - run_drafts.py cannot give a draft its library files

**Sites:** `scripts/spec/run_drafts.py` (`tests_of`).

**Found (1985 triage, slice-13).** Four corrected COPY drafts carry a `files` member (the library text the COPY statement
includes), but `run_drafts.py` writes each test with `"files": []`, so they cannot be run through the harness as written.
Carry a draft's `files` into its test (the conformance-suite harness already supports per-test files), then re-run them.
