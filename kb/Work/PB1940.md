# PB1940 — OPEN

Filed by the train-1007 lander from wave 1007 group B's report (`w1007b-PB480-report.md`, "New defects" item 1).
Same root as [[PB1116]], which landed the typed-INVOKE arm in train 1007.

## Defect

A strong group whose subordinates include `USAGE OBJECT REFERENCE` has no boundary character image, so the CALL and
user-function lanes have no carrier for it, and `CALL "PGNS" AS NESTED USING G` (G of a `TYPEDEF STRONG` holding an
object reference) draws COBOLNET1688 "this activation boundary does not yet carry such a group". §14.8.2.2 2) "If
either the formal parameter or the corresponding argument is a strongly-typed group item, both shall be of the same
type" (`cite.py --check 14.8.2.2` → `OK §14.8.2.2 2)`) is the only conformance rule, and the source satisfies it;
§14.9.4.3 SR25 sends CALL's argument conformance to §14.8.2.
