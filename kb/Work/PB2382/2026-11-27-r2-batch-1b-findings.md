### `runtime-values-4--architecture--f1#4` (finding, unify, votes upheld/upheld/upheld)

**Finding:** Emitted runtime member names joined from strings (CobolBool.{method}All, FloatResultant.{method}OrRaise) escape the nameof anchor RuntimeApi uses everywhere else, so a rename breaks only generated programs and the census reports live members as dead at every run (R0-0116, R0-0189, R0-0194 at this pin)

**Rule:** Reachability is measured, never deduced, and dead code is removed (kb/Work R69 DESIGN-architecture-review §3, DESIGN-architecture-review §8.7 test-only rule); one naming mechanism for emitted runtime entries: RuntimeApi anchors each emitted name with nameof so that renaming the runtime member breaks this member, not the emitted text (src/WiseOwl.Cobol.Compiler/CodeGen/Roslyn/RuntimeApi.cs:62-64, BoolOpName), the discipline DESIGN-architecture-review §8.7 RuntimeMembers wave builds on.

**Scenario:** RuntimeApi.BoolOpAll (RuntimeApi.cs:59-61) writes CobolBool.{method}All(...) for BooleanRenderer.RenderBinary (BooleanRenderer.cs:82, 84, a B-AND/B-OR/B-XOR with an ALL boolean operand), and RuntimeApi.FloatResultantStoreOrRaise (RuntimeApi.cs:1328-1332) writes FloatResultant.{stem}OrRaise for the INVOKE float-formal crossing (OoEmitter.cs:1775). (1) Rename CobolBool.OrAll or FloatResultant.FromDecOrRaise: the solution builds and every unit test of the runtime passes, and a COBOL program using X B-OR ALL B"1", or an INVOKE passing an SDIDI value to a FLOAT-LONG formal under EC-SIZE-TRUNCATION checking, fails its Roslyn compile at the user. (2) The census matches emitted identifiers, so at this pin it lists CobolBool.AndAll/OrAll/XorAll(CobolBoolSized, string) as test-only and unreachable (R0-0116, R0-0189) and FloatResultant.FromDecOrRaise as unreachable (R0-0194): kb/Work PB2202 was filed as a Delete from the same rows and retired as live emitted text (PB2202/2026-11-17-retired.md), and PB2756 re-measure names the joined-name blind spot with no open note owning it, so each new census files the same false Delete again.

**Target:** Every emitted runtime member name is a nameof expression: BoolOpAll takes the ALL-form name from a nameof table keyed by the operator (nameof(CobolBool.AndAll), OrAll, XorAll), as BoolOpName does for the dyadic form, and FloatResultantEntry returns both the stem and its OrRaise twin as nameof values; a drift assertion over RuntimeApi refuses an interpolated runtime member name built from a variable plus a literal suffix. The census then counts the members, R0-0116 (the AndAll part), R0-0189 and R0-0194 drop by measurement, and R0-0116 EqualAll(string, string), which nothing emits, is judged by DESIGN-architecture-review §8.7 as dead code a test keeps alive.
