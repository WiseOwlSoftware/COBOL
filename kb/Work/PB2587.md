`PIC X(6) JUSTIFIED RIGHT` formal arrives `ABCD  ` (a MOVE gives `  ABCD`); `PIC S9(3)` -12 into `PIC X(4)` arrives

## Rule

ISO 14.2.3 GR9, for a program with a program-specifier: the allocated record has the formal's description and is
filled by "a COMPUTE statement without the ROUNDED phrase" if the formal is numeric, "otherwise, a MOVE statement".
ISO 14.9.25.4 6): "If the sending operand is described as being signed numeric, the operational sign is not moved".
Both checked with `cite.py --check` by the implementer.

(`ProgramTable.LandArguments`, `BoundaryItem.Land`) registers only numeric formals' carriers, so it needs the MOVE leg
too: one landing for both lanes, as PB2549 did for the COMPUTE.
