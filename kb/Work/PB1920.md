# PB1920 — LANDED (wave 20261769 B)

## Landing — a valid literal-8 is registered whatever literal-7's verdict

**Re-probe** on 802352531 (`E:/COBOL-coord/scratch/w20261769b/p/p1920.cob`: `CURRENCY SIGN IS SPACE WITH PICTURE
SYMBOL "#"` and `01 A PIC #9.99.`): COBOL0892 (SR18) then COBOL0808 "invalid PICTURE symbol '#'". The same cascade
followed SR23 a) (`"   "`), SR23 b) (`"E1"`) and NULL (COBOL2576), `p1920v0..3.cob`.

**Fix.** In the PICTURE SYMBOL form the two operands are judged independently (§12.3.7.3 SR23: "literal-7 is the
currency string and literal-8 is the associated currency symbol"; `cite.py --check 12.3.7.3` → OK 23)), and
`RegisterCurrency` binds a valid literal-8 even when literal-7 was refused, as `CurrencyDefinition.OfRefusedClause`:
the symbol stays a currency symbol, but no rule reading the string or class is asked of it (SR21 neither meets nor
makes a conflict with it, so a later valid clause takes the symbol over; SR28 is skipped in `PictureAnalyzer`; the
string joins no §15.68.3 r3 count). The bare form is unchanged in effect: there literal-7 IS the symbol. Literal-8's
own faults (SR26, SR27) are now reported beside a refused literal-7's instead of being hidden by its early return.
Sibling sweep: CLASS and ALPHABET clauses refused for an operand leave no cascade (`s1.cob`).

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.Switches.cs` (`SwitchBindCurrency`, `CurrencyStringAdmitted`,
`RegisterCurrency`), `src/WiseOwl.Cobol.Compiler/Binding/Model/CurrencyDefinition.cs` (`ClauseRefused`,
`OfRefusedClause`), `src/WiseOwl.Cobol.Compiler/Binding/PictureAnalyzer.cs` (`AnalyzeCharacterString`).

- Witnesses: `tests/WiseOwl.Cobol.Tests.Conformance/CurrencySignRefusalTests.cs` (exactly one error for each literal-7
  refusal; a later valid clause takes the symbol over with no SR21 conflict), negative golden
  `conformance-suite/cases/12.3.7-SPECIAL-NAMES/pb1920-currency-string-refused-symbol-stands` (2002+).

# PB1920 — as filed

Filed by the train-1004 lander from wave 1004 group A's report (`w1004a-PB1095-report.md`).

## Finding

**Site.** `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.Switches.cs#SwitchBindCurrency` — its early returns on a refused
literal-7 / literal-8 (COBOL0890/0892/2576) skip registering the PICTURE SYMBOL, so a later `PIC #9.99` (the symbol
the clause named) is read as an invalid PICTURE character and draws COBOL0808 and COBOL0819 after the clause's
own error. Harm: noise only — the compilation already fails on the real diagnostic — but the cascade buries it.

**Repro.** Any refused CURRENCY SIGN clause plus a PICTURE using its symbol, e.g. `CURRENCY SIGN IS SPACE WITH PICTURE
SYMBOL "#"` and `01 A PIC #9.99.` (group A's probe `scratchpad\w1004a\p791b.cob` before the fix shape).

**Fix shape.** Register the PICTURE SYMBOL (with a placeholder currency string) even when the clause is refused, so
the one verdict stands alone; a negative golden whose `.err` holds exactly one line.
