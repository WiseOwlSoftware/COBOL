# PB1920 — OPEN

Filed by the train-1004 lander from wave 1004 group A's report (`w1004a-PB1095-report.md`).

## Finding

**Site.** `src/Cobol.Net.Compiler/Binding/DataBinder.Switches.cs#SwitchBindCurrency` — its early returns on a refused
literal-7 / literal-8 (COBOLNET0890/0892/2576) skip registering the PICTURE SYMBOL, so a later `PIC #9.99` (the symbol
the clause named) is read as an invalid PICTURE character and draws COBOLNET0808 and COBOLNET0819 after the clause's
own error. Harm: noise only — the compilation already fails on the real diagnostic — but the cascade buries it.

**Repro.** Any refused CURRENCY SIGN clause plus a PICTURE using its symbol, e.g. `CURRENCY SIGN IS SPACE WITH PICTURE
SYMBOL "#"` and `01 A PIC #9.99.` (group A's probe `scratchpad\w1004a\p791b.cob` before the fix shape).

**Fix shape.** Register the PICTURE SYMBOL (with a placeholder currency string) even when the clause is refused, so
the one verdict stands alone; a negative golden whose `.err` holds exactly one line.
