# PB5594 - which words VALUE OF takes as implementor-name-1 at --std 85

**Sites:** none (no change: the choice stands as documented in `docs/conformance/3.7/index.md`, row "VALUE OF implementor-name-1")

**The question.** §1985:VII.3.9.2 prints `VALUE OF {implementor-name-1 IS {data-name-1 | literal-1}} ...`; the names are
the implementor's, and "The labels are checked or written in accordance with the implementor's specified conventions for
input or output label handling" (§1985:C.2, `cite.py --check` OK). WiseOwl COBOL accepts any word (docs/conformance/3.7,
kb/Work PB5070). The adjudicator reported that GnuCOBOL refuses VOLUME-ID there, which, under CLAUDE.md rule 1's
precedence for latitude, would make the choice differ from GnuCOBOL's.

**Probes** (`E:/COBOL-coord/scratch/op-20261114/records-held/gnu/vo/`, GnuCOBOL 3.2.0 in WSL, `cobc -std=cobol85
-fsyntax-only`, log `cobc.log`; WiseOwl on the records-85-held build, `wiseowl.log`):

| Program | VALUE OF entries | GnuCOBOL | WiseOwl |
|---|---|---|---|
| `vo_mis.cob` (the held probe) | `FILE-ID IS "RIGHT" VOLUME-ID IS W1 OF G1` | syntax error at the second entry ("unexpected Identifier, expecting EXTERNAL or GLOBAL") | accepted, `HELLO` |
| `vo_lit.cob` | `FILE-ID IS "RIGHT" VOLUME-ID IS "V001"` | the same syntax error | accepted, `HELLO` |
| `vo_none.cob` | `FILE-ID IS "RIGHT"` | accepted | (accepted, the held twin `vo_fid.cob`) |
| `vo_volonly.cob` | `VOLUME-ID IS "V001"` | accepted | |
| `vo_anyonly.cob` | `ZZQ-NAME IS "V001"` | accepted | |
| `vo_any.cob` | `FILE-ID IS "RIGHT" ZZQ-NAME IS "V001"` | syntax error at the second entry | accepted, `HELLO` |

**Answer.** GnuCOBOL accepts VOLUME-ID, and any word, as implementor-name-1: the same choice as WiseOwl, so the
documented latitude stands and agrees with the precedence. What GnuCOBOL refuses is a second entry, which the format's
ellipsis admits; that is GnuCOBOL departing from the printed format, not latitude, and WiseOwl accepting it is right.
(Reporting it upstream is the owner's call; it is not filed as an upstream note here.)
