## ⛔ The consequence the report did not name: COBOLNET0849 means two unrelated things

Three of its four emissions are **not declines**. `EcBinder.cs:176/183/192` reject an ordinary Format-3 RAISING
operand under §14.9.18.3 SR4 — a mandatory syntax rule of a claimed facility. `--check 14.9.18.3 "Identifier-1
shall be an object reference"` → **OK §14.9.18.3 4)**, and its sub-rule
`--check 14.9.18.3 "shall not be a universal object reference"` → **OK §14.9.18.3 4) a)**. That rule has
nothing to do with Annex A.4.10, with an optional element, or with anything COBOL.NET declines. So one code
number carries two unrelated meanings, and a user who suppresses it, greps for it, or looks it up gets both.

**That collision is the proof of the defect rather than a separate one.** A catalog descriptor is one code = one
rule = one severity = one suppress key — the semgrep rule's own message says it: *"Every emitted code must be a
catalog descriptor (one code = one rule, ISO §, severity, suppress-key) so the drift test can prove the two
channels agree"* (`scripts/semgrep/invariants.yml:94-96`) — and `DeclinedFacilityDriftTests.cs:138` asserts
`Assert.Single(DiagnosticCatalog.All, d => d.Code == code)` for the codes it knows. A bare literal is owned by
nobody and appears in no such assertion, so a second, unrelated use of the number cannot be detected — and was
not. Any fix must therefore **split the code before adding a descriptor**: giving COBOLNET0849 a
descriptor that declares an A.4.10 annex would label three §14.9.18.3 SR4 errors as declined-facility notices.

## What the absence costs

- **No `docs/DIAGNOSTICS.md` row**, in a band that is otherwise documented around them: the file carries
  COBOLNET0801, 0802, 0855, 0862, 0863, 0869, 0875, 0878, 0881, 0883, 0898, 0899 — 0822 and 0849 sit between
  documented neighbours. (⚠ Scope honesty: `src/` emits **99** distinct COBOLNET08xx codes and DIAGNOSTICS.md
  documents **12** of them. These two are not the whole hole — they are the two whose absence is load-bearing
  for a §4.2.7 claim, which is why they are a note of their own rather than a line in PB175's.)
- **No suppress-key family and no severity datum** — the two things a user acts on.
- **Invisible to the declined-facility guard.** ⛔ The report describes `DeclinedFacilityAnnexDriftTests` and a
  `DeclinedAnnex` flags datum on `DiagnosticDescriptor`; **neither is on main** — that is PB709's change set,
  `status: open`, in flight. What main has today is
  `tests/Cobol.Net.Tests.Unit/DeclinedFacilityDriftTests.cs`, which enumerates descriptors
  (`:122-128` names `ValidateDataDivisionClauseUnsupported`, `ApplyCommitClauseUnsupported`,
  `DeclinedModuleExceptionName` and asserts their `ResolvedSuppressKey`; `:138`
  `Assert.Single(DiagnosticCatalog.All, d => d.Code == code)`). A code that is not in `DiagnosticCatalog.All`
  is not merely unasserted — it is **unreachable** by that guard's whole shape. So when PB709's annex guard
  lands it will protect eleven declines and structurally cannot see these two.
- **Outside the allocation instrument.** `scripts/session-probe.ps1:26-27` scans `COBOLNET1[0-9][0-9][0-9]` for
  the next-free code — the 1xxx band only — so the 08xx band has no next-free calculation at all and no
  cross-check between the two channels.

Three registers already name these codes as the §4.2.7 witnesses, all of them prose: `docs/CONFORMANCE.md:506`
(§4's A.4.10 paragraph), `:969` (§5 row A.4.10) and `:107` (§2 row 45, on COBOLNET0822). The conformance record
asserts a named refusal; nothing mechanical connects that assertion to a diagnostic that exists.

`process_only: true` — no user program computes anything different. `--check 4.2.7 "An implementor shall identify
in user documentation the optional language elements"` → **OK §4.2.7** is what makes it more than housekeeping:
the identification is made in prose and is not held to the compiler by anything.

## The fix shape

1. **Split the reuse first.** Allocate a fresh code for `EcBinder`'s three §14.9.18.3 SR4 emissions (one code,
   or three, per the catalog's grain for a multi-arm syntax rule) from `pwsh scripts/session-probe.ps1`'s
   next-free — ⛔ and note that the probe does not compute one for the 08xx band, so the allocation must scan
   that band explicitly rather than trusting the printed figure. Do not reuse 0849 for the SR4 arm and re-home
   the decline; the decline is the meaning the conformance registers already cite.
2. **Two descriptors**, `Oo` decline codes with the annex datum PB709 introduces (`Annex = DeclinedAnnex.A4`),
   their ISO clause — item 1's is §11.3.2, whose general format prints
   `--check 11.3.2 "object-class-name-2"` → **OK §11.3.2** (`[ INHERITS FROM { object-class-name-2 } … ]`, the
   repetition being the optional element), and item 3's is `--check 9.3.5.3 "parametric polymorphism"` → **OK
   §9.3.5.3** — severity
   Error, and a suppress key in the declined-facility family, plus the two `docs/DIAGNOSTICS.md` rows the
   descriptors generate. **Land this AFTER or WITH PB709**, since `DeclinedAnnex` does not exist on main —
   landing the descriptors first would build a second annex mechanism (`feedback_one_mechanism_per_job`).
3. **Prove the guard fails.** `feedback_green_gates_arent_evidence` / `prove_the_watchdog_fails`: after PB709's
   `DeclinedFacilityAnnexDriftTests` gains these two rows, flip one descriptor's annex on the live catalog and
   confirm it goes red — the report says exactly that experiment turned three of five red for the other eleven.
4. **The semgrep baseline moves, and that is the measurement.** `scripts/semgrep/invariants.yml:90-112`
   (`cobolnet-raw-diagnostic-code-literal`) matches `$X.Error($CODE, …)` with `$CODE` a `"COBOLNET\d{4}"`
   literal — all six sites here match — and `scripts/semgrep/baseline.json` records **427** for that rule today.
   Converting these six drops it to **421**; the commit shall move the baseline by exactly that and no more
   (PB175's discipline).

## Sweep

- **PB175's class is not closed and this is its declined-facility corner.** The 427 remaining literals are the
  population; the right next step after this note is not six more conversions but the question of why an emit
  API accepts a raw string at all — a `DiagnosticDescriptor`-only `Error` overload would make the whole class
  unreachable, which is the shape that makes the next case automatic (CLAUDE.md rule 5).
- **Every other code named in `docs/CONFORMANCE.md` should be a descriptor.** That is the cheap invariant PB744
  proposes adding beside its §4 item-number parser; written once it covers §2, §4 and §5 together and would have
  caught these two the day the registers first named them.
- **Check the rest of the OO band for the same reuse.** COBOLNET0849's collision was found by reading the emit
  sites, not by a tool; `grep -c` over each 08xx code's distinct message families is a ten-minute sweep and
  should be done in the same change set (`feedback_scan_all_similar`).
