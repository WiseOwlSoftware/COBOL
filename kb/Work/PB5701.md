# PB5701 - at --std 2002 a compiler directive written on a debugging line (D>>DEFINE in fixed form) is accepted silently, where 2002 forbids a directive on a debugging line

**Sites:**
- src/WiseOwl.Cobol.Frontend/Preprocessor/ReferenceFormatProcessor.LogicalConversion.cs#ConvertLine (the LineKind.Debugging arm)

**Mechanism.** ReferenceFormatProcessor.ConvertLine carries a debugging line (LineKind.Debugging) for DebuggingLineRewriter and checks only the floating indicator; nothing asks whether the carried text is a compiler directive, so without WITH DEBUGGING MODE the line becomes a comment and no diagnostic is given.

**Inventory.** Rows claimed: `2002-SR-7.2.2-8`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`).**

- `§2002:7.2.2 SR8`: "A compiler directive may be specified anywhere in a compilation group, in source text or in library text, except" (`cite.py --check`: OK  §2002:7.2.2 SR8  (Syntax rules)  the text is in SR8)

**Repro.** Command: `cobol.exe p14x_directive_on_debugline_effect.cob --std 2002 --source-format fixed --run (E:/COBOL-wt/coderead85-tree-d/src/WiseOwl.Cobol.Cli/bin/Debug/net10.0/cobol.exe, main d615406082)`

`defects-work/d/p/p14x_directive_on_debugline_effect.cob`:

```cobol
000000 IDENTIFICATION DIVISION.
000000 PROGRAM-ID. P14X.
000000 ENVIRONMENT DIVISION.
000000 CONFIGURATION SECTION.
000000 SOURCE-COMPUTER. X.
000000 PROCEDURE DIVISION.
000000D>>DEFINE VV AS 1
000000 >>IF VV IS DEFINED
000000     DISPLAY "DEFINED"
000000 >>ELSE
000000     DISPLAY "NOT DEFINED"
000000 >>END-IF
000000     STOP RUN.
```

**Observed.** COBOL0903 obsolete warning for the D line only, then NOT DEFINED, rc=0

**Expected (from the 2002 text).** a diagnostic for the directive on the debugging line (SR8 item d, "on a debugging line", has three words, under the four-word floor of cite.py, so the SR8 lead-in is the checked quotation)

**Other editions.** 2023: no (the D indicator is removed at 2023: COBOL0902). 85: not applicable (85 has no compiler directives).

**Sibling sweep.** the floating debugging indicator >>D followed by a directive; a directive inside pseudo-text on a debugging line
