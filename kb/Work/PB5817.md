# PB5817 - OPEN: does a reference that uses another table's index-name for a dimension violate 1985-SR-IV.4.3.8.2.3-3 (the text admits two readings; the same question at 2023 row SR-8.4.2.3.3-4)?

**Ruling: OPEN.** A reference `C3 (CX, RX)` with the index-names swapped between the dimensions of a two-dimension table compiles and runs at `--std 85` and at `--std 2023`. Whether `§1985:IV.4.3.8.2.3 SR3` bars it, with `§1985:II.4.4.2` and SR2, is not decided by the text. The row `1985-SR-IV.4.3.8.2.3-3` stays undecided (it was not in the batch that raised the question), and so does the same question at 2023, row `SR-8.4.2.3.3-4`. Harm: under_rejects under reading 2 (not set while the question is open). The checker's confidence: medium.

**Where the question came from (the ruling's mechanism 9, REJECTED for its own row).** The row `1985-GR-VI.6.23.4-1` is confirmed: it says only that an index-name is associated with the table whose OCCURS names it in INDEXED BY, the compiler binds each name to its own table's `IndexDeclaration`, and SET conversions across dimensions are right (the refuter confirmed it with `setconv.cob`). The refuter's doubt is about another rule: whether `C3 (CX, RX)`, with the index-names swapped between dimensions, must be refused. That belongs to subscripting, `1985-SR-IV.4.3.8.2.3-3`, which was not in that batch, and there the text admits two readings. The compiler prints `d` at 85 and at 2023 (`CX=2` used for `R3`, `RX=1` for `C3`).

**The two readings (the checker's).**
- Reading 1 (literal): SR3 admits the reference, because each index-name corresponds to an entry in the hierarchy of the referenced table, and the compiler's `DeclaredInHierarchy` follows that reading (kb/Work PB459).
- Reading 2: read with `§1985:II.4.4.2` (an index-name "can be used to reference only the table to which it is associated"; an index corresponds to an occurrence number "for that specific dimension") and SR2 (subscripts in order of less inclusive dimensions), `CX` in the first position references `R3`'s dimension and the reference under-rejects.
- What settles it: whether the Section II concept sentence binds as a rule (Section II is the concepts chapter); failing that, CLAUDE.md rule 1's order (GnuCOBOL measured). The question is the same at 2023 (row `SR-8.4.2.3.3-4`).
