# A12c — ⛔ THE GUARD CAN REPORT `=== ALL GREEN ===` WHILE A PROGRAM SILENTLY VANISHES FROM THE RUN

- ⛔ THE GUARD CAN REPORT `=== ALL GREEN ===` WHILE A PROGRAM SILENTLY VANISHES FROM THE RUN — a FALSE GREEN, which is the direction that actually endangers v1.0
- ⛔ **OBSERVED 2026-08-02 (PB10):** `guard-fast` printed **`=== NIST: 352 MATCH, 0 REGRESSION(S) ===`** and **`=== ALL GREEN ===`** where the recorded baseline is **353 MATCH**. A per-program diff against the previous green run showed `SQ135A` produced **NO LINE AT ALL** — not MATCH, not REGRESSION, not DIVERGENT: absent. Because the verdict is computed from the REGRESSION count alone and nothing asserts the POPULATION, losing a program lowers MATCH and still passes. A12/A12b are about a false RED wasting time; **this is the mirror case, and it is the one §12 R-6 names as the real risk** — "the same non-determinism that produced a false RED can mask a real failure". A reviewer reading only the verdict line would have shipped on it. ⚠ It was caught only because the previous run's output was still on disk to diff against, which is luck, not method. (Disposition for THIS instance: SQ135A is `corpus.tsv:282` GREEN and the greenfield Conformance leg — which runs `NistProgram_MatchesGolden("SQ135A")` — passed 4171/4171, so the program itself is verified through the compiler the change touches; the loss is in the legacy parallel harness.)
- Make the NIST leg assert `reported == \
- TESTS\
- ` and FAIL loudly on any program that produced no verdict line — a missing verdict is a failure, never a silent subtraction. Print the count beside the baseline so the two are compared by the script and not by a human's memory. **AND ISOLATE THE CHAINS** (below).
- ⛔ **Before any "all legs green" claim is used as v1.0 evidence** — a green whose population is unasserted is not evidence
- **CLOSED 2026-08-03.** `scripts/guard-nist-audit.sh`, consumed by BOTH guards, asserts the run is a PARTITION of the declared population (one verdict per program, no strays, no duplicates) and that each program's verdict CLASS equals the one `tests/nist/corpus.tsv` predicts — plus a manifest↔disk cross-check so a golden that VANISHES cannot quietly turn its program into an expected `NO BASELINE`. ⭐ **The expectation is DERIVED, not remembered:** `divergent`→LEGACY DIVERGENT, `golden==none`→NO BASELINE, else MATCH reproduces **353/12/11 over the 376-program population exactly**, and self-updates the moment a golden lands. `--self-test` proves all ELEVEN checks can fail, EACH with its own named finding — the first draft had two cases "passing" because an unrelated bug had already reddened the control, which is the same defect one level up. ⚠ Written as ONE awk pass: the bash-loop draft took >2 min over 376 programs (0.9 s now), and a correct check that is slow gets deleted later for being slow.
