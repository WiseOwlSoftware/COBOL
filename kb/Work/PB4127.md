# PB4127 — the rewritten DOCUMENTED-NON-SUPPORT meaning in tests/version-matrix/inventory-schema.json quotes §4.2.7 as sc

**Sites:** `tests/version-matrix/inventory-schema.json` (the DOCUMENTED-NON-SUPPORT `meaning` text, line 44).

Review lead R1-1 (low, round 1) of PB593. The `meaning` of DOCUMENTED-NON-SUPPORT (inventory-schema.json:44) quotes 4.2.7 as scoping
itself to "the optional language element list" (A.4), but the standard's text is "listed in A.4, Optional language element list". The
quotation fails `python scripts/spec/cite.py --check 4.2.7 "<the quoted phrase>"` (CLAUDE.md rule 1: every citation is validated
mechanically).

**Fix:** replace the paraphrase-in-quotes by the exact text (run `cite.py --check 4.2.7` on the new sentence) or drop the quote marks
if it is a paraphrase. Then sweep the schema file's other quoted phrases through `cite.py --check`.

Source: report `w20261770c-PB593-report.md`, review lead R1-1; PB593 (landed). PB593 is held by an in-flight group (inflight-groups.json),
so this is a new note.
