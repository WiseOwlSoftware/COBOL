# PB4305 - Fourteen 2002 Annex F.2 syntactic relaxations (items 10, 16, 46, 50, 61, 75, 90, 91, 108, 112, 133, 139, 141, 145) compile at `--std 85` with no edition diagnostic; the project's own precedent (D-SIGN2, PB3683, perform-varying-by-omitted-2002) lets F.2 decide the 85 edge

Found by the Mythos front-end review, gap pass, 2026-10-31 (GAP-REVIEW.md, G5-5; artifact https://claude.ai/artifact/KaxkLe85tfZBZ3nZ1tDGTs). Pin d7daee1cf.

**Finding.** Fourteen 2002 Annex F.2 syntactic relaxations compile at `--std 85` with no COBOL0900 (`G5/p03 ... p36`): item 10 CALL USING a level-05 item, 16 class condition with alphabet-name, 46 DISPLAY -5, 50 EXIT PROGRAM not last, 61 GLOBAL in LINKAGE, 75 INSPECT CONVERTING ... Each F.2 item states the 85 restriction it lifts ("Formerly, they had to be elementary or have a level number of 1 or 77"). Probes: p03, p07, p08, p11, p14, p15, p20, p22, p23, p28, p29, p32, p33, p36. The first report framed this as an owner question because `cobc -std=cobol85` accepts twelve; the refuter REFUTED the framing: rule 1 puts ISO text above GnuCOBOL, 2002 F.2 is ISO text about the previous standard, and the project already lets F.2 decide the 85 edge (D-SIGN2 quotes F.2 item 124; PB3683 quotes item 123; perform-varying-by-omitted-2002). cobc's acceptance is dialect leniency (it also refuses p32 and p36 at every dialect). Verified CORRECT in the same sweep: word length (COBOL1567 names 30/31), `PIC 999.  .` refused per SR7, WRITE FILE phrase refused as declined A.4.13, literal CALL BY CONTENT argument refused.

**Fix direction.** One constructs.json row per item, introducedIn 2002, citing its F.2 item; the grammar keeps the 2023 shape; screen in VersionConformancePass or the binder; a determination beside D-SIGN2 stating the general rule; run the NIST-85 / CCVS-85 corpus at `--std 85` before landing.

**Waits on owner question 3** (GAP-REVIEW.md section 5.3): "Apply the 2002 Annex F.2 'formerly' statements as the rule for the 85 edge (fourteen rows, note 10), as D-SIGN2 and PB3683 already did for items 123/124?" Cost of yes: the CCVS-85 corpus must stay green at `--std 85`.
