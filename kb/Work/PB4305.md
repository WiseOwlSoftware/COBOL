# PB4305 - Fourteen 2002 Annex F.2 syntactic relaxations (items 10, 16, 46, 50, 61, 75, 90, 91, 108, 112, 133, 139, 141, 145) compile at `--std 85` with no edition diagnostic; the project's own precedent (D-SIGN2, PB3683, perform-varying-by-omitted-2002) lets F.2 decide the 85 edge

Found by the Mythos front-end review, gap pass, 2026-10-31 (GAP-REVIEW.md, G5-5; artifact https://claude.ai/artifact/KaxkLe85tfZBZ3nZ1tDGTs). Pin e62fbdc35.

**Sites:** `tests/version-matrix/constructs.json` (no rows for these fourteen); `src/WiseOwl.Cobol.Compiler/Validation/VersionConformancePass.cs` (no 85 screen); `docs/CONFORMANCE.md` beside D-SIGN2 (the determination).

**Finding.** Fourteen 2002 Annex F.2 syntactic relaxations compile at `--std 85` with no COBOL0900 (`G5/p03 ... p36`): item 10 CALL USING a level-05 item, 16 class condition with alphabet-name, 46 DISPLAY -5, 50 EXIT PROGRAM not last, 61 GLOBAL in LINKAGE, 75 INSPECT CONVERTING ... TO ALL, 90 statements before the first paragraph, 91 inline PERFORM VARYING ... AFTER, 108 SET qualified index-name, 112 RELATIVE KEY without ACCESS MODE, 133 arithmetic-expression subscript, 139 reference-modified UNSTRING sender, 141 USE AFTER STANDARD ERROR without PROCEDURE, 145 VALUE in LINKAGE. Each F.2 item states the 85 restriction it lifts ("Formerly, they had to be elementary or have a level number of 1 or 77"). Probes: p03, p07, p08, p11, p14, p15, p20, p22, p23, p28, p29, p32, p33, p36. The first report framed this as an owner question because `cobc -std=cobol85` accepts twelve; the refuter REFUTED the framing: rule 1 puts ISO text above GnuCOBOL, 2002 F.2 is ISO text about the previous standard, and the project already lets F.2 decide the 85 edge (D-SIGN2 quotes F.2 item 124; PB3683 quotes item 123; perform-varying-by-omitted-2002). cobc's acceptance is dialect leniency (it also refuses p32 and p36 at every dialect). Verified CORRECT in the same sweep: word length (COBOL1567 names 30/31), `PIC 999.  .` refused per SR7, WRITE FILE phrase refused as declined A.4.13, literal CALL BY CONTENT argument refused.

**Fix direction.** One constructs.json row per item, introducedIn 2002, citing its F.2 item; the grammar keeps the 2023 shape; screen in VersionConformancePass or the binder; a determination beside D-SIGN2 stating the general rule; run the NIST-85 / CCVS-85 corpus at `--std 85` before landing.

**Waits on owner question 3** (GAP-REVIEW.md section 5.3): "Apply the 2002 Annex F.2 'formerly' statements as the rule for the 85 edge (fourteen rows, note 10), as D-SIGN2 and PB3683 already did for items 123/124?" Recommended yes (rule 1: F.2 is ISO text about the previous standard; GnuCOBOL -std=cobol85 acceptance is dialect leniency). The no-case: no X3.23-1985 text is in the repository to confirm each "formerly", and twelve of the fourteen compile under cobc -std=cobol85, the net the project uses for 85. Cost of yes: the CCVS-85 corpus must stay green at `--std 85`.

**Evidence.** E:/COBOL-coord/scratch/w-gr2/GAP-REVIEW.md (sections 2 and 5.1); G5/p03-p36; G5-refute; review-G5.md. Probe names are copied from the shard reports; the refuter folders are E:/COBOL-coord/scratch/w-gr2/G*-refute/. Shard reports: E:/COBOL-coord/scratch/w-gr2/review-G*.md.

**Owner decision, 2026-10-31 (Mythos session, answering GAP-REVIEW.md section 5.3 question 3):** YES. The 2002 Annex F.2 "formerly" statements are the rule for the 85 edge for all fourteen rows, as D-SIGN2 and PB3683 did for items 123 and 124. Condition: the CCVS-85 corpus stays green at `--std 85`, run before landing.

## Landed (wave 20261825 group A)

**Re-probe** (pre-fix build, `G5/p03 … p36` at `--std 85`): all fourteen compiled and ran, with no COBOL0900. p03 passes
an ELEMENTARY level-05 item, which item 10 allows at 85 ("elementary or ... level number of 1 or 77"); the golden uses
a level-05 GROUP.

**Fix.** Fourteen `constructs.json` rows, introducedIn 2002 and COBOL0900, each quoting its F.2 item, with VCR row 7.47
and the determination D-F2-85 (CONFORMANCE.md, beside D-SIGN2). Each row is gated in one place. The parse arm of
`VersionConformancePass` covers items 46 (`VisitDisplayStatement`), 50 (`VisitExitStatement`), 61 (`VisitGlobalClause`),
75 (`VisitInspectConvertingPhrase`), 90 (`VisitProcedureDivision` and `VisitSectionDefinition` through
`GateLeadingSentences`), 91 (`VisitPerformVaryingAfter`), 112 (`VisitRelativeKeyClause`), 133 (`VisitSubscriptPart`,
`IsCobol85Subscript`), 139 (`VisitUnstringStatement`), 141 (`VisitUseStatement`) and 145 (`VisitValueClause`,
`EntryHasExternal` over the new shared `EntryHasClause`). Its bound arm covers item 10 (`GateStatement`, the
`BoundCallProgram` case; adjudicated in `EditionGateArmDriftTests.BoundArmResolvedFact`). The binder covers item 16
(`ConditionBinder.BindUserWordClassCondition`, the alphabet-name arm) and item 108 (`ReferenceResolver.ResolveIndexName`,
once per written reference). The grammar keeps the 2023 shape.

**Goldens:** a positive `pb4305_<item>_2002` (2002 2014 2023, output computed from the cited rule) and a negative
`pb4305-<item>-at-85` (expects its own row's COBOL0900 text) for each item, in the folder of its rule (VCR row 7.47 lists
them). The NIST CCVS-85 corpus runs at `--std 85` in the gate's Conformance population.

**Sites (as landed):** `tests/version-matrix/constructs.json`, `src/WiseOwl.Cobol.Editions/Constructs.g.cs` and
`ConstructRegistry.g.cs` (generated), `src/WiseOwl.Cobol.Compiler/Validation/VersionConformancePass.cs` (the members

## Gate fallout (waves 20261825 and 20261826 group A)

accept at `--std 85` that writes one of the fourteen relaxations (CCVS-85 itself stayed green). Each was corrected so
that it keeps the edition its subject is about:

- **Sentences before the first paragraph-name (item 90), 106 suite tests:** `PB4305-LEAD.` is inserted where the
  compiler names the leading sentence (103 in wave 20261825, and the three `8.4.6.2-Local-and-global-names/pb4432_*`

  `NonstandardExtensionWarningTests`, `ConditionNameValueSizeTests`, `WordCharacterScreenTests`,
  `InheritedConfigurationNameUseTests`, `SetLocaleDispositionTests`, `DeclinedFacilityTests`,
  `BoundArmDiagnosticPositionTests`, `DiagnosticPositionTests` and `StatementSequencePlacementTests` (SQE02, a section
  that began with a sentence) write `MAIN-P.`.
- **The subject IS the relaxation, so the test runs from 2002:** `pb436_varying_after_from_outer` (inline AFTER, item
  91), `pb1523_global_linkage_redefiner` and `pb2087_by_reference_group_aliasing` (GLOBAL in linkage, item 61),
  `pb1643_display_literal_decimal_comma`, `pb3505_display_numeric_decimal_form` and `pb3505_display_numeric_digits_form`

  `pb919_index_name_qualified` (item 108). `pb394_evaluate_function_subscript_subject_85` is deleted: a function
  subscript is the item-133 form, and its 2002, 2014 and 2023 twins keep the subject. `IndexNameUniquenessTests` compiles
  every case that writes a qualified index-name at 2002; the bare-reference SR1 refusals stay at 85.
- **The relaxation is incidental, so the test is rewritten into its COBOL-85 form:** `pb1390_abbreviated_tail_and_or`
  and `pb413_go_to_out_of_inline_perform` nest inline PERFORM VARYINGs (item 91; same iterations, same output);
  `pb440_perform_empty_range_85` keeps the out-of-line VARYING alone (its inline twin is in the 2002+ witnesses);
  `pb1913_debugging_lines_in_open_regions` subscripts with `W-I + 2` (item 133); `pb571_class_condition_one_table` drops
  its alphabet-name line (item 16, witnessed by `pb4305_class_condition_alphabet_name_2002`).
- **`OptionalWordSubsetDriftTests`:** the `use-format-1` row (PROCEDURE optional) compiles at 2002, and a new row
  `use-format-1-85` sweeps AFTER, STANDARD and ON with PROCEDURE written, the COBOL-85 format item 141 describes.

The three new diagnostics that quote source (items 46, 75 and 133) quote it through `WrittenSource.Of`, so a function
subscript reads `FUNCTION INTEGER(1)`, never `FUNCTIONINTEGER(1)`.
