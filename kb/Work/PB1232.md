# PB1232 — OPEN

## Measured

**constant-entry** — F-SR3-CONST-SUB — the SR3 subscript screen admits only integer-literal TOKENS, so an integer constant-name subscript of data-name-2 is rejected

- **Repro:** 01 KI CONSTANT AS 2. 01 T. 05 E PIC X(3) OCCURS 4. 01 K CONSTANT AS LENGTH OF E (KI). DISPLAY K.
- **Expected (spec):** Compiles; K = 3. SR3 requires the subscripts to be literals; SR2 admits a constant-name 'anywhere that a format specifies a literal' and GR1 makes it 'as if literal-1 were written', so an integer constant-name subscript is a literal subscript.
- **Observed:** COBOLNET1547 'all subscripts of the LENGTH OF operand shall be literals (ISO §13.10.3 SR3)'. The token filter (SUB_INTEGERLIT/INTEGERLIT/SUB_WS/SUB_LPAREN/SUB_RPAREN/SUB_COMMA) never consults the constant table, unlike ReferenceResolver.ResolveSubscriptName in the procedure division.
- **Code site:** src/Cobol.Net.Compiler/Binding/DataBinder.Constants.cs#BindConstantLength
- **Clause (adjudicator):** §13.10.3 SR3 with SR2 / §13.10.4 GR1
