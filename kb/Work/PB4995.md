# PB4995 - lineage slice 4: the fleet adjudication of the 1985 change records

docs/rearchitecture/DESIGN-spec-conformance-review.md §10.2, slice 4. Inputs: the audit run `E:/COBOL-coord/scratch/audit-1985/state-route` (`results.json`: DISPUTED 564,
OWN-ROW 930; the verify pass's refutation for each disputed rule; the drafts pass's program and expected outcome for each
own-row rule). Each disputed rule is decided KEPT or CHANGED against the 2023 rules the map named; each own-row rule is
confirmed CHANGED or REMOVED with its evidence, then given a verdict under `--std=1985` with a pinned compiler, its
witness a draft checked against the rule text before use. Dispatched through the workstream skill (CLAUDE.md rule 9).

**How (Mythos session, 2026-11-08: the cheapest path that keeps the strongest signal; the owner's rule that the Batch
API does what it can).** 1,494 rules are too many for an agent each. The work splits by what decides it:
- DISPUTED (564), a text judgment: a new `adjudicate` pass in `audit_batch.py` (Message Batches, Opus, the cache
  layers of PB4998) gives each rule, its routed 2023 candidates and the verify pass's refutation, and asks KEPT (with
  the 2023 rule it carries to) or CHANGED (with what changed), citing both texts. A second, independent batch pass
  refutes each answer; an answer the refuter overturns goes to an agent (`cobol-adjudicator`), never to a vote.
- OWN-ROW (930), a compiler question: a script (not an agent) compiles and runs each rule's checked draft under
  `--std=1985` with the pinned compiler and compares the outcome with the draft's expected one. A match is the
  verdict's witness (the draft becomes the rule's test); a mismatch is a GAP whose defect note is filed, or, where
  the draft is suspect, goes to an agent. REMOVED (the rule has no 2023 successor and the 2023 text drops it) is
  confirmed by the same adjudicate pass.
- Every result is recorded through `record_verdicts.py --edition 1985`, in batches, no hand-written store file.
Agents decide only what the passes and the compiler leave open. The pass, the runner and the recording are code
that lands; the API spend is capped with `--max-usd` after a canary, account 1's key.
