# PB5137 - the order audit claims a check it did not run

**Sites:** `scripts/spec/verify_publishable.py:551` (`main`: the print), `scripts/spec/reserved_word_order.py` (`LISTS`, `check`).

**Found.** `main` prints "every adjacent pair, and the letter groups" for every edition that has a row in `LISTS`. The 2023 row has
`gaps=False`, so the letter-group check did not run for it, yet the success line says it did: a PASS that overstates what it
verified, in an audit whose output is read as the proof.

**Owed.** Build the success text from what the row enabled (and say which checks were skipped), so the claim and the check are one
structure; extend the self-test with a row whose `gaps` is False.
