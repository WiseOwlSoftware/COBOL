# PB4433 - hidden-condition arm suppresses COBOL2096 on a bare operand

**Defect.** The new hidden-condition arm of `ReportMisqualifiedCondition` (ConditionBinder.cs:1716, added by the PB2103
review fix ce19f414b) is also reached from the bare-operand classifier (ConditionBinder.cs:1238, IF and EVALUATE)
whenever `Probe` fails. A subscripted scalar data item that hides a container GLOBAL 88 is then told the position
requires a condition-name, and the verdict the same reference draws when no 88 of the spelling exists, COBOL2096
(ISO 8.4.2.3.3 SR2, as the report cites it), is suppressed.

**Witness.** `E:/COBOL-coord/scratch/reports/w20261821a-PB2103-report.md`, R2-1 (low, not blocking at round 2). Not probed by the reporter.
The clause is the report's own; no text is quoted here.

**Fix direction.** The report gives none beyond the symptom: the bare-operand path must reach the hidden-condition arm
only for a reference that is in a condition-name position, so COBOL2096 stays the verdict for a data item.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ConditionBinder.cs#ReportMisqualifiedCondition`
