# PB5017 - the measured-page drawing reader does not pair a stray delimiter across lines

**Sites:** `scripts/spec/figure_options.py` (`read`, `_text_holders`); the sibling `scripts/spec/figure_reading.py` (`spans`).

**Report.** `figure_reading.spans` had the same root cause (a delimiter whose partner sits on another line) and PB4929 fixed it on that path. The measured-page path, `figure_options.read` through `_text_holders`, has no stray-delimiter pairing across lines. The 2023 run shows one unpaired delimiter each in 12.3.7.2, 12.4.6.2 and 14.9.28.2.

**Harm.** Unproven. An unpaired delimiter can hide or split an optional-word candidate in the optional-word audit (`audit_grammar_optional_words.py`), so the audit may under-report; no harm flag is set because no hidden candidate has been shown. The fix is one pairing mechanism shared by both paths (CLAUDE.md rule 4), not a second copy; the three clauses are the witnesses, and the audit's candidate list for them should be re-read after the fix.
