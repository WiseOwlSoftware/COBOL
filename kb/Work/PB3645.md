# PB3645 — Sources.constants is not the fixed point its docstring promises

**Sites:** `scripts/spec/drift_rules.py` (`Sources.constants`, `STRING_DECL`, `path_expr`), `scripts/spec/impacted_tests.py`.

## What happens

The docstring of `Sources.constants` promises that a constant may name a later one however long the chain, and that a name is ambiguous only when declared twice to different values in ONE pass. The loop is `for _ in range(8)`, and `ambiguous` is a set that is never cleared between passes. So a reverse-ordered chain of more than 8 constants resolves to a partial value, and a name declared twice whose two values become equal once a later constant resolves stays dropped as ambiguous. The consequence is a drift test's read path indexed too short or not at all, so `impacted_tests.py` plans fewer tests for a change than it should.

## Fix direction

Iterate until `consts == before` (the chain length bounds it) and rebuild `ambiguous` per pass; add planted arms to `drift_rules.py --self-test` for a 9-constant reverse chain and for a twice-declared name whose values converge.
