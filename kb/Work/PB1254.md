Probes: out13/probe/linkage-section/sr3.cob, sr3r.cob. || REFUTED: DIVERGES — The CALL ... AS NESTED arm is thoroughly enforced (USAGE, SIGN, JUSTIFIED, scale, BLANK WHEN ZERO, strong-type, group-vs-numeric, BY CONTENT COMPUTE rule, RETURNING length all rejected with COBOLNET1688/1736), but the FUNCTION-activation arm is not: 14.8.2.3.2 rule 2 names 'a function' among the activated elements whose formal and argument shall have the same PICTURE/USAGE, and 8.4.3.2.3 SR8 routes user-defined function arguments through 14.8.2. An in-unit FUNCTION-ID with REPOSITORY entry, formal P-X PIC 9(3), invoked FUNCTION RLKG(W-X) with W-X PIC 9(4) VALUE 21 (an identifier, so BY REFERENCE per 8.4.3.2.4 GR a) compiles clean and prints 00004 (P-X aliases '002' of '0021') -- a silent wrong answer where the spec requires rejection. A pointer argument to an OBJECT REFERENCE function formal is likewise accepted at compile time and fails only at run time. Both halves verified only for CALL NESTED.
