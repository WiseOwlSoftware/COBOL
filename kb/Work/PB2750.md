**Rule it breaks:** CA1062 at AnalysisLevel=latest-all, applied analyzer-first (DESIGN-architecture-review §5.5, R4); the runtime's public surface is the ABI that PublicApiAnalyzers ties to the runtime AssemblyVersion major (DESIGN-external-repository.md §15.4, adopted by open note PB2097), and §8.3 (9) makes RuntimeMembers the one catalogue of what emitted code calls (PB2382)

**Scenario:** Measured on the pin: of the 21 CA1062 hits only 3 are on members the emitter writes (CobolFile.ReleasedRecord, RuntimeApi.cs:1469; CobolSort.AssociationMade, :1498; CobolSort.FillTo, :1558). The other 18 are on FileRegistry (6), FileConnector (6), FileCharacterSet (2), CodeSetConversion (2), FileStatusCode (1) and CobolFile.ResolveHostPath (1), none of which src/Cobol.Net.Compiler writes as emitted text or nameof (zero hits); the only use outside the runtime is the const CodeSetConversion.ChannelUnits in Binding/CollatingModel.cs:317, and the only public signature exposing them is RunUnit.Files. Applying the CA1062 code fix as an R4 wave would add 18 ArgumentNullException checks to plumbing only the runtime calls, several on per-record paths (the FileConnector.Status setter, NoteRecordRead, FitRecord, Stored). Leaving them public is worse: when PB2097 turns on PublicApiAnalyzers, FileRegistry's 113 members, the connector hierarchy and every FileStatusCode constant are recorded in PublicAPI.Shipped as ABI, so the §8.3 decompositions of FileRegistry (SharingPolicy) and FileConnector (OpenModeMachine, RecordArea; PB2335) each become a breaking change that bumps the runtime major for code no host can call.

**Measured how:** R2 batch finding `runtime-io-1--modern-csharp--f1#1` (pair runtime-io-1--modern-csharp), read in the pinned tree at 8be23006851a; skeptics rule upheld, scenario upheld, site refuted. Analyzer rule: `CA1062`.

**Target:** Before PB2097 records the public API, make the runtime's I/O plumbing internal: FileRegistry, FileStatusCode, FileCharacterSet and RunUnit.Files (the connector hierarchy is runtime-io-1--modern-csharp--f2#1's CA1051 target), and the connector-only members CobolFile.ResolveHostPath and CodeSetConversion's constructor, Represents, HighUnit, HasCharacterWithoutImage, ToNative and ToMedium (ChannelUnits stays public for the binder, which §8.1 lets read the runtime). Unit tests already have InternalsVisibleTo Cobol.Net.Tests.Unit. That retires 18 of the 21 hits without touching a body; the 3 emitted entries (ReleasedRecord, AssociationMade, FillTo) take ArgumentNullException.ThrowIfNull. PublicApiAnalyzers then keeps the public set equal to RuntimeMembers' declaring types plus the host API, so the next runtime type is internal by default.

**Design reference:** §8.3.
