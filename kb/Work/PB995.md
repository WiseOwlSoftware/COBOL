# PB995 — OPEN

## Repro — measured
`scratchpad/reg12/q08_sr11.cob`: `SD SF. 01 SR PIC X(5).` / `FD OF1 RECORD VARYING IN SIZE FROM 1 TO 2 CHARACTERS.` /
`SORT SF … USING IF1 GIVING OF1` → compiles clean, prints `COMPILED`.

## The rule
`OK  §14.9.40.3 11)` — "If the file description entry for file-name-3 describes fixed-length records, the file description
entry for file-name-1 shall not describe a record that is larger than the record described for file-name-3." The rule's
first sentence (variable-length file-name-3: file-name-1's records neither smaller than the smallest nor larger than
the largest) is the arm this probe breaks.

## What the fixer owes
One size-range screen in `SortBinder` over every GIVING file (and MERGE's GIVING, whose SR carries the same text — find
its number with `cite.py --find`), using the FD's record-size range the file model already computes. Negative goldens
for both sentences.
