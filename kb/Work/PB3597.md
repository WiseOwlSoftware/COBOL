# PB3597 - the record-struct lane cannot address the implicit filler gaps of a bit table or the tail of a class run

Two leads of the PB3564 finisher report share one root: in the RECORD-STRUCT lane the implicit filler is not yet an item INITIALIZE can
reach. PB3564 made the class lanes (EXTERNAL, BASED, REDEFINES views) reset it through `BitLayout.WindowFillersOf`; the record-struct
lane stores the pad as ONE hidden string and has no per-gap place.

## Lead 1 (PB3564 R2-2, low): a refusal of legal source

`INITIALIZE G WITH FILLER REPLACING BOOLEAN DATA BY B"1"` over the pad between the occurrences of an ALIGNED bit table in a
record-struct group aborts by name in `InitializeBinder.ExpandImplicitFillers`. The pad is one `__bf<k>` string holding n-1 gaps (a
string of '0'/'1' characters, not the packed backing the window coding reads) and no place addresses a single gap, so the REPLACING
sender cannot be applied to each gap as its own elementary bit item (GR 14.9.20.4 5) a) 2, each implicit filler is an elementary
item). Repro (G = `T PIC 1(3) USAGE BIT ALIGNED OCCURS 2` + `X PIC X`; the second INITIALIZE aborts):
`E:\Temp\claude\E--COBOL\8bd1c3d3-6c48-4db9-ada1-5e4edea40828\scratchpad\w1157\review-i-r2\repl.cob`.

## Lead 2 (low): silently wrong data

A record-struct group that holds the canonical of a Tier-B class (the BRD11 shape: `M2` canonical, `M2R REDEFINES M2`) has a run whose
tail is neither stored (`BitLayout.FillerPositions` marks the run `InClass`, so `FillersOf` omits it) nor windowed (the owner is not
itself in the class, so `WindowFillersOf` does not name it). `INITIALIZE G WITH FILLER` leaves the tail, where the rule resets every
implicit filler (8.5.1.6.3 "implicitly described as a filler elementary bit data item").

## Fix shape (for the implementer)

Make each gap of the pad, and the tail of a class-canonical run, an addressable filler item in the record-struct lane as the class lanes
already do (one enumeration, `FillerPositions`, behind the stored list and the window list), so the next filler shape lands in both.
Sweep the sibling readers of the pad (`GroupImageCodec` pad lines, `GroupValueSlicer`, `PhysicalModel`). Goldens: the REPLACING BOOLEAN
arm and the canonical/REDEFINES tail, 2002/2014/2023. Run each citation through `cite.py --check` first.
