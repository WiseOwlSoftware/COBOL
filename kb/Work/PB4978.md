# PB4978 - DEBUG-CONTENTS over-sizing

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/ProcedureTableBuilder.cs:827`, `RecordLayout.AllOccurrencesImageWidth`.

**Report (R1-2, low).** After PB4855, DEBUG-CONTENTS is sized to `AllOccurrencesImageWidth` of every data target, including items no whole-table reference can name:
an elementary item under a table that is no SORT key, and, at `--std 85`, anything but SEARCH identifier-1 (a table with INDEXED BY), which is the only whole-table reference there. The register, every fire `Fit`
and `DISPLAY DEBUG-ITEM` therefore grow by the table maximum for programs that never reference the item as a whole. Fix: size by the targets a whole-table reference can actually name, per edition; keep the width a function of the same predicate the reach walk uses so the two cannot drift.
