The compiler writes no listing in any edition (conformance entry DOC-A.1-117: "The compiler NEVER produces a source
listing, in any edition and under any option"). For 2002, 2014 and 2023 that conforms: each edition leaves the
listing implementor-defined (§2023:7.3.18.3 GR1 "Whether the compiler produces a source listing is
implementor-defined") and asks only that the choice be documented.

1985 does not leave it open:
- §1985:IV.7.1: "each compiler accepts source programs written in reference format and produces an output listing of
  the source program in reference format". kb/Work PB5754 already treats the "accepts" half of the same sentence as
  binding.
- §1985:I.1.5.2.2: "An implementation must accept the syntax and provide the function for all Standard COBOL language
  elements" of a level it claims. Two Nucleus elements have no function except in the listing:
  - the slant comment line (§1985:IV.7.2.4: "The slant in the indicator area causes page ejection prior to printing the
    comment line in the listing"), Nucleus levels 1 and 2;
  - the DATE-COMPILED paragraph (§1985:VI.3.4), Nucleus level 2, obsolete but still required (§1985:I.1.5.2.3).
- 1985 names no exemption: the listing is in neither the implementor-defined list (§1985:C.2) nor the
  hardware-dependent exemptions (§1985:C.3).

The counter-reading ("no listing, so nothing to violate") borrowed its premise from the 2023 annex item A.1-117 and never
weighed §1985:IV.7.1. It fails.

## What the fix must provide at --std 85 (the standard minimum)
Source lines in reference format; comment lines listed, '/' starting a new page; DATE-COMPILED's comment-entry replaced
by the date of compilation; each program identified by its program-name; one compilation timestamp shared with the
WHEN-COMPILED register. The listing is built to PB5925's design, which goes far beyond this minimum.

## Inventory consequences
- `1985-GR-VI.3.4.4-1` (DATE-COMPILED) is recorded CONFORMS through a derivation that leans on A.1-117: it becomes GAP.
- `1985-GR-VI.3.3.4-1` and `1985-GR-X.3.1.4-1` ("identifies ... all listings") become PARTIAL.
- §1985:IV.7.1, IV.7.2.4 and IV.7.4 have no rows at all (PB5924), so "1985 0 GAP" was computed without them.
- DOC-A.1-117's "in any edition" describes a nonconformance at --std 85 until this lands; the derivation behind
  `1989-RV-A.2.46.3-3` leans on the same item.
