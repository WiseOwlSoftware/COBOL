# PB5622 - a zero-length argument at run time to REVERSE or UPPER-CASE (and siblings) raises no EC-ARGUMENT-FUNCTION (2002 and 2023)

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/IntrinsicArgumentRules.cs` (`Verified` REVERSE, UPPER-CASE, LOWER-CASE rows: MinWidth only, the static half, unchanged)
- `src/WiseOwl.Cobol.Runtime/Intrinsics/CobolIntrinsics.Text.cs` (`CobolIntrinsics.Reverse`, `CobolIntrinsics.UpperCase`, `CobolIntrinsics.LowerCase`, `CobolIntrinsics.CaseArgumentZeroLength`: LANDED, the one run-time guard)
- `src/WiseOwl.Cobol.Runtime/Intrinsics/CobolLocale.cs` (`CobolLocale.UpperCase(string?, LocaleFacts?)`, `CobolLocale.LowerCase(string?, LocaleFacts?)`, `CobolLocale.FoldLower`: LANDED, the LOCALE and CHARACTER CLASSIFICATION carriers; the ANYCASE fold split off from the function entry)
- `src/WiseOwl.Cobol.Runtime/Intrinsics/CobolIntrinsics.Exact.cs` (the NUMVAL-C ANYCASE fold now reads `CobolLocale.FoldLower`)

**Mechanism.** The argument rule 'at least one character position' is screened only statically (IntrinsicArgumentRules MinWidth(1)); the runtime CobolIntrinsics.Reverse / UpperCase have no empty-argument arm (Ord has one), so a group whose only content is an OCCURS 0 TO n table at 0 occurrences passes and an empty string is returned.

**Inventory.** Rows claimed: `2002-AR-15.65.2-1`, `2002-AR-15.78.2-1`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:15.78.2 AR1`: "shall be at least one character position in length"
- `§2002:15.2`: "If the evaluation of an argument results in an incorrect value for that argument according"
- `§2002:13.16.36.3`: "the group data item is a zero-length item"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p2/p5_upper_zero_runtime_ecarg.cob); the text is inline. Command: `cobol.exe p2/p5_upper_zero_runtime_ecarg.cob --std 2002 --source-format free --run`

`p2/p5_upper_zero_runtime_ecarg.cob`:

```cobol
>>TURN EC-ARGUMENT-FUNCTION CHECKING ON
IDENTIFICATION DIVISION.
PROGRAM-ID. P5UZ.
DATA DIVISION.

   05 E PIC X OCCURS 0 TO 5 DEPENDING ON CNT.

PROCEDURE DIVISION.
    DISPLAY "LEN=" FUNCTION LENGTH(V)

    STOP RUN.
```

**Observed.** with >>TURN EC-ARGUMENT-FUNCTION CHECKING ON and CNT=0: prints LEN=000000000 and 'AFTER R1=      EXC=' (no exception), rc=0.

**Expected (from the 2002 text).** EC-ARGUMENT-FUNCTION set to exist (fatal).

**Sibling sweep.** LOWER-CASE and every other function whose argument rule asks a minimum length (DISPLAY-OF, NATIONAL-OF, ORD-MAX family), and ANY LENGTH zero-length arguments.

**Other editions.** 2023: yes (identical rule). 2014: yes presumably. 85: n/a (no exception model).
