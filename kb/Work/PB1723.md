# PB1723 — OPEN

Filed by the train-71 lander from wave 71 group E's report (`w71e-PB1720-report.md`, lead 1).

## Finding

Three places compute the repository's `<git common dir>` (the store shared by every worktree):
- `scripts/spec/impacted_tests.py` `default_store` (about line 91);
- `scripts/spec/record_impact_map.py` `default_store` (about line 74);
- `scripts/gate_slot.py` `slot_dir`.

They disagree: the first two do not `.resolve()` an absolute result, while `gate_slot.py` does, because
`git rev-parse --git-common-dir` can return an 8.3-style or forward-slash path on Windows. Two spellings of one
directory can make two tools disagree about whether they share a store.

**Repro.** `git rev-parse --git-common-dir` in a linked worktree on Windows; compare with `Path(...).resolve()`.

**Fix.** One shared helper that every caller imports (rule 4: delete the other two copies in the same change), with
a drift test that no script under `scripts/` calls `--git-common-dir` except through it.
