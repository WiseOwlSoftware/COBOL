# PB4351 - The built CLI apphost path is written by hand in each script: gnucobol_differential.py hard-codes cobol.exe, so on Linux the differential cannot run without --exe

**Sites:** `scripts/gnucobol_differential.py` (`main`), `scripts/differential_fuzz.py` (`main`), `scripts/battery.sh` (whole: the `--exe` argument at line 203 is outside any function), `scripts/guard-compiler.sh` (`guard_select_compiler`, `guard_compiler_self_test`), `scripts/linux-gate.sh` (`cli_fingerprint`), `scripts/version-continuity-sweep.sh` (whole: the `CLI=` assignment at line 24 is outside any function).

Found by the PB4332 finisher (lead 2), which wired the differential into the nightly. `scripts/gnucobol_differential.py#main` (line 295) declares `ap.add_argument('--exe', default='src/WiseOwl.Cobol.Cli/bin/Debug/net10.0/cobol.exe')`, the Windows apphost name, so on Linux (where the apphost is `cobol`) the differential cannot run without an explicit `--exe`; the nightly runs it on Windows only. `scripts/differential_fuzz.py#main` (line 2251, its `--cobol` default) spells the same path with its own `os.name == "nt"` test (`cobol.exe` or `cobol`). Two hand-written copies of one fact, one of them wrong off Windows.

Sibling sweep (`git grep -n "WiseOwl.Cobol.Cli/bin" scripts/` on main):
- `scripts/battery.sh:203` passes `--exe src/WiseOwl.Cobol.Cli/bin/Debug/net10.0/cobol.exe` to the differential: Windows name, hand-written.
- `scripts/guard-compiler.sh:36` (`guard_select_compiler`) sets `GUARD_CLI_BIN` to the directory only; lines 96 and 117 (`guard_compiler_self_test`) name `cobol.dll`, not the apphost.
- `scripts/linux-gate.sh:920` (`cli_fingerprint`) names the `bin` directory only, no file name.
- `scripts/version-continuity-sweep.sh:24` names `cobol.dll`, run through `dotnet`.

Fix direction (for the implementer): one place resolves the apphost per OS (no `.exe` on Linux) and every Python caller uses it, so `gnucobol_differential.py` and `differential_fuzz.py` stop spelling it; the shell scripts above are siblings to check (`battery.sh` passes the Windows name by hand; the others name the directory or the portable `cobol.dll`).
