# PB4016 — a quotation altered inside quote marks, and a doc comment claiming a pin that does not exist

**Sites:** `conformance-suite/cases/14.9.4-CALL/pb3996_call_format2_omitted.cob`, `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CallBinder.cs#OmittedSpelling`

**Failure 1, the quotation.** The golden's comment (lines 10-11) quotes 14.9.4.4 GR11 as "the omitted-argument condition for that
parameter evaluate to true in the called program". The standard reads "evaluates to true". Checked 2026-10-28:

```
$ python scripts/spec/cite.py --check 14.9.4.4 "the omitted-argument condition for that parameter evaluate to true in the called program"
FAIL: §14.9.4.4 exists but does NOT contain 'the omitted-argument condition for that parameter evaluate to true in the called program'
$ python scripts/spec/cite.py --check 14.9.4.4 "evaluates to true"
OK  §14.9.4.4 11)  (General rules)
```

The clause number is right; the quoted words are altered.

**Failure 2, the doc comment.** The comment on the Format 1 spelling check (`CallBinder.cs`, near line 877, above
`OmittedSpelling`) says `CallArgumentFormatDriftTests` pins every alternative of `callByValue`, but `Format1Prints` has no
`CallByValueContext` entry. Harmless (the whole BY VALUE phrase is refused) and the sentence is untrue.

**Fix.** Quote "evaluates to true" and run `cite.py --check` on the final text; drop the callByValue claim from the comment or
add the entry the claim needs (prefer whichever the drift test's design says; state it).

**Acceptance.** `cite.py --check 14.9.4.4 "<the golden's quotation>"` prints OK; the comment states only what the drift test pins.
