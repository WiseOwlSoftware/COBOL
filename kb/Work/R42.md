# R42

Asked 2026-09-24 as a bare question after cloud adjudication wave 1 (PB1522) returned 10 NEEDS-OWNER-DECISION rows,
9 of them A.1 items hanging off declined modules: screen handling (items 3, 4, 11, 27, 41, 45, 83, 91) and commit and
rollback (item 28). The adjudication brief forbids an agent choosing DOCUMENTED-NON-SUPPORT (D13) and no derived
selector reaches such a row. Owner, verbatim: **"yes, close them as documented non-support"**.

## The decision

An Annex A.1 item whose element exists only within a module that `docs/CONFORMANCE.md` §5 declares **Not claimed**
(today A.4.2 screen handling and A.4.3 commit and rollback; the same rule applies to any other declined module)
closes as **DOCUMENTED-NON-SUPPORT**. Licence — A.1's own preamble: "When the element is part of a feature that is
optional or processor-dependent, the item is not required if the optional or processor-dependent feature is not
implemented", plus §4.2.7 (identify the optional elements claimed). This is ground (a) of the verdict's `meaning` in
`tests/version-matrix/inventory-schema.json` — the item is WITHDRAWN, so §7 carries no row — exactly as items 84, 85,
86 and 173 were recorded. Each record's `notes` cite R42 and the §5 row; its witness is the existing test proving
the declined construct is diagnosed (e.g. the screen-section refusals COBOLNET1560 / COBOLNET1707, commit COBOLNET1709).

## Not covered

- **DOC-A.1-47** (FLOAT-DECIMAL default encoding) is NOT a declined-module item — it stays with PB579.
- An A.1 item that is merely unimplemented inside a CLAIMED module is not withdrawn — it stays DIVERGES /
  NOT-IMPLEMENTED.
- If a module later becomes claimed, its rows leave this ground and are re-adjudicated.
