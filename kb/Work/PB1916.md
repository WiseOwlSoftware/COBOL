# PB1916 — OPEN — a fix arm without its witness

Filed by the train-1003 lander from wave 1003 group C's report (`w1003c-PB1040-report.md`, lead 3).

## Finding

PB1040 made `CallEmitter.InvocationText` pass the site's checking state (`siteArgMismatchChecking`) on the
program-pointer AND the function-pointer arms (`src/Cobol.Net.Runtime/Control/ProgramTable.cs#CallPointer` and
`#CallFunctionPointer`), so §14.9.4.4 GR3 d)'s "enabled in both the activated program and activating runtime element"
gate holds for both. The program-pointer arm is pinned by
`tests/conformance/2002/pb1040_activation_mismatch_every_lane.cob`; the function-pointer arm shares the same emitted
`site` string but no test executes it.

## What the fixer owes

A 2023 golden that activates a FUNCTION-ID program through a FUNCTION-POINTER with a mismatched argument count and a
non-conforming RETURNING item under `>>TURN EC-PROGRAM-ARG-MISMATCH CHECKING ON`, asserting the exception, plus the
unchecked fit. Setup to copy: `tests/conformance/2023/pb452_function_address_runtime.cob`.
