# PB5678 - a frozen edited sender is edited a second time

**Site (lead, from the writer; the line read by the integrator):**
`src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/MoveBinder.cs#BindMoveOf`, where `targets.Count > 1` freezes the
sender through `host.SendingValue.Materialize(...)`. The temporary takes identifier-1's EDITED description, so the
move into it applies the insertion editing to characters that already hold it. With one receiver no temporary is
made and the result is right.

**Rule (checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:14.8.24.3 GR1`: "Literal-1 or the content of the data item referenced by identifier-1 is moved to the data
  item referenced by each identifier-2 in the order specified". The content moves to each receiver. The temporary that
  holds it is a copy of that content and does no editing.

**Repro** (`E:/COBOL-coord/scratch/gl2002/integrate-2/repro/g2mvd2.cob`, a copy of the writer's
`lane1/run/g2002-14-8-24-move-p2/gr1defect/g2mvd2.cob`; `cobol.exe g2mvd2.cob --std 2002 --run`):

```cobol
       01 SXE  PIC XBX  VALUE "A B".
       01 SXS  PIC X/X  VALUE "A/B".
       01 SNE  PIC NBN  VALUE N"C D".
       01 RX   PIC X(5).
       01 RX2  PIC X(5).
       01 RN   PIC N(5).
       01 RN2  PIC N(5).
       ...
           MOVE SXE TO RX. DISPLAY "1 [" RX "]".
           MOVE SXE TO RX RX2. DISPLAY "2 [" RX "][" RX2 "]".
           MOVE SXS TO RX RX2. DISPLAY "3 [" RX "][" RX2 "]".
           MOVE SNE TO RN RN2. DISPLAY "4 [" RN "][" RN2 "]".
```

- **Expected:** `1 [A B  ]`, `2 [A B  ][A B  ]`, `3 [A/B  ][A/B  ]`, `4 [C D  ][C D  ]`.
- **Observed** at --std 2002 and --std 2023, on a build of main 63ab0c4ece: `1 [A B  ]`, `2 [A    ][A    ]`,
  `3 [A//  ][A//  ]`, `4 [C    ][C    ]`, exit 0. At --std 85 the national lines are refused (COBOL0900, national is
  2002); the writer saw the alphanumeric lines wrong there too.

**Reach:** this is a wrong answer at the default edition. The 2023 row of the same rule (`GR-14.9.25.4-1`, §2023:14.9.25.4 GR1) is
recorded CONFORMS, and this repro contradicts it. The fix's landing re-probes that row. A sibling sweep belongs to the
fix: every other caller of `SendingValue.Materialize` whose sender can be edited (the implicit phrase moves that
`BindMoveOf` binds, among them CORRESPONDING, ACCEPT, CALL RETURNING).

**Blocks:** `2002-GR-14.8.24.3-1`, recorded DIVERGES naming this note.
