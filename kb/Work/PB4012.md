# PB4012 — `--permissive` must accept OMITTED in a Format 1 CALL (owner decision 2026-10-28)

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CallBinder.cs#OmittedSpelling` (VendorLane is `false` today), `docs/CONFORMANCE.md` (the rule-1 survey and the decision), `src/WiseOwl.Cobol.Editions/Diagnostics/DiagnosticCatalog.cs#CallContentOperandFormat` (COBOL0899 text names the lane)

**OWNER DECISION.** Asked whether `--permissive` should accept OMITTED in a Format 1 CALL, the repository owner answered on
2026-10-28, attended Mythos session: "Yes, permissive accepts". OMITTED in a Format 1 CALL is a vendor spelling carried by the
PB162 `--permissive` lane: STRICT refuses it with COBOL0899 (ISO §14.9.4.2: Format 1's USING prints `{ identifier-2 } ...` only,
OMITTED belongs to Format 2); PERMISSIVE accepts it and emits the vendor-extension notice.

**Harm flags (corrected 2026-10-28 by the Mythos session).** `rejects_legal_source: true`: the source is legal under the
`--permissive` contract the owner set (PB162's vendor lane), not under ISO, and that mode now refuses it. Not `process_only`:
a user's program that compiled is refused.

**Defect.** PB3996 (#743) made `CallBinder.OmittedSpelling` return `VendorLane: false`, so `cobol bare.cob --permissive` on
`CALL "OTHER" USING W OMITTED` now draws COBOL0899; on main before #743 it compiled and ran. The implementer followed PB3996's
premise ("OMITTED is not a vendor Format-1 spelling") and flagged the doubt.

**Evidence the premise is wrong.** The GnuCOBOL testsuite writes `CALL "X" USING OMITTED` with no prototype:
`tests/external/gnucobol/tests/testsuite.src/run_file.at:1217,1221,1323` and `run_misc.at:4415,5318,10463`. IBM Enterprise COBOL
accepts it (LE callable-service calls). The next battery's GnuCOBOL differential flips those callee programs to compile errors
under `--permissive`.

**Flags.** `rejects_legal_source` is false by the brief (a vendor spelling is not ISO source); `process_only: true` only because the register needs one harm flag for an open defect. The vendor-source impact is the permissive lane above.

**Fix.** Set the lane in `OmittedSpelling` (`VendorLane: true`) for the bare, BY REFERENCE and BY CONTENT forms, make the notice
name the spelling; do the rule-1 compiler survey the PB162 lane asks for (GnuCOBOL, IBM, Micro Focus: which OMITTED forms each
accepts in a non-prototype CALL) and record it and this decision in `docs/CONFORMANCE.md`. Strict stays refused.

**Acceptance.**
- `--std` default (strict): `CALL "P" USING W OMITTED` is COBOL0899, unchanged (PB3996's goldens stay green).
- `--permissive`: the same source compiles and runs, one vendor-extension warning naming OMITTED; a conformance case pins both.
- `docs/CONFORMANCE.md` carries the survey and the owner's words and date.
