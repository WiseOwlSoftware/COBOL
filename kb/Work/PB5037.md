# PB5037 - the compiler's default output directory is the source's directory

**Sites:** `src/WiseOwl.Cobol.Cli/Program.cs` (`Program`, the `-o`/`--output` option), `.gitignore` (whole: the cases directory's build output is ignored)

**Witness.** Twice a probe `cobol` compile run inside a worktree wrote its output beside the source. Attempt 000809
(worktree-wf_ae2552ba-c48-1) left `remarks-paragraph.dll`, `.g.cs`, `.runtimeconfig.json` and a copied
`WiseOwl.Cobol.Runtime.dll` in `conformance-suite/cases/11.2-Identification-division-structure/`; attempt 000603
(worktree-wf_ec0327b7-bfd-1) left the same in `conformance-suite/cases/11.9.8-FLOAT-BINARY`. The tree has no ignore rule
for `conformance-suite/cases/**/*.dll`, `*.g.cs` or `*.runtimeconfig.json`, so the landing refused the dirty tree with
exit 2. Like PB4682 (a stray file forcing a resume unit), a probe writes into a tracked directory and nothing stops it.

**Mechanism.** The default output directory is the source's directory, and a tracked source directory takes the build output.

**Owed.** Decide at the root: ignore the cases' build output (the tree's other build-output rules, PB3174, are the
pattern), or default the output to a scratch directory when the source lies under a tracked tree, or both. Add a drift
test that a compile of a `conformance-suite/cases` source leaves `git status` clean.
