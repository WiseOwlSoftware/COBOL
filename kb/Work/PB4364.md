# PB4364 - GeneratedCsPath is C#-named above the seam

**Sites:** `src/WiseOwl.Cobol.Compiler/CompilerDriver.cs` (`CompilerDriver.Result`, `GeneratedCsPath`, line 89 at the filing) and `src/WiseOwl.Cobol.Cli/Program.cs` (the member holding the `error: backend compilation failed (generated C# at ...)` text, line 313). `git grep -l GeneratedCsPath` lists the other callers (about 22 files).

Same root as PB4272 (landed on main via PR #956): the contract above the backend seam is C#-shaped. `Result.GeneratedCsPath` and the CLI message say the artifact is a C# file; a direct-IL (CIL) backend produces no `.g.cs`, so the name and the message are false for it.

Fix: rename to `GeneratedSourcePath` across every caller and delete the old name in the same change (no alias, CLAUDE.md rule 4), and make the CLI message backend-neutral ("generated source at ..."; omitted when the backend wrote none). One change set, tree-wide, so it lands alone.
