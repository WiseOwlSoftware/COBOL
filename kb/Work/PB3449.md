# PB3449 — two concurrent guard runs in one tree share `tests/nist/output`

> ⚙ **flags:** process-only · silent

Source: `E:\COBOL-coord\scratch\reports\w1131d-PB3383-report.md`, "New defects (note-ready)". Found by the PB3383 implementer (branch `worktree-wf_65e0b527-80e-4`, PR #311, open when this note was filed). Re-read on that branch's `scripts/guard-fast.sh`.

**Mechanism.** `scripts/guard-fast.sh` sets `OUT="tests/nist/output"` (line 112 on the PR #311 branch) and, at start, sweeps it with `rm -f "$OUT"/*.dll "$OUT"/*.runtimeconfig.json "$OUT"/*.txt "$OUT"/*.compile.log "$OUT"/*.compile.rc …` (line 121). The compiled programs and their print files then live there while the run goes on. A second guard run in the same tree (an implementer gate and a Linux gate on one checkout, or a hand run beside a gate) deletes the first run's artifacts mid-run or overwrites a same-named file, so the first run reads another run's output and scores a program MATCH, DIFF or NO-VERDICT on an observation that was not its own. The retired serial `scripts/guard.sh` carried a run-isolation snapshot of that directory; PR #311 deletes it and nothing replaced it. Each program already runs in its own `mktemp` directory (PB3334, PB3383), but the compile output and the sweep stay shared.

**Harm.** Process-only and silent: a mis-score (or a spurious red) under concurrent runs in one tree, with no diagnostic naming the collision. No ISO rule.

**Fix direction.** Give each guard run its own output directory (a `mktemp -d` under the run, removed on exit, or keyed by the run's pid) and sweep only that one; keep `tests/nist/output` out of the guard's writes entirely. Then a drift test or a `guard-verify.sh --self-test` witness that two overlapping runs in one tree do not touch each other's files. Sibling sweep: every other script that writes `tests/nist/output` (PB3271 and PB3199 name readers of that directory; the fix must not leave a reader depending on the shared path).

**Repro.** In one tree start `GUARD_TESTS="IX114A IX115A" bash scripts/guard-fast.sh` twice at once under Git Bash (not PowerShell's `bash`, which is WSL without dotnet) and compare the two verdicts against a serial run. Not re-run by the clerk (the scripts that would run it are on the unmerged PR #311 branch); the site is verified by reading.

**Sites:** `scripts/guard-fast.sh` (the `OUT=` assignment and the start-of-run `rm -f` sweep), and any reader of `tests/nist/output` the sibling sweep finds.
