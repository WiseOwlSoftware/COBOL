# PB4455 - REPO-4 and REPO-5 have no end-to-end witness

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/MetadataRepositoryProvider.cs:334` (`MetadataRepositoryProvider.Load`, the
`RepositoryReader.Read` failure arms and `ReportFileFault`'s default arm, REPO-4 COBOL5965),
`src/WiseOwl.Cobol.Compiler/Binding/MetadataRepositoryProvider.cs:297` (`MetadataRepositoryProvider.Answer`, the
`RepositoryRecordException` arm, REPO-5 COBOL5966),
`tests/WiseOwl.Cobol.Tests.Conformance/ExternalRepositoryResolutionTests.cs` (where the witnesses go).

**What is covered, and what is not.** Review R1-3 named REPO-4, -5, -7 and -12 and `OutputFileProtocol.Replace`'s abnormal
paths. Wave 20261836 added the end-to-end witnesses for REPO-7 (`AFunctionSpecifierTheGroupDoesNotAnswer_ReportsTheEntrysFault`,
over `MakeStale`, which rewrites the entry's recorded runtime major) and REPO-12
(`APreviousBuildAnotherRuntimeMajorCompiled_IsRepo12_AndIsOverwritten`), and `OutputFileProtocolTests` for the retry, the loud
failure and the no-temporary guarantees. REPO-4 (a malformed or oversized record or index: COBOL5965) and REPO-5 (a
description the codec cannot rebuild: COBOL5966) still have none. Each needs a fixture that damages ONE record of a
compiled library in a way the reader or the codec detects: the damage must be chosen from the record's attribute blobs
(`CobolSignatureAttributes.cs`, `RepositoryReader.Read`), which is a small design task of its own (a byte patch of the
runtime-version string was enough for REPO-7 and -12; a record needs an attribute-level rewrite).

**Also open: design 17.1's remaining slice-7 multi-unit cases** (`docs/rearchitecture/DESIGN-external-repository.md` 17.1):
REPO-13 across the repository for a program-visible word case in the case shape (the C# witness
`AShadowingRepositoryFunction_WarnsWhenReadable_AndIsQuietWhenNot` pins it today), the word reaching a later-compiled unit, the
pb1115 split, and an 85 program called through a 2023 prototype. They live in `conformance-suite/wiseowl/cases/`.

**Fix shape.** A patched-record helper beside `MakeStale` in `ExternalRepositoryResolutionTests` (or a shared fixture), one Fact
per outcome asserting the code and that no COBOL5962 (REPO-1) follows it; the multi-unit cases as `build` cases.

## Landed (wave 20261840, group B)

**Re-probe.** The tree had no REPO-4 or REPO-5 witness and none of the four slice-7 cases of design 17.1.

- **REPO-4, record and index** (`ExternalRepositoryResolutionTests.AnEntryWhoseRecordIsMalformed_IsRepo4`,
  `AnEntryWhoseIndexIsMalformed_IsRepo4`): a compiled library with ONE damage, made by a same-length byte patch of an
  attribute blob (`RenameNamedArgument` renames the mandatory `SignKind` argument; `BreakIndexRow` changes the separator of the
  `Units` row), compiled against by a caller; each asserts COBOL5965 naming the file and no COBOL5962.
- **REPO-5** (`AnEntryWhoseDescriptionTheCodecCannotRebuild_IsRepo5`): the reader accepts the record and the codec cannot rebuild it
  (`RedirectRedefinition` points a `REDEFINES` at a name no preceding sibling carries); COBOL5966, no COBOL5962, no COBOL5965; the undamaged
  entry compiles first, so the damage is the only difference.
- **Slice-7 cases** under `conformance-suite/wiseowl/cases/12.3.8-REPOSITORY/`: `pb2103_repo13_across_repository` (REPO-13 across the
  repository, program-visible word), `pb2103_function_word_in_repository` (the word reaching a later-compiled unit),
  `pb2103_prototype_group_split_across_units` (the pb1115 split, EC-PROGRAM-ARG-MISMATCH checking on in both units),
  `pb2103_program_of_85_through_prototype` (an 85 program called through a prototype) and the refusal
  `pb2103_prototype_refused_at_85` (COBOL0900 before any REPO-*). The 85 case needed a step to compile at its own edition, so the
  suite gained the build-step option `std` (`generate.py` `STEP_EDITION_OPTION`, `ConformanceSuiteRunner.WithWiseOwlOptions`, the README
  and `DESIGN-conformance-suite.md`): the next mixed-edition case is a metadata file, not code. The warnings a case cannot observe
  (COBOL2969 across the repository, no COBOL5969 for the split) are Facts in the same C# class.
- `RuntimeVersionSkew.Patch` is now the one byte patch of the recorded runtime version (UTF-8 attribute blobs, UTF-16 user strings),
  used by `MakeStale`, the Unit REPO-12 expansion test and `RunUnitTerminationTests` (PB4460's sibling sweep).
