# PB928 — OPEN — a note whose opening move cannot be made

Source: the `PB566` report, "New defects" item 2.

## The measurement

`kb/Work/PB509.md` names
`E:\Temp\claude\E--CobolSharp\a9d94900-…\scratchpad\repros\PB509\` and instructs the implementer that
"the implementer's opening move is to rerun them". **The directory does not exist.** Session scratchpads
are per-session and are collected; the note outlived its evidence.

## Why it is worth a note rather than a repair of one file

Every note written by an agent is written from a session scratchpad, and the register now holds 955 of
them. The question is not "fix PB509" — it is which notes have a load-bearing dependency on a path that no
longer resolves, and what the standing rule is.

**The measurement the fixer starts with** is mechanical: grep `kb/Work/*.md` for `E:\Temp` /
`scratchpad` path references, and for each, test whether the path exists. That gives the population and the
harm (a note whose repro is merely QUOTED in the note body is fine; a note that says "rerun them" is not).

**The standing rule the fix records**: a repro a note depends on is either (a) quoted IN FULL in the note
body — which is what registrar #6's and this pass's notes do — or (b) committed under `tests/` as a golden
or a fixture. A path into a temp directory is neither, and it reads as evidence right up until someone
tries to use it.
