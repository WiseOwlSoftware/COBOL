## Finding — evaluate-directive-p1 (under-rejects)

Format-1 and Format-2 WHEN operands are parsed and syntax-checked only when that WHEN is EVALUATED (parent emitting and no prior match), so every syntax rule on selection objects is enforced for the selected-or-tested prefix of the WHEN list only

**Rows:** SR-7.3.13.3-11, SR-7.3.13.3-12, SR-7.3.13.3-14, SR-7.3.13.3-15, SR-7.3.13.3-16

**Repro:**

```
>>EVALUATE 1 / >>WHEN 1 / DISPLAY "W1" / >>WHEN "A" / DISPLAY "WA" / >>END-EVALUATE -> compiles clean, prints W1 (category mismatch unreported). Likewise after a matching WHEN: `>>WHEN 2 THRU "Z"`, `>>WHEN 2 ** 3`, `>>WHEN B"1" B-AND 1` (boolean subject), and under >>EVALUATE TRUE `>>WHEN 1 = "A"` all compile clean; an alphanumeric subject with a later `>>WHEN 1 THRU 2` compiles clean. The same operands in the FIRST (evaluated) WHEN are COBOLNET1619.
```

**Expected from the spec:** §7.3.13.3 SR11 'All operands of one EVALUATE directive shall be of the same category'; SR12 'If the THROUGH phrase is specified, all selection subjects and selection objects shall be of category numeric'; SR14/SR15/SR16 formation per §7.3.6 / §7.3.7 / §7.3.8. Syntax rules hold for every WHEN phrase of the directive regardless of which branch §7.3.13.4 GR4/GR8 selects -> COBOLNET1619 for each offending WHEN.

**Observed:** Run.Render WHEN arm: `else if (!f.ParentActive || f.BranchTaken) f.Emitting = false;` short-circuits BEFORE EvaluateCceText / MatchWhen, and MatchWhen is where the fragment parse (EvaluateOperandText -> §7.3.6/7.3.7 checks) and the SR11/SR12 category checks live. Fix shape: always fragment-parse and category-check every WHEN operand of an EVALUATE whose parent is active (validation separated from selection), keeping only the emit decision gated on BranchTaken; whether directive syntax in an OMITTED parent branch must also be diagnosed is a separate question (probe: a malformed >>EVALUATE inside a false >>IF compiles clean) not claimed here.

**Code site:** src/Cobol.Net.Frontend/Preprocessor/ConditionalCompilationProcessor.cs#Run.Render (WHEN arm) and #MatchWhen
