## What this is

A Conformance run starts about 8,000 processes, one per compiled program. The diagnosis is `E:\COBOL-coord\scratch\gate-perf\findings.md`. On 2026-11-11 process creation on the dev box measured a median of 1.15 s, and later 2.0 s, against about 7 ms on a healthy machine. A Conformance host took over 70 minutes with its CPU idle.

The design is the sidecar file `PB5320/2026-11-11-design.md`. The controller's decisions on it are in `PB5320/2026-11-11-decisions.md`.

Stage 0 (one way to run a program, and a creation-time probe) is built after PB5230 lands. Stages 1 to 3, the runner that needs no process per case, wait for the owner's reboot and the APC PowerChute test.
