# PB4321 — C# method locals on model nodes (leak L8)

**Found:** by the PB4265 implementer (wave 20261790 group B, report
`E:\COBOL-coord\scratch\reports\w20261790b-PB4265-report.md`), recorded as the OPEN row L8 of
`docs/rearchitecture/DESIGN-backend-abstraction.md` §1.3; PB4265 itself named `PositionLocal` and `LocalVector` as the
C#-only names to move out of the model. Campaign PB2293 (owner 2026-10-31: eliminate the backend seam leaks asap).

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Model/Position.cs:157` (`PositionLocal`, `LocalVector`);
`src/WiseOwl.Cobol.Compiler/Binding/Bound/BoundTree.cs:264` (`BoundReportVaryingRef`);
`src/WiseOwl.Cobol.Compiler/Binding/DataBinder.Reports.cs:527` (`ReportVaryingModel.CsName`);
the same mechanism under other names, found by kb/Work PB4266's backend-contract walk:
`src/WiseOwl.Cobol.Compiler/Binding/Bound/BoundCorresponding.cs:23` (`CorrespondingHoist.Local`),
`src/WiseOwl.Cobol.Compiler/Binding/Bound/BoundInitialize.cs:67` (`InitializeLoop.Var`),
`src/WiseOwl.Cobol.Compiler/Binding/Bound/BoundTree.cs:1333` (`TableElementMove.Var`). Each is an L8 leak row of
`tests/WiseOwl.Cobol.Tests.Unit/Architecture/BackendContract.cs` (`BackendContract.Table`); the landing that removes one deletes its row.

**What leaks.** These strings name C# method locals (`__kv{Uid}` and the position temporaries), not CLR members: no
other module binds to them, so they are no ABI, and a CIL backend has no use for a local's name (it allocates a slot).
A target-naming decision for a local is frozen into the neutral tree.

**Fix direction.** A neutral local identity on the node (the owning model object, or a small `LocalId` value), named
by each backend when it renders; the Roslyn backend keeps today's spellings so the generated C# does not change (the
§4 oracle proves it). PB4266's §6 assertion 2 flags exactly these fields, so this note shrinks its allow-list.

## Landed (wave 20261800 E)

**Re-probe (base 2e48863d5).** The names were formatted by the binders and frozen into the tree, as found:
`IntrinsicBinder` built `new LocalVector($"__all{_allSerial++}")`, `SendingValueTemp` `$"__hold{table.Uid}"`, and
`ReportVaryingModel.CsName` was `$"__kv{Uid}"`. The sweep found four siblings of the same mechanism, each a binder-made
C# local name on a bound node: `InitializeLoop.Var` (`__iniN`, five sites in `InitializeBinder`),
`TableElementMove.Var` (`__vlmN`, `MoveBinder.ElementMove`), `CorrespondingHoist.Local` (`__corrNs`/`__corrNt`) and
the CORRESPONDING anchor's member paths, whose root was a `RootFieldSegment` holding the anchor local's name.

**Fix.** A local is referenced by its identity: `MethodLocal` (`Binding/Model/MethodLocal.cs`), whose binder kind is
`StatementLocal(StatementLocalRole Role, int Ordinal)`, the declaring construct and an ordinal (the design's
"neutral local IDENTITY"). `PositionLocal`, `LocalVector`, `InitializeLoop`, `TableElementMove`, `CorrespondingHoist`
and `BoundReportVaryingRef` carry it, and a CORRESPONDING anchor's member path starts at the new `LocalRootSegment`.
The Roslyn backend spells every local in ONE function, `LocalNames.Of` (`CodeGen/Roslyn/LocalNames.cs`), with
today's stems, so the generated C# is unchanged; the backend's own locals (a hoisted identification, a leaf loop
counter, a sort index) are `CSharpLocal`s it makes itself. The ordinals are the binders' existing serials.

**Witness.** `MethodLocalIdentityDriftTests` (a drift rule over `Binding/`): no `WiseOwl.Cobol.Binding` type has a local-named
`string` property, no binder source spells a role's stem, and every role has a distinct spelling; the first two were
seen to fail on a planted offender. The §6 backend-contract test (kb/Work PB4266, which landed while this branch
waited) tolerated the six members as its L8 leak row in `BackendContract.Table`; the merge with main deletes that row,
since the test refuses a row whose member is gone, so the contract test now holds no L8 member. The §4 oracle (`scripts/arch/compare_oracle.py --base 2e48863d5`) compares the
emitted C# and the diagnostics of the whole enrolled population.
