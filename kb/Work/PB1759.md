# PB1759 — HIGH-VALUE U+FFFF and the typed medium codec (owner R51 / R52)

Design: `docs/COBOLNET_FILES_DESIGN.md` D29. Absorbs kb/Work PB1093 (its rows GR-12.3.7.4-8, GR-12.3.7.4-10,
GR-12.4.5.7.4-1, GR-8.3.3.6.4-6 close when this lands — write `closes_rows` on PB1093 in the landing commit).

## Sequence (each step gated; nothing lands half)

1. **Split the codec's two images.** `GroupImageCodec` emits `AsImage()` / `FromImage()` for two jobs: the IN-MEMORY
   group image (group MOVE, group comparison, DISPLAY, CALL windows — text semantics, must stay lossless) and the FILE
   image. Add `AsMedium()` / `FromMedium()` per record struct: per-leaf kinds — alphanumeric / edited (and groups of
   them): U+FFFF <-> byte 0xFF; numeric byte forms unchanged; national UTF-16BE pairs unchanged; anything else above
   U+00FF stays R47's refusal. File emitters (WRITE, REWRITE, READ, RELEASE/RETURN, START, DELETE key images) use the
   medium image; nothing else does.
2. **Change the HIGH-VALUE answer** at every site R52 lists (`CollatingModel.Extremes` and `.HighValue`,
   `DataBinder.NativeHighValue`, `FigurativeConstants` 'H', `AlphanumericCollation` defaults, the file collating
   FINGERPRINT in `FixedFileAttributes`, `InitialStateBackground`, `ValueInitializer`, `LiteralEnvironment`) — ONE
   member every site reads.
3. **Goldens:** a record file round trip of `MOVE HIGH-VALUES TO REC` / WRITE / READ / `IF REC = HIGH-VALUES`; a
   REDEFINES numeric view over the same bytes (0xFF read as a number); the ALPHABET-with-HIGH-VALUE case PB1093
   measured (`ALPHABET AL IS HIGH-VALUE "B" "A"` — X"FF" must no longer sort first, U+0100 must compare below
   HIGH-VALUE); `ORD(HIGH-VALUE)` = 65536.
4. **Docs in the same change:** DOC-A.1-31 (the accepted `ÿ` cost), DOC-A.1-183/-188, D29, COBOLNET_DESIGN §14.9 /
   §18 #14 ("flagged divergence" paragraphs), PHASE4_RECONCILIATION.

## Revisit before starting (unresolved facts to measure first)

- Enumerate every consumer of the in-memory image versus the file image (47 files reference AsImage/FromImage) and
  classify each — the split is only safe if no memory-image consumer reaches a connector and vice versa.
- Indexed / relative KEY images and the sort store compare record images: HIGH-VALUE keys must compare as the
  collation says on BOTH sides of the medium (in memory U+FFFF, on disk 0xFF).
- Line sequential files: HIGH-VALUE in a text line stays refused ('71', item 115) — confirm with PB1760.
