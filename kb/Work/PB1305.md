## Measured

### Finding varying-clause — ISO §13.18.64.2; §13.18.64.4 GR3, GR5 (crashes; rows FMT-13.18.64.2, GR-13.18.64.4-3, GR-13.18.64.4-5)

**Mechanism.** F1 - ReportWriterEmitter.VaryValue renders a VARYING FROM/BY arithmetic expression through NumericRenderer.Align(..., 0) and assigns it to a C# `long` local; any expression containing an operator (the renderer widens to Int128) or an operand with nonzero scale produces uncompilable C# (CS0266 Int128 -> long).

**Repro.** RD R-V ... 01 DET-A TYPE DE. 02 LINE PLUS 1. 03 COLUMNS 1 3 5 PIC 9 VARYING K FROM 2 * 3 - 5 BY 4 - 2 SOURCE K.  GENERATE DET-A. (probe out13/probe/varying-clause/vint; also vexpr `FROM 7 / 2`, vscl `BY WS-F` PIC 9V9 VALUE 2.0)

**Expected, from the standard.** §13.18.64.2 admits arithmetic-expression-1/-2; §13.18.64.4 GR3 a)/b): counter = 1, 3, 5 -> line `1 3 5`. For a noninteger value (FROM 7 / 2) GR5 sets EC-REPORT-VARYING and the GENERATE is unsuccessful - never a compile failure.

**Observed.** error: backend compilation failed ... (66,25): error CS0266: Cannot implicitly convert type 'System.Int128' to 'long' ; generated `long __rv2_0 = ((Int128)(((Int128)(2L) * (3L))) - (5L));`

**Code site.** src/Cobol.Net.Compiler/CodeGen/Verbs/ReportWriterEmitter.cs#VaryValue (line ~209) and the `long {VaryName}` locals in EmitFieldPlacements (lines ~131-134)

### Finding varying-clause — ISO §13.18.64.4 GR5 (silent; rows GR-13.18.64.4-5)

**Mechanism.** F5 - EC-REPORT-VARYING has no raise site: VaryValue truncates a noninteger FROM/BY to scale 0 and the INITIATE/GENERATE/TERMINATE proceeds normally (currently masked by F1, which crashes first).

**Repro.** >>TURN EC-REPORT-VARYING CHECKING ON; WS-F PIC 9V9 VALUE 1.5; 03 COLUMNS 1 3 5 PIC 9 VARYING K FROM WS-F SOURCE K.; DECLARATIVES USE AFTER EXCEPTION CONDITION EC-REPORT-VARYING DISPLAY. (probe vgr5)

**Expected, from the standard.** GR5: the EC-REPORT-VARYING exception condition is set to exist, the GENERATE is unsuccessful, the print line content is undefined; with checking enabled the declarative runs.

**Observed.** grep of src finds no raise of EC-REPORT-VARYING (only the two 'seam' comments in ReportWriterEmitter); the emitted value is Align(..., 0) truncation; at present the program fails to compile (F1).

**Code site.** src/Cobol.Net.Compiler/CodeGen/Verbs/ReportWriterEmitter.cs#VaryValue / EmitFieldPlacements
