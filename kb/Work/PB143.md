# PB143

Rows: GR5 [delete-statement-p2] (DIVERGES). ARCHITECTURAL — the fix is a shared per-physical-file record store (PhysicalFileTable.State currently holds only Open + RecordLocks, no images), not a per-verb patch: DELETE/WRITE/REWRITE visibility across connectors, and last-close-wins clobbering, all fall out of the same design decision. Scope it as its own design wave (touches Relative/Indexed Load/Persist, sharing modes §9.1.15, record locks §9.1.16); the DELETE GR5 row stays DIVERGES until it lands. DeleteShared also never consults LocksEffective (unlike its Rewrite/Write siblings) — fold that arm in.
