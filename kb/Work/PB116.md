# PB116

Inventory: RV-15.84.4-1, RV-15.84.4-2 (both DIVERGES). §15.4.1's implementor-defined licence explicitly
yields to an 'otherwise specified' function definition, and §15.84.4 r2 is one. Under ARITHMETIC IS
STANDARD-DECIMAL, SQRT(0.1) roots the double 0.1000000000000000055511… — every returned digit past ~16 is
noise where the rule fixes 34. Fix direction: a decimal128 square root in the RenderDec lane (Newton over
CobolDec, seeded from Math.Sqrt — converges in ~2 iterations) with the exact argument entering unrounded;
the native lane keeps binary64 (r4's approximation licence covers it). Related: [[PB115]].
