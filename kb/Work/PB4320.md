# PB4320 — C# access text built in the binder (leak L7)

**Found:** by the PB4265 implementer (wave 20261790 group B, branch worktree-wf_d934ffd7-6da-2, report
`E:\COBOL-coord\scratch\reports\w20261790b-PB4265-report.md`), which recorded it as the OPEN row L7 of
`docs/rearchitecture/DESIGN-backend-abstraction.md` §1.3. Campaign PB2293 (owner 2026-10-31: eliminate the backend
seam leaks asap); it shares the root of PB2293's leak L1.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.Linkage.cs` (`CallBindLinkage`, `GlobalBridgesOf`);
`src/WiseOwl.Cobol.Compiler/Binding/DataBinder.Oo.cs` (`OoBindMethodData`);
`src/WiseOwl.Cobol.Compiler/Binding/Model/AccessPath.cs` (`Reroot`);
`src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/SortBinder.cs:992` (`SortMemberPath`);
`src/WiseOwl.Cobol.Compiler/Binding/Model/BoundUnit.cs` (`AnchorOf`, `ClassRef`, `CallBridge`);
`src/WiseOwl.Cobol.Compiler/Binding/Model/AccessPath.cs:56` (`MemberSegment`).
`MemberSegment.CsMember` also holds a runtime member's name (the cell's `Ref`, written by `PlaceCursor`). Each of
these members is an L7 leak row of `tests/WiseOwl.Cobol.Tests.Unit/Architecture/BackendContract.cs` (`BackendContract.Table`;
kb/Work PB4266); the landing that removes one deletes its row, and the contract test refuses a stale row.

**What leaks.** PB4265 made the model's names CLR names, allocated once for both backends. Four binder sites then
compose C# member-access TEXT from them: a carrier-resident formal's `DataItem.ClrName` is overwritten with
`__lnk{Uid}.Value` (`CallBindLinkage`, `OoBindMethodData`); `AccessPath.Reroot` joins `__outer.` onto
`RootFieldSegment.CsField`; `GlobalBridgesOf` builds `anchorOf(x)+x` paths; `SortMemberPath` joins names with `.`. A
string like `__lnk7.Value` is a C# expression, not a name, so it breaks DESIGN-backend-abstraction §1.2's refusal of
C# fragments, and a CIL backend would have to parse it back.

**Fix direction.** The model states the access structurally (the carrier, the member, the outer instance as
`AccessPath` segments or a dedicated place kind); each backend renders it. `DataItem.ClrName` stays the item's CLR
name and is never overwritten with an expression. PB4266's contract test should refuse a `.` or `__outer` inside a
name-typed model string once this lands.

## Landing (wave 20261800 group D)

**For the next implementer.**
- `Binding/ReferenceResolver.cs#AddRoot` — the ONE root of every access path; a new root shape (another carrier kind)
  goes here, never into a name.
- `Binding/Model/AccessPath.cs#ContainerAnchor` / `#CarrierValueSegment` — the structure; the trap: `RootFieldSegment`
  equality now includes `Anchor`, so compare anchors when comparing roots (`PlaceIdentification.FreezeView`).
- `CodeGen/Roslyn/PlaceRenderer.cs#Anchored` / `#RootStorage` — the ONE spelling of an anchored member; reuse it for
  any new contained-program access (bridges, status places, hoists).
- `Binding/DataBinder.Linkage.cs#GlobalBridgeMembersOf` — the one unanchored bridge list; `InheritedMemberNamesOf`
  reads it. A carrier-resident formal reserves no name of its own (its member is the carrier).
- `Binding/Model/BoundUnit.cs#AnchorOf` — the one static-vs-instance decision; it must not call into `CodeGen`
  (`architecture-edges.json` no longer tolerates `Binding.Model → CodeGen`).
- Proof of neutrality is cheap: `python scripts/arch/compare_oracle.py <base manifest>` (about 1 minute here).

**Re-probe (base 2e48863d5).** The four sites stood as the note says: `DataBinder.CallBindLinkage` and
`DataBinder.OoBindMethodData` assigned `item.ClrName = carrier + ".Value"`, `AccessPath.Reroot` set
`CsField = prefixOf(root.CsField) + root.CsField`, `GlobalBridgesOf` built every `CallBridge.Path` as
`anchorOf(x) + x`, and `SortBinder.SortMemberPath` returned `string.Join(".", segs)`. The new witness, run with the
first leak put back, failed for the right reason: `A DataItem.ClrName holds access text, not a name: L-X:
'__lnk4.Value'`. The sweep found a fifth site of the same shape on the model: `BoundUnit.ClassRef` joined the nested
class names with `.` for the emitter's factory text.

**Fix.** The model states each access as structure, and the Roslyn backend spells it.
- A carrier-resident formal keeps its CLR name and carries its carrier as a fact, `DataItem.ResidentCarrier`; the one
  root builder, `ReferenceResolver.AddRoot`, roots the path at the carrier and adds a `CarrierValueSegment` (ISO
  §14.2.3 GR8). The *-ARG-OMITTED guard's carrier pass-through is a flag, `OmittedFormalGuard.PassesCarrier`; it was
  a prefix that `PlaceRenderer.GuardedRoot` searched for inside the joined root text.
- A root segment of a containing program's member carries a `ContainerAnchor` (`Instance(depth)` or
  `Static(classClrName)`), decided by `BoundUnit.AnchorOf` (ISO §13.18.27.4 GR2, §13.5.4 GR1); `AccessPath.Reroot`
  sets it, and `PlaceRenderer.RootStorage` and `PlaceRenderer.Anchored` spell it. `ProgramEmitter.PrefixPlace` is
  renamed `AnchorPlace`.
- `CallBridge` carries `Field` and `Anchor` (no joined `Path`); `GlobalBridgesOf` anchors the members of
  `GlobalBridgeMembersOf`, which `InheritedMemberNamesOf` reads too, so the two cannot list different members.
- `BoundTableSortKey.MemberChain` is the items from the element down to the key (an empty chain is the element
  itself, ISO §14.9.40.4 GR23); `SortEmitter` spells the access.
- `BoundUnit.ClassRef` is deleted; `ProgramEmitter.ClassRef` forms the nested-class reference.

**The backend-contract test (merged from main, kb/Work PB4266).** PB4266 landed while this branch waited and
tolerated seven members as this note's L7 leak row of `BackendContract.Table`. The fix above deleted four of them
(`CallBridge.Path`, `BoundTableSortKey.MemberPath`, `BoundUnit.ClassRef`, the text-returning `BoundUnit.AnchorOf`) and
the L9 row's `OmittedFormalGuard.CarrierPrefix`, and the conflict finisher answered the other three:
- `CallBridge.Field` held only the bridged member's CLR name, so it is `CallBridge.MemberClrName`, neutral by
  construction (§2.4), and so is the binder's `GlobalBridgeMember.MemberClrName` that feeds it.
- `MemberSegment.CsMember` also held a runtime member's name, the cell's `StorageCell.Ref`; that step is now the
  structural `CellBackingSegment` (built by `PlaceCursor`, `ReferenceResolver.WindowScopeOf` and
  `PlaceIdentification.FreezeView`, spelled by `PlaceRenderer.RenderPath`), so the member is `MemberSegment.MemberClrName`.
  `RenderPath`'s default arm, which silently dropped a segment it had no arm for, now throws.
- `RootFieldSegment.CsField` still names three C# method locals, and `DataItem.ResidentCarrier` one of them: §1.3 L8's
  residue, kb/Work PB4380, which holds them as the table's one L8 leak row. The table has no L7 row.
The emitted C# is unchanged (`scripts/arch/compare_oracle.py --base` main at the merge).

**Behavior neutrality.** `scripts/arch/compare_oracle.py` against the base capture: IDENTICAL, 15712 cases (emitted C#
and diagnostics).
