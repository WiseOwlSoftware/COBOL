# PB161

Found by PB132's positive golden (`2023/pb132_bit_byref_aligned`): passing a fixed-OCCURS bit element
BY REFERENCE registers its group whole-group-referenced, the record's AsImage/FromImage pair is demanded,
and the generated C# failed to compile — `CobolBits.Pack(BT, 24)` handed the raw `string[]` field to a
`string` parameter (CS1503) and `BT = CobolBits.Slice(__bits0, 0, 24)` assigned a `string` to the array
(CS0029). Legal source (§13.18.60.4 GR5 bit items under OCCURS are unrestricted) rejected at the BACKEND
stage — a compiler crash surface, not a diagnostic.

**The sixth instance of the two-arm-dispatch shape** ([[feedback_two_arm_dispatch]]): `EmitBitMethods`'
AsBits/FromBits face had learned OCCURS (a local `Carrier` lambda + an inline `for (__i)` loop) while its
siblings — `AsImageOf`'s run packer riding `BitCarrierOf`, and `EmitMemberFromImage`'s run distributor —
never did. The same law was written three times and upgraded once.

**The fix is the extraction:** `BitCarrierOf` is now THE one carrier law (leaf · group `AsBits()` ·
fixed-OCCURS concat of every occurrence's carrier) and `EmitRunMemberFromBits` THE one slice distributor
(group `FromBits` · OCCURS loop · scalar), with both faces riding them. Verified end-to-end by the golden:
`B8=01011110 / BT2=01011110` — the callee's store through the reference formal visible in both the plain
and the subscripted element.
