# PB4949 - an analysis must declare a harm flag or process_only, as a defect must

**Sites:** `scripts/spec/work.py` (`register_problems`, `HARM_CHECKED_KINDS`, `unflagged_kind_findings`, `self_test`)

**What was wrong.** `work.py next` ranks a note only by its harm flags. `register_problems` refused an open DEFECT that set
no harm flag and not `process_only`, because such a note "can never appear in `work.py next`", but it tested
`kind == "defect"`, so an analysis in the same state passed. On 2026-11-07, 37 open analyses set neither and were never
ranked.

**The audit** (four read-only adjudicators, one batch each, evidence in E:/COBOL-coord/scratch/analyses-audit/A.md to D.md
with probes; the 2026-11-03 build where a probe was cheap, the code at main otherwise):

| Outcome | Notes |
|---|---|
| hidden defect, flag set on the analysis | PB4115 wrong answer, PB4623 wrong answer (code read), PB4641 wrong answer, PB4765 under-rejects, PB4119 misleading diagnostic |
| hidden defect, filed as its own defect | PB4946 (from PB3629) wrong answer, PB4947 (from PB4154) under-rejects, PB4948 (from PB4248) under-rejects |
| suspected, unprobed, flagged so the fix lane probes it | PB3631 wrong answer |
| stale or determined, retired | PB4123 (PB4709), PB4417 (PB4826), PB4618 (GnuCOBOL agrees, the position is open), PB4628 (1985 reserves LAST) |
| no user-visible harm, `process_only: true` with the reason | the other 24, plus PB3629, PB4154 and PB4248 whose harm moved to the new defects |

Each note carries its verdict in an "Audit 2026-11-07" paragraph. PB4232 (44 s to refuse one illegal 5,410-line file) is
recorded as no harm; it becomes `crashes` only if the owner counts that as a hang.

**The fix.** `HARM_CHECKED_KINDS = ("defect", "analysis")`: `register_problems` refuses an open or half note of either kind
that sets no harm flag and not `process_only`, so a newly filed analysis states one or the other the day it is filed.
A decision, adjudication or upstream record is not held to it. `unflagged_kind_findings` is the self-test: an unflagged
defect and analysis are refused, a flagged or process-only analysis and an unflagged decision are not.
