# PB5604 - at --std 2002 a USAGE POINTER or PROGRAM-POINTER record under an output CD is refused COBOL0899 'not yet implemented'

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/Passes/ClassifyRedefinesClassesPass.cs#Run` (implicit-area arm, ImplicitRecordAreaShape)
- `src/WiseOwl.Cobol.Compiler/Binding/CommunicationSectionBinder.cs` (whole: the reader pinned no member; the fixer names it) (record.SetRedefinition(anchor, ImplicitCommunicationRecord), ~line 168)

**Mechanism.** The records after a CD entry are linked into one implicit redefinition class (RedefinitionKind.ImplicitCommunicationRecord). PB981 gave FD/SD pointer, dynamic-length and variable-length records the out-of-line path (FileModel.IsOutOfLineRecord), so they never reach a class; the CD record area was left on the class path, where a pointer record is tiered Rejected and staged COBOL0899.

**Inventory.** Rows claimed: `2002-SR-14.8.28.2-3`, `2002-SR-14.8.3.2-3`, `2002-SR-14.8.35.2-17`, `2002-SR-14.8.35.2-20`, `2002-SR-14.8.35.2-26`, `2002-SR-14.8.35.2-27`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:A.1.2.2 SR9`: "Record description entries subordinate to an output CD entry implicitly redefine the record"
- `§2002:13.16.58.2 SR13`: "may be specified only for an elementary data item with level 1"
- `§2002:14.8.3.2 SR3`: "Data-name-2 shall reference a data item of category data-pointer"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p/cdptr.cob); the text is inline. Command: `cobol.exe p/cdptr.cob --std 2002 --run`

`p/cdptr.cob`:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. CDPTR.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 BUF PIC X(4) VALUE "WXYZ".
       01 BX BASED.
          05 BXC PIC X(4).
       COMMUNICATION SECTION.
       CD COUT FOR OUTPUT.
       01 CP USAGE POINTER.
       PROCEDURE DIVISION.
       MAIN.
           SET CP TO ADDRESS OF BUF
           SET ADDRESS OF BX TO CP
           DISPLAY "BX=" BXC
           STOP RUN.
```

**Observed.** warning COBOL0903 (communication facility obsolete), then error COBOL0899 (9,8): the record area of 'CP' is shared ... (ISO/IEC 1989:2002 A.1.2.2) ... a shared record area of that shape is recognized but not yet implemented; rc=65. The same record under an FD compiles and runs (reader's fdptr.cob).

**Expected (from the 2002 text).** compiles: output-CD records are ordinary record description entries that implicitly redefine the record area, and USAGE POINTER asks only for level 1.

**Sibling sweep.** every other shape PB981 moved out of line for FD/SD (object reference, dynamic-length, variable-length group) under a CD; input-CD records.

**Other editions.** 85: no (no POINTER usage). 2014, 2023: n/a (no communication section).
