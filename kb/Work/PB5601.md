# PB5601 - at --std 2002 a DEFINE directive whose operand is a boolean expression is accepted

**Sites:**
- `src/WiseOwl.Cobol` .Frontend/Preprocessor/ConditionalCompilationProcessor.cs#EvaluateOperandText (DEFINE operand path)

**Mechanism.** The DEFINE operand is parsed as the 2023 compile-time operand (arithmetic | boolean expression | literal | PARAMETER). The boolean-operator gate (GateBooleanOperators) asks only when B-OR etc. were introduced (2002), not whether the DEFINE format admits a boolean expression; 2002 7.2.9.1 admits arithmetic-expression-1, literal-1 or PARAMETER.

**Inventory.** No inventory row is claimed (`inventory_rows` is empty). no slice row; the reach is the 2002 DEFINE general format (7.2.9.1). The suite case conformance-suite/cases/7.3.11-DEFINE/pb1367_define_general_format_alternatives.cob carries accept [2002] for this form, so its band is wrong too.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:7.2.6`: "A compile-time boolean expression may be specified in the EVALUATE directive and in a constant conditional expression"
- `§2002:7.2.9`: "The DEFINE directive specifies a symbolic name, called a compilation variable, for a particular literal value"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p/b_def_bool.cob); the text is inline. Command: `cobol.exe p/b_def_bool.cob --std 2002 --run`

`p/b_def_bool.cob`:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. BDEFBOOL.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 X PIC 9 VALUE 0.
       PROCEDURE DIVISION.
       >>DEFINE V AS B"1100" B-OR B"0011"
       >>IF V = B"1111"
           DISPLAY "DEFINE-BOOL-EXPR"
       >>END-IF
           STOP RUN.
```

**Observed.** >>DEFINE V AS B"1100" B-OR B"0011": compiles, prints DEFINE-BOOL-EXPR, rc=0.

**Expected (from the 2002 text).** refused: a compile-time boolean expression is admitted only in EVALUATE and a constant conditional expression.

**Sibling sweep.** other directive operand positions the 2023 grammar widened (SET, IF/EVALUATE subjects) read at 2002.

**Other editions.** 85: no (no directives). 2014: unknown (check the 2014 DEFINE format).
