# PB5519 - the PB5420 negative conformance-suite case pins only `PADDING CHARACTER IS SYM1`: the `ALL SYM1` arm with a national symbolic-character is untested

**Sites:** `conformance-suite/cases/_unassigned/pb5420-padding-national-symbolic.cob` (whole: the case file the fix adds a sibling to), `src/WiseOwl.Cobol.Compiler/Binding/FileControlBinder.Padding.cs#OneCharacter` (the arm the new case exercises; read, not changed)

**Mechanism.** The kb/Work PB5420 negative `conformance-suite/cases/_unassigned/pb5420-padding-national-symbolic.cob` pins only the bare form `PADDING CHARACTER IS SYM1`. The `ALL SYM1` arm (the `FoldAllLiteral` / `SymbolicCharacter` path in `OneCharacter`, `FileControlBinder.Padding.cs`) with a national symbolic-character has no golden, so a change that treats `ALL sym` differently from `sym` for a national symbol goes unseen. Fix: add the `ALL SYM1` negative beside it, its diagnostic derived from the spec by the implementer.

**Also (a slip in the PB5420 note, not edited here).** `kb/Work/PB5420.md` lists the site `FileControlBinder.Padding.cs#SymbolicCharacter` twice in its Sites block (lines ~33 and ~35). It is for PB5420's owner to correct.
