# PB5115 - at --std 85 BLOCK CONTAINS 2 TO 2 RECORDS is refused (COBOL2009, the 2023 rule that integer-2 be greater than integer-1); the 1985 clause has no such syntax rule

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/FileControlBinder.FileSection.cs#BindBlockContainsClause` (the check kb/Work PB1217 added, reporting COBOL2009 at every edition; it does not look at the file organization)

**Mechanism.** BindBlockContainsClause applies §2023:13.18.10.3 SR1 (integer-2 greater than integer-1) at every edition. The 1985 BLOCK CONTAINS clause (§1985:VII.3.3) has no syntax rules; its only words about the two integers are that they are the minimum and maximum physical record size, so equal bounds conform and the program must translate. kb/Work PB1217 (landed 2026-10-04) added the check at every edition on the authority of the 2023 rule alone and is the cause, not a record of this defect. Inverted bounds (3 TO 2) are refused the same way; the record rests the witness on equal bounds only.

**Found by.** The 1985 witness-drafting pass (kb/Work PB4995 item 3): each rule below is a witness program drafted from the 1985 text alone, run at `--std 85`, and its result differs from what the text requires (outcome MISMATCH). Harm and observed text are the record's; nothing here was re-derived.

**Inventory.** The traceability inventory carries no 1985 rows yet (PB5094: work.py refuses 1985 ids), so `inventory_rows` is empty; the row this note covers is the 1985 rule id listed below (catalog `docs/rearchitecture/spec-rule-catalog-1985.json`).

**Rules (1; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-FMT-VII.3.3.2` - `§1985:VII.3.3.2` (record harm: rejects-legal-source, slice-01): General format "BLOCK CONTAINS [ integer-1 TO ] integer-2 { RECORDS | CHARACTERS }"; the clause has no syntax rules (paragraphs 3.3.1 Function, 3.3.2 General Format, 3.3.3 General Rules). Deciding words: §1985:VII.3.3.3 GR4 "If integer-1 and integer-2 are both specified, they refer to the minimum and maximum size of the physical record, respectively" (citation `§1985:VII.3.3.3 GR4`). The 1985 text states a greater-than relation only where it wants one (§1985:VI.5.8.3 SR5 for OCCURS).
