# PB155

Rows: SR-14.9.2.3-1 (DIVERGES)/-2/-3, SR-14.9.12.3-1/-3/-4, findings [ADD statement]/[divide-statement].

(1) NonNumericOperandKind's guard `{ Category: Alphanumeric or National, EditMask: null }` — PictureAnalyzer builds alphanumeric-edited as Alphanumeric WITH EditMask (no AlphanumericEdited member), so `ADD <PIC XXBXX> TO N` binds silently and FieldNumCore digit-decodes; drop the EditMask condition (the de-editing MOVE grant is §14.9.25.4 GR6d1's alone). (2) STRINGLIT/HEXLIT: CheckLiteral returns the quoted text; IntLiteralX emits `"ABC"L` — wrong stage; screen at NumLiteral. (3) CheckComposite: the BoundNumLiteral arm counts E-form digits (r2b excludes floating-point literals) — `ADD 1.5E+3 TO F(9(28))` rejects legal source — and InComposite requires Category==Numeric so a numeric-edited identifier-3 (SR2-admitted) contributes nothing — both directions wrong in one method.
