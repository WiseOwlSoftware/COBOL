# PB93 — OPEN — `01 CPY-B REDEFINES NOPE PIC 9(2).` with no `NOPE` anywhere compiles clean

> ⚙ **flags:** under-rejects (illegal source accepted), silent · found 2026-08-18 probing [[PB82]]'s copybook
> positions with a deliberately-broken copybook: the "broken" entry drew nothing at all.

**Measured** (`scratchpad/pb82/redef.cob`, `--std 2023`): a WORKING-STORAGE `01 CPY-B REDEFINES NOPE PIC 9(2).`
where no entry named `NOPE` exists compiles with exit 0 and no diagnostic; the program runs.

**Spec:** §13.18.44.3 SR4 ("No entry having a level-number numerically lower than the level-number of data-name-2
may occur between the data description entries of data-name-2 and the subject of the entry"), SR7 and SR10 all
presuppose that data-name-2 names a PRECEDING entry, and §8.4.2.1 requires that "a statement shall contain a
reference that uniquely identifies that resource" — a REDEFINES whose data-name-2 identifies nothing is illegal
source, and (a) is a diagnosable error at every edition.

**Mechanism:** `DataBinder.ResolveRedefines` looks the target up in the sibling scope
(`scope.FirstOrDefault(...)`) and, when nothing matches, reports ONLY the METHOD-scope case (COBOLNET1577,
`OoRootOwner.ContainsKey(RootOf(item))`); a program-scope miss leaves `RedefinesTarget` null while
`RedefinesTargetName` stays set — and the two disagree downstream: `BitLayout` / `ImageWidth` / `ByteWidth` skip the
item as an overlay (`RedefinesTargetName is not null`) while the emitter gives it its own field. Whatever storage
shape results is one no edition defines.

**Fix shape:** the program-scope miss is the SAME diagnostic class as the method-scope one — ONE report at the lookup
miss (a new descriptor, or 1577 generalized to "REDEFINES target is not a preceding entry in the same scope",
positioned at the entry through the [[PB82]] cursor), the item then binding as an ordinary entry (`RedefinesTargetName`
cleared) so no downstream consumer sees the half-state. Sweep: `RENAMES` of an undefined data-name (the 66 path
`Renames66` resolution), `SAME AS` / `TYPE` of an undefined name (`ExpandType`/`ExpandSameAs` — check they report),
`OCCURS … DEPENDING ON` an undefined name (`DataBinder.Odo` — check), `INDEXED BY` duplicates. Golden: a negative
per shape (`.err` = the code) plus a positive that a legal REDEFINES chain still lays out.
