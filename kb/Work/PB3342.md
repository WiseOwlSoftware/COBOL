# PB3342 — COBOLNET4213 refuses legal source: an override named like its class

Source: the PB1784 implementer's lead (carried from round 1 of review), report `E:/COBOL-coord/scratch/reports/w1108a-PB1784-report.md`, "New defects / leads"; branch `worktree-wf_9e52adb3-fa2-7`, PR #188. The lead was NOT re-verified by the filing clerk. The code sites below are on PR #188's branch; main gains them when that PR merges.

**What the compiler does.** A COBOL class that overrides an inherited method whose name equals the overriding class's own name is refused with COBOLNET4213 (`OverrideNamedLikeItsClass`). The diagnostic text itself calls it an "implementation restriction". The restriction comes from C#: the emitted member name would equal the generated class name, which C# rejects as CS0542 ("member names cannot be the same as their enclosing type").

**Why it is a defect.** The lead says the source is legal COBOL. Rejecting legal source is debt (CLAUDE.md rule 3), and the fix is an emitted-name mapping for the collision, never a refusal (rule 4, no workaround).

**Repro.** A base class with a method `M`; a subclass named `M` that OVERRIDEs it. Expected: it compiles and the override dispatches. Seen: COBOLNET4213.

**Code sites (on PR #188's branch).**
- `src/Cobol.Net.Compiler/Oo/OoClassTable.cs`, `MarkRoster` (about line 972): `m.CsName = baseM.CsName; if (m.CsName == sym.CsName) edition.Error(DiagnosticCatalog.OverrideNamedLikeItsClass, ...)`.
- Descriptor: `src/Cobol.Net.Editions/Diagnostics/DiagnosticCatalog.cs` (about line 7083).

**To verify (the implementer's first step).** The spec citation that makes the source legal is NOT yet checked: derive it from `specs/ISO_COBOL.md` and run `python scripts/spec/cite.py --check <clause> "<text>"` before it enters code, a golden or the DEVLOG. Until then it is "to verify", not a citation. Frontmatter values are the most conservative the lead supports (severity MINOR, rejects_legal_source true); the implementer may raise the severity once the repro is measured.

**Fix shape.** Map the emitted C# member name when it equals the class name (one mechanism, in the name allocator that sets `CsName`), delete COBOLNET4213 with its descriptor, docs row and tests in the same change, and sweep for sibling C# naming collisions (member versus enclosing type, member versus nested type).
