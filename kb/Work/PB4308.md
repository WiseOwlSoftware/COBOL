# PB4308 - `FUNCTION LENGTH(x PHYSICAL)` / `BYTE-LENGTH(x PHYSICAL)` are accepted silently at `--std 85` and `2002`, where PHYSICAL is a user word; the keyword is a 2014 introduction

Found by the Mythos front-end review, gap pass, 2026-10-31 (GAP-REVIEW.md, G2-2; artifact https://claude.ai/artifact/KaxkLe85tfZBZ3nZ1tDGTs). Pin d7daee1cf.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/IntrinsicBinder.cs:2319-2333` (the PHYSICAL arm, no `ConstructRegistry.Check`); `tests/version-matrix/constructs.json` (no row); `tests/version-matrix/reserved-words.json` PHYSICAL (r2014 true).

**Finding.** `FUNCTION LENGTH(x PHYSICAL)` and `BYTE-LENGTH(x PHYSICAL)` are accepted silently at 85/2002 where t2002 prints `( argument-1 )` (section 15.39.1 :31798, section 15.10) and PHYSICAL is a user word; `cobc -std=cobol85` and `-std=cobol2002` refuse (probes `r2`, `r2b`). The edge is 2014, not "2014 or 2023": PHYSICAL exists for variable-length groups / dynamic-capacity tables (section 15.50.4 GR8, section 15.14.4 GR7), which 2023 Annex E does not list as new; reserved-words.json has PHYSICAL r2014 true; `cobc -std=cobol2014` accepts. PB24/PB61 landed it without an edge. (PB3934 is a different matter: GnuCOBOL's comma form.)

**Fix direction.** One constructs.json row (edge 2014) checked at IntrinsicBinder.cs:2319 like TRIM's argument-2 gate.

**Citations checked** (`python scripts/spec/cite.py --check`): section 15.50.2 "( argument-1 ["; section 15.14.4 "the PHYSICAL argument is not specified".
