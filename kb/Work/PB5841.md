# PB5841 - a CI job limit that the job's normal duration reaches bounces a landing

**Defect.** Merge-group run 43843342653 (pull request 1769, the BLOCKER fix PB5801; gate GREEN locally, review CLEAN) was
removed from the merge queue for `failed_checks`: the `audits` job was cancelled, 'The job has exceeded the maximum
execution time of 10m0s'. The job was not hung: its last four successful merge-group runs took 354, 402, 447 and 530 s
(runs 43845552192, 43845557167, 43835747589, 43845698642) and it grows with the inventory and the suite. The 10-minute
limit was set at about twice a p90 measured on 2026-10-31 (DESIGN-test-build-ci.md section 1.4); the job outgrew it.

**Root.** The rule that set the limits ("about twice the measured p90, once") had no check that it stayed true, so the
margin eroded with the suite. A wall-clock limit is there to catch a hang; one the normal duration reaches is a failure
with no regression.

**Fix (landed with this note).**
1. Limits raised to at least twice the longest successful run of the last 20 runs (measured 2026-11-16 over every job of
   both workflows): `audits` 10 to 25 (9.6 min), `linux-shard` 15 to 25 (10.8), `windows-shard` 20 to 25 (10.7),
   `linux-built-self-tests` 15 to 20 (7.7), `windows-self-tests` 25 to 35 (14.7), nightly `differential` 60 to 90 (31.9;
   `MAX_JOB_MINUTES` 60 to 90). Every other job was already above twice its longest run.
2. `python scripts/ci_bounds.py --durations` (the nightly's new `job-limits` job) reads the last 20 runs of each workflow
   and is red for a job whose longest run times 2 passes its limit. Chosen over a committed recorded-durations file because
   the tree audits that every gate runs must make no network call and a bot-refreshed file is one more churning artifact;
   the self-test has an arm that fails without the check and one that fails if the nightly stops running it.
3. DESIGN-test-build-ci.md sections 1.4 and 1.4a state the rule, the measurements and the check.

**The slow audits inside `audits`** (step timings of run 43845698642): `Script self-tests` (self_tests.py) 211 s, `Code
citations` (audit_code_citations.py) 66 s, `Rendered views` 25 s in CI (150 s in the local gate), `Conformance suite`
13 s, `Build targets` 20 s, and the rest 10 to 21 s each, with 48 s of checkout, toolchain and pip before them. Lead
(not done here): make `Script self-tests` and `Rendered views` cheaper (the self-tests of the audits already run in their
own steps and again inside the discovered population).
