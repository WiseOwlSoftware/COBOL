# PB3270 — emitted C# names are not seeded with the imported type names

Source: `E:\COBOL-coord\scratch\reports\w1093b-PB2099-report.md`, "New defects", first bullet (found reviewing PB2099's branch; not fixed there under finisher-never-widens).

**Mechanism.** A COBOL word that spells a runtime or `System` type the generated code names unqualified shadows that type. The scopes are seeded with emitter members only, not with the type names the module's `using global::System;` and `using global::CobolNet.Runtime;` import. Result: legal COBOL rejected with CS errors.

**Repros** (all in `E:\COBOL-coord\scratch\w1093b-r1\`, each exit 70):
- `PB.cob`: formal `HostLanding` gives CS1061 `string.LandText`.
- `PC.cob`: record member `HostLanding` gives CS0120.
- `PD.cob`: WORKING-STORAGE `CobolString`/`CobolNum`/`StorageCell` gives CS0236/CS1061. This is the internal program class and record struct, so it predates PB2099's branch.
- `PE.cob`: `PROGRAM-ID. HostLanding.` makes a host class that shadows the runtime type namespace-wide (CS0117).

**Code sites.** `src/Cobol.Net.Compiler/Binding/Model/CsNames.cs` (seed sets, `CsNameScope.ModuleTypes`).

**Fix shape (the report's).** Seed every scope with the imported type names, derived from the runtime assembly's exported `CobolNet.Runtime` types and the reference set's `System` types, with a drift test. Or root every runtime type reference with `global::`. Choosing between them is a design call for the implementer (CLAUDE.md rule 5: prefer the shape that makes the next case automatic).

## Landed

All four repros reproduced on a fresh build and now compile and run (PB, PC, PE with their formals, members and host class
renamed `HostLanding_2`; PD runs and prints `AB   CD   007Q  `). The fix is the report's first option, chosen for rule 5
(the shape that makes the next case automatic): `CsNames.ImportedNamespaces` is the ONE list of the namespaces the generated
file's using directives import, `CsNames.ImportedTypeNames` is DERIVED from it by reflection (the runtime assembly's public
top-level types of those namespaces, and the core library's `System` types), and every `CsNameScope` kind (`RecordStruct`,
`ProgramClass`, `HostEntry`, `ModuleTypes`) holds it as a shared frozen set beside its own members, so `CsNames.Allocate`
gives a word spelled like one the next free `_n`. Rooting every runtime reference with `global::` was rejected: thousands of
emitter strings and every generated file noisier,; reserving renames only a word that spells a type EXACTLY (C# is case-sensitive; COBOL source is
mostly upper case).

Sibling sweep: every producer of a C# name from a COBOL word (`Sanitize` / `WordIdentifier` callers) was read; data items,
group members, formals, published records and the host class all allocate through the four scopes. OO class, interface,
method and property names are `WordIdentifier`'s upper-case fold, so they spell no imported type (the one all-capitals
type, `BASE`, is the OO base class). The wide probes (every one of the 206 runtime type names and 30 System names as
WORKING-STORAGE items and as group members; file, sort, indexed, report, OO, TYPEDEF, 66, 88 and index-name positions)
failed on main with CS0236 / CS0120 / CS1061 and pass here. `ImportedTypeNameDriftTests` found one more arm while being
written: `StatementEmitter` wrote `Console.Error.WriteLine` unqualified (a data item spelled `Console` would shadow it);
it is `global::System.Console…` now.

Witnesses: `ImportedTypeNameDriftTests` (four facts) and `conformance/85/pb3270_runtime_type_names_as_user_words`.

## Landing

- `src/Cobol.Net.Compiler/Binding/Model/CsNames.cs#ImportedNamespaces` / `#ImportedTypeNames` — the one list of namespaces
  the using directives import and the type names derived from it; every `CsNameScope` kind holds it (shared frozen
  set). A new using directive in `ProgramEmitter.Emit` is added to `ImportedNamespaces` (a drift test is red otherwise).
  Trap: the sweep `EmittedGlobalNameDriftTests` reads every compiler string, so a namespace is spelled
  `typeof(X).Namespace`, never as a `"CobolNet.Runtime…"` literal.
- `src/Cobol.Net.Compiler/CodeGen/StatementEmitter.cs` — `Console.Error.WriteLine` is `global::System.Console…`; write any
  `System` type outside the core library `global::`-qualified (`ImportedTypeNameDriftTests`).
- `tests/Cobol.Net.Tests.Unit/ImportedTypeNameDriftTests.cs` — builds a Roslyn compilation over the framework directory;
  `NotEmittedCSharp` is the (empty) exemption list for strings that are not emitted C#.
