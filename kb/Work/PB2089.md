# PB2089 — native numeric argument to an area formal is copied

Filed 2026-10-05 by the train-1022 lander from the w1022a implementer report (PB2087, lead 3).

**Rule.** ISO §14.2.3 GR8: "If the argument is passed by reference, the activated runtime element operates as if the
formal parameter occupies the same storage area as the argument."

**Mechanism.** PB2087 (train 1022) laid AREA formals (group, REDEFINED and addressed LINKAGE formals) over the argument's
own `StorageCell`. The activating element claims an operand onto a cell only when `DataBinder.ClaimsAnArea`
(`src/Cobol.Net.Compiler/Binding/DataBinder.Ptr.cs`) admits it: a group, a REDEFINES-class member, or a non-numeric
elementary item. A native numeric elementary item (DISPLAY, COMP, COMP-3 and so on, stored as a typed field) is excluded
to save the cell cost, so it crosses through its carrier alone. An elementary formal aliases it per access through that
carrier, but an area formal over it gets a fresh cell, filled at entry and stored back at return
(`ProgramEmitter.EmitCallMethod`, the `AreaCopyCarrier` copy guard).

**Failure (reproduced by the train-1022 lander on cd7f00c1d).** Caller `01 N PIC 9(4) VALUE 1.` and
`CALL "NASUB" USING N N`, then `DISPLAY "N " N`. NASUB's LINKAGE: `01 LK-1 PIC 9(4).` `01 LK-1X REDEFINES LK-1 PIC X(4).`
`01 LK-2 PIC 9(4).`, `PROCEDURE DIVISION USING LK-1 LK-2.` `MOVE 7 TO LK-2` `DISPLAY "LK-1 " LK-1` `GOBACK.` Observed
`LK-1 0001` / `N 0001`; GR8 requires `LK-1 0007` / `N 0007`. LK-1 never sees the store, and at return its copy-back
stores its entry image into N over LK-2's store. The same happens when the
only formal is an area formal and a callback (a RECURSIVE re-entry, or a contained program reading N as GLOBAL) stores N
while S is active: S's area formal never sees the store, and its copy-back undoes it.

**Fix direction.** Claim a native numeric BY REFERENCE operand onto a cell when the callee's formal is (or may be) an area
formal, or always, after PB2088 makes cell stores cheap; or carry the operand as a one-item area whose window encodes the
native value. Measure the cost first (PB2088). The INVOKE lane (PB2087's remainder) has the same question.
