# PB5180 - at --std 85 one INITIALIZE REPLACING item may name two categories (REPLACING NUMERIC ALPHANUMERIC DATA BY ZERO): initializeCategory is the 2002 choice-indicator list and CategorySetOf binds it at every edition

**Sites:**

- `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolData.g4` (`initializeCategory`)
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/InitializeBinder.cs` (`CategorySetOf`)
- `src/WiseOwl.Cobol.Compiler/Validation/VersionConformancePass.cs` (`VisitInitializeCategoryName`)

**Mechanism.** §1985:VI.6.17.2 puts the five category words of a REPLACING item in plain braces with no choice indicators, so each item takes one (§1985:IV.2.1.4). `initializeCategory` is `initializeCategoryName+`, the later editions' choice-indicator set, and `InitializeBinder.CategorySetOf` binds the set with no edition arm, so a two-category item compiles at --std 85. kb/Work PB415 (landed) made the multi-category form compile at 85 and the golden pb415_initialize_multi_category_85 pins it; the fix reverses that golden.

**Found by.** The 1985 code read (2026-11-10; its records are `E:/COBOL-coord/scratch/coderead-85/for-register.json`): each rule below was read against the code sites it names and probed at `--std 85`, and found non-conforming. Verdict, harm, evidence, repro and observed text are the records'; the rows' verdicts are recorded on another branch.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids of the list below.

Code read: No open kb/Work note owns the fix. §1985:VI.6.17.2 prints INITIALIZE, one or more identifier-1, and an optional REPLACING phrase of one or more items, each item ONE of the five category words (ALPHABETIC, ALPHANUMERIC, NUMERIC, ALPHANUMERIC-EDITED, NUMERIC-EDITED) inside plain braces, then DATA (optional) BY (required) and identifier-2 or literal-1; the printed page (folio VI-92, rendered) shows braces there and no choice indicators. Implemented at 85: initializeStatement, initializeOperandList, initializeReplacingPhrase and initializeReplacingItem parse it (DATA optional, BY required: the witness's REPLACING NUMERIC DATA 5 is COBOL5506), and the later phrases reach 1985 as refusals: VersionConformancePass.VisitInitializeStatement refuses WITH FILLER, TO VALUE, TO DEFAULT and THEN before REPLACING below COBOL-2002 (COBOL0830 to COBOL0833), and VisitInitializeCategoryName refuses the eight later category words (COBOL0900).
