# PB4262 — landing and impact-map failures are mailed to the operator whichever lane the branch belongs to

**Sites:** `scripts/orchestrator/land_lane.py:700` (`notify_operator`), `scripts/orchestrator/impact_lane.py:188` (`fail`).

`land_lane.py` line 700 and `impact_lane.py` line 188 post landing and impact-map failures to `operator` whatever lane the
branch belongs to. It has the same root as PB4190, no owning lane, but a different mechanism: a landing record carries no
lane, where PB4190 fixed the dispatch ledger. The fix gives a landing record its lane and routes both messages by it.
