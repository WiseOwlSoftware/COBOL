# PB3182 — drift tests the planner cannot read, and tree sweeps without the Sweep trait

Source: lead 1 of `w1080g-PB3165-report.md` ("## Finisher"), filed by the enqueue unit 2026-10-15. Grepped
`kb/Work/` for `paths_of` and `drift_rules`: PB1957 (CI-job to local-leg map), PB3022 (the Sweep trait) and PB3112 (the
cost cap) are the neighbours; none owns the READABILITY of a class's paths.

## What happens

`scripts/spec/drift_rules.py:65` `paths_of` reads only `TestRepo.<Helper>(...)` calls and quoted repo-relative
literals from a `*DriftTests` class. A class that reaches the tree through a private helper, a
`Path.Combine(TestRepo.Root, ...)` or a constant yields no path, so the planner can neither name it a specific rule nor
see it as a tree-wide sweep. 100 of 327 classes are in that state. About 10 of them scan whole trees with no
`[Trait("Sweep", "tree")]` (examples: `EndMarkerRuleDriftTests`, `SubscriptAdmissionDriftTests`,
`RenamesPlaceBuilderDriftTests`, `Table12StatementNameDriftTests`, `SourceEncodingDriftTests`), so they never reach
tier 0c and a Windows leg-1 gate misses their reds.

## Instance

PB3165's `CapacityRegisterReferenceDriftTests` reached `src` through a private `Path.Combine` helper; the Windows gate
did not plan it and the red surfaced at the landing's Linux gate (`=== ENQUEUE: GATE RED (Linux) on 54377b4d4dd3`).
That is a CI-invariant breach (CLAUDE.md, the CI invariant; PB1957). The PB3165 finisher re-pinned that one class to
`TestRepo.Src` plus the trait; the other classes remain.

## Repro

```
python -c "import sys; sys.path.insert(0,'scripts/spec'); import drift_rules as d; print(sum(not r['paths'] for r in d.index()))"
```

(prints the count of classes with no readable path; 100 on 2026-10-15).

## Fix direction (rule 5: a structure, not a list)

Make "a drift class reads the tree" a property the planner can always see: either `paths_of` resolves the other access
forms, or a drift test fails any `*DriftTests` class whose tree access `paths_of` cannot read (and any such class
that scans a tree without the Sweep trait). `HostWitnessTraitDriftTests` already pins sweep set = trait set for the
classes it can read; this note extends the set it can read. Sweep every sibling class, not the five named.
