# PB5243 - a Report Section elementary entry is not checked against 1985 Table 1 of permissible clause combinations: SOURCE with VALUE (VALUE silently discarded), VALUE with BLANK WHEN ZERO, SUM with JUSTIFIED and USAGE on the unprintable SUM entry compile, and the legal SOURCE with JUSTIFIED, BLANK WHEN ZERO or GROUP INDICATE and no COLUMN is refused

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/ReportSectionBinder.cs` (`ScreenReportEntryClausePresence`: the 2023 screens at every edition; its only 1985 arm is the SUM-in-control-footing check)
- `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/ReportWriterEmitter.cs` (`FieldImage`: SOURCE wins over VALUE)
- `src/WiseOwl.Cobol.Compiler/Binding/ReportEntryClauseTable.cs` (new: `ReportEntryClauseTable.Permits`, `AlternativesWritten`; Table 1 as the five-row set)
- `src/WiseOwl.Cobol.Compiler/Binding/ReportSectionBinder.cs` (`ScreenReportEntryClauseTable`; the SOURCE/SUM/VALUE brace screen in `ScreenReportEntryClausePresence`; the SR10, SR13, SR15 and GROUP INDICATE column arms now 2002 and later; the operand-list comment in `BindReportEntry`)
- `src/WiseOwl.Cobol.Editions/Diagnostics/DiagnosticCatalog.cs` (`ReportEntryClausePresence`, description)

**Mechanism.** §1985:XIII.3.9.3 SR11 Table 1 lists every permissible clause combination of a format 3 (elementary) report group entry: "A blank indicates that the clause is not permitted." The format itself writes SOURCE, VALUE and SUM as alternatives of one brace (§1985:XIII.3.9.2), and §1985:XIII.3.22.4 GR1 opens "The VALUE clause must not conflict with other clauses in the data description of the item". The binder applies the 2023 screens instead (§2023:13.15.3 SR15, §2023:13.18.28.3 SR1 among them), and they differ from Table 1 both ways: rows 3 and 4 permit SOURCE with JUSTIFIED, BLANK WHEN ZERO or GROUP INDICATE and no COLUMN (a 1985 entry with no COLUMN is not printed but is legal), which the 2023 COLUMN requirement refuses; and the blank cells SOURCE+VALUE, VALUE+BLANK WHEN ZERO, SUM+JUSTIFIED and USAGE on the unprintable SUM entry are accepted. SOURCE+VALUE also compiles at 2023, whose format has the same brace, so that half is not an edition arm.

**Found by.** The 1985 code read, slice 56 (`1985-SR-XIII.3.9.3-11`, read PARTIAL), and the slice-52 refuter, which OVERTURNED the CONFORMS verdict of `1985-GR-XIII.3.22.4-1` (probes `E:/COBOL-coord/scratch/coderead-85/out-pipe/refute-slice-52/R1J.cob`, `R1K.cob`, `R1Y.cob`). The SOURCE-with-VALUE case was also in the slice-50 read of `1985-FMT-XIII.3.9.2` (kb/Work PB5242 holds that row's other cases).

None of them is recorded: the code read's non-conforming verdicts of slices 36-56 wait in `E:/COBOL-coord/scratch/coderead-85/pipe-for-register.json`.
