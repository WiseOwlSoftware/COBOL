# PB5521 - the negatedAbbreviatedRelation grammar comment still says the node is only the 1985 logical NOT and that VersionConformancePass refuses it: stale after PB5123

**Sites:** `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolExpressions.g4:251-268` (`succeedingCondition`, `negatedAbbreviatedRelation`; the comments above them)

**Mechanism.** The comment above `negatedAbbreviatedRelation` (lines 251-268 on main, read this session) says the grammar is the superset, that ISO 2002 prohibited the form (§2002:F.1 item 22) and that `VersionConformancePass` refuses it from 2002 on (construct `abbreviated-not-logical-removed-2002`, COBOL0902). PB5123 (landed, PR #1644) changed that, so the comment describes a retired state (rule 6: docs describe the CURRENT compiler). The `succeedingCondition` comment above it calls the node "the 1985 logical NOT" too. **Fix:** rewrite both comments from the code PB5123 landed, and run `cite.py --check` on every citation kept.
