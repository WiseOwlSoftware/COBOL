- **R11-1 (blocking): the base rule climbed into the framework.** Round 11's `Bases` derived every overridden member and every
  implemented interface member, metadata included. So one edition-derived override of `object.GetHashCode`, or one implementation
  of `IReadOnlyCollection<T>.Count`, made every unrelated read of that framework member an unsuppressible WOCA0001.
  - **The decision: derivation climbs only into OUR assemblies.** `OursIn(compilation)` returns this compilation's assembly, plus
    every referenced assembly that declares the mark's type (`EditionDerivedAttribute`, the analyzer's own name for it) or
    references an assembly that does.
  - The reason this is the right line: derivation crosses an assembly only through the mark, so an assembly that cannot name the
    mark has nothing to derive. That covers the framework, a third-party package, and today the Listing assembly.
  - The set is read from the compilation's references, never from a list of names or a name root.
