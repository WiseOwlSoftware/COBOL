# PB5996 - two lengths for one EXTERNAL record inside one compilation group

Two programs in one source file describe the EXTERNAL record EXT-R, one as PIC X(10) and the other as X(100); it compiles at
`--std 85` (and 2023). §1985:X.4.5.4 GR2 requires every description of an external record in a run unit to agree, and
docs/conformance/3/D-85-EXTERNAL-FD-AGREEMENT.md (written 2026-11-20, kb/Work PB5912) says the compiler checks the agreement
"where both descriptions are in one compilation group". For records that statement is false today; PB5983 established that the
run time does not crash on it. Fix: compare the descriptions of one external record across the group's programs (the
in-group check the determination describes), refusing a mismatch; or, if the check is judged out of scope, correct the
determination. Golden: extlen.cob refused at 85.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/ExternalFileConnectorRules.cs` (whole: the in-group external comparisons, of which the record's is missing; the fix names the member)
