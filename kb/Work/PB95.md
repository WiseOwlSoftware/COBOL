# PB95 — LANDED — `01 B PIC 1(3) BIT.` was "unexpected 'BIT'"

> ⚙ **flags:** rejects-legal-source (loud, at parse) · found 2026-08-18 writing [[PB79]]'s bit-group golden
> (`01 BR PIC 1(12) BIT.`), fixed in the same landing (DEVLOG 1317).

**Measured (before):** with `--std 2023`, `01 X PIC N(2) NATIONAL.`, `01 Y PIC 1(3) BIT.`, `01 P POINTER.`,
`01 O OBJECT REFERENCE.`, `01 PP PROGRAM-POINTER.`, `01 FP FUNCTION-POINTER.` each drew COBOL0307 "unexpected …";
DISPLAY / COMP / COMP-n / BINARY / PACKED-DECIMAL / INDEX / BINARY-CHAR… / FLOAT-* / MESSAGE-TAG parsed bare.

**Spec:** §13.18.60.2 general format — `[ USAGE IS ] { BINARY | BINARY-CHAR … | BIT | … | NATIONAL | OBJECT REFERENCE
… | POINTER | PROGRAM-POINTER … }`: the USAGE keyword is optional for the WHOLE alternative set, not for a
hand-picked subset.

**Mechanism:** `usageClause` was `USAGE IS? usageKeyword … | DISPLAY | COMPUTATIONAL | … | INDEX` — a hand-maintained
list of bare alternatives beside the full form, and the six missing words were exactly the ones that are
cobolWord-admitted user words (BIT, NATIONAL, PROGRAM-POINTER, FUNCTION-POINTER) or rule-shaped (OBJECT REFERENCE,
PROGRAM-POINTER TO, FUNCTION-POINTER TO), i.e. the ones a hand list is likeliest to omit.

**Fix (as built):** ONE alternative — `usageClause : (USAGE IS?)? usageKeyword binarySign? noSignPhrase?` — so every
spelling, bare or prefixed, carries the `usageKeyword` node and every reader (`DataBinder.UsageKeyword`, the legacy
`SemanticBuilder`) sees one shape (the two bare-BINARY-xxx text workarounds went with the list). No edition
predicate: in `05 BIT.` the entry-NAME alternative is tried first and wins (an '85 item named BIT), and
`05 X BIT.` reads as the usage, which the binder / VersionConformancePass then names as the 2002 introduction — the
superset-parse / bind-narrow direction of DESIGN-version-conformance-pipeline. Golden
`2023/pb95_bare_usage_keywords`; the '85 user-word shape is pinned by the probe in DEVLOG 1317 and by
`VersionMatrixTests`' continuity cells. Inventory `FMT-13.18.60.2` → CONFORMS.
