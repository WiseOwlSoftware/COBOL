# PB105 — LANDED — the CLDR locale loader and tailoring builder (`Runtime/Collation/CLDR/`)

> ⚙ **flags:** owner-directed 2026-08-18/19 ("hard implementation mode", section 6: `COBOLSharp/Collation/CLDR/` with
> `CldrLocaleLoader.cs` (`Load(localeName)`), `CldrLocaleData.cs`, `CldrParser.cs` ("extract primary/secondary/tertiary
> weights, tailoring rules, locale-specific behavior"), `README.md` ("explain how CLDR integrates with CollationTable
> and LocaleManager") and section 8 [2] "LocaleManager: load CLDR data, apply CLDR tailoring rules, apply local
> tailoring files") · completes what [[PB101]]'s hand-derived `es-ES.tailor` did for ONE rule: every locale's order
> derived from its CLDR rules mechanically · rule 5 (re-architect when necessary): the brief's "extract weights"
> premise does not match CLDR (its files carry RULES, not weights), so the deliverable is a BUILDER that turns rules
> into weights over the derived table — the same construction a `.tailor` goes through (`CollationTable.Rebuild`).

## What landed (2026-08-19)

- **Data**: `data/unicode/cldr/collation/*.xml` (all 135 files of release-48-2), `cldr/bcp47/collation.xml`,
  `cldr/supplemental/supplementalData.xml` (parentLocales), `cldr/RELEASE`; the pack script
  `scripts/collation/pack-cldr-collation.py` → the deterministic `Collation/CLDR/Data/cldr-collation.zip` (907 KB) +
  manifest (embedded). The three old `data/unicode/cldr-collation-{es,fr,en}.xml` moved into the directory.
- **Table format 2** (`generate-collation-table.py`, `CollationTable.Decode` reads 1 and 2): the CLDR **reordering
  groups** (space, punct, symbol, currency, digit, then one contiguous primary range per script — 173 groups derived
  from `FractionalUCA.txt`'s `FDD1` first-primary markers + `PropertyValueAliases.txt` script codes; the generator
  asserts they are contiguous, in root order, and that the `*` variable set equals space+punct) and the element
  **case bits** (DUCET uppercase tertiaries 0008–000C). `CollationElement.Case` (`ElementCase` Lower/Mixed/Upper),
  `CollationTable.ReorderGroups` / `TryGetReorderGroup`, `WeightMap` (root → table per level), `TailoringPlan` +
  `Rebuild` (the ONE construction step for both front-ends), `WithTailoring` translating root-scale `.tailor` weights
  through the maps.
- **Engine settings**: `CollationOptions` (Strength, Alternate, **MaxVariable**, **CaseFirst**, **BackwardsSecondary**);
  `Collator(table, options)`, `With(...)`, `CollationEngine.For(table, options)`; caseFirst as ICU's inverted case
  bits (upper-first: Upper < Mixed < Lower), backwards level 2 from the end (the prefix skip is not taken for it),
  maxVariable by group ranges.
- **Parser** (`CldrParser`): LDML XML via `XDocument` (DTD ignored), the JSON mirror (documented — CLDR publishes no
  collation JSON), the rule syntax: `&`, `[before n]`, every logical reset position, `<`/`<<`/`<<<`/`<<<<`/`=`,
  starred relations with ranges, `/` extensions, `|` prefixes, contractions, quoting/escapes, comments,
  Pattern_White_Space (the Arabic files' LRMs), `[import]`, `[strength]`, `[alternate]`, `[maxVariable]`,
  `[caseFirst]`, `[backwards 2]`, `[normalization]`, `[caseLevel]`, `[numericOrdering]`, `[hiraganaQ]`,
  `[reorder]`, `[suppressContractions [set]]`, `[optimize [set]]`, the UnicodeSet subset. **0 unsupported constructs
  over the 135 files** (drift test).
- **Loader** (`CldrLocaleLoader`): `Load`/`TryLoad`/`LoadExact`/`Root`, sources (`COBOL_CLDR_DIR`, `Collation/CLDR/`
  beside the app, the pack), the **chain** per LDML — explicit `parentLocales` from the collations component table
  and the general table's plain entries (nb → no; the `nonlikelyScript` entries are main-component only, so
  zh_Hant → zh, where its `stroke` default lives — verified against ICU's own coll bundles), else truncation, then
  root; `ResolveCollation(tag)` (type from `-u-co-`, else `<defaultCollation>`, else standard; type fallback
  reported); `CldrLocaleTag` (BCP 47 `-u-` keys co/ka/kb/kc/kf/kh/kk/kn/kr/ks/kv).
- **Builder** (`CldrTailoringBuilder`): per-level ordered slot lines; relations insert after the anchor's slot with
  common lower levels; `[before]` predecessors; special positions from the table; expansions; prefixes as
  contractions; imports expanded (cycle-checked); **canonical closure over composites** (Vietnamese ả ắ ậ … from the
  tailored marks; discontiguous marks per S2.1.1–S2.1.3; NFD aliases of tailored keys); **numbering** with gap
  overflow → shift (renumbering) and the recorded maps; **reordering** as a permutation of group tiles with the
  reserved space after `[last regular]` folded into the Hani tile (Chinese pinyin moves with Hani); case bits from
  the string (Mixed for "Aa"); settings → options; suppressContractions; unsupported settings and `<<<<` reported.
- **Integration**: `CollationEngine.ResolveLocale(tag)` (CLDR first, `.tailor` on top; cached) →
  `ResolvedLocaleCollation`; `ForLocale(tag, strength?, alternate?)` takes the locale's own settings unless
  overridden; `TryGetOrderingTable` resolves locale tags through CLDR; `LocaleManager`/`LocaleInfo`/`LocaleConfig`
  over the resolution (`Cldr`, `Options`, `Unsupported`, `Notes`, `CldrLocales`, `IsSupported` incl. `-u-` tags).
- **Verified**: `CldrLocaleLoaderTests` (17), `CldrIcuCrossCheckTests` — **29 locales pair-by-pair against the
  host's ICU 72 (CLDR 42), zero disagreements** except Latvian y/ī, which the two releases' rule files explain
  (CLDR 42 `&I<<y<<<Y`, release-48-2 `&I<y<<<Y<ī<<<Ī`) and which the test allow-lists with that citation; the
  Spanish `.tailor` ⇄ CLDR derivation agreement; keys ⇄ compare per locale. Every previous collation suite still
  green (the CLDR conformance samples included). Build times (`CldrBenchmarks`): es 6.1 ms, da 6.5, vi 7.7, zh
  50.5 ms — once per process; resolved 20 ns.
