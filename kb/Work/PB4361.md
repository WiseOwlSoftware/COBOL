# PB4361 - GOBACK RETURNING is refused with the STATUS phrase's message

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ControlFlowBinder.cs` (`ControlFlowBinder.ReturningAsStatus`, line 102 at the filing). Landed by PB4335.

`ReturningAsStatus` folds a `GOBACK RETURNING operand` into the status path and runs the STATUS phrase's SR6 screen over the operand. Two consequences:

1. When the user wrote no status phrase the refusal still says the status operand shall reference an integer item and cites 14.9.18.3 SR6, a phrase the program does not contain.
2. An operand such as a COMP-3 item with decimals is refused here, although the same statement accepts that operand when a header RETURNING item exists. GnuCOBOL accepts it. No GnuCOBOL differential was run for that case.

**Whether the refusal itself is legal is an adjudicator's question**, not decided here: `rejects_legal_source` stays false until an adjudicator reads 14.9.18.3 (run `python scripts/spec/cite.py --check 14.9.18.3 "<text>"` first) and says whether a RETURNING operand is held to the status rule. If it is, only the message is wrong (this note). If it is not, the refusal is a second defect and this note's flags change.
