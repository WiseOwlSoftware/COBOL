# PB5598 - at --std 2002 the 2014 ACTIVE-CLASS bans on property methods, the PROPERTY clause and inline-invocation results are applied, refusing legal 2002 OO source

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/OoDataBinder.cs#ScreenPropertyMethodHeader` (IsActiveClassReference arms)
- `src/WiseOwl.Cobol.Compiler/Binding/OoDataBinder.cs#BindPropertyClauses` (COBOL2563)
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/OoBinder.cs#OoBindStandardInvoke` and #OoBindResolvedInvoke (COBOL2140)

**Mechanism.** Three 2014-introduced rules (2014 Annex E.2 item 1; carried as §2023:11.7.3 SR6/SR7, §2023:13.18.42.3 SR6, §2023:8.4.3.4.3 SR4) are checked with no edition gate: a GET/SET property method whose returning item / USING parameter is ACTIVE-CLASS (COBOL2790), PROPERTY on an ACTIVE-CLASS object reference (COBOL2563), an inline method invocation whose method returns ACTIVE-CLASS (COBOL2140). 2002 has none of these bans.

**Inventory.** Rows claimed: `2002-SR-8.4.2.9.2-5`, `2002-SR-8.4.2.9.2-7`, `2002-GR-8.4.2.9.3-1`, `2002-GR-8.4.2.9.3-2`, `2002-GR-8.4.2.4.3-2`, `2002-SR-11.6.2-6`, `2002-GR-11.6.3-6`, `2002-GR-11.6.3-7`, `2002-GR-13.16.40.3-3`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:11.6.2 SR6`: "If the GET phrase is specified, then the method shall have no USING phrase parameters specified"
- `§2002:13.16.58.2 SR15`: "The ACTIVE-CLASS phrase may be specified only in a factory definition, an instance definition"
- `§2002:13.16.40.2 SR1`: "The PROPERTY clause may be specified only in the working-storage section of a factory definition"
- `§2002:8.4.2.4.2 SR4`: "shall not be described with the ANY LENGTH clause"

**Observed.** error COBOL2790 (14,8): METHOD-ID GET PROPERTY SELFREF: the returning item of a get property method shall not be an object reference described with the ACTIVE-CLASS phrase (ISO §2023:11.7.3 SR6); COBOL2790 again for the SET method; rc=65. acprop.cob: COBOL2563 citing §2023:13.18.42.3 SR6; acinline.cob: COBOL2140 citing §2023:8.4.3.4.3 SR4.

**Expected (from the 2002 text).** compiles and runs: 2002 11.6.2 SR6/SR7 ask only for the USING/RETURNING shape, 13.16.58.2 SR15 admits ACTIVE-CLASS in an instance definition and method linkage, and 13.16.40.2 places no class limit on PROPERTY.

**Sibling sweep.** every other check that cites a 2014 Annex E.2 addition with no edition gate (grep the binders for IsActiveClassReference / ObjectRefKind.ActiveClass); OoClassTable#ScreenInheritedPropertyNames also raises COBOL2563.

**Other editions.** 85: no (no OO). 2014: no (the bans are 2014 text, so they are right there). 2023: no.
