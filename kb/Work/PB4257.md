# PB4257 — the same message opens differently by recognition path

**Sites:** `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs` (`CobolErrorStrategy.BuildMessage`, `CobolErrorStrategy.ErrorKind`).

A stray gated terminator at a sentence start reads `cannot parse construct near 'END-DISPLAY'`, a failed prediction, while
END-ADD at the same place reads `unexpected 'END-ADD'`, an unwanted token reported from Sync. Both carry the same
diagnostic code and the same hint. The difference is cosmetic and does not mislead the user (misleads_diagnosis: no). It
was not fixed in PB4132 because the opening is chosen by `ErrorKind` for every predicate-failed prediction, so a fix cuts
across all of them. The implementer decides whether the two recognition paths should open alike.
