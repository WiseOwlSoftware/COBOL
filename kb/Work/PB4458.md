# PB4458 - ExpansionPlacementPass has three arms with no test: the Skewed overwrite (REPO-12), ReportForeignState (COBOL2240) and ReportSameName (REPO-2)

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Repository/ExpansionPlacementPass.cs:184` (`WillWrite`, the `TargetFile.Skewed` arm: warning `RepositoryPreviousBuildSkew`, REPO-12; the review cited line 172), `:232` (`ReportForeignState`, COBOL2240), `:217` (`ReportSameName`, the REPO-2 warning and the `shallNot` COBOL2240 error), `:244` (`RepositoryWord`). Sites are at the head of branch `worktree-wf_d44be67f-63e-4` (PB2104, PR #1046); line numbers are that head's.

**Coverage.** No test in `tests/` reaches these three arms (the expansion tests are in `tests/WiseOwl.Cobol.Tests.Unit/ExternalRepositoryExpansionTests.cs`). Each needs a case: a placement-(a) target left by an older-runtime build (the `MakeStale` helper of `ExternalRepositoryResolutionTests` makes one), a skeleton compiled under another compile state whose code names a class of this group, and a same-name expansion with different actuals both elsewhere in the search space (the warning) and at the placement target or in a referenced assembly (the error).

**Not reproduced.** The review said `ReportForeignState` prints "REPOSITORY CLASS" for an interface. At the head it words the entry through `RepositoryWord(symbol)`, which returns `REPOSITORY INTERFACE` for an `OoInterfaceSymbol`, so `misleads_diagnosis` is left false; the test for the interface case should confirm it.


## Landed (wave 20261840, group B): already witnessed

**Re-probe.** The note was filed from the review of an earlier head of the PB2104 branch. Its round 1 fixes (commit `82c85ae3d`)
added the tests before the branch landed, in `tests/WiseOwl.Cobol.Tests.Unit/ExternalRepositoryExpansionTests.cs`, and each
asserts the arm's own message text (so deleting the arm fails it):

- `ExpansionPlacementPass.WillWrite`, `TargetFile.Skewed` (REPO-12, COBOL5972, "is replaced"):
  `AnExpansionFileAnOtherRuntimeMajorWrote_IsReplacedUnderRepo12`.
- `ReportForeignState` (COBOL2240, "another compile state"): `AnImportedSkeletonUnderAnotherCompileState_WhoseExpansionNamesAGroupClass_IsRefused`
  (REPOSITORY CLASS) and `TheForeignStateRefusal_OfAnInterfaceExpansion_NamesAnInterfaceEntry` (REPOSITORY INTERFACE: the "Not reproduced"
  paragraph's case, confirmed).
- `ReportSameName`: the REPO-2 warning (`ASameNameExpansionElsewhereInTheSearchSpace_IsRepo2_AndTheExpansionIsMade`) and the COBOL2240
  error at the placement-(a) target (`ASameNameExpansionOfOtherActuals_AtTheFilePlacementAWouldOverwrite_IsRefused_AndTheFileIsLeftAlone`)
  and in a referenced assembly (`ASameNameExpansionInAnAssemblyTheGroupReferences_IsRefused`).

This landing changes only what the REPO-12 test duplicated: its hand-written byte patch is `RuntimeVersionSkew.Patch` (PB4460).
