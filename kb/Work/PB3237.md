## Landed

Re-probed on the worktree build (2026-10-17): the report reproduced exactly ('DECLARATIVE RAN FS=05' / 'NOT ON EXCEPTION RAN FS=05' / 'AFTER DELETE FS=05').

**Fix.** `KeyedIoEmitter.EmitDeleteFile` kept no hook result and carried its own copy of the phrase / NOT-phrase pair dispatch. The pair dispatch now exists once, `SequentialIoEmitter.EmitPhrasePair(phraseCond, phrase, notPhrase, successCond, UseHookResult hook)`; `EmitInvalid(st, ik, hook)` (INVALID KEY, the WRITE / REWRITE / DELETE / START arms) and DELETE FILE's ON EXCEPTION pair both render through it. The renderers (`EmitNotPhrase`, `EmitPhrasePair`, `EmitInvalid`) take the `UseHookResult` WHOLE, never a nullable gate string, so a dropped hook cannot compile (review round 1, R1-1). The NOT ON EXCEPTION arm is now `else if (Successful(st) && __iorN == DispatchResult.Normal)` (was a bare `else` / `if (Successful(st))`). Both the USE-declarative leg and the PERFORM WHEN twin (§14.6.13.1.4 2)) are skipped; an unhandled warning still runs the NOT phrase.

**Sibling sweep.** Every NOT-phrase read in `CodeGen/` was listed (`NotOnException|NotInvalid|NotAtEnd|NotAtEop|NotOnSize|NotOnOverflow`): the I-O emitters now all reach `EmitNotPhrase` / `EmitPhrasePair`; `CallEmitter` (PB606), `StringEmitter` (overflow) and `SortEmitter.EmitReturn` (an SD file has no I-O status or EC-I-O hook) are other mechanisms. New drift test `NotPhraseGateDriftTests` has three guards: every NOT-phrase read in either I-O emitter reaches a renderer; every `EmitNotPhrase` / `EmitPhrasePair` / `EmitInvalid` call passes the `hook` variable; `new UseHookResult(` / `default(UseHookResult)` appears only inside `EmitUseHook` anywhere in the compiler project (each watched to fail on a planted violation; the class carries the `Sweep=tree` trait).

**Goldens** (`conformance-suite/cases/14.9.10-DELETE/`): `pb3237_delete_file_handled_warning_by_use_declarative_skips_not_on_exception`, `pb3237_delete_file_handled_warning_by_when_phrase_skips_not_on_exception`, `pb3237_delete_file_unhandled_warning_runs_not_on_exception` (control). Design: `docs/FILES_DESIGN.md` "One phrase / NOT-phrase pair renderer".
