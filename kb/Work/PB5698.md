# PB5698 - FUNCTION EXCEPTION-STATEMENT has the 2023 width at 2002 and 2014

**Site:** `src/WiseOwl.Cobol.Runtime/Exceptions/EcFunctions.cs#Statement` returns `new string(' ', 63)` or
`PadRight(63)[..63]` unconditionally; its doc comment cites `§2023:15.32.3`. No edition selects the width, and the
compile-time type of the function (`IntrinsicCatalog.cs`, `EcStatement`, available from 2002) carries no width either,
so `FUNCTION LENGTH` reports the runtime value's 63.

**Rule (checked with `python scripts/spec/cite.py --check`, verdict OK on each quotation).**

- `§2002:15.27.2 RV1`: "the returned value is 31 spaces" (no LOCATION and no location saved).
- `§2002:15.27.2 RV2`: "the returned value is a 31-character alphanumeric character-string" (LOCATION specified).
- `§2014:15.29.2 RV2` says the same 31 characters (label mode: 2014 has no rule catalog). The 63-character width is
  2023's (`§2023:15.32.3`).

**Repro** (`E:/COBOL-coord/scratch/gl2002/integrate-4/repro/g2stw.cob`, a copy of the writer's
`lane1/run/g2002-7-2-19-turn-directive/defect-stmt-width/g2stw.cob`; `cobol.exe g2stw.cob --std 2002 --run`):

```cobol
       >>TURN EC-OVERFLOW-STRING CHECKING ON WITH LOCATION
       ...
       01 W-DST PIC X(3).
       PROCEDURE DIVISION.
           STRING "ABCDEFG" DELIMITED BY SIZE INTO W-DST
               ON OVERFLOW CONTINUE
           END-STRING
           DISPLAY FUNCTION LENGTH(FUNCTION EXCEPTION-STATEMENT)
           DISPLAY FUNCTION LENGTH(FUNCTION EXCEPTION-STATUS)
```

- **Expected** at --std 2002 and 2014 (RV2): `000000031` then `000000031`.
- **Observed** on a build of main d077329121: `000000063` then `000000031` at --std 2002, 2014 and 2023. 2023 is right;
  2002 and 2014 are wrong. EXCEPTION-STATUS (31 at every edition) shows the sibling is right.

**Fix shape:** the width is an edition fact of the function, read where the type is decided (the catalog's entry), not
a literal in the runtime body: the runtime takes the width from the bound call, so RV1 (spaces) and RV2 (the name) at
each edition come from one value. Sweep the other location-bearing functions (EXCEPTION-LOCATION, EXCEPTION-FILE and
their -N twins) for the same 2023-only width. The harness trims trailing spaces per line (PB475), so the witness must
show the width through FUNCTION LENGTH or a delimiter, as the repro does.

**Blocks:** `2002-RV-15.27.2-1` and `2002-RV-15.27.2-2` (no golden of theirs can land while the width is wrong).
