# PB5522 - a self-test case that needs Linux passes off Linux with its reason and the Windows gate records the file GREEN, so a landing's GREEN record claims cases that never ran

**Sites:** `scripts/selftests/inert_lane/test_watch.py` (`<module>`: the cases that print the line `the inotify arms run on Linux only` off Linux)

**Mechanism.** The inert lane's watch is inotify. Each case of `scripts/selftests/inert_lane/test_watch.py` passes off Linux with `expect("the inotify arms run on Linux only (CI's audits job and the Linux gate)", True)`, and the Windows gate records the file GREEN. A landing's GREEN record therefore claims cases that never ran on the host that recorded it; the merge group's Linux audits job is their first run (a class (b) red per CLAUDE.md). Nothing on Windows distinguishes "skipped with its reason" from "ran".

**Witness.** Case 04 of `test_watch.py` needed `scripts/mod.py`, which case 03 created until kb/Work PB5397 split the cases; case 04 stood alone and failed on Linux only. PR #1640 bounced twice (merge-group runs 43623073747 and 43624633970). Fixed on branch `worktree-wf_2e8662c7-06c-15` at deb2c04b6e06. Figures are the filing instruction's; not re-run here. The red was then also misread as INFRA (kb/Work PB5370, second witness).

**Fix direction.** A case that needs a host it is not on is recorded SKIPPED, never passed: the record carries the cases skipped and the host that must run them, and the landing checks require that host's pass before the file counts GREEN; or the cases run under WSL in the Windows gate. A drift test reads the self-test files for the "passes with its reason" line so a new Linux-only case cannot pass silently. Also filed as a finding against kb/Work PB1957 (`kb/Work/PB1957/2026-11-14-linux-only-self-test-cases-first-run-in-merge-group.md`).
