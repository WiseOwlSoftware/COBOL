# PB5042 — a report with no header fields is FINISHED to the wave but nameless to the landing

Filed 2026-11-09 by the operator session after restart. Sibling of PB3260 (a review finisher's rewrite drops the
Status line, so a DONE report reads as SPLIT). This is the other direction: the Status word is there, the fields are
not, so the report reads as FINISHED and the gap shows up only at the landing.

**Symptom.** `E:\COBOL-coord\scratch\reports\w20261949a-PB5031-report.md` began
`DONE` / `**Review:** CLEAN w20261949a-review-r1 8ead032f98…` / `# w20261949a PB5031 report`: it had the
first-line status word that `dispatch-spec-implementer.md` (REPORT paragraph) asks for, but no template header line
(`**Status:** … · **worktree:** … · **branch:** … · **base:** … · **HEAD:** …`,
`templates/implementer-report-template.md`). `reports.status_line` read `DONE`, `Report.finished` was true, the
wave reviewed the branch, and `review_findings.py stamp` put the CLEAN stamp under line 0. But `reports.BRANCH_FIELD`
found no branch, so `prune_worktrees.lifecycle` listed `worktree-wf_ae1d041e-326-1` as a DECISION ('no fix-lane report
names it') and `enqueue.py land` refused it with exit 11. w20261952a (PB5022) had the same shape and was enqueued by hand
(#1416). w20261948a (PB4952, Mythos's lane) also starts with a bare `DONE`.

**Repair done by hand (2026-11-09).** The operator replaced the bare `DONE` line of the PB5031 report with the
template's header, built from facts on disk (worktree from `git worktree list`, base from `git merge-base`, HEAD from
the branch tip, which matches the review stamp's head). The survey then read WAITING TO LAND.

**Sites:** `scripts/orchestrator/reports.py:137` (`Report.finished`), which accepts a DONE report whose header names
no branch. `.claude/skills/workstream/templates/wf_rolling_wave.js:415` (`finishedReport`) asks only that predicate
before it dispatches the review. `scripts/orchestrator/plan_wave.py:978` (`finished_main`) prints the verdict and
names no missing field.

**Fix shape.** A finished report must be attributable: `Report.finished` (the one predicate, PB3181) also requires the
branch field and a HEAD, and `--finished` prints the missing field so the wave can send the SAME agent back to
repair its header (one turn) and not turn the return into SPLIT (a whole finisher, PB3260's cost). A drift test runs
the survey over a report that `finished` accepts and asserts that the survey attributes it to its branch.
