# PB4896 - the flattened phrase numbering is untested

**What the report says (the reviewer's words).** R1-1 LEAD (low, not blocking at round 1):
`conformance-suite/cases/_unassigned/pb4856-debug-evaluate-consecutive-when.cob:40` No golden has a multi-phrase WHEN arm
followed by a later arm whose operand is the debug target, so the statement-wide phrase numbering the fix introduces
(`BoundEvaluate.PhraseOperands` flattened, `EvaluateEmitter` `phrase++` across arms) is not pinned.

**Still true on main (read, 2026-11-06).** The golden `pb4856-debug-evaluate-consecutive-when.cob` has four EVALUATEs
(`WHEN 1 / WHEN D`; the same with `WHEN OTHER`; `ALSO`; `WHEN D / WHEN 1`). In every one the multi-phrase arm is the last
arm that names D, or has no later arm naming D, so a later arm's phrase number is never compared. `BoundEvaluate.PhraseOperands`
is `Whens.SelectMany(w => w.Matches)`.
