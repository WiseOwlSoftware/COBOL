# PB5475 - at --std 85 the CODE clause refuses a figurative constant as literal-1 (CODE ALL "AB" is refused COBOL2713): a figurative constant may be used wherever a format says literal

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/ReportSectionBinder.cs` (`ReportSectionBinder.BindCodeClause`, `ReportSectionBinder.Screen85CodeLiteral`)

**Mechanism.** `ReportSectionBinder.BindCodeClause` refuses an operand whose class is not an alphanumeric literal and `Screen85CodeLiteral` counts its characters, so every figurative constant is refused as "not an alphanumeric literal". 1985 lets "A figurative constant ... be used whenever 'literal' appears in a format" (§1985:IV.4.2.2.2.3), and none of its exceptions is the CODE clause; ALL "AB" not associated with another item has the length of its literal, two. kb/Work PB1072 (landed) admits a figurative constant for SUPPRESS WHEN literal-1, the sibling.

**Found by.** The 1985 code read, read 4 (`kb/Work/PB4996/2026-11-13-read-4.md`): the reader of `E:/COBOL-coord/scratch/coderead-85/out-read4/rd-01.json`.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. Its rows are recorded naming this note (records-rd4).

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`, log `E:/COBOL-coord/scratch/op-20261113/records-rd4/cites.txt`).**

- `1985-SR-XIII.3.6.3-1` - `§1985:XIII.3.6.3 SR1` (read: PARTIAL, harm: rejects-legal-source): "Literal-1 must be a two-character nonnumeric literal". `§1985:IV.4.2.2.2.3`: "A figurative constant may be used whenever".

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-read4/work-rd-01/c8/c15.cob`:

```cobol
       REPORT SECTION.
       RD  RPT-1 CODE ALL "AB".
       01  DL TYPE IS DETAIL.
           05  LINE PLUS 1.
               10  COLUMN 1 PIC X(5) VALUE "HELLO".
```

with two `GENERATE DL`. `cobol.exe --std 85 --source-format fixed --run c15.cob`.

**Observed (the pinned compiler of `E:/COBOL-wt/coderead85-tree-d` (main 725550baca, the base of this branch), rerun 2026-11-13 from copies in `E:/COBOL-coord/scratch/op-20261113/records-rd4/rerun/`; the log is `E:/COBOL-coord/scratch/op-20261113/records-rd4/rerun-log.txt`).** `c15.cob(14,8): error COBOL2713: RD 'RPT-1': the CODE clause names ALL"AB", which is not an alphanumeric literal`, exit 65 (CODE SPACES and CODE ZERO the same, per the reader).

**Expected (from the 1985 text).** Compiles and runs; each report line begins `AB`. A figurative constant whose two-character value is fixed (ALL with a two-character literal) satisfies SR1; one whose length is not two is refused by SR1's length.

**Fix direction (root cause, CLAUDE.md rule 4).** Screen CODE literal-1 by the value it denotes: admit a figurative constant at 85 and apply the two-character rule to its value as §1985:IV.4.2.2.2.3 sizes it.
