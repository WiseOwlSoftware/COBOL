# PB6284 — one CodeGen → Binding use that is not NumericDisplayForm

**Measured (wave 20262172 group A, PB6172).** Moving `NumericDisplayForm` to `Binding.Model` took the census row
`CodeGen → Binding` from 70 to 69 (also `CodeGen.Emit → Binding` 25 → 23, `Binding.Model → Binding` 16 → 15). The PB6172 note
expected 68. No CodeGen source names `NumericDisplayForm` outside `Binding.Model` any more, so the one use above the expectation
is another type. It came in between census `ac83984` and `9e65164`.

**Why it is not found yet.** `docs/rearchitecture/architecture-edges.json` (row `CodeGen → Binding`) and the census records under
`docs/rearchitecture/evidence/arch-census/` keep namespace-pair counts only, not the types behind each count.

**Next step.** A type-level census diff between `ac83984` and `9e65164` (or `python scripts/arch/census.py` extended to list the
types per pair) names the type; then the use either moves the type to `Binding.Model` (as PB6172 did) or becomes its own
ratchet row. Its own root, separate from PB6172 and PB6173.
