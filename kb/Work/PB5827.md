# PB5827 - at --std 85 COBOL2973 refuses a data item of a sort-merge file's record as an operand of another file's statement, a restriction that first appears in 2002

**Ruling: UPHELD (a), harm rejects_legal_source, and misleads_diagnosis.** At 85 the compiler refuses (COBOL2973) a data item of a sort-merge file's record used as an operand of ANOTHER file's statement. 1985 forbids only input-output statements for the sort or merge file itself; the operand restriction first appears in 2002. The ruling's session ran it. The refusal's own text cites a 2023 rule at `--std 85`, which is the misleads_diagnosis flag. The checker's confidence: high. Severity MINOR is the clerk's choice; the ruling names none.

**Mechanism 8, ruled** (the ruling's paragraph, unchanged). `§1985:XI.3.2.3 SR3` forbids only that "input-output statements may be executed for this
sort or merge file" (cite.py OK on the words "no input-output statements may be executed for this sort or merge
file"). `WRITE OF-REC AFTER ADVANCING SW-N LINES` is a statement for another file, and its operand needs only to be
an integer item. The refusal's own text cites `§2023:13.4.6.3 SR4`; the same words first appear at
`§2002:13.3.5.2 SR4` (cite.py OK). The screen needs an edition gate below 2002.

**The checker's evidence.** 1985 SR3 forbids only input-output statements FOR the sort or merge file; no 1985 rule restricts naming an SD record's data items as operands of another file's statement, and WRITE ... AFTER ADVANCING identifier-2 needs only an integer item (`§1985:VII.4.7.3 SR4`). The restriction is new in 2002 (`§2002:13.3.5.2 SR4`, the same words as `§2023:13.4.6.3 SR4`). The compiler refuses COBOL2973 citing §2023 at `--std 85`. The gate belongs below 2002.

**Defect (the checker's summary).** At `--std 85` the 2002 and 2023 rule that an SD record's items appear in an input-output statement only after FROM or INTO is enforced (COBOL2973), though 1985 has no such rule, so legal 1985 source is refused.

**Expected:** compiles and runs at 85, printing `WROTE`. **Observed:** error COBOL2973, exit 65.

**The refusal as the run printed it** (`--std 85`, exit 65; the same COBOL2973 at `--std 2023`, where it is correct):

```text
  m8sdref.cob(21,41): error COBOL2973: WRITE 'SW-N' — 'SW-N' belongs to 'SW-REC', a record description entry of the sort-merge file 'SW', and ISO §2023:13.4.6.3 SR4: "A record description entry associated with file-name-1 shall not be specified in an input-output statement other than following the word FROM or the word INTO." Move the value to a working-storage item first, or name it in the FROM / INTO phrase.
```
