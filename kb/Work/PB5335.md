## The lead

The group C finisher fixed the binder half of the mechanism (kb/Work PB5122 addendum 2026-11-11-review-r1-1): a level-66
alias's own entry has no subordinates, so a screen that asks `Place.DenotedItem` for the item's DESCRIPTION treats
`66 GS-ALIAS RENAMES GS` as an elementary item with no members. §1985:VI.5.11.4 GR2 gives a non-THROUGH alias all of
data-name-2's attributes, and GR1 makes a THROUGH alias a group item. The binder now reads `MoveTable16.OperandItem`,
`ItemCategory.IsGroupItem` and the new `DataItem.SubordinatesOf`. The finisher found the code generator reading
`DenotedItem` for attributes at the five sites above and did not read or probe them.

## The probe owed

CALL a subprogram `USING GS-ALIAS` where `66 GS-ALIAS RENAMES GS` and GS is a group; compare the callee's view (length,
content) with `USING GS`. Repeat with a THROUGH alias and for the OO and activation-description sites. A difference is a
wrong answer; no difference discharges the note with the evidence.
