# PB5567 landing (wave 20262040, group F)

Re-probed on a Debug build: `x_swapalt.cob`'s pattern (conformance case `pb5567-external-alternate-keys-in-another-order`) was refused with COBOL6847 before the fix and prints `ALPHA` / `MAIN DONE` after. Fix: `FileEntryIdentity.Segments` sorts the ALT segment, and the COLL segment's key position for an alternate key is its name (`A:<name>`), not its index among the clauses (an index would still make the order part of the identity once ALT is sorted). Sibling sweep: the other segments either carry no clause order (OPT, ASSIGN, DELIM, RESERVE, ORG, ACC, KEY, SHARE, LOCK, PAD) or sort it already (COLL); the USING qualifiers and a SOURCE key's operands are order-significant by the rule. Closes `1985-GR-IX.2.3.4-1` (PARTIAL to CONFORMS, record_verdicts 1985: GAP 60 to 59).

## Review round 1, R1-1 (blocking): the connector's key index followed the clause order

Sorting the identity admitted describers whose ALTERNATE RECORD KEY clauses are in another order, but the one shared external `IndexedConnector` addresses an alternate key by an index, and every READ KEY / START KEY emitted the i-th clause's index of the describer that runs it: `READ IXF KEY IS IXF-ALT2` in the reordered describer read the other key (the reviewer's probe printed `READ1 FAILED`). Fix at the root: `FileEntryIdentity.AlternateKeyConnectorOrder` derives each alternate's connector index from the identity alone (sorted by the k) entry), `BackendAnswers` stores it in `FileModel.AlternateKeyConnectorIndex` for an EXTERNAL file, `KeyedIoEmitter` registers the keys in that order and names every alternate key of reference through `FileModel.ConnectorKeyIndex`. `FileModel.AlternateKeys` now carries its clause so the order is computed from the same entry string as the identity. The accepting golden now READs by each alternate key and STARTs on one in the reordered describer (expected ALPHA, GAMMA, ALPHA, ALPHA from the record contents). Sibling sweep: the only emitted key indices are `FileReadKeyedShared` and `FileStartIndexed` (grep of `KeyIndex` over CodeGen); both go through `ConnectorKeyIndex`.
