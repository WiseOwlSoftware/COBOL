# PB5752 - the Communication arm is missing from the OO section-refusal message

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/OoDefinitionRules.cs` (`OoDefinitionRules.SectionName`,
`OoDefinitionRules.AdmittedIn`, `OoDefinitionRules.RefusedBy`). `RefusedBy` refuses `OoDataSection.Communication` in a
factory, instance or method definition, but `SectionName` and `AdmittedIn` have no `Communication` arm and fall to their
`_` defaults (`"SCREEN SECTION"`, `"it may appear only in a factory or instance definition"`). The clause string
`"ISO/IEC 1989:2002 Annex A"` is not in the edition citation form of CLAUDE.md rule 1 either. A drift test
that every `OoDataSection` value has its own arm in both switches makes the next section automatic (CLAUDE.md rule 5).

**Repro:** the landed refusal cases
`conformance-suite/cases/10.5@2002-COBOL-COMPILATION-GROUP/g2-cg-method-cd-instance.cob` and `g2-cg-method-cd-factory.cob`
(a method of an instance or factory definition whose data division holds `COMMUNICATION SECTION.` and a CD).
`cobol.exe g2-cg-method-cd-instance.cob --std 2002`:

```
(26,8): warning COBOL0903: the communication facility is obsolete as of COBOL-2002 ...
(26,8): error COBOL1519: method 'M1': a method definition shall not contain a SCREEN SECTION — it may appear only in a factory or instance definition (ISO ISO/IEC 1989:2002 Annex A)
```

**The 2002 rule.** §2002:10.5.2 SR4: "The data division of a method in a class definition shall not contain a
communication section." (`python scripts/spec/cite.py --check "§2002:10.5.2 SR4" "shall not contain a communication section"`
-> OK). §2002:A: "The communications facility may be used only in a program definition." (`cite.py --check "§2002:A" "The communications facility may be used only in a program definition"` -> OK).

**Expected:** COBOL1519 naming the COMMUNICATION SECTION and saying it may appear only in a program definition, citing
§2002:10.5.2 SR4 (method) or §2002:A (factory, instance). **Observed:** both statements of the message are false for a
CD. The refusal itself is right, so the two cases landed as refusals (their expected substring is the code); no
inventory row waits on this note.
