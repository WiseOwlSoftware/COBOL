# PB5281 - on an error found before the destination loop (SEND status 50 or 60, ENABLE or DISABLE OUTPUT status 40) the ERROR KEY occurrences 1 to DESTINATION COUNT are left as they were: the early returns skip the loop that writes them

**Sites:**

- `src/WiseOwl.Cobol.Runtime/Communication/MessageControlSession.cs` (`Send`, `SetOutput`, `SendToDestinations`)

**Mechanism.** §1985:XIV.2.2.4 GR22: when the MCS finds an error during DISABLE OUTPUT, ENABLE OUTPUT, PURGE or SEND, "the content of the data item referenced by data-name-3 and the content of each occurrence of data-name-4, up to and including the occurrence specified by the content of data-name-1, are updated". The error keys are written only inside the per-destination loops; `SetOutput` returns status 40 (bad key) and `Send` returns 50 (text length too long) or 60 (no text) before the loop, so the status key is set and the error keys are not.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the non-conforming verdicts wait in `E:/COBOL-coord/scratch/coderead-85/p2-for-register.json`.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-GR-XIV.2.2.4-22` - `§1985:XIV.2.2.4 GR22` (refuter: OVERTURNED, harm: wrong-answer): "up to and including the occurrence specified by the content of data-name-1, are updated"

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-pipe/refute-slice-58/p2.cob` and `p10.cob` with their mcs.json (error keys preset to "*"): ENABLE and DISABLE OUTPUT with a wrong KEY, count 2; SEND with text length 6 of a 5-character item and with length 0 and no indicator, count 2; `cobol.exe --std 85 --source-format fixed --run <file>`.

**Observed (a build of origin/main f2cf36fd15, rerun 2026-11-11; main has since changed only `IndexedConnector.cs` under `src/`, which none of these repros reaches).** `ENA-BADKEY STAT=40 K=***`, `DIS-BADKEY STAT=40 K=***`; `LEN6 STAT=50 K=**`, `LEN0 STAT=60 K=**`.

**Expected (from the 1985 text).** Each error key 1 to count is updated (a Table 2 value for each destination; the statement-level condition needs an implementor-defined value, documented in docs/CONFORMANCE.md).

**Fix direction (root cause, CLAUDE.md rule 4).** Write the error keys in one place every error return passes through, with the value choice recorded; test each early error.
