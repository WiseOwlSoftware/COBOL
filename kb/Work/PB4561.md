# PB4561 — next-group-next-page-with-reset-not-supported: -std=cobol2014: report writer NEXT GROUP IS NEXT PAGE WITH RESET is refused ('syntax error, unexpected WITH')

Filed 2026-11-03 by `scripts/fuzz_triage.py file` from the triage of the differential-fuzz run `fuzz-batch-3000-20261103`, after an independent refuter. Upstream status `unreported`: the tracker has not been searched (owner-gated, PB3838). The run directory is git-ignored and local: the minimal program below is the repro.

## Summary

Under `-std=cobol2014`, cobc 3.2 refuses the WITH RESET phrase of the report-writer NEXT GROUP clause (`NEXT GROUP IS NEXT PAGE WITH RESET`) with a syntax error. `NEXT GROUP IS NEXT PAGE` alone compiles. Class: feature missing. Fuzz programs: fz02306 (night fuzz-batch-3000-20261103, slice D4).

## Minimal test case

Free reference format.

```cobol
IDENTIFICATION DIVISION.
PROGRAM-ID. NG1.
ENVIRONMENT DIVISION.
INPUT-OUTPUT SECTION.
FILE-CONTROL.
    SELECT RPT-FILE ASSIGN TO "ng1.out".
DATA DIVISION.
FILE SECTION.
FD RPT-FILE REPORT IS RPT.
WORKING-STORAGE SECTION.
01 N PIC 9(3) VALUE 0.
REPORT SECTION.
RD RPT PAGE LIMIT 10 LINES HEADING 1 FIRST DETAIL 2 LAST DETAIL 9.
01 HDR TYPE PAGE HEADING LINE 1.
   05 COLUMN 1 PIC 9(3) SOURCE PAGE-COUNTER.
01 DET TYPE DETAIL LINE PLUS 1 NEXT GROUP IS NEXT PAGE WITH RESET.
   05 COLUMN 5 PIC 9(3) SOURCE N.
PROCEDURE DIVISION.
    OPEN OUTPUT RPT-FILE
    INITIATE RPT
    PERFORM 3 TIMES
        ADD 1 TO N
        GENERATE DET
    END-PERFORM
    TERMINATE RPT
    CLOSE RPT-FILE
    DISPLAY "DONE"
    STOP RUN.
```

## Environment

`cobc (GnuCOBOL) 3.2.0`, WSL2 Ubuntu x86_64. Compiled with `cobc -x -free -std=cobol2014 -o p ng1.cob`; when an executable is produced it is run as `./p` under `timeout 10`. Control: the same program without `WITH RESET` compiles.

## Observed result

```text
ng1.cob:16: error: syntax error, unexpected WITH, expecting DISPLAY or DISPLAY-1 or NATIONAL or UTF-8
```

## Expected result (per ISO)

The program is legal. It prints `DONE`; the report file holds three pages, each with page heading `001` (PAGE-COUNTER is reset to 1 after every page advance) and one detail line, `001`, `002`, `003`.

- §13.18.37.2 (checked): the general format `NEXT GROUP IS { integer-1 | PLUS integer-2 | NEXT PAGE [ WITH RESET ] }`.
- §13.18.37.4, general rule 6 (checked): "If the WITH RESET phrase is present, the value of PAGE-COUNTER for the report is set to 1 (one) immediately after the page feed caused by the next page advance".
- §A.4.11 (checked): Report Writer is an optional element and the list names the "NEXT GROUP clause (13.18.37)". GnuCOBOL implements the Report Writer module (3.2 NEWS: "REPORTWRITER module added") and the NEXT GROUP clause itself, so the WITH RESET phrase is missing from a supported feature.

Edition: 2014. The 2009 committee draft (CD 1.2) prints `NEXT PAGE [ WITH RESET ]` and the same general rule 6.

## Our compiler

WiseOwl COBOL (fresh judge, `--std 2014 --source-format free`): compiles with no diagnostic; the run prints `DONE`; the report file holds pages headed `001`, `001`, `001` with detail lines `001`, `002`, `003`, exit code 0.

## Fix site

`cobc/parser.y`, rules `next_group_plus` and `next_page`: `next_page` is `NEXT_PAGE | PAGE | NEXT` with no `WITH RESET` alternative, and there is no report flag for a PAGE-COUNTER reset.

Unreported; tracker not yet searched. NEWS (3.3-dev tree) does not name it.

## Vetting (2026-11-04)

Verdict SOUND (to be reported); the refuter agrees. NEXT PAGE WITH RESET is defined by 13.18.37.4 6); cobc claims Report Writer and implements the NEXT GROUP clause (A.4.11 11)), A.4.1 makes a claimed element's rules part of the claim, and 4.2.7 requires a partial claim to be documented (all cite.py --check OK). 3.2.0 and 3.3-dev give "syntax error, unexpected WITH" and nothing in cobc or NEWS says the phrase is unsupported; no ticket matches. Lead with -std=cobol2002 (Report Writer is mandatory there and the phrase is a 2002 addition): under 2014 4.2.9 allows a subset claim, so the defect is the missing 4.2.7 documentation.
