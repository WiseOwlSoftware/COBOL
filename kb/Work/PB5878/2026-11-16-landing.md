# Landing, 2026-11-16: with both modes declared, the procedure of the mode the file is open in runs

**Re-probe before the fix** (`run_probe.py`, `r1-modes.cob`, `--std 85`): `OPEN-E2 41` ran `USE-EXTEND`, `OPEN-E4 41`
ran `USE-OUTPUT` (the attempted mode's). **After:** `OPEN-E2 41` runs `USE-OUTPUT`, `OPEN-E4 41` runs `USE-EXTEND`;
`OPEN-A2`/`OPEN-A3` still run `USE-FILE` only, and the READ legs (`47`) are unchanged.

**Shape.** One runtime selector, `FileConnector.UseModeView`, reads the opened mode first when it has a procedure, else
the statement-scoped (attempted) mode, so PB5825's arm (only one declared: it runs) is kept and the sequential, relative,
indexed and report-file modules all take the order at once (one switch, emitted by `UseTierEmitter`). 2023 from its own
text: `§2023:14.9.49.4 GR6` has the same two sentences and no order, so the same determination applies at every edition.
The determination is `docs/conformance/3/D-USE-OPEN-MODE-BOTH.md`, the register sentence of the ruling.

**Goldens.** `cases/14.9.49-USE/pb5878_use_both_modes_open_mode_runs` (sequential, INPUT/OUTPUT/EXTEND all declared;
85, 2014, 2023) and `cases/XIII.4.8@1985-USE-AFTER-STANDARD-EXCEPTION-PROCEDURE-STATEMENT/pb5878-report-file-both-modes-85`
(the report file of the ruling).
