# PB1563

Raised 2026-09-24 by the w59e (PB1053) implementer, who documented the current behaviour in docs/CONFORMANCE.md §3
D-FRA (v) as a limitation. GnuCOBOL, IBM and Micro Focus all refuse dynamic-length items in the file section, so there
is no model implementation (CLAUDE.md rule 1 precedence). Before anything reaches the owner, DERIVE: (1) what §8.5.1.11.2
('behaves as though contiguous') plus the READ general rules say the record area receives from a line — possibly the
contiguous characters with each member's length determined by its own rules (§8.5.1.10.4), which may be exactly the
take-step; (2) whether any encoding inside the line is licensed (§12.4.5.10.3 GR2); (3) whether a compile-time
warning is required. If the derivation shows today's result is what the standard requires, close this as a documented
determination with a golden; otherwise it becomes a defect. Repro: FD L in `<scratchpad 9db39f61…>\w59e\p1\fixedfmt.cob`; site `SequentialConnector.Write`
line-sequential branch.
