# PB4613 — keep every rule-exercising regression program as a per-edition golden

**The goal** (owner, restated 2026-11-04): WiseOwl.Cobol provides a comprehensive test suite for each edition of the COBOL
standard, from COBOL-85 to 2002, 2014, 2023 and, when it is released, 2027. The COBOL-85 suite is comprehensive enough to
subsume and replace NIST-85; each later edition gets an equivalent best-in-class suite.

**The gap.** Fuzz night 10's vetting and reporting (2026-11-03/04) produced many small programs that each exercise one ISO
rule, and almost none is in `conformance-suite/cases/`:
- the repros of the 47 GnuCOBOL records PB4519-PB4565 (their notes' `## Minimal test case`) and the vetters' and refuters'
  probes (`E:/COBOL-coord/scratch/fuzz-vet/step1/p/`, `step2/`, WSL `~/gc-fix/review*`);
- the attachments of the seven reports posted as bugs #1289-#1295 (`E:/COBOL-coord/scratch/mythos/gc-file-n10/drafts/*/`):
  rpt1, srchvary/srchend/srchidx/srchbad, tabcol/pcol/dcol/mrgcol/srtcol/selcol/selcol2/natcol/fdefcol, reldel/deltwice/delhole,
  divrem/divrem2/round, basfrac/basfrac2, sftfrac/sftother;
- the five sibling records PB4594-PB4598 and the probes behind PB4547/PB4577/PB4609, PB4610-PB4612;
- the night's 3,000 generated programs themselves (`E:/COBOL-coord/scratch/fuzz-batch-3000-20261103/`), which are
  git-ignored run output.
Our compiler gave the ISO result on almost all of them, so they are the regression net that keeps it so, and today
nothing runs them.

**Fix shape.** (1) A campaign that turns each program into a golden: one case per rule under the clause's folder, its
`rules` header naming the inventory rows, `accept`/`refuse-at` editions from the construct's edition edges (the 2014 side
from the 2014 FCD, PB4608), the expected `.out` derived from the ISO text (never copied from either compiler's output;
where ours differs from the rule, a defect note instead of a golden); de-duplicated against existing goldens by rule.
(2) The pipeline: `fuzz_triage.py` (or the morning step after it) proposes a golden for every judged program whose
verdict is AGREE-WITH-ISO on a rule no golden witnesses yet, so the suite grows each night without a campaign. (3) The
suite's per-edition coverage is measured against NIST-85's for COBOL-85 (which NIST features and rules have a golden),
so "subsumes NIST-85" becomes a number the burn-down reports.
