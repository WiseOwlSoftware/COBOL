# PB1921 — OPEN

Filed by the train-1004 lander from wave 1004 group A's report (`w1004a-PB1095-report.md`).

## Finding

**Site.** `tests/Cobol.Net.Tests.Unit/UnstringLiveReadDriftTests.cs:197`. The drift test asserts the UNSTRING emitter
asks the one storage-sharing predicate by scanning the compiler sources for the text `MayShare(`. Wave 1004 group A's
new `UserWordKinds.MayShare` (a word-type census predicate, unrelated to storage) turned it red at gate 1 and was
renamed `MayBeOneWord` to get past it. The test checks a NAME, not the relation it states.

**Fix shape.** Assert on the symbol (the predicate's declaring type and member, by reflection or the Roslyn
analysis the other drift tests use), so a same-named method elsewhere neither satisfies nor breaks it.
