**Mechanism and fix.** The gate read the text before the debugging comment treatment decided which of it is program text, and the lexer SKIPS a floating comment, so no token says one was there: the decision cannot be read off the stream. The gate is now two steps. `SurvivingFloatingComments.Note` (in `Frontend.Preprocess`, where it was) finds each surviving `*>` and hands it, with its line of the text the lexer reads, to `ReferenceFormatDiagnostics.NoteSurvivingFloatingComment`; `DebuggingLineRewriter.Rewrite` reports the text lines it makes comment (`commentLines`: each hidden debugging line, each line of a hidden debugging section from its header to the line before the next header, and the portion's own header and END DECLARATIVES when only debugging sections stand in it), the one place that decides it; `Frontend.Parse` then calls `ReferenceFormatDiagnostics.ReportSurvivingFloatingComments`, which issues COBOL0900 and COBOL2495 for the noted `*>` not on such a line, at the index of the bag where the gate's reports stood before (`DiagnosticBag.MoveTail`), so the order of diagnostics is the one it was. The lead was a second cause with the same symptom: the compiler wrote its own note for a COPY that brought in no text as a plain `*> COPY X — library text not found`, which the gate read as source. The note is now `*>` + U+FDD2 (`CopyProcessor.NotePrefix`, a noncharacter like the debugging-line and comment-entry carriers) and `TextWordScanner.TryNext` skips the line as a single space, so no text reader takes it for the program's.

**Sweep.** The other readers of surviving COBOL-85 text before the debugging treatment: COBOL2495 shares the gate's report and is covered by the same set (unit `SurvivingFloatingComment_OnACommentLine_IsNoIntroduction`); `Frontend.cs` sites that ask `*>` of text (`LocateEndPerform`) read physical lines for the GR14 op placement and report nothing. `grep -rn '"\*>' src` finds the four COPY note writers (all converted) and `NistPreprocessor`'s debugging-line comment, a line of the carrier form.
