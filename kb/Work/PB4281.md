# PB4281 — comment-entry after conditional compilation; the residue PB4241 left

**Sites:** `src/WiseOwl.Cobol.Frontend/Preprocessor/DivisionCursor.cs:114` (`DivisionCursor.ReadDirective`, `DivisionCursor.ConditionalGroup`), `src/WiseOwl.Cobol.Frontend/Preprocessor/ReferenceFormatProcessor.LogicalConversion.cs:178` (`ReferenceFormatProcessor.LogicalConversion.CommentEntryOf`, `ReferenceFormatProcessor.LogicalConversion.BeginsCommentEntry`), `docs/CONFORMANCE.md` (the D-CE2 deviation entry at about :2075, which must describe the current compiler and name this note).

## What happens

1. Residue (same root as PB4241, stage order). A non-standard COBOL-85 comment-entry directly after a `>>IF` group whose branches disagree on the division is read as program text: the §6.5 converter decides "which division" per physical line before conditional compilation, `ConditionalGroup.After` answers "not IDENT" when branches disagree, and a comment-entry cannot be recognised without knowing the division. The exact fix is deciding comment-entry after conditional compilation, a stage-order redesign (CLAUDE.md rule 5: the restructuring, not the smallest diff).
2. The register pointer (review R2-2, low). D-CE2 in `docs/CONFORMANCE.md` says the residue "needs a stage-order redesign registered in the PB4241 report". That report is a scratch file outside the repository and PB4241 is landed, so a current-state doc points at a register CLAUDE.md rule 8 says does not exist. This note is that register; D-CE2 must name PB4281.
3. Unverified, not probed (implementer lead 2). `>>COBOL-WORDS EQUATE "IDENTIFICATION" WITH "IDENT"` respells the header after the converter has read it, so `DivisionCursor` never sees IDENT as IDENTIFICATION (`CompilationUnitStart.cs:54` handles the unit start only). Run the probe first: a program whose header is `IDENT DIVISION.` under that EQUATE with a comment-entry in its identification paragraphs; if the entry is read as program text, it is a second instance of the same root.

## Fix

Decide comment-entry after conditional compilation (or carry the division through the group), pinned by goldens for the disagreeing-branches shape and the EQUATE shape. Replace D-CE2's pointer with this note's id in the same change.
