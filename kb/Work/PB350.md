# PB350 — a RETURN loop that never terminates from the statement

**Rows:** `FMT-14.9.34.2` (shared with **PB351**, a second, independent defect in the same format row).

## The programs

`<lane3 scratch>/out-b1/probe/p1/p1.cob` — the OUTPUT PROCEDURE body is
`RETURN SF RECORD END-RETURN. DISPLAY "R=" S-TXT. ADD 1 TO WS-N. IF WS-N < 4 GO TO DUMP-1.`
`<lane3 scratch>/out-b1/probe/p2/p2.cob` — `RETURN SF NOT AT END DISPLAY "R=" S-TXT END-RETURN.`

Both compile clean at `--std 85, 2002, 2014 and 2023` (exit 0, no diagnostic). `p1 --run` prints
`R=ONE / R=TWO / R=TWO / R=TWO` — at end-of-data the record area keeps the previous record and control falls
through, so a program that loops on RETURN never terminates its loop from the statement.

## The rule

§14.9.34.2, rendered from the printed page 738 (folio 708):

```
RETURN file-name-1 RECORD [ INTO identifier-1 ]
    AT END imperative-statement-1
    [ NOT AT END imperative-statement-2 ]
    [ END-RETURN ]
```

**The AT END line is printed with NO brackets and NO choice indicators** — unlike READ (§14.9.30.2), whose
transcription figure note records the printed bar pair. Per §5.2.6.2 brackets are the only thing that makes a
portion omissible, and per §5.2.2 an underlined keyword is required subject to those conventions, so **the AT END
phrase is MANDATORY on every RETURN**. §14.9.34.3 SR4 permits reversal only *when specified*, which does not make
AT END omissible. Both programs shall be rejected at compile time, with a named diagnostic, at all four editions.

## What the compiler does

`CobolIO.g4:679` writes `returnAtEndPhrase?` and `:690`'s second alternative writes
`NOT AT? END statementBlock (AT? END statementBlock)?`, so both the whole phrase and the AT END half of the
reversed pair are optional. `SortBinder.BindReturn:268-273` binds `atEnd = null` without complaint
(`PhraseBlocks.Split` maps a NOT-led single block to `(null, first)`) and `SortEmitter.EmitReturn:177-180` emits
an empty `else` arm. A grep for `returnAtEndPhrase` over `src` finds `SortBinder.cs:269` as the SOLE consumer, so
no later pass recovers the rule.

## The fix, and the sibling that must NOT change with it

The fix belongs in the grammar — make the phrase required, with the reversed alternative requiring both halves —
plus a negative conformance case per edition. ⛔ **`readAtEnd` must not be changed:** READ's AT END really is
optional, and that asymmetry is the whole point of measuring the two pages separately.

**Code sites:** `CobolIO.g4#returnStatement`, `#returnAtEndPhrase`.
