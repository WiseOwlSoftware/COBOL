# PB3803 — a dry run that writes

**Sites:** `scripts/orchestrator/plan_wave.py#main`, `scripts/orchestrator/plan_wave.py#run_fix_clusters`, `scripts/orchestrator/test_plan_wave.py`

## Measured

`plan_wave.py --dry-run` writes `clusters-open.json` and `clusters-half.json` (`run_fix_clusters`) and
`clusters-campaign-<lead>.json` (the `--cluster` branch's `coord.write_json`) into the coordination directory, although
the docstring says a dry run "writes nothing". Repro: any `--dry-run`, then the files' mtimes. Site: `plan_wave.py#main`
(`fix_clusters`, the `--cluster` branch).

## Acceptance

- A `--dry-run` leaves every file in the coordination directory unchanged (mtime and bytes), whichever of `--cluster`,
  the fix-clusters path and the default path it takes; the plan it prints is the plan a real run would write.
- A test in `test_plan_wave.py` runs each path with `--dry-run` against a temporary coordination directory and asserts the
  directory listing and mtimes are unchanged (it fails on the current code).
- Sweep: every other `--dry-run` flag in `scripts/orchestrator/` is checked the same way and its result reported.
