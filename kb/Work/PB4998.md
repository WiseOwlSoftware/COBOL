# PB4998 - the audit's batch requests are built in cache layers

**Found.** Anthropic's notice of 2026-11-08 reported a low prompt-cache hit rate on this account's direct API traffic,
which is the edition audit's Message Batches passes (`audit_batch.py`) and the transcriber (`transcribe_pdf.py`). Each
request was one user text block with no `cache_control`: the route pass sent the same list of every 2023 clause (about
7,000 tokens) in all 247 requests, and the map pass sent each 1985 clause's routed candidates once per rule of that
clause and kind, measured on the re-run (`state-route`) at 20.2 M of the pass's 42.6 M input characters (47 %). The price
function `usd` read input and output tokens only, so the `--max-usd` guard could not see cache writes or reads.

**Fixed.** `message_batches.py` owns the cache: `CACHE_TTL` (an hour: a batch outlives five minutes and its hits are
best-effort), `cached_text` and `cached_system`, `usage_of` (input, output, cache write, cache read from each reply) and
`usd` pricing writes at twice and reads at a twentieth of the input price on Opus 5.5. `audit_batch.prompt_parts` builds
each request in layers, most shared first: the pass's instructions (cached `system`), the group's shared part (cached
first user block: the route pass's clause list; a map request's clause candidates, `Candidates.clause`), then the item's
own part. Map items store `clause_candidates` and `word_candidates` (`map_candidates` joins them). The transcriber's
prompt is below Opus 5.5's 512-token minimum, so it gains nothing and is unchanged. The review lead w20261922b R2-1 (the
closest-first order case planted an order that was already numeric) is fixed in the same test file.

**Sites:** `scripts/spec/message_batches.py` (`CACHE_TTL`, `CACHE_WRITE_MULTIPLIER`, `CACHE_READ_MULTIPLIER`, `usd`,
`usage_of`, `cached_text`, `cached_system`, `BatchRun`), `scripts/spec/audit_batch.py` (`Candidates`, `candidates`,
`plan_map`, `map_candidates`, `plan_verify`, `prompt_parts`, `prompt_text`, `request`, `parse_answer`),
`scripts/spec/test_audit_batch.py` (`main`), `docs/rearchitecture/DESIGN-spec-conformance-review.md` (section 10.3).
