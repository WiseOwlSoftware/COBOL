# PB2609 — the landing check stops a train on work it misidentifies

Found by the train 1037t lander, 2026-10-08 00:35 PDT. `bash scripts/push-main.sh` on train 1037t (`6c7f72b78`, three
clusters, every gate green) exited 3 with two STOPs, both false:

- `worktree selftests-gate`, "dispatched earlier … It is PB1027, PB1149, PB1253, PB1311 work by its dispatch ledger".
  The branch is PB2563+PB2564 (wave 1037 R). It was built on `landing-lease` 19e35db55, this train's own PB2537 branch
  (`git merge-base --is-ancestor 19e35db55 selftests-gate` is true), so it can only land AFTER this train.
- `worktree wf_4f556902-4c1-1`, "dispatched earlier … PB1027, PB1149, PB1253, PB1311 work by its train manifest". The
  branch is PB2087's CALL/function arm from 2026-10-05. That work landed as train 1022 (DEVLOG 1895) and train 1024. The
  worktree is stale; its 5 commits are not ancestors of main only because the lander re-committed them.

## Mechanism
`scripts/orchestrator/landing_check.py#identity` names an in-flight branch's notes as the union of every dispatch-ledger
group whose DECLARED files meet the branch's ACTUAL diff (`bound = [g for g in ledger if files & g["files"]]`). It then
dates the branch by the earliest ledger `at` among those notes. A wide diff, such as a 61-file tooling branch or a
two-day-old branch whose merge-base is far behind main, meets many groups' declared sets. It therefore inherits
unrelated notes (here the same four for both branches) and the oldest dispatch time among them, and becomes
"dispatched earlier" than any current train. Two arms are missing:

1. A branch whose commits CONTAIN one of this train's member branches (or whose base is one) depends on the train and
   is never an earlier competitor.
2. A branch whose notes are already `landed`, or whose files on the branch equal main's, is stale. It should be named
   for removal, not stop a landing. `contained()` (K3) runs only when the branch's notes are unknown or overlap the
   train's, and the ledger binding makes them neither.

## Harm
Process only, but it blocks the main lane: the train that introduces the landing lease could not land, and every later
train that touches `scripts/orchestrator/*` stops the same way while either worktree exists. The brief's answer to exit
3 is "never retry as is". A false stop therefore costs an operator decision per train.

## Fix shape
Bind a branch to ledger groups by the notes its commits name or flip, or by its own train manifest, never by
declared-file overlap alone. Date it by its first commit when no dispatch names it. Add the two arms above, each as a
self-test arm reproducing this incident: a dependent branch built on a member branch, and a stale branch whose work
landed under different shas.
