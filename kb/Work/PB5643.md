# PB5643 - at --std 2002 an overflowing report SUM addition raises EC-REPORT-SUM-SIZE at the addition during GENERATE, where 2002 sets only the size error indicator and raises when the item is presented

**Sites:**
- `src/WiseOwl.Cobol.Runtime/IO/ReportWriter.cs` (whole: the reader pinned no member; the fixer names it; the report sum-counter addition and its EC-REPORT-SUM-SIZE raise)

**Mechanism.** The report engine raises EC-REPORT-SUM-SIZE at the sum-counter addition (§2023:13.18.54.4 GR3) at every edition. 2002 GR3 sets only the size error indicator; GR4 raises the condition and fills the item with spaces when it is printed. With checking on the condition is fatal, so the moment is observable.

**Inventory.** Rows claimed: `2002-GR-13.16.52.3-3`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:13.16.52.3 GR3`: "Each addition is tested for size error; if a size error occurs, the associated size error"
- `§2002:13.16.52.3 GR4`: "If the associated size error indicator is set, an EC-REPORT-SUM-SIZE exception condition is set to exist and the printable item is filled with spaces"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p3/sum_ec.cob); the text is inline. Command: `cobol.exe p3/sum_ec.cob --std 2002 --run`

`p3/sum_ec.cob`:

```cobol
       >>TURN EC-REPORT-SUM-SIZE CHECKING ON
       IDENTIFICATION DIVISION.
       PROGRAM-ID. SUMEC.
       ENVIRONMENT DIVISION.
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT PRT ASSIGN TO "SUMEC.TXT".
       DATA DIVISION.
       FILE SECTION.
       FD  PRT REPORT IS R.
       WORKING-STORAGE SECTION.
       01  WS-B    PIC 9     VALUE 0.
       01  WS-N    PIC 9     VALUE 0.
       REPORT SECTION.
       RD  R CONTROL IS FINAL.
       01  DL TYPE DETAIL LINE PLUS 1.
           05  COLUMN 1 PIC 9 SOURCE WS-B.
       01  CFT TYPE CONTROL FOOTING FINAL LINE PLUS 1.
           05  S1 COLUMN 1 PIC 9 SUM WS-B.
       PROCEDURE DIVISION.
       DECLARATIVES.
       H SECTION.
           USE AFTER EXCEPTION CONDITION EC-REPORT-SUM-SIZE.
       H-P.
           ADD 1 TO WS-N
           DISPLAY "RAISED " WS-N " " FUNCTION EXCEPTION-STATUS.
       END DECLARATIVES.
       MAIN SECTION.
       MAIN-PARA.
           OPEN OUTPUT PRT.
           INITIATE R.
           MOVE 5 TO WS-B. GENERATE DL.
           DISPLAY "GEN1 DONE S1=" S1
           MOVE 6 TO WS-B. GENERATE DL.
           DISPLAY "GEN2 DONE S1=" S1
           TERMINATE R.
           DISPLAY "TERM DONE"
           CLOSE PRT.
           STOP RUN.
```

**Observed.** GEN1 DONE S1=+5, RAISED 1 EC-REPORT-SUM-SIZE, then 'abnormal run-unit termination: EC-REPORT-SUM-SIZE (fatal): report R: an addition into sum counter 1 is a size error (ISO §2023:13.18.54.4 GR3)', rc=1.

**Expected (from the 2002 text).** no condition at the addition; EC-REPORT-SUM-SIZE when the group holding the item is presented.

**Sibling sweep.** SUM reset and rolling-forward additions; TERMINATE's additions.

**Other editions.** 2023: no (raising at the addition is 2023's GR3). 2014: unknown. 85: n/a (no EC model).
