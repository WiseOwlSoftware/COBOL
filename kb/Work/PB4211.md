# PB4211 — a forwarder kept after its mechanism moved

**Sites:** `src/WiseOwl.Cobol.Frontend/Parsing/CobolParserCoreBase.cs:802` (`CobolParserCoreBase.UsageFollowSet`, to delete;
`CobolParserCoreBase.FollowSet`, `internal static` at line 810, is the survivor),
`src/WiseOwl.Cobol.Frontend/Parsing/CobolParserCoreBase.cs:793` (`CobolParserCoreBase.pointerOperandHere`, caller 1),
`tests/WiseOwl.Cobol.Tests.Unit/PointerUsageOperandDriftTests.cs:73` (`PointerUsageOperandDriftTests.ClauseLeadingWordsCobolWordAdmits`, caller 2;
the Frontend project grants `InternalsVisibleTo WiseOwl.Cobol.Tests.Unit`, so `FollowSet` is reachable there). The forwarder's
`<summary>` (line ~801) names PointerUsageOperandDriftTests; move that sentence to `pointerOperandHere`.

**The defect (a lead from the branch review, R3-2, low).** e48103c6f replaced `UsageFollowSet`'s own cache (`s_usageFollow`) with
the general `FollowSet(atn, rule)` and kept `UsageFollowSet` as `=> FollowSet(atn, CobolParserCore.RULE_usageKeyword)`.
CLAUDE.md rule 4 forbids forwarders: when a mechanism is replaced, every caller moves and the old entry point is deleted in the
same change. `git grep UsageFollowSet -- src tests` on main at 127843f92 finds the two callers above only (the other hits are
comments in `CobolData.g4:710` and `FMT-13.18.60.2.json`, which name the test, not the method).

**Fix.** Both callers call `FollowSet(Atn, CobolParserCore.RULE_usageKeyword)` (the test passes `CobolParserCore._ATN`); delete
the forwarder; rebuild the solution. Behavior-neutral.
