# PB4426 — the admitted set after a completed operand is not the set of tokens that may follow it

**Found:** by the PB4224/PB4225 finisher (lead 2) and the round-2 review (R2-1 LEAD, a consequence of the same workaround; one note). PB4224's final fix states only what is true wherever the statement arm fires ("a statement may begin here; the token cannot begin one") and lists no expected word, because the admitted set cannot be trusted at that position.

**Mechanism.** The walk's admitted set at a position just after a completed operand (the condition or the selection object already closed) is the parser's own, taken after the construct was closed, so it lacks the tokens that would lengthen the construct: AND, OR, relational operators, THRU. Running the admitted walk from the start of the construct closed just before the token (`ClosedJustBefore` / `AdmittedAt`) restores them for IF. For `EVALUATE ... WHEN 1 5` the closed construct is the whole WHEN phrase, and the walk re-opens the superset grammar (the class-name alternative: a user-defined word and the sign words), routing the refusal into the literal-category arm ("only ZERO is expected") with a 100-word list. The finisher discarded that approach.

**Repros:** `E:/COBOL-coord/scratch/w20261819b-fin/a1.cob` and `a3.cob` (a2 and a4-a9 are the sibling probes).

**Sites:**
- `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs#OffendingPosition.Admitted`.
- `src/WiseOwl.Cobol.Frontend/Parsing/AdmittedKinds.cs#Name` (R2-1): the comment at about line 193 ("At a statement position the statement names are the one element a statement") and the noise-word guard at about line 225, `(statement ? 1 : 0)`, still count the statement element, though no arm prints Words or that element at a statement position any more (Statement implies Open, so the closed-list arm never fires there).

**Fix direction.** Make the admitted set after a completed operand a closed, derived set (the construct's continuations unioned with the follow), so a future 'expected' list is true; delete the dead statement-element counting and its comment in `Name` in the same change. Sweep every other `Admitted` consumer with a closed-list arm, and give the EVALUATE WHEN rows a golden at each edition.
