`scripts/orchestrator/orchestrate.ps1` (about line 446) sets `$tasksDir = (Join-Path $env:TEMP "claude/E--COBOL/$sessionId/tasks")` and substitutes it for `{TASKS_DIR}` in the unit prompts. The real directory on 2026-11-04 was `E:/Temp/claude/a398860f1e7c5585/<session>/tasks`, so a unit that follows the prompt waits on a path that never appears. `test_orchestrate_prompt.ps1` pins the wrong path, so its check stays green.

**Fix shape.** Find how the harness derives that directory component and compute it from the same input, or stop the unit prompts relying on the path at all. Change the test to pin the real rule.

**Sites:** `scripts/orchestrator/orchestrate.ps1`, `scripts/orchestrator/test_orchestrate_prompt.ps1`.
