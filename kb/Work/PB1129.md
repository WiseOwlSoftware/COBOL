## Measured (adjudicator / refuter evidence, verbatim)
### [generate-statement] The RD CODE clause is rejected as COBOLNET0899 'not yet implemented' in every form. As a result the GENERATE page-advance step §14.9.16.4 GR6 c), which evaluates a CODE identifier, has nothing to act on, and legal source is rejected.
- **Rows:** GR-14.9.16.4-6 — harm `rejects-legal-source`
- **Repro:** RD R-1 CODE IS WS-CD PAGE LIMIT IS 60 LINES CONTROLS ARE FINAL K1 K2. with 01 WS-CD PIC X VALUE "A" in WORKING-STORAGE (scratch out/probe/generate/g3.cob) -> error COBOLNET0899: RD 'R-1': the CODE clause (ISO §13.18.12) is not yet implemented.
- **Expected (spec):** §13.18.12.2 admits CODE IS {literal-1 | identifier-1}. The program must compile. §13.18.12.4 GR1 places the CODE value in the first characters of each logical record written for the report. GR3 evaluates identifier-1 'at the start of the processing for each body group, either during page advance processing, as detailed in the GENERATE statement, or whenever page advance processing is not performed'. §14.9.16.4 GR6 c) is that evaluation, done between the physical advance (b) and the PAGE-COUNTER step (d).
- **Observed:** DataBinder.Reports.cs BindReportDescriptionClauses rejects every reportCodeClause with DiagnosticCatalog.ReportCodeClause (COBOLNET0899, RecognizedNotImplemented). ReportWriter.AdvancePage documents step c) as 'a cited no-op'. CONFORMANCE.md A.4.11 names only 'cross-program CODE' as staged, while the binder stages ALL of CODE, so the documentation understates the gap. No open kb/Work note owns it.
- **Code site:** src/Cobol.Net.Compiler/Binding/DataBinder.Reports.cs#BindReportDescriptionClauses (reportCodeClause arm); src/Cobol.Net.Runtime/IO/ReportWriter.cs#CobolReport.AdvancePage

## What the fixer owes
Implement the RD CODE clause (literal and identifier operands) in DataBinder.Reports.BindReportDescriptionClauses and the report engine's line emission, with GR6 c)'s evaluation in CobolReport.AdvancePage. Implement FROM DESIGN-REPORT-WRITER; positive golden at the introducing edition.
