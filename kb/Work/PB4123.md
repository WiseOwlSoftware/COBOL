# PB4123 — determination owed

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/IntrinsicResultType.cs:341` (`IntrinsicResultType.IsIntegerOperand`), `src/WiseOwl.Cobol.Compiler/Binding/Procedure/SendingValueTemp.cs:141` (`SendingValueTemp.IntermediatePic`).

New defect/lead 1 of PB4036's finisher ("Needs a spec adjudication first"). §15.3 6) says an Integer argument is "an arithmetic
expression that will always result in an integer value or an integer data item", and §15.59.1 gives "All arguments integer" -> Integer.
So `MAX (A * B, 5)` (the expression's `ExpressionExtent` has scale 0, soundly) would be Integer and legal in
`PERFORM FUNCTION MAX (A * B, 5) TIMES`. `IntrinsicResultType.IsIntegerOperand(BoundOperand)` has no arithmetic-expression arm, so the
call is Numeric and refused (COBOL1646), rejecting legal source IF the reading holds. Run `cite.py --check 15.3` /
`15.59.1` on the quoted text, then adjudicate which expressions "will always result in an integer value" (a data-item scale of 0 is
sound; division, `**` and function operands are not).

**Entangled:** `SendingValueTemp.IntermediatePic(c)` (SendingValueTemp.cs:182) asks the same classifier of a held expression
(EVALUATE subjects, PB3974): an answer here changes that.

**Repro:** `p3.cob` of the PB4036 finisher (wave 20261762 group E scratch, `E:/COBOL-coord/scratch/mythos/w-n1/w20261762e/p3.cob`).
PB4036's landed note records the probe on its base: `PERFORM FUNCTION MAX (A * B, 5) TIMES` refused COBOL1646, and "a separate
classifier question, reported as a lead" (this note).
