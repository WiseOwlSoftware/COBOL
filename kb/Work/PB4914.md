# PB4914 - the citations PB4911 left

PB4911 (PR 1274, c33672fbfb) made the citations audit read the tooling, string literals included, with 0 findings over 389
files. Its implementer and reviewer left these, each sharing PB4911's root: a citation reader that does not reach every
place a citation is written.

1. **580 undecided design-doc candidates.** The ranking filter (scratch `w-citation3/w20261894a/rank.py`, the heading-word
   mismatch of PB4911's item 3) ranks bare-turned-2023 citations that may be a design doc's own section. Its top-ranked
   ones were decided; 580 remain. Decide each by reading it: a document's section names its document.
2. **Citations composed at run time.** Console output that builds a citation from pieces is never seen by a static audit:
   `scripts/spec/audit_doc_citations.py` (lines 415-428), `scripts/spec/audit_catalog_coverage.py` (209-226),
   `scripts/spec/build_inventory.py` (161), `scripts/spec/repairs/heading_depth.py` (94-100). Build each one through
   `citation.py`'s renderer, so the edition form comes from the one place that defines it, and test that the output carries
   the edition.
3. **Two readers that still skip the tooling.** `ordinal_scan` and `audit_doc_citations.py` read docs only; make them read
   the tree the citations audit reads, or record why they need not.
4. **Two low review items (w20261895a R1-1, R1-2).** The stamped DEVLOG entry of PB4911 carries no gate line; it is history
   and is not edited, but the next entry states it. `audit_code_citations.py:391` puts the example marker inside a backtick
   code span, splitting the example the comment exists to show: move the marker outside the span.

**Sites:** `scripts/spec/audit_doc_citations.py` (`main`), `scripts/spec/audit_catalog_coverage.py` (`main`), `scripts/spec/build_inventory.py` (`main`), `scripts/spec/repairs/heading_depth.py` (whole: its composed citation), `scripts/spec/audit_code_citations.py` (`OWN_HEADING`).
