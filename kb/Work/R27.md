# R27 — the argument-class lattice cannot express class INDEX or MESSAGE-TAG, so an index argument passes every 'n' screen

> R00 ledger-audit orphan (2026-08-08): F82 of `PHASE-B-15.32-15.44-findings.md`, probe-verified OPEN
> against the R10-landed tree (`5312996a`). The probe programs are reproducible from the finding text.

PROBE (2026-08-08): `SET IX TO 2. COMPUTE R = FUNCTION INTEGER(IX)` — accepted and computes 2 (prints
00000000B) though §8.5.2.1 Table 2 makes class INDEX distinct from class numeric and §15.44.3 r1 requires
class numeric. `CobolClass` has no Index/MessageTag members; `ClassOfPlace` returns null for a PIC-less
USAGE INDEX leaf and `ClassOf`'s default swallows BoundIndexRef, so `Violation()` fails open. This is the
residual that keeps CONFORMS out of reach for every 'n'/'s' row — not a re-report of the (landed, working)
PB1 mechanism. FIX (ledger): add the two CobolClass members, give ClassOfPlace a PIC-less-leaf arm keyed on
USAGE before the fail-open null, and a drift test so a new PIC-less usage cannot re-open the hole.

## LANDED 2026-08-08

Measured mechanism, two fail-opens, slightly different from the ledger's guess: an index DATA item is not
PIC-less — `PicInfo.IndexItem` carries **category NUMERIC** for the storage model, so `ClassOfPlace`
answered "numeric" (not null) and every 'n' screen passed it; an index-NAME fell into
`ClassOf1`'s generic `BoundComputedOperand => Numeric` arm. Fix: **`CobolClass.Index`** (§8.5.2.1
Table 2's distinct class, which no §15 argument rule admits — so classifying it IS the rejection), a
USAGE-keyed arm in `ClassOfPlace` riding BEFORE the category table, and a `BoundIndexRef` arm before the
generic computed arm. **MESSAGE-TAG deliberately got NO member**: the MCS facility has no `Usage` member
to classify, and a dead enum member is [[a_dead_lookup_is_also_unverified]] — instead the new
`EveryUsageMember_HasATable2ClassDisposition` drift fact (in `IntrinsicArgumentClassDriftTests`)
enumerates the Usage inventory against a dispositioned map, so the moment MESSAGE-TAG or any new usage
lands, the fact goes red until its Table-2 class is decided and wired.

Probes: `FUNCTION INTEGER(IX-ITEM)` and `FUNCTION INTEGER(IX)` both draw COBOLNET1627 "is of class
index; ISO §15.3 requires class numeric" (both computed silently before); the r7-legal contexts
(subscript, SET both directions, relation) stay green. Negative fixture `intrinsic-index-argument`
(reject-at 2002 2014 2023, both shapes). Gate: Unit intrinsic set 35/35 · Conformance Intrinsic|Corpus
660/660 · the fixture green by name · characterization 33/33.
