# PB4405 — references to the moved pipeline test classes

**Sites:** `docs/rearchitecture/DESIGN-orchestrator-loop.md` (§16), `tests/_shared/test-weights.json`, `scripts/shard_weights.py` (`main`).

PB4395 (landed in #991) deleted about 29 pipeline C# test classes and moved each rule into a script self-test. The
finisher updated the current-state docs (DOC_INDEX, plan §0, five DESIGN docs, MANDATORY-PRACTICES, landing.md and the
scripts' comments). Two places still name the deleted classes:

1. **`docs/rearchitecture/DESIGN-orchestrator-loop.md`, the per-step records (about lines 1594-1970).** They name each
   step's guard class as it was when the step was designed. CLAUDE.md rule 6 says only `DEVLOG/` holds history, so a
   design doc names the guard that holds the rule NOW: the script self-test and its arm.

   `shard_weights.py` regenerates it. Regenerate it, and check whether `shard_weights.py` (or a drift test) should refuse
   weights for a class the Unit assembly no longer has, so the next deletion cannot leave them behind.

Sweep: `git grep` each deleted class name (the list is in PB4395's landing commit) across `docs/`, `.claude/`, `scripts/`
and `tests/`, excluding `DEVLOG/`.
