# PB3135 — every unit start archives the previous unit's handoff.json as an orphan

**Sites:** `scripts/orchestrator/orchestrate.ps1` (the unit loop's orphan check and its handoff copies),
`scripts/orchestrator/test_orchestrate_handoff.ps1`.

> flags: process-only

Source: the operator, 2026-10-13 (found while reading the loop log; measured the same evening).

**Mechanism:** `scripts/orchestrator/orchestrate.ps1`, in the unit loop. Before a unit starts, the supervisor treats a
`handoff.json` it finds as a hand edit (kb/Work PB2596's orphan check, near line 607): it moves the file to
`logs\<time>-<unit>.handoff.orphan.json` and logs "a handoff.json no unit of this run wrote was archived as …: it steers
nothing". When a unit ends with a valid handoff, the supervisor COPIES `handoff.json` to `<logBase>.handoff.json` and to
`handoff.last.json` (near line 632) and leaves `handoff.json` in place. The synthesized-handoff path (near line 642)
copies as well. So the next unit start of the same run always finds the previous unit's `handoff.json` and archives it
as an orphan, with a log line that says no unit of this run wrote it.

**Measured 2026-10-13:** the run started 18:00:50Z (`logs\orchestrate-20261013-110050.out.log`) logged the orphan line
before each of its 7 unit starts (meter, resume, enqueue, wave, enqueue, wave, enqueue). Only the first of those
(18:00:51Z, the first unit of the run) could have been anything other than the previous unit's own handoff. The logs of
2026-10-12 carry 1, 5 and 8 such lines.

**Harm:** the warning PB2596 added to make a hand edit visible fires on every unit transition, so a real hand-edited
`handoff.json` is indistinguishable from the routine case, and every unit leaves a misleading `*.handoff.orphan.json`
beside its own `*.handoff.json`. Nothing is steered wrongly: `next_unit.py` reads `handoff.last.json`.

**Fix shape (for the implementer to confirm):** once the unit's handoff has been archived and made `handoff.last.json`,
the supervisor removes `handoff.json` (on the valid, invalid and synthesized paths alike), so the orphan check only
ever sees a file written between units; a `test_orchestrate_handoff.ps1` case where two units run in one supervisor
run and the second start logs no orphan, beside the existing case where a hand-written `handoff.json` is archived.

**Related:** PB2596 (the orphan check and the steer design).
