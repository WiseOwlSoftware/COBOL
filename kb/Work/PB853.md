# PB853 — OPEN — a rule with no screen, and an invented operand that now crashes

Source: the `PB506` implementer report, item (C). ⚠ Its observation has MOVED: PB506's landing routed the
fabricated figurative `SPACE` through the VALUE recipe instead of `ConvertSource`, and the re-measurement below
shows the consequence.

## Repro — re-run on this tree

`scratchpad/reg4/probe/p16b_column_no_source.cob` (PROGRAM-ID `R4P16B`), `--std 2023 --run`:

```cobol
       01 DET TYPE DE LINE PLUS 1.
          03 COLUMN 1  PIC 999.
          03 COLUMN 6  PIC X(3).
          03 COLUMN 11 PIC ZZ9.
          03 COLUMN 16 PIC X(3) VALUE "END".
```

```
Unhandled exception. CobolNet.Runtime.NotImplementedCobolFeatureException: COBOL.NET: a COBOL feature that is
not yet implemented was reached at run time: figurative 'S' in a numeric context
   at _PRG_R4P16B.__RPT_C_0_0_0()
   at CobolNet.Runtime.IO.CobolReport.PresentLine(...)
```

No diagnostic at compile time; the run unit aborts at GENERATE. (PB506 measured the older behaviour —
`[000            END]` — so both the under-rejection and the fabrication are confirmed, and the fabrication is
now worse than a wrong image.)

## The rule, quoted

```
$ python scripts/spec/cite.py --check 13.15.3 "Every elementary entry with a COLUMN clause shall also contain either a SOURCE, VALUE or SUM clause."
  OK  §13.15.3 10)  (Syntax rules)
```

## Code site and the shape of the fix

`src/Cobol.Net.Compiler/Binding/DataBinder.Reports.cs`, the `else` of the source selection —
`: [new FieldValueSource("SPACE")];   // no VALUE/SOURCE/SUM => spaces (ISO §13.15 - empty item)`. That fallback
is the compiler INVENTING an operand for a shape SR10 forbids. The fix is to DIAGNOSE the entry (COBOLNET2014 is
allocated to this rule and unused) and DELETE the fabrication; the crash then becomes unreachable for the right
reason rather than being caught.

## Sibling sweep the fixer owes

* Every other fabricated operand in `DataBinder.Reports.cs` (grep `FieldValueSource("` for constructed
  literals) — each is the same shape: a compiler-invented sender standing in for a rule it did not enforce.
* §13.15.3's neighbouring syntax rules (SR8, SR9, SR11) — whichever have no site are the same pass's work.
* The `figurative 'S' in a numeric context` staging in the numeric renderer is reachable from this fallback
  ONLY; if another caller can reach it, that is a second note.
