# PB1004 — OPEN

## Repro — measured
`scratchpad/w49f/probe/p4_gr14.cob` vs its control `p4_ctl.cob`: with the directive inside a WHEN handler, a later
zero-length reference modification outside the PERFORM runs (`LEN0=[]`, `GR14-RMZL-ESCAPED`); the control without the
PERFORM raises `EC-BOUND-REF-MOD (fatal)`. GR-14.9.28.4-14 is CONFORMS today on a TURN-only witness.

## The rule
`OK  §14.9.28.4 14)` — "An implicit PUSH ALL followed by TURN OFF ALL is assumed at the end of imperative-statement-1."
and, immediately preceding END-PERFORM, an implicit POP ALL. PUSH ALL saves EVERY directive state the PUSH directive
covers (§7.3.22), not only TURN.

## What the fixer owes
Route the implicit PUSH/POP through the same directive-state registry PB941's branch builds for explicit >>PUSH/>>POP,
so every state it holds is saved and restored. Re-verdict GR-14.9.28.4-14 with p4_gr14 as its golden.
