# PB4047 — an emitted assembly is compiled against the TPA, so an ordinary .NET host cannot build against it

**Sites:** `src/WiseOwl.Cobol.Compiler/CodeGen/RoslynBackend.cs:121` (`RoslynBackend.BuildReferenceAssemblies`, `RoslynBackend._referenceAssemblies`, `RoslynBackend.ReferenceAssemblies`); `docs/rearchitecture/DESIGN-external-repository.md` (§4.3 the host entry, §17.5 the trimmed host test it blocks); `docs/CONFORMANCE.md` (DOC-A.1-141, the host mechanism).

**What.** `RoslynBackend.BuildReferenceAssemblies` builds the reference set the generated program compiles against from
`AppContext.GetData("TRUSTED_PLATFORM_ASSEMBLIES")`, the compiler host's own implementation assemblies, plus
`AssemblyPackager.RuntimePath`. The emitted assembly therefore carries an assembly reference to `System.Private.CoreLib`
(the implementation assembly) rather than `System.Runtime` (the reference assemblies' identity). An ordinary MSBuild .NET
host project compiles against reference assemblies, cannot resolve `System.Private.CoreLib`, and fails with CS0012 ("the
type 'Object' is defined in an assembly that is not referenced") the moment it uses a type of the emitted assembly.

**Repro** (wave 20261747 A; the clerk did not re-run it): `E:/COBOL-coord/scratch/w20261747a/trim/x1` holds `Host.csproj`
(net10.0 Exe; `Reference` items with HintPaths to `WiseOwl.Cobol.Runtime.dll` and the compiled callee `P5398CALLEE.dll`)
and `Program.cs` (`Cobol.P5398CALLEE.P5398CALLEE.Call();`). It builds only because the csproj ends with a hand-added
`Reference` to the SDK's `System.Private.CoreLib.dll`. A real host cannot be asked to do that.

**Why it is a defect.** The design makes the generated public class the one host interface for .NET. DOC-A.1-141
(`docs/CONFORMANCE.md`, §14.2.3 GR13) names "any .NET language" as a supported activating product, with "the C# compiler"
checking the count and the types of `Call`; `DESIGN-external-repository.md` §4.3 specifies the class a host calls, and §17.5
and the harness paragraph (about line 2117, "a C# host compiled against an emitted assembly") specify a host built against
it. None of these texts says the host must reference the compiler's implementation assemblies, and an ordinary project
cannot. (The clerk grepped both locations: neither names reference assemblies; the contradiction is with the host build
they specify, not with a sentence about references.)

**Cure named by the report.** Compile the generated program against reference assemblies (the targeting pack's `ref/net10.0`
set, `Microsoft.NETCore.App.Ref`), keeping `AssemblyPackager.RuntimePath` as the one runtime reference, so the emitted
assembly references `System.Runtime`. Add a drift test that an emitted assembly's reference list holds no `System.Private.*`.

**Blocks.** The automated trimmed host test of `DESIGN-external-repository.md` §17.5 (a HOST-COMPOSED application: a .NET
host referencing the main program's assembly and the callee's), together with PB4048.

**Harm.** Crashes the build of a user's host, loudly (CS0012); no wrong answer.
