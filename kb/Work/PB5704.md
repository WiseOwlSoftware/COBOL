# PB5704 - at --std 2002 a user-defined function or a method raises 2023's split exception-names (EC-FUNCTION-NOT-FOUND, EC-FUNCTION-ARG-OMITTED, EC-OO-ARG-OMITTED) where 2002 raises EC-PROGRAM-NOT-FOUND and EC-PROGRAM-ARG-OMITTED, so a 2002 declarative and >>TURN for the 2002 name never see the condition

**Sites:**
- src/WiseOwl.Cobol.Runtime/Control/OmittedFormal.cs#ConditionName
- src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/EcBinder.RaiseDeclarations.cs#FunctionActivationNames
- `src/WiseOwl.Cobol.Runtime/Control/ProgramTable.cs` (whole: notFoundEc)

**Mechanism.** The (activation kind -> exception-name) choice is one 2023 table with no edition: OmittedFormal.ConditionName maps Function to EC-FUNCTION-ARG-OMITTED and Method to EC-OO-ARG-OMITTED, and the function locate miss is EcBinder.RaiseDeclarations.FunctionActivationNames ['EC-FUNCTION-NOT-FOUND'] with ProgramTable's notFoundEc. The compiler queries >>TURN for that same name, so checking enabled for the 2002 name enables nothing.

**Inventory.** Rows claimed: `2002-GR-8.4.2.2.3-5`, `2002-GR-8.4.2.2.3-7`, `2002-GR-14.8.22.3-10`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`).**

- `§2002:8.4.2.2.3 GR5`: "If the function is not found, the EC-PROGRAM-NOT-FOUND exception condition is set to exist, the function is not activated" (`cite.py --check`: OK  §2002:8.4.2.2.3 GR5  (General rules)  the text is in GR5)
- `§2002:8.4.2.2.3 GR7`: "except as an argument or in the omitted-argument condition, the EC-PROGRAM-ARG-OMITTED exception condition is set to exist" (`cite.py --check`: OK  §2002:8.4.2.2.3 GR7  (General rules)  the text is in GR7)
- `§2002:14.8.22.3 GR10`: "the EC-PROGRAM-ARG-OMITTED exception condition is set to exist" (`cite.py --check`: OK  §2002:14.8.22.3 GR10  (General Rules)  the text is in GR10)
