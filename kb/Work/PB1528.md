# PB1528 — OPEN

## The rule

Annex A.4.1 admits an optional element's syntax "only when support for that language element is claimed by the implementor"
(`cite.py --check A.4.1 "only when support for that language element is claimed by the implementor"` → OK §A.4.1), and
docs/CONFORMANCE.md §5 row A.4.2 determines that EVERY screen source shape draws a NAMED Error (COBOLNET1560 for the
data-division shapes, COBOLNET1707 for ACCEPT format 3 / DISPLAY format 2 / SET ATTRIBUTE).

## Repro (re-probed by the registrar, Debug build of `0caa7d5`, `--std 2023`)

`/tmp/adj/adj-w2-14-12-s2/probe/acc2.cob` (and the DISPLAY twin `dsp2.cob`):

```cobol
       SCREEN SECTION.
       01 SG.
          05 SI1 PIC X TO WS-X.
       ...
           ACCEPT SG
               ON EXCEPTION DISPLAY "E"
               NOT ON EXCEPTION DISPLAY "N"
           END-ACCEPT.
```

Observed: `error COBOL0307: unexpected 'ON'. A period may be missing …`, the same for `NOT`, and
`error COBOLNET0901: 'END-ACCEPT' is a reserved word …`. Expected: COBOLNET1707 naming ACCEPT format 3. The program is refused
either way (no wrong answer), but by an anonymous error pointing at a "missing period", and the §5 determination is false
for this shape.

## Code sites

`src/Cobol.Net.Frontend/Grammar/Core/CobolScreen.g4#screenTail` binds the exception phrases to the POSITIONING phrase (a recorded
deliberate cost, to stop DISPLAY stealing an enclosing statement's ON EXCEPTION arm); `AT` and the exception brackets are
independent in §14.9.1's Format 3, so the unpositioned shape falls out of the grammar before
`src/Cobol.Net.Compiler/Binding/Procedure/Verbs/AcceptDisplayBinder.cs#ScreenFormatOf` can name it.

## Fix and witness

Admit the exception brackets after an unpositioned screen operand (the stealing hazard is resolved by the operand being a
screen-name, known after binding), then refuse by name. Negative goldens `negative/a42-accept-screen-exception` and the DISPLAY
twin, each `.err` carrying COBOLNET1707. The five ACCEPT rows this note claims are NEEDS-OWNER-DECISION under PB1151 (their
verdict question); this note owns only the diagnostic defect they exposed.
