# PB5918 - the collation cache environment variables fall back silently on an unreadable value

Filed from wave 20262102 group C's lead (kb/Work PB4950's branch, which also landed PB5839). The implementer's words, unchanged:

> RuntimeConfig's collation cache variables fall back silently on an unreadable value (PB5839's sibling class; recorded in its dated file).

PB5839's dated file, unchanged:

> **Sibling inputs, not changed (lead):** `RuntimeConfig` documents `WISEOWL_COBOL_*` collation cache variables whose value "anything else = the default" (the cache size and eviction): the same silent fallback for an unresolvable value.

**The project rule** (the owner's, memory `unresolvable-fails-loudly`): an input a tool cannot resolve is a bug that fails; never a "safe" default. PB5839 applied it to `WISEOWL_COBOL_CLOCK`: `SystemClock.Now` throws `CobolImplementorFatalException` naming the variable and value for a set value that does not parse; an unset or empty variable is the default.

**What main's code reads** (the clerk, on main 74fb285036, no run): `src/WiseOwl.Cobol.Runtime/Collation/Cache/CacheConfig.cs`, `FromEnvironment`, whose summary says "Never throws: an unparsable value keeps the default". `COBOL_COLLATION_CACHE` (`SizeVariable`) takes `off`, `false`, `0` or a positive integer and ignores any other text; `COBOL_COLLATION_CACHE_EVICTION` (`EvictionVariable`) takes `fifo`, `size` or `lru` and ignores any other text. The source names `WISEOWL_COBOL_*` collation cache variables; main's constants carry the names above, so the clerk lists what the code holds.
**Not ruled:** which of these values is "unresolvable" and whether the fix throws or warns; the source names only the cache size and eviction.

**Sites:** `src/WiseOwl.Cobol.Runtime/Collation/Cache/CacheConfig.cs` (`FromEnvironment`); `src/WiseOwl.Cobol.Runtime/Collation/CollationRuntime.cs` (`Initialize`, the one caller). The latch around it is kb/Work PB380 and PB4337; the cache layer is PB106.

**Rows.** None claimed.

**Scope.** Every edition (the runtime's collation cache).
