# PB4935 - pin the file-control arm of the moved HeaderWords return

**Sites:** `tests/WiseOwl.Cobol.Tests.Unit/ClosedFormatReservedWordTests.cs` (`ClosedFormatReservedWordTests.AForeignRunEndedByAHeader_IsNamed`), `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs` (`CobolErrorStrategy.ClosedFormatResidue`)

**Report (R1-1 low).** PB4845 moved `ClosedFormatResidue`'s `HeaderWords(atn).Contains(token.Type)` return to follow the `ResidueRun` check and the `WritesAHeader`
return so a foreign run ended by a keyword header is named (`01 W-A PIC X VALEU` + `LINKAGE SECTION.` now draws COBOL1941 at VALEU). The same move changes the
FILE-CONTROL arm: a SELECT entry whose run is ended by `DATA DIVISION` or `I-O-CONTROL` is now named COBOL1970. Every new witness (the three
`InlineData` rows in `AForeignRunEndedByAHeader_IsNamed` at line 633 and the negative golden `pb4845-...json`) is a data-description entry; PB4770 pinned both arms and
PB4845 pins one. Expected: rows in `AForeignRunEndedByAHeader_IsNamed` (or a sibling theory) for `SELECT F ASSIGN TO "X" VALEU` followed by `DATA DIVISION.` and by `I-O-CONTROL.`,
asserting COBOL1970 at the foreign word, plus the plain `SELECT F ASSIGN TO "X"` + `DATA DIVISION.` control staying the missing-period report. If a probe shows the arm answers
otherwise, the fixer fixes the strategy and files that as a defect. The clerk did not run it.
