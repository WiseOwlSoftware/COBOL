# PB2116 — the oracle (DESIGN-architecture-review §4 items 1 and 2)

A refactor can change behavior through registration order, static initialization or a shared cache while every test
stays green (the PB1708 lesson). The oracle sees what tests do not. **Model:** Opus. **Prerequisite:** none.

## Output

1. `scripts/arch/capture_oracle.py`: for every program the suites compile (the corpus goldens, NIST CCVS, the
   version-matrix construct samples), at every edition, the emitted C# saved under a content-addressed path with the
   baseline sha recorded; for every negative fixture and diagnostic golden, the diagnostic stream (code, severity,
   line, column, message). The capture is reproducible from a clean checkout on Windows and Linux.
2. `scripts/arch/compare_oracle.py`: the case-by-case comparison a wave runs (never totals, `test-gate`); each
   difference is listed with its program and edition, and a wave's DEVLOG entry either shows zero differences or
   explains every one (a renamed runtime helper is the only expected class).
3. Grammar changes add the token-stream differential (the PB1715 form) and a parse-tree shape differential over
   every lexer input the suites use (§4 item 3); PB2113 and PB2114 are its first consumers.
4. A drift test: the captured population equals the suites' discovered population, so a new golden cannot escape the
   oracle.

## Rules

The capture is RECORDED at a named commit before the first restructuring wave and re-recorded after each landed
fix-lane train (a fix legitimately changes emitted C#; the oracle must be re-based, by script, never by hand).

## Landing (wave 1026 D, 2026-10-07)

Items 1, 2 and 4 landed; item 3 (the token-stream and parse-tree differential) is the named next step in
DESIGN-architecture-review.md §4.1, and PB2113 and PB2114 are its first consumers.

- **Design correction (rule 5), written into §4.1.** The recorded oracle is a MANIFEST of SHA-256 hashes, one line
  per case (`docs/rearchitecture/evidence/arch-oracle/<commit12>.manifest.json`, the only file there), never the
  emitted C# itself; the blobs go to the gitignored `TestResults/arch-oracle/<commit12>/` for local diffs.
- **The population is the suites' own, by construction.** `tests/Cobol.Net.Tests.Conformance/ArchOracle.cs#Sources`
  enrols every `[PartitionedRowSource]` of the Conformance assembly and maps each row to the compile its theory
  performs, through option builders the theories now share: `ConformanceCorpus.PositiveOptions` and `NegativeCase`
  (CorpusRunnerTests.cs), `CorpusManifest.CompileOptions` (the NIST golden run, `EditionHarness.CompileNist`,
  SpecPinnedNistTests and CompiledProgramCacheDriftTests, which each built the NIST options inline), and the
  observer cores `EditionHarness.CompileStaged` and `CompileNistObserved`. 7,357 cases at base a02b165da:
  corpus 85/2002/2014/2023 = 391/743/201/806, negative 2,437, nist/85 361 (349 green or divergent plus 12 chain
  predecessors), nist-continuity 349 per edition 2002/2014/2023, matrix 247 per edition plus 200/75/58/50 permissive
  cells at 85/2002/2014/2023.
- **Portability.** `ArchOracle.Portable` writes the repository root and each scratch directory as `<repo>` and
  `<scratch>` (native, C#-escaped and forward-slash spellings, and the bare root a default-library search prints);
  `Observe` masks the WHEN-COMPILED stamp only where `CompilationInputs.ReadsCompilationTime` says the clock was
  read. Two captures of the same tree are IDENTICAL. A Linux capture of the same commit (WSL, the linux-gate
  clone) differs in 19 NIST continuity cells only, whose diagnostics name a COPY text as the case-insensitive
  probe spelled it (`K1FDA.CPY` on Windows, `K1FDA.cpy` on Linux;
  src/Cobol.Net.Frontend/Preprocessor/CopyProcessor.cs CopybookSuffixes probes `.CPY` first), so a manifest
  records its `platform` and a wave compares captures of one platform.
- **Drift.** `ArchOracleDriftTests` (Conformance, beside the row sources it reflects over; the dispatch named Unit,
  which cannot see them) pins enrolment, row-to-case identity, portability and the one recorded manifest.

For the next implementer: `ArchOracle.Sources` is where a new partitioned population is enrolled (the drift test
names it); the host `tests/Cobol.Net.ArchOracle` has no logic; a capture is about 80 s on 32 cores, run with
`python scripts/arch/capture_oracle.py` (add `--record` on a clean tree after a fix-lane train) and compared with
`python scripts/arch/compare_oracle.py [--diff]`.
