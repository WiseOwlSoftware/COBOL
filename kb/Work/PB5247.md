# PB5247 - at --std 85 the sum counter of an alphanumeric SUM entry is not capped at 18 digits: SumCounterDigits sizes it from every non-insertion position (the 2023 rule), so a PIC X(20) entry prints a 20-digit total where 1985 gives an 18-digit counter left-aligned

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/ReportSectionBinder.cs` (`SumCounterDigits`, `SumFamilyOf`; landed: `CharacterDigits`, `Cobol85AlphanumericSumCounterDigits`)
- `src/WiseOwl.Cobol.Compiler/Binding/Model/PicInfo.cs` (`SumCounterItem`)

**Mechanism.** §1985:XIII.3.19.4 GR1 c sizes the counter of an alphanumeric or alphanumeric edited SUM entry as "the size of that data item, excluding any editing characters, or 18 characters, whichever is smaller, and the sum counter is an integer". `SumCounterDigits` takes every non-insertion position (the 2023 rule) and never applies the 18 limit, so an X(20) entry gets a 20-digit counter; GR4 then moves it into the item by the MOVE rules, giving a different image. The numeric and numeric edited arms (a, b) and the integer arm of c are right (the read's probes).

**Found by.** The 1985 code read, slice 51.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the code read's non-conforming verdicts of slices 36-56 wait in `E:/COBOL-coord/scratch/coderead-85/pipe-for-register.json`.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-GR-XIII.3.19.4-1` - `§1985:XIII.3.19.4 GR1` (read: PARTIAL, harm: wrong-answer): "or 18 characters, whichever is smaller".

**Repro (`E:/COBOL-coord/scratch/coderead-85/reprobe-85c/rw_sum20.cob`).** `01 WS-A PIC S9(3)V999 VALUE 1.005.`, `RD RPT CONTROL IS FINAL.`, a detail `COLUMN 1 PIC -9(3).999 SOURCE WS-A`, `01 CFT TYPE CONTROL FOOTING FINAL LINE PLUS 1. 05 C4 COLUMN 30 PIC X(20) SUM WS-A.`; GENERATE twice; `cobol.exe --std 85 --source-format fixed --run rw_sum20.cob`.

**Observed (the records-85c build of origin/main f2cf36fd15, rerun 2026-11-10).** The footing line holds `00000000000000000002` in columns 30-49 (twenty digits).

**Expected (from the 1985 text).** An 18-digit integer counter holding 2, moved to X(20) by alphanumeric MOVE rules: `000000000000000002` followed by two spaces.

**Fix direction (root cause, CLAUDE.md rule 4).** The counter size is an edition rule of one function; give `SumCounterDigits` the 1985 cap (and check §2002 and §2014 for where it was dropped), with the X(20) program as the test.
