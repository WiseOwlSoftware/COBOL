## Measured (adjudicator / refuter evidence, verbatim)
### [exception-conditions] propagate-directive-inert: >>PROPAGATE ON is recognized, edition-gated and BLANKED by PropagateDirectiveProcessor with no state any binder, emitter or runtime stage reads, so automatic propagation (§7.3.21.4 GR1) never happens - an unhandled fatal condition terminates the run unit inside the activated element, and an unhandled exception object skips straight to the EC-OO-EXCEPTION conversion; no diagnostic tells the user the directive is inert
- **Rows:** GR-14.6.13.1.3-6, GR-14.6.13.1.5-L2.3 — harm `wrong-answer`
- **Repro:** out/probe/exc-propagate/p1.cob: '>>TURN EC-BOUND-SUBSCRIPT CHECKING ON' at the head of the group; EXP1A has DECLARATIVES 'USE AFTER EC EC-BOUND-SUBSCRIPT' (DISPLAY "A-CAUGHT " FUNCTION EXCEPTION-STATUS, RESUME AT NEXT STATEMENT) and MAIN 'CALL "EXP1B". DISPLAY "A-AFTER". STOP RUN.'; then '>>PROPAGATE ON'; EXP1B has a 3-occurrence table, I PIC 99 VALUE 7, 'MOVE 1 TO E(I).' and no declaratives. Run with the pinned cobol.exe --run.
- **Expected (spec):** §14.6.13.1.3 6): checking is enabled, the condition is not EC-FLOW-GLOBAL-*, and PROPAGATE ON applies to EXP1B, so the condition propagates as if GOBACK RAISING LAST EXCEPTION; §14.9.18.4 GR1 b) raises it in EXP1A (checking enabled there), whose declarative runs and resumes: output 'A-CAUGHT EC-BOUND-SUBSCRIPT' / 'A-AFTER', exit 0.
- **Observed:** Observed: 'abnormal run-unit termination: EC-BOUND-SUBSCRIPT (fatal): subscript 7 is outside 1..3', exit 1; no compile diagnostic. PropagateDirectiveProcessor's own summary says the runtime semantics are deferred to PHASE-13 and 'does not yet change EC behavior'; CallEmitter.EmitPropagationPickup carries the comment 'rule 3 PROPAGATE ON: directive not implemented (residue)'. The PHASE-12 scout notes record that the P13 plan has no owning step, and no open kb/Work note owns it.
- **Code site:** src/Cobol.Net.Frontend/Preprocessor/PropagateDirectiveProcessor.cs#Process; src/Cobol.Net.Compiler/CodeGen/Verbs/CallEmitter.cs#EmitPropagationPickup; src/Cobol.Net.Runtime/Control/ProgramTable.cs (the activation boundary where an unhandled fatal condition would be converted to a staged LAST propagation)

## What the fixer owes
Carry the directive's ON/OFF span into the bound program (per-statement flag like the checking masks) and, at the fatal-disposition point, propagate as GOBACK RAISING LAST EXCEPTION when it applies (excluding EC-FLOW-GLOBAL-EXIT/-GOBACK). Goldens at 2014 (PROPAGATE's introducing edition) + the edition-gate negative.
