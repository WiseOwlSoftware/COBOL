## Measured (adjudicator / refuter evidence, verbatim)

- **Observed:** Observed: 'abnormal run-unit termination: EC-BOUND-SUBSCRIPT (fatal): subscript 7 is outside 1..3', exit 1; no compile diagnostic. PropagateDirectiveProcessor's own summary says the runtime semantics are deferred to PHASE-13 and 'does not yet change EC behavior'; CallEmitter.EmitPropagationPickup carries the comment 'rule 3 PROPAGATE ON: directive not implemented (residue)'. The PHASE-12 scout notes record that the P13 plan has no owning step, and no open kb/Work note owns it.
- **Code site:** src/Cobol.Net.Frontend/Preprocessor/PropagateDirectiveProcessor.cs#Process; src/Cobol.Net.Compiler/CodeGen/Verbs/CallEmitter.cs#EmitPropagationPickup; src/Cobol.Net.Runtime/Control/ProgramTable.cs (the activation boundary where an unhandled fatal condition would be converted to a staged LAST propagation)

## What the fixer owes
Carry the directive's ON/OFF span into the bound program (per-statement flag like the checking masks) and, at the fatal-disposition point, propagate as GOBACK RAISING LAST EXCEPTION when it applies (excluding EC-FLOW-GLOBAL-EXIT/-GOBACK). Goldens at 2014 (PROPAGATE's introducing edition) + the edition-gate negative.

## Landed — wave 73 group D2 (finisher of `worktree-wf_1a52c830-9ba-4`): the directive carries state, the fatal default reads it

**Re-probed first** on the D2 build: the note's repro (`w73d2/probe/p1.cob`) printed `abnormal run-unit termination:
EC-BOUND-SUBSCRIPT (fatal): subscript 7 is outside 1..3`, exit 1. Now `A-CAUGHT EC-BOUND-SUBSCRIPT` / `A-AFTER`, exit 0.

**Mechanism (rule 5 — the directive became a line-scoped directive like the others).** `PropagateDirectiveProcessor`
collects the ON/OFF toggles into a `DirectiveTimeline<PropagateEvent>` (PUSH/POP replayed; `DirectiveResults.PropagateEvents`;
`DirectiveStateRegistry` now CARRIES `propagate-directive-2002`), and the binder folds it ONCE per source element at
its first line — `PropagateState` → `DataBinder.AutomaticPropagation` (program / function) and
`OoMethodSymbol.AutomaticPropagationHere` (method). The fold is the timeline's new `TryLastInEffectBefore`, which
`RefModZeroLengthState` now uses too (its private copy of the same loop is gone). The emitter holds the element's
`AutomaticPropagation` (GOBACK signal + header RAISING classes) in `EcState.Propagation`, and the rule is applied
where the fatal default is decided: `EcEmitter.EmitSelection` emits `if (r == -3) <stage LAST; return>` between
§14.6.13.1.3 5) and 7) (`ExceptionState.StageAutomaticPropagation` excludes EC-FLOW-GLOBAL-EXIT/-GOBACK), the EC-I-O
arm of `__IoCheckEc` does the same (§14.6.13.1.3 3)), and the INVOKE/CALL pickup's object `-3` arm emits
`EcEmitter.ObjectPropagationReturn` ahead of item 4 (§14.6.13.1.5 item 3: the object when the activator's header
RAISING names an applicable class/interface, else EXCEPTION EC-OO-EXCEPTION). The activator's existing pickup raises
what was staged, so a chain of PROPAGATE ON elements propagates hop by hop.

**Determinations** (CONFORMANCE.md D-PROP): a NONFATAL level-3 condition is not propagated (§14.6.13.1.4 has no
propagation step); a MAIN program propagates nothing (§7.3.21.1 "to the activating runtime element"; its GOBACK
would be a STOP that ignores RAISING), so §14.6.13.1.3 7) terminates it.
