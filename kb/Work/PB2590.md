- startup, after 71 s: `FAIL: and its handoff is synthesized: got 'False', want 'True'`

then the startup one; both exit 0). The train touches no file under `scripts/orchestrator/` except `plan_wave.py`
(PB2562, PB2575), which the synthesis path does not read.

## Code site

`scripts/orchestrator/orchestrate.ps1` lines 386-387 and 496-500 call `checkpoint.py synthesize`, which runs
`git worktree list --porcelain` and per-worktree git probes (`checkpoint.py#synthesize` → `worktrees(repo)`); a `catch` turns any failure into
"handoff not synthesized". Under 60 parallel self-tests that call (or the fake unit's timing around it) does not
finish in time. Fix: find which step times out under load and either give it a deadline the test controls or mark
the two tests serial in `self_tests.py` (the CI invariant needs the gate's run and CI's run to agree).
