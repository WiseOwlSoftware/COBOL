# PB876 — LANDED

## Mechanism — the missing VEHICLE, not a missing rule

`GR-13.18.63.4-7` and `GR-13.18.63.4-8` are both recorded PARTIAL, and both records say the same thing about
why: the rule's NATIONAL leg has no vehicle. A national-edited item — `PICTURE N` with a `B`, `0` or `/`
insertion character — draws

```
COBOLNET0899: national-edited data (PICTURE N with B 0 /) is recognized but not yet implemented
```

so the population each rule's second exception is about cannot be constructed, at any edition. Both rules are
otherwise MEASURED and correct in Format 1:

- **GR7**, "Each literal is aligned in the associated data item in accordance with 14.6.8, Alignment and
  transfer of data into data items, except that initialization is not affected by a JUSTIFIED clause and no
  editing takes place." The JUSTIFIED exception is byte-measured (`PIC X(5) JUSTIFIED RIGHT VALUE "AB"` is
  byte-identical to its unjustified twin, at all four editions), and the no-editing exception is measured
  against a MOVE control into the identical picture (`PIC XXBXX VALUE "ABCDE"` gives `ABCDE` where the MOVE
  gives `AB CD`). What is unmeasurable is the same exception on a NATIONAL-edited picture.
- **GR8**, "When a numeric-edited data description includes the BLANK WHEN ZERO clause and the VALUE clause uses
  either an alphanumeric or national literal, the BLANK WHEN ZERO clause has no effect on initialization." The
  ALPHANUMERIC leg is measured with its contrasts (`PIC ZZZ9 BLANK WHEN ZERO VALUE "0000"` prints `0000`, while
  `VALUE ZERO` and `VALUE 0` print spaces and `VALUE 12` prints `  12`). The NATIONAL leg needs a
  national-class numeric-edited item, which is the same refused vehicle.
