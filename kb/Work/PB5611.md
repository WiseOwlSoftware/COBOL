# PB5611 - at --std 2002 ANY LENGTH items are accepted as CALL ... AS NESTED arguments and RETURNING item, which 2002 CALL SR10 forbids in every format

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CallBinder.cs#ScreenCallOperand` (~line 1595)

**Mechanism.** CallBinder.ScreenCallOperand computes anyLengthBanned = !formatTwo || (!isReturning && mode is Content or Value): the 2023 narrowing to Format 1 plus SR18, with no edition gate. 2002 SR10 sits under ALL FORMATS.

**Inventory.** Rows claimed: `2002-SR-14.8.4.2-10`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:14.8.4.2 SR10`: "Identifier-2, identifier-3, and identifier-4 shall not be described with the ANY LENGTH clause"
