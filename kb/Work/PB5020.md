# PB5020 - the 2023 rule catalog omits normative text that is not a numbered rule

**Sites:** `scripts/spec/extract_rule_catalog.py` (`main_2023`, `prose_paragraphs`, `unharvested_rule_blocks`), `docs/rearchitecture/spec-rule-catalog.json` (whole: regenerated with the new rows)

**Report (the 36 adjudicators of PB4995's contested 1985 records, 2026-11-09).** `extract_rule_catalog.py` makes a row
of each numbered syntax, general and argument rule and each general format. Normative text that is not one of those has
no row, so no inventory row answers to it and no 1985 change record can name it in `to`. Agents found, each with the
1985 rule it carries:

- §2023:14.5.1 Table 12 and §2023:14.5.2 (which statements and phrases are conditional), §2023:14.5.3.2 and 14.5.3.3
  prose (END- scope): the 11 1985 records `1985-GR-IV.6.4.2.1.1-*` and `1985-GR-IV.6.4.2.1.1.1-*`, KEPT with no `to`.
- §2023:10.3 and 10.4 (division begin and end; object code of a contained program): `1985-GR-X.2.3.3-1` (CHANGED),
  `-3` (KEPT), and `1985-GR-VI.2.3.3-1`, left undecided for this reason.
- §2023:14.6.2.2 (PERFORM control reset on activation): `1985-GR-X.2.4.1-3`.
- §2023:8.3.2.3.1 and 8.3.2.3 (system-name types; computer-name): `1985-SR-XVI.2.2.3-1`.
- Cited in reasons only, beside other `to` rules: §2023:9.1.6 (fixed file attributes), §2023:9.1.13.1 (the I-O status
  classes and the fatal-status rule), §2023:14.6.8.5 (alphanumeric receiving alignment), §2023:8.1.2, §2023:8.8.4.2.5,
  §2023:8.3.5, §2023:8.4.2.1 (global and external name uniqueness), §2023:8.4.2.2.1, §2023:8.4.6.1, §2023:8.6.3,
  §2023:8.6.4, §2023:8.6.6, §2023:5.2.4, §2023:8.3.2.1 and 8.3.2.2, §2023:13.8.4 (report active state), §2023:14.8.2.1,
  §2023:14.8.4.2, §2023:15.2, §2023:15.3, §2023:15.4.1, §2023:15.5.2, §2023:15.88.1, §2023:4.2.7, §2023:A.4.11, §2023:E.2.

The 15 records that name no rule are held in `E:/COBOL-coord/scratch/adj-712/adj-712-uncatalogued.json`, not recorded.

**Harm.** The 2023 inventory reports 0 GAP over 4,214 rules, but these requirements were never in its denominator, so no
verdict says the compiler meets them (the same shape as PB4968 for 1985 Section I). The 1985 lineage cannot record the
15 records above.

**Expected:** the catalog gains a row for each normative paragraph, list item or table that states a requirement and
is not already a numbered rule (a kind for prose and one for a table row, cited by clause and item, `citation.py`
parsing it), with a drift test that every normative block of the transcription is either a row or marked informative;
the new rows are adjudicated (2023) and the 15 held 1985 records recorded against them.
