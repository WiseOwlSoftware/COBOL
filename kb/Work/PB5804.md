# PB5804 - at --std 85 CLASS-ID, INTERFACE-ID, FUNCTION-ID and REPOSITORY are refused as a computer-name, though 1985 does not reserve them

**What is wrong.** CLASS-ID, INTERFACE-ID, FUNCTION-ID and REPOSITORY are refused as the computer-name of OBJECT-COMPUTER and SOURCE-COMPUTER at `--std 85`; none is a reserved word in 1985. Ruling: UPHELD (a), wrong at 85 only (refused at 2023 correctly). Harm: rejects_legal_source. The checker's confidence: high.

**Mechanism (the checker's reading).** Computer-name is a system-name (`§1985:XVI.2.2.3 SR1`); its formation is the implementor's apart from the character set (`§1985:IV.4.2.2.1.2`), and the documented determination (`docs/conformance/7/DOC-A.1-198.md`) admits any COBOL word of the edition that is not all digits. CLASS-ID, FUNCTION-ID and REPOSITORY appear nowhere in the 1985 text (the checker's grep count is 0), so they are legal computer-names at 85; TYPEDEF, freed the same way, compiles (`oc_typedef.cob`). The optional `computerName` lets the parser end the paragraph at a header word, so `ReservationGateRewriter` never frees the word. SOURCE-COMPUTER is refused the same way at 85 (`sc_classid.cob`, `§1985:VI.4.3.3 SR1`, a row outside this batch).
