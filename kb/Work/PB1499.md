## What the fixer owes

The covariant-return adapter (and the override emitter) must convert every object-reference return kind the binder admits under rule 5 — universal, class-typed, INTERFACE-typed, ACTIVE-CLASS — to the base/prototype's CLR return type, so a binder-admitted pair never reaches Roslyn as a type error. Add a drift test that enumerates the rule-5 return kinds against the adapter's cases. Goldens: interface-typed return implementing a universal prototype (IMPLEMENTS) and overriding a universal-returning base method (OVERRIDE). PB1012 still owns the golden round for the other §9.3.8.2.3 rows.
