# PB6090 - a corrected rule text may not silently stale the code reads of an edition

Source: account 2 mailbox 2026-11-22 14:52 and account 1.

PB6056 (#1952, #1954) made the landing checks refuse a branch that moves the code a stored code read names. A second way to
re-open an edition was not covered: PR #1953 corrected the 1985 transcription of six rules, which changed each inventory row's
`rule-digest` (e.g. 1985-GR-VI.6.27.4-19 and 1985-FMT-VI.2.4.2), so their stored reads went stale (`code_read_store.outcome`:
the read's digest is not the row's) and `edition_status.py` 1985 gained six code-read terms, every landing check green. PB6056's
sweep had put the stale arm among the changes "made by a deliberate catalog edit, visible in the diff": the catalog edit is
visible, its effect on the reads is not.

**Sites:** scripts/spec/code_read_landing.py (`check`, `refusal`); scripts/spec/code_reads.py (`staled_by`);
scripts/spec/code_read_store.py (`outcome`, `owed`)

## Landed (wave 20262138, group F)

**Fix.** One check, one rule: `code_read_landing.py` also asks `code_reads.staled_by(head_ctx, base_ctx, records)`: a record that
decided its row on main (`outcome` confirmed or contradicted against main's rows) and leaves the row `owed` at the head (the audit's
and `edition_status.py`'s own predicate, so a deleted row or one closed without a read is not refused). It names each row with both
digests and the remedy (re-read on the branch, `code_reads.py import --replace` against the corrected text); a branch that carries the
re-read passes, a change that changes no rule text passes, a row already stale on main is not this change's. The base context is
`context_at(year, root, base)`, as committed at main.

**Verified read-only.** `python scripts/spec/code_read_landing.py --rev 239834a8bb --base 09e224d38f` (#1953's merge commit against
its first parent) exits 1 naming six rows: 1985-FMT-VI.2.4.2, 1985-GR-VI.6.27.4-19, 1985-GR-VI.6.27.4-20, 1985-GR-VIII.4.6.4-13,
1985-GR-IX.4.6.4-16, 1985-GR-X.5.2.4-4.

**Self-tests:** `case_23` to `case_25` of `scripts/selftests/spec/code_reads/test_code_reads.py`.
