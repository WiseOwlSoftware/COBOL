# PB3680 — the packed and float decoders' new ImageByte path is unwitnessed

**Sites:** `src/WiseOwl.Cobol.Runtime/Values/Numeric/CobolNum.Image.cs` (the packed-decimal decoders at about lines 449 and

(`conformance-suite/cases/` and `tests/WiseOwl.Cobol.Tests.Unit/`).

## What is missing

PB547 moved the packed-decimal and floating-point-bits decoders to `StorageByte.ImageByte`. Only the COMP binary view
and the bit/national windows are pinned. No test reads a PACKED-DECIMAL or FLOAT view (REDEFINES over an alphanumeric
item) whose item holds a code unit above U+00FF, so the refusal path (EC-DATA-CONVERSION through `ImageByte`) of those
two decoders is unwitnessed. The expected result for such a view is a spec question (the PB547 determination and ISO
§14.6.13.2 / the storage-image rules); the implementer derives it, the clerk does not.
