# R57 — the harness source format

Measured by the reference-format research (PB1757): `InitialReferenceFormat.Auto` reads all 58 column-7 `>>` goldens as free form (its "text past column 72" rule), and 2,905 of 3,576 conformance sources as free form; under the CLI's fixed default 181 positive goldens fail (55 are the column-7 `>>` files, 126 have code past column 72 or in columns 1-7). **Owner: switch the harness to the CLI default (fixed) and tag the goldens that genuinely need free form** with the `source-format` option `tests/conformance/README.md` now documents, so the fixed-form tests test fixed form. The mis-formatted goldens are corrected (directive to column 8) rather than tagged where the source is fixed-form text.
