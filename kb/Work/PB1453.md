# PB1453 — OPEN

## The rule (every citation re-run by the registrar through `cite.py --check`)

> the EC-PROGRAM-NOT-FOUND exception condition is set to exist and the value of the address-identifier is the predefined address NULL

`python scripts/spec/cite.py --check 8.4.3.13.4 "…"` → `OK  §8.4.3.13.4 4)  (General rules)`

## Refuter evidence — row `GR-8.4.3.13.4-4` (PARTIAL)

PARTIAL — The NULL-value half conforms on every surface. The 'EC-PROGRAM-NOT-FOUND is set to exist' half is broken on two surfaces. (1) Relation operand: with >>TURN EC-PROGRAM-NOT-FOUND CHECKING ON, the IF emits EntryOfOperand("NOSUCHP", false), so the condition is never set. EXCEPTION-STATUS stays blank, no declarative runs and execution continues. The adjudicator's note says this surface raises the fatal condition; the probe shows it does not. PtrEmitter.ProgramAddressText reads ecState.Info for the carrying statement, and inside a condition that yields no enabled entry. (2) SET surface: the condition is set, but it is processed as nonfatal. EC-PROGRAM-NOT-FOUND is Fatal in Table 13, so §14.6.13.1.3 items 5 and 7 require abnormal run-unit termination once checking is enabled, whether the USE declarative completes normally or no declarative applies. Instead SET continues with the next statement. Only the CALL-argument surface (pb239) behaves correctly (declarative, then abnormal termination).

**Code site.** src/Cobol.Net.Runtime/Control/ProgramTable.cs#EntryOf; src/Cobol.Net.Runtime/Control/ProgramRegistry.cs#EntryOfArgument; src/Cobol.Net.Runtime/Control/ProgramRegistry.cs#EntryOfOperand; src/Cobol.Net.Compiler/CodeGen/Verbs/PtrEmitter.cs#EmitSetEntry

## What the fixer owes

One raise path for the program-address lookup shared by SET, CALL argument, INVOKE argument and relation operand (PtrEmitter.ProgramAddressText must see the carrying statement's EC state inside a condition too), and the fatal-condition processing of §14.6.13.1.3 items 5/7 on every surface. Goldens: checked relation (declarative runs, then abnormal termination), checked SET (same); keep ec1/ok2 as the unchecked NULL witnesses.
