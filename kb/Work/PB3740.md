# PB3740 — 375 of 771 reports state no turns figure

**Sites:** `scripts/orchestrator/turns_by_group_size.py#measure`, `.claude/skills/workstream/templates/implementer-report-template.md` (the Status line, which carries `**turns:** N of cap`), `.claude/skills/workstream/check_practices.py#check`.

On 2026-10-25 `turns_by_group_size.py` left out 375 of 771 `w*-report.md` files because they state no turns figure (`skipped["no turns figure"]`). The fit that sizes the fix-lane group (PB3704, PB3718) is drawn from the other half, and the missing half is not a random sample (reports from the older template, and reports an implementer ended by SPLIT).

Fix: a rule that a group report states its turns (the report template's Status line already has the slot; `check_practices.py` should refuse a report template or brief that drops it, and the report checker the loop runs on a returned report should name a report without the figure), so the next fit is honest. Measure first whether the 375 are old reports (before the template carried the slot) or current ones; only the current ones need the rule.

(2026-10-25, wave 20261107 group A.)
