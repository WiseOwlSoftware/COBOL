## Finding — `subscripts` (under-rejects; rows `SR-8.4.2.3.3-4`)

**Mechanism.** The table(ALL) intrinsic-argument arm renders its non-ALL subscripts through ReferenceResolver.RenderIndexSegment, which carries no index-name collector, so §8.4.2.3.3 SR4's association screen (ScreenIndexNameAssociation, run only by ReadSubscripts) never sees them - the second arm of a two-arm subscript dispatch

**Repro.** 01 T1. 05 E1 PIC 9 OCCURS 3 INDEXED BY IXA.
01 T2. 05 R2 OCCURS 3 INDEXED BY IXB. 10 E2 PIC 9 OCCURS 3.
PROCEDURE DIVISION. SET IXA TO 2. DISPLAY FUNCTION SUM(E2(IXA, ALL)). STOP RUN.  (--std 2023)

**Expected from the spec.** Compile-time refusal (COBOLNET1961): §8.4.2.3.3 SR4 'Index-name-1 shall correspond to a data description entry in the hierarchy of the table being referenced that contains an INDEXED BY phrase specifying that index-name' - IXA is declared on T1, not in E2's hierarchy. The same reference outside the ALL argument (`E2(IXA, 1)`, `C2(IXA)`, `ADDRESS OF E2(IXA)`) IS refused.

**Observed / reasoning.** Compiles clean and prints 0 (pinned adj-d2 cobol.exe). IntrinsicBinder.TryBindAllArgument -> ctx.Refs.RenderIndexSegment(innerSegs[i]) -> RenderSegment(tokens, Subscript) with no List<IndexUse>; ReadSubscripts (the only ScreenIndexNameAssociation caller) is never reached for this argument. Fix shape: have the ALL arm read its segments through the same collector-bearing interpreter (or call the screen with the resolved index uses) so the SR4 screen lives on the one reading every arm shares.

**Code site.** src/Cobol.Net.Compiler/Binding/Procedure/Verbs/IntrinsicBinder.cs#TryBindAllArgument (line ~2831); src/Cobol.Net.Compiler/Binding/ReferenceResolver.cs#RenderIndexSegment / #ScreenIndexNameAssociation

## What the fixer owes

The second arm of a two-arm subscript dispatch: IntrinsicBinder.TryBindAllArgument reads its segments through the collector-bearing interpreter (or calls the screen with the resolved index uses), so SR4 lives on the one reading every arm shares. Negative golden (COBOLNET1961).
