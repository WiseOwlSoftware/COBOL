# PB4313 - Shape-only refusals delegated to the bind (COBOL1689 ADD without TO/GIVING; COBOL1970/1941 unknown clause runs) are lost whenever the unit has any parse error; the trade-off is recorded only for the area pass

Found by the Mythos front-end review, gap pass, 2026-10-31 (GAP-REVIEW.md, G4-4; artifact https://claude.ai/artifact/KaxkLe85tfZBZ3nZ1tDGTs). Pin d7daee1cf.

**Sites:** `src/WiseOwl.Cobol.Compiler/CompilerDriver.cs:154-157`; `src/WiseOwl.Cobol.Compiler/Validation/ClosedFormatPass.cs` (whole: the pass to run over error-free contexts); `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ArithmeticBinder.cs` (COBOL1689, to extract); `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.Switches.cs:1479` (`AlphabetCodeName`, stays at bind, PB1942); `docs/rearchitecture/DESIGN-frontend-grammar.md:1134` and section 3.10; `src/WiseOwl.Cobol.Frontend/Grammar/CobolParserCore.g4:1254` (comment).

**Finding.** Refusals the superset grammar delegates to the bind (ADD with neither TO nor GIVING -> COBOL1689, section 14.9.2.2; ALPHABET ... STANDARD-3 -> COBOL1907; an unknown clause run -> COBOL1970/1941 by name) are not reported when the unit has any parse error, because CompilerDriver.cs:154-157 returns FrontendError before the bind; a second compile finds faults the first one parsed and dropped (`m2`/`i2`, `m4`, `i29`). Nothing is false; the faults surface on the second compile. The trade-off is recorded only for the area pass (DESIGN-frontend-grammar.md:1134); section 3.10 and the CobolParserCore.g4:1254 comment do not state it.

**Fix direction.** Fix only for truly shape-only checks: ClosedFormatPass, and the ADD/SUBTRACT format shape once extracted from ArithmeticBinder into a tree pass, run over contexts without an exception or error node. COBOL1907 stays at bind: DataBinder.AlphabetCodeName reads the unit's constant declarations (PB1942); section 12.3.7.3 SR15 makes the code-name set implementor-defined. Reconcile with the unknown-clause-keyword note (G4-3) so one word is never named twice.

**Citations checked** (`python scripts/spec/cite.py --check`): section 14.9.2.2 "Format 2 (GIVING)"; section 12.3.7.3 "The implementor shall specify the names supported for code-name-1 and code-name-2 in the ALPHABET clause".

**Evidence.** E:/COBOL-coord/scratch/w-gr2/GAP-REVIEW.md (sections 2 and 5.1); G4/m2, m4, i2, i29; review-G4.md. Probe names are copied from the shard reports; the refuter folders are E:/COBOL-coord/scratch/w-gr2/G*-refute/. Shard reports: E:/COBOL-coord/scratch/w-gr2/review-G*.md.
