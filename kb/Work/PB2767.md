# PB2767 — prohibition rules need a rejection witness

**Owner decision, 2026-10-08 (kb/Work PB468 Q7, asked in plain words):** before zero GAP is claimed, every rule that
forbids something in a user's program needs a witness that the compiler REJECTS a program breaking it, not only a legal
program that works. A row whose only evidence is a passing program goes back to GAP until a negative witness exists,
and the compiler is fixed wherever it does not reject (an `under_rejects` defect, filed as its own note).

## Rough measure (main 9fa72ad44, 2026-10-08)

A regex over each row's `test-ref` (no `negative`, `reject`, `diagnos` or diagnostic-code token) and an empty
`derivation`: **384** SR/AR rows in state OK (364 CONFORMS, 20 DOCUMENTED-NON-SUPPORT). That over-counts: some syntax
rules restrict nothing (a permission, a definition, "may"), and a unit test can witness a rejection without those words
in its name. The 2026-09-04 count that prompted the question was about 120.

## What closes it

1. **Classify exactly.** Over `spec-rule-catalog.json` and the inventory: which rows impose a prohibition on the user's
   program (a "shall" / "shall not" whose violation a conforming implementation must diagnose — §4.2.1 for the
   compiler's obligation; cite-check the clause in the classifier's doc), and for each such OK row whether its
   witnesses include one that feeds a violating program and asserts the diagnostic. The classifier is a script with a
   self-test, not a hand list (CLAUDE.md rule 8).
2. **Re-open.** Each prohibition row with no rejection witness goes to GAP through `record_verdicts.py` with this note
   as the reason, so the burn-down shows the true remaining work.
3. **Guard.** `SpecTraceabilityInventoryDriftTests` (or `record_verdicts.py`) refuses a CONFORMS verdict on a
   prohibition row whose witnesses include no negative fixture or rejection-asserting test, so the class cannot regrow.
4. Witness the rows: a negative fixture per rule (or a table test under PB2768), fixing the compiler where the violation
   compiles clean.
