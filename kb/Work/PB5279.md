# PB5279 - RECEIVE INTO a subscripted or reference-modified identifier-1 whose subscript reads an item of the CD writes the message to the place the subscript names AFTER the MCS updates the CD: EmitReceive stores the CD area first and evaluates identifier-1's place again

**Sites:**

- `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/CommunicationEmitter.cs` (`EmitReceive`)
- Landing: `EmitReceive` freezes identifier-1 through `PlaceIdentification.Freeze` before the MCS call; witness `conformance-suite/wiseowl/cases/_unassigned/pb5279_receive_into_subscript_reads_cd`.

**Mechanism.** Subscripts and reference modifiers are "evaluated only once as the first operation of the execution of that statement" (§1985:IV.4.3.8), and RECEIVE transfers the text to "the area referenced by identifier-1" (§1985:XIV.3.5.4 GR3, GR8, GR9). `EmitReceive` passes identifier-1's image (read at the old subscript) to the MCS, stores the CD area (TEXT LENGTH among it), and then writes the result back through identifier-1's place evaluated again, so `INTO ENT (IN-LEN)` lands in the occurrence the NEW text length names, carrying the old occurrence's unoccupied characters with it.
