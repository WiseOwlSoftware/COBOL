# PB5657 - goldens PB5602's fix has no witness for

PB5602 (landed) made `--std 2002` read a subscripted data-name-n operand in RECORD KEY, ALTERNATE RECORD KEY, RELATIVE KEY, the key-level COLLATING SEQUENCE
and the report CONTROL clause. Two arms of that fix are witnessed only by a reviewer's probe, not by a golden.

**1. Keyed I/O through a subscripted key (R1-2 LEAD, low).** "`conformance-suite/cases/12.3.4.12@2002-RECORD-KEY-CLAUSE/pb5602-indexed-keys-subscripted-2002.cob:1`
no WRITE INVALID KEY (22), DELETE or START INVALID KEY (23) through a subscripted key in the goldens (coverage only; the reviewer's probe shows the
behaviour right)." The fix adds a golden (an indexed file whose RECORD KEY is `K(2)`, an ALTERNATE KEY likewise) that: WRITEs a duplicate to status 22 with
INVALID KEY, DELETEs a missing key to 23, STARTs past the last key to 23, each with its `.out`, at `--std 2002` (`accept: [2002]`).

**2. RESET ON naming a non-CONTROL occurrence (R2-2 LEAD, low).** "`conformance-suite/cases/13.16.15@2002-CONTROL-CLAUSE/pb5602-control-footing-other-occurrence.cob:1`
R1-1's fix serves both TYPE CH/CF and SUM RESET ON through ControlLevelOf, but only the TYPE CF arm got a refusal golden; no golden refuses RESET ON naming a
non-CONTROL occurrence at --std 2002." The fix adds a refusal golden beside it (a `.cob` plus its `wiseowl/diagnostics/<id>.json`, `refuse-at: ["2002"]`,
the diagnostic the existing TYPE CF golden uses, COBOL0899): a CONTROL clause naming `T-C(1)` and a `SUM ... RESET ON T-C(2)`. Its `rules:` row is the RESET ON
rule's own (`§2002:13.16.55.2`'s operand rule is for TYPE CF; take the RESET ON clause's SR from the 2002 catalog with `cite.py --find`, not by inheriting
PB5602's row, which is itself wrong: PB5656).

**Sites:** none (new conformance-suite goldens only, no code file): `conformance-suite/cases/12.3.4.12@2002-RECORD-KEY-CLAUSE/` and
`conformance-suite/cases/13.16.15@2002-CONTROL-CLAUSE/` and `conformance-suite/wiseowl/diagnostics/`.

**Sibling sweep.** Each operand PB5602 reads at 2002 (FILE STATUS, RELATIVE KEY, RECORD KEY, ALTERNATE KEY, COLLATING SEQUENCE key operand, CONTROL, TYPE CH/CF,
RESET ON, READ/START KEY) with one golden arm per statement that reaches it (write, delete, start, read, rewrite) and one refusal arm each, so a regression in
any is a red. `ReportControlRef.Subscripts`, `RecordKey.Subscripts`, `Place.ConstantOccurrence` are the members the arms exercise.
