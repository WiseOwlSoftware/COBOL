# PB5639 - at --std 2002 (and 2014) an indexed READ PREVIOUS immediately after OPEN returns the last record with status 00, where 2002 requires at end with status 10

**Sites:**
- `src/WiseOwl.Cobol.Runtime/Control/DialectBehavior.cs#Table` (the row IndexedReadPreviousAfterOpenAtEnd, from-edition 2023)
- `src/WiseOwl.Cobol.Runtime/IO/IndexedConnector.cs#SelectSequentialRecord` (the IsActive(IndexedReadPreviousAfterOpenAtEnd) arm)
- `src/WiseOwl.Cobol.Runtime/IO/IndexedConnector.cs#LowestKey` (new: the OPEN file position indicator's value)
- `src/WiseOwl.Cobol.Compiler/CodeGen/UseTierEmitter.cs` (doc comment only)

**Mechanism.** DialectBehavior.IndexedReadPreviousAfterOpenAtEnd is banded 2023-only, so IndexedConnector.SelectSequentialRecord gives editions before 2023 'the first existing record'. 2002 itself sets the file position indicator of an indexed file to the lowest ordinal characters at OPEN (GR12), so PREVIOUS finds no key less than or equal to it and GR18's no-record sentence applies; the GR18 NOTE says the same. kb/Work PB344 (landed) derived the pre-2023 answer from §2023 Annex E.2 item 22 alone, because the pre-2023 text was not held then (its own caveat says the prior rule had to be recovered); the 2002 text now held contradicts that derivation. The goldens conformance-suite/cases/14.9.30-READ/pb344_read_previous_indexed_2002.out and _2014.out pin the wrong answer (P1=K002|00).

**Inventory.** Rows claimed: `2002-GR-14.8.29.3-18`, `2002-GR-14.8.26.3-12`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:14.8.26.3 GR12`: "When the organization is indexed, the file position indicator is set to the characters that have the lowest ordinal position in the collating sequence associated with the file"
- `§2002:14.8.29.3 GR18c2`: "If PREVIOUS is specified, the first existing record in the physical file whose record number or key value is less than or equal to the file position indicator"
- `§2002:14.8.29.3 GR18`: "If no record is found that satisfies the above rules, the file position indicator is set to indicate that no next or previous logical record exists, the I-O status value associated with file-name-1 is set to '10', the at end condition exists"
- `§2002:14.8.29.3 GR18`: "normally get an at end condition for indexed"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p3/prev-open-ix.cob); the text is inline. Command: `cobol.exe p3/prev-open-ix.cob --std 2002 --source-format free --run`
