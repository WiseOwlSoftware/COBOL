# PB6175 — a diagnostic's citation is pinned to the 2023 rule or left empty at another edition

**Mechanism.** The PB4950 rule: a diagnostic cites the rule of the edition being compiled under (`EditionInfo.Cite` /
`CiteRule`, one argument per edition). Three sites pass the 2023 text, or `""`, for an edition whose own rule differs. One
mechanism (an edition argument of a citation helper left pinned or empty), found by three separate landed branches.

1. **PB5618** (`w20262163a-PB5618-report.md` R1-1). `EcRaiseSite.GlobalDeclarativeCite` fixes the edition citation only for EXIT
   at 2002 and pins `y2014` to the 2023 number. At 2014 COBOL2102 cites §2023:14.9.14.3 SR2 where 2014's own rule is
   §2014:14.9.13.2 SR2. GOBACK at 2002 and 2014 cites §2023:14.9.18.3 SR1 where the editions' own rules are
   §2002:14.8.17.2 SR1 and §2014:14.9.17.2 SR1 (the reviewer ran `cite.py --check` OK on each).
2. **PB5702** (`w20262163c-PB5702-report.md` R1-2). The `NotPermitted` arm of `CobolCharacterRepertoire.Violation` still cites the
   2023 Annex B rules at 2002 (left "for the clerk" because that file was not changed in the round).
3. **PB5725** (`w20262163g-PB5725-report.md` R1-1). Both COBOL0718 messages in `TurnDirectiveProcessor` pass an empty `y1985`
   citation to `EditionInfo.CiteRule` (the new repeated-name diagnostic, and the pair diagnostic that cited §2023:7.3.25.3 SR3
   before). `ParseTurn` still runs below 2002, so at `--std 85` the message prints an empty citation `()` beside COBOL0900; the
   class doctrine (`Below2002_TheNameWindowAddsNoSecondDiagnostic`, `tests/WiseOwl.Cobol.Tests.Unit/TurnDirectiveExceptionNameTests.cs`)
   is that below 2002 the directive refusal alone speaks.

**Fix shape.** Give each arm its edition's own rule (re-derived, `cite.py --check`), or, where an edition has no such rule, make the
diagnostic not print a citation (case 3: the 1985 turn-directive path adds no second diagnostic). Then sweep every
`CiteRule("` / `Cite(` call with an empty or 2023-only edition argument and add a drift test so a citation helper cannot be
called with an empty edition text.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/EcRaiseSite.cs:71` (`EcRaiseSite.GlobalDeclarativeCite`),
`src/WiseOwl.Cobol.Editions/CobolCharacterRepertoire.cs:181` (`CobolCharacterRepertoire.Violation`),
`src/WiseOwl.Cobol.Frontend/Preprocessor/TurnDirectiveProcessor.cs:124` (`TurnDirectiveProcessor.ParseTurn`)
