# PB5287 - a DISABLE or ENABLE whose KEY equals a system password that ends in a space is answered 40 (password invalid): MessageEndpoint.Admits trims trailing spaces from the KEY value but not from the defined password

**Sites:**

- `src/WiseOwl.Cobol.Runtime/Communication/MessageStoreState.cs` (`Admits`)

**Mechanism.** DISABLE and ENABLE are honored "only if literal-1 or the content of the data item referenced by identifier-1 match the system password" (§1985:XIV.3.2.4 GR7, §1985:XIV.3.3.4 GR6). `MessageEndpoint.Admits` trims trailing spaces from the KEY only, so a defined password with a trailing space ("AB ", or " ") can never be matched, and the definition reader accepts such a password silently. The refuter also found that an omitted KEY phrase is honored against a passworded endpoint; GR6 and GR7 state no exemption for it, so that reading is to be decided and recorded in docs/CONFORMANCE.md with the fix.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the non-conforming verdicts wait in `E:/COBOL-coord/scratch/coderead-85/p2-for-register.json`.

- `1985-GR-XIV.3.3.4-6` - `§1985:XIV.3.3.4 GR6` (refuter: OVERTURNED, harm: wrong-answer): "match the system password"

**Observed (a build of origin/main f2cf36fd15, rerun 2026-11-11; main has since changed only `IndexedConnector.cs` under `src/`, which none of these repros reaches).** `D1 'AB ' 40`, `D1 'AB'  40`, `D3 KEYX  40`, `D3 ' '   40`, `Q1 ' '   40`.

**Expected (from the 1985 text).** `D1 'AB ' 00` (the key matches the password), likewise D3 and Q1 with a key of one space; or the definition refused (status 91) and the choice documented.

**Fix direction (root cause, CLAUDE.md rule 4).** Compare KEY and password as COBOL alphanumeric operands (the shorter padded with spaces) in `Admits`, decide the omitted-KEY reading, and test both.
