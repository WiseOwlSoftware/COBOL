# PB3702 — a finisher waits for the gate by grepping a log name other finishers share

**Sites:** `.claude/skills/workstream/templates/finisher-brief.md` (step 2, the `until grep -q "=== BUILD-LOCAL GATE: " <log>` recipe), `.claude/skills/workstream/templates/dispatch-spec-implementer.md` (the gate wait at line 39, `until grep -qE "=== BUILD-LOCAL GATE: " "<log>"`), `.claude/skills/workstream/templates/MANDATORY-PRACTICES.md` (P2, which names the same grep-a-log recipe).

## What happens

Finishers (and implementers) that a single session dispatches share that session's scratchpad. The brief tells each to start
`pwsh scripts/build-local.ps1 -Priority BelowNormal` into a log and block on `=== BUILD-LOCAL GATE: ` in that log. When two
agents pick the same log name in the shared scratchpad, the second one's `until grep` returns on the FIRST agent's verdict
line: it reads another worktree's GREEN as its own (a false green) and returns DONE with a gate that never covered its tip.

Two finishers hit it on 2026-10-24: wave 20261104 A3 (`worktree-wf_5669d89a-9c0-19`, gate run
`000002-20261025T054950Z`) wrote its verdict into the `gate.log` that wave 20261106 group A's finisher
(`worktree-wf_12e98f2a-957-1`) was blocking on. Group A's finisher noticed, and both confirmed their own result with
`run_gate_legs.py --await <run>`, which reads the run directory's `verdict.json`, never a shared log. Evidence: the `## Finisher`
sections of `E:\COBOL-coord\scratch\reports\w20261104a3-PB3660-report.md` and `w20261106a-PB3446-report.md`.

## Fix direction

PB3536 already made the run directory (`gate.log`, `gate.pid`, `verdict.json`) the one record of a gate and `--await` its one
reader. The templates still teach the older grep of a caller-named log. Replace the recipe in every template with: start the
gate, take the `run directory` it prints, and block on `python scripts/run_gate_legs.py --await <run>` (it checks the verdict file
and the gate lock, and names the head the record covers). Add a drift check (`check_practices.py`) that refuses a brief or
rendered spec that waits on a `=== BUILD-LOCAL GATE: ` grep of a log, so the unsafe wait cannot return. Sweep the
sibling briefs (`fix-lane-implementer-brief.md`, `implementer-brief.md`, `golden-lane-brief.md`) for the same wait.
