# PB2982 — indicator-column gates ignore a TAB in the sequence area

Filed 2026-10-10 by the train 1055 lander from the wave 1055 B report
(`E:\COBOL-coord\scratch\reports\w1055b-PB1688-report.md`, lead 1; first seen as w1053c lead 1). Same family as
PB1688 / PB1801 (train 1055: a diagnostic's column is the SOURCE column, mapped through the logical line), a site
those notes did not reach.

**Repro:** a fixed-form line whose sequence area is a TAB, then the indicator: `<TAB>-  "X".` (a continuation
line written after a TAB). The line's indicator is at the TAB-expanded position, but every indicator-column
diagnostic reports column 7, the EXPANDED column, never the source column the indicator character sits in.

**Sites:** `src/Cobol.Net.Frontend/Preprocessor/ReferenceFormatDiagnostics.cs` lines 48, 72, 80, 93, 150, 161,
173 (each passes `FixedFormLine.IndicatorColumn` as the column) and
`src/Cobol.Net.Frontend/Preprocessor/ReferenceFormatProcessor.LogicalLineBuilder.cs:187`
(`gates?.OnTwoContinuationForms(file, site.Line, FixedFormLine.IndicatorColumn)`).

**Fix shape:** the gates take the `TextSite` (whose `Col(text, i)` already maps a TAB-expanded index back to the
physical column, `ReferenceFormatProcessor.LogicalLineBuilder.cs:371`) instead of the constant, as PB1801 did for
the other reference-format diagnostics; a negative golden per gate with a TAB-led line pins the column.
