# PB5251 - at --std 85 two GROUP INDICATE items of one print line may be written out of column order or overlapping: ScreenReportColumnArrangement excuses items under different PRESENT WHEN clauses and PresentWhenClausesOf counts GROUP INDICATE as one (the 2023 reading) at every edition

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/ReportSectionBinder.cs` (`ScreenReportColumnArrangement`, `PresentWhenClausesOf`, `NominalPlacements`)

**Mechanism.** §1985:XIII.3.11.3 SR2: "Within a given print line, the printable items must be defined in ascending column number order such that each printable item defined occupies a unique sequence of contiguous character positions." It has no exception. `ScreenReportColumnArrangement` refuses out-of-order and overlapping columns (COBOL2745) except for two items "each subject to a different PRESENT WHEN clause", and `PresentWhenClausesOf` counts a GROUP INDICATE clause as one (§2023:13.18.28.4 GR1) with no edition arm, so at 85 two GROUP INDICATE items escape the rule.

**Found by.** The 1985 code read, slice 54.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the code read's non-conforming verdicts of slices 36-56 wait in `E:/COBOL-coord/scratch/coderead-85/pipe-for-register.json`.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-SR-XIII.3.11.3-2` - `§1985:XIII.3.11.3 SR2` (read: PARTIAL, harm: under-rejects): "the printable items must be defined in ascending column number order".

**Repro (`E:/COBOL-coord/scratch/coderead-85/reprobe-85c/rw_gidesc.cob`).** `01 DTL TYPE IS DETAIL LINE NUMBER IS PLUS 1. 05 COLUMN 10 PIC X(3) VALUE "AAA" GROUP INDICATE. 05 COLUMN 1 PIC X(3) VALUE "BBB" GROUP INDICATE.`; `cobol.exe --std 85 --source-format fixed --run rw_gidesc.cob`. The read's `c5e-gi-overlap.cob` overlaps columns 1-5 and 3-5 the same way.

**Observed (the records-85c build of origin/main f2cf36fd15, rerun 2026-11-10).** exit 0, DONE.

**Expected (from the 1985 text).** Refused (COBOL2745), as the same line without GROUP INDICATE is.

**Fix direction (root cause, CLAUDE.md rule 4).** The PRESENT WHEN exception is a 2002-and-later rule; make it an edition arm of the one arrangement screen, with tests of the out-of-order and overlapping pairs at both editions.
