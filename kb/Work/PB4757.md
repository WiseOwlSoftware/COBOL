# PB4757 - NonIntegralItemsBeneath: the type-6 screen fails open

**What the report says (R2-2, low; left for the clerk because `IntrinsicArgumentRules.cs` was not changed in that round).** The
R1-4 answer of PB4709 (the walk enters call arguments) walks the arguments of every call in `NonIntegralItemsBeneath`, so an item
inside any numeric function argument becomes opaque and the type-6 screen fails open on illegal source main refused:
`S2 PIC 9V9 VALUE 0.2`, `FACTORIAL (S2 + FUNCTION ABS (S2))`. The report names no probe path.

**R1.** No open note covers it. PB4709 (landed) is the change that introduced it.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/IntrinsicArgumentRules.cs#NonIntegralItemsBeneath`.

**Fix (landed).** `CollectAdditive` reads `FUNCTION ABS` of an unsigned numeric item as the item (`UnsignedArgumentOfAbs`, §15.7.4 1) a)), so `S2 + FUNCTION ABS (S2)` counts S2 twice and the witness refuses it (COBOL1627); `S2 - FUNCTION ABS (S2)` still nets to 0 and stays legal, and a signed argument or any other function keeps its items opaque (no identity to read; the screen fails open there, sound but incomplete). Probe on the pre-fix build: `FACTORIAL (S2 + FUNCTION ABS (S2))` over `S2 PIC 9V9 VALUE 0.2` compiled clean and printed `000000001`. Witness: `conformance-suite/cases/15.3-Arguments/pb4757-abs-unsigned-sum-non-integral.cob` (+ `conformance-suite/wiseowl/diagnostics/pb4757-abs-unsigned-sum-non-integral.json`).
**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/IntrinsicArgumentRules.cs#CollectAdditive`, `#UnsignedArgumentOfAbs`, `#NonIntegralItemsBeneath`.
