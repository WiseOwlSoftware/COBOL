**2026-11-15, the landing (wave 20262043, group B): the FORMAT and SELECT WHEN clauses are implemented; 28 of the 33 rows close, 5 stay open.**

Re-probe: the 2026-11-15 reads reproduced (`FD F FORMAT CHARACTER DATA`, `--std 2002`: COBOL1705). Fixed at the root: ISO/IEC 1989:2002 requires both clauses, so Annex A.4.8 is now CLAIMED
(docs/conformance/5/A.4.8.md) and COBOL1705 is retired. The mechanism: one runtime engine (`RecordFormat`) translates a record between the record area and the medium item by item
over the SELECTED record description entry, called at exactly the two places a record crosses the medium (`SequentialConnector.ExternalRecord` at the top of each write entry, so the RECORD
clause's bounds and the line character set are about the record on the medium; `SequentialConnector.InternalRecord` at the one read); SORT and MERGE USING and GIVING reach it through the
connector. The compiler lays each record description out as steps (`RecordPlans.Of`), registers the plans, the FORMAT kinds, the CODE-SET alphabet and the SELECT WHEN selector (the clauses'
level-88 conditions compiled in order, `SequentialIoEmitter.EmitRecordFormatRegistration`), and `ResolveRecordFormatPass` screens the syntax rules (COBOL7342, COBOL7343, COBOL7344).
CODE-SET with SELECT WHEN converts item by item (SR3 lifts, GR4); the external connector's FORMAT agreement (GR12) is `ExternalFileConnectorRules.CheckFormat`; OPEN I-O of a FORMAT file and the FROM identifier
(SR2, SR3) are screened by the statement binders. Rows closed: the 28 in `closes_rows`; 2023 rows re-verdicted from DOCUMENTED-NON-SUPPORT (36, batch `pb5578-2023`).

**Decisions recorded here (CLAUDE.md rule 3: a deferral is taken by a recorded decision).**
1. A record description entry holding a table whose size depends on a data item (OCCURS DEPENDING ON) or is dynamic, in a translated record, is refused by name (COBOL7344): its items have no fixed
   place, and a plan needs one (the translation would walk `CobolContiguousLayout`). 2002 requires the clause, so `2002-GR-13.16.22.3-3` stays open; the 2023 rows GR-13.18.24.4-2/-3 are
   DOCUMENTED-NON-SUPPORT (the A.4.8 claim is bounded by them).
2. A FORMAT file with no record description entry (GR2 c: the items are those of the READ INTO or WRITE FROM operand) is refused by name (COBOL7344). Its WRITE form is `WRITE FILE`, Annex A.4.13 (PB5579).
3. A plain WRITE of a file with a CODE-SET or FORMAT clause evaluates the SELECT WHEN clauses (FORMAT GR2 b selects the entry the clauses identify); the 2023 text restricts the evaluation to the
   FILE phrases, which are not claimed (DOC-A.1-173).
4. REWRITE of a FORMAT file is unreachable: OPEN I-O is refused (SR9), so the connector's rewrite arms translate nothing.
