# PB2563 — the orchestrator's self-tests run in no gate

Found by wave 1037 group P (PB2537): its pr-test-analyzer review noted that `next_unit.py`'s new land deferral was
tested only in `test_orchestrate.ps1` section 8c, which no gate runs. The same holds for `coord.locked`, which PB2537
moved out of `alloc.py`: its stale-lock arm is tested only by `test_alloc.py`.

Eleven run nowhere. `landing_check.py` runs only in CI's `audits` job, so it is also a CI-only step and breaks the CI
invariant (kb/Work PB1957): a local gate cannot see a red that CI would show. DESIGN-orchestrator-loop section 12
records the gap as an intention: "the orchestrator tests would be one more step there".

## Harm

A regression in the loop's unit choice, the allocator, the planner, the budget or the mailbox passes every gate and
CI. The checks were run by hand this session: test_orchestrate 144/144, test_alloc 23/23, test_plan_wave 111/111. A
hand run is not a gate.

## Shape (rule 5: the next self-test is covered automatically)

One gate leg or audit runs them all, and finds them by DISCOVERY, never from a list: every
`scripts/orchestrator/test_*.{py,ps1}` and every module there that accepts `--self-test`. The local gate runs it (an
entry in `run_gate_legs.py`, or one Unit drift test that enumerates and runs them), and CI runs the same entry point,
so a CI step cannot be missing locally (PB1957). A drift test fails when a self-test exists that the runner did not
run.

Constraints for the implementer:
- `test_orchestrate.ps1` takes more than 10 minutes, longer than `PythonInstrument`'s 120 s limit. It needs its own leg
  or a faster fake.
- It needs PowerShell 7. `test_autostart.ps1` touches Task Scheduler shapes. Both are Windows-only, so the Linux side
  must say so explicitly; it must not skip them silently.
- `test_plan_wave.py` imports `check_practices.py`, which needs the `tools/claude-skills` submodule; a fresh worktree
  lacks it, so the runner fetches the submodule, as CI's fleet-practices step does.
- Once the runner covers them, remove the per-script Unit tests (LandingLeaseDriftTests, TrainMeasureDriftTests) and
  CI's separate landing_check step, unless they assert arms by name, which the runner should then do instead
  (CLAUDE.md rule 4: one mechanism).

(line 294), `docs/rearchitecture/DESIGN-orchestrator-loop.md` section 12.
