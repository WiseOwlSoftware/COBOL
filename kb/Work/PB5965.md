# PB5965 - one rule, three copies

**Found** by review round 1 of listing step 9b (lead R1-3; the reviewer cited `BinderDriver.cs:830`).

**The sites** (verified 2026-11-20): `src/WiseOwl.Cobol.Compiler/Binding/BinderDriver.cs:832` `ProgramVisibleFrom` (used at `:826`); the partial copy
`BinderDriver.cs:872` `NestedCallablesOf` (used at `:796`); `src/WiseOwl.Cobol.Runtime/Control/ProgramTable.cs:1054` `ResolveVisible`. Only the COMMON
exception is shared (`ProgramNameScope`, made by kb/Work PB1460 because the bind-time and run-time copies had drifted).

**Gap.** `ListingCallGraphTests` exercises only arm 1 (a directly contained program) and the external case; the RECURSIVE-caller, COMMON-sibling and
outermost-sibling arms and the COMMON exception are untested in the listing.

**Scenario** (reviewer): reorder arms 3 and 4 of `ProgramVisibleFrom`, or drop the `CommonProgramReferable` test: a 1985 program OUTER containing a
COMMON non-recursive C, with C writing `CALL "C"`, is listed as an edge to C while the runtime refuses it; every listing test stays green.

**Fix shape** (CLAUDE.md rule 5): one generic arm-order function in `ProgramNameScope` (children, parent, recursive and common accessors) that
`ResolveVisible`, `NestedCallablesOf` and `ProgramVisibleFrom` all call, plus listing cases for the COMMON, RECURSIVE and outermost-sibling arms, and
a drift test.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/BinderDriver.cs:832` (`BinderDriver.ProgramVisibleFrom`, `BinderDriver.NestedCallablesOf`), `src/WiseOwl.Cobol.Runtime/Control/ProgramTable.cs:1054` (`ProgramTable.ResolveVisible`)
