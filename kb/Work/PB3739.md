# PB3739 — turns_by_group_size.py's TURNS reads the first turns figure in the header

**Sites:** `scripts/orchestrator/turns_by_group_size.py#TURNS`, `scripts/orchestrator/turns_by_group_size.py#measure`.

`measure` searches the first `HEAD_BYTES` of each report with `TURNS.search`, which returns the FIRST turns figure it meets. A report whose header a review finisher rewrote (the `**turns:** about N` arm) carries the finisher's own turns, and the report is joined with them as the group's turns. The PB3704 report is such a row, and it falls in the 4-note bucket the PB3704 decision quotes (`model_rules.json` `wave.max_notes_per_group_source`), so the bucket mean moves by a figure that is not the implementer's.

Fix: read the implementer's figure only (the header line the implementer template writes, `**Status:** ... · **turns:** N of cap`), or take the largest/first figure on the Status line and ignore a figure a later section states; count a report whose header holds two different figures in the "left out" tally rather than joining it. Self-test: a header with an implementer figure and a finisher figure.

(2026-10-25, review R1-1, severity low.)
