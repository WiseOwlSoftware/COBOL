# PB3541 — a retired connector stays CommitControlled

## Lead

A connector stays `CommitControlled` after its clause is retired (the file closed, then a COMMIT executed) and the clause
is deactivated, so "item 8" (the unconditional ROLLBACK of a fatal exception condition on a file subject to an active
APPLY COMMIT clause, §14.6.13.1.3 item 8) and the AUTOMATIC lock posture still apply to it.

Code site: `src/Cobol.Net.Runtime/IO/TransactionControl.cs#Commit` and `src/Cobol.Net.Runtime/IO/FileRegistry.cs#RegisterCommitControl`
(there is no inverse of the registration).

The report gives no separate repro; the implementer or adjudicator writes one when taking the note.
