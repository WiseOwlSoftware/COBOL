# PB3471 — three-organization file-test classes duplicate the harness

Low, non-blocking DUPLICATION lead from the branch review of PB3459 (report `E:\COBOL-coord\scratch\reports\w1134b-PB3458-report.md`, `## Review findings` LEAD 1). PB3459 deliberately left these classes unconverted because `KeyedOrg` has no Sequential arm.

**Mechanism.** One job (register a file in a chosen organization, seed records, build the record image) is written privately in each class that spans Sequential, Relative and Indexed, so a connector API change needs one edit per copy.

**Sites.**
- `tests/Cobol.Net.Tests.Unit/FileLockPostureDriftTests.cs`: RegisterOrg, SeedOne
- `tests/Cobol.Net.Tests.Unit/SharingRefusalStatusTests.cs`: RegisterOrg, Seed
- `tests/Cobol.Net.Tests.Unit/PermanentErrorOutranksRecordLockTests.cs`: Register, Seed, Image
- `tests/Cobol.Net.Tests.Unit/RunUnitFileLockDriftTests.cs`: Register (Org switch, 4-char record)

**Fix shape.** Extend `tests/_shared/KeyedFileHarness.cs` (`KeyedOrg`, `Register`, `Seed`) with a Sequential arm, convert the four classes, delete the private copies in the same change (no forwarders, CLAUDE.md rules 4 and 5). Sweep `tests/Cobol.Net.Tests.Unit` for further Org-switch registrations before cutting the arm.
