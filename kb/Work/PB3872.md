# PB3872 — the prototype/definition pairing of the host entries compares externalized names ordinally

**Site:** `src/WiseOwl.Cobol.Compiler/CodeGen/HostEntryEmitter.cs#EntryUnits`

## The defect

`EntryUnits` withholds a prototype's host entry when the group also compiles its definition (design §7.2: "A group
holding both a prototype and its definition (§10.6.2 SR2/SR3) emits one host-entry class (the definition's)"). It
pairs them with `string.Equals(d.ExternalizedName, u.ExternalizedName, StringComparison.Ordinal)`. `BoundUnit.ExternalizedName`
is the word as written (or the formed AS literal), so a prototype `PROGRAM-ID. psub IS PROTOTYPE.` and a definition
`PROGRAM-ID. PSUB.` do not pair. Every other comparison of an externalized name uses the Annex C fold
(`ExternalizedNames.Same`, DOC-A.1-68; owner decision Q4 in design §19, "the Annex C fold everywhere"), and the run unit
treats the two as one program.

## Probe (2026-10-27, main build of 2026-10-26)

`E:/Temp/claude/E--COBOL/ef566665-2d16-4eee-a339-006d49d4731e/scratchpad/pb1086d/probe/fold.cob`: a prototype `psub`,
a definition `PSUB` and a main that names `PROGRAM psub`. The generated `fold.g.cs` declares `public static class psub`
AND `public static class PSUB`; the same source with both spelled `PSUB` (`upper.cob`) declares one, `PSUB`.

## Harm

Today: the compiled assembly's public host surface is wrong — two host-entry classes for one program where DOC-A.1-141's
mechanism and design §7.2 state one (`wrong_answer` is set for that output; both classes activate the program by name,
so a call through either reaches the right program). From
design slice 4 (kb/Work PB2100) on, each host entry is the anchor of a repository record, so the group would publish a
`ProgramPrototype` record and a `Program` record for one externalized name, and `--repository-check` (slice 7) would
compare them as two entries.

## Fix

Pair by `ExternalizedNames.Same` (the one mapping rule) and add the case-differing pair to
`HostEntryShapeDriftTests`. The design (§7.2, §17.3, §21 item 4) makes the fix a slice-4 obligation if this note has not
landed first.
