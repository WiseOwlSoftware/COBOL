# PB4591 - the written spelling is computed before it is known to be needed

**Mechanism.** PB4573 reads the written word with `WrittenSource.Of(token)` for the COBOL0901 sentence. Both call sites evaluate it as an argument of `FlagReservedUserWord(word, written)`,
whose first statement is the guard `!_reservedWords.RejectsAt(word, ...) || !_flaggedWords.Add(word)`, which returns without a message for almost every word. The spelling is computed and allocated
for every word that reaches the call and used only for the rare one that reports.

- `VersionConformancePass.cs#VisitReservedGatedWord` (about line 2976): the call is on the path taken for EVERY `reservedGatedWord` visited.
- `VersionConformancePass.cs#VisitCobolWord` (about line 2931): the call is also NOT only on the reporting path. It follows the early returns (checked token types / provable user-word position,
  a bare function argument, a declined construct, EXCEPTION-OBJECT inside a statement, the debugging-mode register) and then runs for every word that survives them, before the guard inside `FlagReservedUserWord`.

**Fix shape.** Compute the written spelling only where a message is built: pass the token into `FlagReservedUserWord` and call `WrittenSource.Of` after its guard.

The `DenotedBy` duplicate of `CobolWordsRewriter.CanonicalWordOf` that the same review first reported (R1-3) was removed before PB4573 landed (DEVLOG 3085).

**Sites:** `src/WiseOwl.Cobol.Compiler/Validation/VersionConformancePass.cs` (`VisitReservedGatedWord`, `VisitCobolWord`, `FlagReservedUserWord`).

**Landed (operator hand fix, wave 20261864 A, branch fix-pb4590-pb4591).** `VersionConformancePass.FlagReservedUserWord` takes the word's token and spells it (`CobolKeywords.Spelling(WrittenSource.Of(token))`) only after `RejectsAt` says the word is reserved, so both callers named here, `VisitCobolWord` and `VisitReservedGatedWord`, allocate nothing for a word the funnel accepts. The change was first written as review round 3 of `worktree-wf_acba161d-4d1-4` (a9ef7e4be, the duplicate PB4573 branch of kb/Work PB4593) and was carried here onto main.
