# PB3757 — a confirmed edition edge is still described as provisional

**Sites:** `docs/VERSION_CHANGE_REFERENCE.md` (the Table 7 preamble and row 7.31), `tests/version-matrix/constructs.json` (the row `string-delimited-omitted-2002`: its `description` and `vcr` strings).

Filed 2026-10-25 by the enqueue clerk. The Table 7 preamble says "The repo holds no 2002 or 2014 text (ratified decision #1), so every row's
EDITION EDGE below 2023 is DERIVED". Row 7.31 says "⚠ THE EDGE IS DERIVED, NOT QUOTED … the row takes the provisional 2002 edge … Overturn here in one line when a 2002 text is read", and the
`string-delimited-omitted-2002` row carries `"vcr": "STRING DELIMITED phrase optional (post-85; provisional 2002 edge); VCR row 7.31"`. PB3602 (landed) confirmed this edge from the 2002
text: clause 14.8.39 SR8 and Annex F.2 item 132 (the PB3605 report's wording; the PB3602 note holds the evidence). The prose was never reworded.

## Fix
Reword row 7.31, the constructs.json `description` and `vcr` strings to say the 2002 edge is confirmed (quote the clause), and drop the "overturn when a 2002 text is read" line.
Sweep for the same root: any other row PB3602 confirmed without rewording (rows 7.26, 7.32, 7.33, 7.36, 7.37 and 7.38 carry the same "provisional 2002 edge" phrasing in the VCR today; PB3602 says which of them it confirmed). Keep both
files consistent in one change (the VCR drift tests compare them).
