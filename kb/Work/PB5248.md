# PB5248 - at --std 85 a SUM entry whose counter took a size error is printed as spaces: FieldImage asks SumPresentable, the 2023 size-error indicator, at every edition, where 1985 has no indicator and moves the counter to the item by the MOVE rules

**Sites:**

- `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/ReportWriterEmitter.cs` (`FieldImage`)
- `src/WiseOwl.Cobol.Runtime/IO/ReportWriter.cs` (`SumPresentable`, `SumImage`)

**Mechanism.** §1985:XIII.3.19.4 GR4: "the sum counter serves as a source data item. The report writer control system moves the data contained in the sum counter, according to the rules of the MOVE statement, to the printable item for presentation." The additions follow the arithmetic statement rules with no SIZE ERROR phrase, so an overflow leaves the counter's value undefined, but the item still receives the counter by MOVE. `FieldImage` asks `SumPresentable`, which fills the item with spaces when the 2023 size-error indicator is set (§2023:13.18.54.4 GR4; kb/Work PB1130 landed it at every edition), so at 85 a numeric item prints blank.

**Found by.** The 1985 code read, slice 51.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the code read's non-conforming verdicts of slices 36-56 wait in `E:/COBOL-coord/scratch/coderead-85/pipe-for-register.json`.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-GR-XIII.3.19.4-4` - `§1985:XIII.3.19.4 GR4` (read: PARTIAL, harm: wrong-answer): "moves the data contained in the sum counter, according to the rules of the MOVE statement". (The ROUNDED half of this row's read is kb/Work PB5242.)

**Repro (`E:/COBOL-coord/scratch/coderead-85/reprobe-85c/rw_sumspace.cob`).** `01 WS-B PIC 9.`, a detail `COLUMN 1 PIC 9 SOURCE WS-B`, `01 CFT TYPE CONTROL FOOTING FINAL LINE PLUS 1. 05 S1 COLUMN 1 PIC 9 SUM WS-B.`, a USE BEFORE REPORTING CFT procedure that displays S1; GENERATE with WS-B 5 and 6; `cobol.exe --std 85 --source-format fixed --run rw_sumspace.cob`.

**Observed (the records-85c build of origin/main f2cf36fd15, rerun 2026-11-10).** The USE procedure displays `S1=+5`; the report file holds `5`, `6` and a footing line that is a space.

**Expected (from the 1985 text).** The footing's column 1 holds a digit, the counter moved by MOVE rules (its value after the overflow is undefined, its presentation is not).

**Fix direction (root cause, CLAUDE.md rule 4).** The blank presentation is a 2023 rule; make it an edition arm in the one place the sum image is composed, with this program as the test at both editions.
