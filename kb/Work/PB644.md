# PB644 — OPEN — the emit bypasses the catalogue

Found 2026-09-05 by the `PB292` implementer (report §"New defects" (b)), while writing
`AnnexA3RegisterDriftTests.EveryDiagnosticCodeNamedInTheRegister_IsEmittedByTheCompiler`: the test's oracle had
to be "is the code emitted anywhere in `src/`" rather than "is it a catalogue descriptor", because §2 rows 2, 17,
19 and 45 cite codes that the compiler really emits and the catalogue does not carry. The test documents the
measurement and deliberately does not gate on catalogue membership, so this note can be closed without touching it.

## The sites (main after train 5)

- `src/Cobol.Net.Compiler/Binding/OptionsBinder.cs:105` — `edition?.Error("COBOLNET0806", "ARITHMETIC IS STANDARD-B…")`
- `src/Cobol.Net.Compiler/Binding/PictureAnalyzer.cs:596`, `:602`, `:608` — `edition.Error("COBOLNET1564", …)` ×3
- `src/Cobol.Net.Compiler/Oo/OoClassTable.cs:273`, `:317` — `edition.Error("COBOLNET0822", …)` ×2 (method overloading)

`grep -c COBOLNET0806 docs/DIAGNOSTICS.md` → 0 while the compiler emits it; same for the other two.

## Why it matters

`DiagnosticCatalog`'s own header records what a bypassed emit costs: the next-free scan (session-probe's `diag`
line) reads the catalogue and the source, and a code that exists only as a literal in a call can be re-allocated
to a different meaning — it happened to COBOLNET1573 and COBOLNET1518. Three user-visible diagnostics are also
missing from the published reference, so a user hitting COBOLNET1564 has nowhere to look it up.

## Fix shape

Migrate each to a descriptor and emit by `Id`, exactly as `RefModZeroLengthMalformedOperand` and
`MethodRedefinesScope` already were; regenerate `docs/DIAGNOSTICS.md`; sweep for the class with
`grep -rn 'Error("COBOLNET\|Warning("COBOLNET' src --include=*.cs` outside `Generated/` (every hit is a bare emit),
and make the sweep a drift test beside `DiagnosticRegistryDriftTests` so the shape cannot return. Codes stay as
they are — renumbering is what this note prevents.

## Instance 2026-09-05 (PB334 implementer)

`COBOLNET0864` (§14.9.30.3 SR10, the READ KEY-phrase organization rule) is a bare string literal at four `ctx.Edition.Error("COBOLNET0864", …)` sites with no `DiagnosticCatalog` descriptor and no `docs/DIAGNOSTICS.md` row; PB334 reused it for the sequential arm (correctly — same rule), so that arm is likewise undocumented until the descriptor exists.
