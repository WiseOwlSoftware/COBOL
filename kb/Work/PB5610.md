# PB5610 - a factory working-storage item passed bare as an INVOKE argument from a factory method fails the backend compile with CS0117 (2002 and 2023)

**Sites:**
- `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/OoEmitter.cs` (whole: the reader pinned no member; the fixer names it) (INVOKE argument emission in a factory method
- member not pinned)

**Mechanism.** The BY CONTENT image temp emitted for the argument qualifies its picture profile constant with the factory class (OOFWC._P_100001), where the constant is not declared; the instance-object twin emits correctly.

**Inventory.** Rows claimed: `2002-SR-14.8.22.2-10`.
