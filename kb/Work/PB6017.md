# PB6017 - a dynamic-capacity table's disagreeing description in an EXTERNAL record: FORMAT-CONFLICT or DATA-INCOMPATIBLE?

**Site:** `src/WiseOwl.Cobol.Runtime/Control/ExternalTable.cs` (`ExternalTable.Describe`): the run time compares each
describer's `ByteCount` of a variable-length external record too, as it does a fixed-length one.

**Probed** (wave 20262131 group k, build of `train85b-small` at the head that files this note, `run_probe.py --std 2023`,
`E:/COBOL-coord/scratch/w20262131k/probes/extdyn.cob`): program EXTDA describes `01 EXTDX EXTERNAL. 05 GH PIC X(2). 05 GT PIC
X(2) OCCURS DYNAMIC CAPACITY IN GC.`, EXTDB the same record with `GT PIC X(3)`; both conditions are checked (`>>TURN
EC-DATA-INCOMPATIBLE CHECKING ON`, `>>TURN EC-EXTERNAL-FORMAT-CONFLICT CHECKING ON`) and both programs declare `USE AFTER
EXCEPTION CONDITION EC-ALL`. Output: `A HANDLED EC-EXTERNAL-FORMAT-CONFLICT` at EXTDA's `CALL "EXTDB"`, then `MAIN-AFTER
0000000002`; EXTDB never runs. At `--std 2014` the program is refused (EC-EXTERNAL-FORMAT-CONFLICT is a 2023 name, COBOL0878),
and `conformance-suite/cases/14.6.13.2-Incompatible-data/pb1042_dyn_table_agreement` (2014, no FORMAT-CONFLICT) raises
EC-DATA-INCOMPATIBLE at the reference, as it should.

**The two texts** (each through `cite.py --check`):

- §2023:14.6.13.2 GR6: "When the internal format of a dynamic-capacity table, as defined by the implementor, is not correctly
  formed or does not agree with the corresponding OCCURS clause an EC-DATA-INCOMPATIBLE exception condition is set to exist."
- §2023:14.8.4.3: "For external data items, the rules specified in 13.18.22, EXTERNAL clause, General rule 6 apply", and
  §2023:13.18.22.4 GR6 requires that the records "shall define the same number of bytes"; the CALL statement's table (§2023:14.9.4.4
  GR3) maps 14.8.4.3 to EC-EXTERNAL-FORMAT-CONFLICT.

**The question.** A record holding a dynamic-capacity table defines no fixed number of bytes, so whether GR6's byte agreement
reaches it (FORMAT-CONFLICT at the CALL, today's answer) or whether the disagreement is the table's own internal-format rule
(DATA-INCOMPATIBLE at the reference, the answer at 2014) is a reading of the 2023 text; GnuCOBOL implements neither condition.
The ruling decides `ExternalTable.Describe`'s comparison for a variable-length record (PB5996 already leaves such a record's
size out of the compile-time comparison). Owed: the ruling (a `kind: adjudication` record or a decision note), then the fix with
a 2023 golden of the pb1042 shape with both conditions checked.

## Ruling and fix (wave 20262165 group E, decision)

**Ruling: DATA-INCOMPATIBLE at the reference, not FORMAT-CONFLICT at the CALL.** §2023:13.18.22.4 GR6 requires that "the records
shall define the same number of bytes"; a record holding a dynamic-capacity table (or a dynamic-length item) defines no fixed
number of bytes, since its capacity varies during execution (§2023:8.5.1.9.1). GR6's byte agreement therefore has no count to compare, and the
disagreement of the table's element size is the table's own rule, §2023:14.6.13.2 GR6 (EC-DATA-INCOMPATIBLE), as the 2014 text
gives it. This is also what the compile-time comparison already did since PB5996 (`ExternalRecordDescription.DefinesItsSize`);
the run time now agrees with it. The VALUE, strong-type and CONSTANT RECORD identities are still compared.

**Fix.** `ExternalDescriptor.ByteCount` is `int?`, null for a variable-length record (`ExternalRecordDescription.Of`, emitted by
`OoEmitter.EmitExternalDescribes`); `ExternalTable.Describe` compares two counts only when both are present (`BytesDisagree`).
Golden `conformance-suite/cases/14.6.13.2-Incompatible-data/pb6017_dyn_table_external_2023` (2023, both conditions checked),
refused at 2002 and 2014 by `conformance-suite/wiseowl/diagnostics/pb6017_dyn_table_external_2023.json` (COBOL0878); unit test
`ExternalTableTests.FixedRecordsOfDifferentSize_RaiseFormatConflict_VariableLengthRecordsDoNot`.

**Sites:** `src/WiseOwl.Cobol.Runtime/Control/ExternalTable.cs` (`ExternalDescriptor`, `ExternalTable.Describe`,
`ExternalTable.BytesDisagree`); `src/WiseOwl.Cobol.Compiler/Binding/ExternalRecordDescription.cs` (`ExternalRecordDescription.Of`);
`src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/OoEmitter.cs` (`OoEmitter.EmitExternalDescribes`).
