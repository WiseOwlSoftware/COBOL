# PB4309 - COBOL1501 tells a user whose `>>COBOL-WORDS UNDEFINE`/`SUBSTITUTE` removed an intrinsic name that the function "is not an intrinsic function of ISO/IEC 1989", although the binder holds `word.RemovedByDirective`

Found by the Mythos front-end review, gap pass, 2026-10-31 (GAP-REVIEW.md, G1-2; artifact https://claude.ai/artifact/KaxkLe85tfZBZ3nZ1tDGTs). Pin d7daee1cf.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/IntrinsicBinder.cs` (`cobolWordsRemoved = word.RemovedByDirective` :586, the single message for both causes :603-607); `src/WiseOwl.Cobol.Editions/CobolWordsMap.cs:36` (`CobolWordsOp.At`, the cursor to cite).

**Finding.** After `>>COBOL-WORDS UNDEFINE "LENGTH"` or SUBSTITUTE, `FUNCTION LENGTH(S)` is rightly refused (section 7.3.10.4 GR3) but COBOL1501 says "FUNCTION LENGTH is not an intrinsic function of ISO/IEC 1989 (section 15.6 summary of functions)", false (section 15.50), the same sentence a typo gets (`b3` LENGHT). IntrinsicBinder.cs:586 holds `word.RemovedByDirective` and :603 folds both causes into one message. Probes b1, b2, b3. PB1372 (landed) recorded the sentence. The cw02 lead (a de-reserved verb used as a verb -> bare COBOL0001) is unverified. Sibling of PB4239.

**Fix direction.** Name the directive that removed the word, citing the `CobolWordsOp.At` cursor.

**Citations checked** (`python scripts/spec/cite.py --check`): section 7.3.10.4 "shall no longer be reserved or restricted in any way"; section 15.50 "LENGTH function".

**Evidence.** E:/COBOL-coord/scratch/w-gr2/GAP-REVIEW.md (sections 2 and 5.1); G1/b1-b3, G1-refute; review-G1.md. Probe names are copied from the shard reports; the refuter folders are E:/COBOL-coord/scratch/w-gr2/G*-refute/. Shard reports: E:/COBOL-coord/scratch/w-gr2/review-G*.md.
