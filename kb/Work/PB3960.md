# PB3960 — a figurative ZERO in a reference-modification position escapes the compile-time range screen: T(ZERO:2) over PIC X(4) compiles and aborts at run time, T(0:2) is refused COBOL2670

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/ReferenceResolver.cs:807` (`LiteralRefModRangeViolation` and its caller)

`DISPLAY T(ZERO:2)` over `PIC X(4)` compiles and aborts at run time with EC-BOUND-REF-MOD, while `T(0:2)` is refused
COBOL2670 at compile time (rule: §8.4.3.3.4 5) b), the R60 screen). `ReferenceResolver.LiteralRefModRangeViolation`'s
caller passes start / length as null for anything but an integer literal, so the `ZERO_ARITH` primary is never judged. Repro
`E:/COBOL-coord/scratch/w20261720b/p/ZY.cob`. Harm: under-reject (a compile-time error left to run time). Separate root from
PB3961 (the message text).

## Acceptance
- The screen judges a figurative ZERO as the value 0 at the start and the length position (`ZERO` and `ALL ZERO` forms);
  golden refusal pair `T(ZERO:2)` and `T(2:ZERO)`; sweep the siblings (subscripts, the other literal-only screens).
