**Rule it breaks:** one mechanism per job and single responsibility (DESIGN-architecture-review section 5.1, section 8.3 method; dimensions.md 1): scoping the state of the source element being emitted (program, class half, method) is one job and has one mechanism; the repository already has that mechanism, Scoped<T> (Binding/Model/RestoringScopes.cs:15), used here for EmitContext.Options

**Scenario:** The state of the element being emitted lives in three run-unit-lifetime objects (CodeGen/EmitterState.cs:38 DispatchState, :432 EcState, :577 CallUnitState) and is written field by field: ProgramEmitter.EmitProgramClass (ProgramEmitter.cs:307-321) and DispatchEmitter.EmitDispatcher (DispatchEmitter.cs:31-50) for a program; OoEmitter.EmitTypeHalf (OoEmitter.cs:445-454) for a class half, which clears SelfPath, ReturningPlace, Formals, UnitHasF3, UnitHasF3Perform, UseDecls, OuterGlobalUse, BeforeReportingSelectors and DebugActive but not UnitHasF4, DeclCount, F3HandlerBasePc, GlobalDeclIds, DebugByPc, DebugSectionRanges or PdRaisingObjectCsTypes; then a save-set-restore of UnitHasF3Perform and Propagation around two class-member emissions (OoEmitter.cs:487-500); OoEmitter.EmitMethod saves a six-field tuple plus GlobalDeclIds, Propagation, PdRaisingObjectCsTypes, DispatchName, ActivationLocalRoots and MethodFormals by hand and restores them with no finally (OoEmitter.cs:1059, 1230-1282, 1306-1331, 1373-1396); ReportWriterEmitter.RenderChecked toggles EcState.ComposeSizeChecking with try/finally (ReportWriterEmitter.cs:537-543); EmitContext.Options alone goes through Scoped<T>.Push (OoEmitter.cs:1230). The unreset class-half fields are right today only because ProgramEmitter emits every interface and class unit before any program unit (ProgramEmitter.cs:142-159) and each method restores what it set: EcEmitter.ObjDispatchExpr and EmitActivationSite read UnitHasF4 (EcEmitter.cs:66, 206) and EcEmitter.SortUseScope reads DeclCount (EcEmitter.cs:61), so reordering unit emission, or adding a field to EcState that one of the three writers does not clear, renders a class member against the previous unit state (an __EcObjDispatch call into a type that declares none, CS0103). Every new per-element fact is a three-writer edit with nothing to catch the writer that is missed.
