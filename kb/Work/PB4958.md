# PB4958 - the reservation gate's refusalWhereFree stops short of clause words and unit headers

**Sites:** `tests/version-matrix/cobol-words.json` (rows; `refusalWhereFree` determinations), `src/WiseOwl.Cobol.Frontend/Parsing/ReservationGateRewriter.cs` (`KeywordsReadIn` already handles such rows), `tests/WiseOwl.Cobol.Tests.Unit/CobolWordsDriftTests.cs` (`SourceUnitHeaderWords`)

**Report (PB4933 finisher; same root as PB4933, which is landed, so one new note linked to it: the gate retypes every occurrence of a declared free word).**
1. A declared free CLAUSE word hides its clause's edition refusal. Repro `E:/COBOL-coord/scratch/w20261915f/probes/td1.cob --std 85` (`01 TYPEDEF PIC X.` then `01 T PIC X TYPEDEF.`) draws COBOL1941 "'TYPEDEF' is not a clause", where `td2.cob` (no declaration) draws COBOL0900 TYPEDEF requires COBOL-2002. The fix is a `refusalWhereFree` row per clause word whose keyword positions no free-word reading competes for; it needs per-word analysis (TYPEDEF, BASED, ALIGNED, GROUP-USAGE, PROTOTYPE, ...). Statement verbs like GOBACK compete with a paragraph header and do not qualify.
2. Source-unit header words declared at 85 (minor): `probes/factory-decl.cob --std 85` draws COBOL5506 "unexpected 'FACTORY' ... expected END, ENVIRONMENT or IDENTIFICATION" where the plain form draws the class's COBOL0900. The six source-unit words are exempt because a unit header competes with a COBOL-85 procedure paragraph; FACTORY and OBJECT could qualify if every keyword position were proved free of competition.

Expected: each qualifying word gets its determination (the per-word competition proof recorded in the row), the drift tests pin the set, and the repros draw COBOL0900.

**Resolution (wave 20261930 H).** Re-probed on bf46220cde: `td1.cob --std 85` drew COBOL1941 "'TYPEDEF' is not a clause" where `td2.cob`
draws COBOL0900; `factory-decl.cob --std 85` drew COBOL5506 "unexpected 'FACTORY'" where `factory-plain.cob` draws the class's COBOL0900.
The note's proposed fix, a `refusalWhereFree` row per clause word, was built and measured first and is unsound: with a TYPEDEF row,
the legal COBOL-85 table `05 ENT OCCURS 3 ASCENDING KEY IS K TYPEDEF.` (keyed on an item named TYPEDEF) drew COBOL0900, because the
clause reading of TYPEDEF parses at the end of the KEY list too and the row kept every keyword reading of the word. Every clause of a
data description entry competes this way, so no clause word qualifies. Fix: the gate decides per OCCURRENCE. Before a word's retype
it records the tokens the pass read in a keyword position (`KeywordsReadIn`); a later pass whose user-word reading of such a token
fails (a syntax error at it, or a closed format's error production holding it: `NameReadingsRefused`) gives it its keyword back
(`TokenRetypes.KeptKeywords`; `RetypedToken` remembers the keyword type) and the source is parsed again; a refused reading is settled
before the pass's newly freed words, which may be its consequence (`OPTIONS.` read as an unknown paragraph made DEFAULT of `DEFAULT
ROUNDED MODE` an offender and freed it). The per-occurrence rule subsumes PB4933's header words and the source-unit words FACTORY,
CLASS-ID, ..., so the `refusalWhereFree` determination, its generator step and its drift tests are deleted. The probes now draw
COBOL0900 (TYPEDEF) and the class's COBOL0900 (FACTORY); every PB4933 golden keeps its diagnosis.

## Landing

- `src/WiseOwl.Cobol.Frontend/Parsing/ReservationGateRewriter.cs#NameReadingsRefused` decides which keyword tokens of a freed word come back: only a token `#KeywordsReadIn` saw read as a keyword before the retype, and only where the user-word reading then failed. Trap: never decide it per word (a row or a list): every data description clause competes with the OCCURS KEY list.
- `ParseToFixpoint` settles a refused reading BEFORE freeing the pass's new words: an offender after a refused header is usually that header's cascade.
- `tests/WiseOwl.Cobol.Tests.Unit/DeclaredFreeWordKeywordTests.cs` computes the closed-list gated words from the ATN; a new one needs a sample there, not code.
