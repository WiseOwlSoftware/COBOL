# PB4124 — a frozen function argument's FunctionValueField description differs from the unfrozen one for the selecting fu

**Sites:** `src/WiseOwl.Cobol.Compiler/CodeGen/Emit/FunctionDeviceText.cs:132` (`FunctionDeviceText.Field`), `src/WiseOwl.Cobol.Compiler/Binding/Procedure/SendingValueTemp.cs:675` (`SendingValueTemp.OfComputed`),
`src/WiseOwl.Cobol.Compiler/Binding/Procedure/ArgumentOrder.cs` (`ArgumentOrder.Hold`, `ArgumentOrder.NeedsItsArguments`, `ArgumentOrder.Window.Freeze`, `ArgumentOrder.Window.Settle`).

New defect/lead 2 of PB4036's finisher ("file separately"). A frozen argument's `FunctionValueField` description differs from the
unfrozen one, for the selecting functions MAX / MIN / MEDIAN / ABS and for LENGTH / DISPLAY of the result:

- `LENGTH (MAX (A * B, 3))` -> 4 vs `LENGTH (MAX (A * B, UDF (A)))` -> 8;
- nested `LENGTH (MAX (MAX (C, 5), UDF (A)))` -> 38 vs unfrozen 8 (C PIC 9(8)).

The two forms of one call disagree, so at least one answer is wrong on legal source. Repro:
`E:/COBOL-coord/scratch/mythos/w-n1/w20261762e/p6.cob`.

**Root (the report's):** the freeze keeps the value, not the description. `FunctionDeviceText.Field`'s `BoundFieldOperand` arm describes a
frozen temp by its item; `SendingValueTemp.OfComputed` builds the temp. A nested function needs a `FunctionValueField`-holding temp, "a
design beyond this slice". Loosely shares the freeze-loses-identity root with PB4123 (the classifier lead); file and fix separately.
Determine the correct LENGTH from §15 (the result's description is the function's result type/size) before choosing which side is
the wrong one.

Source: report `w20261762e-PB4036-report.md`, "New defects / leads" item 2; PB4036 (landed).

## Landed (branch worktree-wf_4b00724e-f7f-1)

**Fix sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/ArgumentOrder.cs` (`ArgumentOrder.Hold`, `ArgumentOrder.NeedsItsArguments`, `Window.Freeze`, `Window.Settle`),
`src/WiseOwl.Cobol.Compiler/CodeGen/Emit/FunctionDeviceText.cs` (`FunctionDeviceText.Field`, the function-value-temporary arm).
`SendingValueTemp.OfComputed` is unchanged: the temporary it builds is right for its value, and the fault was in describing it as a data item.

**Which side was wrong.** The held one. A function's returned value is a temporary whose description is the implementor's (§15.4.1,
docs/CONFORMANCE.md DOC-A.1-92: a COPY of the selected argument's item for ABS / MAX / MIN / MEDIAN / single MEAN, described by the value for the
rest), and §8.4.3.2.4 GR2 only orders the evaluation, so the same call must answer the same with or without a later activation.
Measured on the base build over 22 argument shapes x MAX / MIN / MEDIAN x DISPLAY / LENGTH / BYTE-LENGTH (p7.cob, scratch w20261773a): 141 held answers
differed from the unheld ones, the unheld all on the 4-byte / 8-byte / copied-item descriptions of DOC-A.1-92; after the fix none differs but the
legs where the activation's PIC 9(8) result, not the argument, is the selected item.

**Two mechanisms, one root (the freeze kept the value, not the description).** (1) An expression or `Value`-form function argument is held in a
`FunctionValueSeparator`-flagged temporary; `FunctionDeviceText.Field` now describes that temporary by its value, as it describes the argument it replaced.
(2) A nested function whose result copies an argument's item (`FunctionDeviceForm.Argument` / `FixedDigits`) is held by holding ITS arguments
(`ArgumentOrder.Hold`), because the description it returns is chosen at run time by which argument it copies. A user-defined function's argument is
read for its value alone and is still held as a value.

**Residual (not fixed, reported):** a nested selecting call that names a table(ALL) argument is still held as a value (the ALL operand is no
recorded operand, `IntrinsicBinder.TryBindAllArgument`), so `LENGTH (MAX (MAX (T (ALL), 1), UDF (X)))` is 4 where unheld it is 8 (probe p8.cob). The root is
the same one as the direct `MAX (T (ALL), UDF (X))` reading the table AFTER the activation: an ALL argument is enumerated where the call renders and is
never held for GR2's order.
