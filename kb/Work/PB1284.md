## Measured

### Finding renames-clause — ISO/IEC 1989:2023 §13.18.45.3 SR8, SR10 (wrong-answer; rows SR-13.18.45.3-8, SR-13.18.45.3-10)

**Mechanism.** F-range-content: after tiling, ResolveRedefines checks nothing about the items INSIDE the RENAMES … THROUGH window. It has no test for an occurs-depending table, a variable-length item (DYNAMIC LENGTH, OCCURS DYNAMIC) or a pointer-class item (SR8), and none for whether the window is a whole number of bytes (SR10, reachable through packed USAGE BIT items). Only SR8's strongly-typed arms are enforced, by CheckStrongTypeDeclarations COBOLNET1532.

**Repro.** scratchpad adj-d1/out13/probe/renames-clause/sr8odo.cob: `01 N PIC 9 VALUE 2. 01 R. 05 A PIC X(2) VALUE "AB". 05 T PIC X OCCURS 1 TO 3 DEPENDING ON N. 66 X1 RENAMES A THRU T.` + DISPLAY X1 -> compiles and prints 'AB   ' (85: 'AB'). sr8dyn2.cob (range holds `05 D PIC X DYNAMIC LENGTH`) -> prints ABCD, dropping D; sr8odog.cob (RENAMES a group containing an ODO) -> prints blank; sr8occdyn.cob (range holds OCCURS DYNAMIC) -> aborts at run time; sr10bit2.cob (`05 A PIC 1(3) USAGE BIT`, `05 B PIC 1(2) USAGE BIT`, `66 X2 RENAMES A THRU B`) -> prints 10111, a 5-bit area.

**Expected, from the standard.** Each is rejected at compile time. §13.18.45.3 SR8: 'None of the items within the range, including data-name-2 and data-name-3, if specified, shall be of class object, message-tag, or pointer, a strongly-typed group item, an item subordinate to a strongly-typed group item, a variable-length data item, or an occurs-depending table.' SR10: 'The area described by data-name-2 THROUGH data-name-3 shall define an integral number of bytes.' (docs/CONFORMANCE.md USAGE BIT: adjacent same-level bit items share a byte, so 3+2 bits is 5 bits.)

**Observed.** Illegal source is accepted and prints values that are not the item's storage, or aborts at run time. The screen belongs where the window's leaves are already enumerated (the Walk/tiling in ResolveRedefines): every leaf and group in [startOff, endOff] needs a variable-length / ODO / pointer-class test, and the window's extent in BITS needs a mod-8 test.

**Code site.** src/Cobol.Net.Compiler/Binding/DataBinder.cs#ResolveRedefines (leaf Walk + greedy tiling, the `ren.Pic = new PicInfo(... Length: endOff - startOff + 1 ...)` tail)
