# PB3265 — member_index.resolve does not resolve dotted Python names

**Mechanism.** `resolve(index, names)` (`scripts/arch/member_index.py:224`) looks every name up with `keys_for(index, n)`, which knows C# types and members only. A Python site written `scripts.spec.work.named_paths` or `work.named_paths` is returned in `unknown`, contributing no files, so a Python-tooling note's declared set is its paths only.

**Source.** Report `w1090a-PB3242-report.md`, lead 3. Repro: `python scripts/arch/member_index.py` on a note whose site block names a dotted Python function.

**Fix shape.** A Python arm in the index (module path to file, function to its file) behind the same `keys_for`; or refuse such names at `work.py check` with a message that says to write the file path. Decide one; do not leave them silently unknown.
