# PB3957 — the ORDER row of reserved-words.json says r85=false on the strength of GnuCOBOL's list alone: the 1985 reservation of ORDER is unverified, a possible under-rejection at --std 85

**Sites:** `tests/version-matrix/reserved-words.json` (the ORDER row)

`tests/version-matrix/reserved-words.json` ORDER has `r85: false`, citing the GnuCOBOL 2002 list only. The 85 SORT
format spells `WITH DUPLICATES IN ORDER`, and the ANSI X3.23-1985 reserved list is commonly given with ORDER, so at 85 a user
word ORDER may be accepted where the 1985 standard reserves it. Repro: `E:/COBOL-coord/scratch/w20261720a/probe/ord1.cob`
`--std 85` compiles. The repository holds no X3.23-1985 text (D-RW3), so this needs an authority before it is a defect.
PB3794's mechanism (a `keywordWhereFree` row) is correct either way.

## Acceptance
- Obtain the 1985 reserved-word list (owner or a recorded secondary source per the D-RW3 protocol); set `r85` from it, or
  record the determination in `docs/CONFORMANCE.md`; a refusal golden at 85 if reserved.
