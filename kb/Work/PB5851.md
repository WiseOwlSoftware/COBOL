# PB5851 - a group VALUE is silently dropped when a subordinate item carries REDEFINES (every edition)

**The Mythos lane ran the program (`grpv.cob`, at `--std 85` with the tracked probe runner) and it printed `G1=[ABCD]`, `G3=[    ]` and `G5=[0000]`.** The group VALUE is lost when a subordinate carries REDEFINES. The row's own read in slice 1985-013 agreed without trying it. A refuter of slice 1985-192 raised it as a lead outside its rows; the row it contradicts is `1985-GR-VI.5.15.6-3` (the group-VALUE rule), whatever its stored verdict. **Ruling: UPHELD (b), harm wrong_answer.** The checker's confidence: high. Cause (b): the same at `--std 2023`. Severity MAJOR: a wrong-answer defect is at least MAJOR.

**Not traced (a lead nobody has checked).** The checker did not trace which code path drops the value. It names two candidates, "LIKELY, from the code's comments, not verified": the group-VALUE seeding of a group whose subtree holds a REDEFINES (a shared-storage, Tier-B backing) in `GroupValueSlicer.cs` (ComposedInit, which skips a redefining member) and `GroupImageCodec.cs#ImageInitOf` (the backing lane). Which lane drops it is not established.

**The checker's evidence (rulings.json, copied).** `§1985:VI.5.15.6 GR3`: a group VALUE means that "the group area is initialized without consideration for the individual elementary or group items contained within this group". GR2 forbids VALUE only on an entry that contains REDEFINES or is subordinate to one; the group G3 is neither (its subordinate A4 redefines its sibling A3), so `01 G3 VALUE "ABCD". 05 A3 PIC X(4). 05 A4 REDEFINES A3 PIC X(4).` is legal 1985 source and G3 must start as ABCD. Observed `G3=[    ]` and, for a numeric subordinate, `G5=[0000]` (not 1234); the control group without REDEFINES prints ABCD. Same at 2023.

**Sites:**
- `src/WiseOwl.Cobol.Compiler/CodeGen/DataDivision/GroupValueSlicer.cs#ComposedInit` (line about 323 skips a redefining member; a candidate, not verified)
- `src/WiseOwl.Cobol.Compiler/CodeGen/DataDivision/GroupImageCodec.cs#ImageInitOf` (the backing lane; a candidate, not verified)

**Where** (the checker's reading): the group-VALUE seeding of a group whose subtree holds a REDEFINES; which lane drops it is not traced.
