# PB4796 - the consequences of reading a signed ABS as the item

One mechanism: commit 8b316e3e1 made `CollectAdditive` read a signed `FUNCTION ABS` argument as the item. Four leads, in the reviewer's words.

- **R2-1 LEAD (low, not blocking at round 2):** `IntrinsicArgumentRules.cs:1763` Two comments the R1-1/R1-4 fix wrote call `G2 - FUNCTION ABS (G2)` (and `G2 - FUNCTION ABS (G2 + 0)`) over the signed G2 legal and always an integer, but it is not an integer on a negative G2, so section 15.3 6) makes it illegal; the screen fails open on it and no note or report line names that shape.
- **R2-2 LEAD (low, not blocking at round 2):** `IntrinsicArgumentRules.cs:1721` Reading a signed ABS as the item lets a signed difference reach the constant witness, whose message states facts that are false for a signed item: every other term is an integer and the value is never an integer.
- **R2-4 LEAD (low, not blocking at round 2):** `IntrinsicArgumentRules.cs:1784` The method `UnsignedArgumentOfAbs` no longer has anything to do with an unsigned argument: the diff removed its `Signed: false` test, so its name states the opposite of what it now accepts.
- **R2-5 LEAD (low, not blocking at round 2):** `conformance-suite/cases/15.3-Arguments/pb4757-abs-negated-sum-non-integral.cob:8` The negated golden cites section 15.7.4 1) a) for `ABS (- S2)`, but the argument -0.2 is negative, so the rule that gives the value is 1) b); the citation is copied from the signed golden, and the `UnsignedArgumentOfAbs` summary also names only a).

**Citations (`cite.py --check`).** 15.3 6) OK ("Integer. An arithmetic expression that will always result in an integer value ..."); 15.7.4 1) b) OK ("When the value of argument-1 is negative").

**R1.** A grep of kb/Work for `UnsignedArgumentOfAbs` finds only PB4757 (landed). No open note covers these.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/IntrinsicArgumentRules.cs#CollectAdditive`, `#UnsignedArgumentOfAbs`; `conformance-suite/cases/15.3-Arguments/pb4757-abs-negated-sum-non-integral.cob` (the golden's header citation).

**Fix (landed, wave 20261881 group B).** R2-1 and R2-2: `FACTORIAL (G2 - FUNCTION ABS (G2))` over a signed `G2` compiled (the call was read as G2 alone, the difference netted to 0), though it is 2 * G2 for a negative G2 (15.7.4 1) b)). `NotAlwaysIntegral` walks the spine once with a signed ABS read as the item and, when one was met (`AdditiveSpine.SawSignedAbs`), once more read as its negation, and refuses when either walk leaves an item uncancelled (`ItemWitness`); the constant witness's message no longer claims "every other term is an integer" and says where it holds when an ABS of a sum was read. R2-4: `UnsignedArgumentOfAbs` is gone, replaced by `ReadCall` and `BareNumericItem`. R2-5: the `pb4757-abs-negated-sum-non-integral` header cites 15.7.4 1) b). The two comments that called `G2 - FUNCTION ABS (G2)` legal now describe the unsigned case only. Witness: `pb4796-abs-signed-difference-non-integral` (refused, COBOL1627). Still fail-open, by design (one valuation region per item is all a witness gets): `G2 - FUNCTION ABS (G2 + 0)` over a SIGNED G2.
**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/IntrinsicArgumentRules.cs#NotAlwaysIntegral`, `#ItemWitness`, `#CollectAdditive`, `#ReadCall`, `#AdditiveSpine`; `conformance-suite/cases/15.3-Arguments/pb4757-abs-negated-sum-non-integral.cob` (the header citation).
