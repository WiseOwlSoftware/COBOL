# PB1908 — STRING overlap: decide, document and pin (the PB1907 shape)

Found by wave 1002 group B (PB1907's UNSTRING part) and filed at the train-1002 landing.

## The case

Row `GR-14.9.43.4-10` (§14.9.43.4 GR10, Annex A.2 item 60: a STRING whose sending, delimiter, receiving or pointer
operands occupy the same storage — the result is undefined) is verdicted CONFORMS with NO witness. §4.4 2) makes a
run unit that allows it a conforming one. The owner's PB1907 decision (2026-10-01: "determine what the
best/appropriate/current behavior we provide judged against what other implementations do in each case, document
our behavior … then produce a golden"; and "Follow GnuCOBOL, except WRITE length") covers it, but no wave-1002 group
carried STRING.

## What is known

- Code site: `src/Cobol.Net.Compiler/CodeGen/Verbs/StringEmitter.cs` `EmitString` (~line 31). It keeps a receiver
  IMAGE and reads the senders from storage, so a sender that overlaps the receiver reads its pre-statement value;
  libcob (`cob_string_append`) appends in place, so a later sender overlapping the receiver reads what earlier
  senders wrote. That is a candidate measurable difference; not yet measured.
- Shares its root (`StringEmitter`) with D-UNS1..4 (`docs/CONFORMANCE.md` §3.1). The may-share predicate to ask
  is the one PB1911 settles.
- Repro: not yet written. Measure with a built cobc 3.2 under WSL (`tests/external/gnucobol-3.2.tar.xz`; the
  wave-1002 scratch scripts `run_cobc1.sh` show the recipe).

## Closing shape

As PB1907: measure ours and GnuCOBOL's on each sub-case (sender/receiver, delimiter/receiver, pointer/receiver),
follow GnuCOBOL where it measurably differs, write D-STR rows beside D-UNS in `docs/CONFORMANCE.md` §3.1, pin with a
golden at edition 85, record the verdict with a test-ref.
