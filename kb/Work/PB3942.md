# PB3942 — the diagnostic code COBOL1985 (picture-editing-extended-count) reads like the year 'COBOL 1985' (owner question: renumber it?)

Decision wanted from the owner. The diagnostic code `COBOL1985` (`picture-editing-extended-count`) is spelled like the
edition name "COBOL 1985", so a reader of a log line cannot tell a code from an edition. Report evidence: carried over from
round 0 of the PB3575 review; it carries no harm flag. Renumbering a code is an owner question because a code number is
quoted by goldens, the refusal registry (`conformance-suite/wiseowl/diagnostics/`), the DEVLOG and users' suppressions (PB3575 renamed the prefix to `COBOL` in the same
way).
