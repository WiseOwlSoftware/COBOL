### Adjudicator finding (repository-paragraph, harm under-rejects)
- **Mechanism:** There is no §8.13 external repository: the REPOSITORY specifiers are never checked for resolvability, and each consumer substitutes its own reading - program prototypes resolve at run time against the run-unit registry (no details), functions draw COBOLNET1505 only at a use, classes/interfaces COBOLNET0813/0859 only at a use, properties the generic diagnosis only at a use. None of it is documented (Annex A.1 items 66, 161, 162 have no CONFORMANCE.md row).
- **Repro:** out/probe/repo/sr10.cob (--std 2023): REPOSITORY. FUNCTION NOSUCHFN FUNCTION ALIASFN AS "NOSUCH-EXT" PROGRAM NOSUCHPG CLASS NOSUCHCL INTERFACE NOSUCHIF PROPERTY NOSUCHPR. with nothing of those names anywhere; PROCEDURE DIVISION displays RAN. sr6.cob: PROGRAM NOSUCHPG + CALL NOSUCHPG ON EXCEPTION DISPLAY "NOT-FOUND".
- **Expected (spec):** §12.3.8.3 SR6/SR9/SR16: there SHALL be external-repository information for the named class / interface / property; SR10/SR14: the function / program name shall be an in-group prototype, a PREVIOUS in-group definition, or one with external-repository information. With no external repository none of the six names has information, so sr10.cob is nonconforming at every specifier. §8.13 requires the implementor to provide a mechanism to update the external repository and to flag prototype/definition differences from it (Annex A.1 item 66, required + documented); GR6/GR9 require the class/interface details to come from the specifier 'together with the external repository' (A.1 items 161/162, required + documented).
- **Observed:** sr10.cob compiles clean and prints RAN; sr6.cob prints NOT-FOUND at run time. The program arm's determination ('this implementation's external repository is the run unit's program registry', BinderDriver.ProgramPrototypesOf / PrototypeSignatures) supplies a callee but no DETAILS, so GR10 c)'s signature-driven behaviour (GR9 b) BY VALUE default, §14.8 conformance) silently falls back for any separately compiled program; the function arm refuses the same situation (COBOLNET1505) and the class arm refuses it at the use - three readings of one clause. kb/Work PB989 (open) owns only the 'previously' half of GR10/GR11. This needs an owner decision (implement §8.13's repository and its two mechanisms, or document a determination for A.1 items 66/161/162 and check each specifier against it) before a fix can be derived.
