# PB3263 — PB3160 slice notes have no site block

**Mechanism.** PB3242 made a note's declared file set its structured site blocks (a bold `Code site` / `Site` / `Sites` label's paragraph and list). The PB3160 slices (PB3172, PB3173 and their siblings) carry only `**Prerequisites:**` / `**Scope:**` prose, so they declare nothing and two slices that touch the same files collide silently in `plan_wave.py`.

**Repro.** `python scripts/arch/member_index.py --note PB3172` lists no sites. Source: report `w1090a-PB3242-report.md`, lead 1.

**Fix shape.** Add a `**Sites:**` paragraph naming every file each slice edits (the slice's author knows them from `DESIGN-conformance-suite.md` section 13), and make `work.py check` refuse an open note with `cluster: ["PB3160"]` and no site block (one rule, so slice N+1 is automatic).
