# PB5976 - COBOL1757 does not say the report-name is hidden by the program's own data item

After PB5973, `INITIATE R1` in a contained program that declares its own `01 R1` is correctly refused even though a container
declares `RD R1 GLOBAL`: by §1985:X.1.3.8.2 GR3a, R1 there names the program's own data item. The refusal is COBOL1757, which
does not name the hiding declaration, so a programmer looking at the container's RD reads it as wrong. The message should say
that R1 in this program is the data item declared at its line, which hides the container's GLOBAL report (GR3a).

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ReportWriterBinder.cs:380` (`ReportWriterBinder.BindInitiate`)

Witness: the existing golden pb5973-own-data-name-hides-global-report-85 gains the expected message text.
