# PB4981 - a rounding mode changes the exponent's kind

**Sites:** `src/WiseOwl.Cobol.Compiler/CodeGen/Emit/NumericRenderer.cs:1538` (inside `NumericRenderer.Power`).

**Report (R2-1, low per the reviewer; a wrong answer).** Pre-existing, not introduced by PB4923's diff (same output from the E:/COBOL checkout build). Under
`ROUNDED MODE TRUNCATION` or `AWAY-FROM-ZERO`, a non-integer literal exponent over an intrinsic base is rendered as an INTEGER exponent (0.7 turns into `0L`, or 1 into the base itself),
so `Power` takes the exact integer arm. `ROUNDED` (default mode) and a direct item base are correct. The cause is not yet traced (read line 1538 first). Probe: a COMPUTE with `ROUNDED MODE TRUNCATION` of `FUNCTION <intrinsic> ** 0.7` against the same without the mode and against an item base.
