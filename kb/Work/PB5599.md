# PB5599 - at --std 2002 the compiler-directive word table is the 2023 one: FLAG-85 and FLAG-NATIVE-ARITHMETIC are not reserved, PUSH and EQUATE are

**Sites:**
- `src/WiseOwl.Cobol.Frontend/Common/CompilerDirectiveWords.cs#IsReserved` (Table)
- callers ConditionalCompilationProcessor.cs (DEFINE, line ~731), CompileTimeExpressionEvaluator.cs (~551), TurnDirectiveProcessor.cs#ParseTurn (~187)

**Mechanism.** One edition-blind table, CompilerDirectiveWords.Table (§2023:8.12), answers IsReserved(word) with no edition. 2002 8.12 lists FLAG-85 and FLAG-NATIVE-ARITHMETIC and lacks PUSH, POP, EQUATE, SUBSTITUTE, COBOL-WORDS, FLAG-02, FLAG-14 and the other 2023 additions. Callers: DEFINE name check (COBOL2650), compile-time IS DEFINED, >>TURN file-name-1 (COBOL0718).

**Inventory.** Rows claimed: `2002-SR-7.2.2-6`, `2002-SR-7.2.19.2-1`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:7.2.2 SR6`: "Compiler-directive words are identified in 8.12, Compiler-directive words"
- `§2002:8.12`: "The following words are reserved in compiler directives"
- `§2002:7.2.9.2 SR1`: "Compilation-variable-name-1 shall not be the same as a compiler-directive reserved word"
- `§2002:7.2.19.2 SR1`: "Any user-defined word that duplicates a compiler-directive word is interpreted as a compiler-directive word rather than as file-name-1"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p/d_def_push.cob, p/d_def_f85.cob, p/turn-push.cob); the text is inline. Command: `cobol.exe p/d_def_push.cob --std 2002 --run`

`p/d_def_push.cob`:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. DDEFPUSH.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 X PIC 9 VALUE 0.
       01 Y PIC X(10) VALUE "123".
       PROCEDURE DIVISION.
       >>DEFINE PUSH AS 1
       >>IF PUSH = 1
           DISPLAY "PUSHVAR"
       >>END-IF
           STOP RUN.
```

`p/d_def_f85.cob`:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. DDEFF85.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 X PIC 9 VALUE 0.
       01 Y PIC X(10) VALUE "123".
       PROCEDURE DIVISION.
       >>DEFINE FLAG-85 AS 1
           DISPLAY "A"
           STOP RUN.
```

`p/turn-push.cob`:

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. TRNPSH.
       PROCEDURE DIVISION.
       >>TURN EC-I-O PUSH CHECKING ON
           DISPLAY "A".
           STOP RUN.
```

**Observed.** d_def_push: error COBOL2650 'PUSH' is a compiler-directive word (ISO §2023:8.12), rc=65; d_def_f85 (>>DEFINE FLAG-85 AS 1): accepted, prints A, rc=0; turn-push (>>TURN EC-I-O PUSH CHECKING ON): COBOL0718 citing §2023:7.3.25.3 SR1, rc=65.

**Expected (from the 2002 text).** d_def_push and turn-push accepted (PUSH is not a 2002 compiler-directive word); d_def_f85 refused (FLAG-85 is one).

**Sibling sweep.** every other word table in Frontend/Common keyed to one edition (the reserved-word and context-sensitive-word tables are edition-keyed; this one is not); every IsReserved caller.

**Other editions.** 85: no (no >> directives). 2014: unknown, 2014 8.12 is its own list and the same table answers it; probe at --std 2014.
