## Measured

**code-clause** — The report-description CODE clause (§13.18.12) is parsed but staged LOUD at bind: DataBinder.BindReportDescriptionClauses raises COBOLNET0899 report-code-clause for EVERY CODE clause, so no CODE prefix is emitted, the logical record size is not extended, identifier-1 is never evaluated at body-group / page-advance time, and none of the three syntax rules is screened. No kb/Work note owns this staging.

- **Repro:** FD RPT-FILE REPORT IS RPT1 (ORGANIZATION LINE SEQUENTIAL). RD RPT1 CODE "A1". 01 DL TYPE DETAIL LINE PLUS 1. 05 COLUMN 1 PIC X(5) VALUE "HELLO". PROCEDURE: OPEN OUTPUT, INITIATE RPT1, GENERATE DL, TERMINATE RPT1, CLOSE, STOP RUN. Identifier form: RD RPT1 CODE IS WS-CD with 01 WS-CD PIC XX VALUE "B1". Files: out13/probe/code-clause/{codelit,codeid,codeno}.cob.
- **Expected (spec):** Compiles; each logical record written for RPT1 begins with the CODE characters followed by the line: 'A1HELLO' (§13.18.12.4 GR1); the two characters count in the logical record size but not in the line description (GR2); with identifier-1 the value is evaluated at the start of each body group / during page advance (GR3; §14.9.16.4 6) c)) giving 'B1HELLO'. Non-conforming operands draw SR-specific diagnostics: a non-alphanumeric literal (SR1), an identifier that is not alphanumeric or is an ODO group / variable-length group / dynamic-length item (SR2), and a report file whose RDs do not all specify CODE (SR3).
- **Observed:** Both forms, --std 2023 and --std 85: 'error COBOLNET0899: RD RPT1: the CODE clause (ISO §13.18.12) is not yet implemented'. The identical program without CODE compiles and writes 'HELLO'. The grammar rule reportCodeClause is correct; the defect is the missing binder/emitter/runtime path plus the missing SR1-SR3 screens.
- **Code site:** src/Cobol.Net.Compiler/Binding/DataBinder.Reports.cs:741-743 (BindReportDescriptionClauses); src/Cobol.Net.Editions/Diagnostics/DiagnosticCatalog.cs:855 (ReportCodeClause); src/Cobol.Net.Compiler/CodeGen/Verbs/ReportWriterEmitter.cs (no CODE path)
- **Clause (adjudicator):** §13.18.12.2; §13.18.12.3 SR1-SR3; §13.18.12.4 GR1-GR3; §14.9.16.4 6) c)
