# PB5104 - at --std 85 RELEASE and RETURN are accepted outside the range of a SORT or MERGE procedure that names their sort file: RELEASE of the record of a sort file no SORT names, RETURN from a sort file no SORT or MERGE names, or in a section no SORT refers to

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/SortBinder.cs#BindRelease` and `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/SortBinder.cs#BindReturn` (the binders PB5077 names for the same statements; the records name no site)

**Mechanism.** The 1985 placement restrictions of RELEASE (XI.4.2.3 SR2) and RETURN (XI.4.3.3 SR3) are not checked: the statement compiles and runs, the released record is dropped silently, and the RETURN takes its AT END branch at once. The same holds when the statement stands in a section no SORT refers to while the only SORT for the file has USING (RELEASE) or GIVING (RETURN). PB5077 holds the sibling storage-area rules (SR3 of RELEASE, SR1 of RETURN), a different rule.

**Found by.** The 1985 MATCH confirmation pass (kb/Work PB4995 item 3): each rule below is a corrected draft (a "redraft") that the compiler at `--std 85` still fails (redraft_run MISMATCH). Harm and observed text are the records; nothing here was re-derived.

**Inventory.** The traceability inventory carries no 1985 rows yet (PB5094: work.py refuses 1985 ids), so `inventory_rows` is empty; the rows this note covers are the 1985 rule ids listed below (catalog `docs/rearchitecture/spec-rule-catalog-1985.json`).

**Rules (2; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-SR-XI.4.2.3-2` - `§1985:XI.4.2.3 SR2` (record harm: under-rejects, slice-23): "A RELEASE statement may be used only within the range of an input procedure associated with a SORT statement" (followed by "for the file-name whose sort-merge file description entry contains record-name-1."). The corrected draft releases, inside SORT-A input procedure, a record of SORT-B, a sort file no SORT statement names (line 28, RELEASE REC-B). Its control (RELEASE REC-A) compiles and prints AAA BBB CCC.
- `1985-SR-XI.4.3.3-3` - `§1985:XI.4.3.3 SR3` (record harm: under-rejects, slice-23): "A RETURN statement may only be used within the range of an output procedure associated with a SORT or MERGE statement for file-name-1" . The corrected draft returns, inside SORT-A output procedure, from SORT-B, a sort file no SORT or MERGE statement names (E:/COBOL-coord/scratch/confirm-85/out/work-slice-23/ret2.cob line 33, RETURN SORT-B AT END GO TO O9). Its control (RETURN SORT-A) compiles and prints AAA BBB CCC.
