# PB1612

**Filed 2026-09-26 from owner decision `kb/Work/R50.md`** and the design `docs/rearchitecture/DESIGN-USER-DOCUMENTATION.md`.

Generate the Command-line reference from `CliOptions` (one source for `--help` and the page) and the Diagnostics reference from the diagnostic catalog (one entry per COBOL#### code: severity, enforced rule with § citation, minimal example), each with its drift test per DESIGN-USER-DOCUMENTATION.md §5.

**The manual page this note changes (2026-10-31, kb/Work PB1610).** `docs/manual/user-guide/command-line.md` carries the option and exit-status tables by hand, guarded by `UserManualDriftTests`; the generated Command-line reference supersedes the option table and the page keeps the concepts and links the reference. The diagnostic codes the hand-written pages name are checked against the catalogue by the same test.
