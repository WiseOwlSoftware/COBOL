# PB3851 — the generated parser's ignore rule followed the project's name

**Sites:** `.gitignore` (the ANTLR build-output rule)

## The defect

The build writes the ANTLR lexer and parser into the Frontend project's `Generated/` directory, and `.gitignore` ignored
that output by the project's path, `src/<project>/Generated/`. PB3837 (#663) moved the project from
its former directory to `src/WiseOwl.Cobol.Frontend` and the rule with it, so in every checkout that had built
before the rename, the generated files the build left at the OLD path became untracked and visible:
`CobolLexer.cs`, `CobolParserCore.cs`, their visitors, `.interp` and `.tokens`, eight files. The checkpoint protocol
(`git add -A -- . ":!.claude/settings.local.json"`, MANDATORY-PRACTICES and the workstream skill) stages them, so the next
WIP commit in such a worktree commits a stale parser under a retired name. The retired-names audit
(`scripts/rename_retired_names.py --check`) reads tracked files, so it would refuse the branch at landing: the harm is a
stopped landing and a finisher's turn, not a wrong answer. `bin/` and `obj/` were never affected: their rules name the
shape of the output, not the project.

## The fix

The rule names the output's shape, `src/*/Generated/`, the way the `bin/` and `obj/` rules do, so the next move of any
project needs no ignore edit and leaves no visible file behind. No `Generated/` directory under `src/` is tracked
(`git ls-files` lists none), so the wider rule hides nothing that belongs in the tree. The main checkout's stale
former-name project directories under `src/` and `tests/` (build output only, nothing tracked) were deleted by hand; a
worktree that merges main after this lands sees its own leftovers as ignored.

## Acceptance

- `git check-ignore --no-index` ignores `CobolLexer.cs` under the former directory's `Generated/` and
  `src/WiseOwl.Cobol.Frontend/Generated/CobolParserCore.cs`, and does not ignore `src/WiseOwl.Cobol.Frontend/Foo.cs`
  (checked on this branch).
- No `.gitignore` rule names a project directory under `src/`.
