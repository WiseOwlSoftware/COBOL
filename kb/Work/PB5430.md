## The step

Three commits, in order. (1) THE BURN-DOWN: measure every `CONFORMANCE.md §N` and `CONFORMANCE.md#ANCHOR` in the files the CITATIONS audit reads that does not resolve (`git grep -nE 'CONFORMANCE\.md,? §[0-9.]+|CONFORMANCE\.md#[A-Za-z0-9._-]+'` against `conformance_source.load`), and rewrite each misattribution to what it means (the standard's clause in edition form, or the document's section or key the sentence is about), mark each planted fixture in a code file with `citation.EXAMPLE_MARKER`, and re-bless any golden whose text changed (`CobolNum.cs:334` prints one). (2) THE CUT: `conformance_migrate.py` cuts the normalised monolith into `docs/conformance/` (section 16.8's table), `conformance_source.py` reads the directories, `conformance_doc.py` renders and checks, `docs/CONFORMANCE.md` leaves the tree for a `rendered_views.VIEWS` row and `.gitignore`; `rendered_views.py` stamps every in-tree file view it renders and adds rule (e) (a file at a view's path with no stamp or an edited body is RED, and a render refuses to overwrite it; a stale unedited view is not RED); the migration script is deleted. (3) THE POINTERS AND THE ARM: every instruction that names a place to write a determination and every Markdown link moves to `docs/conformance/` (section 16.8's list, re-swept by its two commands), `cite-resolve-baseline.json` is re-keyed to the moved lines, the CITATIONS audit gains the conformance arm, and PB4053 is retired with its acceptance run as the evidence.
