# PB4939 - COBOL2112 names the 2023 formats at 85

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/SetFormatSelection.cs` (`SetFormatSelection.ReportNoFormat`, `SetFormatSelection.ReportNotAdmitted`, `SetFormatSelection.ReportNotSoleReceiver`, `SetFormatSelection.BraceOf`, `SetFormatSelection.RuleOf`, `SetFormatSelection.FormatsClause`, `RowAt1985`), `src/WiseOwl.Cobol.Editions/Diagnostics/DiagnosticCatalog.cs` (`DiagnosticCatalog.SetNoFormatAdmitsReceiver`, the COBOL2112 descriptor)

**Report.** PB4901's re-probe of `SET DEBUG-SUB-1 UP BY 1` at `--std 85` found COBOL2112 CORRECT (`§1985:VI.6.23.2`: Format 2 is `SET {index-name-3} ... UP/DOWN BY`; the receiver is an index-name
only), but its text is the 2023 statement of the rule: it lists the 2023 SET formats (Format 14, Format 10) and cites only `§2023:14.9.39.2`, even though the 1985 SET has
its own, smaller format set (the fixer reads it off the rendered page) and the program is being compiled under it. Expected: the message is
edition-filtered, like `ParameterConformance.ScreenSection` now is for CALL (PB4901): at 85 it lists the 1985 formats and cites `§1985:VI.6.23.2` (checked with `cite.py --check`), at 2002+ the
2023 text. Repro: `E:/COBOL-coord/scratch/w20261887a/sw/r1.cob --std 85` (`SET DEBUG-SUB-1 UP BY 1`). The fix adds a golden at 85 asserting the 1985 clause substring and the format list, per the
PB4938 lesson that the citation itself needs its own pin. The clerk did not re-count the 1985 formats; the fixer does from the rendered page.

Source report and lead: `w20261905f-PB4901-report.md`, New defects (the report calls it "COBOL2112 text").

**Landed.** Re-probe on the branch build (`SET WS-N UP BY 1`, `SET WS-N I1 UP BY 2` at `--std 85`) reproduced both 2023-worded messages. `SetFormatSelection.Row` now carries an optional `RowAt1985` (Formats 1 and 2, the only receiver-taking formats of `§1985:VI.6.23.2`, whose Formats 3 and 4 are the switch and condition-name statements); at `--std 85` the messages list only those rows and cite `§1985:VI.6.23.2`, `§1985:VI.6.23.3 SR2` and `§1985:VI.6.23.4 GR4` (all `cite.py --check` OK). 2002 and later keep the 2023 text, as the note asked. Pinned by `pb4939-set-no-format-names-1985-clause-at-85` and `pb4939-set-not-admitted-cites-1985-rules-at-85`.
