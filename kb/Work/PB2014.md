# PB2014 — OPEN: stall_watch.py has no grace period for an empty transcript

Repro: wave 1018 (run `wf_80c785b7-d71`, 2026-10-04 18:24 PDT). `stall_watch.py` started right after the Workflow
call exited 3 within seconds:

```
STALLED:
  impl-D-PB1425 (a688676dfdc55a406): transcript unreadable or empty
  impl-E-PB1110 (a4b2f5d584585d1bb): transcript unreadable or empty
```

Code site: `tools/claude-skills/skills/agent-fleet/references/stall_watch.py#check` (line 118): `last_record(...)
is None` means STALLED at once. A pending agent whose transcript exists but holds no record yet has just been
spawned. This happens at the start of every wave and on every rolling refill.

Fix (public skill first, then move the pin, then run the evals per MANDATORY-PRACTICES O7): give an empty
transcript the `model_stall` grace period, timed from the file's creation (its mtime, while it is still empty, is
its creation time; this is the one place a file time is the right signal because no record exists yet). Report it
as STALLED only after that. Restarting the watchdog once the agents had written records worked around it for wave
1018.
