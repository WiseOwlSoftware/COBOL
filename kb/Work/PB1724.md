# PB1724 — OPEN

Filed by the train-71 lander from wave 71 group D's report (`w71d-PB1718-report.md`, new lead 1).

## Finding

`NistDifferentialTests_P2.NistProgram_MatchesGolden(testName: "SM206A")` failed with `[run] exit non-zero` in
battery PHASE 1 (run at BelowNormal while the host carried the rest of wave 71), and passed when run alone
(`DisplayName~SM206A`, 4 of 4).

**Repro artifact.** `E:\Temp\claude\E--COBOL\73cac64c-391d-42c0-bcdf-c880e3e10305\scratchpad\w71d\battery\conformance.trx`
holds the failing result's message and stack.

**Code site.** The NIST run harness in `tests/Cobol.Net.Tests.Conformance` (`NistDifferentialTests`), which runs the
compiled program and treats a non-zero exit as a failure.

**Cause not attributed.** A "flake" is not a verdict (gate skill): read the trx's captured stderr and exit code first.
A program-side cause (a shared temp file, a resource contention on a file the
program opens) is as possible as a harness timeout.
