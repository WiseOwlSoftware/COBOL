# PB4194 — a later stamp masks an earlier FINDINGS

Filed by the clerk from the previous loop unit's finding (`resume-20261030-review-lease-gap.md`, "Second harm" and "Third
harm"); the lease gap that produces the second reviewer is PB3405's mechanism.

**Second harm: a masked FINDINGS.** `review_findings.stamp` (`scripts/orchestrator/review_findings.py:468`) replaces the
report's `**Review:**` line unconditionally. When a second reviewer of the same head (for example the lane's duplicate)
finishes after the first with CLEAN while the first said FINDINGS, its CLEAN is the stamp. The FINDINGS file is then in no
place the survey looks, `prune_worktrees.py` reads the branch WAITING TO LAND, and the land lane can land a branch whose
blocking finding is unanswered.

**Third harm: a split record.** A lane FINDINGS on a predecessor, answered in the wave's file by the successor's round,
reads as unanswered in the lane's file, which can hold the successor (`carrying_findings`).

**Fix direction.** `stamp` refuses to replace a FINDINGS stamp that names another file at the same head. The self-test
plants a FINDINGS stamp naming file A and a CLEAN verdict in file B at the same head, and asserts the refusal. For the third
harm the fix decides whether `carrying_findings` should read the answered round across both files; PB3405's
one-place-for-the-files fix may remove it.

**Sites:** `scripts/orchestrator/review_findings.py` (`stamp`), `scripts/prune_worktrees.py` (`carrying_findings`).
