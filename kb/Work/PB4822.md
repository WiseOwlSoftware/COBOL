# PB4822 - a call of a user function whose literal-5 was refused still draws COBOL1505 (declared but no prototype), a cascade

**What the report says (the reviewer's words).** A call of a function whose literal-5 was refused still draws COBOL1505 ("declared ... but no prototype"), true but a cascade; PB4708-style refused-word memory (like RefusedProgramSpecifiers) could silence it. Site: IntrinsicBinder / BinderDriver.UserFunctionsOf. Codes: none used (COBOL6319-6321 returned).

**R1.** kb/Work PB4708 and PB4774 name RefusedProgramSpecifiers (the mechanism the lead points at); both were already landed or not covering the function call.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/BinderDriver.cs` (`BinderDriver.UserFunctionsOf`), `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/IntrinsicBinder.cs` (`IntrinsicBinder`), `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/UdfBinder.cs` (`UdfBinder.UdfBindCall`, `UdfBinder.UdfBindPointerCall`), `src/WiseOwl.Cobol.Compiler/Binding/ConfigurationSlice.cs` (`ConfigurationSlice.RefusedFunctionSpecifiers`), `src/WiseOwl.Cobol.Compiler/Binding/ConfigurationStep.cs` (the REPOSITORY inheritance), `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.cs` (the FUNCTION specifier binding), `src/WiseOwl.Cobol.Compiler/Binding/EditionContext.cs` (`EditionContext.NoteCauseReportedEarlier`).

## Resolution

Reproduced on the wave-20261905 build: `FUNCTION MYF AS ""` drew COBOL1761 at the specifier and COBOL1505 at `FUNCTION MYF(1)`. A refused literal-5 registers no `FunctionSpecifiers` row, so the reference found no prototype. Fix: `ConfigurationSlice.RefusedFunctionSpecifiers` (the function twin of `RefusedProgramSpecifiers`, recorded by the specifier binding, inherited by `ConfigurationStep`) is asked by `UdfBinder.UdfBindCall` and `UdfBindPointerCall` before the prototype table, so the reference adds no COBOL1505 and cannot resolve the bare word to a same-named group function. The statement funnel still requires an error per refusal node, so `EditionContext.NoteCauseReportedEarlier` answers for the earlier report. Test: `ExternalRepositoryResolutionTests.AReferenceToAFunctionWhoseLiteral5IsRefused_AddsNoCascade`; golden `pb4822-function-literal5-refused-reference`. `IntrinsicBinder` and `BinderDriver.UserFunctionsOf` needed no change.
