**Landing (2026-11-16, branch fix/pb5801-level66-places).** Re-probed first on this branch's build: all five repros
(`ren_fs`, `ren_lin`, `ren_dep`, `ren_rel`, `ren_ctl`) ended with `Unhandled exception: System.InvalidOperationException:
no Place was built for data item ...` at `--std 85` and `--std 2023` (exit 1); `ren_ctl0` compiled (exit 0).

**Mechanism.** `DataBinder.PlaceableItems` walked the storage tree (`DataItem.SelfAndDescendantsOf`), where a level 66
entry never appears: it rides its owner's `Renames66`. `PlaceBuilder.PlaceForItem` already builds a 66 entry's place
(`PlaceForRenames`: the renamed item's place carrying `DenotesAs`, or a `RenamesPlace` for THROUGH), so the table only
had to be asked for it. Every by-item reader of the table (`FileStatusOf`, `RelativeKeyOf`, `LinageOpExpr`,
`VaryingDepending`, ASSIGN USING, `PlaceTablePass`'s CONTROL loop, `ReportWriterEmitter`'s DEPENDING item, the SELECT
WHEN condition parent) asks through the one table, so the fix is one place: `DataItem.SelfDescendantsAndAliasesOf`, the
walk of every item a data-name can reference, and `PlaceableItems` walks it (the GLOBAL file path,
`GlobalPlaceableItems`, follows, since a 66 entry's `Root` is its owner's).

**Sibling found and fixed.** With the crash gone, the 1985 CONTROL witness exposed a second defect: the
§1985:XIII.3.20.3 SR5 USE half (`ReportWriterBinder.CheckControlDataReferences`) asked `Place.Item`, the attributes half,
so `DISPLAY RX` in the control footing's USE procedure, RX being the control itself, was refused (COBOL6825) as a
reference to the item RX renames. It now asks `Place.DenotedItem` (kb/Work PB602's identity half).

**Sweep (probes at 85, 2002, 2023, each exit 0 or a diagnostic, none an exception).** LINAGE with FOOTING/TOP/BOTTOM,
OCCURS DEPENDING ON, RECORD KEY and ALTERNATE RECORD KEY (plus READ KEY and START KEY), a THROUGH alias as RECORD KEY and
FILE STATUS, PADDING CHARACTER (85 and 2002; refused COBOL0902 at 2023, removed in 2014), CONTROL and CONTROLS ARE CX RX,
SOURCE and SUM, ACCEPT, DISPLAY, SEARCH VARYING, CALL USING, a SORT key, ASSIGN USING (2002 and 2023; refused COBOL0900
at 85), and a GLOBAL file's FILE STATUS used by a contained program.

**Open reading.** `1985-SR-XIII.3.7.3-2` ("Each recurrence of data-name-1 must identify a different data item"):
`CONTROLS ARE CX RX` (RX renames CX) compiles at 85; whether a no-THROUGH 66 entry and its renamed item are two data
items for that rule is an adjudication, not this fix, so the row gained no witness.
