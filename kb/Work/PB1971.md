# PB1971

Filed by the train-1015 lander from wave 1015 group X's lead 4 (PB1062).

## Rule

§8.4.3.11.3 1): "Identifier-1 shall not be defined in the working-storage or file section of an object or a factory
object." (`cite.py --check 8.4.3.11.3 "Identifier-1 shall not be defined in the working-storage or file section of an
object or a factory object"` -> OK §8.4.3.11.3 1)).

## Gap

PB1062's negative `tests/conformance/negative/pb1062-address-of-object-data.cob` writes the WORKING-STORAGE arm (object
and factory). The FILE SECTION arm goes through the same predicate (`src/Cobol.Net.Compiler/Binding/DataBinder.Oo.cs#OoIsObjectData`, ~line 257,
reached from `PtrBinder.PtrBindAddressOf` via `AddressOfOperandScreen`), but no source writes an FD inside an
OBJECT or FACTORY definition and takes ADDRESS OF its record, so a regression in that arm would be green.

## Next step

Add a negative (2002+) with an FD in the OBJECT and in the FACTORY definition, ADDRESS OF each record, expecting
COBOLNET2784 twice. If the object/factory file section does not reach the predicate, this becomes a defect.
