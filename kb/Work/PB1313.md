# PB1313 — OPEN — `IS-A OF R1` becomes `IS-AOFR1`

## Measured (`diag2.cob`, `--std 2023`)

```cobol
       01 R1.
          05 IS-A PIC X.
       01 R2.
          05 IS-A PIC X.
       01 C PIC X.
          88 C-Y VALUE "Y".
       PROCEDURE DIVISION.
           EVALUATE IS-A OF R1
             WHEN C-Y OF R2 DISPLAY "X"
           END-EVALUATE.
```

```
diag2.cob(12,12): error COBOLNET1639: 'C-Y OF R2' does not identify a condition-name — …      ← WrittenText: right
diag2.cob(12,12): error COBOLNET1634: the selection subject is an identifier and the selection object
  'C-YOFR2' is a condition; ISO §14.9.13.3 SR10 Table 15 marks that combination invalid.      ← GetText: wrong
```

The same run shows one diagnostic spelling the operand correctly and the next one spelling it wrongly.

## Mechanism
`ParserRuleContext.GetText()` concatenates the leaf tokens with no separators. `DataBinder.WrittenText`
(`src/Cobol.Net.Compiler/Binding/DataBinder.cs:1363`) reads the source extent instead. It keeps one space per
separator run and falls back safely on an error-recovered node. PB589's implementer moved only the SET site
(`SetBinder.cs:1356`).

The `dref.GetText()` sites on main `071ff04ea`, by file (29 in all):
- 3 in `DataBinder.cs`.
- 2 each in `DataBinder.Reports.cs`, `PtrBinder.cs`, `InitializeBinder.cs`, `ControlFlowBinder.PerformVarying.cs`,
  `ConditionBinder.cs` and `CallBinder.cs`.
- 1 each in `StatementValidation.cs`, `SearchAllFormat2Rules.cs`, `ReferenceResolver.cs`,
  `StringUnstringBinder.cs`, `SortBinder.cs`, `SetBinder.cs`, `SetAlterBinder.cs`, `OoBinder.cs`, `MoveBinder.cs`,
  `InspectBinder.cs`, `AcceptDisplayBinder.cs`, `ExpressionBinder.cs`, `DataBinder.Oo.cs` and
  `DataBinder.Linkage.cs`.

The 1634 site is EVALUATE's selection-object text. It interpolates a condition context's `GetText()`, not a
`dref`, so the sweep has to cover every `ctx.GetText()` inside a message, not only `dref`.

## What the fixer owes
- Every user-facing operand text (diagnostics, `NotImplemented` feature strings, trace text) goes through
  `WrittenText`.
- A **drift test** fails on a `.GetText()` interpolated into an `Edition.Error`/`Warning` call or a
  `NotImplemented`/`LoudValue` string. An allowlist covers the sites that use `GetText()` as a KEY, for name
  lookup or keyword tests, and not as display text.
- One negative golden with a qualified operand in the message, e.g. this repro's 1634.
- **Not the same root as PB567** (condition-name qualification semantics, landed).
