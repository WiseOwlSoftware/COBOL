# PB1674 — OPEN

Filed 2026-09-28 by the train-69 lander from the wave-69 Z finisher report (`w69z-PB1084-report.md`, "New
defects"). Same root as PB1243: the global-subtree inheritance misses a name class.

**What happens.** Repro (compile at `--std 2023`):

```
       IDENTIFICATION DIVISION.
       PROGRAM-ID. ZC3OUT.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 D-G GLOBAL.
           05 D-TAB OCCURS DYNAMIC CAPACITY IN D-CAP FROM 1 TO 4.
               10 D-X PIC X(2) VALUES ARE "AB" "CD" FROM (1) TO (3).
       PROCEDURE DIVISION.
           CALL "ZC3IN"
           STOP RUN.
       IDENTIFICATION DIVISION.
       PROGRAM-ID. ZC3IN.
       PROCEDURE DIVISION.
           DISPLAY "IN CAP=" D-CAP
           GOBACK.
       END PROGRAM ZC3IN.
       END PROGRAM ZC3OUT.
```

→ COBOLNET1639 `D-CAP is not defined`.

**Rule.** §13.18.38.3 SR30 (`cite.py --check 13.18.38.3 "Data-name-3 shall not be defined elsewhere in the source
element"` → OK §13.18.38.3 30)): "If qualifiers are required for uniqueness, it shall be treated as though
implicitly defined at the same level as the entry containing the OCCURS clause" — i.e. subordinate to the GLOBAL
record; §8.4.6.2.2 (`cite.py --check 8.4.6.2.2 "subordinate to a global name are global names"` → OK): "All
data-names and screen-names subordinate to a global name are global names".

**Code site.** `src/Cobol.Net.Compiler/Binding/DataBinder.Linkage.cs#InheritGlobalSubtree` never inherits
`_capacityRegisters` (registered in `DataBinder.Odo.cs` ~409-426); the bridge list (`GlobalBridgesOf`) must also
carry the register's cell.

**What the fixer owes.** Inherit the register at the subtree's depth (so §8.4.6.2.1 3)'s nearest-tier rule applies
to it too), bridge its storage, and sweep every other implicitly-defined name class for the same miss; a 2023
positive golden with a nested reader and writer of the register.

## Revisit before implementing (triage 2026-09-29, batch 9)

**Not taken: same root as PB1243, so the fix should be the ONE list of name classes a GLOBAL subtree hands to contained programs.** Prerequisites: enumerate every name class `InheritGlobalSubtree` must carry (data-names, condition-names, RENAMES, index-names — done — and the OCCURS DYNAMIC CAPACITY IN registers, plus anything else the binder synthesizes for a GLOBAL item), express it once, and pin it with a drift test so a new synthesized name class cannot be forgotten; then a golden with the note's `D-CAP` shape read from a contained program.
