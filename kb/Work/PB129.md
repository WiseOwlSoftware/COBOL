# PB129

Rows: GR-14.9.12.4-4/-5/-6/-7, GR-8.8.1.2-1, GR-14.9.2.4-5 (aggregation untested).

Four mechanisms, one campaign. (1) ArithmeticEmitter.EmitArith wraps the whole per-receiver store loop in ONE try; CobolNum.DivideOrThrow's PROHIBITED throw unwinds it, so `DIVIDE A BY B GIVING E ROUNDED MODE IS PROHIBITED F ON SIZE ERROR …` leaves F unstored where §14.7.7 r4b requires processing to proceed to the next resultant (repro in the rows: E=8.8 stays, F must be 1.04, emitted leaves 8.00). Per-receiver try. (2) EmitDivideRemainder stores identifier-4 unconditionally after the quotient's size error (GR6c: only if not raised) and never gives the subsidiary quotient identifier-3's DIGIT capacity (Q PIC 9 stores 3 while qt keeps 333 — R wrong with no phrase at all). (3) NumericRenderer._outermost is cleared for children only by Visit(BoundBinary); Negate/Power/ComputedOperand recurse with it set, so `(1 / 3) ** 0` under PROHIBITED reinstates the exact pre-CA5 spurious EC-SIZE-TRUNCATION, and `(A / B) ** 2` computes at the receiver's scale (mode-free witness: 11.1086 vs 11.1111 — multiplying by 1 changes the value). CA5 fixed one of three arms. (4) The GR7 back-multiply `({qt} * {divisor})` is a raw splice bypassing CombineNative's Checked MulChecked fork — an Int128 wrap the composite licence does not cover.
