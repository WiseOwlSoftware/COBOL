# PB1576

Found 2026-09-25 by the w59h finisher. Add a drift test that enumerates every axis ConformanceDescriptor encodes and
asserts DescriptionMismatch compares it (or derive one from the other — rule 5: one rule in one place).

## Task brief (research 2026-09-30)

**Premise partly overtaken.** A drift guard exists since kb/Work PB1166:
`tests/Cobol.Net.Tests.Unit/PictureClauseIdentityDriftTests.cs#ConformanceDescriptor_AgreesWithTheComparator_OverEveryCarriedPair`
(equal descriptors ⇔ the comparator conforms, over a PICTURE population). It does NOT cover groups (`S:`/`V:`/`G:`),
pointers (`P:`), object references (`O:`) or strong types — and its invariant is itself the wrong target: §9.3.6's MATCH
is not equality of the §14.8.2 conformance projection (groups: kb/Work PB1780, PB480).

- **Change:** land WITH PB480 — a reflection-driven test over `ActivationDescription`'s fields asserting each field is
  read by `ActivationRelations.Matches` or `.ConformanceViolation` (or carries the §-clause that makes it irrelevant),
  and delete `ConformanceDescriptor_AgreesWithTheComparator` with the string it guarded. If PB480 is not scheduled in the
  same batch, the interim fix is to extend the existing matrix to groups, pointers and object references — but that is
  work thrown away by PB480, so prefer landing together.
- **Size:** included in PB480's slot.

## 2026-10-12 (w1069x, Mythos) — closes with kb/Work PB3101

with the comparator and `OneRelationDriftTests` asserts structurally that the conformance question has one asker.
