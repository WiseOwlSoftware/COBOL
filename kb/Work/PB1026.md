# PB1026 — OPEN

## The rule
`OK  §13.18.22.4 4)` — "If the EXTERNAL clause is specified in a file description entry: a) the file connector associated
with this file description entry is an external file connector; and" (b) the record area is shared by every program
that describes the file EXTERNAL.

## What the fixer owes
The run-unit's EXTERNAL cell must carry the whole shared area PB981 defines (character half AND the out-of-line
members), so every program describing the file sees the same record; goldens with two separately-compiled programs.
