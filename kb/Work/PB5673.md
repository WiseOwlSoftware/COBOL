# PB5673 - a filtered differential run is treated as the whole population

**Finding.** `scripts/gnucobol_differential.py` takes `--only`, a prefix of the `.at` wrapper file name (it has no help
text), and passes it to `gnucobol_extract.differential_cases`. Three arms of `main()` then treat the filtered selection
as if it were the whole corpus:

1. **An empty selection reads green.** `--only syn_file:108` (a case id, which is no wrapper prefix) selects 0 cases;
   the run prints `=== DIFFERENTIAL: 0 PER-CASE FLIP(S) ===`, the exact line `scripts/battery.sh` greps for the leg's
   green, and exits 0. Measured 2026-11-15 by the command in `source`.
2. **Every unselected case is reported REMOVED.** `diff_baseline` diffs the selection against the whole manifest, so a
   run under `--only syn_file` says `corpus changed: 0 NEW case(s), <all the others> REMOVED - not flips, but explain
   them`. The corpus did not change; the run was filtered.
3. **`--write-baseline` under `--only` is not refused** (read from the code, not run: `write_baseline(a.baseline,
   results, a.record)` has no guard on `a.only`), so it would rewrite the manifest with the subset alone and drop every
   other row.

**Root.** The population a run is ENTITLED to judge is not a value in `main()`: the baseline is read whole whatever
the filter is. The fix gives the filtered run its own scope: an `--only` that selects nothing is an error that names
the value and the wrappers that exist; the per-case diff under `--only` compares against the manifest rows of the
selected wrappers only and says so; `--write-baseline` with `--only` is refused; `--only` gains help text.

**Sites:** `scripts/gnucobol_differential.py` (`main`, `diff_baseline`).
