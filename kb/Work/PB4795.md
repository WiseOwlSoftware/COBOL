# PB4795 - the PB4757 mechanism survives for every other call over the same item

**What the report says (the reviewer's words).** R1-3 LEAD (low, not blocking at round 1): `src/WiseOwl.Cobol.Compiler/Binding/IntrinsicArgumentRules.cs:2031` The PB4757 mechanism survives for every other call over the same item (`S2 + FUNCTION MAX (S2)`, `S2 + FUNCTION ABS (S2 + 1)`); left for the clerk.

**New defects / leads paragraph of the same report (one mechanism).** Same root as R1-3: `S2 + FUNCTION MAX (S2)`, `S2 + FUNCTION ABS (S2 + 1)` fail open; ABS of an expression and one-argument MAX/MIN/SUM identities are not read (`IntrinsicArgumentRules.cs` `CollectAdditive` call arm).

**R1.** A grep of kb/Work for `CollectAdditive` finds PB4757 (landed, the note whose fix wrote the call arm) and landed PB1526, PB248, PB617. No open note covers it.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/IntrinsicArgumentRules.cs#CollectAdditive`.

**Fix (landed, wave 20261881 group B).** Re-probe on the pre-fix build: `FACTORIAL (S2 + FUNCTION MAX (S2))` and `FACTORIAL (S2 + FUNCTION ABS (S2 + 1))` compiled (the call arm read only `ABS` of a bare item). `CollectAdditive`'s call arm is now `ReadCall`: a one-argument MAX, MIN, SUM, MEAN, MEDIAN or MIDRANGE is its argument (the spec's one-occurrence equivalents, 15.59.4 1), 15.63.4 1), 15.88.4 1) a), 15.60.4 1) a), 15.61.4 1), 15.62.4 1)); a table(ALL) argument is excluded; `ABS` of a sum of items and constants that cannot be negative where the items are not negative is read as the sum (`AdditiveSpine.AbsOfSum`). Witnesses: `pb4795-max-identity-sum-non-integral`, `pb4795-abs-of-sum-non-integral` (refused, COBOL1627), `pb4795_identity_difference_legal` (accepted).
**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/IntrinsicArgumentRules.cs#CollectAdditive`, `#ReadCall`, `#ValueOfArgument`, `#BareNumericItem`, `#IsNeverNegativeWhereItemsAreNot`, `#OneArgumentIdentities`.
