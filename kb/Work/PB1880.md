## Adjudication 2026-09-30: which of the five tests pin spec-required behavior (read-only ISO check, citations checked)

1. `RegisterReport` emitter test: an internal choice (the standard has no rule about a stderr notice). The ISO-observable part is 9.1.13.2 1) "I-O status = 00" on OPEN EXTEND: assert that (conformance witness) and that no notice is emitted (quality witness).
2. ODO READ validation: all three sub-cases are spec-required witnesses. 9.1.13.6 4) b) gives status 34 when the DEPENDING ON item makes the record exceed "the value specified or implied by the file description entry"
   (a) an explicit RECORD clause is "specified"; (b) a BIT table: 13.18.43.4 GR4 "the record size includes the entire byte in which that data item ends"; (c) the rule does not require the DEPENDING ON item to lie inside the record.
3. PB1562 round trip for relative and indexed files: witnesses the documented D-FRA (vi) form, an implementor determination, not a requirement. One part is spec-anchored: for indexed files the key window must be the same in every record (9.1.7.4: key components are fixed file attributes).
4. WRITE WITH LOCK under a permanent error: spec-required (9.1.13.1 "remains in effect for all subsequent input-output operations on the file unless an implementor-defined technique is invoked"; CLOSE is that technique, DOC-A.1-105).
5. National blank-area pad: spec-required only for LINE SEQUENTIAL (14.9.30.4 GR15, "a trailing space is defined to be the national space character"); for record-sequential and relative files the tail is "undefined" (GR14), an internal choice. Check which file kind "sequential" means here before writing the test.
