# PB6049 - suite 85 Stage 0: the NIST-85 unit list and its mechanical map to 1985 rows through NIST's own ANSI references (design §6.3, S17's first half)

Revision 4 of `docs/rearchitecture/DESIGN-conformance-suite.md` (§8 Stage 0, §13), decided in kb/Work PB6046.

Enumerate NIST CCVS85's 6,969 units (6,929 paragraph-name tests and 40 OBSOLETE flags; the 17 FIPS programs `excluded`,
decision 11). Resolve each program's ANSI-REFERENCE settings and each format-keyed paragraph name (`MPY-TEST-F1-n`)
to 1985 catalog rows through `cite.py --edition 1985`, which revision 3 could not (it called the 1985 text unheld).
Output: units mapped, ambiguous (several candidate rows), unmapped, per program, as `tests/nist/crosswalk/<program>.json`
with the `rows`/`excluded`/`open` dispositions of design §6.3 (no `unit` class: the 1985 catalog holds Segmentation,
Debug and ALTER). Feeds PB6047's NIST term; the residue is Stage 4 (PB4696).

**Sites:** conformance-suite/harness/crosswalk.py (parse_program, flagged_statement, parse_reference, Catalog, resolve, by_name, map_unit, map_flag, build_program, audit, audit_elements, audit_unit, owed, unmet); conformance-suite/harness/obligations.py (facts_of_repository); tests/nist/crosswalk/ (new, one file per program, read by crosswalk.py); conformance-suite/harness/selftests/crosswalk/test_crosswalk.py; conformance-suite/README.md; docs/rearchitecture/DESIGN-conformance-suite.md (section 6.3, 8, 13)

**Landed.** `harness/crosswalk.py` enumerates the units of the 459 programs (7,101: 6,884 distinct paragraph names in 389 programs,
40 OBSOLETE flags, 177 FIPS flags; the design's 6,929 counted spacing variants of one name apart) and writes
`tests/nist/crosswalk/<program>.json`. The held 1985 text is not NIST's: NIST's section numbers run one short from ENTER
onward (its MULTIPLY units cite 6.19.4, the held MOVE), so a reference maps a unit to rows only when it names its rules and the
section's subject agrees with the unit's own words. Result: 347 units `rows`, 4,095 `open`/`ambiguous` (candidates from the literal
reference or from the one section the unit's words name), 2,482 `open`/`unmapped` (2,422 set no reference), 177 FIPS flags
`excluded`, 7 `unenumerated` table-driven PAR-NAME moves (DB105A, NC107A, NC210A, OBIC1A, OBIC3A), owed. Obsolete-flag
units map through Appendix C.1 (the catalog's `obsolete: C.1(n)` rows). `unmet(85)` is the status line's NIST term: at
this landing `=== SUITE 85: INCOMPLETE — rows 2961 · points UNMEASURED · NIST 6931 · second compiler 211 · transcription UNMEASURED ===`.
`crosswalk.py --check` audits every file against its program and the catalog and the element table against Appendix C.1;
self-test `selftests/crosswalk/test_crosswalk.py`. The residue (4,095 + 2,482 units and the unsubsumed rows) is Stage 4 (PB4696).
