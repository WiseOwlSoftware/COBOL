# PB1030 — LANDED

## What the fixer owes
Change the resolver's return type to a closed result (Place | Reported | Deferred) so every caller must handle the three
cases, delete the null checks, and let the compiler find every site that assumed non-null. Each Deferred arm names the
note that owns building it.

## State after PB1029 (wave 54 group G) — the starting point for the fixer
PB1029 put every refusal node on a ledger the statement funnel checks, and moved the resolver-null `BoundNop` sites
(14: ACCEPT/INSPECT/STRING/UNSTRING receivers through `ExpressionBinder.ResolveReceiving`, SET LOCALE / SET receivers,
the OO SET object-reference receiver) to `BoundUnsupported`, and the operand-level resolver nulls
(`ExpressionBinder` `RefFailure` ×2, INSPECT operand, the table(ALL) addressing arms, the UDF result temporary) to
`BoundXError.Unbuilt`. Both are still classified by "did this statement draw an error" — the heuristic this note
replaces. The typed result should make each of those sites choose `Refused` (Reported) or `Unbuilt` (Deferred) from
the resolver's answer, and let `EditionContext.NoteUnbuilt` carry the owning note id of each Deferred arm.

## Landed (wave 55 finisher D, 2026-09-22)
Re-probed on the finisher's own build first: `DISPLAY E("A")`, `DISPLAY E(ALL)`, `DISPLAY AL` (an alphabet-name) and a
RENAMES THRU over a COMP leaf all compiled with the COBOLNET1756 "not implemented" warning and aborted the run unit;
`MOVE "A" TO E("A")` / `MOVE X TO E(ALL)` drew COBOLNET0899's "not yet implemented" promise. Three of those are ILLEGAL
source the compiler announced as its own gap.
- `RefResolution` (`src/Cobol.Net.Compiler/Binding/RefResolution.cs`) is the resolver's closed answer — `Place`,
  `Reported`, `Deferred` — and `DeferredShape` is the ONE census of unbuilt reference shapes (each with its text).
  `ReferenceResolver.Resolve` / `ResolveForItem` and `ExpressionBinder.ResolveSending` return it; every caller builds
  its node FROM it (`Refusal` / `OperandError` / `ExprError` / `BoolError`, or `PlaceOrReported` where the caller
  cannot carry a deferral — reported there as COBOLNET0899). The resolver puts every deferral on the unbuilt ledger
  before a caller sees it, so a caller that drops the answer cannot make it silent. `RefFailure` and the per-site
  "unresolvable" errors on top of the resolver's own (SET ENTRY, INVOKE method-name, SORT key, CALL operands …) are gone.
- Every null arm was classified by reading the rule, not by counting errors: a segment that does not parse as an
  arithmetic expression is not a subscript (§8.4.2.3.2; the word ALL outside §8.4.2.3.3 SR6's two contexts; a
  reference-modifier bound per §8.4.3.3.3 SR4) and is now COBOLNET2363 at the materializer; a reference to a refused
  declaration (a Tier-D REDEFINES view, a RENAMES whose operands did not resolve, a SCREEN SECTION name) is COBOLNET2364;
  an alphabet-name where a data item is required is COBOLNET1639 (§8.4.2.1, R38's strict-ISO adjudication).
- `ReadSubscripts` is now the ONE reading of a written subscript list for all three identifier entries (Resolve,
  ResolveForItem, ResolveForAddressOf each carried a copy).
- Owners of the Deferred arms are UNFILED: the census names the shapes, and the wave-55-D report carries them as leads
  for the registrar (RENAMES THRU over a leaf with no character image, §13.18.45.4 GR2, is the one measured legal shape).
Goldens: `tests/conformance/85/pb1030_reference_answers` (positive) and five negatives `pb1030-*`. Drift:
