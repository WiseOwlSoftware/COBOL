# R39 — a REPLACE statement with non-pseudo-text operands is silently half-parsed: the illegal statement draws no diagnostic and the failure surfaces downstream

> Found 2026-08-08 during R36's adjudication probes (the syn_copy:686 GCOS/ACU vendor shape).

PROBE: `REPLACE LEADING "PREFIX-" BY SPACES.` — literal partial-word operands, which REPLACE's general
format has NEVER admitted in any ISO edition (its operands are pseudo-text; COPY's literal operands were
the thing 2023 removed, and COBOLNET0902 rides COPY's parse only, deliberately). Our
`ApplyReplaceStatements` half-parses the statement, applies nothing, reports NOTHING about the REPLACE
itself, and the program fails downstream as COBOLNET1639 on the never-replaced name — the R34 shape
(the verdict right-ish, the reason misleading, the statement's own illegality unnamed) at 2014 and 2023
alike.

FIX SHAPE: `ApplyReplaceStatements` is static with no diagnostics path — thread the bag (its callers
have one) and report a REPLACE operand that is not pseudo-text with its own diagnostic citing the
REPLACE general format (verify the exact clause number with cite.py before coding — 7.2.4.2 assumed
here from the 7.2.3-COPY neighborhood). The GCOS/ACU semantics (literal partial-words, BY SPACES
deletion) remain a vendor-axis candidate alongside [[R36]]'s record; GnuCOBOL itself gates them behind
-fpartial-replace-when-literal-src.

## LANDED 2026-08-08

**COBOLNET1641** (`replace-operand-not-pseudo-text`): `ApplyReplaceStatements` takes an optional
`DiagnosticBag` + source name (both callers thread theirs), and the SAME `NoteNonPseudoText` hook the
COPY 0902 gate rides now reports for REPLACE — one detector, two rules, each cited at its own site
(§7.2.4.2's format; §7.2.4.3 SR7 cite.py-checked, barring literals as partial-words — REPLACE's
operands were never literals in ANY edition, unlike COPY's removed-in-2023 forms). One report per
REPLACE statement, at its line; parsing continues so the downstream posture is unchanged. Probes: the
GCOS/ACU form draws 1641 at the statement (was: silence + downstream 1639); the three ISO pseudo-text
forms stay green. Fixture `replace-literal-partial-word` (reject-at 2002 2014 2023, registered).
DIAGNOSTICS.md regenerated. Gate: full Unit 4099/4099 · Intrinsic|Corpus 667/667 ·
characterization 33/33.
