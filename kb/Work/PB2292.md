**Found by:** the R1 refuter (wave 1031, C7, carried as a lead), checking `DESIGN-architecture-review.md` §8.4's claim
about ANTLR imports.

**Sites:** `src/Cobol.Net.Frontend/Grammar/Core/CobolExpressions.g4:336` (`className : NUMERIC | ALPHABETIC | … |
cobolWord | BOOLEAN | FLOAT_* …`, the class-condition operand) and `src/Cobol.Net.Frontend/Grammar/Core/CobolOO.g4:56`
(`className : cobolWord ;`, the OO class name). `CobolParserCore.g4:16` imports `CobolExpressions` before `CobolOO`.

**Repro:** `python -I E:/COBOL-coord/scratch/w1031-refute/c7_rules.py` from the repository root prints
`duplicate parser rule names: 1` / `className ['CobolExpressions.g4', 'CobolOO.g4']`. ANTLR 4's `doc/grammars.md`: "If
two or more imported grammars define rule r, ANTLR chooses the first version of r it finds" (depth-first), so the
Expressions definition is the one every `className` reference uses.

**The rule it breaks:** one rule in one place (CLAUDE.md rule 4's sibling, `feedback_one_rule_one_place`): two
different productions share one name, and which one the OO clauses get is decided by the import order, not by the
grammar's text. The OO references (`CLASS-ID`, `END CLASS`, `INHERITS`, `OBJECT REFERENCE`) take the class-condition
keyword set (`NUMERIC`, `ALPHABETIC`, `BOOLEAN` …) as a class name.

**Scenario:** `CLASS-ID. NUMERIC.` (a reserved word in the class-name position) reaches the binder as a class named
NUMERIC instead of a syntax error at the name; whether a later check refuses it is the fix lane's first measurement
(a probe program at `--std=2023`), and it confirms or clears the `under_rejects` flag set here for the parse-level acceptance. A second
scenario: DESIGN-architecture-review §8.4's fragment regroup changes the import list, and the OTHER definition would
silently win.

**Fix shape:** rename one rule (the class-condition operand is `classConditionName` or the OO one `ooClassName`),
change every reference in the same change, and add the grammar drift assertion §8.4 names: no rule name is defined in
two fragments. Goldens: the token-stream and parse-tree shape over the corpus must be unchanged except at OO class
names.

**Model:** Opus (a `.g4` change; area grammar routes to Opus).
