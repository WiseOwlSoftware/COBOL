## 2026-09-02 — the sweep found a GRAMMAR-COMMENT cluster, and it has a concrete consumer

Building the Phase-B dossier surfaced a whole class this note had only sampled. A heuristic sweep over the
statement-header comments in the `.g4` files (script:
`E:\Temp\claude\E--CobolSharp\c609c011-7fda-4dbc-a369-a563a47cedd1\scratchpad\pb_citation_sweep.py`) produced
**92 candidate wrong clause numbers**; **8 were hand-verified**, each re-derived with `cite.py --check` in both
directions — the number that is there, and the number that should be:

| site | cited | actually names | correct |
|---|---|---|---|
| `CobolParserCore.g4:813` ROUNDED | §14.9.4 | CALL statement | **§14.7.4** (ROUNDED phrase) |
| `CobolParserCore.g4:847` ADD | §14.9.1 | ACCEPT statement | **§14.9.2** |
| `CobolParserCore.g4:894` SUBTRACT | §14.9.42 | STOP statement | **§14.9.44** |
| `CobolParserCore.g4:927` MULTIPLY | §14.9.23 | INVOKE statement | **§14.9.26** |
| `CobolParserCore.g4:1009` MOVE | §14.9.24 | MERGE statement | **§14.9.25** |
| `CobolParserCore.g4:1338` GOBACK | §14.9.16 | GENERATE statement | **§14.9.18** |
| `Core/CobolIO.g4:250` OPEN / CLOSE | §14.9.25, §14.9.7 | MOVE statement, COMMIT statement | **§14.9.27, §14.9.6** |
| `Core/CobolIO.g4:279` OPEN tape phrase | §14.9.25 | MOVE statement | **§14.9.27** |

⛔ **The shape is the danger: every wrong number is a VALID clause naming a DIFFERENT REAL STATEMENT.** None is a
typo that dangles, so nothing that merely asks "does this clause exist" can see any of them — the check has to
compare the clause against the construct the comment is about. This is `feedback_a_real_clause_can_answer_a_different_question` at grammar scale.

**Concrete harm, measured not supposed.** The dossier's grammar arm (`build_dossier`) matches a `.g4` rule to a
subject three ways, one of which is *the clause its comment block cites*. So these comments now steer
adjudication: running `phase_b_batch.py 14.9.25` (MOVE) returns a grammar list containing **`openFileSpec`
(`Core/CobolIO.g4:281`)** among MOVE's rules, purely because that rule's comment cites §14.9.25. An adjudicator
reading MOVE's dossier is handed an OPEN-statement rule as evidence about MOVE.

A separate agent is repairing the eight; the remaining ~84 candidates are unverified heuristic hits and are the
rest of this sweep. **PB159 stays open.**
