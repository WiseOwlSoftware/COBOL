# PB3983 — OWNER DESIGN CALL: constant-expression reference-modification positions (T(1 + 0:2), T(-0:2), T((ZERO):2), T(1:2 + 9)) are not screened at compile time although Position.ConstantValue folds them

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/ReferenceResolver.cs:838` (`ReferenceResolver.LiteralPosition`, `ReferenceResolver.LiteralRefModRangeViolation`), `docs/CONFORMANCE.md` (DOC-A.1-69)

Found while fixing PB3960: branch `worktree-wf_53929e80-790-5` (PR #717, in the merge queue). It records the question and the evidence;
it does not decide.

> LiteralPosition (ReferenceResolver.cs) judges only a sole integer literal/ZERO; constant expressions T(1 + 0:2), T(-0:2), T((ZERO):2),
> T(1:2 + 9) over a fixed item still reach run time although Position.ConstantValue folds them (shares root with PB3960's screen;
> DOC-A.1-69 says expressions are never screened - a design call for the owner, not a bug fix).

## The question
`LiteralPosition` (on main at `ReferenceResolver.cs:838`) judges only a sole integer literal (ZERO too once PB3960 lands); the ONE
screen (`LiteralRefModRangeViolation`, §8.4.3.3.4 5) b)/c) against a FIXED-size item, COBOL2670 / COBOL2671) therefore never sees a
position written as a constant expression, although `Position.ConstantValue` already folds those expressions. Such a program still
compiles and reaches run time, where EC-BOUND-REF-MOD ends it (checking on) or the run unit ends (checking off).

`docs/CONFORMANCE.md` DOC-A.1-69 (an implementor-defined, optional detection under §14.6.13.1.3) states the present choice: "An
expression or data-item position is never screened; it is the run-time test's." Widening the screen to folded constant expressions
is a documented-behavior change (the DOC row and its conformance case move with it), not a bug fix.

## Options for the owner
1. Keep: expressions are never screened (the DOC-A.1-69 text stands; this note closes as decided).
2. Screen any position `Position.ConstantValue` folds, with the same COBOL2670 / COBOL2671 split; update DOC-A.1-69 and add goldens
   for the four shapes above.

## Acceptance
- The owner's choice recorded here; if option 2, the screen, DOC-A.1-69 and goldens land in one change set.
