# PB3574

## Scenario

Review of PB3513 (PR #432), lead R1-2 (info, same report as PB3573).

`CobolNum.DeviceDecimal.cs` doc comments (the `commaMode` parameter and the reader summary, branch
`worktree-wf_37d4041f-6f7-6`) cite "§12.3.7.4 GR14 a)" for the decimal separator of the device text. `python scripts/spec/cite.py --check 12.3.7.4` shows rule 14) is
"If the DECIMAL-POINT IS COMMA clause is specified, the functionality of the characters used to represent the decimal
separator and the grouping separator are exchanged"; its a) governs only the character written in numeric literals. The
exchange of the separators is the 14) lead sentence. docs/CONFORMANCE.md and the conformance test cite GR14 correctly.

## Fix shape

Re-cite as "§12.3.7.4 GR14" (lead sentence) in every comment of the file, sweep the runtime for the same "GR14 a)" misuse
with `--check`. Land after PR #432.
