# PB5417 - at --std 85 VALUE OF data-name-1 accepts a group item whose own entry specifies USAGE IS INDEX: ResolveValueOfDataNames refuses only an elementary index item

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/FileControlBinder.ObsoleteFdClauses.cs#ResolveValueOfDataNames`

**Mechanism.** `ResolveValueOfDataNames` refuses (COBOL6849) a data-name-1 whose elementary usage is INDEX. USAGE may be written at group level and then applies to each subordinate (`§1985:VI.5.14.4 GR1`), and the rule bars "an item described with the USAGE IS INDEX clause", which the group's own entry is. So `01 G-IX USAGE INDEX. 05 A-IX. 05 B-IX.` named as data-name-1 is accepted while its subordinate `A-IX` is refused.
