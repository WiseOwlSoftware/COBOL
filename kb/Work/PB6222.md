# PB6222 — does GOBACK RAISING at 2002 import EXIT PROGRAM's rules?

PB6082 (with PB6175) gates GOBACK's RAISING phrase at 2002 on a determination. §2002:14.8.17.2 (the GOBACK syntax rules) holds one
rule, about declaratives with GLOBAL. §2002:14.8.17.3 GR1 (read in `specs/ISO_COBOL_2002.md`) says: "If a GOBACK statement is
executed in a program that is under the control of a calling runtime element, the program operates as if executing an EXIT PROGRAM
statement with the RAISING phrase, if any, that is specified in the GOBACK statement"; GR3 and GR4 say the same for a function (EXIT
FUNCTION) and a method (EXIT METHOD). The reading to confirm or overturn: GOBACK's RAISING is governed, for syntax, by the matching
EXIT statement's rules (which RAISING operands each unit kind accepts), though 2002 states it only as an execution equivalence.

**To decide.** From §2002 alone (rule 1; each edition on its own text), what GOBACK RAISING accepts in a program, a function and a
method at 2002, and whether the code's current gate agrees. Record the verdict in `kb/Work/PB6222/<date>-verdict.md`; a code change
(if any) is a defect note under the 2002 plan, which is frozen until its fix-train stage.
