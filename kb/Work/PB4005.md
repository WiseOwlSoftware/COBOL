# PB4005 — the once-check counts a repeated file path as a repeated rule

**Sites:** `.claude/skills/workstream/check_practices.py` (`repeated_sentences`, `check`), `.claude/skills/workstream/templates/dispatch-spec-implementer.md` (the `THE GROUP IS ONE ROOT: {root}.` line), `scripts/orchestrator/groups.py` (`body_of`: the `CODE SITES the notes name: {sites}.` clause)

## The defect

`plan_wave.py --from-budget --borrow-days 0` for wave 20261740 planned four groups and went RED on one:

```
FAIL     msg-w20261740-d.txt: missing ['PB3777: states twice: src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CallBinder.cs.…']
=== PRACTICES CHECK: RED (1) ===
```

Group D (PB3996) has one root file, `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CallBinder.cs`. The rendered
spec names it twice, and both times it is DATA, not a rule:

- line 15, from the template: `THE GROUP IS ONE ROOT: {root}. Your contract is ...`
- line 29, from `groups.py`: `... CODE SITES the notes name: {sites}. Re-probe each note ...`

`repeated_sentences` splits after `. ! ? : ;` followed by whitespace, so `ROOT:` and `name:` each end a "sentence" and
the bare path with its full stop, `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CallBinder.cs.` (65 characters),
becomes a sentence of its own. At 60 characters or more (`SENTENCE_MIN`) the second copy is refused. Reproduced on
the rendered file: `check_practices.repeated_sentences(text)` returns exactly
`['src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/CallBinder.cs.']`.

The trigger is a group whose root is ONE file whose path, with the full stop, is 60 characters or more, and whose notes'
code sites are that same file. Groups A to C of the same wave passed by luck. A and B name several files as code sites,
so the CODE SITES clause is no longer the bare root path (A: root `.../CodeGen/Verbs/ArithmeticEmitter.cs`, sites
starting `docs/CONFORMANCE.md,`). C names its root twice, but the path is shorter
(`src/WiseOwl.Cobol.Runtime/IO/KeyedConnector.cs.`, 48 characters). Most `src/WiseOwl.Cobol.Compiler/Binding/...` and `.../CodeGen/...` paths are that long, so the
check refuses a common shape of fix-lane group.

## What it cost

A RED plan reserves nothing (kb/Work PB2597's rule), so the wave unit can launch only by dropping the group: wave 20261740
was re-planned with `--max-groups 3`, which left out D (PB3996, a Format 1 CALL that accepts OMITTED). Every later plan
that ranks such a group in its first N fails the same way, so the note behind it is starved until someone notices.

## Acceptance

- The once-check refuses a repeated RULE and never a repeated datum. Either the check skips a "sentence" that is one
  token with no internal whitespace (a path, an id list), or the rendered spec stops restating the root as the code
  sites when they are the same set. Pick the root cause: if the CODE SITES clause adds nothing when it equals the root,
  it is the duplicate PB3777 meant to remove. Otherwise it is the check's sentence splitter.
- A self-test, seen RED first: a group whose single root file's path is 60 characters or more and whose notes name only
  that file renders a spec that `check_practices.py` passes. Keep a planted repeated rule refused (the existing
  `test_plan_wave.py` cases at lines 937 and 1389).
- Sweep: the other rendered fragments that state a path or an id list after a colon (the finisher spec, the
  predecessor and DEPENDENCY SUCCESSOR clauses, `requirements_text`) for the same false positive.
- Standing owner rules: fix the root causes, never simply making the diagnostic pass; always be consistent with
  ourselves barring an explicit requirement differently.
