# PB1068 — OPEN

## Measured
`DISPLAY FUNCTION BYTE-LENGTH(FUNCTION UPPER-CASE(X))` → `error COBOLNET1627: FUNCTION BYTE-LENGTH argument-1 is a
numeric literal, which §15.14.3 r1 does not admit`. `STRING ALL "AB" DELIMITED BY SIZE INTO Y` →
`COBOLNET1757: STRING sending operand 'ALL"AB"' is a figurative constant …` (the source reads `ALL "AB"`).
The refusals are right; the words are wrong.

## Code sites
`Binding/Procedure/Verbs/IntrinsicBinder.cs` ~2057 (LENGTH) and ~2394 (BYTE-LENGTH): the `_ =>` arm names 'a numeric
literal' — the PB70 misattribution shape, one arm per function. Operand text: `GetText()` at the new STRING / SPECIAL-
NAMES diagnostics; `DataBinder.WrittenText` covers data references only.

## What the fixer owes
Name the operand's actual kind (a function-identifier, a boolean expression, …) from ONE describer shared by both
screens; widen `WrittenText` to any parse node (token text joined with the source's spacing) and use it in every
diagnostic that quotes source.
