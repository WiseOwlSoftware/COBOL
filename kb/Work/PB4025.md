# PB4025 — `inert-watch` flaked once in the Linux half

**Sites:** `scripts/inert_lane.py` (`watch`), `scripts/linux-gate.sh:888-934` (the inert-watch leg).

**What.** On an earlier head of the PB3814 branch the Linux half's `inert-watch` leg reported RED once (16 inert directories
opened) and went GREEN on a rerun; the final gate's Linux half was GREEN. No cause was recorded. A leg that reads the file
system while the gate's own build writes it is the pattern PB3814 describes for the drift tests, so the first suspect is a
directory opened by the build or another leg in the same clone, not by the code under test.

**Next step.** Reproduce under load (two Linux halves at once), read what `watch` counts as "opened", and either make the
count exclude the gate's own writers or name the code that opened the 16. A flake left unexplained is a timing failure
(owner: a timing failure is a failure).
