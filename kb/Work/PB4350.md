# PB4350 - PB4327's doc sweep left four sites that still describe the deleted Linux half of the per-change gate

**Sites:** `.claude/skills/workstream/templates/MANDATORY-PRACTICES.md` (row L2), `.claude/skills/workstream/references/landing.md` (section 3, the first bullet), `README.md` (the Linux gate paragraph, line 111), `docs/rearchitecture/DESIGN-orchestrator-loop.md` (the `land_lane.py --self-test` paragraph at line 1434, and the 16.7 table row for `lane_decide.py`, line 1815), `tests/WiseOwl.Cobol.Tests.Unit/InertLaneDriftTests.cs` (`InertLaneDriftTests`).

Found by the branch review of PB4327 (pipeline step 4, the Linux half leaves the per-change gate; PR #942, branch `worktree-wf_b208daa7-e31-1`, head 1982c1a4da). PB4327 deleted the Linux half of `build-local`, `linux-gate.sh --legs targeted`, the `linux-gate.sh --probe` second source of exit 12 and `land_lane.linux_gate_holder`. Its doc sweep missed these sites, read on that branch:

1. `MANDATORY-PRACTICES.md` row L2 (line 66) says "(I1, I8: leg 1 on Windows plus the same plan's legs in a WSL clone, under one slot)". That contradicts row I8 (line 55) and the code: `build-local` runs nothing on Linux. An agent reading L2 treats a branch's GREEN gate record as Linux evidence. Fix: "(I1, I8: leg 1 on Windows, under one slot)".
2. `README.md` line 111 (the `linux-gate.sh` paragraph): "`build-local` runs the Linux half of its own plan the same way (`--legs targeted`)". `bash scripts/linux-gate.sh --legs targeted` now prints `=== LINUX GATE: NOT RUN [arguments] (bad arguments) ===` and exits 2. Fix: delete the clause, or say the per-change gate runs nothing on Linux (PB4327).
3. `DESIGN-orchestrator-loop.md` line 1434: the `land_lane.py --self-test` description still says exit 12 is retried only once "no Linux gate of the tree runs (`linux-gate.sh --probe`, exit 12's second source, kb/Work PB3649)"; and the 16.7 row for `lane_decide.py` (line 1815) still lists `linux_gate_holder` among the members to move. Fix: delete that clause and that member.
4. `InertLaneDriftTests.cs` line 12, the class summary: "CI's changes job, the local gate (scripts/run_gate_legs.py) and the Windows gate (scripts/run_gate_legs.py) decide ..." names one script twice as two deciders, and `drift_rules.py` prints that sentence to every implementer touching `run_gate_legs.py` or `linux-gate.sh`. Fix: "CI's changes job and the local gate (scripts/run_gate_legs.py) decide ...".

Sibling sweep (`git grep -n -E 'legs targeted|Linux half|linux_gate_holder|linux-gate.sh --probe'` on PB4327's branch, DEVLOG and kb/Work excluded): every other hit already says the Linux half LEFT the gate (MANDATORY-PRACTICES I8 and L10, `DOC_INDEX.md` lines 169 and 192, `REARCHITECTURE_PLAN.md` 3263, `DESIGN-orchestrator-loop.md` 1637 and 1776, `DESIGN-test-build-ci.md` 1868, 2302, 2688, 2815-2824 and 3131, the comments in `gate_slot.py`, `linux-gate.sh`, `enqueue.py`, `run_gate_legs.py`, `GateSlotDriftTests.cs` and `LinuxGateDriftTests.cs`). The two that still describe it as current are `CLAUDE.md` (lines 148-149, "the implementer's gate runs the Linux half of the targeted leg under WSL ... `--legs targeted`") and `docs/rearchitecture/DESIGN-test-build-ci.md`; PB4334 (step 11) rewrites both whole under an owner-approved wording, so this note does NOT touch them.

blocked_by PB4327: the four sites are on its branch, so the fix applies after #942 lands. Process-only, so no compiler diagnostic is involved.
