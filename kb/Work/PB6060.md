# PB6060 - an internal throw in a pass reaches the user as a raw .NET stack

Any internal exception inside a compiler pass (binder, validation, lowering) escapes `src/WiseOwl.Cobol.Cli/Program.cs` unhandled:
the runtime prints the .NET stack trace and the process exits 1, with no COBOL diagnostic, no source position and no statement of
which program or pass failed. `rg "catch" src/WiseOwl.Cobol.Cli` finds nothing.

A user cannot tell a rejected program from a compiler fault, and a crash while compiling legal source is indistinguishable in the
exit code from an ordinary refusal. (A fault in a pass is a defect in its own right; this note is only the missing last line of
defence, not a licence to swallow the exception.)

**Fix shape (for the implementer to choose against `docs/DESIGN.md`):** one guard at the CLI entry that reports a named internal
error (pass, program, last source position the pass held, the exception) on stderr and exits with a code distinct from the
refusal code, and does not hide the stack. Pair it with a test that forces a throw in a pass. Find every other entry point
(`cobol --run`, the listing path, the library host) that has the same gap.

**Sites:** `src/WiseOwl.Cobol.Cli/Program.cs` (whole entry), the pass driver that calls each pass.
