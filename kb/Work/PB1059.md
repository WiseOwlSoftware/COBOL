### Finding page-clause — §13.18.39.2 general format; §13.18.39.3 SR1, SR4 (rejects-legal-source; rows FMT-13.18.39.2, SR-13.18.39.3-1, SR-13.18.39.3-4)

**Mechanism.** The PAGE clause's phrase list is a four-alternative `reportPageSubclause*`: it has no LAST CONTROL HEADING phrase and none of the §13.18.39.3 SR1 abbreviations (FIRST DE, LAST CH, LAST DE), and the Kleene star admits any phrase twice with last-wins binding

**Repro.** RD R PAGE LIMIT 10 LINES LAST CONTROL HEADING 5.  -> COBOL0001 unexpected 'CONTROL' / 'HEADING'.  RD R PAGE LIMIT 10 LINES LAST CH 5. -> COBOL0001 unexpected 'CH'.  RD R PAGE LIMIT 10 LINES FIRST DE 3 LAST DE 8. -> COBOL0001 unexpected 'DE' (x2).  RD R PAGE LIMIT 10 LINES HEADING 2 HEADING 3. -> compiles rc=0 (Heading silently = 3). Probe sources in out13/probe/page-clause/{lch,lchab,fde,dup}.cob, pinned adj-d1 cobol.exe --std 2023.

**Expected, from the standard.** §13.18.39.2 general format: five separate optional brackets HEADING / FIRST {DETAIL|DE} / LAST {CONTROL HEADING|CH} / LAST {DETAIL|DE} / FOOTING, each at most once, in any order (§13.18.39.3 SR4). SR1: FIRST DE == FIRST DETAIL, LAST CH == LAST CONTROL HEADING, LAST DE == LAST DETAIL. So the first three compile, LAST CONTROL HEADING 5 sets integer-5 = 5 (the control-heading lower limit, §13.18.57.4 GR8d), and the duplicate HEADING is a syntax error.

**Observed.** CobolReportWriter.g4 reportPageSubclause = HEADING | FIRST DETAIL | LAST DETAIL | FOOTING; the lexer already has CH and DE tokens. The binder (BindReportDescriptionClauses) dispatches on HEADING()/FIRST()/LAST()/FOOTING() and the comment at line 793 records 'the grammar has no LAST CONTROL HEADING phrase, so GR3c always defaults'; the runtime already carries lastControlHeading and reads it in LowerLimit (GR8d), so only the surface + binding + a once-per-phrase screen are missing. docs/CONFORMANCE.md A.4.11 names LAST CONTROL HEADING as having no grammar surface but no kb/Work note owns it (PB1059 owns only COLS/COLUMNS and tells its fixer to file this).

**Code site.** src/Cobol.Net.Frontend/Grammar/Core/CobolReportWriter.g4#reportPageSubclause; src/Cobol.Net.Compiler/Binding/DataBinder.Reports.cs#BindReportDescriptionClauses
