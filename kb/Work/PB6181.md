# PB6181 — rendering the views from a worktree overwrites the published ledger

**Observation (from the report, not re-run here).** `python scripts/rendered_views.py` with no arguments renders every light view to its
output path. One view's output path is outside the tree, `E:/COBOL-coord/ledger.html` (the ledger). Run from a worktree, it wrote that
file from the BRANCH's tree and printed "NOT MAIN'S PAGE"; the published ledger shows a branch's state until the orchestrator's next
ledger publish overwrites it. A reader who opens the ledger in that window sees a wrong count.

**Fix shape.** A view whose output is outside the tree is written only from main's tree (refuse with the same "NOT MAIN'S PAGE"
text as an error, exit non-zero, and write nothing), or the no-argument form renders only the in-tree gitignored views.
`--check` already writes nothing; a drift test pins that no output path outside `ROOT` is written from a non-main tree.

**Sites:** `scripts/rendered_views.py:251` (`write_rendered`, `render_all`, `main`)
