## Landing (wave 20261998, group B)

**Re-probe on the build.** `INSPECT D4 TALLYING I FOR ALL "X" REPLACING ALL FUNCTION UPPER-CASE (LIT (I)) BY "Z"` (D4 "XAXB", I 1, LIT "abb") printed `3 XAXZ` at `--std 85` and `--std 2023`; after the fix it prints `3 XZXB`, and the same for a function REPLACEMENT operand (`3 AAAB`).

**Fix.** One rule for every phrase: `InspectEmitter.EmitBody` takes each operand's text through one `Once` closure in source order (TALLYING operands, then REPLACING, then CONVERTING), and a function-identifier operand is evaluated into a local before the first counter is stored. `TallyOperandTexts` takes the closure and a new twin `ReplaceOperandTexts` does the REPLACING half; the stale `Freeze` comment that said a function's argument subscripts were hoisted at bind time now says only a function-bearing subscript is. Golden: `14.9.22-INSPECT/pb5184_replacing_function_once` (85 2002 2014 2023), edition-invariant (§2023:14.9.22.4 GR6; §1985:VI.6.18.4 GR5).
