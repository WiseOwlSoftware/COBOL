# PB1054 — LANDED

## Landed — wave 1006 group B, 2026-10-03

Re-probed on a fresh Debug build of 805fb16c2: the repro below still drew COBOLNET1756 and aborted with
`NotImplementedCobolFeatureException`. **Root cause:** `ReferenceResolver.SpanLeafPlace` admitted a numeric span leaf
only when `PicInfo.IsCharacterFormNumeric` (usage display / national) and deferred every other usage, although the
place it would have built, `NumericImagePlace`, already renders every numeric usage through the ONE storage codec
(`NumFormatImage` / `NumStoreImage`, zoned / radix-2 / BCD bytes per V59, and the float IEEE lane). The gate was a
narrower copy of the question the renderer answers. **Fix:** every numeric leaf takes `NumericImagePlace`; string-valued
leaves keep their place; `DeferredShape.RenamesNonCharacterLeaf` is deleted (no producer remains). Pointer, object and
message-tag members cannot reach the span: §13.18.45.3 SR8 refuses them at the declaration
(`cite.py --check 13.18.45.3 "shall be of class object, message-tag, or pointer"` → OK §13.18.45.3 8)).
`cite.py --check 13.18.45.4 "data-name-1 defines an alphanumeric group item that includes all elementary items starting
with data-name-2"` → OK §13.18.45.4 2).

MEASURED: the repro now prints `AB`, the two binary bytes and `C`; a probe over BINARY, PACKED, COMP-2, INDEX and
BINARY-LONG members gives `FUNCTION LENGTH(RN)` 27 (2+2+2+8+8+4+1) and exactly the storage bytes, and stores through
`RN(3:2)` and a whole-alias MOVE decode back into each member. Golden `conformance:85/pb1054_renames_thru_binary_packed_span`
(85 — RENAMES, BINARY and PACKED-DECIMAL are all COBOL-85; no edition gate, so no negative). GR-13.18.45.4-2 CONFORMS.

A GREEN TEST HELD THIS GAP OPEN: `conformance:negative/pb70-receiving-reference-shape-not-implemented` used exactly
this span (`66 RN RENAMES A THRU B` over a `PIC 9(4) COMP`) as its example of "a shape not implemented as a receiver"
and demanded COBOLNET0899 for legal source; the first gate went red on it. It is deleted, and its receiver-list case
(`MOVE "X" TO OK1 RM`) moved into the positive golden as section 3 (`LIST=X X  8224`), so PB70's concern — a receiver
dropped from a list — stays witnessed on a shape that now works.

Sibling sweep: `IsCharacterFormNumeric` consumers (`grep IsCharacterFormNumeric src`) — the remaining ones ask about a
leaf's CHARACTER positions (ref-mod of an elementary numeric item, §8.4.3.3.3 SR1; the whole-group promotion PicInfo
documents), where the restriction is the rule, not a gap; the RENAMES span was the one site asking about STORAGE.
