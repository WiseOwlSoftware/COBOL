# PB3322 — refute PB3173's edition decisions

Filed by the clerk from lead 4 of the PB3173 report (`E:\COBOL-coord\scratch\reports\w1104c2-PB3173-report.md`, "New defects (leads)"). PB3173's branch is PR #173; this note's work starts once it is on main.

**Gap.** PB3173's note says: "No separate refuter ran in this lane: the decision script checks every decision's evidence mechanically, and the branch review is the judgment check." PB3173's own scope said "an adjudicator decides, a refuter checks each decision (the adjudication lane)".

**First slice for the refuter.** The lower-confidence decisions PB3173 names: the split-key SOURCE phrase rows (2002, with FMT-12.4.5.12.2; the repo holds no 2002 or 2014 text); the A.4.8 module's 2002 edge (derived from FORMAT's reservation); DOC-A.1-34 and -37 (the compile-time and runtime coded-character-set items, 2002); DOC-A.1-188 (the UCS-4 / UTF-8 / UTF-16 alphabet phrases, 2002); DOC-A.1-202 (the time formats' fraction digits, 2014).

**Fix shape (for the implementer to confirm).** Run the adjudication lane's refuter (`templates/wf_lane3_refute.js`) over the 215-record batch, the lower-confidence ones first. An overturn is one batch record.

**Resolution (wave 20262137 group F, 2026-11-22).** The gap's premise is stale: `specs/ISO_COBOL_2002.md` and `specs/ISO_COBOL_2014.md` are now in the repo, so the lower-confidence decisions are checked against their own editions' text, by reading it. The inventory is also a per-rule store now (`tests/version-matrix/inventory/<rule-id>.json`), so an overturn is one `record_verdicts` record. Results of the named first slice:
- The split-key SOURCE rows (SR-12.4.5.6.3-6, GR-12.4.5.6.4-2, SR-12.4.5.12.3-5, GR-12.4.5.12.4-2): UPHELD at 2002. `ISO_COBOL_2002.md` carries the `record-key-name-1 SOURCE IS { data-name }...` format and the rules (class and category of data-name-2; the concatenation) in both clauses; 2014 carries the same text; 1985 has none.
- The A.4.8 FORMAT / SELECT WHEN rows: UPHELD at 2002. The FORMAT clause (13.16.22) and SELECT WHEN clause (13.16.49) are 2002 clauses; the 1985 text has neither.
- DOC-A.1-34 and -37: UPHELD at 2002. §2002:8.1.1 states the compile-time versus runtime computer's coded character set and the alphanumeric / national encodings; 1985 has no such concept.
- DOC-A.1-188: UPHELD at 2002 (§2002:B.1 item 151, whose clause is the ALPHABET clause, §2002:12.2.6.3 GR7f, GR7g and GR7h, with the UCS-4, UTF-8 and UTF-16 phrases).
- DOC-A.1-202: UPHELD at 2014 (§2014:A.1 item 184 only; 2002 has no fractional-seconds time format).
- DOC-A.1-112: UPHELD at 2002 (§2002:7.2.14 LEAP-SECOND directive and §2002:B.1 item 87).
- DOC-A.1-64: OVERTURNED to 2002,2014,2023. The item documents entry-convention-names, their meanings and the default, all of which §2002:11.8.5.3 (GR2 and the default paragraph) and §2002:B.1 item 44 carry; PB3173's ENTRYCONV reason cited the construct `options-entry-convention-2014`, which is only the COBOL alternative added in 2014. One record, `adjudication/pb3322-refute-pb3173/overturn-batch.json`.

The hits on short generic rule sentences (SR-14.9.38.3-1, GR-13.18.24.4-12) are coincidental matches, not evidence.
