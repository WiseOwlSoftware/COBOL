# PB2861 — every session start and resume names its skills

Owner, 2026-10-08 ~22:05 PDT: "Be sure to setup all session start and resume processes to always use these skills, as
appropriate."

## What was missing

- A FRESH attended session started by `scripts/start-session.ps1` is told "(1) run the session-start skill" by its
  restart prompt; a loop unit is told the same by `scripts/orchestrator/units/common.md` (a `meter` unit skips it), and
  land and wave units load `workstream`.
- A RESUMED attended session — how both the operator and the Mythos session came back after the Claude Code update on
  2026-10-08 (`claude --resume …` / `claude --model …` with the prompt "resume") — got only the SessionStart hook's
  probe, which named no skill. The same day the operator did not re-arm its inbox watcher after a restart (PB2814).

## Landed

`scripts/hooks/session_start.py` (it runs at every start, resume, clear and compaction, in every lane) now puts a
`SKILLS` block FIRST in the session's context, chosen by the hook payload's `source` and the session's lane
(`session_lane()`: mailbox.py's one lane rule; `loop:<type>` from `COBOL_LOOP_UNIT`; `solo` without a coordination
directory):
- start / resume / clear: 1. invoke `session-start` now; 2. the lane's skills (operator: `workstream` before it
  supervises, steers, lands or dispatches, and arm its inbox watcher; Mythos: owner-approved Mythos tasks, `workstream`
  before any dispatch, arm its watcher); 3. the work skills as work arises (`spec-lookup`, `land-a-fix`, `gate`,
  `kb-sync`, `review`, `architecture-review`, `new-construct`), each project overlay loading its `brent-tools:` base.
- compaction: the skills invoked before it stay in force; re-invoke one whose text is no longer in context.
- loop units: `session-start` then the unit prompt's skills, and no watcher; a `meter` unit skips `session-start`.

`--self-test` (discovered by scripts/self_tests.py, so every gate and CI runs it) checks each lane and source; the
hook's top-level code moved under `main()`. CLAUDE.md "Start here every session" gains step 0; DOC_INDEX's hook row
says what the block does.
