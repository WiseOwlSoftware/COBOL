# PB244

**Rows:** `GR-14.9.11.4-6`, `GR-14.9.11.4-7`

A legal DISPLAY group operand the STRUCT-SCOPED image composer cannot build is refused at RUN TIME: a pointer/object-class leaf and an access-path-dependent extent both become a Tier-C loud instead of a rendering — and a GREEN test pins the refusal.

ROWS: GR-14.9.11.4-6 (PARTIAL — GR6, the sending size) and GR-14.9.11.4-7 (PARTIAL — GR7, the variable-length-group display format). Both were narrowed to a single residue each by the PB164/R40 wave, and the two residues are the same mechanism seen from two rules.

MECHANISM. A group identifier-1 reaches the DISPLAY emitter as an IMAGE: `GroupImageCodec.EmitCurrentImageMethod` composes the members' images inside the record STRUCT, and `AcceptDisplayEmitter.EmitDisplay` writes that one string. The composer is therefore bounded twice — by what a leaf can contribute as characters, and by what a struct-scoped method can see. Anything outside those bounds is not rendered and not diagnosed at bind: it is staged as a Tier-C runtime loud on source no syntax rule forbids.

SHAPE (a) — CLASS POINTER / OBJECT LEAF (GR-14.9.11.4-6's whole residue, and GR-14.9.11.4-4's residue member (1)). A group with a POINTER / PROGRAM-POINTER / FUNCTION-POINTER / OBJECT REFERENCE leaf has no character image in the byte-cell model, so it throws with no sending size at all. §14.9.11.3 SR1 excludes only the ELEMENTARY pointer/object IDENTIFIER — the containing GROUP is a legal identifier-1. That is the same SR1 reading PB148 relied on in the OTHER direction to build the elementary class gate, so the compiler now holds both halves of one rule and honours neither for the group. MEASURED: tests/Cobol.Net.Tests.Conformance/TierCRejectionTests.cs:66-89 — `AssertPointerGroupLoud` compiles `01 WS-GP. 05 WS-GP-A PIC X(3). 05 WS-GP-P USAGE POINTER.` then `DISPLAY WS-GP.` and asserts `Assert.False(ok, "a pointer-leafed group has no whole-group image — loud (§1.4)")` plus `Assert.Contains("Tier-C", detail)`. The program COMPILES and throws at run time — a GREEN test pinning the refusal of legal source, the feedback_green_test_can_hold_a_gap_open shape exactly.

SHAPE (b) — AN EXTENT THAT LIVES ON THE ACCESS PATH (GR-14.9.11.4-7's whole residue). A runtime-length item INSIDE a table element, and any member carrying or containing OCCURS DEPENDING, are rejected loudly because the current count/extent lives on the OPERAND's access path and is unreachable from a struct-scoped composer (the same boundary the named stage `IntrinsicBinder.VariableLengthGroupSum` documents). docs/CONFORMANCE.md §7 row 57 records these as 'Excluded shapes, rejected loudly rather than shown at a wrong extent' — an honest disclosure of the current state, but A.1 item 57 asks the implementor to define the FORMAT of a variable-length group's display, not to license refusing legal operands.

WHY ONE NOTE. The fix is one fix: ask the question of the REFERENCED operand and give the composer the operand's access path (the discriminator lesson PB189 states for its own arm), and decide what a pointer/object leaf CONTRIBUTES to a group image — the latter is an A.1 item 56/57 determination and is the one owner-visible question inside this note. Fixing either shape alone leaves the other, and leaves PB189's third arm.

SPEC REFS (carried from the rows): §14.9.11.4 GR4 (the transfer), GR6 (the sending size), GR7 (the VLG format, A.1 item 57); §14.9.11.3 SR1 (the ELEMENTARY-only class exclusion); §8.5.1.12.1 (a variable-length group is one with a dynamic SUBORDINATE — the clause PB189 uses to prove an ELEMENT is a fixed-length group).

SEVERITY NOTE: filed MINOR to match its open sibling PB189, which carries identical flags at MINOR; on what it DOES to a user program — a conforming DISPLAY aborts at run time — it would rank higher, and all three members should be re-ranked together.

## Mechanism

The DISPLAY sender obtains a GROUP operand's character image from the struct-scoped composer `src/Cobol.Net.Compiler/CodeGen/DataDivision/GroupImageCodec.cs#EmitCurrentImageMethod`, reached through `AcceptDisplayEmitter.EmitDisplay` / `OperandText.FieldAsString`; every shape that composer cannot represent is turned into a Tier-C runtime loud rather than into an image. GR4's 'the data item being transferred' and GR6's 'sending size' fail together because they are the same decision point.

PB164 + R40 (LANDED) narrowed both rows to exactly this residue — R40's review fleet caught the first CONFORMS flip over-claiming 'every operand kind', and the numeric leaf kinds (COMP/COMP-5/BINARY-*/PACKED/COMP-1/COMP-2/INDEX) plus the composable variable-length group are now pinned byte-level.
