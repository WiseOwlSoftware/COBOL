# PB5621 - an ANY LENGTH formal parameter bound to an OCCURS DEPENDING group takes the argument's maximum length, not its current length (2002 and 2023)

**Sites:**
- `src/WiseOwl.Cobol.Compiler/CodeGen/ProgramEmitter.cs` (whole: the reader pinned no member; the fixer names it) (the ANY LENGTH argument intake, RuntimeApi.ArgAdaptText arm for IsAnyLength)
- `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/CallEmitter.cs` (whole: the reader pinned no member; the fixer names it) (the argument side)

**Mechanism.** The CALL argument intake for an ANY LENGTH formal passes the argument's full storage extent; GR1 makes the formal's length the argument's length (zero when the argument is a zero-length item). UNSTRING of such a sender then examines 5 characters where it should terminate, and an ANY LENGTH delimiter acts as a 5-space delimiter.

**Inventory.** Rows claimed: `2002-GR-14.8.44.3-2`, `2002-GR-14.8.44.3-9`.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**

- `§2002:13.16.2.3 GR1`: "a zero-length item when the corresponding argument or returning item of the activating runtime element is a zero-length item"
- `§2002:14.8.44.3 GR2`: "If the data item referenced by identifier-1 is a zero-length item, execution of the UNSTRI"
- `§2002:14.8.44.3 GR9`: "it is as if the DELIMITED phrase were not specified"

**Repro.** Scratch originals under `E:/COBOL-coord/scratch/op-20261114/read-2002/defects-work/` (p2/unstr_anylen.cob); the text is inline. Command: `cobol.exe p2/unstr_anylen.cob --std 2002 --source-format free --run`

`p2/unstr_anylen.cob`:

```cobol
IDENTIFICATION DIVISION.
PROGRAM-ID. UNSTRAL.
DATA DIVISION.
WORKING-STORAGE SECTION.
01 N  PIC 9 VALUE 0.
01 WS-D.
   02 WS-DE PIC X OCCURS 0 TO 5 DEPENDING ON N.
PROCEDURE DIVISION.
    CALL "INNER" USING WS-D
    MOVE 3 TO N
    MOVE "Q;R" TO WS-D
    CALL "INNER" USING WS-D
    STOP RUN.
IDENTIFICATION DIVISION.
PROGRAM-ID. INNER.
DATA DIVISION.
WORKING-STORAGE SECTION.
01 S  PIC X(5) VALUE "AB;CD".
01 A1 PIC X(4).
01 A2 PIC X(4).
01 P  PIC 99.
01 T  PIC 9.
LINKAGE SECTION.
01 L PIC X ANY LENGTH.
PROCEDURE DIVISION USING L.
    MOVE "****" TO A1 A2
    MOVE 1 TO P
    MOVE 0 TO T
    UNSTRING L DELIMITED BY ";" INTO A1 A2 WITH POINTER P TALLYING IN T
        ON OVERFLOW DISPLAY "S OVF"
        NOT ON OVERFLOW DISPLAY "S NOVF"
    END-UNSTRING
    DISPLAY "SENDER L [" A1 "][" A2 "] P=" P " T=" T
    MOVE "****" TO A1 A2
    MOVE 1 TO P
    MOVE 0 TO T
    UNSTRING S DELIMITED BY L OR ";" INTO A1 A2 WITH POINTER P TALLYING IN T
    DISPLAY "DELIM L [" A1 "][" A2 "] P=" P " T=" T
    GOBACK.
END PROGRAM INNER.
END PROGRAM UNSTRAL.
```

**Observed.** SENDER L [    ][****] P=06 T=1 for a zero-length argument; anylen_odo: 'CALLER LEN 000000000' then 'INNER LEN 000000005', and 'CALLER LEN 000000003' then 'INNER LEN 000000005 [Q;R  ]', at 2002 and 2023.

**Expected (from the 2002 text).** the formal's length is 0 (UNSTRING terminates at once, P=01 T=0) and 3 respectively.

**Sibling sweep.** every statement and function reading an ANY LENGTH formal bound to a variable-length argument (STRING, INSPECT, MOVE, LENGTH OF, FUNCTION LENGTH); INVOKE arguments; RETURNING ANY LENGTH.

**Other editions.** 2023: yes (same rule, same output). 2014: yes presumably. 85: n/a.
