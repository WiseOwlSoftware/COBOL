**Landed (2026-08-18):** three root sites, ONE shape each. Grammar: `figurativeConstant`'s Format-6 arm is
`ALL allLiteral` (`allLiteralOperand (& allLiteralOperand)*` over STRINGLIT / HEXLIT / NATLIT / BOOLLIT — one arm
for the four kinds §8.3.3.6.3 SR2 admits, and literal-1 "may be a concatenation expression": `ALL "AB" & "C"` is
ALL over "ABC"; `nonNumericLiteral` lists the figurative first so that reading wins the ANTLR tie); every consumer
asks `fig.allLiteral()` (the binder, `ConcatFolder`, the boolean channel, INSPECT's SR3 screen, the legacy
oracle). Binder: `BoundAllLiteral.Of(raws)` is THE constructor — the category rides on literal-1's class through
`CobolLiteral.ClassOf` (THE literal-class classifier: N/NX national, B/BX boolean, plain/X alphanumeric), so
`ALL B"1"` no longer falls to a `BoundOperandError` and INITIALIZE / Report Writer / UNSTRING-delimiter producers
keep the class. VALUE: `DataBinder.ValidateValueCategory` classifies through `ClassOf` (it read `raw[0]`/`raw[1]`
and refused NX"…"/BX"…" and every ALL literal); a concatenated ALL literal-1 folds to one re-quoted literal
(`ConcatFolder.FoldAll`) before the raw-text VALUE pipeline; `CobolLiteral.SplitLiteral` requires ONE well-formed
literal (it answered "a literal" for `"A"&"B"`). Version pass: `VisitFigurativeConstant` gates a national /
boolean literal-1 (COBOLNET0900 below 2002 — `ALL B"1"` compiled at --std 85), applies the §8.3.3 hex grouping,
SR2's zero-length (COBOLNET1648) and §8.8.3.2 SR1's same-class (COBOLNET1540) checks. Golden
`pb71_all_national_boolean_figurative` (18 rows: MOVE / relation / VALUE / DISPLAY over N, NX, B, BX, X and the
concatenated forms); negatives `pb71-all-{national,boolean}-figurative-below-2002`,
`pb71-value-all-alphanumeric-on-national`, `pb71-all-literal-zero-length`,
`pb71-all-literal-mixed-class-concatenation`. Verdicts SR-8.3.3.6.3-2 + FMT-8.3.3.6.2 → CONFORMS (GAP 4042 →
4040).

literal (`ALL "Q"`) parses and runs.

grammar's ALL production evidently admits only the alphanumeric/hex literal forms. Sweep at fix time:
