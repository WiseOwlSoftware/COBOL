# PB5624 - a report VARYING counter named in the PRESENT WHEN condition of its own or a subordinate entry is refused 'not defined' COBOL1639 (2002 and 2023)

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ReportWriterBinder.cs#BindReportClauses` (PresentWhenCtxs bound before VaryingScope is set, lines ~103-127)

**Mechanism.** ReportWriterBinder.BindReportClauses binds each line's and field's PRESENT WHEN chain while ctx.Refs.VaryingScope is null; the scope is set only afterwards for the field's SOURCE operands, so a counter reference in PRESENT WHEN resolves to nothing. 2002 SR2 lets the counter be referenced within the current entry or a subordinate entry. Not only reachable through VALIDATE: this is the report-writer VARYING clause, so it is a new note, not PB5577.
