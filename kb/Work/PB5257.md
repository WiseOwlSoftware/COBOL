# PB5257 - a golden header carries a quotation the standard does not contain

`conformance-suite/cases/14.9.49-USE/pb5127_detail_use_computes_source_before_rolled_addition.cob:12` quotes
§2023:13.18.54.4 GR6 as "the value added is that of the operand of the SOURCE clause". The standard reads "... of the
operand of the SOURCE or VALUE clause", so the quotation fails `python scripts/spec/cite.py --check` (the clause
number is right). Re-derive: run `cite.py --check "§2023:13.18.54.4 GR6" "<the text>"` with the corrected text and
put the checked text in the header; then sweep the sibling PB5127 goldens for the same quotation.
