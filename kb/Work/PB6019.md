# PB6019 - at 1985 one kind of argument violation terminates and the others return 0

**What.** kb/Work PB5889 made an intrinsic integer argument that the compile-time screen leaves undecided a run-time check, and at
`--std 85` a value that is not an integer terminates the run unit (`CobolIntrinsics.NotAnIntegerArgument`,
`CobolImplementorFatalException`), as the Correction Amendment's clarification allows: "This clarification in the Correction Amendment
allows an implementation of amended third Standard COBOL to terminate processing in this circumstance" (`§1985:p.B-46`, cite.py OK).
That clarification covers every argument whose value does not "comply with the specified constraints", not only integrality. Every
other value check of the runtime (`Exceptions.ExceptionState.ArgumentError`: FACTORIAL of a negative argument, a date out of range,
INTEGER-OF-DATE of month 13) still raises EC-ARGUMENT-FUNCTION only when checking is enabled, which never happens at `--std 85`, and
otherwise returns the §2023:15.3 default 0. So at 1985 `FUNCTION FACTORIAL (N - 5)` with N = 1 is 0 and the run goes on, while
`FUNCTION FACTORIAL (FUNCTION ORD (A) / 2)` with A = "B" stops it. Both results are permitted (the result is undefined,
`§1985:I.1.6`), so neither is nonconforming; the defect is that the implementation answers one rule two ways, and a 1985 program that
passes FACTORIAL a negative value gets a silent wrong answer.

**What to decide.** Whether every 1985 argument-constraint violation terminates (one 1985 arm in `ArgumentError`, which would also
change every 1985 golden that observes the 0 default today), or the integer check returns the truncated integer at 1985 as
DOC-A.1-124 does elsewhere. The ruling of PB5889 chose termination for integrality only.

**Repro.** `FUNCTION FACTORIAL (N - 5)` with `N PIC 9 VALUE 1` at `--std 85` prints 0 and continues; the PB5889 case
`conformance:cases/15.3-Arguments/pb5889_run_time_check_85` terminates.

**Sites:** `src/WiseOwl.Cobol.Runtime/Exceptions/ExceptionState.cs#ArgumentError` and
`src/WiseOwl.Cobol.Runtime/Intrinsics/CobolIntrinsics.cs#NotAnIntegerArgument`.
