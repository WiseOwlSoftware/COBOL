# R46

Answers PB738. The published ISO/IEC 1989:2023 PDF drops `<letter><space><opening-quote>` at five sites (e.g. "The
value '62' is placed…" prints as "The valu62'…"); the transcription was byte-faithful to the defect, so `cite.py
--check` against the intended text failed. Owner chose **marked corrections**: at each site insert the intended text
inside a visible editorial marker (one convention, documented where the transcription conventions live) with the
printed form noted; the rule catalog and `cite.py` read the intended text; a drift test pins that exactly these five
sites carry the marker, so no silent edits creep in elsewhere.
