# PB4815 - one edition parameter for the spec tools

**The defect.** PB4812 and PB4813 must run "the same processes and guidelines" as `specs/ISO_COBOL_2023.md` (owner 2026-11-05),
and every tool of that process is welded to the 2023 edition. Measured 2026-11-06 on main 7e69af1a7f:
- `scripts/spec/figure_geometry.py`, `scripts/spec/render_figure.py` and `scripts/render-spec-page.py` call `spec_pdf.path(2023)` /
  `spec_pdf.require(2023)` at module level;
- `scripts/spec/sweep_figures.py`, `lint_rendering.py`, `verify_publishable.py`, `verify_acknowledgment.py`, `cite.py`,
  `audit_underlining.py`, `audit_figure_structure.py`, `audit_figure_text.py`, `audit_grammar_optional_words.py` and
  `.claude/workflows/spec-reconcile.js` name `specs/ISO_COBOL_2023.md` themselves.

**The fix (rule 4: one tool per job, no copies, no aliases).**
- `scripts/spec/spec_pdf.py` becomes the ONE edition table: for each edition (1985, 2002, 2023) the PDF (it already has
  this) AND the public Markdown path (`specs/ANSI_COBOL_1985.md`, `specs/ISO_COBOL_2002.md`, `specs/ISO_COBOL_2023.md`). A
  function returns the Markdown path; nothing else spells one.
- Every tool above takes `--edition {1985,2002,2023}` (default 2023, so every existing caller, gate and CI step is
  unchanged) and asks `spec_pdf` for both files. A module-level `PDF = spec_pdf.path(2023)` becomes a value resolved from
  the argument. The workflow script takes the edition in its args.
- Edition-specific DATA a tool carries (page offsets, clause tables, the acknowledgment text `verify_acknowledgment.py`
  checks, the licence-stamp patterns `verify_publishable.py` refuses) is keyed by edition in that tool; an edition with no
  data yet fails loudly naming the missing table, never falls back to 2023's.
- `verify_publishable.py` checks the stamp shapes of all three editions on every run (the 1985 and 2002 PDFs' per-copy
  stamps are recorded in PB4812/PB4813; read the PDFs' stamp lines to derive the patterns, and never write the licensee's
  name or order number into the repository: the patterns are shapes, like the existing `\bX_\d{6}\b`).
- The drift sweep in `spec_pdf.py --self-test` gains a check: no file under `scripts/` or `.claude/` other than
  `spec_pdf.py` spells a `specs/*COBOL*.md` transcription path (the existing PDF-name sweep is the model), so the next
  tool cannot weld itself to one edition again.
- Every tool's self-test (where it has one) gains a case per edition for the argument plumbing, on planted inputs.
