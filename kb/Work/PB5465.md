# PB5465 - INVOKE BY CONTENT is not transitive: `INVOKE C "M" USING BY CONTENT G N` passes N BY REFERENCE, so the method's `COMPUTE LN2 = LN2 + 1` changes the caller's N (silent wrong answer)

**What happens.** `INVOKE C "M" USING BY CONTENT G N` passes `G` by content and `N` BY REFERENCE. The method's `COMPUTE LN2 = LN2 + 1` then changes the caller's `N`. Writing an explicit BY CONTENT on each argument is correct. Repro: `E:/COBOL-coord/scratch/w20262013b/o2.cob` (one BY CONTENT over a list: wrong) against `o3.cob` in the same directory (BY CONTENT on each argument: right). The run is silent: no diagnostic, a wrong value.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/OoBinder.InlineInvocation.cs` (`InvocationArg.OfInvokeArgument`: each argument reads only its own BY phrase, and a keyword-less one becomes Expression/BY REFERENCE; the fix carries the passing mechanism of the nearest preceding BY CONTENT or BY REFERENCE phrase across the keyword-less arguments that follow it).

**Authority.** The INVOKE general format (`§2023:14.9.23.2`) puts a list of arguments under one BY phrase; its figure note reads "The outer brackets make the whole USING phrase optional; the ellipsis is INSIDE those brackets" (`cite.py --check`: OK, the quotation is in the clause; the diagram itself is not machine-checkable, so the fixer renders the PDF page, CLAUDE.md rule 1, and states the carry-over from it). The checker found no transitivity rule among the first rules of 14.9.23.4; the fixer reads the whole clause. CALL states the same carry-over as a rule, `§2023:14.9.4.4 GR5`: "Both the BY CONTENT and BY REFERENCE phrases are transitive across the parameters that follow them until another BY CONTENT or BY REFERENCE phrase is encountered. If neither the BY CONTENT nor the BY REFERENCE phrase is specified prior to the first parameter, the BY REFERENCE phrase is assumed." (`cite.py --check`: OK).

**Variant sweep for the fixer.** The same carry-over for the other INVOKE argument shapes (BY VALUE, an expression argument, PB1135's keyword-less expression arm), for an INVOKE of a prototype or function-style call, and for the CALL binder, which must already do it (compare its reader and share one if the two differ).
