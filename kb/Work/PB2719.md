## Landing
- `src/WiseOwl.Cobol.Frontend/WiseOwl.Cobol.Frontend.csproj#EnsureGeneratedFiles` — the ONE up-to-date decision for
  `Generated/`. A new generation input joins its `Inputs` (a file) or the `WriteAntlrGenerationStamp` lines (a value),
  never a second staleness check in a script.
- MSBuild expands a wildcard only in an item's `Include`; in a target's `Inputs`/`Outputs` it is a literal file name
  that never exists, so the target always runs. Glob through an item.
