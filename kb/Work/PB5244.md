# PB5244 - at --std 85 a report footing may be placed on a line the page footing's NEXT GROUP has already passed: GroupLimits bounds the RF by the PF's last line (the 2023 rule), where 1985 bounds it by the final LINE-COUNTER setting the PF establishes, NEXT GROUP included

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/ReportSectionBinder.cs` (`GroupLimits`: the report-footing bound `MinimumLastLine(pageFooting) + 1`; `ScreenReportGroupLines`, COBOL2199; landed: `Cobol85FinalLineCounter`, the edition arm of `GroupLimits`)

**Mechanism.** §1985:XIII.3.10.10 GR1 a places a report footing after a page footing on the same page at a first line "one greater than the final LINE-COUNTER setting established by the page footing report group", and the page footing's NEXT GROUP sets that LINE-COUNTER (§1985:XIII.3.10.9 GR5: the NEXT GROUP integer, or its sum with the last line). `GroupLimits` computes the bound by the 2023 rule (the line after the PF's last line) at every edition, so an absolute RF line between the PF's last line and its NEXT GROUP setting compiles at 85 and prints directly under the PF, though LINE-COUNTER reads the NEXT GROUP value in the RF's USE BEFORE REPORTING procedure.

**Found by.** The 1985 code read, slice 50.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the code read's non-conforming verdicts of slices 36-56 wait in `E:/COBOL-coord/scratch/coderead-85/pipe-for-register.json`.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-GR-XIII.3.10.10-1` - `§1985:XIII.3.10.10 GR1` (read: PARTIAL, harm: under-rejects): "one greater than the final LINE-COUNTER setting established by the page footing report group"; `§1985:XIII.3.10.9 GR5` (the PF's NEXT GROUP sets LINE-COUNTER).

**Repro (`E:/COBOL-coord/scratch/coderead-85/reprobe-85c/rw_pfng.cob`).** `RD RPT PAGE LIMIT 20 LINES HEADING 3 FIRST DETAIL 4 LAST DETAIL 15 FOOTING 16.`, `01 TYPE PAGE FOOTING LINE 17 NEXT GROUP 19.` (`PF17`), `01 RFG TYPE REPORT FOOTING LINE 18.` (`RF`), one detail; INITIATE, GENERATE, TERMINATE; `cobol.exe --std 85 --source-format fixed --run rw_pfng.cob`.

**Observed (the records-85c build of origin/main f2cf36fd15, rerun 2026-11-10).** exit 0, DONE; the report file holds `PF17` on line 17 and `RF` on line 18.

**Expected (from the 1985 text).** Refused at compile time: the RF's first line can be no earlier than 20 (19 + 1), and LINE 18 lies above that.

**Fix direction (root cause, CLAUDE.md rule 4).** The PF's final LINE-COUNTER setting is a fact `GroupLimits` can compute from the PF's NEXT GROUP clause; make the RF bound an edition row (1985: after NEXT GROUP; 2023: after the last line) in the one place the limits are computed, and test both NEXT GROUP forms (absolute and PLUS).
