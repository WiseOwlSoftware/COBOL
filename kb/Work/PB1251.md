# PB1251 — OPEN

## Measured

**linkage-section** — A LINKAGE SECTION in a FACTORY or OBJECT (instance) definition's data division is accepted silently: CobolOO.g4 gives both a full dataDivision and nothing screens linkageSection() there; the method-level screen (COBOLNET1519, DataBinder.Oo.cs) covers only FILE/REPORT/SCREEN in methods.

- **Repro:** out13/probe/linkage-section/sr1.cob --std 2002 --run: CLASS-ID LKAGG. ... OBJECT. DATA DIVISION. LINKAGE SECTION. 01 OBJ-L PIC X(3). PROCEDURE DIVISION. METHOD-ID. DOIT ... -> compiles clean, runs (ARG=0042). sr1f.cob, the same under FACTORY., also clean.
- **Expected (spec):** §13.7.3 SR1 enumerates where a linkage section may be specified — program, function, method, program prototype and function prototype definitions. A factory or instance definition is not among them, so its LINKAGE SECTION is a compile-time error (2002+).
- **Observed:** Clean compile. Only three consumers of linkageSection() exist (DataBinder.Linkage.cs:230, :476; DataBinder.Oo.cs:329 for methods).
- **Code site:** src/Cobol.Net.Compiler/Binding/DataBinder.Oo.cs (factory/object data-division binding, beside the method COBOLNET1519 section screen); src/Cobol.Net.Frontend/Grammar/Core/CobolOO.g4:37,78
- **Clause (adjudicator):** ISO/IEC 1989:2023 §13.7.3 SR1 (cite.py --check 13.7.3 "The linkage section may be specified in a program definition, function definition, method definition, program prototype definition, or function prototype definition" -> OK §13.7.3 1))

**local-storage-section** — ls-in-factory-object-under-rejected: the FACTORY and OBJECT paragraphs share the general dataDivision rule (which carries localStorageSection?) and no binder or validation pass screens the §13.6.3 SR1 placement, so a LOCAL-STORAGE SECTION in a factory or instance definition compiles silently and binds as persistent factory/instance data

- **Repro:** E:\Temp\claude\E--CobolSharp\a700c052-f9e4-4942-84ff-a13c7505d6ec\scratchpad\adj-d1\out13\probe\local-storage-section\b_OBJECT.cob and b_FACTORY.cob: CLASS-ID. LSBOBJECT. OBJECT. - **Expected (spec):** §13.6.3 SR1: the local-storage section may be specified in a program definition, a function definition, or a method definition contained in a class definition.
