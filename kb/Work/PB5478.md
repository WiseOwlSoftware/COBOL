# PB5478 - GrammarDiagramGeneratorDriftTests.Generator_RunsClean is red at random on Windows under the whole Unit population: its FileSystemWatcher keeps the default 8 KB buffer, which overflows (InternalBufferOverflowException) while the generator writes about 106 files, and PB5463 made a watcher Error fail the test

**Sites:**

- `tests/WiseOwl.Cobol.Tests.Unit/GrammarDiagramGeneratorDriftTests.cs` (`GrammarDiagramGeneratorDriftTests.FreshFileHolder.FreshFileHolder`, `GrammarDiagramGeneratorDriftTests.FreshFileHolder.Fail`)

**Mechanism.** kb/Work PB5463 (landed) made the test's `FreshFileHolder` fail on any watcher `Error` ("a watcher `Error` fails the test"), so an event the holder never saw cannot pass as a held file. The holder's `FileSystemWatcher` (constructor, line 151) is built with `IncludeSubdirectories = true` and the default `InternalBufferSize` of 8192 bytes. The generator writes about 106 files under the held directory in a burst (here held 44, skipped 62), and on a host running the whole Unit, Conformance and Characterization populations at once the watcher's thread does not drain the buffer in time: Windows reports `InternalBufferOverflowException`, the holder's `Error` handler fails the test, and a gate whose change touches nothing the test reads goes red.

**Observed.** The gate of `records-85-rd4` (a register-only change: `kb/Work`, `DEVLOG`, `tests/version-matrix/inventory-1985/*.json`), run `TestResults/build-local/000001-20261114T021539Z` at head 2b3729c31c on main 725550baca, Windows, BelowNormal, gate slot 1 of 3: `=== POPULATION Unit: EXACT — 40,852/40,852 cases ran ===`, one failure:

```
Failed WiseOwl.Cobol.Tests.Unit.GrammarDiagramGeneratorDriftTests.Generator_RunsClean [1 m 21 s]
the holder under E:\Temp\wiseowl-cobol-tests\238676-e6a7f2301dff\grammar-diagram-held-150e3706d556 failed (a watcher error or a take that threw), so it may have missed files the generator wrote (held 44 file(s), skipped 62, errors 1):
the watcher reported an error: System.IO.InternalBufferOverflowException: Too many changes at once in directory:E:\Temp\wiseowl-cobol-tests\238676-e6a7f2301dff\grammar-diagram-held-150e3706d556.
```

Conformance (24,710) and Characterization (37) passed in the same run. The branch changes no grammar, no generator and no test source.

**Expected.** The test is red only when the generator fails or a held file escapes it; a load that overflows the watcher's buffer is neither.

**Fix direction (root cause, CLAUDE.md rule 4).** Size the watcher for the burst it watches (`InternalBufferSize` up to 64 KB, with `NotifyFilter` already minimal) and make an overflow recoverable rather than a verdict: on `InternalBufferOverflowException` the holder rescans the held directory and takes every file it has not yet taken, so the witness PB5463 wants (no fresh file escapes) still holds; keep any other watcher `Error` fatal. A test of the holder raises an overflow through `FileSystemWatcher.OnError` and shows the rescan takes the files written meanwhile. Sweep the other watchers PB5463 named (`DirectoryNameWatch`).
