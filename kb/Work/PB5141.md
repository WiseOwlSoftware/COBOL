# PB5141 - COBOL0846 names a data item a literal

**Site:** `src/WiseOwl.Cobol.Compiler/Binding/Validation/StatementValidation.cs` (`CheckInspectLiteralSizes`, near lines 953-1000: the operand
labels `("literal-4", "literal-5")` and `("literal-1", "literal-3")`).

**Found.** PB5103 made the check report data items at --std 85 (INSPECT REPLACING, CHARACTERS and CONVERTING whose identifiers differ
in size), but the message still labels each operand with the literal name of the same slot. A user whose operands are identifiers
reads that a literal is the wrong size. A misleading diagnostic on a refusal: the refusal is right, its words are not.

**Owed.** Label each operand by what it is: the literal's name for a literal, the identifier's name (identifier-3 / identifier-5,
identifier-4 / identifier-6 by slot) for a data item, taken from the operand's bound kind in one place. Add a refusal golden whose
assertion includes the message text for a data-item operand.
