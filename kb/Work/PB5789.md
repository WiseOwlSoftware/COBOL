# PB5789 - OPEN: 1985-GR-XIII.3.10.7-1 cannot be ruled while §1985:XIII.3.10.7 GR1 is reconstructed text (the scan lacks folio XIII-30, kb/Work PB4952)

**Ruling: OPEN.** Whether an absolute page-heading LINE after a report heading with NEXT GROUP is an error turns on `§1985:XIII.3.10.7 GR1`, whose text is RECONSTRUCTED: the scan lacks folio XIII-30 (kb/Work PB4952, landed). It is not ruled until the printed page is read. The row `1985-GR-XIII.3.10.7-1` stays `undecided`. Harm: under_rejects if reading 1 holds (not set while the row is open).

**The case.** `RD HEADING 3 FIRST DETAIL 6`; `RH LINE 3 NEXT GROUP 4` (legal by XIII.3.10.6 GR4a; final LINE-COUNTER 4 by GR5a); `PH LINE 4` prints on line 4.
- Reading 1 (the reconstructed `XIII.3.10.7 GR1`, kb/Work PB4952): the PH's first line may be no higher than one greater than the RH's final LINE-COUNTER (5), so `PH LINE 4` is an error.
- Reading 2 (printed text only): the PH region is HEADING to FIRST DETAIL - 1, lines 3 to 5 (XIII.3.8.3 SR8b, XIII.3.8.4 GR1c), and line 4 is inside it; XIII.3.16.4 GR4 says only that the RH's NEXT GROUP "can affect" where the PH is presented, which a relative PH (placed from LINE-COUNTER) satisfies without bounding an absolute one.

The rule itself is on the missing folio XIII-30; the verdict depends on its words. It is settled by obtaining folios XIII-30/31 (kb/Work PB4952). The sibling report footing rule, printed, does bound the RF by the PF's final LINE-COUNTER (XIII.3.10.10 GR1a), which makes reading 1 likely but does not prove it. The checker's confidence: medium.
