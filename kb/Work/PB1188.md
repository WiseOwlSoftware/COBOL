# PB1188 — LANDED 2026-09-27 (wave 68 V2; EC-REPORT-LINE-OVERLAP landed with PB1130, wave 68 V)

## Landed (wave 68 V2, 2026-09-27) — the three remaining nonfatal report raise sites

- **EC-REPORT-PAGE-LIMIT** (§13.18.35.4 GR2): `CobolReport.PresentLine` raises it for a line of a paged report
  placed below the page limit; RAISED, the rest of the GROUP is abandoned (`PresentLines` → false) and the group's
  NEXT GROUP and end-of-group reset are skipped — §14.9.16.4 GR8 / §14.9.46.4 GR5 "resumes at the next report item,
  line, or report group, whichever follows in logical order", the unit that cannot be printed on one page being the
  group.
- **EC-REPORT-COLUMN-OVERLAP** (§13.18.14.4 GR4): a composed line is a `ReportLineImage` that records which columns
  a printable item uses; the engine's `Place` (now an instance method, `__RPT_n.Place`) raises the condition for an
  item over a used column and, RAISED, does not place it (resume at the next item). Absent items never reach it
  (§13.18.41.4 GR3 e)).
- **EC-REPORT-PAGE-WIDTH** (§13.18.14.4 GR5): `Place` raises it for an item ending past the page width; the line
  "is truncated, and the report line is printed" either way. The page width is §13.18.39.4 GR5's default 999: the
  PAGE clause's COLUMNS operand still has no grammar surface (kb/Work PB1059 — its GR-13.18.14.4-5 row).
- Wiring: the three `CheckingFlags` fields, `ExceptionEngine` raise methods and `ExceptionState` facades,
  `EcEmitter.NonfatalAmbientGates` rows and `EcBinder.ReportProductionNames` (GENERATE and TERMINATE).
- **Golden:** `conformance:2002/pb1188_report_nonfatal_raise` — all three raised under GENERATE and PAGE-LIMIT under
  TERMINATE, where the report footing still prints after the abandoned control footing. No negative: >>TURN below
  2002 is already gated.

## Finding — `terminate-statement` (silent; rows `GR-14.9.46.4-5`)

**Mechanism.** The report engine has no raise site for any NONFATAL report exception (EC-REPORT-PAGE-LIMIT, EC-REPORT-LINE-OVERLAP, EC-REPORT-PAGE-WIDTH, EC-REPORT-COLUMN-OVERLAP), so the TERMINATE continuation rule for a nonfatal exception has no path to act on

**Repro.** >>TURN EC-REPORT-PAGE-LIMIT CHECKING ON; RD R-1 PAGE LIMIT 5 LINES with a TYPE RF group of 8 lines; USE AFTER EXCEPTION CONDITION EC-REPORT-PAGE-LIMIT declarative that DISPLAYs; INITIATE; GENERATE; TERMINATE. (reasoned from source: grep of src/ for the four names finds only ExceptionCatalog.cs entries)

**Expected from the spec.** §13.18.35.4 GR2: a report group that cannot be printed on one page raises EC-REPORT-PAGE-LIMIT; §14.9.46.4 GR5: after a nonfatal exception during TERMINATE, execution resumes at the next report item, line or report group in logical order — the declarative runs, then the rest of the TERMINATE's groups are produced.

**Observed / reasoning.** ReportWriter.cs raises only FlowReportError, ReportActiveError, ReportInactiveError and ReportFileModeError (all Fatal). The nonfatal names are catalogued in ExceptionCatalog.cs (lines ~197-204) with no raise site; PB326 (landed) lists them as residual geometry seams with no open owning note. The declarative never runs and no resumption semantics exist.

**Code site.** src/Cobol.Net.Runtime/IO/ReportWriter.cs (PresentBody / PresentHeadingFooting / PresentPageFooting — no nonfatal raise); src/Cobol.Net.Runtime/Exceptions/ExceptionCatalog.cs (the unraised Nonfatal EC-REPORT-* names)

## What the fixer owes

Give ReportWriter (PresentBody / PresentHeadingFooting / PresentPageFooting) raise sites for the four nonfatal names with resumption per GR5, bound PRECISELY like the fatal EC-REPORT-* family in EcBinder; PB326 (landed) listed them as residual geometry seams with no owner — this note owns them. Sweep GENERATE's nonfatal twin rule.

## Update 2026-09-27 (wave 68 V) — EC-REPORT-LINE-OVERLAP now has its raise site (kb/Work PB1130 / PB1247)

`CobolReport.PresentLine` raises EC-REPORT-LINE-OVERLAP (`ExceptionState.ReportLineOverlapError`) for a line on or
above one already printed (other than a relative line with integer-2 zero, which overprints — §13.18.35.4 GR3), and
when it is RAISED abandons the line and resumes at the next one (§14.9.16.4 GR8 / §14.9.46.4 GR5); the name binds to
GENERATE and TERMINATE through `EcBinder.ReportProductionNames` and rides the `EcEmitter.NonfatalAmbientGates` row
`ReportLineOverlapChecking`. The three names left here — EC-REPORT-PAGE-LIMIT (resume at the next GROUP),
EC-REPORT-PAGE-WIDTH and EC-REPORT-COLUMN-OVERLAP (resume at the next ITEM) — join that list and that table with
their raise sites; TERMINATE's GR5 resume already holds at LINE granularity for the one raised today.
