# PB5734 - UNSTRING COUNT IN, TALLYING IN and WITH POINTER, and STRING WITH POINTER, over a reference-modified integer item pass the binder (StringUnstringBinder.StrUnstrIsInteger reads the base item's PICTURE) and fail in the C# compile, CS1503, with no COBOL diagnostic (every edition)

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/StringUnstringBinder.cs#StrUnstrIsInteger` (reads `p.Item.Pic`, the base item's PICTURE, through a reference modification; the one integer classifier is `IntrinsicResultType.IsIntegerOperand`, which answers false for a `RefModPlace`, kb/Work PB5384)
- `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/StringUnstringBinder.cs#StrUnstrIsInteger` (now asks `IntrinsicResultType.IsIntegerOperand` of the operand as bound, landed)

**Mechanism.** The same shape kb/Work PB5384 (landed) fixed for SEND: an integer-item rule asked of the item as declared,
not of the operand as bound. A reference modification of a numeric item is alphanumeric (§1985:IV.4.3.8.4.4 GR2; at 2023
§2023:8.4.3.3.4), so the operand is no integer data item; the binder admits it, the emitter passes a string where the
runtime takes a long, and Roslyn refuses the generated C#. Every caller of `StrUnstrIsInteger` is one arm: STRING's
POINTER (identifier-4), UNSTRING's COUNT IN (identifier-6), POINTER (identifier-7) and TALLYING IN (identifier-8).

**Inventory.** 2023: `SR-14.9.48.3-5` (COUNT IN / TALLYING IN), `SR-14.9.48.3-6` (UNSTRING POINTER), `SR-14.9.43.3-7` (STRING
POINTER), each re-recorded PARTIAL naming this note by the registrar landing records-sample-pb5692. The 1985 row
`1985-SR-VI.6.27.3-4` (KEPT into `SR-14.9.48.3-5`; a 1985 id is refused in `inventory_rows`, kb/Work PB5094), and with it
`1985-SR-VI.6.25.3-5` (STRING's pointer, KEPT into `SR-14.9.43.3-7`) and `1985-SR-VI.6.27.3-5` (UNSTRING's pointer, KEPT into
`SR-14.9.48.3-6`), read GAP through their chains once the 2023 rows are non-conforming (measured with `inventory_view.py
--states --edition 1985` before and after the re-record); no 2002 row's state moved.
