# PB5136 - the empty-section debug subject

**Found.** PB5083 places a section subject at its first pc. A section with zero paragraphs has no pc and executes no statement,
so a section subject of it never fires, and the compiler says nothing. The implementer reasoned that no cause applies (nothing
executes), which is the behavior today; whether the standard requires a diagnostic or a different behavior is not established.

**Sites:** none (an analysis; it changes no file until it concludes).

**Owed (analysis).** Read §1985 section XV (the debug module, 3.2.4 general rules on procedure-name subjects) and the 2002 text
that PB5083 removed the facility from, decide whether the silent never-fire is conforming, and if a diagnostic is warranted, file
the defect. Run `cite.py --check` on any citation before it is written. Same area as PB5083; shares no root with PB5134.
