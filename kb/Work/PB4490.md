# PB4490 - two static caches of one ATN set

**Defect.** PB4449's `BeginsAStatement` (`src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs` ~258) reads FIRST(`statement`)
from the ATN once into the static `_statementStarts`. The grammar's `statementBlock` is `statement+`
(`CobolParserCore.g4` ~1132), so FIRST(`statement`) IS FIRST(`statementBlock`), which `StatementBlockStart` (~2918,
`_statementBlockStart`) already reads once and five call sites use. One rule is written twice (CLAUDE.md rule 5: one
mechanism per job).

**Fix direction.** `BeginsAStatement` asks `StatementBlockStart(recognizer).Contains(type)`; delete `_statementStarts`. Keep the
doc comment's reason (a statement-start word at a synchronization point ends no left statement, ISO 14.5.3.3 4) b)). The unit
theory `TheStartOfTheNextStatement_EndsNoStatementTheRecoveryLeft` is the regression net. If a future grammar change makes
`statementBlock` more than `statement+`, the two sets differ and the sweep must pick the one the question means: say so in the
doc comment.

**Sites:** `src/WiseOwl.Cobol.Frontend/Parsing/CobolErrorStrategy.cs` (`CobolErrorStrategy.BeginsAStatement`, `CobolErrorStrategy.StatementBlockStart`).
