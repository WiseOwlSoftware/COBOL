# PB5777 - UNSTRING with no DELIMITED BY examines a group receiver that holds an OCCURS DEPENDING ON table at its maximum size (every edition)

**What is wrong.** UNSTRING without DELIMITED BY examines a group receiver holding an OCCURS DEPENDING ON table (object outside the group) at the group's maximum size instead of its current size, consuming extra sender characters and taking the wrong characters. GR13b: the characters examined equal the size of the current receiving area; with data-name-1 outside the group only the part given by its value is used (`§1985:VI.5.8.4 GR3a`). OH's current size is 2, so the expected result is `OH=[AB] R1=[CDE] P=06`. Observed `R1=[FGH] P=09` at 85 and at 2023: `ReceivingStore.CharacterPositions` answers a group with its static `ImageWidth` (the maximum). The Mythos lane did not run this program itself.
