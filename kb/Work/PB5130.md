# PB5130 - at --std 85 FUNCTION INTEGER-OF-DATE and INTEGER-OF-DAY return 0 for a year above 9999; the 1989 intrinsic-function module bounds the year below only (greater than 1600)

**Sites:** `src/WiseOwl.Cobol.Runtime/Intrinsics/CobolDate.cs#IntegerOfDate` (line 67 of the pinned tree: "year is < 1601 or > 9999" returns `ExceptionState.ArgumentError`, 0, in every edition) and `#IntegerOfDay` (line 78, the same test); the conversion uses System.DateTime, whose range ends at year 9999, and `MaxIntegerDate = 3_067_671` is the 2023 ceiling. LANDED: the year's upper bound is gated by `DialectBehavior.IntegerDateFormBounded` (2002, VCR 7.57): `src/WiseOwl.Cobol.Runtime/Control/DialectBehavior.cs` (`DialectBehaviors.Table`), `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/IntrinsicBinder.cs` (`BindFunctionResult`), `src/WiseOwl.Cobol.Compiler/Binding/Bound/BoundTree.cs` (`BoundIntrinsicCall.IntegerDateFormUnbounded`), `src/WiseOwl.Cobol.Compiler/CodeGen/Emit/IntrinsicRenderer.cs` (the date-conversion arm), `src/WiseOwl.Cobol.Runtime/Intrinsics/CobolDate.cs` (`DateOfInteger`, `DayOfInteger`, `IntegerOfDate`, `IntegerOfDay`, `YearAndDayOf`, `DaysBeforeYear`) and `src/WiseOwl.Cobol.Runtime/Values/Numeric/FunctionValueField.cs` (`OfDigits`, the DISPLAY temporary of a nine-digit date)

**Mechanism.** §1989:A.2.16.3 AR1 requires the year to be "an integer greater than 1600" and gives no upper bound (2023 adds "and less than 10000", §2023:15.46.3 AR1). The argument is an integer of the form YYYYMMDD defined by the calculation (YYYY * 10,000) + (MM * 100) + DD, so 100000101 (YYYY 10000) and 100001231 are valid 1989 arguments and the returned value is the number of days the date succeeds December 31, 1600 (§1989:A.2.16.4). Derivation in the record: 1601 through 10000 is 8,400 years, 21 cycles of 146,097 days, so 10000-12-31 is day 3068037; year 10000 is a leap year, so 9999-12-31 is day 3067671 and 10000-01-01 is day 3067672. The compiler returns 0 in silence at every edition (1985 has no exception condition to report it). Sibling probe: FUNCTION INTEGER-OF-DAY (10000001), valid under §1989:A.2.17.3 (the same "greater than 1600" and no upper limit), also returns 0 where the 1989 value is 3067672. kb/Work PB23 (landed) and PB2634 hold the 2023 ceiling of 9999 / 3,067,671 as correct for 2023. The reading rests on the year's only stated limit being "greater than 1600"; the change record (CHANGED, stricter in 2023) rejects an eight-digit-limit reading.
