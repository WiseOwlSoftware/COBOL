# PB5720 - at --std 2002 STANDARD-COMPARE uses the 2020-derived default ordering table, and ORDER TABLE "ISO14651_2002_TABLE1" is declared not provided yet no EC-ORDER-NOT-SUPPORTED is raised

**Sites:**
- src/WiseOwl.Cobol.Runtime/Collation/CollationEngine.cs#TryGetOrderingTable
- `src/WiseOwl.Cobol.Compiler/Binding/SpecialNamesBinder.cs` (whole: COBOL1662)
