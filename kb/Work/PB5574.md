# PB5574 - the 2002 inventory to zero: decisions, stages, measures

**The decisions.**

1. **No edition is linked between 1985 and 2023, ever.** Every older held edition's change record names the newest held
   edition (2023). Holding an edition never re-targets another edition's records. Adjacent deltas are derived by
   composing two direct records into the same 2023 rule, and a drift script lists contradictions (a 1985 KEPT and a
   2002 CHANGED into one rule).

   Why: linking 2002 would refuse all 2,260 1985 records. 648 of the 1,180 2023 rules that 1985 KEPT records reach
   could be composed by script; about 1,400 records would need judgment, and up to 1,373 closed 1985 rows would reopen
   meanwhile. Linking 2014 later would refuse every 2002 record. Neither closes a row. With direct chains, each of the
   four per-edition compilers is validated against its own edition, and no edition's GAP waits on, or inherits errors
   from, a neighbour.

   Follow-up (the tooling note filed beside this one, PB5583):
   - DESIGN-spec-conformance-review.md §10.2 and §10.4 state this design;
   - `Edition.linked`, the schema's `linked` key, `link_errors`' linking clause and the C# reading of it are deleted;
   - `next_held` of every older edition is the newest edition;
   - a chain proves its band at its own edition only (`lineage.spanned` / `chain_bands`).

2. **The rule stage.** A 2002 rule is recorded KEPT by rule only when all of these hold:
   - it is word-identical (`exact`) to one 2023 rule that is CONFORMS, OK and band-2002;
   - it is word-identical in the 2014 text;
   - it names no clause number;
   - it uses no term whose definition changed (35) or that §2002:4 defines and 2023's definitions clause does not (54);
   - it depends on no pending clause that changed or was removed (the pending-clause diff,
     `lineage.py --pending-diff 2002`);
   - it lies in no clause holding a DialectBehavior row with ChangedIn > 2002 (INSPECT, READ, WRITE, compile-time
     arithmetic and constants).

   Every other pair is judged by a reader with the changed pending clause in its brief, and an independent refuter.
   The 89 pending clauses are NOT adjudicated first. Their disposition decides the denominator (PB5456), not the
   meaning of a paired rule; the diff decides that, and it is a script.

3. **The residual.** At most 20 false KEPT rows among the 674 rows of the first rule batch, at 95 %. The basis: a seeded
   blind sample of 100 (seed 20261115) with 0 false identities found, so p <= 1 - 0.05^(1/100) = 2.95 % and
   674 x 2.95 % = 19.9. One error stops the rule batch; its mechanism becomes a P0 trigger and the sample is re-drawn.
   After landing, a standing sample of 20 KEPT rows a wave is read by the code-read pipe at `--std 2002`. An overturn
   reopens its class.

4. **Evidence for a KEPT row.** The 2023 row's evidence stands through the chain, as the schema says. No run at 2002 is
   required. A 2023-derived witness run at 2002 shows only that the compiler agrees with itself (review F2), and it
   is evidence only where an edition gate sits on the rule's path; those rows are excluded from the rule stage by
   decision 2. The widened cases that pass at 2002 (404) land as regression coverage. The 91 refused for an unrelated
   newer construct are reverted and need no 2002 twin.

5. **Documented non-support** is recorded CHANGED, with the reason that the conformance requirement differs
   (§2002:3.1 against §2023:A.4.x), and its own 2002 verdict. A KEPT row cannot carry a 2002 licence.
   - **Screen handling** (127 rows) is licensed by §2002:3.1.5 and B.3 item 1, and is recorded DOCUMENTED-NON-SUPPORT
     (PB5581).
   - **A.3 processor-dependent** (5 rows) holds only where B.3 lists the element.
   - **No licence** for VALIDATE (54 paired rows, PB5577), FORMAT and SELECT WHEN file handling (22, PB5578), REWRITE
     FILE and WRITE FILE (5, PB5579), and the OO optional items (1, PB5580). §2002:3.1.1 requires every element
     outside Annex A and the processor-dependent list. These rows are NOT-IMPLEMENTED until the features are built at
     `--std 2002`. I decide to build them.

- S1 (adopt-2002-s1, 8ebed7c4e0): 948 runs at 2002, 852 pass, 1 output difference (a test accepted only at 85), 95
  refused by edition gates (91 for a construct outside the rule, 4 naming the rule's own construct, held); the
  1,313-record dry run accepted every record (GAP 3,297 -> 1,984 unfiltered).
