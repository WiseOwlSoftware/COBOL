# PB5293 - DEBUG-CONTENTS of a data-item trigger on a variable-length group carries the occurrences past the current OCCURS DEPENDING ON count: the runtime sends the item's maximum-length storage image, where 1985 moves the item's current content and space-fills the rest

**Sites:**

- `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/DebugTriggerEmitter.cs` (`FireText`)
- `src/WiseOwl.Cobol.Runtime/Control/DebugItem.cs` (`Populate`)

**Mechanism.** §1985:XV.3.2.4 GR11 updates DEBUG-ITEM by MOVE rules, DEBUG-CONTENTS "as if it was an alphanumeric to alphanumeric elementary move with no conversion", and GR24 c fills it with "the content of the data item referenced by identifier-1 at the time that control passes to the debugging section"; a variable-length group uses "only that part of the table area that is specified by the value of the data item referenced by data-name-1 at the start of the operation" (§1985:VI.5.8.4 GR3). `FireText` passes the item's whole storage image (docs/CONFORMANCE.md D-DEBUG-DATA item 5), so characters of occurrences past the count appear.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the non-conforming verdicts wait in `E:/COBOL-coord/scratch/coderead-85/p2-for-register.json`.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-GR-XV.3.2.4-11` - `§1985:XV.3.2.4 GR11` (refuter: OVERTURNED, harm: wrong-answer): "no conversion of data from one form of internal representation to another"

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-pipe/refute-slice-67/r8.cob`: `01 G. 05 GE PIC X OCCURS 1 TO 5 DEPENDING ON N.`, USE FOR DEBUGGING ON G; MOVE "VWXYZ" TO G with N 5, then N 2 and MOVE "AB" TO G; `cobol.exe --std 85 --source-format fixed --run r8.cob`.

**Observed (a build of origin/main f2cf36fd15, rerun 2026-11-11; main has since changed only `IndexedConnector.cs` under `src/`, which none of these repros reaches).** `G  C=[VWXYZ   ]`, then `G  C=[ABXYZ   ]`.

**Expected (from the 1985 text).** The second line `G  C=[AB      ]`.

**Fix direction (root cause, CLAUDE.md rule 4).** Size the DEBUG-CONTENTS move by the referenced item's current length at 85, then update D-DEBUG-DATA item 5; test the ODO group.
