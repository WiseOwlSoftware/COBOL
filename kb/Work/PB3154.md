# PB3154 — repository class names are declared again in the factory and instance censuses

Source: wave 1076 (unit `w1076a`, PB2921), new-defects lead 2. The repro was run by the w1076a implementer on its build (bf8-1 at 3429aad94) with the result below; the report adds that the w1074a2 build refuses it too, so it predates PB2921. Not re-probed by the clerk (R2). R1: no open note covers it (PB2160 unifies the two OoReparent* copies, a different mechanism).

**Rule.** The report cites §10.5 and §8.4.6.1. §8.4.6.1 checks OK; the quoted text of §10.5 could not be checked mechanically (`cite.py --check 10.5 "REPOSITORY"` FAILs), so only the clause numbers are recorded and an implementer must re-derive them (rule 1).

**Observed.** `01 F1G PIC X.` in the FACTORY of class F1H, whose REPOSITORY names CLASS F1G, is refused COBOLNET2692, although the factory never uses F1G. Expected: accepted (legal source).

**Code site.** `OoDriver.BindClassData` (`src/Cobol.Net.Compiler/Oo/OoDriver.cs:117`) binds the class's environment division through each definition's binder, via `OoReparentClassData` (defined :219, called :143) and `OoReparentFactoryData` (defined :231, called :162); the repository entries are thereby declared in the factory census too (`fdata.BindDeclarations(fsynthetic)`, :163) and in the instance census (:144). Related: PB2160 (the two reparent copies).

**Repro (`f1.cob`, scratch path transient, source inline):**

```cobol
       IDENTIFICATION DIVISION.
       CLASS-ID. F1G INHERITS FROM BASE.
       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.
       REPOSITORY.
           CLASS BASE.
       END CLASS F1G.

       IDENTIFICATION DIVISION.
       CLASS-ID. F1H INHERITS FROM BASE.
       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.
       REPOSITORY.
           CLASS BASE
           CLASS F1G.
       IDENTIFICATION DIVISION.
       FACTORY.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 F1G PIC X.
       END FACTORY.
       END CLASS F1H.
```

**Fix shape.** Declare the class environment's repository names once, in the binder that owns them, and give the factory and instance binders an inherited (not declared) view, the PB990 inherited-name model; sweep the instance (OBJECT) side, which shares the mechanism.
