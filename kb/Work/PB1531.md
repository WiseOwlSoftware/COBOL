# PB1531 — LANDED

## The rule

> There are two types of level-3 of implementor-defined exception-names. The first type … are defined by the implementor by creating a level-3 exception-name starting with the characters 'EC-IMP-' … The second type is the suffix '-IMP' added to the end of all of the level-2 exception names …

`cite.py --check 14.6.13.1.1 "There are two types of level-3 of implementor-defined exception-names"` → OK §14.6.13.1.1 (the
adjudicator's §14.6.13.1.6 is Table 13, `cite.py --check 14.6.13.1.6 "EC-IMP-suffix"` → OK). Annex A.1 items 99 (EC-IMP-suffix) and
100 (EC-level-2-IMP) are optional and documented if provided.

## Repro (re-probed by the registrar, Debug build of `0caa7d5`, `--std 2023`)

```cobol
      >>TURN EC-ALL CHECKING ON
           RAISE EXCEPTION EC-IMP-WIBBLE.
```

→ compiles clean; run: `abnormal run-unit termination: EC-IMP-WIBBLE (fatal): raised by RAISE and not resumed`. The implementor
DEFINES the EC-IMP- names; COBOL.NET defines none, so `EC-IMP-WIBBLE` names no exception condition and a program naming it
should be refused (or the family must be documented as provided). `RAISE EXCEPTION EC-PROGRAM-IMP` → fatal, exit 1; EC-PROGRAM-IMP IS
provided (raised at one internal site) and is undocumented.

## Code sites

`src/Cobol.Net.Runtime/Exceptions/ExceptionCatalog.cs#TryGet` (the open EC-IMP-* arm); `src/Cobol.Net.Runtime/Control/ProgramTable.cs`
(~l.518, the one EC-PROGRAM-IMP raise); `src/Cobol.Net.Runtime/Control/ProgramRegistry.cs#CobolCallException`. The Imp → fatal
determination lives only in code comments.

## Fix

Make the provided set a closed, documented list (the catalog is the SSOT; §7 rows DOC-A.1-99/-100 generated or drift-tested from it)
and refuse any other EC-IMP-suffix at compile time with a named diagnostic. Rows `DOC-A.1-99`, `DOC-A.1-100` (adjudicated
**DIVERGES** on `claude/adj-a1-w1-s4`; not recorded — DOC rows wait on PB1535).
