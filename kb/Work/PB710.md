# PB710 — OPEN — the gate cannot see a word the lexer never makes

Found 2026-09-05 by the `PB693` finisher (report, "Things that did not hold" 2) while sweeping every `cobolWord`
site for keywords routed through the user-word slot. A design boundary of PB693's mechanism, stated there, not a
regression.

## The facts

- PB693 derives the reservation gate from `reserved-words.json` (§8.9 — `cite.py --check 8.9 "Reserved words"` →
  OK on the clause heading; the finisher additionally cited §8.3.2.1 rule 1 for "a reserved word shall not be used
  as a user-defined word" — **re-derive that quote with `--check` before relying on it**) and enforces it in the
  parser through the `userWordHere` predicate on the gated words' TOKENS.
- The lexer tokenizes only the reserved words some grammar rule consumes as a keyword. Words §8.9 reserves that no
  rule consumes — the finisher's sweep names LOCALE, ORDER, CLASSIFICATION among the `cobolWord`-routed set, and the
  full complement is `reserved-words.json` minus the lexer's token list — reach the parser as IDENTIFIER, so the gate
  has nothing to test and `01 LOCALE PIC X.` at `--std 2002/2014/2023` compiles without COBOLNET0901.
- Repro shape: for each word in `reserved-words.json` whose edition set includes 2002, compile `01 <word> PIC X.` at
  `--std 2002` strict and expect COBOLNET0901 — the complement of the tokenized set passes. The probe's population
  must be asserted (`verdict_evidence_invariant`): the count of words probed equals the count in the JSON.

## Why it matters

Under-rejection: a 2002+ program that uses a reserved word as a data-name is accepted here and rejected by every
conforming compiler, so source that compiles here is not portable — the mirror image of PB693's over-rejection, and
the same rule. It is silent: no diagnostic, no warning, nothing in the conformance statement.

## The fix shape

The gate belongs at the WORD level, not the token level: after lexing, an IDENTIFIER whose text is in the edition's
§8.9 set is a reserved word in a user-word slot and gets COBOLNET0901 through the same `userWordHere` path — one
predicate, one message (`ReservedWordSet.UserWordViolationMessage`), one drift test extended from
`CobolWordsG4_ReservationGate_Is_Derived_From_Section89` to assert that EVERY §8.9 word, tokenized or not, is
gated. Re-admission slots (program/section/paragraph names, SELECT file-name) keep their PB693 behaviour. Then the
per-word probe above becomes a conformance test with an asserted population.
