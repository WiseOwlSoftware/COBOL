# PB5272 - at --std 85 EXIT PROGRAM followed by a conditional statement (an IF without END-IF, READ ... AT END, ADD ... ON SIZE ERROR) is refused COBOL0900: the edition gate asks whether any statement follows EXIT PROGRAM, not whether EXIT PROGRAM ends its run of imperative statements

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Validation/VersionConformancePass.cs` (`VisitExitStatement`)

**Mechanism.** The 85 arm of construct `exit-program-not-last-2002` (kb/Work PB4305, COBOL0900) fires when any statement follows EXIT PROGRAM in its sentence. §1985:X.5.4.3 SR1 asks only that EXIT PROGRAM be the last statement of a consecutive sequence of IMPERATIVE statements, and an undelimited IF, READ ... AT END or ADD ... ON SIZE ERROR is a conditional statement (§1985:IV.6.4.2.1.1), so EXIT PROGRAM followed by one ends its imperative run. The GO TO twin already asks the right predicate, `StatementPosition.EndsImperativeRun` (kb/Work PB2610).

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the non-conforming verdicts wait in `E:/COBOL-coord/scratch/coderead-85/p2-for-register.json`.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-SR-X.5.4.3-1` - `§1985:X.5.4.3 SR1` (read: PARTIAL, harm: rejects-legal-source): "it must appear as the last statement in that sequence"

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-pipe/work-slice-44/e1-cond.cob`: a contained SUBPGM whose paragraph is `EXIT PROGRAM IF B = 1 DISPLAY 'Y'.` called from MAINPGM, which then displays BACK; `cobol.exe --std 85 --source-format fixed --run e1-cond.cob` (siblings `e1-readc.cob`, `e1-wsize.cob`).

**Observed (a build of origin/main f2cf36fd15, rerun 2026-11-11; main has since changed only `IndexedConnector.cs` under `src/`, which none of these repros reaches).** exit 65: `e1-cond.cob(18,12): error COBOL0900: an EXIT PROGRAM statement followed by another statement in its sequence requires COBOL-2002 (targeting COBOL-85)`.

**Expected (from the 1985 text).** Compiles and prints BACK.

**Fix direction (root cause, CLAUDE.md rule 4).** Ask `StatementPosition.EndsImperativeRun` in the EXIT PROGRAM arm, as the GO TO arm does, so both statements read one predicate; test each conditional follower at 85.
