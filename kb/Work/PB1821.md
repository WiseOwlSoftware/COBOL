# PB1821 — OPEN

Found 2026-09-30 while landing PB1800 (the one line-entry stage, `PhysicalLines`). `src/Cobol.Net.Frontend/Common/SourceText.cs`
is a buffer with a line-start index whose own reading of line ends treats a lone CR as a line end (`SourceText.cs` ~l.94-115:
`'\n' or '\r'`, "skip \n in \r\n") — the answer DOC-A.1-156 now rejects (LF, or CR LF; a lone CR is a character). Nothing in
`src/` uses it (`grep SourceText src` finds only the Roslyn source generator's unrelated `Microsoft.CodeAnalysis.Text.SourceText`);
the one referrer was the legacy unit project's `Common/SourceTextTests.cs`, deleted with that project (PB2110), so nothing refers to it now. SURVEY-frontend-plumbing §S7 already recorded it
as dead (2026-07-07).

**Fix.** Delete `SourceText.cs` and `SourceTextTests.cs` (and the two lines naming it in the SURVEY, which is a dated snapshot
and is left as is). It is out of PB1800's change set only because it is unreferenced, so deleting it is not needed to keep the
pipeline's one line model true; left alone it is a second, wrong line model one `using` away from a future consumer — which is
the next instance of the pattern PB1800 closed. One-line sweep once deleted: `PhysicalLinesDriftTests` already guards the
pipeline directories; extend its scope to `Common/` only if a live line consumer ever appears there.
