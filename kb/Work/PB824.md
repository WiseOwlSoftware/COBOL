# PB824 — OPEN — the claims that decide behaviour are the ones nothing checks

Filed 2026-09-09 by the registrar (second pass) from the **PB366 implementer's report** §13 (b) —
`scratchpad/reports/PB366-report.md`. The implementer fixed the one line in the same change set (rule 6) and
asked for the *pattern* to be measured. **It is measured below.**

## The instance, and what it cost

`docs/COBOLNET_OO_DESIGN.md` §EC-OO RESOLVED read:

> USE Format 4 (`__EcObjDispatch` — GR14a class-or-subclass IS C#'s `is`)

That sentence is where the [[PB366]] wrong answer was actually decided. §14.9.49.4 GR14 a) names **two** object
kinds in one clause — the exception object "is a factory object or instance object of object-class-name-1 or of
a subclass of object-class-name-1" — and a COBOL class is emitted as **two disjoint C# hierarchies**. The
paraphrase silently dropped one, `EcEmitter.EmitObjDispatchSelector` implemented the doc faithfully, and
`USE AFTER EXCEPTION OBJECT CF1` selected **no declarative at all** for a factory exception object, silently.

The doc was not wrong about a detail. The doc was the design, and the design had lost half the rule.

## The measurement

```
$ grep -rn "RESOLVED\|holds structurally" docs/*.md docs/rearchitecture/DESIGN-*.md | wc -l
50
$ …                                            | grep -c '"'                              6
$ …                                            | grep -cE '§?[0-9]+\.[0-9]+(\.[0-9]+)+'    5
```

Roughly **44 of 50** such claims carry neither a quoted fragment nor a clause number on their own line. For
contrast, the audit that exists reports its population as:

```
$ python scripts/spec/audit_doc_citations.py --check
382 verbatim-shaped citations checked · 326 correct
⛔ 0 MISFILED (the text is real, the clause is wrong) — these are defects
```

382 checkable citations, 0 misfiled — and the 44 claims most likely to *be* a design decision are not among
them. (The line-oriented grep is a first-order count: a claim whose quotation sits on the following line is
counted as unquoted, and a claim spanning a paragraph may be counted once. Sharpening it is step 1 below; the
order of magnitude is the finding.)

## Why this is not [[PB476]] and not [[PB591]]

Three notes now describe holes in the same two audits, and merging them would lose what each says:

| note | the hole | the cure it proposes |
|---|---|---|
| [[PB476]] | the audits gate on FINDINGS, never on POPULATION, so coverage can SHRINK silently (measured 249 → 248 in one edit) | assert the population count |
| [[PB591]] | a prose `§X GR<n>` reference names a rule ordinal that nothing checks (25 sites, 2 wrong) | an ordinal-existence check over `§<clause> GR<n>` spellings |
| **PB824** | a claim with **no citation at all** was never in the population and never will be; the audits are structurally blind to it | a citation-SHAPE rule for normative claims, plus the measurement above as a gate |

PB476's cure does not fire — the population never contained these. PB591's cure does not fire — there is no
`§X GR<n>` to check. **A claim with no citation is not a weak citation; it is outside the audits' domain**, and
that is the finding.

## What the analysis owes

1. **Sharpen the measurement** into a script (`scripts/spec/`): enumerate normative claims in the design docs —
   "RESOLVED", "holds structurally", "DETERMINATION", "the rule is", "per §" — and classify each as
   (a) quoting a fragment `cite.py --check` can validate, (b) naming a clause with no quotation, or (c) neither.
   Report the three counts. Prove it fails once before trusting it (`feedback_green_gates_arent_evidence`).
2. **Propose the citation-shape rule** for the doctrine: a design-doc sentence that states what the STANDARD
   requires shall carry a quotable fragment and its clause, so `audit_doc_citations.py` can see it. A sentence
   that states what COBOL.NET DOES needs no citation and shall not be forced into one — the rule has to
   distinguish them or it will be gamed by decoration.
3. **Decide the gate**: whether class (c) is allowed to be non-zero, and if so, with what marker. A hard zero on
   50 claims is a large repair; a ratchet (the count may not grow) is landable now and is the shape
   [[PB476]]'s population gate wants anyway — which is where these three notes could share one mechanism.

## The forensic point worth keeping

`feedback_a_real_clause_can_answer_a_different_question` records three instances in one session of a citation
that is *real* and answers a *different* question. This note is the degenerate case of the same family: no
citation, and therefore nothing to be wrong — which reads as confidence rather than as a gap, and passed every
gate for as long as it existed.
