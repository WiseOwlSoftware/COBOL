# PB5170 - at --std 85 SOURCE-COMPUTER, OBJECT-COMPUTER and SPECIAL-NAMES followed by two periods and no entry compile: the paragraph's second period is optional whatever precedes it, and ScreenParagraphPeriods returns when there is no sentence

**Sites:**

- `src/WiseOwl.Cobol.Frontend/Grammar/CobolParserCore.g4` (`sourceComputerParagraph`, `objectComputerParagraph`)
- `src/WiseOwl.Cobol.Compiler/Validation/ClosedFormatPass.cs` (`ScreenParagraphPeriods`)
- `src/WiseOwl.Cobol.Frontend/Cst/ParagraphPeriods.cs` (`Sentences`)
- the fix (2026-11-11): `src/WiseOwl.Cobol.Frontend/Cst/ParagraphPeriods.cs` (`LonePeriod`); `src/WiseOwl.Cobol.Compiler/Validation/VersionConformancePass.cs` (`GateLonePeriod`, `VisitSourceComputerParagraph`, `VisitObjectComputerParagraph`, `VisitSpecialNamesParagraph`); `tests/version-matrix/constructs/configuration-paragraph-lone-period-2002.json`

**Mechanism.** The 1985 configuration paragraphs print the header and its period, then one bracket holding the entry and the second period, so the second period comes only with an entry (§1985:VI.4.3.2, §1985:VI.4.4.2, §1985:VI.4.5.2, printed pages rendered by the code read). The grammar makes the final period optional whatever precedes it, and `ClosedFormatPass.ScreenParagraphPeriods` returns at once when `ParagraphPeriods.Sentences` finds no sentence, so `SOURCE-COMPUTER. .`, `OBJECT-COMPUTER. .` and `SPECIAL-NAMES. .` compile at --std 85; that spelling is the 2023 format's. The SPECIAL-NAMES case is recorded on 1985-FMT-VI.4.5.2, which kb/Work PB5171 claims.

**Found by.** The 1985 code read (2026-11-10; its records are `E:/COBOL-coord/scratch/coderead-85/for-register.json`): each rule below was read against the code sites it names and probed at `--std 85`, and found non-conforming. Verdict, harm, evidence, repro and observed text are the records'; the rows' verdicts are recorded on another branch.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids of the list below.
