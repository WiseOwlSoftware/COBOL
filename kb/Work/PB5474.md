# PB5474 - at --std 85 SUM ... UPON a detail report group of ANOTHER report compiles and totals: ResolveUponDetail resolves the name across reports, where §1985:XIII.3.19.3 SR2 requires a detail of the same report

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/ReportSectionBinder.cs` (`ReportSectionBinder.ResolveUponDetail`)

**Mechanism.** `ReportSectionBinder.ResolveUponDetail` resolves UPON data-name-1 through the report-group resolution of the whole Report Section and refuses only a non-group or a non-detail (COBOL2046). kb/Work PB1294 built the cross-report UPON for 2002 and later; at 85 the detail must be "described in the same report as the control footing report group in which the SUM clause appears", so `UPON DET2 OF RPT2` (and the unqualified `UPON DET2`) from a footing of RPT must be refused. kb/Work PB5253 (landed) is the SR1 sibling (a sum counter of another report).

**Found by.** The 1985 code read, read 4 (`kb/Work/PB4996/2026-11-13-read-4.md`): the reader of `E:/COBOL-coord/scratch/coderead-85/out-read4/rd-01.json`.

- `1985-SR-XIII.3.19.3-2` - `§1985:XIII.3.19.3 SR2` (read: PARTIAL, harm: under-rejects): "Data-name-1 must be the name of a detail report group described in the same report as the control footing report group in which the SUM clause appears".

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-read4/work-rd-01/c7/s03.cob` (and `s04.cob`, the unqualified `UPON DET2`): two reports RPT and RPT2, each CONTROL IS FINAL; RPT's footing

with `GENERATE DET2` twice. `cobol.exe --std 85 --source-format fixed --run s03.cob`.
