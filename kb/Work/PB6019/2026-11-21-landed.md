# PB6019 landed (wave 20262131 group r, branch train85b-argrange): every 1985 breach terminates, one path

Decided by the controller (brief w20262131 group r): at `--std 85` every argument-rule violation detected at run time takes the path
group l built for the integer check. Implemented at the one raise site: `ExceptionEngine.ArgumentError` (and `ArgumentErrorZeroLength`,
`ArgumentErrorSpaces`, which call it) terminates the run unit when `ArgumentBreachTerminates` is set, with the detail and "the result of
such a reference is undefined (§1989:A.2.2 p3) and the run unit is terminated, as §1985:p.B-46 allows". The flag is the ACTIVATION's:
`ICobolProgram.ArgumentBreachTerminates` (default false), which a COBOL-85 program class overrides to true (`ProgramEmitter`), and
`ProgramTable.ActivateMain` / `CallProgram` install it and restore the activator's, as they do the nonfatal selector. Group l's
compile-time `terminates` argument of `CheckedIntegerArgument*` and `RuntimeApi.IntegerArgumentSite.Terminates` are deleted; the integer
check calls `ArgumentError` like every other check. From 2002 nothing changes (EC-ARGUMENT-FUNCTION, §2002:15.2 AR13, §2014:15.3 AR13,
§2023:15.3 AR14; DOC-A.1-90 unchecked).

Re-probe at --std 85 on the base (fa98065c7a): FACTORIAL (N - 5) printed `R 0000` and `CONTINUED`; SQRT (-1) printed 0. On the head
both terminate. Sweep (24 probes, `E:/COBOL-coord/scratch/w20262131r/sweep/`): FACTORIAL, SQRT, LOG, LOG10, ACOS, ASIN, MOD, REM,
INTEGER-OF-DATE, INTEGER-OF-DAY, DATE-OF-INTEGER, DAY-OF-INTEGER, ANNUITY (both arguments), PRESENT-VALUE, RANDOM, CHAR, NUMVAL,
NUMVAL-C each terminate at 85 with their message; literal arguments (FACTORIAL (-1), SQRT (-1), MOD (5, 0), INTEGER-OF-DATE (20231301),
LOG (0), RANDOM (-1)) the same, and at 2023 each still returns 0 unchecked. No intrinsic body answered a breach outside `ArgumentError`
(the drift test's first run named three sites: the exception catalog, which raises nothing, and the two empty-argument-list guards,
which call `ArgumentError` first and then end the reference; both are now its stated exemptions). CHAR (9999) at 85 returns a character:
not a breach, the native alphanumeric sequence has 65,536 positions in this implementation.
