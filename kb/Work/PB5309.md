# PB5309 - READ or RETURN ... INTO from a RECORD IS VARYING file sends fewer characters than the record read, padded with spaces, when the FIRST record description holds an OCCURS DEPENDING ON table whose count is below the length read: CurrentRecordImage windows the record area by that group's current ODO extent

**Sites:**

- `src/WiseOwl.Cobol.Compiler/CodeGen/Emit/OperandText.cs` (`CurrentRecordImage`, `CurrentRecordLength`)

**Mechanism.** With INTO, "the number of character positions in the current record that participate as the sending data items in the implicit MOVE statement" is fixed by §1985:VII.3.8.4 GR12: with RECORD IS VARYING ... DEPENDING ON, the length the data-name-1 holds. `CurrentRecordImage` reads `RecordAreaImage(area)`, which for a variable-occurrence group is the group's image at its CURRENT ODO count, and pads past it instead of reading the record area, so the sender is short and the result depends on the order of the record descriptions. kb/Work PB5217 is the WRITE twin (a shorter record sent at the ODO record's extent) at a different site.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the adjudicated non-conforming verdicts wait in `E:/COBOL-coord/scratch/coderead-85/held-for-register.json`.

**Rules (1; every citation checked with `scripts/spec/cite.py --check`, and each 1985 rule number compared with the numbered paragraph the quotation sits in, which cite.py does not do: kb/Work PB5317).**

- `1985-GR-VII.3.8.4-12` - `§1985:VII.3.8.4 GR12` (adjudicated: PARTIAL, harm: wrong-answer): "the number of character positions in the current record that participate as the sending data items in the implicit MOVE statement is determined by the following conditions"

**Repro.** `E:/COBOL-coord/scratch/held-85/set1/p/p08.cob`: `FD F1 RECORD IS VARYING IN SIZE FROM 1 TO 15 DEPENDING ON LEN.` with `01 R1. 05 E PIC X OCCURS 1 TO 15 DEPENDING ON CNT.` and `01 R2 PIC X(15).`; write ABCDEFGHIJKL with LEN 12, `MOVE 2 TO CNT`, `READ F1 INTO W` (W PIC X(20) JUSTIFIED RIGHT); `cobol.exe --std 85 --source-format fixed --run p08.cob`.

**Observed (a build of origin/main d9dde0e7ba (the source exported to `E:/COBOL-coord/scratch/main-d9dde0e7ba`), rerun 2026-11-11).** `INTO: [        AB          ] LEN=12`, `R2:   [ABCDEFGHIJKL   ]`.

**Expected (from the 1985 text).** `INTO: [        ABCDEFGHIJKL]`: twelve characters of the current record move.

**Fix direction (root cause, CLAUDE.md rule 4).** Take the INTO sender from the record area at the length GR12 fixes, not from a record description's current extent, in the one helper READ and RETURN share; test both orders of the record descriptions.
