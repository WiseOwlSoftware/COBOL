# PB4287 — SLL lookahead depth of the pointer usages (measurement only)

**Sites:** `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolScreen.g4` (whole: `screenToClause` puts TO in `usageKeyword`'s context-free follow; a grammar file is claimed whole), `src/WiseOwl.Cobol.Frontend/Parsing/CobolParserCoreBase.cs:431` (`CobolParserCoreBase.entryNameHere`, the speculative entry reading; read-only unless the measurement points there).

## What happens

Mythos review S3-1: the SLL lookahead for `functionPointerUsage` and `programPointerUsage` runs 28 and 19 tokens. TO is in `usageKeyword`'s context-free follow through `CobolScreen.g4`'s `screenToClause`, so the prediction between "TO continues the usage" and "exit the rule" looks ahead until the context-free paths separate. PB4235's live-context predicate (`pointerOperandHere`) does not change that TO-versus-exit prediction. No measurement exists beyond the review's depth figures, so this is an analysis note.

## Fix direction

Measure first: the per-decision lookahead and the time of a program with many `USAGE POINTER` entries (an allocation/decision-count witness, never a wall-clock test); close the note with the figures if it is not worth changing. If it is, restructure the grammar so the follow is the live one (a rule context argument), not a longer predicate. Related PB4243 measures the cold DFA of the same probe family.
