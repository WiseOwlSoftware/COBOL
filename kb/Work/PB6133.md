# PB6133 - BenchmarkDotNet 0.15.8 does not know net11.0

**Repro.** `tests/WiseOwl.Cobol.Benchmarks/bin/Release/net11.0/WiseOwl.Cobol.Benchmarks.exe --filter '*ScaledFloat*'` stops with an unhandled
`System.NotImplementedException: GetRuntimeVersion not implemented for NotRecognized` from `DotNetSdkValidator.ValidateCoreSdks`. `--inProcess`
does not help, because the `[Config]` job keeps the CsProj toolchain.

**Sites.** `tests/WiseOwl.Cobol.Benchmarks/Collation/BenchmarkConfig.cs:40-46` (`BenchmarkConfig..ctor`); `Directory.Packages.props:33`
(BenchmarkDotNet 0.15.8). `scripts/arch/perf_baseline.py` (CompileBenchmarks and GeneratedProgramBenchmarks share this config) has probably been
unable to measure since PB5971's move to net11.0.

**Fix options.** Upgrade to a BenchmarkDotNet that knows net11.0, or pin the toolchain. Pinning changes how the recorded baseline numbers are
measured, so it needs a decision note (PB2658's witness ran with `InProcessEmitToolchain` set on the job for that measurement only).
