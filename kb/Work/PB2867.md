# PB2867 — LANDED (wave 20261769 B)

## Landing — the subject's TYPE / SAME AS clause is composed while its own table bounds bind

**Re-verdict: the shape REJECTS LEGAL SOURCE.** The note's expected outcome (a being-described refusal) was wrong, and
COBOL0899 is no longer a being-described code (PB1941 retired it). §13.18.57.4 GR1 (`cite.py --check 13.18.57.4 "The
effect of the TYPE clause is as though the data description identified by type-name-1 had been coded in place of the
TYPE clause"` → OK 1)) makes `05 V TYPE T OCCURS K.` the same source as `05 V OCCURS K. 10 M PIC X(3).`, which PB1941
landed as legal: §13.10.3 SR4 (`cite.py --check 13.10.3` → OK 4)) forbids only a length that depends on K, and an
element's subordinate does not. §13.18.49.4 GR1 (checked, OK 1)) says the same of SAME AS.

**Re-probe** on 802352531 (`E:/COBOL-coord/scratch/w20261769b/p/p2867.cob`, and `p2867b.cob` with the constant before
the record): both drew `COBOL1547 … LENGTH OF 'M OF V (1)' — the data-name is not defined`, and so did the unqualified
`LENGTH OF M (1)` (`c5.cob`). The explicitly written twin (`c3.cob`) printed `3 9`. After the fix: `p2867` and `p2867b`
compile, `c5` prints `3 9`, a forward-declared nested type (`c6.cob`, `M OF I OF V (1)`) prints `4 24`, and a T whose
M is `PIC X(K)` (`c7.cob`) is still the SR4 cycle.

**Root.** Not `IsBeingDescribed`: a qualifier being described before its item exists cannot be a legal group, since
only the elementary-only clauses (PICTURE, VALUE, DYNAMIC LENGTH) read a constant there. `ComposePendingSubjectsAhead`
skipped every subject whose description was OPEN, and that includes the entry's own item while its table bounds bind,
the one moment PB1941 made an entry with subordinates able to demand a constant. So V's TYPE clause was never expanded
and `M OF V` found nothing.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/DataBinder.DescriptionCompletion.cs` (`ComposePendingSubjectsAhead`),
`src/WiseOwl.Cobol.Compiler/Binding/DataBinder.EntryOrder.cs` (`IsDescriptionOpen`, `HasSubordinatesBeingDescribed`),
`docs/DATA_MODEL_DESIGN.md` (whole: the constant-entry ordering paragraph).

- The subject is composed unless it is a group whose subordinate ENTRIES are still being described
  (`HasSubordinatesBeingDescribed`, the ancestor half of `IsDescriptionOpen`); measuring V itself or G stays SR4.
- Golden `conformance-suite/cases/13.10-Constant/pb2867_constant_length_composed_open_entry` (2002: TYPE, BYTE-LENGTH,
  SAME AS); negative `pb2867-constant-length-composed-cycle` (`LENGTH OF G`, SR4 through a TYPE clause).
