# PB5990 - at `--std 85` a debugging line in a unit compiled WITHOUT the debugging mode is never checked as source, though §1985:VI.7.3 requires a debugging line to be syntactically correct 'with or without' the mode

Campaign slice 85p-11: "with or without" binds both directions; a unit without WITH DEBUGGING MODE treats its D lines as
comments and never parses them, so a syntactically wrong debugging line compiles. PB5466 (in wave 20262116) adds the missing
test of the "without" direction; this note is the defect that test will find. No decision note records the omission (PB5212
left it open). Golden drafted in work/85p-11.

**Sites:** `src/WiseOwl.Cobol.Frontend/Preprocessor/` (whole: debugging-line handling without the mode; the fix names the member)
