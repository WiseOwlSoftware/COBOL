# PB5990 - at `--std 85` a debugging line in a unit compiled WITHOUT the debugging mode is never checked as source, though §1985:VI.7.3 requires a debugging line to be syntactically correct 'with or without' the mode

Campaign slice 85p-11: "with or without" binds both directions; a unit without WITH DEBUGGING MODE treats its D lines as
comments and never parses them, so a syntactically wrong debugging line compiles. PB5466 (in wave 20262116) adds the missing
test of the "without" direction; this note is the defect that test will find. No decision note records the omission (PB5212
left it open). Golden drafted in work/85p-11.

**Sites:**

- `src/WiseOwl.Cobol.Frontend/Parsing/DebuggingLineRewriter.cs` (`Rewrite` (`hiddenLines`), `Resolve`, `WithCarriersBlanked`)
- `src/WiseOwl.Cobol.Frontend/Pipeline/Frontend.cs` (`LexAndParseOnce`, `ReportDebuggingLinesBreakingTheProgramAsSource`)
- `src/WiseOwl.Cobol.Editions/Diagnostics/DiagnosticCatalog.cs` (`DebuggingLineSyntaxBothWays` COBOL7061)

**Fixed (after PB5466 landed the same direction; merged with it).** PB5466 landed the first reading of a unit's hidden debugging lines as
source (a token-copy re-parse, COBOL7061). That reading could not see what only the lexer and the token screens decide, nor a line inside
a PICTURE or subscript region, so this branch replaced it: at `--std 85` the hidden lines (`Rewrite`'s `hiddenLines`) have their carriers
blanked, the text is lexed and parsed again, and it runs the SAME screens source text gets (`ReportTokenScreens`, `ReportArithmeticOperatorScreen`,
which includes the PB5989 condition operators); a program that no longer parses, or a screen error ON a hidden line, is COBOL7061 at the
last hidden line before the first error. ONE code and one reporter (`ReportIfDebuggingLinesBreak`) for both directions; the branch's own
the COBOL7675 first written here was deleted. Goldens: PB5466's `pb5466-debugging-line-syntax-no-mode` and `...-parses-both-ways` (the branch's duplicates of them were
dropped) and this branch's `pb5990-*` cases for the separator, operator, unterminated-literal, misplaced-once and not-blamed shapes.
