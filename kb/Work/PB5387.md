# PB5387 - external file description entries that disagree in RECORD CONTAINS integer-1 compile and run, for sequential and report files alike, while the BLOCK CONTAINS and LABEL RECORDS siblings of the same rule are refused COBOL6847

**Sites:**

- `src/WiseOwl.Cobol.Compiler/Binding/ExternalFileConnectorRules.cs#Check` (compares the file descriptions of one external file connector across the run unit: BLOCK CONTAINS and LABEL RECORDS, not the RECORD clause)

**Mechanism.** `ExternalFileConnectorRules.Check` holds the 1985 run-unit consistency rules for an external file connector and refuses a BLOCK CONTAINS or LABEL RECORDS disagreement (COBOL6847). It has no arm for the RECORD clause, whose general rule makes the same demand.

**Inventory.** This rule is outside the 92 rules of the re-read; no row is claimed or recorded here.

**Rules (every citation checked with `scripts/spec/cite.py --check`).**

- `§1985:VII.3.8.4 GR2`: "If the associated file connector is an external file connector, all file description entries in the run unit which are associated with that file connector must specify the same values for integer-1".

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-reread2/refute-rr-03/ext_record.cob` (a report file) and `ext_record_seq.cob` (a sequential file): an outer and a contained program each describe the same EXTERNAL file, one with `RECORD CONTAINS 80` and one with `RECORD CONTAINS 90`; `cobol.exe --std 85 --source-format fixed --run <file>`.

**Observed (the pinned compiler of `E:/COBOL-wt/coderead85-tree-b` (origin/main 8147f008b3; `git diff --stat 8147f008b3 origin/main -- src` is empty at 5237495315), rerun 2026-11-12; `E:/COBOL-coord/scratch/coderead-85/reprobe-85f/log.txt`).** Both compile and print `OUTER OPEN`, `INNER DONE`, `OUTER CLOSED`.

**Expected (from the 1985 text).** Both refused, as the BLOCK CONTAINS (`ext_block.cob`) and LABEL RECORDS (`ext_label.cob`) disagreements are: both refused COBOL6847 on the same compiler (`E:/COBOL-coord/scratch/coderead-85/reprobe-85f/log3.txt`).

**Fix direction (root cause, CLAUDE.md rule 4).** Add the RECORD clause to the list of descriptions `Check` compares, and check whether the run-unit rules of the other organizations (relative, indexed) list it too.
