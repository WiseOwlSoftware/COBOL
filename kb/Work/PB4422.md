# PB4422 — commentary PB4420 made false

**Found:** by the round-1 review of the PB4420 branch (R1-1 LEAD, R1-2 LEAD, both low and not blocking). Both are one mechanism: prose that describes the pre-PB4420 fold. Text-only, but a comment must not state a rule the code no longer keeps; the filing clerk may not edit code or goldens, so this is a note.

**Sites:**
- `src/WiseOwl.Cobol.Frontend/Grammar/Core/CobolLexer.g4#ApplyEditionSpelling` (the comment above `_caseMappingEdition`, about lines 130-134, regenerated into `Generated/CobolLexer.cs`): says a COBOL 2002/2014 word is written with the E.2 item 14 letters, (0131,0069) and (03C2,03C3), already folded. After PB4420, `EditionSpelling` respells final sigma alone and leaves the dotless i as written (the `(0131,0069)` pair crosses letter classes and is in `NotApplied`).
- `tests/WiseOwl.Cobol.Tests.Unit/AnnexBCDriftTests.cs` (class doc, about line 24): "once the lexer has written E.2 item 14's two letters in their spelling", the same claim.
- Five PB4240 goldens in `conformance-suite/cases/8.1.3-COBOL-character-repertoire/`:
  - `pb4240-cobol-words-existing-word-spelled-with-dotted-capital-i.cob:11` ("It fails when the literal is read by the fold, which makes it DISPLAY");
  - the function-name golden (:13, "the function catalog is searched by the fold, which reads the word as INTEGER");
  - the context-word golden (:14, "that predicate compares by the fold, which reads the word as the clause");
  - the DEFINED golden (:13, "DEFINED is compared by the fold, which reads the condition as X IS DEFINED");
  - the directive-word golden (:12, the dotted-capital-I `>>IF` read as `>>IF`).

  After PB4420 no extended letter folds to a basic one at any edition, so none of these failure modes can occur. The expected outputs are unchanged; only the explanatory comments are. The sibling `pb4240-keyword-spelled-with-dotted-capital-i` was re-worded by the PB4420 implementer for exactly this reason and these five were left.

**Fix direction.** Reword the two code comments to say that only final sigma is respelled and the dotless i is left as written; reword the five golden headers to state what each now pins (a keyword is matched on basic letters alone, so the extended spelling is a user word). Regenerate the lexer if the .g4 comment is carried into `Generated/`. Sweep `*.g4`, `AnnexBCDriftTests`, `CobolNames*.cs`, DESIGN-frontend-grammar 3.13 and the `8.1.3-*` goldens for other "E.2 item 14" prose.
