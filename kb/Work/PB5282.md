# PB5282 - an INITIAL input-output CD in a CALLed program receives the scheduling terminal and its first RECEIVE takes the scheduling message: InitialArea fills every program's INITIAL CD, where 1985 gives it only to the program the MCS scheduled

**Sites:**

- `src/WiseOwl.Cobol.Compiler/CodeGen/Verbs/CommunicationEmitter.cs` (`EmitActivation`)
- `src/WiseOwl.Cobol.Runtime/Communication/MessageControlSession.cs` (`InitialArea`)
- Landing: `src/WiseOwl.Cobol.Runtime/Communication/MessageControl.cs` (`InitialArea`), `src/WiseOwl.Cobol.Runtime/Control/ModuleStack.cs` (`RunningIsMain`); witnesses `tests/WiseOwl.Cobol.Tests.Conformance/ScheduledProgramTests.cs` and `MessageControlTests.InitialArea_OfAProgramTheMcsDidNotSchedule_IsSpaces_AndTakesNoTerminalLock`.

**Mechanism.** §1985:XIV.2.2.4 GR28 puts the scheduling terminal's name in data-name-3 of the INITIAL input-output CD of the program the MCS schedules, the program that "establishes a run unit"; "In all other cases" it is initialized to spaces. A CALLed program is not scheduled. `EmitActivation` calls `InitialArea` for every instance of every program with an INITIAL CD, and `InitialArea` fills it from WISEOWL_COBOL_MCS_SCHEDULED, so a called program's INITIAL CD gets the terminal and its RECEIVE takes the message the main program's first RECEIVE is owed (GR25).

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so `inventory_rows` is empty and the rows this note claims are the rule ids below. None of them is recorded: the non-conforming verdicts wait in `E:/COBOL-coord/scratch/coderead-85/p2-for-register.json`.

**Rules (1 claimed; every citation checked with `scripts/spec/cite.py --check`).**

- `1985-GR-XIV.2.2.4-28` - `§1985:XIV.2.2.4 GR28` (refuter: OVERTURNED to DIVERGES, harm: wrong-answer): "In all other cases"

**Repro.** `E:/COBOL-coord/scratch/coderead-85/out-pipe/refute-slice-59/g28d/p.cob` with its mcs.json (T1 holds HELLO): main program G28D has an INITIAL I-O CD and calls SUB28D, which has its own; `WISEOWL_COBOL_MCS_SCHEDULED=T1 cobol.exe --std 85 --source-format fixed --run p.cob`.

**Observed (a build of origin/main f2cf36fd15, rerun 2026-11-11; main has since changed only `IndexedConnector.cs` under `src/`, which none of these repros reaches).** `MAIN TERM [T1          ]`, `SUB TERM [T1          ]`. (The refuter's `g28e` shows the sub's RECEIVE taking HELLO and the main program's first RECEIVE then finding no data.)

**Expected (from the 1985 text).** `SUB TERM` is spaces, and only the main program's first RECEIVE returns the scheduling message.

**Fix direction (root cause, CLAUDE.md rule 4).** Fill the INITIAL CD only for the run unit's first program (the runtime knows which instance established the run unit); test a called program with its own INITIAL CD.
