# PB4765 - unprobed tree-shape function-identifier reads

**What the report says (unprobed).** `MoveBinder.cs:624` (`senderIsFunction`), `ConditionBinder.cs:965`, `OoBinder.cs:1370` and
`RelationComparability.cs:119` read `{ Expr: BoundIntrinsicCall }` as a function-identifier. PB4712 found that the binder drops a
parenthesis, so a tree-shape read cannot tell a function-identifier from a parenthesized function. The report did not probe these
four sites; each needs a probe before it is called a defect or cleared.

**R1.** No open note covers it. PB4712 (landed) replaced the tree-shape read at its four sites.

**Sites:** `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/MoveBinder.cs:624` (`senderIsFunction`), `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/ConditionBinder.cs:965`, `src/WiseOwl.Cobol.Compiler/Binding/Procedure/Verbs/OoBinder.cs:1370`, `src/WiseOwl.Cobol.Compiler/Binding/RelationComparability.cs:119`.

**Audit 2026-11-07** (the operator's audit of the 37 open analyses that set no harm flag (kb/Work PB4949; four read-only adjudicators, evidence in E:/COBOL-coord/scratch/analyses-audit/)). HIDDEN DEFECT, under-rejects, probed: `IF IX = (FUNCTION ABS (N))` compiles while `IF IX = (N)` is refused with COBOL2533 (RelationComparability.cs:119; §2023:8.8.4.2.13 GR2).
