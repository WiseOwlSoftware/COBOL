# PB5731 - at --std 85 a format 3 file (RECORD CONTAINS integer-4 TO integer-5) whose record holds an OCCURS DEPENDING ON table is sized with the table at its MINIMUM occurrences, where §1985:VII.3.8.4 GR15 sizes it at the maximum: a SORT GIVING file's size check under-rejects and an SD's size and key-position checks refuse legal source

**Sites:**
- `src/WiseOwl.Cobol.Compiler/Binding/FileControlBinder.FileSection.cs#BindRecordClause` (sets `VaryingRecordInfo.BoundsEnforced` false for a format 3 clause below 2002)
- `src/WiseOwl.Cobol.Compiler/Binding/Model/FileModel.cs#VaryMin` (falls to `Records.Min(MinRecordSize)`, the table at its minimum occurrences, when the bounds are not enforced)

**Mechanism.** Below 2002 `BindRecordClause` records a format 3 clause with `BoundsEnforced: false` (kb/Work PB5197: at 85 the
integers only document the sizes, §1985:VII.3.8.4 GR14). `FileModel.VaryMin` then answers the record descriptions' own minimum,
and that minimum counts an OCCURS DEPENDING ON table at its minimum occurrences, which is the Format 2 summation (GR5a). Format 3's
own size rule (GR15) sums every variable length item at its MAXIMUM. Every consumer of `VaryMin` / `MinRecordSize` for a format 3
file at 85 inherits it: the SORT and MERGE GIVING size check (§1985:XI.4.4.3 SR10), the SD key-position check (SR4f), and the record
size checks of WRITE and RELEASE are the sweep.

**Inventory.** `work.py check` refuses a 1985 rule id in `inventory_rows` (kb/Work PB5094, open), so the rows this note claims
are named here: `1985-SR-XI.4.4.3-10` and `1985-SR-XI.4.4.3-4`, both stored as KEPT lineage records into `SR-14.9.40.3-11` and
`SR-14.9.40.3-6`, whose 2023 verdicts stay right (at `--std 2023` the integers bound the record, and every probe below is right
there). A KEPT row holds no verdict of its own (`lineage.next_errors`), so the tools give these rows no non-conforming record
until the lineage switch (kb/Work PB5682) or a CHANGED re-record; see the registrar landing's DEVLOG entry.

**Rules (each citation checked with `python scripts/spec/cite.py --check`, verdict OK).**
- `§1985:VII.3.8.4 GR15`: "the sum of the maximum number of characters in any variable length item subordinate to the record"
- `§1985:VII.3.8.4 GR14`: "the size of each data record is completely defined in the record description entry"
- `§1985:VII.3.8.4 GR5a` (Format 2's rule, not format 3's): "The minimum number of table elements described in the record is used in the summation"
- `§1985:VII.3.8.4 GR13`: "It is implementor defined whether format 3 of the RECORD clause produces fixed length records or variable length records" (this compiler treats them as variable at 85, as its messages below say)
- `§1985:XI.4.4.3 SR10`: "must not be less than the smallest record nor larger than the largest record described for file-name-3"
- `§1985:XI.4.4.3 SR4f`: "where x equals the minimum record size specified for the file referenced by file-name-1"
