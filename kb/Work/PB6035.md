# PB6035 - the canonicalizer is not safe for C# message text

**What happened.** The controller asked for `audit_code_citations.py --canonicalize src/ tests/` (the C# part of
PB4976/PB6000, after groups s and q). On train-1985-c it rewrote 3,749 lines. The audit then read `0 finding(s)`, but gate
000003 was RED on 61 cases: 57 conformance goldens and unit expectations still held the old message text, and three
classes of rewrite had damaged the messages themselves:

1. **A sub-item path written without a space.** `SPACED_PATH` (`scripts/spec/citation.py`) requires a space before the
   numbered level, so `§2023:14.9.39.3 SR12 a)2.` is glued as `SR12a` and the trailing `2.` is left attached:
   `SR12a2.`. cite.py refuses that form (`'SR12a2.' is not a rule designator ... GR6d.2`), and the audit does not catch
   it. Group s's own run over docs/ and the goldens had already left 31 such sites (for example `GR22d2.a.`, `GR6d4.a`,
   `GR3n1.a`), and this train's run added 36 more. Measured: `git grep -cE '(SR|GR|AR|RV)[0-9]+[a-z][0-9]+\.'` gave 6 on
   main 26e6da8f73 (all pre-existing hand spellings), 37 before this train's canonicalization, and 73 after it.
2. **A label ')' that also closes the message's own parenthesis.** `"... (ISO §2023:14.9.40.3 SR14 e)"` became
   `"... (ISO §2023:14.9.40.3 SR14e"`, so the emitted message lost its closing parenthesis (COBOL1757's text, seen in
   pb1173-sort-table-key-inner-occurs). A scan of the rewrite for lines whose count of unmatched '(' grew found such
   losses in non-comment `src/` lines, for example `PictureAnalyzer.cs` "(ISO §2023:13.18.40.3 SR12b" and
   `ReservedWords.cs` "(ISO §2023:8.3.2.1 SR1". The same scan also hits multi-line strings, so it is a lead, not a
   proof.
3. **A label after an interpolation hole.** `$"(ISO §2023:9.3.8.2.3 rule 9 {arm}))"` became `GR9 {arm}))`, which
   prints `GR9 a))` at run time. That form is neither the old one nor canonical.

**What the train did.** The canonicalization commit 4df4484256 was reverted (`git revert -n`, keeping this train's
citation repairs on the lines it had touched) and the shrink-only baseline was regrown to 6,029 entries. That is the
debt that stood before the train, plus the seven list-item lines of PB6015. Group z's four intrinsic files were restored
to z's own text. The construct rows' citations (`tests/version-matrix/constructs/*.json`, see the PB4976 addendum) stay
canonical, because the audit's suggested forms there were exact.

**The fix owed.** (a) `SPACED_PATH` reads a path written with or without the space (`a)2.`, `d)2.b.`). (b) The rewrite
keeps a `)` when the label's `)` was also the closer of an open `(` before the citation on the same logical string
(count the unmatched opens before the citation). (c) The rewrite refuses, rather than rewrites, a designator followed by
an interpolation hole or string concatenation. (d) The audit refuses the glued-number form `SR12a2.`. (e) A run over
`src/` rewrites the goldens and expectations that quote each changed message in the same operation (the
conformance-suite diagnostics JSON, `EditionHarness.AssertHasDiagnostic` strings), or it stays limited to comments.
Then the 31 glued sites in docs/ and the goldens are repaired and the C# part is run again. Each step needs a self-test
that plants the three shapes.
