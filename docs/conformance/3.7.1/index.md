---
heading: "### 3.7.1 Three other COBOL-85 implementor choices (kb/Work PB4996)"
---
| Item | Determination |
|---|---|
| The ENTER statement (§1985:VI.6.12.3 SR1, "Language-name-1 is specified by the implementor"; §1985:C.2 item 38) | Not provided: an implementation "may include the ENTER statement or not, at the option of the implementor" (§1985:I.1.5.2.5.5), the 2023 text has no ENTER to decide it, and GnuCOBOL refuses the statement (CLAUDE.md rule 1), so no language-name is specified and no other-language text is ever compiled in-line. The compiler does not yet refuse ENTER: it compiles it to nothing (kb/Work PB5308) |
| A group item where a 1985 rule requires usage DISPLAY (reference modification, STRING, UNSTRING, INSPECT) | A group item is usage DISPLAY for those rules. The class of a group item is "treated at object time as alphanumeric regardless of the class of elementary items subordinate to that group item" (§1985:IV.4.3.3), and the later editions state the usage outright (§2023:8.5.2.1: "An alphanumeric group item is treated as though it had a usage of display") |
| An external file connector's entries that omit RESERVE, or RECORD DELIMITER, beside one that writes its default | They agree: the entries are compared on what they specify for the connector, so an omitted RESERVE clause is the implementor's one area (§1985:VII.2.9.3 GR1; A.1 item 164) and equals RESERVE 1 AREA, and an omitted RECORD DELIMITER clause is the implementor's method (§1985:VII.2.8.4 GR4; A.1 item 151). The compiler compares the effective values, at compile time and at run time (`FileEntryIdentity.Segments`, kb/Work PB5311); RESERVE 3 AREAS against an omitted clause stays a disagreement |
