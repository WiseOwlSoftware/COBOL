- **D-MEDIUM-85 — the storage medium of a file at COBOL-85** (kb/Work PB5779; the text admits both classifications, so the choice is the implementor's). Every physical file WiseOwl COBOL supports at `--std 85` is on a non-reel/unit medium: one host path, with no reel, unit or volume behind it (`PhysicalFileCategory` on `FileConnector`; A.1 item 24 states the same placement for COBOL-2023).
  §1985:VII.4.2.4 GR2a defines that category by the medium: "A file whose input or output medium is such that the concepts of rewind and reels/units have no meaning".
  §1985:B.2.2 (substantive change 40c) says what the status is for: "with mass storage files, these instances of OPEN and CLOSE can be considered successful in essence, if the anomaly of the NO REWIND, REEL/UNIT, or FOR REMOVAL phrase is overlooked".
  So an OPEN or a CLOSE with NO REWIND, and a CLOSE with REEL, UNIT or FOR REMOVAL, completes with I-O status 07, which §1985:VII.1.3.5 gives when "the referenced file is on a non-reel/unit medium". A CLOSE with REEL or UNIT leaves the file open. The rules stated for a medium that permits rewinding do not apply, and the NO REWIND phrase is otherwise ignored, as §1985:XIII.4.5.4 GR8 says: "The NO REWIND phrase will be ignored if it does not apply to the storage medium on which the file resides".
  The sentence that opens the CLOSE rules is §1985:VII.4.2.4: "Treatment of sequential mass storage files is logically equivalent to the treatment of a file on tape or analogous sequential media". It is read as the treatment of a mass storage file an implementor has divided into units, and WiseOwl COBOL divides none. An adjudicator read it the other way and two refuters before it; a third refuter, given both, found that the 1985 text admits both classifications (kb/Work PB5779). By the precedence of CLAUDE.md rule 1 GnuCOBOL then decides: its `libcob/fileio.c` (3.3-dev; the source was read, the compiler was not run) returns 07 from the close of a sequential disk file for CLOSE WITH NO REWIND and for CLOSE with REEL or UNIT, the two places it sets the status; what it does for OPEN WITH NO REWIND was not read.
  The same determination covers row `1985-GR-VII.4.4.4-9`: the end-of-reel condition it governs arises only with a multi-reel file, which no file at `--std 85` is, so a READ meets one end of file (status 10) (kb/Work PB5164, ruled 2026-11-20).
