- **D-DEBUG-SWITCH-85 — the object time switch of the COBOL-85 debug facility** (kb/Work PB5765, PB4997; the standard leaves the switch outside the program).
  §1985:XV.1.3.4 says of the switch: "This switch cannot be addressed in the program; it is controlled outside the COBOL environment", and "Recompilation of the source program is not required to provide or take away this facility".
  WiseOwl COBOL's switch is `RunUnit.DebugMode`: host configuration that no COBOL statement can set. A host that embeds the runtime sets it; otherwise the environment variable `WISEOWL_COBOL_DEBUG` sets it when the run unit first reads it: `OFF` takes the facility away and `ON`, empty or unset gives it (compared without regard to case), and any other value stops the run with a message naming the variable. So a program compiled WITH DEBUGGING MODE and run as `cobol` built it executes its debugging sections, the same program run with `WISEOWL_COBOL_DEBUG=OFF` executes none of them and does its own work unchanged, and a program compiled without the mode has none to execute (D-DEBUG). Witnesses: `conformance:cases/VI.6.24@1985-STOP-STATEMENT/g85_z07`, whose debugging section runs for an OPEN and for an explicit CLOSE, and `DebugSwitchTests`, which runs one compiled program with the switch unset, on, off and unreadable.
