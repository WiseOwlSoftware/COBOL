OPEN OUTPUT, OPEN I-O and OPEN EXTEND establish **SHARING WITH NO OTHER**. Both are the standard's own modes, so §2023:9.1.15's rules and Table 19 apply to them unchanged. Clause-less readers can share a file. A clause-less updater or writer has the file to itself: its OPEN is refused with '61' while any other connector has the file open, and while it is open every other connector's OPEN is refused with '61'. A clause-less OPEN INPUT is refused with '61' while another connector has the file open in a mode other than input. The same default applies to a file control entry that has a LOCK MODE clause but no SHARING clause, and to an OPEN whose only sharing-related phrase is RETRY. Record locking for such a connector is item 153. Example (three clause-less SELECTs on one file): A OPEN INPUT '00', B OPEN INPUT '00', C OPEN I-O '61', C OPEN EXTEND '61', C OPEN OUTPUT '61'.
