Selecting the same locale is not having the same external identification: where a PICTURE clause identity is compared (the type-equivalence and parameter / returning-item conformance rules, which define the identification as \"the external-locale-name or literal value\" itself) the identification is compared as written, a literal value character for character (kb/Work PB1166).
