The STATUS operand becomes the process exit code**, with the same mapping as STOP (A.1 item 192, §3 'STOP RUN / GOBACK termination status'). The syntax rules still apply: identifier-2 must be an integer data item or a data item of usage display or national (§2023:14.9.18.3 SR6), and a numeric literal-1 must be an integer (SR7). The mapping is: **(1)** a numeric operand's integer value is the exit code (a data item's value truncated toward zero); **(2)** a non-numeric operand (an alphanumeric or national item, a non-numeric literal, a figurative constant) is decoded as an unsigned integer from its digit characters, and a position that is not a digit adds no digit, so `STATUS \"007\"` exits 7, `STATUS \"A1B2\"` exits 12 and `STATUS \"ABEND\"` or `STATUS SPACE` exits 0 (`CobolNum.FromAlphanumeric`); **(3)** the host then keeps what it can report: the value is clamped (never wrapped) to the 32-bit range, so `STATUS 4294967296` exits 2,147,483,647 (kb/Work PB1178), and a POSIX host keeps only the low 8 bits, so `STATUS 300` exits 44 and `STATUS -3` exits 253. With no STATUS value, `GOBACK WITH ERROR` exits 1 and `WITH NORMAL` (or no phrase) exits 0; a STATUS value, when present, wins over ERROR or NORMAL. The value reaches the operating system only when the GOBACK ends the run unit, that is, in a main program (§2023:14.9.18.4 GR3); in a called program the GOBACK returns to its caller and the status is not used. The phrase is COBOL-2023 only: at `--std 2014` and below it is refused with COBOL0900.
