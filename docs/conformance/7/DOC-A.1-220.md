A dynamic-capacity table (`OCCURS DYNAMIC`, `CobolDynTable`) holds its occurrences in a managed array that grows by doubling and is NEVER shrunk: lowering the capacity (`SET … TO`, `DOWN BY`) only lowers the current count, keeping the removed occurrences' storage until the table is enlarged again — when each re-created occurrence is created afresh as a new occurrence, never with the value it held before — or until the table itself becomes unreachable.
