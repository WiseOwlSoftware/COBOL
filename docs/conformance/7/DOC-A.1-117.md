At `--std 85` the absence of a listing is a **known nonconformance, not a documented choice**: §1985:IV.7.1 requires each compiler to produce an output listing, so \"in any edition\" describes what the compiler does, and only for 2002, 2014 and 2023 is it conforming (kb/Work PB5923; it holds until the listing lands).", "`conformance:cases/7.3.18-LISTING/pb725_directive_facility`"]
