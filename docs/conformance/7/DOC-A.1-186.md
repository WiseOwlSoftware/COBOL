(§2023:12.3.7.4), required + documented (the scheme, not each character)", "**The ordinal number of every character is its position in the alphabet's collating sequence, counting the first position as 1, and the unspecified characters are numbered in the order GR7 k) 3. collates them.** A literal-phrase alphabet's coded character set contains every native character — 65,536 UTF-16 code units, for an alphanumeric and a national alphabet alike (`CodedCharacterSet.OrdinalCount`). The characters the literal phrase specifies take ordinals 1 through *n*, one per collating position in the order written (a THROUGH range fills successive positions; an ALSO group shares one position, and that ordinal names ALL the group's characters — literal-1 first — per GR7 k) 6.). Which of them a reference uses depends on what it needs: a reference that needs ONE character takes literal-1 alone (`SYMBOLIC CHARACTERS … IN`, GR7 k) 6.'s last sentence: \"only literal-1 is used to represent the character in the native character set\"), a reference that names a SET takes them all (a numeric `CLASS … IN` literal, GR12 a, so `CLASS C1 IS 1 IN AL` over `ALPHABET AL IS \"B\" ALSO \"A\" ALSO \"Z\"` is {B, A, Z} — the singular \"a character\" of GR12 a is read as the plural because the other reading would make k) 6.'s exception redundant; kb/Work PB1095). A group's ordinal is no single character to begin or end a THROUGH run, so `CLASS C IS 1 THRU 3 IN AL` over such an ordinal is refused (COBOL1671, §2023:12.3.7.4 GR12). The characters NOT specified then take ordinals *n*+1, *n*+2, … in ascending native code order, skipping the specified ones (`CodedCharacterSet.CharAt` for one character, `CodedCharacterSet.CharactersAt` for the set). Worked example: `ALPHABET AL IS \"Z\" \"Y\" ALSO \"W\" \"X\"` has *n* = 3, so ordinal 1 is `Z`, 2 is `Y`, 3 is `X`, 4 is U+0000, 5 is U+0001, and ordinal 70 is `B` (U+0042, the 67th unspecified character). These are the ordinals `SYMBOLIC CHARACTERS … IN alphabet-name` and a numeric `CLASS … IN alphabet-name` literal use. Because an ALSO character has no ordinal of its own, the highest ordinal is 65,536 minus the number of ALSO characters (in the example, ordinal 65,535 is U+FFFF and 65,536 is `COBOL1670`).
