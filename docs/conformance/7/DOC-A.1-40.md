cells: ["DOC-A.1-40", "**COPY statement — rules for identifying and locating default library text**, §2023:7.2.3.3 SR5 and §2023:7.2.3.4 GR3 (with GR2), required + documented", "**The default COBOL library is an ordered list of places, searched in GnuCOBOL's order** (CLAUDE.md rule 1: the standard leaves both the list and the search to the implementor): (1) the compiler process's current working directory — the name is first tried as a path relative to it, or as written when it is absolute; (2) each `--copy DIR` in command-line order; (3) with `--nist`, the `copylib` directory beside the source file's directory. The source file's own directory is searched only when it is one of these — as in GnuCOBOL 3.2, whose own testsuite carries \"COPY: relative copybooks\" (a COPY resolved against the including source's directory) as an expected failure, not implemented. The same list serves every COPY in the compilation group, including a COPY inside library text. **Locating a text:** text-name-1 is used as spelled; literal-1's content is a host path (SR5: any non-empty host path is an allowable literal-1 or literal-2) — its VALUE, so a doubled quotation symbol is one character and a hexadecimal-format `X\"…\"` names the characters its digit pairs encode; a national or boolean literal, a concatenation expression or a figurative constant is refused as COBOL2450 (SR4/SR5; kb/Work PB1354). The literal forms (literal-1, literal-2) are a COBOL-2002 introduction (constructs row `copy-literal-name-2002`, VCR row 7.44, edge derived; kb/Work PB1601): `--std 85` names a text only by a word and refuses a literal as COBOL0900. In each place in turn WiseOwl COBOL tries the name as spelled and then with the suffixes `.CPY`, `.CBL`, `.COB`, `.cpy`, `.cbl`, `.cob`, in that order (a name whose FILE NAME — the part after the last directory separator — already contains a period is tried only as spelled; `\"../lib/BOOK\"` still takes the suffixes), and the FIRST regular file that exists IS the library text; so a text-name names exactly one text in a library (SR3) and no ambiguity is diagnosed. If `BK3.cbl` and `BK3.cob` sit in one directory, `COPY BK3` is `BK3.cbl`. Whether letter case in the name matters is the host file system's rule; the text found is named, in every diagnostic, the line map and the dependency record, by its directory entry's own spelling and never by the spelling that was probed (on a case-insensitive file system the probe `BOOK.CPY` finds `book.cpy` and the text is `book.cpy`; `CompilationInputs.LocateFile`, kb/Work PB1680). **OF/IN library-name-1 or literal-2** names a subdirectory: the FIRST place (in the same order) that holds a subdirectory of that name IS the library, and the text is located in it alone, with the same suffix rule. **A library that no place holds, or a text the library does not contain, is the compile-time error CBL3620** (GR2: the library shall be available): compilation fails, and there is no fallback from a named library to the default one and no silent omission of the COPY (GnuCOBOL's fallback to the default library, with a warning, is not followed: GR2 controls). The same at every edition. One mechanism implements all of it: `CopyProcessor.FindCopybook` over `LibraryPlaces` (the working directory, then the configured search paths) and `LocateInLibrary` (the name as spelled, then `CopybookSuffixes`); CBL3620 is reported by `CopyProcessor.ResolveOneCopy` on every path (kb/Work PB1355). The test harnesses name a golden's directory as a `--copy` path, as a user does, and the GnuCOBOL differential compiles each case as GnuCOBOL's testsuite runs `cobc`: in the case's directory, with its files at their own relative paths and each `-I DIR` passed as `--copy DIR`.", "`conformance:wiseowl/cases/7.2.3-COPY/pb1355_library_text_located`; `conformance:cases/7.2.3-COPY/pb1355-library-text-not-found`; `conformance:cases/7.2.3-COPY/pb1355-library-not-available`; `unit:TextManipulationStatementTests.LibraryText_APeriodInADirectoryPart_IsNotAnExtension`; `conformance-test:DiagnosticPositionTests.Copy_MainLinesStayMain_CopiedLinesNameTheCopybook`"]
