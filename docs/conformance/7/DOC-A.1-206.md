The signed exclusion of `-2**(w-1)` is deliberate — it lets a sign-magnitude or ones'-complement machine conform — and §2023:15.58.4's NOTE concedes it in terms: “BINARY-CHAR SIGNED | -128 (assuming an 8-bit twos-complement representation)”. WiseOwl COBOL provides the full NATIVE TWO'S-COMPLEMENT band of each usage's byte width: **BINARY-CHAR** SIGNED -128..+127, UNSIGNED 0..255; **BINARY-SHORT** SIGNED -32768..+32767, UNSIGNED 0..65535; **BINARY-LONG** SIGNED -2147483648..+2147483647, UNSIGNED 0..4294967295; **BINARY-DOUBLE** SIGNED -9223372036854775808..+9223372036854775807, UNSIGNED 0..18446744073709551615. Each SIGNED usage therefore expresses exactly ONE value beyond the GR12 minimum — `-2**(w-1)` — and the four UNSIGNED usages are exactly the minimum. A value outside the band raises the size-error condition (§2023:14.7.5), never a silent widening; GR12's nesting sentence still holds at the wider end, LOWEST-ALGEBRAIC of each narrower signed usage being expressible in the next. The band is written down ONCE — the byte width per usage (1/2/4/8) in `PicInfo.StorageWidth` under the `BinaryCapacity` discipline (`PicInfo.Truncation`) — and read by the runtime store bound (`CobolNum.InBinaryRange` / `CobolNum.TryStoreU`) and by the compile-time HIGHEST/LOWEST-ALGEBRAIC fold (`IntrinsicBinder.BindAlgebraicFold`), which `AlgebraicFoldContainerAgreementTests` holds in agreement. **A numeric `VALUE` literal outside the band is refused at compile time (COBOL1625; §2023:13.18.63.3 SR2, \"permissible values within the range indicated by the PICTURE clause or the USAGE clause\")** on every `VALUE` form — the item's own, a level-88 value, either end of a `THRU` range, the `WHEN SET TO FALSE` value, a format-2 table occurrence — because `DataBinder.ValidateNumericValue` asks `AlgebraicRanges.Admits` of the same `AlgebraicRanges.Of` band (kb/Work PB3997; witnesses `conformance:cases/13.18.63-VALUE/pb3997_value_binary_usage_band_edges_2002` and the refusals `pb3997-value-binary-usage-above-band`, `pb3997-value-binary-usage-condition-above-band`).
