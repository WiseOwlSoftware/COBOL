cells: ["DOC-A.1-79", "**FLAG-02 directive — the warning mechanism**, §2023:7.3.14 GR1 (§2023:7.3.14.4 GR1), required + documented", "**A compile-time warning, COBOL1620, for each flagged construct. The warning does not change the compiled program.** `>>FLAG-02` names ALL, or one or more of its five options (EC-PROGRAM-EXCEPTIONS, I-O-STATUS-07, MOVE-TO-SAME-NAME, RANGE-EXCEPTION-FOR-INDEX, TERMINATE-WITH-VARYING) in any order, followed by ON or OFF. Both pairs of braces carry a default, because the printed format leaves ALL and ON un-underlined (optional words, §2023:5.2.3; the default alternative, §2023:5.2.6.3): with no option named ALL applies, and with neither ON nor OFF written ON applies, so `>>FLAG-02`, `>>FLAG-02 ON` and `>>FLAG-02 OFF` are legal. An option is on from the line after the directive until a later FLAG-02 turns it off, or turns ALL off, or the compilation group ends. Every option is off by default. While an option is on, each construct §2023:7.3.14.4 GR4 describes for it is reported as `warning COBOL1620: <the construct> (<the 2002-to-2014 change>) — flagged by >>FLAG-02 <option>` at the construct's line and column. For example, with I-O-STATUS-07 on, each `CLOSE ... WITH NO REWIND` or `UNIT` is reported. An option word that is not one of the five, or ALL combined with named options, or an option word or ALL written twice (§2023:5.2.6.4), or an ON or OFF that is not the last word, is refused with COBOL1622. The directive is a COBOL-2014 element: at `--std 2002` and below it is refused with COBOL0900, and at `--std 2023` it still works but draws the obsolete-element warning COBOL0903 (§2023:7.3.14.1 NOTE). MOVE-TO-SAME-NAME and RANGE-EXCEPTION-FOR-INDEX resolve a method body's operands in the method's own name scope over its class half's data (kb/Work PB1952), so both flag inside a method as they do in a program. EC-PROGRAM-EXCEPTIONS flags each qualifying `>>TURN` at its own line when the SOURCE ELEMENT it belongs to (§2023:3.164: a program, a function, a contained program, a class, an interface or a method, excluding what it contains) calls a function (including a function-identifier written without the word FUNCTION, and one inside a subscript) or invokes a method (INVOKE, an inline method invocation, an object-property reference); a `>>TURN` written before an element's IDENTIFICATION DIVISION belongs to the element that follows it, and a CALL of a program is not a trigger. MOVE-TO-SAME-NAME treats a reference-modified operand as category alphanumeric (§2023:8.4.3.3.4 GR6 a), so only the subordinate OCCURS DEPENDING arm flags it. TERMINATE-WITH-VARYING reads a VARYING clause on any report group description entry.
