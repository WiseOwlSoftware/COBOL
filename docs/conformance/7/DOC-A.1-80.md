The warning does not change the compiled program.** `>>FLAG-14` names ALL, or one or more of its twelve options (COMPILE-TIME-ARITHMETIC-EXPRESSIONS, EVALUATE, I-O-DECLARATIVE, I-O-STATUS-04, I-O-STATUS-07, NUM-ED-ZERO-FIGCONST, READ-PREVIOUS, REF-MOD-ZERO-LENGTH, VALUE-EDITING, VALUE-FIG-CON-LENGTH, VALUE-ZERO, WRITE-END-OF-PAGE) in any order, followed by ON or OFF. Both pairs of braces carry a default, because the printed format leaves ALL and ON un-underlined (optional words, §2023:5.2.3; the default alternative, §2023:5.2.6.3): with no option named ALL applies, and with neither ON nor OFF written ON applies, so `>>FLAG-14 VALUE-ZERO`, `>>FLAG-14 ALL`, `>>FLAG-14 ON`, `>>FLAG-14 OFF` and a bare `>>FLAG-14` are legal. An option is on from the line after the directive until a later FLAG-14 turns it off, or turns ALL off, or the compilation group ends. Every option is off by default. While an option is on, each construct §2023:7.3.15.4 GR4 describes for it is reported as `warning COBOL1621: <the construct> (<the 2014-to-2023 change>) — flagged by >>FLAG-14 <option>` at the construct's line and column. For example, `>>FLAG-14 READ-PREVIOUS I-O-STATUS-04 ON` reports each READ PREVIOUS statement and each reference that tests a FILE STATUS item for '04', and `>>FLAG-14 VALUE-ZERO ON` reports a numeric-edited item whose VALUE is ZERO. An option word that is not one of the twelve, or ALL combined with named options, or an option word or ALL written twice (§2023:5.2.6.4), or an ON or OFF that is not the last word, is refused with COBOL1622. The directive is COBOL-2023 only: at `--std 2014` and below it is refused with COBOL0900. Known defect in the open notes, not part of this determination: an OO method body's operands are not name-resolved (an advisory false negative). Each option flags its GR4 population: COMPILE-TIME-ARITHMETIC-EXPRESSIONS flags an expression with an arithmetic operator in a DEFINE, EVALUATE or DISPLAY directive, a constant conditional expression and a CONSTANT entry; I-O-DECLARATIVE flags a statement that can take an INVALID KEY phrase (not a REWRITE of a relative file in sequential access, §2023:14.9.35.3 SR2, nor a DELETE RECORD of a file in sequential access, §2023:14.9.10.3 SR2); I-O-STATUS-04 and I-O-STATUS-07 flag a relation, an abbreviated combined relation, a level-88 condition-name and an EVALUATE selection subject/object pair that tests the FILE STATUS item; NUM-ED-ZERO-FIGCONST, VALUE-EDITING and VALUE-ZERO treat a numeric item with BLANK WHEN ZERO as numeric-edited (§2023:13.18.8.4 GR2); WRITE-END-OF-PAGE flags a WRITE that does not specify the AT END-OF-PAGE phrase, one with only NOT AT END-OF-PAGE included (§2023:14.9.51.3 SR19).
