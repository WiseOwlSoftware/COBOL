Every other character position must be a plain digit.** Under the default `ibm` the sign position admits `0`–`9`, `{`, `A`–`I`, `}`, `J`–`R`; under `ascii` it admits `0`–`9` and `p`–`y`. Any other character there makes the item **NOT NUMERIC**. GR5 b) — “The implementor defines what constitutes valid signs for data items” — is the whole of the latitude, and §2023:8.8.4.4.4 GR3 n)1.a delegates the NUMERIC class condition to it by name (“Valid operational signs are defined in 13.18.52, SIGN clause”). **A PLAIN DIGIT IS VALID, and means POSITIVE**: an unseparated sign shares a digit position, so an item whose sign was never punched — what a group MOVE of raw characters deposits, and what the `ascii` convention writes for every positive value — is well formed. **A punched character carries a DIGIT as well as a sign**, so the valid set also fixes the VALUE: under `ibm`, `12C` is +123, `12L` is −123, `12{` is +120 and `12}` is −120, and at the LEADING position `C23` is +**3**23 (the punch contributes digit 3, exactly as it does at the trailing position of `12C`) — a sign-only reading would answer +123 and be wrong. The refused near-misses are worth naming: `+` and `-` are §2023:13.18.52.4 GR6 b)'s SEPARATE characters and are NOT valid here, and neither are a space, a lower-case `l`, or a letter past the end of the run such as `Z`. **The set is DERIVED from the same `ZonedSign` tables the encoder punches with** — `ZonedSign.IsSignCharacter`, reached from `CobolClass.IsNumericZoned` (the class condition, emitted by `ConditionRenderer.RenderClass`) and from `CobolNum.IsNumericImage` (§2023:14.6.13.2 rule 2's checked sending read, which the standard defines BY REFERENCE to the class condition) — never written a second time; it previously stood as a literal character-range pattern beside the tables and could only ever have answered for one convention. **GR5 a) is documented with it because it is NOT latitude:** the sign is *presumed to be associated with* a DIGIT position, so `PIC S9(3) SIGN IS LEADING` and `PIC S9(3) SIGN IS TRAILING` are each **3** character positions, never 4.
