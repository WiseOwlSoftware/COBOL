A sort-merge file entry has no FILE STATUS clause (§2023:12.4.5.1 Format 4), so the failure has no I-O status to carry; the statement's effect is the observation. **Content that is empty after the space removal, or that carries a character below U+0020, names no physical file**: the association cannot be made, so the statement is unsuccessful with §2023:9.1.13.6 item 2's '31' — the status the standard reserves for exactly this failure.
