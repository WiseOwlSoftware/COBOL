For a name written as a COBOL word with no AS phrase (a program-name, a user-function-name, a class-name, an interface-name, an EXTERNAL data-name or file-name) it is the word's spelling. For a name given by an `AS literal` it is the literal's content with **leading and trailing spaces removed**; spaces inside the name are kept. A CALL, CANCEL, `ADDRESS OF PROGRAM` or `ADDRESS OF FUNCTION` target and an INVOKE method name are formed the same way: a literal's content, or an identifier's content, with leading and trailing spaces removed. A name WRITTEN in source text as a literal (an AS literal, a CALL, CANCEL or `ADDRESS OF` literal, an INVOKE method-name literal) is also written in the edition's Annex C spelling (`ExternalizedNames.FormInEdition`, kb/Work PB2840), as the word it names was lexed: below 2023 `CALL \"Z<final sigma>\"` reaches `PROGRAM-ID. Z<sigma>` and `INVOKE O \"X<final sigma>\"` names `METHOD-ID. X<sigma>`, because Annex E.2 item 14 deleted the mappings of final sigma and dotless i at 2023 only; at 2023 they are two names. An identifier's content (a CALL, CANCEL, `SET program-pointer TO ENTRY` or `ADDRESS OF` target, a universal INVOKE's method name) is formed by the same function, which the emitted C# calls with the compiled program's edition (kb/Work PB2991), so `CALL WS-NAME` holding `Z<final sigma>` reaches `PROGRAM-ID. Z<sigma>` below 2023 exactly as the literal does; the run time itself compares every name by the 2023 table. One function forms and maps every one of these names, at bind time and at run time alike (`WiseOwl.Cobol.Runtime.ExternalizedNames`). An AS literal made only of spaces forms the zero-length name, which nothing can name, so it is refused (COBOL2643) wherever the clause itself refuses a zero-length literal: every AS clause except CLASS-ID, whose §2023:11.3.3 SR1 admits one. ISO leaves formation to the implementor (§2023:8.3.2.2). GnuCOBOL removes leading and trailing spaces, with a warning, from a CALL or CANCEL literal and from a literal program-name, but keeps an AS literal as written, so a GnuCOBOL program named `AS \"trail  \"` cannot be called. SUB-P`, and `EXTERNAL AS \"Shared Two\"` and `EXTERNAL AS \"shared two\"` are one data item.
