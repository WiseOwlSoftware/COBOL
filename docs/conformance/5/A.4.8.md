cells: ["A.4.8", "FORMAT and SELECT WHEN file handling", "**Claimed**", "(kb/Work PB5578.) ISO/IEC 1989:2002 requires the FORMAT clause (§2002:13.16.22) and the SELECT WHEN clause (§2002:13.16.49) — §2002:3.1 makes the communication facility the one optional element of that standard — and 2014 and 2023 carry the same rules, so both are provided at every edition they exist in (2002 and later; at COBOL-85 each is refused as a later edition's construct, COBOL0900). **Provided:** the FORMAT clause on a sequential or line sequential file description entry, with any combination of BIT, CHARACTER and NUMERIC (the representation: A.1 item 84; its exclusions: item 85); the SELECT WHEN clause on the 01-level record description entries of such a file, evaluated in the order written, for the FORMAT clause and for the item-by-item conversion of a CODE-SET clause (§2023:13.18.13.4 GR4); I-O status 45 when no entry is selected (what the clauses do without a CODE-SET or a FORMAT clause: A.1 item 173); every syntax rule of both clauses (COBOL7342, COBOL7343), the external file connector's agreement of FORMAT clauses (GR12) and OPEN I-O of a FORMAT file (§2023:14.9.27.3 SR9) refused; SORT and MERGE of such files, whose short records are filled with the space the SELECTED entry names (D-SMF). **Not provided:** a record description entry holding a table whose size depends on a data item or is dynamic, and a FORMAT file with no record description entry (the items would be those of a READ INTO or WRITE FROM operand, §2023:13.18.24.4 GR2 c) — refused by name, COBOL7344; and the FILE phrase of WRITE and REWRITE (Annex A.4.13, COBOL1706), which is the other way a SELECT WHEN clause is evaluated under §2023:13.18.51.4 GR1. The module's items are documented in section 7: A.1 items 84, 85 and 173. Witnesses `conformance:cases/13.18.24-FORMAT-clause/format_roundtrip_character_numeric`, `conformance:cases/13.18.51-SELECT-WHEN-clause/select_when_selects_record`, `conformance:cases/13.18.51-SELECT-WHEN-clause/select_when_no_record_selected_status_45`."]
