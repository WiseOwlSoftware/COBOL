Three mechanisms in the communication and debugging emitters, each re-probed on this build first and each reproducing as the notes describe.

**PB5282 (a called program's INITIAL CD).** `InitialArea` filled every program's INITIAL CD from `WISEOWL_COBOL_MCS_SCHEDULED`. §1985:XIV.2.2.4 GR28 and §1985:XIV.2.2.4 GR6 give the names to the program the MCS schedules and spaces "in all other cases". `ModuleStack.RunningIsMain` (the frame `PushMain` pushed) now tells `MessageControl.InitialArea`, which passes `scheduledProgram` to the session; a CALLed program's CD is spaces and takes no terminal lock. The scheduling terminal is an environment variable no conformance-suite case can set, so the witnesses are `ScheduledProgramTests` and a unit test on the session.
