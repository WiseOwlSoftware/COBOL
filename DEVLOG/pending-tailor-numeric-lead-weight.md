## No character may carry the numeric lead's primary, in a .tailor or a CLDR collation (PB4264)

A numeric `.tailor` primary equal to the digit zero primary - 1 gave the character the primary of CollationTable.NumericLead, the lead of a number under numericOrdering. Only the CLDR builder kept that value free (CldrTailoringBuilder.Line reservedTop); a hand-written weight can name any value, and nothing checked it.

Re-probe on the build: U+E000 at the lead applied without error and carried the lead primary (unit test red before the fix). Fix at the root: CollationTable.WithTailoring reads the PRODUCED table NumericLead after Rebuild and refuses an entry whose primary equals it with a LocaleCollationException naming the file and the entry line (PB2773 contract); a tailoring that moves the digit zero moves the reserved value with it. Two unit tests (root scale; the tailored-zero case), and the TailoringRules format summary states the reserved value. No conformance golden: no ISO rule governs a .tailor file. Rows: none claimed, none closed.

Review round 1 (R1-1, blocking): the entry-only check missed the same collision reached by moving the digit zero: a .tailor line U+0030 at P_a + 1, or the CLDR rule &a < 0 (the builder numbers an inserted slot root + 1), put the lead on the untailored letter a, so under numericOrdering 1 sorted inside the a-words. Re-fix: the invariant (no character carries NumericLead.Primary) is checked in CollationTable.Rebuild over the produced table's reachable mappings (RefuseNumericLeadCarrier), so every derivation is covered; the CLDR builder keeps it by construction, marking the digit zero's inserted primary slot ReservesValueBelow so Line.Number leaves the value below it unused (&a < 0 now builds with the zero after a). Tests: a .tailor that moves the zero onto a letter's lead is refused with its line and one value further is legal; a CLDR theory over three rule shapes (&a < 0, &a < X < 0, &a < X << 0) asserts the lead is free and numbers sort after the a-words; without the builder's reservation all three were red.
