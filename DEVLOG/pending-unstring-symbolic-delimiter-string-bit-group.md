## UNSTRING DELIMITED BY a bare symbolic character is one occurrence; STRING refuses a bit group under the one usage predicate

Wave 1111 group F fixed two R2 findings in the STRING/UNSTRING binder (kb/Work PB3226, PB3228). Both inventory rows they touch were already CONFORMS, so no row closes; each row gains the witnesses for the case its verdict had hidden.

**PB3226, UNSTRING DELIMITED BY symbolic-character.** Re-probe on the Debug build: with `SYMBOLIC CHARACTERS COMMA-CH IS 45` and sender `"A,,B"`, `DELIMITED BY COMMA-CH INTO X1 X2 X3` displayed `[A  ][B  ][   ]`, while `DELIMITED BY ","` displayed `[A  ][   ][B  ]`, the result §14.9.48.4 GR8 requires. `ExpressionBinder.SymbolicOperand` binds a bare symbolic character as a `BoundAllLiteral` with `BeginsWithAll` false, and `BindUnstring` rewrote every `BoundAllLiteral` delimiter into a plain literal with the ALL flag set. The rewrite now sets the flag from the written `ALL` token or from `BeginsWithAll`, so only the ALL phrase collapses contiguous delimiters (GR7). Sweep: INSPECT already keys on the written ALL token; no other consumer turns a `BoundAllLiteral` into a phrase flag. Golden `pb3226_unstring_symbolic_delimiter` covers the bare symbolic character, the literal, `ALL` symbolic and `ALL` literal, with a numeric middle receiver that GR8 zero-fills.

**PB3228, STRING SR1 and the bit group.** Re-probe: `STRING BG DELIMITED BY SIZE INTO R` over a `GROUP-USAGE BIT` group compiled clean and sent the bit string as characters, while `INSPECT BG TALLYING` was refused COBOLNET1626 under the word-identical sentence. `StringUnstringBinder.Sr1Offence` re-derived "described implicitly or explicitly as usage display or national" from `Pic.Usage` guarded by `!IsGroup`, so the as-if elementary bit group (§13.18.29.4 GR1 b) fell through. The rule is now one predicate in `ItemCategory` beside `UsageOf`: `IsDisplayOrNationalUsage` (INSPECT's elementary arm asks it) and `UsageOutsideDisplayOrNational` (STRING asks it for the offending item). The strongly-typed group's leaf walk moved there as its strongly-typed arm, and the `StoreAsImage` exemption is deleted, since a storage form is not a usage. A variable-length group, for which the standard states no usage, stays admitted as before. Goldens: three refusals (identifier-1, -2 and -3 as a bit group, COBOLNET1626 at 2002 and later) and a positive control with an alphanumeric and a national group. `DisplayOrNationalUsagePredicateDriftTests` pins that both rules ask the one predicate and that the leaf walk exists once. `COBOLNET_STRING_OPS_DESIGN.md` is updated.

No diagnostic code was used; the three codes allocated (COBOLNET4256-4258) are returned.
