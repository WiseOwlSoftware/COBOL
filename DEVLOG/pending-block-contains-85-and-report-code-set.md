## PB5115 and PB5202: the 1985 BLOCK CONTAINS clause takes equal bounds, and a CODE-SET report file screens its printable items

**PB5115.** At `--std 85` `FD F BLOCK CONTAINS 2 TO 2 RECORDS` was refused COBOL2009, the 2023 rule that integer-2 be greater than integer-1 (§2023:13.18.10.3 SR1), which kb/Work PB1217 had applied at every edition. The 1985 clause has no syntax rules and says only that the integers are the minimum and maximum physical record size (§1985:VII.3.3.3 GR4); the rule first appears in §2002:13.16.10.2 SR1. `BindBlockContainsClause` now asks it from 2002. Re-probe before the fix: refused at 85 and at 2002; after: translates and round-trips three records at 85, still refused at 2002 and 2023. Goldens: `1985-FMT-VII_3_3_2` (accepted at 85); `pb1217-block-contains-equal-bounds` and `pb1217-block-contains-inverted-range` now refuse from 2002 only.

**PB5202.** At `--std 85` a report file with CODE-SET took a signed PIC S9(4) printable item with no SIGN clause and wrote an over-punched sign, because `CheckCodeSetRecordItemsPass` walked only `FileModel.WrittenRecords` and a report file has none. §1985:VII.3.4.3 SR1 covers "all data in that file", and §1985:XIII.3.2.4 GR3 gives the report file description the Sequential I-O clause rules. The pass now also walks the printable items of the reports the file's REPORT clause names, at 85 only (the later editions word the rule over data and record description entries). The per-item screen became one predicate shared by both arms. Output: the repro is refused COBOL1672 at the item; with SIGN IS LEADING SEPARATE it writes `AMT  -0012`. Goldens: `pb5202-report-code-set-signed-item-refused`, `pb5202-report-code-set-sign-separate`. Rows `1985-SR-VII.3.4.3-1` and `1985-GR-XIII.3.2.4-3` PARTIAL to CONFORMS (GAP 207 to 205).

**Self-review.** Architecture: the report arm lives in the pass that already owns the CODE-SET screen, not in the report binder. Code: the 85 arm cites the 1985 rule and the record arm keeps its 2023 text unchanged. Performance: one hash set per CODE-SET report file. Duplication: the two arms share `CheckCodeSetItem`.
