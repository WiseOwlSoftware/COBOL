## PB5625 adjudicated: three 2002 determinations recorded, defect PB5674 filed, reading D held on a failed Annex D check

**The adjudication.** kb/Work PB5625 held four open readings of the 2002 text. The lead session decided all four on 2026-11-15 (`kb/Work/PB5625/2026-11-15-adjudication.md`, copied unchanged). This landing puts A, B and C on record and holds D. No compiler source, test, golden or inventory record changes; every citation written was run through `cite.py --check` (31 from the adjudication, 27 more in the new files, all OK except a too-short quotation whose clause was then found with `--find`).

**A.** A reference to a parameterized interface or class that the REPOSITORY lists without EXPANDS is refused at every edition. At 2002 this is a determination for a gap in the text (`docs/conformance/3/D-PARAMETERIZED-UNEXPANDED.md`): §2002:12.2.7.3 GR7 grants the name, and no rule gives it a meaning. The 2002 class text (§2002:9.3.12, §2002:12.2.7.3 GR1 and GR5) has the same gap, so the determination covers both. COBOL0859 and its class sibling COBOL0813 still cite §2023 rules at `--std 2002`, which is filed with PB4950.

**B.** At 2002 a PIC 9 or PIC 1 item of USAGE NATIONAL is class and category numeric or boolean. §2002:8.5.2.7 item 3 is recorded as a defect in the text (`D-USAGE-NATIONAL-CLASS-2002.md`).

**C.** SET of an index outside its table with checking not enabled stores the value (`D-SET-INDEX-UNCHECKED.md`, §2002:B.1 item 51). GnuCOBOL 3.2.0 does the same, measured in WSL under `-std=default`, `-std=cobol2002` and `-std=cobol2002 -debug`. With checking enabled the compiler is wrong: under `>>TURN EC-BOUND-SUBSCRIPT CHECKING ON` at `--std 2002`, `SET IX TO 11` on a 10-entry table printed `S2=11` and ran no declarative, where §2002:14.8.35.3 GR2a.1 and GR3b leave IX at 3 and raise the condition. A control program with an out-of-range subscript reference does raise it. This is new defect **PB5674**, which takes rows `2002-GR-14.8.35.3-2` and `-3`. The GR3a arm (a non-integer UP BY amount) already conforms. `SetEmitter` and `CobolIndex` have no edition-dependent path, so 2002 runs the 2023 rule.

**D held.** Before D could be recorded, the adjudication required a check that every Annex D pair maps as the annex lists it. The full check, a generated program over all 600 pairs, fails on 5 pairs. LOWER-CASE maps 596 of 600; U+0130, U+0256, U+0131 and U+03C2 come back unchanged. UPPER-CASE maps 586 of 587 unambiguous lowercase letters; U+0189 comes back unchanged. Page 724 of the 2002 PDF prints the 0130 and 0256 pairs as transcribed. The adjudication makes each failing pair its own note, and no id was allocated for one, so `D-CASE-MAPPING` is not extended. PB5625 is `half` until that is done (`kb/Work/PB5625/2026-11-15-recording.md`).
