## PB4569, PB1654, PB4446 and PB4239 — four determinations become defects

Four read-only determinations (wave 20261861) turned four open `kb/Work` leads into defects and filed their siblings. No code changed.

**PB4569.** Under native arithmetic an integer base raised to an integer exponent past the Int128 carrier is a binary64 approximation, so `ABS (2 ** 130)` shows 16 digits. The deciding citation is `OK  §8.8.1.3` ("Native arithmetic is an implementor-defined method of evaluating an arithmetic expression ..."), which leaves the technique to the implementor, so CLAUDE.md rule 1 sends it to GnuCOBOL, whose run-time power is exact. The 16-digit carrier is NUMERIC_DESIGN D19 (a), an owner decision of 2026-08-03 (PB18). The owner decided on 2026-11-04, asked whether rule 1's precedence supersedes D19 (a): "Yes, exact". The fix therefore changes D19 (a), DOC-A.1-123, DOC-A.1-179 and the pb69 golden. Filed from it: PB4587 (a power past 77 digits is a round-to-odd chain, not correctly rounded: `2.5 ** 100`; an analysis, PB4111's question) and PB4588 (upstream: cobc 3.2.0 folds `literal ** literal` in a wrapping signed 64-bit integer, `2 ** 130` gives 0; nothing posted).

**PB1654.** The `.Pic is { }` audit now covers 108 sites in 57 files and found no under-rejection: wherever a rule names group kinds, the group arm is asked separately. The one defect is a diagnostic face, `CheckAlignedClausesPass.DescribeAlignedSubject`, which calls a strongly-typed or variable-length group "an alphanumeric group item" and prints the enum name "numericedited". The deciding citation is `OK  §13.18.1.3 1)` ("The ALIGNED clause may be specified only for a bit group item or an elementary bit data item") with `OK  §3.11` and `OK  §13.18.29.4 3)`. The note is now a MINOR defect (`under_rejects` false). PB3229 gained the four enum-name sites CA1308 cannot see.

**PB4446.** A Table 15 refusal (COBOL1634) hides every fault in the selection object's own reference, and the surplus objects of an SR2 breach are never bound. The no-88 control gives the same, so the hidden condition-name plays no part. The deciding citation is `OK  §4.2.2   (Acceptance of standard language elements)` ("An implementation shall provide a warning mechanism ... to indicate violations of the general formats and the explicit syntax rules"), with `OK  §14.9.13.3 10)` for Table 15. The note is now a TRIVIAL defect (`misleads_diagnosis`).
