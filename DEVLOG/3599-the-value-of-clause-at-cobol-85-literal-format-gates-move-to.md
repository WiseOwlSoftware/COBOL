## Entry 3599 — 2026-11-14 05:37 PST — The VALUE OF clause at COBOL-85: literal format gates move to the token, an index group is refused, literals agree by value (PB5416, PB5417, PB5362)

Wave 20262029 group C, three notes on the obsolete FD clause VALUE OF, each re-probed on this worktree's build first.

**PB5416: the national and boolean literal gates were position-scoped.** At --std 85 `VALUE OF ID IS N"AB"`, `B"1"`, `NX"0041"` and `BX"4"` compiled and ran `FS=00`, while `X"4142"` in the same position was COBOL0900. The `X"…"` gate was the literal token's (`LiteralScreen.GateFormat`, asked of every literal token), but the national and boolean gates were the version pass's `VisitNonNumericLiteral` and `VisitFigurativeConstant`, scoped to a procedure-division statement on the reasoning that a data-division literal seeds an item whose category `GateData` gates. A literal in VALUE OF, a level-88 VALUE of an alphanumeric item, a VALUE of a PIC X item or a SPECIAL-NAMES CLASS or ALPHABET literal seeds no national or boolean item, so the edition was never named (the last four drew a category refusal alone). The gates now sit in `GateFormat` beside the hexadecimal one, position-blind; the two version-pass arms and their `InStatement` helper are deleted, and `EditionGateArmDriftTests.AdjudicatedDualArm` loses the two entries that described the split. Every position above now draws COBOL0900; a national item's own national VALUE literal draws two reports, the item's and the literal's, each at its own position. The note's 19-digit arm is dropped as its adjudication found: 18 digits is the least a 1985 implementor must allow (§1985:IV.4.2.2.2.2). That the compiler's own 18-digit literal limit at 85 is asked only of procedure-division literals is left as a lead.

**PB5417: an index group passed as data-name-1.** `ResolveValueOfDataNames` asked only the elementary usage, so `01 G-IX USAGE INDEX` (and an 03 group with the clause) named in VALUE OF compiled while its subordinate was COBOL6849. §1985:VII.3.9.3 SR1 bars "an item described with the USAGE IS INDEX clause", and the group's own entry is; the screen now asks `DataItem.OwnUsage` too. A group that merely contains an index item is still admitted.

**PB5362: VALUE OF literals compared by spelling.** The external connector's consistency rule compared each literal-1 by `GetText()`, so `'A'` and `"A"` conflicted. `ValueOfLiteralValue` keys a literal by class and value: decoded content in hexadecimal (which also closes a latent break, a decoded `|` or `=` splitting the joined key), a numeric literal by its normalized value, a figurative constant by its kind. `FdClauseValue` gains `Written`, the clause as written, which COBOL6847 now shows in place of the comparison key.
