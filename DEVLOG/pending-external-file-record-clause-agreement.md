## The RECORD clause joins the external file connector's file description agreement rules; PADDING CHARACTER refuses a table element

Wave 20262029, group H (kb/Work PB5387, PB5499).

**PB5387.** Two programs of one run unit describing the same EXTERNAL file with RECORD CONTAINS 80 and RECORD CONTAINS 90 compiled and ran, sequential and report files alike, while the BLOCK CONTAINS and LABEL RECORDS disagreements were refused COBOL6847. Re-probe on this build reproduced both repros. The note cited §1985:VII.3.8.4 GR2, which is the RECORD clause's rule ("must specify the same values for integer-1 or integer-2 and integer-3. If the RECORD clause is not specified, all record description entries associated with this file connector must be the same length"). The fix is two rows in `FileDescriptionIdentity.Rules`, the table the 1985 file description clauses are compared by: RECORD (the clause's operands; Format 1 integer-1, Formats 2 and 3 the pair; an omitted or refused operand agrees with anything) and RECORD-LENGTH (entries that write no clause, compared by smallest and largest record size). No new arm in `ExternalFileConnectorRules`: its one loop reads the table. The LINAGE row had carried this rule's citation; LINAGE's own is §1985:VII.3.7.4 GR11, so the code, docs and the PB5300 golden (moved to the LINAGE folder) now say so. Goldens: pb5387-external-record-contains-differ and pb5387-external-record-lengths-differ (refused COBOL6847 at 85), pb5387-external-record-varying-agree (Format 2 against Format 3 with the same pair runs). Row 1985-GR-VII.3.8.4-2 NOT-IMPLEMENTED to CONFORMS.

**PB5499.** The lead said PADDING accepts table elements. Re-probe: a subscripted operand was refused already (COBOL2024); an unsubscripted table element (`PADDING CHARACTER IS PT`, PT PIC X OCCURS 3) compiled and ran. The clause names a qualified data-name only (§1985:VII.2.7.3 SR2) and a table element reference must be subscripted (§1985:IV.4.3.8.2.3 SR4; §2002:8.4.1.2.2 SR5), so no reading exists; `ScreenPaddingDataName` refuses it (COBOL6848). Golden pb5499-padding-table-element.

Not changed: the 2002 and later texts' own external-FD rule (§2023:13.4.5.4 GR2 d) is not asked here; the table asks COBOL-85 only, as before.
