## Work register: the $200 API credit gets a note (PB3309), and a hung Linux gate is traced to concurrent landings of one branch (PB3310)

The owner said the WiseOwl Software API organization holds $200 of API credit, to be used before 2026-11-04. It came from linking account 1 to that organization. Account 2 could only join the organization as a member, and its own credit did not apply. Account 2's billing page says "None of your API organizations can be linked. Create one to start receiving credits." So its own $200 a month needs a new organization of its own, which is an owner action.

The telemetry gives the exchange rate. Account 2 spent about $300–340 of API-priced tokens on 2026-10-16 while its meter moved about 12 points, so a Max weekly point is worth about $25–30 at API prices and the credit buys about 7 points. The difference comes from cache reads: the API bills them, and the subscription meter's calibration does not count them. PB3309 records what the lane needs: the owner's one-time sign-in of a dedicated config dir, an account row of kind `api` with a dollar cap and an expiry, and a check that API-key telemetry is attributed. Telemetry without `user.account_uuid` is counted against both Max estimates today.

PB3310: a Linux gate held a gate slot from 10:15 to 16:57, one third of landing capacity, for a branch that had already merged at 10:34. Two `enqueue.py land` runs of `notes-leads-enqueue-20261016d` overlapped, because a unit's `nohup` launch is outside the landing lane's attempt tracking and `enqueue.py` has no per-branch lock. `linux-gate.sh` keys its WSL snapshot and its log directory on the tree's basename and deletes both at start, so the second run removed the first's clone while the first was still testing in it. The first run's `dotnet test` processes then deadlocked in directories marked `(deleted)`. The operator stopped the stale tree after re-reading its command line. The note gives the fix: a per-branch lock, per-run snapshots removed on exit (which also closes PB3194's leak), and a surfaced ceiling on slot hold time.
