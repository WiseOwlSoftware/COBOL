## The drift-rule index reads the committed tree's sweeps, and the gate runs every governing drift test in leg 1 (PB3531)

PB3523's branch edited `scripts/differential_fuzz.py`, gated GREEN on Windows, and went RED in the landing's Linux unit leg on `CatalogCoverageDriftTests.NoScriptOrTest_SpellsTheGeneralFormatHeadingItself`, a sweep that reads every tracked script. `drift_rules.py scripts/differential_fuzz.py` had not listed it, and the gate's planner had left it in leg 2 (44 s recorded, so not a cheap tier-0c sweep). The re-probe on this branch's base reproduced it: 0 specific rules, 5 sweeps, no CatalogCoverageDriftTests.

The cause was structural. Seven drift classes read `git ls-files` through `TrackedTree.Files()` and filtered the list in code, so they named no path the index could read. The fix gives them one declaration that both sides read. `TrackedTree.Files(TreeScope)` is now the only read of the tree, and `TreeScope(Under, Except, Kinds)` is its one filter (`Holds`), declared as a `static readonly` field of string literals. The parameterless `Files()` is deleted and every caller moved; each sweep's planted failure-branch test applies the same scope. `drift_rules.py` reads the declarations (`scopes_of`) and applies them as `Holds` does (`in_scope`), so a class governs every file its scope holds. It also gained `--scopes`, `--held` and an unreadable-scope arm in `--check`. ConflictMarkerDriftTests and LandingMeasureDriftTests became sweeps and carry the `Sweep` trait. ConflictMarker and NulByte now sweep the tree once per test assembly rather than once per test.

The planner got a new tier, 0d. `impacted_tests.Reach.drift_tests` comes from the diff alone (no gate on 2026-10-22 had an impact map) and names the drift tests the index says govern a changed file. `gate_plan.py` puts them in leg 1, exempt from the budgets and the cap. The tier order is now `0a, 0h, 0c, 0d, 0u, 1, 2, 3`. `TrackedTreeScopeDriftTests` holds three things: every scan names a declared field, every declaration is read as the compiler builds it, and `in_scope` equals `Holds`. Its failure branch was fired on planted source, and once for real: its own failure message spelled a declaration and the index read it. Self-test arms cover tier 0d in `gate_plan.py` and the real index's answer for `scripts/differential_fuzz.py` in `impacted_tests.py`.
