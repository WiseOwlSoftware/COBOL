## The entry-name slot names its entry, and a dangling level-number before a section header is a missing period again

Two leads from the PB4604 landing, one root: how `CobolErrorStrategy` reads the first word after a data description entry's level-number.

**PB4646.** `01` with its period forgotten, then `LINKAGE SECTION.` (or `REPORT SECTION.`, `END PROGRAM`, `IDENTIFICATION DIVISION.`), drew COBOL0901 "reserved word" at the header word, where the missing-period report COBOL0307 stood before PB4604. `OffendingPosition.EntryNameIsDue` marked the slot from the previous token alone. It is now false when the word and the token after it are taken by a walk from the entry's end in its real context (`BeginsWhatFollows`, `ResimulationWalk.After` with the error productions skipped), so `ReservedWordUse`, `ClosedFormatResidue` and the extension-word hint all stand down together. Two tokens, because one cannot tell `01 LINKAGE SECTION.` from `01 LINKAGE PIC X.`, where LINKAGE is a name written and keeps COBOL0901. `ClosedFormats.EntryNameDueAfter` became `EntryAwaitingItsName`, returning the entry; its one caller changed.

**PB4645.** `01 W-A MOVE.` drew COBOL1941 without `for 'W-A'`, while `01 W-A PIC X MOVE.` named it. The decision at the entry's optional name looks ahead past W-A and dies at MOVE with the parser still before the name, so the context holds no data-name. `OffendingPosition.OwnerName()` falls back to the word written after the level-number when only the data-name rule can begin it (`ClosedFormats.EntryNameOnlyWords`: FIRST(dataName) less the clause starts read from the ATN, not counting the error production's opening) and the parser has not passed it. A word that is also a clause start stays unnamed. The FD, SD and SELECT names are mandatory and attached first (probed), so the data description entry is the one format with the gap.

Goldens: `pb4645-clause-word-after-an-entry-name` and `pb4646-dangling-level-number-before-section-header` under `13.16-Data-description`, each refused at all four editions; unit cases in `ClosedFormatReservedWordTests` (names W-A, FILLER and a level-05 entry; the dangling level-number at four editions; `LINKAGE PIC X.` and `LINKAGE.` as controls). Rows closed: none (both notes claim none).

Found and not fixed: `01` then `PROCEDURE DIVISION.` reads PROCEDURE as the entry's name (the NC205A alternative) and refuses DIVISION as a clause "for 'PROCEDURE'", where a missing period is the likelier reading; it is a grammar alternative, not this strategy, and is filed as a lead in the report.
